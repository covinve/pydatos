Las funciones puras se prueban fácil: llamas y comparas. Pero tus programas también leen archivos, imprimen, leen variables de entorno y escriben logs. pytest trae herramientas para todo eso.

## Archivos: tmp_path

Nunca uses los datos reales en las pruebas: crea archivos pequeños, con exactamente los casos que quieres probar, en una carpeta temporal que pytest borra sola.

```python
def test_cuenta_registros_por_tipo(tmp_path):
    archivo = tmp_path / "cdr.csv"
    archivo.write_text(
        "cdr_id|linea_origen|tipo|duracion_seg\n"
        "1|3001|VOZ|125\n"
        "2|3001|SMS|0\n"
        "3|3002|VOX|10\n",
        encoding="utf-8",
    )

    resumen = resumir(archivo)

    assert resumen["por_tipo"] == {"SMS": 1, "VOX": 1, "VOZ": 1}
```

:::consejo Datos de prueba pequeños y elocuentes
Tres o cuatro registros elegidos a mano, uno por caso, valen más que mil registros aleatorios: cuando la prueba falla, entiendes por qué.
:::

## Variables de entorno, atributos y argumentos: monkeypatch

`monkeypatch` cambia algo **solo durante la prueba** y lo restaura al terminar:

```python
def test_lee_la_carpeta_de_entrada_del_entorno(monkeypatch, tmp_path):
    monkeypatch.setenv("CARPETA_CDR", str(tmp_path))
    assert carpeta_entrada() == tmp_path


def test_argumentos_de_terminal(monkeypatch, capsys):
    monkeypatch.setattr("sys.argv", ["telco-formato", "48719.5"])
    main()
    assert capsys.readouterr().out == "$48.720\n"


def test_reintento_sin_esperar(monkeypatch):
    esperas = []
    monkeypatch.setattr("time.sleep", esperas.append)   # reemplaza sleep por una función que solo anota
    con_reintentos(funcion_que_falla_dos_veces, espera=1)
    assert esperas == [1, 2]
```

Esto se llama **reemplazar una dependencia** (*mock*): la prueba no espera de verdad, no depende de la hora ni de la configuración de tu computador.

## La bitácora: caplog

```python
import logging


def test_advierte_lineas_desconocidas(caplog):
    with caplog.at_level(logging.WARNING):
        validar([{"linea_origen": "3999999999", "tipo": "VOZ"}], lineas_clientes={"3001"})
    assert "3999999999" in caplog.text
    assert caplog.records[0].levelname == "WARNING"
```

## La hora actual: inyectarla en lugar de leerla

Una función que llama a `datetime.now()` adentro da resultados distintos cada día: es difícil de probar. La solución más limpia no es un truco de pytest sino de diseño: **recibir la fecha como parámetro**.

:::comparar
:::mal Difícil de probar
```python
def antiguedad(fecha_alta):
    return (date.today() - fecha_alta).days // 365
```
:::
:::bien Fácil de probar
```python
def antiguedad(fecha_alta, hoy=None):
    hoy = hoy or date.today()
    return (hoy - fecha_alta).days // 365

def test_antiguedad():
    assert antiguedad(date(2020, 5, 10), hoy=date(2026, 9, 30)) == 6
```
:::
:::

:::telco Pruebas que corren en cualquier lado
Una prueba que lee `D:\facturacion\septiembre\cdr.csv` solo funciona en tu computador. Con `tmp_path` y datos pequeños, las mismas pruebas corren en tu PC de la casa, en el de la oficina y en GitHub Actions (módulo 20), cada vez que subes un cambio.
:::
