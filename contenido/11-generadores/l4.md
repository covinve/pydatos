Un **pipeline** es una cadena de etapas en la que cada una recibe los registros de la anterior, los transforma y los pasa a la siguiente. Con generadores, **cada registro recorre todo el pipeline antes de que se lea el siguiente**.

## Un pipeline completo

```pyrun
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n1|3001|VOZ|125\n2|3001|SMS|0\n3||VOZ|60\n4|3002|VOZ|-5\n5|3002|VOZ|61\n",
    encoding="utf-8",
)


def leer(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield linea.rstrip("\n")


def parsear(lineas):
    for linea in lineas:
        cdr_id, linea_origen, tipo, duracion = linea.split("|")
        yield {"cdr_id": int(cdr_id), "linea": linea_origen, "tipo": tipo, "duracion": int(duracion)}


def validos(cdrs):
    for c in cdrs:
        if c["linea"] and c["duracion"] >= 0:
            yield c


def minutos_por_linea(cdrs):
    totales = {}
    for c in cdrs:
        if c["tipo"] == "VOZ":
            totales[c["linea"]] = totales.get(c["linea"], 0) + (c["duracion"] + 59) // 60
    return totales


print(minutos_por_linea(validos(parsear(leer("cdr.csv")))))
```

Cada etapa es una función pequeña, fácil de probar por separado (con una lista en lugar de un archivo) y fácil de reordenar o reemplazar.

## Medir la memoria: tracemalloc

`tracemalloc` (biblioteca estándar) mide cuánta memoria reservó Python:

```pyrun
import tracemalloc

tracemalloc.start()
total = sum((d + 59) // 60 for d in range(2_000_000))       # generador
_, pico_generador = tracemalloc.get_traced_memory()
tracemalloc.reset_peak()

total = sum([(d + 59) // 60 for d in range(2_000_000)])     # lista
_, pico_lista = tracemalloc.get_traced_memory()
tracemalloc.stop()

print(f"Pico con generador: {pico_generador / 1e6:6.2f} MB")
print(f"Pico con lista:     {pico_lista / 1e6:6.2f} MB")
```

## Duplicados con memoria acotada

Detectar duplicados con un `set` de todos los IDs necesita memoria proporcional al archivo: con 280 millones de CDR no cabe. Pero si sabes que los duplicados aparecen **cerca** del original (como en los datos del curso, donde el duplicado llega a menos de 5.000 registros de distancia), basta recordar los **últimos N** IDs:

```pyrun
from collections import deque


def duplicados_cercanos(ids, ventana):
    recientes = deque(maxlen=ventana)   # al llenarse, descarta el más viejo solo
    vistos = set()
    for cdr_id in ids:
        if cdr_id in vistos:
            yield cdr_id
            continue
        if len(recientes) == ventana:
            vistos.discard(recientes[0])
        recientes.append(cdr_id)
        vistos.add(cdr_id)


print(list(duplicados_cercanos([1, 2, 3, 2, 4, 5, 1, 6], ventana=3)))
```

El `1` del final no se detecta porque ya salió de la ventana de 3. Es un **compromiso consciente**: memoria constante a cambio de detectar solo duplicados cercanos. Documenta siempre ese supuesto.

:::telco El supuesto debe verificarse
"Los duplicados llegan cerca" es una hipótesis sobre el sistema de mediación. Antes de confiar en ella, verifícala con un archivo mediano usando el método exacto (`set`) y el aproximado (ventana): si dan lo mismo, puedes usar la ventana con el archivo grande. Lo harás en el ejercicio 7.
:::
