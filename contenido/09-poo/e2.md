## Enunciado

Modela un CDR como dataclass **inmutable** (`frozen=True`) con los campos `cdr_id: int`, `linea_origen: str`, `tipo: str`, `destino: str`, `duracion_seg: int` y `mb: float`. Agrega:

1. La propiedad `minutos_facturables` (redondeo hacia arriba; 0 si no es `VOZ`).
2. El constructor alternativo `desde_linea(texto)` (`@classmethod`) que crea el CDR a partir de una línea de `cdr.csv` (separada por `|`, con o sin salto de línea al final).

```python
c = CDR.desde_linea("2|3302703263|3040879936|VOZ|NACIONAL|2026-09-13 10:31:28|30|0.000|CEL97932\n")
c.cdr_id                 # 2
c.minutos_facturables    # 1
c.duracion_seg = 99      # FrozenInstanceError
```

## Código inicial

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class CDR:
    pass


c = CDR.desde_linea("2|3302703263|3040879936|VOZ|NACIONAL|2026-09-13 10:31:28|30|0.000|CEL97932\n")
print(c, c.minutos_facturables)
```

```python
import dataclasses

LINEA = "2|3302703263|3040879936|VOZ|NACIONAL|2026-09-13 10:31:28|30|0.000|CEL97932\n"


def prueba_campos():
    """Tiene los seis campos con sus tipos"""
    requiere("CDR")
    nombres = [f.name for f in dataclasses.fields(CDR)]
    igual(nombres, ["cdr_id", "linea_origen", "tipo", "destino", "duracion_seg", "mb"])


def prueba_desde_linea():
    """Crea el CDR desde una línea del archivo"""
    igual(CDR.desde_linea(LINEA), CDR(2, "3302703263", "VOZ", "NACIONAL", 30, 0.0))
    datos = CDR.desde_linea("3|3042731004||DATOS||2026-09-11 05:04:00|1199|15.131|CEL40460")
    igual((datos.tipo, datos.destino, datos.mb), ("DATOS", "", 15.131))


def prueba_minutos():
    """minutos_facturables es una propiedad"""
    igual(CDR(1, "3001", "VOZ", "LOCAL", 125, 0.0).minutos_facturables, 3)
    igual(CDR(1, "3001", "DATOS", "", 900, 5.0).minutos_facturables, 0)


def prueba_inmutable():
    """No se puede modificar"""
    c = CDR.desde_linea(LINEA)
    lanza(dataclasses.FrozenInstanceError, setattr, c, "duracion_seg", 99)


def prueba_hashable():
    """Se puede usar en conjuntos"""
    igual(len({CDR.desde_linea(LINEA), CDR.desde_linea(LINEA)}), 1)
```

## Solución

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class CDR:
    cdr_id: int
    linea_origen: str
    tipo: str
    destino: str
    duracion_seg: int
    mb: float

    @property
    def minutos_facturables(self):
        return (self.duracion_seg + 59) // 60 if self.tipo == "VOZ" else 0

    @classmethod
    def desde_linea(cls, texto):
        campos = texto.rstrip("\n").split("|")
        return cls(
            cdr_id=int(campos[0]),
            linea_origen=campos[1],
            tipo=campos[3],
            destino=campos[4],
            duracion_seg=int(campos[6]),
            mb=float(campos[7]),
        )


c = CDR.desde_linea("2|3302703263|3040879936|VOZ|NACIONAL|2026-09-13 10:31:28|30|0.000|CEL97932\n")
print(c, c.minutos_facturables)
```

## Explicación

Con 15 líneas tienes un tipo de dato completo: se construye desde el archivo, se imprime legible, se compara por valor, se puede meter en conjuntos y no se puede alterar por accidente.

Pasar los argumentos por nombre en `cls(cdr_id=..., ...)` hace que el constructor no dependa del orden de los campos: si mañana alguien agrega un campo en el medio de la clase, este código sigue correcto.
