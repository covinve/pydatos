## Enunciado

El módulo `lineas.py` tiene `es_linea_movil(texto)`: normaliza el texto (quita espacios, guiones, puntos, paréntesis y el prefijo `+57`) y devuelve `True` si quedan exactamente 10 dígitos que empiezan por `3`.

Escribe **una sola** función de prueba parametrizada con `@pytest.mark.parametrize` y **al menos 8 casos** (válidos e inválidos) que atrape los cuatro mutantes.

## Preparación

```python
from pathlib import Path

Path("lineas.py").write_text(
    "def es_linea_movil(texto):\n"
    "    limpio = texto.strip().removeprefix('+57')\n"
    "    for simbolo in [' ', '-', '.', '(', ')']:\n"
    "        limpio = limpio.replace(simbolo, '')\n"
    "    return len(limpio) == 10 and limpio.isdigit() and limpio.startswith('3')\n",
    encoding="utf-8",
)
```

## Código inicial

```python
import pytest

from lineas import es_linea_movil


@pytest.mark.parametrize(
    ("texto", "esperado"),
    [
        ("3001234567", True),
        # agrega aquí más casos
    ],
)
def test_es_linea_movil(texto, esperado):
    assert es_linea_movil(texto) == esperado
```

## Pruebas

```python
import ast

import pytest

CORRECTA = (
    "def es_linea_movil(texto):\n"
    "    limpio = texto.strip().removeprefix('+57')\n"
    "    for simbolo in [' ', '-', '.', '(', ')']:\n"
    "        limpio = limpio.replace(simbolo, '')\n"
    "    return len(limpio) == 10 and limpio.isdigit() and limpio.startswith('3')\n"
)


def correr(implementacion):
    return correr_pytest(codigo, {"lineas": implementacion})


def prueba_usa_parametrize_con_ocho_casos():
    """Una prueba parametrizada con al menos 8 casos"""
    casos = 0
    for nodo in ast.walk(ast.parse(codigo)):
        if isinstance(nodo, ast.Call) and "parametrize" in ast.unparse(nodo.func):
            lista = nodo.args[1] if len(nodo.args) > 1 else None
            if isinstance(lista, (ast.List, ast.Tuple)):
                casos = max(casos, len(lista.elts))
    assert casos >= 8, f"Usa @pytest.mark.parametrize con al menos 8 casos; encontré {casos}"


def prueba_pasan_con_el_codigo_correcto():
    """Tus casos pasan con la implementación correcta"""
    salida, texto = correr(CORRECTA)
    assert salida == 0, "Algún caso falla con el código CORRECTO:\n" + texto[-900:]


def prueba_atrapa_sin_prefijo():
    """Atrapan el mutante que no quita +57"""
    salida, _ = correr(CORRECTA.replace(".removeprefix('+57')", ""))
    assert salida == 1, "Ningún caso usa el prefijo +57"


def prueba_atrapa_sin_validar_digitos():
    """Atrapan el mutante que no revisa que sean dígitos"""
    salida, _ = correr(CORRECTA.replace(" and limpio.isdigit()", ""))
    assert salida == 1, "Ningún caso tiene letras con 10 caracteres"


def prueba_atrapa_cualquier_prefijo():
    """Atrapan el mutante que acepta líneas que no empiezan por 3"""
    salida, _ = correr(CORRECTA.replace(" and limpio.startswith('3')", ""))
    assert salida == 1, "Ningún caso es una línea fija (que empiece por 6)"


def prueba_atrapa_longitud():
    """Atrapan el mutante que acepta 9 o más dígitos"""
    salida, _ = correr(CORRECTA.replace("len(limpio) == 10", "len(limpio) >= 9"))
    assert salida == 1, "Ningún caso tiene 9 u 11 dígitos"
```

## Pista 1

Piensa un caso para cada condición de la regla: formato con guiones o espacios (válido), con `+57` (válido), fijo que empieza por 6 (inválido), con 9 dígitos, con 11, con una letra, vacío…

## Pista 2

Cada caso es una tupla `(texto, esperado)`:

```python
("+57 300-123-4567", True),
("6014445566", False),
("300123456", False),
("30012345678", False),
("300123456A", False),
```

## Solución

```python
import pytest

from lineas import es_linea_movil


@pytest.mark.parametrize(
    ("texto", "esperado"),
    [
        ("3001234567", True),
        (" 300 123 4567 ", True),
        ("(320) 555.1234", True),
        ("+57 315-777-8899", True),
        ("6014445566", False),
        ("300123456", False),
        ("30012345678", False),
        ("300123456A", False),
        ("", False),
    ],
)
def test_es_linea_movil(texto, esperado):
    assert es_linea_movil(texto) == esperado
```

## Explicación

Una tabla de casos es la forma más clara de documentar una regla con muchas condiciones: se lee como una especificación. Agregar un caso nuevo (por ejemplo, cuando aparece un formato raro en producción) es agregar una línea.

Fíjate que cada caso inválido existe para **una** condición específica: `"6014445566"` tiene 10 dígitos pero no empieza por 3; `"300123456A"` tiene 10 caracteres pero no son dígitos. Así, si un caso falla, sabes exactamente qué regla se rompió.
