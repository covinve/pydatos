Un carpintero profesional no empieza a trabajar sin tener su taller ordenado. En programación pasa lo mismo: antes de escribir código conviene saber **dónde** se escribe, **quién** lo ejecuta y **cómo** se le dan órdenes al computador.

## Las tres piezas

:::columnas
:::columna 🐍 Python
Es el **intérprete**: un programa que lee tu código línea por línea y lo ejecuta. Ya lo tienes instalado.
:::
:::columna 📝 VS Code
Es el **editor**: donde escribes el código. Te ayuda con colores, autocompletado, detección de errores y una terminal integrada.
:::
:::columna ⌨️ La terminal
Es la forma de darle **órdenes escritas** al computador: ejecutar un script, instalar una librería, guardar cambios con Git.
:::
:::

## Dos formas de ejecutar Python en este curso

| | En esta página | En tu computador |
|---|---|---|
| Dónde corre | En tu navegador (Pyodide, Python compilado para la web) | En el Python instalado en tu PC |
| Ideal para | Aprender conceptos y ejercicios cortos | Archivos grandes, Git, proyectos reales |
| Instalación | Ninguna | Python, VS Code y librerías |
| Archivos de 20 GB | ❌ | ✅ |

Pruébalo ahora. Cambia el valor del plan y vuelve a ejecutar:

```pyrun
cargo_fijo = 35900
iva = cargo_fijo * 0.19
print("Cargo fijo:", cargo_fijo)
print("IVA:", iva)
print("Total:", cargo_fijo + iva)
```

## La terminal sin miedo

La terminal integrada de VS Code se abre con **Ctrl + Ñ** (o **Ctrl + `** según tu teclado), o desde el menú **Terminal → New Terminal**. En Windows, por defecto es **PowerShell**.

Estos son los comandos que usarás el 90 % del tiempo:

| Comando | Qué hace | Ejemplo |
|---|---|---|
| `pwd` | Muestra en qué carpeta estás | `pwd` |
| `ls` | Lista los archivos de la carpeta | `ls` |
| `cd` | Entra a una carpeta | `cd ejercicios` |
| `cd ..` | Sube una carpeta | `cd ..` |
| `python archivo.py` | Ejecuta un script | `python comprobar.py --lista` |
| `python --version` | Muestra la versión de Python | `python --version` |
| Flecha ↑ | Repite comandos anteriores | |
| Tab | Completa nombres de archivos y carpetas | `cd ejer` + Tab |

:::consejo Tab es tu mejor amigo
Escribe las primeras letras de un archivo o carpeta y pulsa **Tab**: la terminal completa el nombre. Te ahorra tiempo y errores de escritura.
:::

## VS Code bien configurado

Instala estas extensiones desde el panel de extensiones (**Ctrl + Shift + X**). Todas son gratuitas y se instalan en tu usuario, sin permisos de administrador:

| Extensión | Para qué |
|---|---|
| **Python** (Microsoft) | Ejecutar y depurar Python, elegir el entorno virtual |
| **Pylance** | Autocompletado inteligente y detección de errores mientras escribes |
| **Jupyter** | Notebooks (`.ipynb`) dentro de VS Code |
| **Ruff** | Revisa el estilo de tu código y lo formatea |
| **Rainbow CSV** | Colorea las columnas de los archivos CSV |

Atajos que vale la pena aprender desde ya:

| Atajo | Acción |
|---|---|
| `Ctrl + P` | Abrir un archivo por su nombre |
| `Ctrl + Shift + P` | Paleta de comandos (todo lo que VS Code sabe hacer) |
| `Ctrl + /` | Comentar o descomentar líneas |
| `Alt + ↑ / ↓` | Mover la línea actual |
| `Shift + Alt + F` | Formatear el archivo |
| `F5` | Ejecutar con el depurador |

## La carpeta del curso

Cuando clones el curso (lo haremos en la lección 3) tendrás esta estructura:

```text
pydatos/
├── index.html            ← esta página
├── comprobar.py          ← revisa tus ejercicios de VS Code
├── requirements.txt      ← librerías que necesita el curso
├── contenido/            ← lecciones y ejercicios (no necesitas tocarlo)
├── ejercicios/           ← AQUÍ trabajas los ejercicios de VS Code
├── proyectos/            ← los tres proyectos del curso
├── herramientas/         ← generador de datos y otras utilidades
└── datos/                ← datos generados (no se sube a Git)
```

:::telco Por qué esto importa en tu trabajo
Cuando automatices el procesamiento de los archivos de facturación, tu script correrá en la terminal, probablemente programado para ejecutarse solo cada noche. Sentirte cómodo en la terminal es el primer paso para eso.
:::

## Cuestionario

? Escribiste un archivo `tarifas.py`. ¿Qué comando lo ejecuta desde la terminal?
- [ ] `run tarifas.py`
- [x] `python tarifas.py`
- [ ] `open tarifas.py`
- [ ] `cd tarifas.py`
> `python` abre el intérprete y le entrega el archivo para ejecutarlo. `cd` sirve para cambiar de carpeta, no para ejecutar.

? ¿Cuál de estas tareas NO puedes hacer en la versión de Python que corre en esta página?
- [ ] Ejecutar un cálculo con variables
- [ ] Usar Pandas con un archivo pequeño
- [x] Procesar un archivo de 20 GB de tu computador
- [ ] Probar un ejemplo de una lección
> Python en el navegador no tiene acceso a los archivos de tu disco y tiene memoria limitada. Los archivos grandes se trabajan en VS Code.

? Estás en la carpeta `pydatos/ejercicios` y quieres volver a `pydatos`. ¿Qué escribes?
- [ ] `cd pydatos`
- [x] `cd ..`
- [ ] `ls ..`
- [ ] `back`
> `..` significa "la carpeta de arriba". `ls ..` solo mostraría su contenido sin moverte.
