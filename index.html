💾 Tu progreso

El progreso se guarda automáticamente en este navegador. Para continuar en otro computador (casa ↔ oficina):

  1. Exporta el archivo progreso-pydatos.json y guárdalo en la carpeta .progreso/ del curso.
  2. Haz git commit y git push.
  3. En el otro computador haz git pull e impórtalo aquí.

Al importar se combinan ambos progresos: se conserva lo más avanzado de cada ejercicio.
