## Enunciado

`ejercicios/m10-e9/proceso.py` es un proceso de los que corren solos cada noche: lee la carpeta de entrada de una **variable de entorno**, recorre archivos, **imprime** un resumen, deja advertencias y errores en el **log** y devuelve un **código de salida**. Lee su docstring con atención. **No lo modifiques.**

Escribe sus pruebas en `test_proceso.py` usando las cuatro herramientas de la lección 4:

- `tmp_path` para crear la carpeta y los archivos de prueba;
- `monkeypatch` para apuntar `CARPETA_CDR` a esa carpeta;
- `capsys` para verificar lo que imprime;
- `caplog` para verificar las advertencias y errores.

Tus pruebas deben pasar con el proceso correcto y atrapar **siete mutantes**. Comprueba con `python comprobar.py m10-e9`.

## Pista 1

Una fixture que arme el escenario completo ahorra mucho código:

```python
import logging

import pytest

from proceso import main


@pytest.fixture
def carpeta(tmp_path, monkeypatch):
    entrada = tmp_path / "entrada"
    entrada.mkdir()
    (entrada / "cdr_01.csv").write_text("cdr_id|tipo\n1|VOZ\n2|SMS\n", encoding="utf-8")
    (entrada / "cdr_02.csv").write_text("cdr_id|tipo\n", encoding="utf-8")          # vacío
    (entrada / "otros.csv").write_text("x\n1\n2\n3\n", encoding="utf-8")            # no es cdr_*
    monkeypatch.setenv("CARPETA_CDR", str(entrada))
    return entrada
```

## Pista 2

`main` recibe la lista de argumentos, así que no necesitas tocar `sys.argv`: `main(["--minimo", "5"])`. Para verificar el log:

```python
def test_advierte_archivo_vacio(carpeta, caplog):
    with caplog.at_level(logging.WARNING):
        main([])
    assert "cdr_02.csv" in caplog.text
```

No olvides el caso en que la carpeta no existe: `monkeypatch.setenv("CARPETA_CDR", str(tmp_path / "no_existe"))`.

## Solución

```python test_proceso.py
import logging

import pytest

from proceso import main


@pytest.fixture
def carpeta(tmp_path, monkeypatch):
    entrada = tmp_path / "entrada"
    entrada.mkdir()
    (entrada / "cdr_01.csv").write_text("cdr_id|tipo\n1|VOZ\n2|SMS\n", encoding="utf-8")
    (entrada / "cdr_02.csv").write_text("cdr_id|tipo\n", encoding="utf-8")
    (entrada / "otros.csv").write_text("x\n1\n2\n3\n", encoding="utf-8")
    monkeypatch.setenv("CARPETA_CDR", str(entrada))
    return entrada


def test_imprime_cada_archivo_y_el_total(carpeta, capsys):
    assert main([]) == 0
    assert capsys.readouterr().out == "cdr_01.csv: 2 registros\ncdr_02.csv: 0 registros\nTotal: 2 registros\n"


def test_advierte_archivo_vacio(carpeta, caplog):
    with caplog.at_level(logging.WARNING):
        main([])
    advertencias = [r for r in caplog.records if r.levelname == "WARNING"]
    assert len(advertencias) == 1
    assert "cdr_02.csv" in advertencias[0].getMessage()


def test_minimo_no_alcanzado(carpeta, caplog):
    with caplog.at_level(logging.ERROR):
        assert main(["--minimo", "5"]) == 1
    assert "al menos 5" in caplog.text


def test_minimo_alcanzado(carpeta):
    assert main(["--minimo", "2"]) == 0


def test_carpeta_inexistente(tmp_path, monkeypatch, caplog):
    monkeypatch.setenv("CARPETA_CDR", str(tmp_path / "no_existe"))
    with caplog.at_level(logging.ERROR):
        assert main([]) == 2
    assert "no_existe" in caplog.text
```

## Explicación

Este proceso tiene **cuatro salidas** distintas, y una buena batería verifica todas:

| Salida | Herramienta |
|---|---|
| Lo que imprime | `capsys` |
| Advertencias y errores | `caplog` |
| Código de salida | `assert main(...) == 0` |
| Archivos que lee | `tmp_path` + `monkeypatch.setenv` |

Dos decisiones de diseño del propio `proceso.py` hacen que sea fácil de probar:

- `main(argumentos=None)` **recibe** los argumentos en vez de leer siempre `sys.argv`.
- La carpeta viene de una **variable de entorno**, que `monkeypatch` cambia sin tocar tu sistema.

La fixture `carpeta` incluye a propósito un archivo vacío y uno que no es `cdr_*.csv`: así una sola configuración atrapa varios mutantes. Diseñar el escenario de prueba es tan importante como escribir los `assert`.
