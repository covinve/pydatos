## Pista 2

Para la franja, `matriz.stack()` convierte la tabla en una Series con índice `(dia, hora)`; `idxmax()` devuelve la primera combinación con el máximo. Convierte cada parte a `int`.

## Solución

```python
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def inicios_de_voz(cdr):
    inicio = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    return inicio[(cdr["tipo"] == "VOZ") & inicio.notna()]


def matriz_dia_hora(cdr):
    voz = inicios_de_voz(cdr)
    tabla = pd.crosstab(voz.dt.dayofweek, voz.dt.hour)
    tabla = tabla.reindex(index=range(7), columns=range(24), fill_value=0)
    tabla.index.name = "dia"
    tabla.columns.name = "hora"
    return tabla


def franja_mas_activa(matriz):
    dia, hora = matriz.stack().idxmax()
    return int(dia), int(hora)


def porcentaje_fin_de_semana(cdr):
    voz = inicios_de_voz(cdr)
    return round(float((voz.dt.dayofweek >= 5).mean() * 100), 1)


m = matriz_dia_hora(cdr)
print(m)
print(franja_mas_activa(m), porcentaje_fin_de_semana(cdr))
```

## Explicación

`crosstab` construye una **tabla de contingencia**: cuenta cuántas veces aparece cada combinación de dos variables. La matriz día × hora es la base del clásico "mapa de calor" de tráfico que verás en el módulo 15.

El `reindex` es un detalle que importa: si un domingo a las 3 a. m. no hubo llamadas, `crosstab` simplemente omite esa celda. Reindexar garantiza una forma fija de 7 × 24, que es lo que esperan los gráficos y los reportes.
