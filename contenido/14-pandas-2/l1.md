`groupby` sigue tres pasos: **dividir** la tabla en grupos, **aplicar** una función a cada grupo y **combinar** los resultados. Es el `GROUP BY` de SQL y el patrón "agrupar" del módulo 4, ahora vectorizado.

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
validos = cdr[cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (cdr["duracion_seg"] >= 0)].copy()
validos["minutos"] = (validos["duracion_seg"] + 59) // 60

print(validos.groupby("tipo").size())                         # registros por tipo
print(validos.groupby("tipo")["duracion_seg"].mean().round(1))
print(validos.groupby(["linea_origen", "tipo"]).size().head(6))
```

## Agregaciones con nombre

La forma más clara de pedir varias métricas: `agg` con pares `nombre=(columna, funcion)`:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].copy()
voz["minutos"] = (voz["duracion_seg"] + 59) // 60

por_linea = voz.groupby("linea_origen").agg(
    llamadas=("cdr_id", "size"),
    minutos=("minutos", "sum"),
    promedio_seg=("duracion_seg", "mean"),
    mas_larga=("duracion_seg", "max"),
    destinos=("destino", "nunique"),
)
print(por_linea.sort_values("minutos", ascending=False).head())
```

| Función | Calcula |
|---|---|
| `"size"` | Filas del grupo (incluye faltantes) |
| `"count"` | Valores **no faltantes** de la columna |
| `"sum"`, `"mean"`, `"median"`, `"min"`, `"max"`, `"std"` | Lo de siempre |
| `"nunique"` | Valores distintos |
| `"first"`, `"last"` | Primer y último valor del grupo |

:::consejo reset_index
El resultado de un `groupby` usa las columnas de agrupación como índice. Agrega `.reset_index()` (o `as_index=False`) para tenerlas como columnas normales, por ejemplo antes de un `merge` o de guardar en CSV.
:::

## transform: un resultado por fila

`agg` devuelve **una fila por grupo**. `transform` devuelve un valor **por cada fila original**, alineado con ella. Sirve para comparar cada registro con su grupo:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0)].copy()

voz["total_linea"] = voz.groupby("linea_origen")["duracion_seg"].transform("sum")
voz["participacion"] = (voz["duracion_seg"] / voz["total_linea"] * 100).round(1)
voz["promedio_linea"] = voz.groupby("linea_origen")["duracion_seg"].transform("mean")
voz["atipica"] = voz["duracion_seg"] > 5 * voz["promedio_linea"]
print(voz[["linea_origen", "duracion_seg", "participacion", "atipica"]].head(8))
print(voz["atipica"].sum(), "llamadas 5 veces más largas que el promedio de su línea")
```

## Los N primeros de cada grupo

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[cdr["tipo"] == "VOZ"]

top2 = (voz.sort_values("duracion_seg", ascending=False)
           .groupby("linea_origen")
           .head(2)
           .sort_values(["linea_origen", "duracion_seg"], ascending=[True, False]))
print(top2[["linea_origen", "cdr_id", "duracion_seg"]].head(8))
```

## filter: quedarse con grupos completos

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[cdr["tipo"] == "VOZ"]

intensas = voz.groupby("linea_origen").filter(lambda g: len(g) > 40)
print(intensas["linea_origen"].nunique(), "líneas con más de 40 llamadas")
```

:::telco El resumen que alimenta la factura
El consumo mensual de cada línea (minutos nacionales e internacionales, megas, SMS) es un `groupby("linea_origen").agg(...)`. Es el paso entre los millones de CDR y las cientos de miles de facturas.
:::

## Cuestionario

? ¿Qué diferencia hay entre `agg` y `transform`?
- [ ] Ninguna
- [x] `agg` devuelve una fila por grupo; `transform` devuelve un valor por cada fila original
- [ ] `transform` es más rápido
- [ ] `agg` no acepta funciones
> `transform` permite comparar cada registro con un valor de su grupo.

? ¿Qué cuenta `groupby(...)["mb"].count()`?
- [ ] Todas las filas del grupo
- [x] Los valores no faltantes de `mb` en cada grupo
- [ ] Los valores distintos
- [ ] La suma de megas
> `size` cuenta filas; `count` cuenta valores no faltantes de una columna.

? Quieres las 3 llamadas más largas de cada línea. ¿Qué haces?
- [ ] `groupby("linea").max()`
- [x] Ordenar por duración descendente y luego `groupby("linea").head(3)`
- [ ] `nlargest(3, "duracion")`
- [ ] `groupby("linea").filter(...)`
> Ordenar primero hace que `head(3)` de cada grupo sean sus mayores.
