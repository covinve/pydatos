## Enunciado

En `ejercicios/m09-e9/tarificacion.py` ya están la dataclass `Llamada` y el contrato `ReglaDescuento` (un `Protocol` con el método `porcentaje(llamada) -> int`). Completa:

**Reglas de descuento** (cada una con su `__repr__`, por ejemplo `DescuentoNocturno(50)`):

| Clase | `porcentaje(llamada)` |
|---|---|
| `SinDescuento()` | Siempre 0 |
| `DescuentoNocturno(porcentaje)` | El porcentaje si la llamada empieza entre las 22:00 y las 05:59 **y** el destino no es `INTERNACIONAL`; si no, 0 |
| `DescuentoFinDeSemana(porcentaje)` | El porcentaje si empieza en sábado o domingo; si no, 0 |

Si el porcentaje no está entre 0 y 100, el constructor lanza `ValueError`.

**`Tarificador(tarifas, reglas=None)`**:

- `tarificar(llamada)` → minutos × tarifa del destino, aplicando **el mayor** de los porcentajes de las reglas (los descuentos **no** se suman), redondeado al peso (0,5 sube). Destino desconocido → `KeyError`.
- Lleva el estado de lo tarificado: atributos `cantidad` y `total`, y el método `total_por_linea()` → `{linea: total}`.
- `__repr__` → `Tarificador(1 llamadas, total=300, reglas=[DescuentoNocturno(50)])`.

El tarificador debe aceptar **cualquier** objeto que tenga el método `porcentaje` (las pruebas usan una clase `Promo` que no hereda de nada).

Comprueba con `python comprobar.py m09-e9`.

## Pista 1

Las reglas son clases pequeñas. La validación del porcentaje es igual en las dos con parámetro: puedes escribir una función auxiliar o una clase base común:

```python
class DescuentoNocturno:
    def __init__(self, porcentaje: int) -> None:
        if not 0 <= porcentaje <= 100:
            raise ValueError(f"Porcentaje inválido: {porcentaje}")
        self.valor = porcentaje

    def porcentaje(self, llamada: Llamada) -> int:
        hora = llamada.inicio.hour
        nocturna = hora >= 22 or hora < 6
        return self.valor if nocturna and llamada.destino != "INTERNACIONAL" else 0

    def __repr__(self) -> str:
        return f"DescuentoNocturno({self.valor})"
```

`datetime.weekday()` devuelve 5 para sábado y 6 para domingo.

## Pista 2

En el tarificador, el mejor descuento es `max((r.porcentaje(llamada) for r in self.reglas), default=0)`. Para el redondeo:

```python
bruto = Decimal(llamada.minutos * self.tarifas[llamada.destino])
neto = bruto * (100 - descuento) / 100
valor = int(neto.quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```

Para `total_por_linea`, guarda los acumulados en un diccionario (o `defaultdict(int)`) y devuelve una copia con `dict(...)`.

## Solución

```python tarificacion.py
"""Ejercicio m09-e9: un tarificador con reglas de descuento intercambiables."""

from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass
from datetime import datetime
from decimal import ROUND_HALF_UP, Decimal
from typing import Protocol


@dataclass(frozen=True)
class Llamada:
    linea: str
    destino: str
    inicio: datetime
    segundos: int

    @property
    def minutos(self) -> int:
        return (self.segundos + 59) // 60


class ReglaDescuento(Protocol):
    """Contrato: cualquier objeto con este método es una regla de descuento."""

    def porcentaje(self, llamada: Llamada) -> int:
        """Devuelve el porcentaje de descuento (0 a 100) que aplica a la llamada."""
        ...


class SinDescuento:
    def porcentaje(self, llamada: Llamada) -> int:
        return 0

    def __repr__(self) -> str:
        return "SinDescuento()"


class _DescuentoPorcentual:
    """Base interna: guarda y valida el porcentaje."""

    def __init__(self, porcentaje: int) -> None:
        if not 0 <= porcentaje <= 100:
            raise ValueError(f"Porcentaje inválido: {porcentaje}")
        self.valor = porcentaje

    def __repr__(self) -> str:
        return f"{type(self).__name__}({self.valor})"


class DescuentoNocturno(_DescuentoPorcentual):
    def porcentaje(self, llamada: Llamada) -> int:
        hora = llamada.inicio.hour
        nocturna = hora >= 22 or hora < 6
        return self.valor if nocturna and llamada.destino != "INTERNACIONAL" else 0


class DescuentoFinDeSemana(_DescuentoPorcentual):
    def porcentaje(self, llamada: Llamada) -> int:
        return self.valor if llamada.inicio.weekday() >= 5 else 0


class Tarificador:
    def __init__(self, tarifas: dict[str, int], reglas: list[ReglaDescuento] | None = None) -> None:
        self.tarifas = dict(tarifas)
        self.reglas = list(reglas or [])
        self.cantidad = 0
        self.total = 0
        self._por_linea: defaultdict[str, int] = defaultdict(int)

    def tarificar(self, llamada: Llamada) -> int:
        bruto = Decimal(llamada.minutos * self.tarifas[llamada.destino])
        descuento = max((regla.porcentaje(llamada) for regla in self.reglas), default=0)
        valor = int((bruto * (100 - descuento) / 100).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
        self.cantidad += 1
        self.total += valor
        self._por_linea[llamada.linea] += valor
        return valor

    def total_por_linea(self) -> dict[str, int]:
        return dict(self._por_linea)

    def __repr__(self) -> str:
        return f"Tarificador({self.cantidad} llamadas, total={self.total}, reglas={self.reglas})"
```

## Explicación

Este diseño se conoce como el patrón **Estrategia**: el tarificador delega una decisión (cuánto descuento aplicar) en objetos intercambiables. Comparado con el closure del módulo 5:

| | Closure (módulo 5) | Clase + reglas |
|---|---|---|
| Configuración | Parámetros de la fábrica | Lista de objetos regla |
| Estado | Variables `nonlocal` | Atributos (`cantidad`, `total`) |
| Agregar una política nueva | Cambiar la fábrica | Escribir una clase nueva con `porcentaje` |
| Inspeccionar | Difícil | `repr(tarificador)` muestra todo |

Gracias al `Protocol`, la `Promo` de las pruebas funciona sin heredar de nada: basta con que tenga el método correcto. Pylance y mypy verificarán ese contrato.

`_DescuentoPorcentual` empieza con guion bajo: es un detalle interno para no repetir la validación, no parte de la interfaz pública.
