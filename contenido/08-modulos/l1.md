Un **módulo** es simplemente un archivo `.py`. Cuando tu proyecto crece, lo divides en varios módulos, cada uno con una responsabilidad: leer archivos, aplicar reglas, generar reportes.

## Las formas de importar

```pyrun
import math                          # el módulo completo
from decimal import Decimal          # un nombre del módulo
from collections import Counter, defaultdict
import datetime as dt                # con alias
from statistics import mean as promedio

print(math.ceil(15.1))
print(Decimal("0.19"))
print(Counter("VOZ VOZ SMS".split()))
print(dt.date(2026, 9, 30))
print(promedio([125, 61, 300]))
```

| Forma | Cuándo usarla |
|---|---|
| `import modulo` | Por defecto. El prefijo (`math.ceil`) deja claro de dónde viene cada cosa |
| `from modulo import nombre` | Para nombres que usas mucho y son inconfundibles (`Decimal`, `Path`) |
| `import modulo as alias` | Alias **convencionales**: `import pandas as pd`, `import numpy as np` |
| `from modulo import *` | **Nunca** en código real: no se sabe qué nombres trae y puede pisar los tuyos |

:::consejo El orden de los imports
PEP 8 pide agruparlos así, con una línea en blanco entre grupos: **1)** biblioteca estándar, **2)** librerías externas, **3)** tus propios módulos. `ruff check --select I --fix` los ordena solo.
:::

## ¿Qué pasa al importar?

La primera vez que importas un módulo, Python **ejecuta todo el archivo** de arriba abajo y guarda el resultado en `sys.modules`. Las siguientes veces reutiliza ese resultado, sin volver a ejecutarlo.

```pyrun
from pathlib import Path

Path("tarifas.py").write_text(
    'print("Cargando tarifas...")\n'
    'TARIFAS = {"LOCAL": 100, "NACIONAL": 120}\n'
    "def tarifa(destino):\n"
    "    return TARIFAS[destino]\n",
    encoding="utf-8",
)

import tarifas          # se ejecuta el archivo: imprime "Cargando tarifas..."
import tarifas          # ya estaba cargado: no imprime nada
print(tarifas.tarifa("LOCAL"))
```

## El guardián `__name__`

Cada módulo tiene una variable `__name__`. Vale `"__main__"` cuando el archivo se **ejecuta directamente** (`python validador.py`) y el nombre del módulo cuando se **importa** (`import validador`).

```python
def validar(ruta):
    ...


def main():
    validar("datos/10MB/cdr.csv")


if __name__ == "__main__":
    main()
```

Así el archivo sirve para dos cosas: como **script** (ejecuta `main`) y como **módulo** (otros archivos importan `validar` sin que se dispare todo el proceso).

:::error Código suelto al nivel del módulo
Si tu archivo procesa un archivo de 1 GB "al nivel del módulo" (fuera de funciones y sin el guardián), **importarlo** desde las pruebas o desde otro script disparará el procesamiento completo. Todo lo que hace trabajo real va dentro de funciones; el arranque, dentro del `if __name__ == "__main__":`.
:::

## ¿Dónde busca Python los módulos?

Python busca en la lista `sys.path`, en orden:

1. La carpeta del script que ejecutaste (o la carpeta actual en la consola interactiva).
2. Las rutas de la variable de entorno `PYTHONPATH`, si existe.
3. La biblioteca estándar.
4. `site-packages` de tu entorno virtual: ahí `pip` instala las librerías.

```pyrun
import sys

for ruta in sys.path[:6]:
    print(ruta)
```

:::error No llames a tus archivos como módulos existentes
Si creas `csv.py`, `json.py`, `pandas.py` o `datetime.py` en tu carpeta, Python los encontrará **antes** que los verdaderos, y `import csv` cargará tu archivo. Los errores que produce esto son desconcertantes ("module 'csv' has no attribute 'DictReader'"). Usa nombres propios: `lector_cdr.py`, no `csv.py`.
:::

## Un paseo por la biblioteca estándar

Python trae "baterías incluidas". Antes de instalar algo, revisa si ya existe:

| Módulo | Para qué | Ya lo usaste en |
|---|---|---|
| `pathlib` | Rutas y archivos | Módulo 6 |
| `csv`, `json` | Formatos de datos | Módulo 6 |
| `datetime` | Fechas | Módulo 6 |
| `decimal` | Dinero | Módulo 2 |
| `collections` | `Counter`, `defaultdict`, `namedtuple` | Módulo 4 |
| `logging` | Bitácora | Módulo 7 |
| `itertools` | Herramientas para iterar | Módulo 11 |
| `statistics` | Media, mediana, desviación | Módulo 15 |
| `sqlite3` | Base de datos en un archivo | Módulo 17 |
| `argparse` | Argumentos de terminal | Proyecto 1 |
| `zipfile`, `gzip` | Archivos comprimidos | |
| `shutil` | Copiar, mover, comprimir carpetas | |
