## Enunciado

En `ejercicios/m10-e4/` está `lector.py` con la función `resumir(ruta)`, que lee un archivo de CDR y devuelve `registros`, `por_tipo` (ordenado), `minutos_voz` (VOZ con duración ≥ 0, redondeo hacia arriba) y `lineas` (distintas y no vacías). **No lo modifiques.**

Tu tarea es escribir sus pruebas, como lo harías en un proyecto real:

1. En `conftest.py`, crea la fixture `archivo_cdr` que use `tmp_path` para escribir un archivo de CDR **pequeño y pensado a propósito** y devuelva su ruta.
2. En `test_lector.py`, escribe las pruebas de `resumir` usando esa fixture.

`python comprobar.py m10-e4` ejecutará tus pruebas contra el lector correcto y contra **cinco versiones con errores**. Tus pruebas deben atraparlas todas.

## Pista 1

Diseña los registros del archivo para que cada regla tenga su caso:

```text
cdr_id|linea_origen|tipo|duracion_seg
1|3001|VOZ|61          ← 2 minutos (redondeo)
2|3001|SMS|0
3||DATOS|900           ← línea vacía
4|3002|VOZ|-90         ← duración negativa: no suma
5|3002|VOX|10          ← tipo raro, aparece en por_tipo
```

## Solución

```python conftest.py
import pytest


@pytest.fixture
def archivo_cdr(tmp_path):
    ruta = tmp_path / "cdr.csv"
    ruta.write_text(
        "cdr_id|linea_origen|tipo|duracion_seg\n"
        "1|3001|VOZ|61\n"
        "2|3001|SMS|0\n"
        "3||DATOS|900\n"
        "4|3002|VOZ|-90\n"
        "5|3002|VOX|10\n",
        encoding="utf-8",
    )
    return ruta
```

```python test_lector.py
from lector import resumir


def test_cuenta_registros_sin_encabezado(archivo_cdr):
    assert resumir(archivo_cdr)["registros"] == 5


def test_por_tipo_ordenado(archivo_cdr):
    por_tipo = resumir(archivo_cdr)["por_tipo"]
    assert por_tipo == {"DATOS": 1, "SMS": 1, "VOX": 1, "VOZ": 2}
    assert list(por_tipo) == ["DATOS", "SMS", "VOX", "VOZ"]


def test_minutos_redondean_y_excluyen_negativas(archivo_cdr):
    assert resumir(archivo_cdr)["minutos_voz"] == 2


def test_lineas_distintas_sin_vacias(archivo_cdr):
    assert resumir(archivo_cdr)["lineas"] == 2


def test_archivo_solo_con_encabezado(tmp_path):
    ruta = tmp_path / "vacio.csv"
    ruta.write_text("cdr_id|linea_origen|tipo|duracion_seg\n", encoding="utf-8")
    assert resumir(ruta) == {"registros": 0, "por_tipo": {}, "minutos_voz": 0, "lineas": 0}
```

## Explicación

Cinco registros, cada uno con un propósito, bastan para atrapar los cinco errores. Fíjate en tres decisiones:

- **El 61** (y no 60 ni 120) distingue redondear hacia arriba de truncar.
- **La línea vacía** existe solo para probar que no se cuenta.
- **`list(por_tipo)`**: comparar diccionarios con `==` ignora el orden; comparar la lista de claves no.

La fixture en `conftest.py` queda disponible para todos los archivos de pruebas de la carpeta, y cada prueba recibe su propia carpeta temporal: ninguna prueba puede ensuciar a otra.
