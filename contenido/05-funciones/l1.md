Ya escribes funciones desde el módulo 1. Ahora vas a diseñarlas para que sean **fáciles de usar bien y difíciles de usar mal**.

## Argumentos posicionales y por nombre

```pyrun
def valor_llamada(segundos, tarifa_minuto, descuento=0.0):
    minutos = (segundos + 59) // 60
    return round(minutos * tarifa_minuto * (1 - descuento))


print(valor_llamada(125, 120))                    # posicionales
print(valor_llamada(125, 120, 0.5))               # el tercero también posicional
print(valor_llamada(segundos=125, tarifa_minuto=120, descuento=0.5))   # por nombre
print(valor_llamada(125, tarifa_minuto=120))      # mezcla: primero posicionales
```

Pasar argumentos **por nombre** hace que la llamada se lea sola. Compara `valor_llamada(125, 120, 0.5)` con `valor_llamada(125, 120, descuento=0.5)`: la segunda no necesita que recuerdes el orden.

## Valores por defecto

`descuento=0.0` hace que el parámetro sea **opcional**. Los parámetros con valor por defecto van **después** de los obligatorios.

:::error La trampa del valor por defecto mutable
El valor por defecto se crea **una sola vez**, cuando se define la función, no cada vez que se llama. Si es una lista o un diccionario, todas las llamadas comparten el mismo objeto:

```pyrun
def registrar_error(error, errores=[]):
    errores.append(error)
    return errores


print(registrar_error("duplicado"))
print(registrar_error("fecha_invalida"))   # ¡arrastra el error anterior!
```

La solución estándar es usar `None` como valor por defecto y crear la lista adentro:

```pyrun
def registrar_error(error, errores=None):
    if errores is None:
        errores = []
    errores.append(error)
    return errores


print(registrar_error("duplicado"))
print(registrar_error("fecha_invalida"))
```
:::

## Parámetros de solo-nombre: `*`

Todo lo que va después de un `*` en la definición **debe** pasarse por nombre. Úsalo para opciones que serían confusas como posicionales:

```pyrun
def formatear(valor, *, decimales=0, moneda="$"):
    return f"{moneda}{valor:,.{decimales}f}"


print(formatear(1234.5, decimales=2))
print(formatear(1234.5, moneda="USD "))
print(formatear(1234.5, 2))   # error esperado
```

`formatear(1234.5, 2)` falla a propósito: nadie que lea esa línea sabría qué significa el `2`.

## *args: cantidad variable de argumentos

```pyrun
def total_minutos(*duraciones):
    return sum((d + 59) // 60 for d in duraciones)


print(total_minutos(125))
print(total_minutos(125, 61, 3600))

llamadas = [125, 0, 61]
print(total_minutos(*llamadas))   # * "desempaqueta" la lista en argumentos
```

## **kwargs: argumentos por nombre variables

```pyrun
def crear_cdr(cdr_id, tipo, **campos):
    registro = {"cdr_id": cdr_id, "tipo": tipo}
    registro.update(campos)
    return registro


print(crear_cdr(1, "VOZ", duracion_seg=125, destino="LOCAL"))

plan = {"plan_id": "HOG30", "cargo_fijo": 35900}
print(crear_cdr(2, "DATOS", **plan))   # ** desempaqueta un diccionario
```

:::consejo Úsalos con moderación
`*args` y `**kwargs` son potentes pero esconden qué acepta la función. Prefiere parámetros con nombre explícito; reserva `*args`/`**kwargs` para funciones que realmente aceptan "cualquier cantidad" o que reenvían argumentos a otra función.
:::

## El orden completo

```python
def f(posicional_solo, /, normal, *args, solo_nombre, **kwargs):
    ...
```

Rara vez necesitarás todo junto. Lo importante: **obligatorios → con valor por defecto → `*` → solo-nombre**.

:::telco Funciones que se usan en toda la empresa
Si escribes la función que calcula el IVA y la usan diez procesos distintos, cada parámetro mal diseñado se convierte en diez lugares donde alguien puede equivocarse. Un `*, redondeo="comercial"` obligatorio por nombre es mucho más seguro que un `True` posicional que nadie recuerda qué significa.
:::

## Cuestionario

? ¿Qué imprime la segunda llamada? `def f(x, lista=[]): lista.append(x); return lista` — `f(1)`, luego `print(f(2))`
- [ ] `[2]`
- [x] `[1, 2]`
- [ ] `[1]`
- [ ] Un error
> La lista por defecto se crea una sola vez y se comparte entre llamadas. Por eso se usa `None` como valor por defecto.

? Con `def formatear(valor, *, decimales=0)`, ¿cuál llamada es válida?
- [ ] `formatear(10, 2)`
- [x] `formatear(10, decimales=2)`
- [ ] `formatear(decimales=2)`
- [ ] `formatear(10, *2)`
> Después del `*`, los parámetros solo se pueden pasar por nombre. `valor` sigue siendo obligatorio.

? ¿Qué recibe `args` en `def f(*args)` si llamas `f(1, 2, 3)`?
- [ ] `[1, 2, 3]`
- [x] `(1, 2, 3)`
- [ ] `{1, 2, 3}`
- [ ] `1`
> `*args` agrupa los argumentos posicionales en una tupla.
