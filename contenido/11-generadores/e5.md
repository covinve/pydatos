## Enunciado

El sistema de mediación entrega un archivo **ordenado por línea** (`linea|segundos`). Gracias a ese orden puedes resumirlo con memoria constante, sin diccionarios que crezcan.

Escribe el generador `resumen_por_linea(registros)` que reciba un iterable de tuplas `(linea, segundos)` **ordenadas por línea** y entregue, por cada línea, una tupla `(linea, llamadas, minutos_facturables)`.

Como el orden es un **supuesto**, verifícalo: si una línea aparece otra vez después de que su grupo terminó, lanza `ValueError("Datos no ordenados: la línea 3001 aparece de nuevo")`. El error debe lanzarse **al llegar** a ese registro (los grupos anteriores ya se habrán entregado).

```python
datos = [("3001", 125), ("3001", 61), ("3002", 30), ("3003", 0)]
list(resumen_por_linea(datos))
# [("3001", 2, 5), ("3002", 1, 1), ("3003", 1, 0)]
```

## Pista 1

`groupby(registros, key=lambda r: r[0])` entrega pares `(linea, grupo)`, donde `grupo` es un iterador con los registros de esa línea. Recorre el grupo una vez para contar y sumar a la vez.

## Pista 2

Para detectar el desorden, guarda las líneas ya vistas en un conjunto. Si la clave de un grupo nuevo ya estaba, lanza el error **antes** de entregar ese grupo.

¿Y la memoria? El conjunto crece con la cantidad de **líneas** (unos cientos de miles), no de registros (cientos de millones). Otra opción, aún más barata: como los datos deben estar ordenados, basta comparar con la **última** línea vista: si la nueva es menor o igual, hay desorden.

## Solución

```python
from itertools import groupby


def resumen_por_linea(registros):
    anterior = None
    for linea, grupo in groupby(registros, key=lambda r: r[0]):
        if anterior is not None and linea <= anterior:
            raise ValueError(f"Datos no ordenados: la línea {linea} aparece de nuevo")
        llamadas = 0
        minutos = 0
        for _, segundos in grupo:
            llamadas += 1
            minutos += (segundos + 59) // 60
        yield linea, llamadas, minutos
        anterior = linea


datos = [("3001", 125), ("3001", 61), ("3002", 30), ("3003", 0)]
print(list(resumen_por_linea(datos)))
```

## Explicación

Este es el algoritmo que usan las bases de datos para agrupar datos **ya ordenados**: no necesita un diccionario con todos los grupos, solo el grupo actual. Con un archivo de 20 GB ordenado por línea, la memoria usada es la de un grupo.

La validación compara con la línea anterior (`linea <= anterior`): si los datos están ordenados, cada clave nueva es estrictamente mayor. Es más barato que un conjunto y detecta tanto una línea repetida como cualquier desorden.

**Verificar los supuestos** es una práctica clave con datos reales: si mañana el proveedor envía el archivo sin ordenar, un `groupby` sin verificación daría resultados equivocados en silencio (la misma línea partida en varios grupos). Con la verificación, el proceso se detiene con un error claro.
