Los **métodos especiales** (o "dunder", por los dobles guiones bajos) permiten que tus objetos funcionen con las herramientas del lenguaje: `print`, `==`, `<`, `len`, `for`, `+`…

## __repr__ y __str__

```pyrun
class Factura:
    def __init__(self, factura_id, total):
        self.factura_id = factura_id
        self.total = total

    def __repr__(self):
        return f"Factura({self.factura_id!r}, {self.total!r})"

    def __str__(self):
        return f"Factura {self.factura_id} por ${self.total:,}".replace(",", ".")


f = Factura("F2026090000001", 48719)
print(repr(f))      # para programadores: inequívoco
print(f)            # para personas: legible
print([f])          # dentro de listas se usa __repr__
```

| Método | Lo usa | Debe ser |
|---|---|---|
| `__repr__` | `repr()`, la consola, el depurador, listas | Inequívoco; idealmente, código que recrea el objeto |
| `__str__` | `print()`, `str()`, f-strings | Legible para una persona |

:::reto Un plan que se muestra bien
Agrega a la clase `Plan` los dos métodos de presentación:

- `__repr__` → `Plan('HOG30', 35900)`
- `__str__` → `Plan HOG30: $35.900` (con punto de miles)

```pyreto
class Plan:
    def __init__(self, plan_id, cargo_fijo):
        self.plan_id = plan_id
        self.cargo_fijo = cargo_fijo


p = Plan("HOG30", 35900)
print(repr(p))
print(p)
```

:::pista
Para el repr usa `!r`, que pone las comillas: `f"Plan({self.plan_id!r}, {self.cargo_fijo!r})"`. Para el str, `f"{self.cargo_fijo:,}"` y cambia la coma por punto.
:::

```pyprueba
def prueba_repr():
    """repr es inequívoco"""
    requiere("Plan")
    igual(repr(Plan("HOG30", 35900)), "Plan('HOG30', 35900)")


def prueba_str():
    """str es legible para personas"""
    igual(str(Plan("HOG30", 35900)), "Plan HOG30: $35.900")
    igual(str(Plan("EMP300", 149900)), "Plan EMP300: $149.900")


def prueba_en_lista():
    """Dentro de una lista se ve el repr"""
    igual(str([Plan("ILIM", 89900)]), "[Plan('ILIM', 89900)]")
```

## Comparar y ordenar

```pyrun
from functools import total_ordering


@total_ordering
class Factura:
    def __init__(self, factura_id, total):
        self.factura_id = factura_id
        self.total = total

    def __eq__(self, otra):
        if not isinstance(otra, Factura):
            return NotImplemented
        return self.factura_id == otra.factura_id

    def __lt__(self, otra):
        return self.total < otra.total

    def __hash__(self):
        return hash(self.factura_id)

    def __repr__(self):
        return f"Factura({self.factura_id!r}, {self.total})"


facturas = [Factura("F3", 85573), Factura("F1", 48719), Factura("F2", 160543)]
print(sorted(facturas))
print(max(facturas))
print(Factura("F1", 0) == Factura("F1", 999))   # igual por ID
```

`@total_ordering` completa `<=`, `>` y `>=` a partir de `__eq__` y `__lt__`. Si defines `__eq__`, define también `__hash__` (si el objeto va a usarse en conjuntos o como clave).

:::reto Consumos que se ordenan solos
Completa la clase `Consumo` para que:

- dos consumos sean **iguales** si son de la misma `linea` (aunque tengan distintos minutos);
- se ordenen por `minutos` (con `sorted`, `max`, `<`, `>=`…);
- se puedan meter en un conjunto (necesita `__hash__`, coherente con la igualdad).

```pyreto
from functools import total_ordering


class Consumo:
    def __init__(self, linea, minutos):
        self.linea = linea
        self.minutos = minutos

    def __repr__(self):
        return f"Consumo({self.linea!r}, {self.minutos})"


consumos = [Consumo("3001", 342), Consumo("3002", 15), Consumo("3003", 1203)]
print(sorted(consumos))
print(max(consumos))
```

:::pista
Decora la clase con `@total_ordering` y agrega `__eq__` (compara `linea`), `__lt__` (compara `minutos`) y `__hash__` (`hash(self.linea)`).
:::

```pyprueba
def prueba_ordenar():
    """Se ordenan por minutos"""
    requiere("Consumo")
    datos = [Consumo("3001", 342), Consumo("3002", 15), Consumo("3003", 1203)]
    igual([c.linea for c in sorted(datos)], ["3002", "3001", "3003"])
    igual(max(datos).linea, "3003")
    assert Consumo("A", 10) >= Consumo("B", 5), "Con @total_ordering también debe funcionar >="


def prueba_igualdad():
    """Iguales si son de la misma línea"""
    igual(Consumo("3001", 1) == Consumo("3001", 999), True, "misma línea")
    igual(Consumo("3001", 1) == Consumo("3002", 1), False, "distinta línea")


def prueba_conjunto():
    """Un conjunto deja un consumo por línea"""
    igual(len({Consumo("3001", 1), Consumo("3001", 2), Consumo("3002", 3)}), 2)
```


## Contenedores: __len__, __iter__, __contains__, __getitem__

```pyrun
class Lote:
    def __init__(self, duraciones):
        self._duraciones = list(duraciones)

    def __len__(self):
        return len(self._duraciones)

    def __iter__(self):
        return iter(self._duraciones)

    def __getitem__(self, posicion):
        return self._duraciones[posicion]

    def __contains__(self, valor):
        return valor in self._duraciones


lote = Lote([125, 0, 61])
print(len(lote), lote[0], 61 in lote)
for d in lote:
    print(d, end=" ")
```

:::reto Un tarifario que se usa como diccionario
Haz que la clase `Tarifario` funcione con las herramientas de Python:

- `len(t)` → cuántos destinos tiene;
- `"LOCAL" in t` → si existe el destino;
- `t["LOCAL"]` → la tarifa; si no existe, `KeyError` con el mensaje `Destino sin tarifa: 'SATELITAL'`;
- `for destino in t` → recorre los destinos.

```pyreto
class Tarifario:
    def __init__(self, tarifas):
        self._tarifas = dict(tarifas)


t = Tarifario({"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950})
print(len(t), "NACIONAL" in t, t["LOCAL"], list(t))
```

:::pista
Agrega `__len__`, `__contains__`, `__getitem__` e `__iter__`, delegando en `self._tarifas`. En `__getitem__`, si el destino no está, `raise KeyError(f"Destino sin tarifa: {destino!r}")`.
:::

```pyprueba
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def prueba_len_y_in():
    """len e in funcionan"""
    requiere("Tarifario")
    t = Tarifario(TARIFAS)
    igual(len(t), 3, "len")
    igual("NACIONAL" in t, True, "NACIONAL in t")
    igual("SATELITAL" in t, False, "SATELITAL in t")


def prueba_getitem():
    """t[destino] devuelve la tarifa o un KeyError claro"""
    t = Tarifario(TARIFAS)
    igual(t["INTERNACIONAL"], 950)
    error = lanza(KeyError, lambda: t["SATELITAL"])
    assert "SATELITAL" in str(error), f"El mensaje debe nombrar el destino. Mensaje: {error}"


def prueba_iter():
    """Se puede recorrer con for"""
    igual(list(Tarifario(TARIFAS)), ["LOCAL", "NACIONAL", "INTERNACIONAL"])
```

```pysolucion
class Tarifario:
    def __init__(self, tarifas):
        self._tarifas = dict(tarifas)

    def __len__(self):
        return len(self._tarifas)

    def __contains__(self, destino):
        return destino in self._tarifas

    def __getitem__(self, destino):
        if destino not in self._tarifas:
            raise KeyError(f"Destino sin tarifa: {destino!r}")
        return self._tarifas[destino]

    def __iter__(self):
        return iter(self._tarifas)


t = Tarifario({"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950})
print(len(t), "NACIONAL" in t, t["LOCAL"], list(t))
```

## @property: atributos calculados

Una **propiedad** se usa como un atributo, pero se calcula con un método. Ideal para valores que dependen de otros:

```pyrun
from dataclasses import dataclass


@dataclass(frozen=True)
class Llamada:
    segundos: int
    tarifa_minuto: int

    @property
    def minutos_facturables(self):
        return (self.segundos + 59) // 60

    @property
    def valor(self):
        return self.minutos_facturables * self.tarifa_minuto


ll = Llamada(125, 120)
print(ll.minutos_facturables, ll.valor)   # sin paréntesis
```

Como `valor` se calcula a partir de los datos, nunca puede quedar desactualizado.

## @classmethod: constructores alternativos

Un `@classmethod` recibe la **clase** (`cls`) en lugar del objeto. Su uso estrella: crear objetos desde otros formatos.

```pyrun
from dataclasses import dataclass


@dataclass(frozen=True)
class CDR:
    cdr_id: int
    linea_origen: str
    tipo: str
    duracion_seg: int

    @classmethod
    def desde_linea_csv(cls, texto, separador="|"):
        campos = texto.rstrip("\n").split(separador)
        return cls(int(campos[0]), campos[1], campos[3], int(campos[6]))

    @classmethod
    def desde_ancho_fijo(cls, registro):
        return cls(int(registro[0:12]), registro[12:22].strip(), registro[35:40].strip(), int(registro[67:73]))


print(CDR.desde_linea_csv("2|3302703263|3040879936|VOZ|NACIONAL|2026-09-13 10:31:28|30|0.000|CEL97932"))
print(CDR.desde_ancho_fijo("00000000000233027032633040879936   VOZ  NACIONAL     20260913103128000030000000.000CEL97932"))
```

## @staticmethod

Un `@staticmethod` no recibe ni el objeto ni la clase: es una función normal que vive dentro de la clase porque tiene que ver con ella.

```python
class CDR:
    @staticmethod
    def es_tipo_valido(tipo: str) -> bool:
        return tipo in {"VOZ", "SMS", "DATOS"}
```

| Decorador | Primer parámetro | Úsalo para |
|---|---|---|
| (ninguno) | `self`, el objeto | Operaciones sobre un objeto |
| `@classmethod` | `cls`, la clase | Constructores alternativos |
| `@staticmethod` | ninguno | Utilidades relacionadas con la clase |
| `@property` | `self` | Valores calculados que se leen como atributos |

:::reto Propiedades y un constructor alternativo
Completa la dataclass `ConsumoVoz`:

- la propiedad `exceso`: minutos por encima de los incluidos (nunca negativo);
- el `@classmethod` `desde_texto(cls, texto)`, que crea el objeto desde un texto como `"3001234567|342|300"` (línea, usados e incluidos);
- el `@staticmethod` `es_linea_movil(linea)`: `True` si tiene 10 dígitos y empieza por `"3"`.

```pyreto
from dataclasses import dataclass


@dataclass(frozen=True)
class ConsumoVoz:
    linea: str
    usados: int
    incluidos: int


c = ConsumoVoz.desde_texto("3001234567|342|300")
print(c, c.exceso, ConsumoVoz.es_linea_movil(c.linea))
```

:::pista
La propiedad: `@property` y `def exceso(self): return max(0, self.usados - self.incluidos)`. El constructor: separa con `split("|")` y devuelve `cls(linea, int(usados), int(incluidos))`.
:::

```pyprueba
def prueba_exceso():
    """exceso se lee como atributo"""
    requiere("ConsumoVoz")
    igual(ConsumoVoz("3001", 342, 300).exceso, 42)
    igual(ConsumoVoz("3001", 100, 300).exceso, 0)


def prueba_desde_texto():
    """desde_texto crea el objeto con los tipos correctos"""
    c = ConsumoVoz.desde_texto("3001234567|342|300")
    igual(c, ConsumoVoz("3001234567", 342, 300))


def prueba_estatico():
    """es_linea_movil se llama desde la clase"""
    igual(ConsumoVoz.es_linea_movil("3001234567"), True, "3001234567")
    igual(ConsumoVoz.es_linea_movil("6014445566"), False, "6014445566")
    igual(ConsumoVoz.es_linea_movil("300"), False, "300")
```

```pysolucion
from dataclasses import dataclass


@dataclass(frozen=True)
class ConsumoVoz:
    linea: str
    usados: int
    incluidos: int

    @property
    def exceso(self):
        return max(0, self.usados - self.incluidos)

    @classmethod
    def desde_texto(cls, texto):
        linea, usados, incluidos = texto.split("|")
        return cls(linea, int(usados), int(incluidos))

    @staticmethod
    def es_linea_movil(linea):
        return len(linea) == 10 and linea.isdigit() and linea.startswith("3")


c = ConsumoVoz.desde_texto("3001234567|342|300")
print(c, c.exceso, ConsumoVoz.es_linea_movil(c.linea))
```

## Cuestionario

? ¿Qué método usa `print(objeto)`?
- [ ] `__repr__` siempre
- [x] `__str__` (y si no existe, `__repr__`)
- [ ] `__print__`
- [ ] `__init__`
> `print` usa `__str__`; si la clase no lo define, Python usa `__repr__`.

? ¿Cómo se usa una propiedad `valor` definida con `@property`?
- [ ] `llamada.valor()`
- [x] `llamada.valor`
- [ ] `Llamada.valor(llamada)`
- [ ] `property(llamada)`
> Las propiedades se leen como atributos, sin paréntesis, aunque por dentro sean métodos.

? ¿Para qué sirve típicamente un `@classmethod` como `CDR.desde_linea_csv(texto)`?
- [ ] Para modificar todos los objetos a la vez
- [x] Para construir objetos de la clase a partir de otro formato
- [ ] Para borrar la clase
- [ ] Para hacer el método privado
> Recibe la clase (`cls`) y devuelve `cls(...)`: es un constructor alternativo.
