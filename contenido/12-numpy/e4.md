## Enunciado

Vectoriza el ejercicio de tarifas del módulo 3. Con los arrays `destinos`, `horas` y `duraciones`, escribe `tarificar(destinos, horas, duraciones)` que devuelva el array de valores:

| Destino | Tarifa | Nocturna (22:00–05:59) |
|---|---|---|
| `LOCAL` | 100 | 50 |
| `NACIONAL` | 120 | 60 |
| `INTERNACIONAL` | 950 | 950 (sin descuento) |
| Otro | 0 | 0 |

Valor = minutos facturables × tarifa. Escribe también `resumen_por_destino(destinos, horas, duraciones)` → diccionario `{destino: total}` con los tres destinos válidos (aunque alguno sume 0), como enteros de Python.

Sin bucles sobre los registros.

## Código inicial

import numpy as np

def tarificar(destinos, horas, duraciones):
    pass


def resumen_por_destino(destinos, horas, duraciones):
    pass

## Pista 1

Calcula primero la máscara nocturna y la tarifa base:

```python
nocturna = (horas >= 22) | (horas < 6)
base = np.select([destinos == d for d in DESTINOS], [100, 120, 950], default=0)
```

(La comprensión recorre los 3 destinos, no los registros: está bien.)

## Pista 2

Aplica el descuento con `np.where`: si es nocturna y no es internacional, `base // 2`; si no, `base`. En el resumen sí puedes recorrer los 3 destinos: `int(valores[destinos == d].sum())`.

## Solución

```python
import numpy as np

DESTINOS = ["LOCAL", "NACIONAL", "INTERNACIONAL"]
TARIFAS = [100, 120, 950]


def tarificar(destinos, horas, duraciones):
    nocturna = (horas >= 22) | (horas < 6)
    base = np.select([destinos == "LOCAL", destinos == "NACIONAL", destinos == "INTERNACIONAL"], TARIFAS, default=0)
    tarifa = np.where(nocturna & (destinos != "INTERNACIONAL"), base // 2, base)
    return (duraciones + 59) // 60 * tarifa


def resumen_por_destino(destinos, horas, duraciones):
    valores = tarificar(destinos, horas, duraciones)
    return {d: int(valores[destinos == d].sum()) for d in DESTINOS}
```

## Explicación

Toda la lógica del ejercicio del módulo 3 (un `match` con salidas tempranas) cabe en tres líneas vectorizadas: `np.select` para el destino, `np.where` para la franja y una multiplicación. La diferencia: esto tarifica millones de llamadas de una vez.

Recorrer los **destinos** (3) con una comprensión no es un problema de rendimiento; lo que hay que evitar es recorrer los **registros** (millones).
