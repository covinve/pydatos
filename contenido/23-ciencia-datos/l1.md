En el módulo 15 viste que los consumos de una telco tienen **cola larga**: la mayoría de las llamadas duran poco y unas pocas duran horas; la mayoría de las líneas consume pocos MB y unas pocas, cientos de GB. Con datos así, muchas herramientas estadísticas "de libro" (que suponen una campana de Gauss) dan respuestas engañosas.

## Media frente a mediana

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

print(f"Media:    {voz.mean():8.1f} s")
print(f"Mediana:  {voz.median():8.1f} s")
print(f"p90/p99:  {voz.quantile(0.9):8.1f} / {voz.quantile(0.99):.1f} s")
print(f"Asimetría: {voz.skew():.2f}  (0 = simétrica; > 1 = cola larga a la derecha)")

con_atipico = pd.concat([voz, pd.Series([86_400])])     # una sola llamada de 24 horas (un error de tasación)
print(f"Con una llamada de 24 h → media {con_atipico.mean():.1f}, mediana {con_atipico.median():.1f}")
```

Una sola llamada mal registrada mueve la media; la mediana ni se entera. Por eso se dice que la mediana es **robusta**.

| Medida "clásica" | Medida robusta | Robusta frente a |
|---|---|---|
| Media | Mediana | Valores extremos |
| Desviación estándar | **MAD**: mediana de las distancias absolutas a la mediana | Valores extremos |
| Mínimo / máximo | Percentiles 1 y 99 | Errores puntuales |
| Rango | Rango intercuartílico (IQR = p75 − p25) | Colas |

:::consejo MAD en la escala de la desviación estándar
Para datos normales, `1.4826 × MAD` ≈ desviación estándar. Ese factor permite usar MAD en fórmulas como el z-score (lección 2) con los mismos umbrales que ya conoces.
:::

## ¿Cuánto podría variar? Bootstrap

La mediana de la duración de tu muestra es, digamos, 118 segundos. Si hubieras tomado otro mes, ¿sería 118? ¿110? ¿130? El **bootstrap** responde sin fórmulas: simula "otros meses" remuestreando tus propios datos **con reemplazo**, y mira cuánto varía el estadístico.

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"].to_numpy()

rng = np.random.default_rng(2026)
medianas = np.array([np.median(rng.choice(voz, size=len(voz), replace=True)) for _ in range(2000)])
bajo, alto = np.percentile(medianas, [2.5, 97.5])
print(f"Mediana {np.median(voz):.0f} s; intervalo de confianza del 95 %: [{bajo:.0f}, {alto:.0f}] s")
```

:::pasos Cómo funciona el bootstrap
:::paso 1. Remuestrear
De tus N valores, toma N al azar **con reemplazo** (algunos se repiten, otros no salen). Es "un mes alternativo" plausible.
:::
:::paso 2. Calcular
Calcula el estadístico (mediana, media, percentil 95, tasa de rechazo…) en esa muestra.
:::
:::paso 3. Repetir
Miles de veces. Obtienes la distribución del estadístico.
:::
:::paso 4. Leer el intervalo
Los percentiles 2.5 y 97.5 de esa distribución forman un intervalo de confianza del 95 %. Funciona para casi cualquier estadístico, sin suponer normalidad.
:::
:::

## ¿Es real la diferencia? Pruebas de permutación

Las llamadas de clientes empresariales duran en promedio 15 segundos más que las residenciales. ¿Es una diferencia real o puro azar? La **prueba de permutación** razona así: *si el segmento no tuviera nada que ver con la duración, mezclar las etiquetas al azar debería producir diferencias tan grandes como la observada con frecuencia*.

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"})
cli = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0)].merge(cli, left_on="linea_origen", right_on="linea")

emp = voz.loc[voz["segmento"] == "EMPRESARIAL", "duracion_seg"].to_numpy()
res = voz.loc[voz["segmento"] == "RESIDENCIAL", "duracion_seg"].to_numpy()
observada = emp.mean() - res.mean()

rng = np.random.default_rng(7)
todas = np.concatenate([emp, res])
extremas = 0
for _ in range(2000):
    mezcla = rng.permutation(todas)
    diferencia = mezcla[:len(emp)].mean() - mezcla[len(emp):].mean()
    extremas += abs(diferencia) >= abs(observada)
p = (extremas + 1) / (2000 + 1)
print(f"Diferencia observada: {observada:.1f} s   valor p ≈ {p:.3f}")
```

Un **valor p** pequeño (por convención, < 0.05) dice que una diferencia así rara vez aparece por azar. No dice que la diferencia sea **importante**: con millones de CDR, una diferencia de 0.3 segundos puede tener p = 0.0001 y no importarle a nadie. Mira siempre el **tamaño** del efecto, no solo el valor p.

:::capo Correlación no es causalidad
Las líneas con más llamadas internacionales tienen más reclamos. ¿Las llamadas causan reclamos? Quizás ambas cosas se deben a un tercer factor (clientes empresariales con más actividad en general). Antes de recomendar una acción ("limitar llamadas internacionales para reducir reclamos"), pregunta qué más podría explicar la relación.
:::
