**Pandas** es la librería estándar para trabajar con tablas en Python. Está construida sobre NumPy: cada columna es un array, y todas las columnas comparten un **índice** que identifica las filas.

## Series y DataFrame

```pyrun
import pandas as pd

duraciones = pd.Series([125, 0, 61, 3600], name="duracion_seg")
print(duraciones)
print(duraciones.mean())

cdr = pd.DataFrame({
    "cdr_id": [1, 2, 3, 4],
    "linea_origen": ["3001", "3002", "3001", "3003"],
    "tipo": ["VOZ", "SMS", "VOZ", "DATOS"],
    "duracion_seg": [125, 0, 61, 3600],
})
print(cdr)
print(cdr.shape)
print(cdr.columns.tolist())
```

| Estructura | Es como… | Ejemplo |
|---|---|---|
| `Series` | Una columna con índice | `cdr["duracion_seg"]` |
| `DataFrame` | Una tabla: varias Series que comparten índice | `cdr` |
| `Index` | Las etiquetas de las filas | `cdr.index` |

## Leer un CSV

`read_csv` tiene muchos parámetros; estos son los que más vas a usar con archivos de facturación:

```python
cdr = pd.read_csv(
    "datos/10MB/cdr.csv",
    sep="|",                                   # separador
    encoding="utf-8",                          # codificación
    dtype={"linea_origen": "string", "linea_destino": "string", "celda": "string"},
    keep_default_na=False, na_values=[""],     # qué se considera faltante
)
clientes = pd.read_csv("datos/10MB/clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})
```

:::error Los identificadores con dígitos se leen como números
Sin `dtype`, Pandas convierte `linea` y `documento` en enteros: los ceros a la izquierda se pierden (`"0013055551234"` → `13055551234`) y los cruces entre tablas fallan en silencio. **Lee siempre los identificadores como texto.**
:::

Los ejemplos de esta página tienen a mano la muestra del curso (`cdr.csv`, `clientes.csv`, `planes.csv` y `facturas.csv`). Léela:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})

print(cdr.shape, clientes.shape)
print(cdr.head())
print(clientes[["cliente_id", "nombre", "ciudad"]].head(3))
```

:::reto Lee los planes y las facturas
Lee dos archivos de la muestra:

- `planes`: `planes.csv` (separado por comas, UTF-8);
- `facturas`: `facturas.csv` (separado por comas, UTF-8), con `cliente_id`, `linea` y `factura_id` como **texto**.

Después crea `total_facturado`: la suma de la columna `total` de las facturas.

```pyreto
import pandas as pd

# planes, facturas y total_facturado

print(planes.shape, facturas.shape, total_facturado)
```

:::pista
`pd.read_csv("facturas.csv", dtype={"cliente_id": "string", "linea": "string", "factura_id": "string"})`. La suma: `facturas["total"].sum()`.
:::

```pyprueba
import pandas as pd


def prueba_planes():
    """planes tiene los 6 planes"""
    requiere("planes")
    igual(planes.shape, (6, 11), "forma de planes")


def prueba_facturas():
    """facturas tiene los identificadores como texto"""
    requiere("facturas")
    igual(facturas.shape[0], 40, "filas de facturas")
    for columna in ("cliente_id", "linea", "factura_id"):
        assert pd.api.types.is_string_dtype(facturas[columna]), f"La columna {columna} debe leerse como texto (dtype)"


def prueba_total():
    """total_facturado suma la columna total"""
    requiere("total_facturado")
    esperado = pd.read_csv("facturas.csv")["total"].sum()
    igual(int(total_facturado), int(esperado))
```

```pysolucion
import pandas as pd

planes = pd.read_csv("planes.csv")
facturas = pd.read_csv("facturas.csv", dtype={"cliente_id": "string", "linea": "string", "factura_id": "string"})
total_facturado = facturas["total"].sum()

print(planes.shape, facturas.shape, total_facturado)
```

## Explorar: la primera mirada

```pyrun
import pandas as pd

cdr = pd.DataFrame({
    "cdr_id": [1, 2, 3, 4, 5, 6],
    "linea_origen": ["3001", "3002", "3001", "3003", "", "3002"],
    "tipo": ["VOZ", "SMS", "VOZ", "DATOS", "VOZ", "VOX"],
    "destino": ["LOCAL", "NACIONAL", "INTERNACIONAL", "", "LOCAL", "LOCAL"],
    "duracion_seg": [125, 0, 61, 3600, -45, 30],
    "mb": [0.0, 0.0, 0.0, 26.274, 0.0, 0.0],
})

print(cdr.head(3))            # primeras filas
print(cdr.dtypes)             # tipo de cada columna
cdr.info()                    # tipos, no nulos y memoria
print(cdr.describe())         # estadísticas de las columnas numéricas
print(cdr["tipo"].value_counts())   # frecuencias
print(cdr["tipo"].unique())
```

| Método | Para qué |
|---|---|
| `head(n)` / `tail(n)` / `sample(n)` | Mirar filas |
| `shape`, `columns`, `dtypes` | Estructura |
| `info()` | Tipos, cantidad de no nulos y memoria |
| `describe()` | Estadísticas (con `include="all"` también de texto) |
| `value_counts()` | Frecuencia de cada valor |
| `nunique()` | Cantidad de valores distintos por columna |

:::reto La primera mirada a los CDR
Lee el `cdr.csv` de la muestra (separado por `|`, líneas como texto) en `cdr` y responde:

- `filas`: cuántos registros tiene;
- `frecuencias`: cuántos registros hay de cada `tipo` (una Series, de mayor a menor);
- `tipos_distintos`: cuántos tipos distintos aparecen;
- `duracion_media`: el promedio de `duracion_seg`, redondeado a 1 decimal.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# filas, frecuencias, tipos_distintos y duracion_media

print(filas, tipos_distintos, duracion_media)
print(frecuencias)
```

:::pista
`len(cdr)` (o `cdr.shape[0]`), `cdr["tipo"].value_counts()`, `cdr["tipo"].nunique()` y `round(cdr["duracion_seg"].mean(), 1)`.
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def prueba_filas():
    """filas = cantidad de registros"""
    requiere("filas")
    igual(int(filas), len(_cdr()))


def prueba_frecuencias():
    """frecuencias cuenta cada tipo"""
    requiere("frecuencias")
    igual(dict(frecuencias), dict(_cdr()["tipo"].value_counts()))


def prueba_resumenes():
    """tipos_distintos y duracion_media"""
    requiere("tipos_distintos", "duracion_media")
    datos = _cdr()
    igual(int(tipos_distintos), int(datos["tipo"].nunique()), "tipos_distintos")
    cerca(float(duracion_media), round(float(datos["duracion_seg"].mean()), 1), 0.051, "duracion_media")
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

filas = len(cdr)
frecuencias = cdr["tipo"].value_counts()
tipos_distintos = cdr["tipo"].nunique()
duracion_media = round(cdr["duracion_seg"].mean(), 1)

print(filas, tipos_distintos, duracion_media)
print(frecuencias)
```
:::

## Leer archivos grandes

Con el archivo de 1 GB, `read_csv` funciona en tu computador (ocupa unos 2–3 GB de RAM). Con 20 GB no: necesitarás leer por partes (`chunksize`, módulo 14) o herramientas como DuckDB y Polars (módulo 16). Dos trucos para explorar rápido:

```python
pd.read_csv(ruta, sep="|", nrows=1000)                 # solo las primeras 1.000 filas
pd.read_csv(ruta, sep="|", usecols=["tipo", "mb"])     # solo algunas columnas
```

:::consejo El motor pyarrow
`pd.read_csv(..., engine="pyarrow")` usa el lector de Apache Arrow, varias veces más rápido con archivos grandes. Lo tienes instalado con las librerías del curso.
:::

:::telco Pandas 3 y el tipo string
Desde Pandas 3, las columnas de texto usan un tipo `str` dedicado (respaldado por Arrow) en lugar de `object`: ocupan menos memoria y son más rápidas. Si ves `dtype: object` en tutoriales viejos, es la versión anterior.
:::
