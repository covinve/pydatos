## Enunciado

Escribe `instrucciones(texto)` que lea un Dockerfile y devuelva una lista de tuplas `(INSTRUCCION, argumentos, linea)`:

- `INSTRUCCION` en **mayúsculas** (Docker acepta `from` o `FROM`).
- `argumentos`: el resto, sin espacios al principio ni al final. Si una línea termina en `\`, la instrucción **continúa** en la siguiente: une las partes con un espacio (sin la barra).
- `linea`: el número de línea (desde 1) donde **empieza** la instrucción.
- Las líneas vacías y los comentarios (`#` al principio, después de espacios) se ignoran, también dentro de una continuación.

Y `etapa_base(texto)` → la imagen del **primer** `FROM` (sin `AS nombre` si lo tiene), o `None`.

## Código inicial

```python
def instrucciones(texto):
    pass


def etapa_base(texto):
    pass


DOCKERFILE = """
# Imagen del pipeline
FROM python:3.12-slim AS base
WORKDIR /app
RUN pip install --no-cache-dir \\
        pandas \\
        duckdb
copy src/ src/
"""
for i in instrucciones(DOCKERFILE):
    print(i)
print(etapa_base(DOCKERFILE))
```

## Pruebas

```python
D = """
# Imagen del pipeline
FROM python:3.12-slim AS base

ENV PYTHONUNBUFFERED=1
WORKDIR /app
RUN pip install --no-cache-dir \\
        pandas \\
    # el motor SQL
        duckdb
copy src/ src/
   # comentario con sangría
ENTRYPOINT ["python", "-m", "app"]
"""


def prueba_instrucciones():
    """Instrucciones, continuaciones y líneas"""
    requiere("instrucciones")
    igual(instrucciones(D), [
        ("FROM", "python:3.12-slim AS base", 3),
        ("ENV", "PYTHONUNBUFFERED=1", 5),
        ("WORKDIR", "/app", 6),
        ("RUN", "pip install --no-cache-dir pandas duckdb", 7),
        ("COPY", "src/ src/", 11),
        ("ENTRYPOINT", '["python", "-m", "app"]', 13),
    ])


def prueba_vacio():
    """Sin instrucciones"""
    igual(instrucciones("\n# nada\n"), [])


def prueba_base():
    """Imagen base"""
    requiere("etapa_base")
    igual(etapa_base(D), "python:3.12-slim")
    igual(etapa_base("FROM postgres:16\nFROM python:3.12"), "postgres:16")
    igual(etapa_base("# vacío"), None)
```

## Pista 2

Al cerrar: `completa = " ".join(p for p in actual if p)`, luego `nombre, _, args = completa.partition(" ")`. Para la base: busca la primera con `"FROM"` y toma `args.split()[0]`.

## Solución

```python
def instrucciones(texto):
    resultado, actual, inicio = [], [], None
    for numero, linea in enumerate(texto.splitlines(), start=1):
        limpia = linea.strip()
        if not limpia or limpia.startswith("#"):
            continue
        if inicio is None:
            inicio = numero
        continua = limpia.endswith("\\")
        actual.append(limpia[:-1].strip() if continua else limpia)
        if not continua:
            completa = " ".join(p for p in actual if p)
            nombre, _, argumentos = completa.partition(" ")
            resultado.append((nombre.upper(), argumentos.strip(), inicio))
            actual, inicio = [], None
    return resultado


def etapa_base(texto):
    for nombre, argumentos, _ in instrucciones(texto):
        if nombre == "FROM":
            return argumentos.split()[0]
    return None


DOCKERFILE = """
# Imagen del pipeline
FROM python:3.12-slim AS base
WORKDIR /app
RUN pip install --no-cache-dir \\
        pandas \\
        duckdb
copy src/ src/
"""
for i in instrucciones(DOCKERFILE):
    print(i)
print(etapa_base(DOCKERFILE))
```

## Explicación

Este lector es el primer paso de cualquier herramienta que revisa Dockerfiles (como `hadolint`): en el ejercicio 2 lo usarás para detectar malas prácticas. Guardar el **número de línea** de inicio es lo que permite mensajes útiles como "línea 7: falta `--no-cache-dir`".

El detalle de las continuaciones es real: un `RUN` largo se parte en varias líneas con `\`, y Docker permite comentarios en medio (se ignoran). Si no los descartaras, la palabra `# el motor SQL` terminaría dentro del comando.

Fíjate en que `etapa_base` ignora el `AS base`: Dockerfiles con varias etapas (*multi-stage builds*) usan `FROM ... AS nombre` para construir en una imagen grande y copiar solo el resultado a una pequeña.
