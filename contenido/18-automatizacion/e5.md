## Enunciado

Escribe `con_reintentos(peticion, intentos=4, base=1.0, dormir=time.sleep)`, que ejecuta `peticion()` (una función sin argumentos que devuelve una respuesta con `.status_code` y `.headers`) y la **reintenta** cuando falla de forma transitoria:

| Resultado de `peticion()` | Qué hacer |
|---|---|
| Estado 2xx o 3xx | Devolver la respuesta |
| Estado 4xx (salvo 429) | Devolver la respuesta **sin reintentar** (es un error del cliente) |
| Estado 429 o 5xx | Reintentar |
| Lanza `ConnectionError` o `TimeoutError` | Reintentar |
| Lanza cualquier otra excepción | Dejarla salir **sin reintentar** |

- Antes del reintento número `n` (empezando en 0) espera `base * 2**n` segundos llamando `dormir(segundos)`. Si la respuesta es 429 y trae la cabecera `Retry-After` (segundos), espera **eso** en lugar del cálculo.
- `intentos` es el total de llamadas a `peticion()`. Si se agotan: si el último fallo fue una excepción, relánzala; si fue una respuesta, devuelve esa última respuesta.

`dormir` es un parámetro para que las pruebas no esperen de verdad: le pasan una función que **anota** las esperas.

## Código inicial

```python
import time


def con_reintentos(peticion, intentos=4, base=1.0, dormir=time.sleep):
    pass
```

## Pruebas

```python
class R:
    def __init__(self, estado, headers=None):
        self.status_code = estado
        self.headers = headers or {}


def guion(*pasos):
    """Una petición falsa que devuelve (o lanza) cada paso en orden."""
    llamadas = []

    def peticion():
        paso = pasos[len(llamadas)]
        llamadas.append(paso)
        if isinstance(paso, Exception):
            raise paso
        return paso

    return peticion, llamadas


def correr(*pasos, **opciones):
    esperas = []
    peticion, llamadas = guion(*pasos)
    resultado = con_reintentos(peticion, dormir=esperas.append, **opciones)
    return resultado, len(llamadas), esperas


def prueba_exito_directo():
    """Sin errores no espera nada"""
    requiere("con_reintentos")
    r, n, esperas = correr(R(200))
    igual((r.status_code, n, esperas), (200, 1, []))


def prueba_recupera():
    """Reintenta 5xx y errores de conexión con espera exponencial"""
    r, n, esperas = correr(R(503), ConnectionError("caída"), TimeoutError(), R(200))
    igual((r.status_code, n), (200, 4))
    igual(esperas, [1.0, 2.0, 4.0])
    r, n, esperas = correr(R(500), R(201), base=0.5)
    igual(esperas, [0.5])


def prueba_no_reintenta_4xx():
    """Un 404 o 401 se devuelve de inmediato"""
    for estado in (400, 401, 404):
        r, n, esperas = correr(R(estado), R(200))
        igual((r.status_code, n, esperas), (estado, 1, []))


def prueba_retry_after():
    """Respeta Retry-After en un 429"""
    r, n, esperas = correr(R(429, {"Retry-After": "7"}), R(429), R(200))
    igual(esperas, [7.0, 2.0])
    igual(r.status_code, 200)


def prueba_se_agotan():
    """Al agotar los intentos devuelve la última respuesta o relanza la excepción"""
    r, n, esperas = correr(R(503), R(502), R(504), R(500), R(200))
    igual((r.status_code, n, esperas), (500, 4, [1.0, 2.0, 4.0]))
    esperas = []
    peticion, llamadas = guion(ConnectionError("a"), ConnectionError("b"))
    e = lanza(ConnectionError, con_reintentos, peticion, intentos=2, dormir=esperas.append)
    igual((str(e), esperas), ("b", [1.0]))


def prueba_otras_excepciones():
    """Un error de programación no se reintenta"""
    esperas = []
    peticion, llamadas = guion(KeyError("x"), R(200))
    lanza(KeyError, con_reintentos, peticion, dormir=esperas.append)
    igual((len(llamadas), esperas), (1, []))
```

## Solución

```python
import time


def _transitorio(respuesta):
    return respuesta.status_code == 429 or respuesta.status_code >= 500


def con_reintentos(peticion, intentos=4, base=1.0, dormir=time.sleep):
    ultimo = None
    for intento in range(intentos):
        espera = base * 2 ** intento
        try:
            respuesta = peticion()
        except (ConnectionError, TimeoutError) as e:
            ultimo = e
        else:
            if not _transitorio(respuesta):
                return respuesta
            ultimo = respuesta
            if respuesta.status_code == 429 and "Retry-After" in respuesta.headers:
                espera = float(respuesta.headers["Retry-After"])
        if intento < intentos - 1:
            dormir(espera)
    if isinstance(ultimo, Exception):
        raise ultimo
    return ultimo
```

## Explicación

Esta función es **genérica**: no sabe nada de facturas ni de URL. Recibe "algo que hacer" (`peticion`) y una política de reintentos. Se usa así:

```python
respuesta = con_reintentos(lambda: sesion.get(url, params=params, timeout=10))
```

Pasar `dormir` como parámetro es una forma sencilla de **inyección de dependencias**: en producción es `time.sleep`; en las pruebas, una función que anota. Sin esto, probar los reintentos tardaría segundos de espera real en cada ejecución. Es la misma idea que verás con `unittest.mock` y en la arquitectura en capas.

En proyectos reales también existen librerías (como `tenacity`, o los `Retry` de `urllib3` que usa requests por dentro) que hacen esto con decoradores. Pero ahora sabes exactamente qué hacen y qué configurar.
