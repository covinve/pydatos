El **análisis exploratorio de datos** (EDA, por *Exploratory Data Analysis*) es la primera conversación con un conjunto de datos nuevo. Hacerlo con método evita sorpresas después.

## Lista de chequeo

1. **Estructura**: filas, columnas, tipos (`shape`, `info`).
2. **Calidad**: faltantes, duplicados, valores imposibles (duraciones negativas, fechas inválidas).
3. **Cada variable sola**: distribución (histograma), centro, dispersión, atípicos.
4. **Variables juntas**: comparaciones por grupo (cajas, barras), relaciones (dispersión, correlación).
5. **Tiempo**: tendencias, estacionalidad semanal o diaria, días faltantes.
6. **Conclusiones y preguntas**: qué encontraste y qué hay que investigar.

## Varias vistas en una figura

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
validos = cdr[cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (cdr["duracion_seg"] >= 0) & cdr["inicio"].notna()]

fig, ejes = plt.subplots(2, 2, figsize=(10, 6), constrained_layout=True)
fig.suptitle("Panorama del consumo · septiembre 2026", fontweight="bold")

validos["tipo"].value_counts().plot.bar(ax=ejes[0, 0], color="#4f46e5", rot=0, title="Registros por tipo")
validos.set_index("inicio").resample("D").size().plot(ax=ejes[0, 1], color="#16a34a", title="Registros por día")
voz = validos[validos["tipo"] == "VOZ"]
ejes[1, 0].hist(voz["duracion_seg"].clip(upper=1800), bins=30, color="#0891b2")
ejes[1, 0].set_title("Duración de llamadas (cortada en 30 min)")
validos[validos["tipo"] == "DATOS"].groupby(validos["inicio"].dt.hour)["mb"].sum().div(1024).plot.bar(
    ax=ejes[1, 1], color="#f59e0b", title="GB por hora del día")
for eje in ejes.flat:
    eje.set_xlabel("")
```

## Notebooks bien llevados

Los notebooks de Jupyter son el lugar natural del EDA. Para que sigan siendo útiles después de una semana:

- **Ejecuta todo de arriba abajo** antes de compartirlo (*Restart & Run All*). Un notebook que solo funciona en cierto orden de celdas no es reproducible.
- **Las funciones van a módulos** (`from mi_proyecto.lectura import leer_cdr`): el notebook explora, el paquete implementa.
- **Celdas de texto** con las conclusiones, no solo código.
- **Rutas relativas** y parámetros al inicio (`CARPETA = Path("datos/10MB")`).
- En Git, limpia las salidas antes de hacer commit si el notebook es grande.

## seaborn: gráficos estadísticos en una línea

En tu computador tienes **seaborn**, construido sobre matplotlib, que hace en una línea gráficos estadísticos que con matplotlib llevarían varias:

```python
import seaborn as sns

sns.boxplot(data=por_linea, x="plan_id", y="minutos")
sns.histplot(data=voz, x="duracion_seg", hue="destino", log_scale=True)
sns.heatmap(matriz, cmap="viridis")
sns.pairplot(por_linea[["minutos", "mb", "sms"]])
```

## Reportes automáticos

Si el mismo análisis se repite cada mes, conviértelo en un **script** que genere las figuras y un resumen en Markdown o HTML. Así el reporte del mes siguiente es ejecutar un comando:

```python
fig.savefig(salida / "panorama.png", dpi=150, bbox_inches="tight")
(salida / "resumen.md").write_text(f"# Consumo {periodo}\n\n![Panorama](panorama.png)\n\n- Registros válidos: {n:,}\n", encoding="utf-8")
```

Lo harás en el ejercicio 9, y en el Proyecto 2 el reporte de conciliación incluirá sus gráficos.

`carpeta = Path("reporte")` y `carpeta.mkdir(exist_ok=True)`. `fig.savefig(carpeta / "tipos.png", dpi=100, bbox_inches="tight")`. Para el número: `f"{len(validos):,}".replace(",", ".")`. Escribe el texto con `(carpeta / "resumen.md").write_text(..., encoding="utf-8")`.

```pyprueba
from pathlib import Path


def prueba_imagen():
    """Se guardó reporte/tipos.png"""
    ruta = Path("reporte") / "tipos.png"
    assert ruta.exists(), "No se encontró reporte/tipos.png"
    assert ruta.read_bytes()[:4] == b"\x89PNG", "tipos.png no es una imagen PNG"


def prueba_resumen():
    """resumen.md tiene el título, la imagen y el conteo"""
    requiere("validos")
    ruta = Path("reporte") / "resumen.md"
    assert ruta.exists(), "No se encontró reporte/resumen.md"
    texto = ruta.read_text(encoding="utf-8")
    assert "# Consumo 202609" in texto, "Falta el título «# Consumo 202609»"
    assert "![Registros por tipo](tipos.png)" in texto, "Falta la imagen con ![Registros por tipo](tipos.png)"
    n = f"{len(validos):,}".replace(",", ".")
    assert f"- Registros válidos: {n}" in texto, f"Falta la línea «- Registros válidos: {n}»"
```

## Cuestionario

? ¿Qué significa que un notebook sea reproducible?
- [ ] Que tiene muchos gráficos
- [x] Que al reiniciarlo y ejecutar todas las celdas en orden produce los mismos resultados
- [ ] Que está en la nube
- [ ] Que no tiene código
> Si depende de haber ejecutado celdas en un orden especial, nadie más (ni tú en un mes) podrá repetirlo.

? En `fig, ejes = plt.subplots(2, 2)`, ¿cómo accedes al gráfico de abajo a la derecha?
- [ ] `ejes[4]`
- [x] `ejes[1, 1]`
- [ ] `ejes[2, 2]`
- [ ] `ejes.ultimo`
> `ejes` es un array de 2 × 2: fila 1, columna 1 (contando desde 0).

? ¿Dónde conviene poner las funciones que usas en el análisis?
- [ ] Copiadas en cada notebook
- [x] En módulos de un paquete, importados desde el notebook
- [ ] En un archivo de texto
- [ ] No conviene usar funciones
> Así se prueban, se reutilizan y el notebook queda enfocado en explorar.
