## Agregaciones

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45, 300, 15])

print("Total:", duraciones.sum())
print("Promedio:", duraciones.mean().round(1))
print("Mediana:", np.median(duraciones))
print("Desviación:", duraciones.std().round(1))
print("Mín / máx:", duraciones.min(), duraciones.max())
print("Percentil 95:", np.percentile(duraciones, 95))
print("Posición del máximo:", duraciones.argmax())
```

### El parámetro axis

En arrays de 2 dimensiones, `axis` dice en qué dirección agregar: `axis=0` recorre **filas** (resultado por columna) y `axis=1` recorre **columnas** (resultado por fila).

```pyrun
import numpy as np

# filas: 3 líneas; columnas: minutos de 4 semanas
semanas = np.array([
    [80, 95, 70, 97],
    [5, 0, 10, 0],
    [300, 280, 310, 313],
])
print(semanas.sum(axis=1))    # total de cada línea
print(semanas.sum(axis=0))    # total de cada semana
print(semanas.mean(axis=0))
```

## Agrupar: np.unique y np.bincount

Para sumar por grupo (minutos por línea), NumPy no tiene `groupby`, pero tiene piezas muy rápidas:

```pyrun
import numpy as np

lineas = np.array(["3002", "3001", "3002", "3003", "3001", "3002"])
minutos = np.array([3, 2, 1, 60, 5, 2])

unicas, indice = np.unique(lineas, return_inverse=True)
print(unicas)          # las líneas distintas, ordenadas
print(indice)          # para cada registro, la posición de su línea en `unicas`

totales = np.bincount(indice, weights=minutos)
print(dict(zip(unicas.tolist(), totales.astype(int).tolist())))

conteos = np.bincount(indice)            # sin weights: cuenta registros por grupo
print(conteos)
```

`np.bincount(indice, weights=valores)` suma `valores` en la posición `indice` de cada uno. Es exactamente lo que hace el generador de datos del curso para acumular el consumo de cientos de miles de líneas.

## Ordenar

```pyrun
import numpy as np

minutos = np.array([342, 15, 1203, 342, 60])
print(np.sort(minutos))                  # copia ordenada
orden = np.argsort(minutos)[::-1]        # posiciones de mayor a menor
print(orden)
lineas = np.array(["3001", "3002", "3003", "3004", "3005"])
print(lineas[orden][:3])                 # top 3
```

`argsort` devuelve **posiciones**: sirve para ordenar varios arrays "en paralelo" según uno de ellos.

## Acumulados

```pyrun
import numpy as np

minutos_por_llamada = np.array([3, 0, 2, 60, 1, 5])
acumulado = np.cumsum(minutos_por_llamada)
print(acumulado)
print(np.argmax(acumulado > 60))   # primera llamada en que se superan 60 minutos
```

## Broadcasting

NumPy puede operar arrays de **formas distintas** "estirando" el más pequeño. El caso más común es un array con un escalar (`array * 120`), pero también funciona con filas y columnas:

```pyrun
import numpy as np

# 3 líneas × 3 conceptos (minutos, megas, sms) de exceso
excesos = np.array([
    [42, 141, 20],
    [0, 0, 0],
    [203, 0, 5],
])
tarifas = np.array([120, 18, 60])      # una tarifa por columna

print(excesos * tarifas)               # la fila de tarifas se aplica a cada fila
print((excesos * tarifas).sum(axis=1))
```

:::capo La regla del broadcasting
Se comparan las formas desde la última dimensión: son compatibles si son iguales o si una de ellas es 1. `(3, 3)` con `(3,)` funciona (la fila se repite); `(3, 3)` con `(4,)` da error.
:::

:::telco De diccionarios a arrays
En el módulo 4 agrupaste con diccionarios: correcto y claro, pero con 280 millones de registros es lento. Con `np.unique` + `np.bincount`, el mismo agrupamiento sobre millones de valores toma milisegundos. Pandas (`groupby`) usa estas mismas ideas por dentro.
:::
