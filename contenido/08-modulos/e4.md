## Enunciado

`ejercicios/m08-e4/monolito.py` hace todo en un solo bloque: lee el archivo, valida, suma minutos e imprime. Funciona, pero no se puede probar ni reutilizar ninguna parte.

Crea el paquete `ejercicios/m08-e4/facturador/` con esta estructura y responsabilidades:

| Módulo | Contiene | Reglas |
|---|---|---|
| `lectura.py` | `leer_cdr(ruta)` → **generador** de diccionarios (uno por fila) | Es el único que abre archivos |
| `reglas.py` | `minutos_facturables(segundos)`, `es_valido(fila)` | No importa nada del paquete ni `csv` |
| `reportes.py` | `resumir(filas)` → diccionario; `formatear(resumen)` → texto | No abre archivos: recibe las filas |
| `__init__.py` | `procesar(ruta)` → el texto final | Une las piezas |

`resumir` devuelve `{"validos": int, "invalidos": int, "minutos_por_linea": {linea: minutos}}` y `formatear` produce **exactamente** el mismo texto que imprime el monolito (sin el salto de línea final).

No modifiques `monolito.py`: las pruebas lo ejecutan para comparar.

```powershell
python ejercicios/m08-e4/monolito.py ejercicios/m08-e4/llamadas.csv
python comprobar.py m08-e4
```

## Pista 1

Empieza por `reglas.py`, que es lo más fácil y no depende de nadie:

```python
TIPOS = {"VOZ", "SMS", "DATOS"}


def minutos_facturables(segundos: int) -> int:
    return (segundos + 59) // 60


def es_valido(fila: dict) -> bool:
    return fila["tipo"] in TIPOS and int(fila["duracion_seg"]) >= 0
```

Luego `lectura.py`: un `with open(...)` y `yield from csv.DictReader(...)`.

## Pista 2

`reportes.py` importa de `reglas` (la dirección correcta) y recibe un iterable de filas. `formatear` arma la lista de líneas con el mismo orden que el monolito: de más minutos a menos, y en empate por línea.

En `__init__.py`:

```python
from facturador.lectura import leer_cdr
from facturador.reportes import formatear, resumir


def procesar(ruta):
    return formatear(resumir(leer_cdr(ruta)))
```

## Solución

```python facturador/__init__.py
"""Reporte de consumo de voz, dividido por responsabilidades."""

from facturador.lectura import leer_cdr
from facturador.reportes import formatear, resumir

__all__ = ["procesar"]


def procesar(ruta):
    return formatear(resumir(leer_cdr(ruta)))
```

```python facturador/lectura.py
import csv
from collections.abc import Iterator
from pathlib import Path


def leer_cdr(ruta: Path) -> Iterator[dict[str, str]]:
    with open(ruta, encoding="utf-8", newline="") as archivo:
        yield from csv.DictReader(archivo, delimiter="|")
```

```python facturador/reglas.py
TIPOS = {"VOZ", "SMS", "DATOS"}


def minutos_facturables(segundos: int) -> int:
    return (segundos + 59) // 60


def es_valido(fila: dict) -> bool:
    return fila["tipo"] in TIPOS and int(fila["duracion_seg"]) >= 0
```

```python facturador/reportes.py
from collections.abc import Iterable

from facturador.reglas import es_valido, minutos_facturables


def resumir(filas: Iterable[dict]) -> dict:
    validos = invalidos = 0
    minutos_por_linea: dict[str, int] = {}
    for fila in filas:
        if not es_valido(fila):
            invalidos += 1
            continue
        validos += 1
        if fila["tipo"] == "VOZ":
            linea = fila["linea_origen"]
            minutos = minutos_facturables(int(fila["duracion_seg"]))
            minutos_por_linea[linea] = minutos_por_linea.get(linea, 0) + minutos
    return {"validos": validos, "invalidos": invalidos, "minutos_por_linea": minutos_por_linea}


def formatear(resumen: dict) -> str:
    lineas = [f"Registros válidos: {resumen['validos']} · inválidos: {resumen['invalidos']}"]
    ordenadas = sorted(resumen["minutos_por_linea"].items(), key=lambda par: (-par[1], par[0]))
    lineas += [f"  {linea}: {minutos} min" for linea, minutos in ordenadas]
    lineas.append(f"Total: {sum(resumen['minutos_por_linea'].values())} min")
    return "\n".join(lineas)
```

## Explicación

El código hace lo mismo, pero ahora:

- **`reglas.py` se puede probar sin archivos**: `es_valido({"tipo": "VOX", ...})` y listo.
- **`reportes.resumir` acepta cualquier iterable** de filas: un archivo, una lista de prueba, o en el futuro una consulta a base de datos.
- **`lectura.leer_cdr` es un generador** (`yield from`): el archivo se recorre una sola vez, fila por fila, aunque pese 20 GB.
- **Las dependencias van en una dirección**: `__init__` → `reportes` → `reglas`. Las pruebas `test_reglas_no_dependen_de_nadie` y `test_reportes_no_abren_archivos` vigilan que siga así.

Separar `resumir` (calcular) de `formatear` (presentar) parece exagerado en un ejemplo pequeño, pero es lo que permite agregar mañana un reporte en JSON o en Excel sin tocar el cálculo.
