La mayoría de los problemas de datos se resuelven combinando **seis patrones**. Cuando los reconozcas, dejarás de pensar "¿cómo hago esto?" y empezarás a pensar "¿qué patrón es?".

Usaremos estas llamadas de un cliente en todos los ejemplos:

```python
duraciones = [125, 0, 61, 3600, 45, 0, 300]
```

## 1. Acumular

Una variable que empieza en un valor neutro y crece en cada vuelta.

```pyrun
duraciones = [125, 0, 61, 3600, 45, 0, 300]

total_minutos = 0                       # empieza en 0
for d in duraciones:
    total_minutos += (d + 59) // 60     # += es "sumar y guardar"

print(total_minutos)
```

`x += 1` es lo mismo que `x = x + 1`. También existen `-=`, `*=` y `/=`.

## 2. Contar

Un acumulador que suma 1 solo cuando se cumple una condición.

```pyrun
duraciones = [125, 0, 61, 3600, 45, 0, 300]

no_contestadas = 0
for d in duraciones:
    if d == 0:
        no_contestadas += 1

print(f"{no_contestadas} llamadas sin contestar")
```

:::reto Acumular y contar a la vez
En un solo recorrido de `duraciones`:

- cuenta en `largas` las llamadas de **5 minutos o más** (300 segundos o más);
- acumula en `segundos_largas` los segundos de esas llamadas.

```pyreto
duraciones = [125, 0, 61, 3600, 45, 0, 300, 299, 900]
largas = 0
segundos_largas = 0

# Un solo for: cuenta y acumula las llamadas largas

print(largas, segundos_largas)
```

:::pista
Dentro del `for`, un solo `if d >= 300:` con dos líneas adentro: `largas += 1` y `segundos_largas += d`.
:::

```pyprueba
def prueba_largas():
    """largas = 3"""
    requiere("largas")
    igual(largas, 3)


def prueba_segundos():
    """segundos_largas = 4800"""
    requiere("segundos_largas")
    igual(segundos_largas, 4800)
```

```pysolucion
duraciones = [125, 0, 61, 3600, 45, 0, 300, 299, 900]
largas = 0
segundos_largas = 0

for d in duraciones:
    if d >= 300:
        largas += 1
        segundos_largas += d

print(largas, segundos_largas)
```
:::

## 3. Buscar

Recorrer hasta encontrar y salir con `break`. Si no se encuentra, la variable conserva su valor inicial (normalmente `None`).

```pyrun
duraciones = [125, 0, 61, 3600, 45, 0, 300]

primera_larga = None
for posicion, d in enumerate(duraciones):
    if d >= 3600:
        primera_larga = posicion
        break

print(f"Primera llamada de una hora o más: posición {primera_larga}")
```

:::reto ¿Dónde está la primera llamada internacional?
Escribe `primera_internacional(destinos)` que devuelva la **posición** del primer `"INTERNACIONAL"` de la lista, o `None` si no hay ninguno.

```pyreto
def primera_internacional(destinos):
    # Patrón buscar: recorre con enumerate y sal al encontrarlo
    pass


print(primera_internacional(["LOCAL", "NACIONAL", "INTERNACIONAL", "INTERNACIONAL"]))  # 2
print(primera_internacional(["LOCAL"]))                                                # None
```

:::pista
Dentro de una función puedes salir con `return` en lugar de `break`: `for posicion, destino in enumerate(destinos):` y, si coincide, `return posicion`. Después del `for`, `return None`.
:::

```pyprueba
def prueba_encuentra():
    """Devuelve la posición del primero"""
    requiere("primera_internacional")
    igual(primera_internacional(["LOCAL", "NACIONAL", "INTERNACIONAL", "INTERNACIONAL"]), 2)
    igual(primera_internacional(["INTERNACIONAL"]), 0)


def prueba_no_encuentra():
    """Devuelve None si no hay ninguno"""
    igual(primera_internacional(["LOCAL", "NACIONAL"]), None)
    igual(primera_internacional([]), None)
```

```pysolucion
def primera_internacional(destinos):
    for posicion, destino in enumerate(destinos):
        if destino == "INTERNACIONAL":
            return posicion
    return None


print(primera_internacional(["LOCAL", "NACIONAL", "INTERNACIONAL", "INTERNACIONAL"]))  # 2
print(primera_internacional(["LOCAL"]))                                                # None
```
:::

## 4. Filtrar

Crear una lista nueva solo con los elementos que cumplen una condición. `lista.append(x)` agrega un elemento al final.

```pyrun
duraciones = [125, 0, 61, 3600, 45, 0, 300]

contestadas = []
for d in duraciones:
    if d > 0:
        contestadas.append(d)

print(contestadas)
```

:::reto Solo las líneas móviles
Filtra en la lista `moviles` las líneas que empiezan por `"3"` y tienen 10 caracteres. Usa un `for` y `append`.

```pyreto
lineas = ["3001234567", "6014445566", "3109876543", "31577", "3157778899", ""]
moviles = []

# Recorre y agrega solo las móviles

print(moviles)
```

:::pista
La condición es `linea.startswith("3") and len(linea) == 10`. Si se cumple, `moviles.append(linea)`.
:::

```pyprueba
def prueba_moviles():
    """moviles tiene las tres líneas válidas, en orden"""
    requiere("moviles")
    igual(moviles, ["3001234567", "3109876543", "3157778899"])


def prueba_usa_append():
    """Usa append"""
    assert ".append(" in codigo, "Agrega cada línea con moviles.append(...)"
```

```pysolucion
lineas = ["3001234567", "6014445566", "3109876543", "31577", "3157778899", ""]
moviles = []

for linea in lineas:
    if linea.startswith("3") and len(linea) == 10:
        moviles.append(linea)

print(moviles)
```
:::

## 5. Máximo y mínimo

Guardar "el mejor hasta ahora" y reemplazarlo cuando aparece uno mejor.

```pytrace
duraciones = [125, 0, 3600, 45]
mas_larga = duraciones[0]
for d in duraciones:
    if d > mas_larga:
        mas_larga = d
print(mas_larga)
```

Python trae `max()`, `min()` y `sum()` que hacen esto en una línea. Úsalos en tu código real; pero entender el patrón te sirve para casos que no cubren, como "la llamada más larga **de cada cliente**".

:::reto La línea que más habló
`max()` te da el mayor número, pero no **de quién** es. Con el patrón del máximo, encuentra la línea con más minutos:

- `mas_minutos`: los minutos de la línea que más habló;
- `linea_top`: esa línea.

```pyreto
lineas = ["3001234567", "3109876543", "3157778899", "3204445566"]
minutos = [342, 15, 1203, 980]

# Patrón máximo: guarda el mejor hasta ahora (y de quién es)

print(linea_top, mas_minutos)
```

:::pista
Empieza con el primero: `mas_minutos = minutos[0]` y `linea_top = lineas[0]`. Recorre con `zip(lineas, minutos)` y, cuando encuentres uno mayor, actualiza **las dos** variables.
:::

```pyprueba
def prueba_maximo():
    """mas_minutos = 1203 y linea_top = «3157778899»"""
    requiere("mas_minutos", "linea_top")
    igual(mas_minutos, 1203, "mas_minutos")
    igual(linea_top, "3157778899", "linea_top")
```

```pysolucion
lineas = ["3001234567", "3109876543", "3157778899", "3204445566"]
minutos = [342, 15, 1203, 980]

mas_minutos = minutos[0]
linea_top = lineas[0]
for linea, mins in zip(lineas, minutos):
    if mins > mas_minutos:
        mas_minutos = mins
        linea_top = linea

print(linea_top, mas_minutos)
```
:::

## 6. Banderas: ¿alguno?, ¿todos?

Una variable booleana que cambia si aparece cierto caso.

```pyrun
duraciones = [125, 0, 61, -30, 45]

hay_negativas = False
for d in duraciones:
    if d < 0:
        hay_negativas = True
        break

print("¿Hay duraciones negativas?", hay_negativas)

# Python trae any() y all() para esto:
print(any(d < 0 for d in duraciones))
print(all(d >= 0 for d in duraciones))
```

:::reto Preguntas de sí o no
Con `any()` y `all()`, responde sobre los `tipos` de un archivo:

- `hay_datos`: ¿hay **algún** registro de `"DATOS"`?
- `todos_validos`: ¿son **todos** `VOZ`, `SMS` o `DATOS`?

```pyreto
tipos = ["VOZ", "SMS", "VOZ", "DATOS", "VOX", "SMS"]

# Crea hay_datos y todos_validos con any() y all()

print(hay_datos, todos_validos)
```

:::pista
`any(t == "DATOS" for t in tipos)` y `all(t in ("VOZ", "SMS", "DATOS") for t in tipos)`.
:::

```pyprueba
def prueba_respuestas():
    """hay_datos es True y todos_validos es False"""
    requiere("hay_datos", "todos_validos")
    igual(hay_datos, True, "hay_datos")
    igual(todos_validos, False, "todos_validos")


def prueba_usa_any_all():
    """Usa any() y all()"""
    assert "any(" in codigo and "all(" in codigo, "Responde con any(...) y all(...)"
```

```pysolucion
tipos = ["VOZ", "SMS", "VOZ", "DATOS", "VOX", "SMS"]

hay_datos = any(t == "DATOS" for t in tipos)
todos_validos = all(t in ("VOZ", "SMS", "DATOS") for t in tipos)

print(hay_datos, todos_validos)
```
:::

## Comprensiones de listas

El patrón **filtrar y transformar** es tan común que Python tiene una sintaxis especial para escribirlo en una línea:

:::comparar
:::mal Bucle de 4 líneas
```python
minutos = []
for d in duraciones:
    if d > 0:
        minutos.append((d + 59) // 60)
```
:::
:::bien Comprensión
```python
minutos = [(d + 59) // 60 for d in duraciones if d > 0]
```
:::
:::

Se lee casi en español: "*(d + 59) // 60 **para cada** d **en** duraciones **si** d > 0*".

```pyrun
duraciones = [125, 0, 61, 3600, 45, 0, 300]

minutos = [(d + 59) // 60 for d in duraciones if d > 0]
print(minutos)
print("Total:", sum(minutos))
print("Más larga:", max(minutos), "min")
```

:::consejo Cuándo usar comprensiones
Úsalas cuando caben en una línea y se leen fácil. Si necesitas varios `if`, cálculos intermedios o un `print` adentro, el bucle normal es más claro. La legibilidad gana siempre.
:::

:::reto Megas facturables en una línea
Con **una comprensión de listas**, crea `facturables` con las megas de cada sesión redondeadas hacia arriba (`math.ceil`), **omitiendo** las sesiones de 0 MB.

```pyreto
import math

sesiones_mb = [15.131, 0, 230.5, 0.2, 0, 1024.0]

facturables = []   # reemplaza esto por una comprensión

print(facturables)
```

:::pista
La forma es `[transformación for elemento in lista if condición]`: `[math.ceil(mb) for mb in sesiones_mb if mb > 0]`.
:::

```pyprueba
import ast


def prueba_valores():
    """facturables = [16, 231, 1, 1024]"""
    requiere("facturables")
    igual(facturables, [16, 231, 1, 1024])


def prueba_comprension():
    """Usa una comprensión de listas"""
    assert any(isinstance(n, ast.ListComp) for n in ast.walk(ast.parse(codigo))), "Crea la lista con [... for ... in ... if ...]"
```

```pysolucion
import math

sesiones_mb = [15.131, 0, 230.5, 0.2, 0, 1024.0]

facturables = [math.ceil(mb) for mb in sesiones_mb if mb > 0]

print(facturables)
```
:::

## Combinar patrones

Un problema real casi siempre combina varios. Por ejemplo: "valor total de las llamadas internacionales contestadas" es **filtrar** (internacionales y contestadas) + **acumular** (valor):

```pyrun
llamadas = [
    ("INTERNACIONAL", 125),
    ("LOCAL", 300),
    ("INTERNACIONAL", 0),
    ("INTERNACIONAL", 61),
]
TARIFA_INT = 950

valor = 0
for destino, segundos in llamadas:
    if destino != "INTERNACIONAL" or segundos == 0:
        continue
    valor += (segundos + 59) // 60 * TARIFA_INT

print(f"Valor internacional: ${valor:,}")
```

:::telco Validar un archivo completo
Validar un archivo de CDR es exactamente esto: **contar** registros por tipo de error, **filtrar** los válidos, **acumular** minutos y megas, **buscar** el primer registro problemático. Los patrones son los mismos con 10 registros o con 200 millones.
:::

## Cuestionario

? Quieres saber cuántas llamadas internacionales hay. ¿Qué patrón usas?
- [ ] Acumular
- [x] Contar
- [ ] Buscar
- [ ] Máximo
> Contar es sumar 1 cada vez que se cumple una condición (destino internacional).

? ¿Qué produce `[d * 2 for d in [1, 2, 3] if d != 2]`?
- [ ] `[2, 4, 6]`
- [x] `[2, 6]`
- [ ] `[1, 3]`
- [ ] `[4]`
> Se filtran los valores distintos de 2 (quedan 1 y 3) y cada uno se multiplica por 2.

? ¿Qué devuelve `all(d > 0 for d in [5, 3, 0])`?
- [ ] `True`
- [x] `False`
- [ ] `0`
- [ ] `[True, True, False]`
> `all` es verdadero solo si **todos** cumplen la condición; el 0 no es mayor que 0.
