## Enunciado

Crea la clase `Plan` con:

- `__init__(self, plan_id, cargo_fijo, minutos_incluidos, mb_incluidos, tarifa_minuto, tarifa_mb)` que guarde todo como atributos.
- La constante de clase `ILIMITADO = -1`.
- `valor_voz(self, minutos)` → exceso de minutos × tarifa (0 si es ilimitado).
- `valor_datos(self, mb)` → las megas se redondean hacia arriba; exceso × tarifa (0 si es ilimitado).
- `es_ilimitado(self)` → `True` si **ambos** (minutos y megas) son ilimitados.

```python
hogar = Plan("HOG30", 35900, 300, 15360, 120, 18)
hogar.valor_voz(342)         # 5040
hogar.valor_datos(15500.2)   # 2538
hogar.es_ilimitado()         # False
```

## Solución

```python
import math


class Plan:
    ILIMITADO = -1

    def __init__(self, plan_id, cargo_fijo, minutos_incluidos, mb_incluidos, tarifa_minuto, tarifa_mb):
        self.plan_id = plan_id
        self.cargo_fijo = cargo_fijo
        self.minutos_incluidos = minutos_incluidos
        self.mb_incluidos = mb_incluidos
        self.tarifa_minuto = tarifa_minuto
        self.tarifa_mb = tarifa_mb

    def valor_voz(self, minutos):
        if self.minutos_incluidos == self.ILIMITADO:
            return 0
        return max(0, minutos - self.minutos_incluidos) * self.tarifa_minuto

    def valor_datos(self, mb):
        if self.mb_incluidos == self.ILIMITADO:
            return 0
        return max(0, math.ceil(mb) - self.mb_incluidos) * self.tarifa_mb

    def es_ilimitado(self):
        return self.minutos_incluidos == self.ILIMITADO and self.mb_incluidos == self.ILIMITADO


hogar = Plan("HOG30", 35900, 300, 15360, 120, 18)
print(hogar.valor_voz(342), hogar.valor_datos(15500.2))
```

## Explicación

Las reglas que antes eran funciones sueltas con muchos parámetros ahora **viven con los datos que usan**: `hogar.valor_voz(342)` no necesita que le pases las tarifas, porque el plan ya las conoce.

`self.ILIMITADO` funciona porque, si un atributo no está en el objeto, Python lo busca en la clase. Es la forma usual de leer constantes de clase desde los métodos.
