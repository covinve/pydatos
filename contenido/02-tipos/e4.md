## Enunciado

El sistema de mediación entrega los CDR en **ancho fijo**. Escribe una función por campo que reciba un registro (una línea de texto de 91 caracteres) y devuelva el valor **con el tipo correcto**:

| Función | Posiciones (desde 1) | Devuelve | Detalle |
|---|---|---|---|
| `extraer_cdr_id(registro)` | 1–12 | `int` | Sin ceros a la izquierda |
| `extraer_linea_origen(registro)` | 13–22 | `str` | Sin espacios sobrantes |
| `extraer_tipo(registro)` | 36–40 | `str` | Sin espacios (`"VOZ"`) |
| `extraer_fecha(registro)` | 54–67 | `str` | Con formato `"AAAA-MM-DD HH:MM:SS"` |
| `extraer_duracion(registro)` | 68–73 | `int` | Puede ser negativa (`-00045` → `-45`) |
| `extraer_mb(registro)` | 74–83 | `float` | `000026.274` → `26.274` |

```python
r = "0000000000023267999245             DATOS             20260914085504001856000026.274CEL59973"
extraer_cdr_id(r)        # 2
extraer_linea_origen(r)  # "3267999245"
extraer_tipo(r)          # "DATOS"
extraer_fecha(r)         # "2026-09-14 08:55:04"
extraer_duracion(r)      # 1856
extraer_mb(r)            # 26.274
```

El diseño completo está en **Referencia → Datos del curso**.

## Pruebas

```python
VOZ = "00000000000233027032633040879936   VOZ  NACIONAL     20260913103128000030000000.000CEL97932"
DATOS = "0000000000023267999245             DATOS             20260914085504001856000026.274CEL59973"
NEGATIVA = "00000004512331234567893109876543   VOZ  LOCAL        20260901000501-00045000000.000CEL11111"
VACIA = "000000000777          3001112233   SMS  LOCAL        20260930235959000000000000.000CEL22222"


def prueba_cdr_id():
    """El cdr_id es un int sin ceros a la izquierda"""
    requiere("extraer_cdr_id")
    igual(extraer_cdr_id(VOZ), 2)
    igual(extraer_cdr_id(NEGATIVA), 45123)
    assert isinstance(extraer_cdr_id(VOZ), int), "extraer_cdr_id debe devolver int"


def prueba_linea_origen():
    """La línea de origen es texto de 10 dígitos"""
    igual(extraer_linea_origen(VOZ), "3302703263")
    igual(extraer_linea_origen(NEGATIVA), "3123456789")


def prueba_linea_origen_vacia():
    """Si la línea está en blanco, devuelve texto vacío"""
    igual(extraer_linea_origen(VACIA), "")


def prueba_tipo_sin_espacios():
    """El tipo no tiene espacios sobrantes"""
    igual(extraer_tipo(VOZ), "VOZ")
    igual(extraer_tipo(DATOS), "DATOS")
    igual(extraer_tipo(VACIA), "SMS")


def prueba_fecha():
    """La fecha queda como AAAA-MM-DD HH:MM:SS"""
    igual(extraer_fecha(VOZ), "2026-09-13 10:31:28")
    igual(extraer_fecha(VACIA), "2026-09-30 23:59:59")


def prueba_duracion():
    """La duración es un int"""
    igual(extraer_duracion(VOZ), 30)
    igual(extraer_duracion(DATOS), 1856)


def prueba_duracion_negativa():
    """-00045 se lee como -45"""
    igual(extraer_duracion(NEGATIVA), -45)


def prueba_mb():
    """Las megas son float"""
    cerca(extraer_mb(DATOS), 26.274)
    cerca(extraer_mb(VOZ), 0.0)
    assert isinstance(extraer_mb(DATOS), float), "extraer_mb debe devolver float"
```

## Pista 1

Para el campo que va de la posición **a** a la **b** del documento, el slicing es `registro[a - 1:b]`. Por ejemplo, el `cdr_id` (1–12) es `registro[0:12]` y la duración (68–73) es `registro[67:73]`.

`int()` y `float()` aceptan ceros a la izquierda y el signo menos: `int("-00045")` da `-45`.

## Pista 2

Para la fecha, corta primero los 14 caracteres y luego arma el texto con más slicing:

```python
f = registro[53:67]          # "20260913103128"
return f"{f[0:4]}-{f[4:6]}-{f[6:8]} {f[8:10]}:{f[10:12]}:{f[12:14]}"
```

Para quitar los espacios de relleno usa `.strip()`.

## Solución

```python
REGISTRO = "0000000000023267999245             DATOS             20260914085504001856000026.274CEL59973"


def extraer_cdr_id(registro):
    return int(registro[0:12])


def extraer_linea_origen(registro):
    return registro[12:22].strip()


def extraer_tipo(registro):
    return registro[35:40].strip()


def extraer_fecha(registro):
    f = registro[53:67]
    return f"{f[0:4]}-{f[4:6]}-{f[6:8]} {f[8:10]}:{f[10:12]}:{f[12:14]}"


def extraer_duracion(registro):
    return int(registro[67:73])


def extraer_mb(registro):
    return float(registro[73:83])


print(extraer_cdr_id(REGISTRO), extraer_tipo(REGISTRO), extraer_fecha(REGISTRO))
```

## Explicación

Cada función es una línea, y todas siguen la misma receta: **cortar → limpiar → convertir**. Es la receta de cualquier lector de archivos de ancho fijo.

El detalle más delicado son los índices. Un error de una posición (el famoso *off-by-one*) no da error: simplemente lee un carácter de más o de menos y produce datos basura silenciosamente. Por eso las pruebas usan registros reales con valores conocidos.

En el módulo 4 guardarás estas posiciones en un diccionario (el "diseño del registro") y una sola función leerá todos los campos. En el módulo 6 leerás el archivo completo, línea por línea.
