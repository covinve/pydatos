## Enunciado

Crea la clase `LoteCDR`, un contenedor **inmutable** de objetos `CDR` (la dataclass ya está en el código inicial) que se comporte como las colecciones de Python:

| Operación | Comportamiento |
|---|---|
| `LoteCDR(cdrs)` | Recibe cualquier iterable de CDR. Si hay `cdr_id` repetidos, conserva el primero |
| `len(lote)` | Cantidad de CDR |
| `for c in lote` | Recorre en orden |
| `lote[0]` | Un CDR |
| `lote[1:3]` | Un **nuevo** `LoteCDR` (no una lista) |
| `5 in lote` | `True` si hay un CDR con `cdr_id == 5` (búsqueda instantánea) |
| `lote_a + lote_b` | Un nuevo `LoteCDR` con los de ambos, sin repetidos |
| `lote.filtrar(condicion)` | Un nuevo `LoteCDR` con los que cumplen la función `condicion(cdr)` |
| `lote.por_tipo()` | Diccionario `tipo → cantidad`, ordenado por tipo |
| `lote.minutos_por_linea()` | Diccionario `linea → minutos facturables` (solo `VOZ`) |
| `repr(lote)` | `LoteCDR(3 registros)` |

```python
lote = LoteCDR([CDR(1, "3001", "VOZ", 125), CDR(2, "3002", "SMS", 0), CDR(1, "3001", "VOZ", 125)])
len(lote)                                    # 2
lote.filtrar(lambda c: c.tipo == "VOZ")      # LoteCDR(1 registros)
```

## Código inicial

```python
from collections import Counter
from dataclasses import dataclass


@dataclass(frozen=True)
class CDR:
    cdr_id: int
    linea_origen: str
    tipo: str
    duracion_seg: int


class LoteCDR:
    pass


lote = LoteCDR([CDR(1, "3001", "VOZ", 125), CDR(2, "3002", "SMS", 0), CDR(1, "3001", "VOZ", 125)])
print(lote, len(lote))
```

## Pista 2

`__getitem__` recibe un entero o un objeto `slice`. Distingue los casos:

```python
def __getitem__(self, posicion):
    if isinstance(posicion, slice):
        return LoteCDR(self._cdrs[posicion])
    return self._cdrs[posicion]
```

Para `__add__`: `LoteCDR([*self, *otro])` reutiliza la lógica de duplicados del constructor.

## Solución

```python
from collections import Counter
from dataclasses import dataclass


@dataclass(frozen=True)
class CDR:
    cdr_id: int
    linea_origen: str
    tipo: str
    duracion_seg: int


class LoteCDR:
    def __init__(self, cdrs=()):
        unicos = []
        ids = set()
        for cdr in cdrs:
            if cdr.cdr_id not in ids:
                ids.add(cdr.cdr_id)
                unicos.append(cdr)
        self._cdrs = tuple(unicos)
        self._ids = frozenset(ids)

    def __len__(self):
        return len(self._cdrs)

    def __iter__(self):
        return iter(self._cdrs)

    def __getitem__(self, posicion):
        if isinstance(posicion, slice):
            return LoteCDR(self._cdrs[posicion])
        return self._cdrs[posicion]

    def __contains__(self, cdr_id):
        return cdr_id in self._ids

    def __add__(self, otro):
        if not isinstance(otro, LoteCDR):
            return NotImplemented
        return LoteCDR([*self, *otro])

    def __repr__(self):
        return f"LoteCDR({len(self)} registros)"

    def filtrar(self, condicion):
        return LoteCDR(c for c in self if condicion(c))

    def por_tipo(self):
        return dict(sorted(Counter(c.tipo for c in self).items()))

    def minutos_por_linea(self):
        minutos = {}
        for c in self.filtrar(lambda c: c.tipo == "VOZ"):
            minutos[c.linea_origen] = minutos.get(c.linea_origen, 0) + (c.duracion_seg + 59) // 60
        return minutos


lote = LoteCDR([CDR(1, "3001", "VOZ", 125), CDR(2, "3002", "SMS", 0), CDR(1, "3001", "VOZ", 125)])
print(lote, len(lote))
```

## Explicación

Con seis métodos especiales, `LoteCDR` funciona con `len`, `for`, `[]`, `in` y `+` como cualquier colección de Python. Quien lo usa no necesita aprender una interfaz nueva.

Decisiones de diseño:

- **Inmutable**: `_cdrs` es una tupla y todas las operaciones devuelven lotes nuevos. Nadie puede alterar un lote que otra parte del programa está usando.
- **`__contains__` con un conjunto**: la prueba de 100.000 registros fallaría si `in` recorriera la tupla (el patrón lista vs. diccionario del módulo 4).
- **`NotImplemented` en `__add__`**: si alguien suma un lote con una lista, Python da un `TypeError` claro en lugar de un resultado raro.

Así funcionan por dentro muchas librerías: un `DataFrame` de Pandas también implementa `__len__`, `__getitem__`, `__iter__` y compañía.
