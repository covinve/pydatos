titulo: Bases de datos
icono: 🗄️
resumen: SQL de verdad contra bases de datos. SQLite desde Python, consultas parametrizadas, diseño de tablas con claves e índices, transacciones, SQLAlchemy, PostgreSQL y carga masiva de millones de CDR.
objetivos:
  - Conectarte a **SQLite** con `sqlite3` y ejecutar consultas **parametrizadas** (y entender la inyección SQL).
  - Diseñar tablas con **claves primarias, foráneas, restricciones e índices**.
  - Usar **transacciones** para que una operación se haga completa o no se haga.
  - Pasar datos entre Pandas y una base de datos con `to_sql` y `read_sql`.
  - Trabajar con **SQLAlchemy** (Core y ORM) para escribir código que sirva igual en SQLite y PostgreSQL.
  - Cargar **millones de registros** rápido: lotes, `executemany`, *upsert* y `COPY`.
