## Enunciado

Cada campaña comercial tiene su propio esquema de tarifas y descuentos. Escribe `crear_tarificador(tarifas, *, descuento_nocturno=0.0, sin_descuento=("INTERNACIONAL",))` que devuelva **dos funciones** (una tupla):

1. `tarificar(destino, hora, segundos)` → el valor de la llamada:
   - minutos facturables (redondeo hacia arriba) × tarifa del destino;
   - si la hora está en la franja nocturna (22:00 a 05:59) y el destino **no** está en `sin_descuento`, se aplica `descuento_nocturno` (0.5 = 50 %);
   - el resultado se redondea al peso con la regla comercial;
   - si el destino no existe en las tarifas, devuelve `None` y **no** suma nada.
2. `total()` → la suma de todos los valores calculados **por ese tarificador** hasta el momento.

Cada tarificador lleva su propio total: crear uno nuevo no afecta a los demás.

```python
tarificar, total = crear_tarificador({"LOCAL": 100, "INTERNACIONAL": 950}, descuento_nocturno=0.5)
tarificar("LOCAL", 23, 125)          # 150   → 3 min × 100 × 0.5
tarificar("INTERNACIONAL", 23, 30)   # 950   → sin descuento
tarificar("SATELITAL", 10, 60)       # None
total()                              # 1100
```

## Pista 1

Dentro de `crear_tarificador` define las dos funciones y devuélvelas como tupla: `return tarificar, total`. Para que `tarificar` pueda **modificar** el acumulado que vive en `crear_tarificador`, declara la variable con `nonlocal`:

```python
def crear_tarificador(tarifas, *, descuento_nocturno=0.0, sin_descuento=("INTERNACIONAL",)):
    acumulado = 0

    def tarificar(destino, hora, segundos):
        nonlocal acumulado
        ...

    def total():
        return acumulado

    return tarificar, total
```

## Solución

```python
from decimal import Decimal, ROUND_HALF_UP


def crear_tarificador(tarifas, *, descuento_nocturno=0.0, sin_descuento=("INTERNACIONAL",)):
    acumulado = 0
    descuento = Decimal(str(descuento_nocturno))

    def tarificar(destino, hora, segundos):
        nonlocal acumulado
        tarifa = tarifas.get(destino)
        if tarifa is None:
            return None
        minutos = (segundos + 59) // 60
        nocturna = hora >= 22 or hora < 6
        factor = 1 - descuento if nocturna and destino not in sin_descuento else Decimal(1)
        valor = int((minutos * tarifa * factor).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
        acumulado += valor
        return valor

    def total():
        return acumulado

    return tarificar, total


tarificar, total = crear_tarificador({"LOCAL": 100, "INTERNACIONAL": 950}, descuento_nocturno=0.5)
print(tarificar("LOCAL", 23, 125))
print(total())
```

## Explicación

`tarificar` y `total` son **closures** que comparten la variable `acumulado` del `crear_tarificador` que las creó. Cada llamada a `crear_tarificador` crea un `acumulado` nuevo, por eso los tarificadores son independientes.

`nonlocal acumulado` es necesario porque `tarificar` **asigna** a la variable (`+=`). Sin `nonlocal`, Python crearía una variable local nueva y daría `UnboundLocalError`. `total` solo la **lee**, así que no lo necesita.

¿Es esto una función pura? `tarificar` no: guarda estado. Es una herramienta útil cuando necesitas configuración + memoria juntas. En el módulo 9 verás que una **clase** es la forma más común de expresar lo mismo, y comparar ambas versiones te ayudará a entender las dos.
