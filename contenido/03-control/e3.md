## Enunciado

Escribe el corazón de un validador de CDR. Primero, una función auxiliar:

**`fecha_valida(texto)`** → `True` si el texto tiene exactamente el formato `AAAA-MM-DD HH:MM:SS` y representa una fecha y hora reales:

- 19 caracteres, con `-` en las posiciones 4 y 7, un espacio en la 10 y `:` en la 13 y 16 (contando desde 0).
- Año, mes, día, hora, minuto y segundo deben ser dígitos.
- Mes de 1 a 12; hora de 0 a 23; minutos y segundos de 0 a 59.
- El día debe existir en ese mes: abril, junio, septiembre y noviembre tienen 30 días; febrero 28 (ignora los años bisiestos); los demás, 31.

Luego, **`clasificar_cdr(linea_origen, tipo, duracion_seg, fecha_inicio)`** → devuelve el **primer** problema encontrado, revisando en este orden:

| Orden | Devuelve | Si… |
|---|---|---|
| 1 | `"linea_vacia"` | `linea_origen` está vacía o solo tiene espacios |
| 2 | `"tipo_desconocido"` | `tipo` no es `VOZ`, `SMS` ni `DATOS` |
| 3 | `"duracion_negativa"` | `duracion_seg` es menor que 0 |
| 4 | `"fecha_invalida"` | `fecha_valida(fecha_inicio)` es falso |
| — | `"valido"` | no hay ningún problema |

```python
fecha_valida("2026-09-13 10:31:28")   # True
fecha_valida("2026-09-31 10:15:00")   # False: septiembre tiene 30 días
fecha_valida("2026-09-15 25:10:00")   # False: hora 25
clasificar_cdr("3001234567", "VOZ", 125, "2026-09-13 10:31:28")   # "valido"
clasificar_cdr("", "VOX", -5, "malo")                              # "linea_vacia"
```

## Pista 1

Para `fecha_valida`, revisa la forma antes de convertir nada. Si la longitud no es 19 o los separadores no están en su lugar, devuelve `False` de inmediato:

```python
if len(texto) != 19:
    return False
if texto[4] != "-" or texto[7] != "-" or texto[10] != " " or texto[13] != ":" or texto[16] != ":":
    return False
```

Luego corta cada parte con slicing y comprueba con `.isdigit()` antes de usar `int()`.

## Pista 2

Para los días por mes:

```python
if mes in (4, 6, 9, 11):
    dias_del_mes = 30
elif mes == 2:
    dias_del_mes = 28
else:
    dias_del_mes = 31
```

En `clasificar_cdr`, cada regla es un `if` con `return`, en el orden de la tabla. Si ninguno se cumple, al final `return "valido"`.

## Solución

```python
TIPOS_VALIDOS = ("VOZ", "SMS", "DATOS")


def dias_del_mes(mes):
    if mes in (4, 6, 9, 11):
        return 30
    if mes == 2:
        return 28
    return 31


def fecha_valida(texto):
    if len(texto) != 19:
        return False
    if texto[4] != "-" or texto[7] != "-" or texto[10] != " " or texto[13] != ":" or texto[16] != ":":
        return False
    partes = [texto[0:4], texto[5:7], texto[8:10], texto[11:13], texto[14:16], texto[17:19]]
    for parte in partes:
        if not parte.isdigit():
            return False
    anio, mes, dia, hora, minuto, segundo = [int(p) for p in partes]
    if not 1 <= mes <= 12:
        return False
    if not 1 <= dia <= dias_del_mes(mes):
        return False
    return hora <= 23 and minuto <= 59 and segundo <= 59


def clasificar_cdr(linea_origen, tipo, duracion_seg, fecha_inicio):
    if not linea_origen.strip():
        return "linea_vacia"
    if tipo not in TIPOS_VALIDOS:
        return "tipo_desconocido"
    if duracion_seg < 0:
        return "duracion_negativa"
    if not fecha_valida(fecha_inicio):
        return "fecha_invalida"
    return "valido"


print(fecha_valida("2026-09-31 10:15:00"))
print(clasificar_cdr("3001234567", "VOZ", 125, "2026-09-13 10:31:28"))
```

## Explicación

`fecha_valida` es una **cascada de salidas tempranas**: cada comprobación descarta un tipo de error, de la más barata (la longitud) a la más elaborada (días del mes). Así nunca se llama `int()` sobre algo que no son dígitos.

Dos detalles:

- `anio, mes, dia, hora, minuto, segundo = [...]` **desempaqueta** una lista en seis variables. Lo verás en el módulo 4.
- No hace falta comprobar que la hora sea mayor o igual a 0: si pasó `.isdigit()`, no puede tener signo negativo.

¿Hay una forma más corta? Sí: el módulo `datetime` (módulo 6) valida fechas con `datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")`, que además conoce los años bisiestos. Pero escribirlo una vez a mano te enseña exactamente qué significa "validar".
