Ya escribes funciones desde el módulo 1. Ahora vas a diseñarlas para que sean **fáciles de usar bien y difíciles de usar mal**.

## Argumentos posicionales y por nombre

```pyrun
def valor_llamada(segundos, tarifa_minuto, descuento=0.0):
    minutos = (segundos + 59) // 60
    return round(minutos * tarifa_minuto * (1 - descuento))


print(valor_llamada(125, 120))                    # posicionales
print(valor_llamada(125, 120, 0.5))               # el tercero también posicional
print(valor_llamada(segundos=125, tarifa_minuto=120, descuento=0.5))   # por nombre
print(valor_llamada(125, tarifa_minuto=120))      # mezcla: primero posicionales
```

Pasar argumentos **por nombre** hace que la llamada se lea sola. Compara `valor_llamada(125, 120, 0.5)` con `valor_llamada(125, 120, descuento=0.5)`: la segunda no necesita que recuerdes el orden.

## Valores por defecto

`descuento=0.0` hace que el parámetro sea **opcional**. Los parámetros con valor por defecto van **después** de los obligatorios.

:::error La trampa del valor por defecto mutable
El valor por defecto se crea **una sola vez**, cuando se define la función, no cada vez que se llama. Si es una lista o un diccionario, todas las llamadas comparten el mismo objeto:

```pyrun
def registrar_error(error, errores=[]):
    errores.append(error)
    return errores


print(registrar_error("duplicado"))
print(registrar_error("fecha_invalida"))   # ¡arrastra el error anterior!
```

La solución estándar es usar `None` como valor por defecto y crear la lista adentro:

```pyrun
def registrar_error(error, errores=None):
    if errores is None:
        errores = []
    errores.append(error)
    return errores


print(registrar_error("duplicado"))
print(registrar_error("fecha_invalida"))
```
:::

:::reto Desactiva la trampa
Esta función agrega una línea a un lote de suspensión. Tiene la trampa del valor por defecto mutable: cada lote nuevo arrastra las líneas de los anteriores. Corrígela.

```pyreto
def agregar_a_lote(linea, lote=[]):
    lote.append(linea)
    return lote


print(agregar_a_lote("3001234567"))   # ['3001234567']
print(agregar_a_lote("3109876543"))   # debería ser ['3109876543']
```

:::pista
Cambia el valor por defecto a `None` y, dentro de la función, crea la lista solo si no te pasaron una: `if lote is None: lote = []`.
:::

```pyprueba
def prueba_lotes_independientes():
    """Cada llamada sin lote empieza con un lote vacío"""
    requiere("agregar_a_lote")
    igual(agregar_a_lote("A"), ["A"])
    igual(agregar_a_lote("B"), ["B"])


def prueba_lote_existente():
    """Si le pasas un lote, agrega a ese mismo lote"""
    lote = ["X"]
    agregar_a_lote("Y", lote)
    igual(lote, ["X", "Y"])
```

```pysolucion
def agregar_a_lote(linea, lote=None):
    if lote is None:
        lote = []
    lote.append(linea)
    return lote


print(agregar_a_lote("3001234567"))   # ['3001234567']
print(agregar_a_lote("3109876543"))   # debería ser ['3109876543']
```
:::

## Parámetros de solo-nombre: `*`

Todo lo que va después de un `*` en la definición **debe** pasarse por nombre. Úsalo para opciones que serían confusas como posicionales:

```pyrun
def formatear(valor, *, decimales=0, moneda="$"):
    return f"{moneda}{valor:,.{decimales}f}"


print(formatear(1234.5, decimales=2))
print(formatear(1234.5, moneda="USD "))
print(formatear(1234.5, 2))   # error esperado
```

`formatear(1234.5, 2)` falla a propósito: nadie que lea esa línea sabría qué significa el `2`.

:::reto Opciones que se leen solas
Escribe `con_iva(subtotal, *, tasa=0.19, redondear=True)`:

- devuelve `subtotal × (1 + tasa)`;
- si `redondear` es `True`, lo devuelve redondeado a entero con `round`;
- `tasa` y `redondear` **solo** se pueden pasar por nombre.

```pyreto
def con_iva(subtotal):
    pass


print(con_iva(100))                     # 119
print(con_iva(100, tasa=0.05))          # 105
print(con_iva(150, redondear=False))    # 178.5
```

:::pista
El `*` va justo después de `subtotal`: `def con_iva(subtotal, *, tasa=0.19, redondear=True):`. Calcula el total y, si `redondear`, devuelve `round(total)`.
:::

```pyprueba
def prueba_valores():
    """Calcula el IVA con la tasa por defecto o la que le pasen"""
    requiere("con_iva")
    igual(con_iva(100), 119)
    igual(con_iva(100, tasa=0.05), 105)


def prueba_sin_redondear():
    """redondear=False devuelve el valor exacto"""
    cerca(con_iva(150, redondear=False), 178.5)


def prueba_solo_nombre():
    """tasa no se puede pasar como posicional"""
    lanza(TypeError, con_iva, 100, 0.05)
```

```pysolucion
def con_iva(subtotal, *, tasa=0.19, redondear=True):
    total = subtotal * (1 + tasa)
    if redondear:
        return round(total)
    return total


print(con_iva(100))                     # 119
print(con_iva(100, tasa=0.05))          # 105
print(con_iva(150, redondear=False))    # 178.5
```
:::

## *args: cantidad variable de argumentos

```pyrun
def total_minutos(*duraciones):
    return sum((d + 59) // 60 for d in duraciones)


print(total_minutos(125))
print(total_minutos(125, 61, 3600))

llamadas = [125, 0, 61]
print(total_minutos(*llamadas))   # * "desempaqueta" la lista en argumentos
```

:::reto El mayor de varios cargos
Escribe `cargo_mayor(*cargos)` que reciba **cualquier cantidad** de cargos y devuelva el mayor. Si no recibe ninguno, devuelve `0`.

```pyreto
def cargo_mayor():
    pass


print(cargo_mayor(35900, 5040, 1200))   # 35900
print(cargo_mayor())                    # 0

cargos_factura = [19900, 62900, 3000]
print(cargo_mayor(*cargos_factura))     # 62900
```

:::pista
Dentro de la función, `cargos` es una tupla. Si está vacía (`if not cargos:`) devuelve 0; si no, `max(cargos)`.
:::

```pyprueba
def prueba_varios():
    """Devuelve el mayor de los cargos recibidos"""
    requiere("cargo_mayor")
    igual(cargo_mayor(35900, 5040, 1200), 35900)
    igual(cargo_mayor(7), 7)
    igual(cargo_mayor(*[19900, 62900, 3000]), 62900)


def prueba_ninguno():
    """Sin cargos devuelve 0"""
    igual(cargo_mayor(), 0)
```

```pysolucion
def cargo_mayor(*cargos):
    if not cargos:
        return 0
    return max(cargos)


print(cargo_mayor(35900, 5040, 1200))   # 35900
print(cargo_mayor())                    # 0

cargos_factura = [19900, 62900, 3000]
print(cargo_mayor(*cargos_factura))     # 62900
```
:::

## **kwargs: argumentos por nombre variables

```pyrun
def crear_cdr(cdr_id, tipo, **campos):
    registro = {"cdr_id": cdr_id, "tipo": tipo}
    registro.update(campos)
    return registro


print(crear_cdr(1, "VOZ", duracion_seg=125, destino="LOCAL"))

plan = {"plan_id": "HOG30", "cargo_fijo": 35900}
print(crear_cdr(2, "DATOS", **plan))   # ** desempaqueta un diccionario
```

:::reto Cambios de plan
Escribe `actualizar_plan(plan, **cambios)` que devuelva un diccionario **nuevo** con el plan y los cambios aplicados. El plan original no se toca.

```pyreto
def actualizar_plan(plan):
    pass


hog30 = {"plan_id": "HOG30", "cargo_fijo": 35900, "minutos": 300}
nuevo = actualizar_plan(hog30, cargo_fijo=37900, minutos=400)
print(nuevo)   # {'plan_id': 'HOG30', 'cargo_fijo': 37900, 'minutos': 400}
print(hog30)   # sin cambios
```

:::pista
`cambios` llega como diccionario. Copia el plan con `nuevo = plan.copy()` (o `dict(plan)`) y aplica los cambios con `nuevo.update(cambios)`.
:::

```pyprueba
def prueba_aplica_cambios():
    """Aplica los cambios recibidos por nombre"""
    requiere("actualizar_plan")
    plan = {"plan_id": "HOG30", "cargo_fijo": 35900, "minutos": 300}
    igual(actualizar_plan(plan, cargo_fijo=37900, minutos=400), {"plan_id": "HOG30", "cargo_fijo": 37900, "minutos": 400})
    igual(actualizar_plan(plan, nuevo_campo=1)["nuevo_campo"], 1)


def prueba_sin_cambios():
    """Sin cambios, devuelve una copia igual"""
    plan = {"plan_id": "ILIM"}
    igual(actualizar_plan(plan), {"plan_id": "ILIM"})


def prueba_no_modifica():
    """El plan original no cambia"""
    plan = {"plan_id": "HOG30", "cargo_fijo": 35900}
    actualizar_plan(plan, cargo_fijo=1)
    igual(plan, {"plan_id": "HOG30", "cargo_fijo": 35900}, "El plan original fue modificado")
```

```pysolucion
def actualizar_plan(plan, **cambios):
    nuevo = plan.copy()
    nuevo.update(cambios)
    return nuevo


hog30 = {"plan_id": "HOG30", "cargo_fijo": 35900, "minutos": 300}
nuevo = actualizar_plan(hog30, cargo_fijo=37900, minutos=400)
print(nuevo)   # {'plan_id': 'HOG30', 'cargo_fijo': 37900, 'minutos': 400}
print(hog30)   # sin cambios
```
:::

:::consejo Úsalos con moderación
`*args` y `**kwargs` son potentes pero esconden qué acepta la función. Prefiere parámetros con nombre explícito; reserva `*args`/`**kwargs` para funciones que realmente aceptan "cualquier cantidad" o que reenvían argumentos a otra función.
:::

## El orden completo

```python
def f(posicional_solo, /, normal, *args, solo_nombre, **kwargs):
    ...
```

Rara vez necesitarás todo junto. Lo importante: **obligatorios → con valor por defecto → `*` → solo-nombre**.

:::telco Funciones que se usan en toda la empresa
Si escribes la función que calcula el IVA y la usan diez procesos distintos, cada parámetro mal diseñado se convierte en diez lugares donde alguien puede equivocarse. Un `*, redondeo="comercial"` obligatorio por nombre es mucho más seguro que un `True` posicional que nadie recuerda qué significa.
:::

## Cuestionario

? ¿Qué imprime la segunda llamada? `def f(x, lista=[]): lista.append(x); return lista` — `f(1)`, luego `print(f(2))`
- [ ] `[2]`
- [x] `[1, 2]`
- [ ] `[1]`
- [ ] Un error
> La lista por defecto se crea una sola vez y se comparte entre llamadas. Por eso se usa `None` como valor por defecto.

? Con `def formatear(valor, *, decimales=0)`, ¿cuál llamada es válida?
- [ ] `formatear(10, 2)`
- [x] `formatear(10, decimales=2)`
- [ ] `formatear(decimales=2)`
- [ ] `formatear(10, *2)`
> Después del `*`, los parámetros solo se pueden pasar por nombre. `valor` sigue siendo obligatorio.

? ¿Qué recibe `args` en `def f(*args)` si llamas `f(1, 2, 3)`?
- [ ] `[1, 2, 3]`
- [x] `(1, 2, 3)`
- [ ] `{1, 2, 3}`
- [ ] `1`
> `*args` agrupa los argumentos posicionales en una tupla.
