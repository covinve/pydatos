## Enunciado

Con los CDR de fecha válida, analiza el tráfico en el tiempo:

1. `serie_diaria(cdr)` → DataFrame indexado por día (`DatetimeIndex`, frecuencia diaria, del primer al último día **sin huecos**) con columnas `registros`, `minutos_voz` (VOZ con duración ≥ 0) y `mb` (redondeado a 1 decimal). Usa `resample`.
2. `alertas_de_carga(serie, umbral=0.7)` → lista de fechas (texto `AAAA-MM-DD`) en que `registros` cayó por debajo de `umbral ×` el promedio móvil de los **7 días anteriores** (sin incluir el día actual). Los primeros 7 días no se evalúan.

## Pista 2

El promedio de los 7 días **anteriores** es `serie["registros"].rolling(7).mean().shift(1)`: `shift(1)` desplaza el resultado un día, así el día actual no se incluye en su propia referencia. Compara y convierte el índice de las fechas alertadas con `.strftime("%Y-%m-%d")`.

## Solución

```python
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr_incompleto.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)


def serie_diaria(cdr):
    d = cdr.assign(inicio=pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce"))
    d = d.dropna(subset=["inicio"])
    es_voz = (d["tipo"] == "VOZ") & (d["duracion_seg"] >= 0)
    d["minutos_voz"] = np.where(es_voz, (d["duracion_seg"] + 59) // 60, 0)
    d["mb_datos"] = np.where(d["tipo"] == "DATOS", d["mb"], 0.0)
    serie = d.set_index("inicio").resample("D").agg(
        registros=("cdr_id", "size"),
        minutos_voz=("minutos_voz", "sum"),
        mb=("mb_datos", "sum"),
    )
    serie["mb"] = serie["mb"].round(1)
    return serie


def alertas_de_carga(serie, umbral=0.7):
    referencia = serie["registros"].rolling(7).mean().shift(1)
    alertas = serie.index[(serie["registros"] < umbral * referencia).to_numpy()]
    return alertas.strftime("%Y-%m-%d").tolist()


s = serie_diaria(cdr)
print(s.head())
print(alertas_de_carga(s))
```

## Explicación

Este es un **control de completitud**: antes de facturar, verificar que cada día tenga un volumen razonable. Un archivo faltante de una central no da ningún error: simplemente "desaparece" consumo, y la facturación sale más baja sin que nadie lo note.

El `shift(1)` es el detalle clave: si el día 20 entrara en su propio promedio, el promedio bajaría y la alerta sería menos sensible. La referencia debe construirse solo con información **anterior** al día evaluado, la misma idea que evita "hacer trampa" al validar modelos predictivos (módulo 23).
