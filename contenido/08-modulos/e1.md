## Enunciado

Completa las funciones usando **la biblioteca estándar**, sin reimplementar lo que ya existe. Escribe los imports al inicio del archivo, uno por línea, y **sin** `import *`.

1. `megas_facturables(mb)` → redondea hacia arriba con `math.ceil`.
2. `tipo_mas_frecuente(tipos)` → el tipo que más se repite, usando `Counter` de `collections`.
3. `mediana_duracion(duraciones)` → la mediana, usando `median` de `statistics`.
4. `nombre_archivo(ruta)` → solo el nombre del archivo de una ruta (`"datos/10MB/cdr.csv"` → `"cdr.csv"`), usando `Path` de `pathlib`.

```python
megas_facturables(15.131)                        # 16
tipo_mas_frecuente(["VOZ", "DATOS", "DATOS"])    # "DATOS"
mediana_duracion([125, 0, 61, 3600])             # 93.0
nombre_archivo("datos/10MB/cdr.csv")             # "cdr.csv"
```

## Pruebas

```python
import ast

ARBOL = ast.parse(codigo)


def prueba_resultados():
    """Las cuatro funciones dan el resultado esperado"""
    requiere("megas_facturables", "tipo_mas_frecuente", "mediana_duracion", "nombre_archivo")
    igual(megas_facturables(15.131), 16)
    igual(tipo_mas_frecuente(["VOZ", "DATOS", "DATOS", "SMS"]), "DATOS")
    igual(mediana_duracion([125, 0, 61, 3600]), 93.0)
    igual(nombre_archivo("datos/10MB/cdr.csv"), "cdr.csv")


def prueba_sin_import_asterisco():
    """No usa import *"""
    for nodo in ast.walk(ARBOL):
        if isinstance(nodo, ast.ImportFrom):
            assert all(alias.name != "*" for alias in nodo.names), "No uses `from ... import *`"


def prueba_usa_la_biblioteca_estandar():
    """Importa math, Counter, median y Path"""
    importados = set()
    for nodo in ast.walk(ARBOL):
        if isinstance(nodo, ast.Import):
            importados |= {a.name for a in nodo.names}
        elif isinstance(nodo, ast.ImportFrom):
            importados |= {f"{nodo.module}.{a.name}" for a in nodo.names}
    for esperado in ("math", "collections.Counter", "statistics.median", "pathlib.Path"):
        assert esperado in importados, f"Falta importar {esperado}"


def prueba_imports_al_inicio():
    """Los imports están al inicio, antes de las funciones"""
    vistos_def = False
    for nodo in ARBOL.body:
        if isinstance(nodo, ast.FunctionDef):
            vistos_def = True
        if isinstance(nodo, (ast.Import, ast.ImportFrom)):
            assert not vistos_def, "Pon todos los imports al inicio del archivo"
```

## Pista 2

- `Counter(tipos).most_common(1)` devuelve una lista con una tupla `(tipo, cantidad)`.
- `Path(ruta).name` devuelve el nombre del archivo.
- `median` devuelve `93.0` para una lista de cantidad par (promedia los dos del medio).

## Solución

```python
import math
from collections import Counter
from pathlib import Path
from statistics import median


def megas_facturables(mb):
    return math.ceil(mb)


def tipo_mas_frecuente(tipos):
    return Counter(tipos).most_common(1)[0][0]


def mediana_duracion(duraciones):
    return median(duraciones)


def nombre_archivo(ruta):
    return Path(ruta).name
```

## Explicación

Cada función es una línea porque la biblioteca estándar ya resolvió el problema. Antes de escribir un algoritmo, pregúntate: "¿esto no existirá ya?".

Fíjate en los dos estilos de import: `import math` deja el prefijo (`math.ceil`), útil para funciones con nombres genéricos; `from pathlib import Path` trae el nombre directo, natural para clases muy conocidas. Ordenarlos alfabéticamente dentro del grupo de la biblioteca estándar es lo que hace `ruff check --select I --fix`.
