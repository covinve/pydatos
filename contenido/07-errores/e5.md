## Pista 1

Los tres errores están en tres funciones distintas: `minutos`, `tarifa` y `valor_por_linea`. Ninguno lanza excepciones: todos producen números "razonables" pero equivocados.

Prueba en la Debug Console qué devuelve `minutos(0)` y `minutos(60)`, y compáralo con la regla de negocio.

## Pista 2

- `minutos`: la fórmula correcta de redondeo hacia arriba es `(segundos + 59) // 60`.
- `tarifa`: ¿qué devuelve `"LOCAL".title()`? ¿Coincide con las claves de `TARIFAS`? Y peor: `get(..., 0)` esconde el problema devolviendo tarifa cero.
- `valor_por_linea`: mira la definición de la función. ¿Recuerdas la trampa del valor por defecto mutable del módulo 5?

## Solución

```python tarificador.py
"""Tarificador de llamadas heredado de otro equipo (corregido).

Uso:
    python ejercicios/m07-e5/tarificador.py
"""

from pathlib import Path

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def leer_registro(linea):
    campos = linea.strip().split("|")
    return {
        "linea": campos[1],
        "tipo": campos[3],
        "destino": campos[4],
        "duracion": int(campos[6]),
    }


def minutos(segundos):
    """Minutos facturables: se cobra cada minuto iniciado."""
    return (segundos + 59) // 60


def tarifa(destino, tarifas):
    return tarifas[destino.strip().upper()]


def valor_por_linea(lineas_archivo, tarifas, acumulado=None):
    """Suma el valor de las llamadas de voz de cada línea. Recibe las líneas del archivo con encabezado."""
    if acumulado is None:
        acumulado = {}
    for texto in lineas_archivo[1:]:
        registro = leer_registro(texto)
        if registro["tipo"] == "VOZ":
            valor = minutos(registro["duracion"]) * tarifa(registro["destino"], tarifas)
            acumulado[registro["linea"]] = acumulado.get(registro["linea"], 0) + valor
    return acumulado


if __name__ == "__main__":
    ruta = Path(__file__).parent / "llamadas.csv"
    lineas = ruta.read_text(encoding="utf-8").splitlines()
    print(valor_por_linea(lineas, TARIFAS))

# Diagnóstico:
# 1. minutos(): con el depurador vi que la llamada de 60 s daba 2 minutos y la de 0 s daba 1.
#    "+ 1" no es redondear hacia arriba; la fórmula correcta es (segundos + 59) // 60.
# 2. tarifa(): en la Debug Console, "LOCAL".title() devolvía "Local", que no está en TARIFAS,
#    y get(..., 0) lo convertía en tarifa cero sin avisar. Ahora un destino desconocido lanza KeyError.
# 3. valor_por_linea(): la segunda llamada duplicaba los valores. El acumulado={} por defecto
#    se comparte entre llamadas; se cambió a None.
```

## Explicación

Los tres errores son "silenciosos", los más peligrosos en facturación:

| Error | Síntoma | Por qué no se notaba |
|---|---|---|
| `segundos // 60 + 1` | 60 s se cobraban como 2 minutos y las llamadas no contestadas como 1 | 125 s daba 3 minutos, justo el valor correcto: el ejemplo típico "funcionaba" |
| `destino.title()` + `get(..., 0)` | Todas las tarifas en cero | `get` con valor por defecto ocultó la clave inexistente |
| `acumulado={}` | La segunda ejecución duplicaba los valores | Con una sola ejecución todo se veía bien |

Fíjate en la corrección de `tarifa`: en lugar de devolver 0 ante un destino desconocido, ahora **falla con `KeyError`**. Fallar ruidosamente es mejor que facturar cero en silencio. Un valor por defecto solo es aceptable cuando tiene sentido de negocio.

El depurador convierte "creo que el problema está en…" en "veo que esta variable vale…". Úsalo cada vez que un resultado no cuadre.
