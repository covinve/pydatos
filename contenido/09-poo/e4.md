## Enunciado

Crea la dataclass `Cliente` con los campos `cliente_id: str`, `nombre: str`, `linea: str`, `segmento: str`, `plan_id: str` y `fecha_alta: date`. En `__post_init__`:

1. **Normaliza**: quita espacios de `nombre`, `linea` y `plan_id`; pasa `segmento` y `plan_id` a mayúsculas.
2. **Convierte**: si `fecha_alta` llega como texto `"AAAA-MM-DD"`, conviértela a `date`.
3. **Valida** y lanza `ValueError` con un mensaje que nombre el campo si:
   - `linea` no tiene 10 dígitos o no empieza por 3 → mensaje que contenga `"linea"`;
   - `segmento` no es `RESIDENCIAL` ni `EMPRESARIAL` → mensaje que contenga `"segmento"`;
   - `fecha_alta` es posterior al 2026-09-30 → mensaje que contenga `"fecha_alta"`.

Agrega también:

- La propiedad `anios_antiguedad` → años completos entre `fecha_alta` y el 2026-09-30.
- El método `tiene_descuento()` → `True` si es `EMPRESARIAL` y tiene 3 años o más de antigüedad (alta **antes** del 2023-09-01).

```python
c = Cliente("CL1", " Lucía Gómez ", "3001234567", "empresarial", "emp100", "2020-05-10")
c.nombre, c.segmento, c.plan_id     # ("Lucía Gómez", "EMPRESARIAL", "EMP100")
c.fecha_alta                        # date(2020, 5, 10)
c.anios_antiguedad                  # 6
c.tiene_descuento()                 # True
```

## Pista 1

En `__post_init__` puedes reasignar los campos (la dataclass no es `frozen`):

```python
def __post_init__(self):
    self.nombre = self.nombre.strip()
    self.segmento = self.segmento.strip().upper()
    if isinstance(self.fecha_alta, str):
        self.fecha_alta = date.fromisoformat(self.fecha_alta)
    if not (len(self.linea) == 10 and self.linea.isdigit() and self.linea.startswith("3")):
        raise ValueError(f"linea inválida: {self.linea!r}")
```

## Pista 2

Años completos: resta los años y quita uno si todavía no se cumplió el "aniversario" en el año del corte:

```python
anios = FECHA_CORTE.year - self.fecha_alta.year
if (FECHA_CORTE.month, FECHA_CORTE.day) < (self.fecha_alta.month, self.fecha_alta.day):
    anios -= 1
```

Para el descuento, compara directamente fechas: `self.fecha_alta < date(2023, 9, 1)`.

## Solución

```python
from dataclasses import dataclass
from datetime import date

FECHA_CORTE = date(2026, 9, 30)
FECHA_DESCUENTO = date(2023, 9, 1)
SEGMENTOS = {"RESIDENCIAL", "EMPRESARIAL"}


@dataclass
class Cliente:
    cliente_id: str
    nombre: str
    linea: str
    segmento: str
    plan_id: str
    fecha_alta: date

    def __post_init__(self):
        self.nombre = self.nombre.strip()
        self.linea = self.linea.strip()
        self.segmento = self.segmento.strip().upper()
        self.plan_id = self.plan_id.strip().upper()
        if isinstance(self.fecha_alta, str):
            self.fecha_alta = date.fromisoformat(self.fecha_alta)
        if not (len(self.linea) == 10 and self.linea.isdigit() and self.linea.startswith("3")):
            raise ValueError(f"linea inválida: {self.linea!r}")
        if self.segmento not in SEGMENTOS:
            raise ValueError(f"segmento inválido: {self.segmento!r}")
        if self.fecha_alta > FECHA_CORTE:
            raise ValueError(f"fecha_alta posterior al corte: {self.fecha_alta}")

    @property
    def anios_antiguedad(self):
        anios = FECHA_CORTE.year - self.fecha_alta.year
        if (FECHA_CORTE.month, FECHA_CORTE.day) < (self.fecha_alta.month, self.fecha_alta.day):
            anios -= 1
        return anios

    def tiene_descuento(self):
        return self.segmento == "EMPRESARIAL" and self.fecha_alta < FECHA_DESCUENTO


c = Cliente("CL1", " Lucía Gómez ", "3001234567", "empresarial", "emp100", "2020-05-10")
print(c, c.anios_antiguedad, c.tiene_descuento())
```

## Explicación

`__post_init__` hace tres trabajos en orden: **normalizar**, **convertir** y **validar**. Al terminar, cualquier `Cliente` que exista en el programa está limpio y es válido: el resto del código puede confiar en él.

Comparar tuplas `(mes, día)` es un truco elegante para saber si ya pasó el aniversario: Python compara primero el mes y, si empatan, el día.

Fíjate en la diferencia entre `anios_antiguedad >= 3` y `fecha_alta < 2023-09-01`: no son equivalentes en todos los casos. La regla de negocio del curso dice "alta anterior al 2023-09-01", así que el código usa exactamente esa comparación. Implementar la regla **tal como está escrita** evita discusiones con auditoría.
