## Enunciado

Antes de facturar hay que **resumir** los CDR válidos de cada línea. Recibes una lista de CDR (diccionarios) y debes devolver un diccionario `linea → consumo`, aplicando las reglas del curso:

| Clave del consumo | Cómo se calcula |
|---|---|
| `minutos_nacionales` | Suma de `ceil(duración / 60)` de cada `VOZ` con destino `LOCAL` o `NACIONAL` |
| `minutos_internacionales` | Lo mismo para `VOZ` con destino `INTERNACIONAL` |
| `mb` | Suma de las `mb` de los `DATOS`, redondeada a 3 decimales |
| `sms` | Cantidad de `SMS` |

Cada línea que aparezca en los CDR debe tener **las cuatro claves**, aunque alguna valga 0.

```python
cdrs = [
    {"linea_origen": "3001", "tipo": "VOZ", "destino": "LOCAL", "duracion_seg": 125, "mb": 0.0},
    {"linea_origen": "3001", "tipo": "DATOS", "destino": "", "duracion_seg": 900, "mb": 15.131},
    {"linea_origen": "3002", "tipo": "SMS", "destino": "NACIONAL", "duracion_seg": 0, "mb": 0.0},
]
consumo_por_linea(cdrs)
# {"3001": {"minutos_nacionales": 3, "minutos_internacionales": 0, "mb": 15.131, "sms": 0},
#  "3002": {"minutos_nacionales": 0, "minutos_internacionales": 0, "mb": 0.0, "sms": 1}}
```

def cdr(linea, tipo, destino="", duracion=0, mb=0.0):
    return {"linea_origen": linea, "tipo": tipo, "destino": destino, "duracion_seg": duracion, "mb": mb}


CDRS = [

## Pista 1

Recorre los CDR y, la primera vez que veas una línea, créale su diccionario de consumo con las cuatro claves en cero:

```python
if linea not in resultado:
    resultado[linea] = {"minutos_nacionales": 0, "minutos_internacionales": 0, "mb": 0.0, "sms": 0}
```

Luego, según el `tipo` y el `destino`, suma en la clave correspondiente.

## Pista 2

Para no repetir el diccionario inicial, puedes usar `setdefault`, que crea la clave si no existe y devuelve su valor:

```python
consumo = resultado.setdefault(linea, {"minutos_nacionales": 0, ...})
```

Al final, recorre el resultado para redondear las megas: `consumo["mb"] = round(consumo["mb"], 3)`. El `0.1 + 0.2` de float te recordará por qué.

## Solución

```python
def consumo_vacio():
    return {"minutos_nacionales": 0, "minutos_internacionales": 0, "mb": 0.0, "sms": 0}


def consumo_por_linea(cdrs):
    resultado = {}
    for cdr in cdrs:
        consumo = resultado.setdefault(cdr["linea_origen"], consumo_vacio())
        tipo = cdr["tipo"]
        if tipo == "VOZ":
            minutos = (cdr["duracion_seg"] + 59) // 60
            if cdr["destino"] == "INTERNACIONAL":
                consumo["minutos_internacionales"] += minutos
            else:
                consumo["minutos_nacionales"] += minutos
        elif tipo == "DATOS":
            consumo["mb"] += cdr["mb"]
        elif tipo == "SMS":
            consumo["sms"] += 1
    for consumo in resultado.values():
        consumo["mb"] = round(consumo["mb"], 3)
    return resultado


cdrs = [
    {"linea_origen": "3001", "tipo": "VOZ", "destino": "LOCAL", "duracion_seg": 125, "mb": 0.0},
    {"linea_origen": "3001", "tipo": "DATOS", "destino": "", "duracion_seg": 900, "mb": 15.131},
    {"linea_origen": "3002", "tipo": "SMS", "destino": "NACIONAL", "duracion_seg": 0, "mb": 0.0},
]
print(consumo_por_linea(cdrs))
```

## Explicación

Este es el patrón **agrupar**, la base de cualquier resumen de datos (y de lo que en SQL o Pandas se llama `GROUP BY`):

1. Recorrer una vez los datos.
2. Buscar (o crear) el grupo de cada registro con `setdefault`.
3. Acumular en el grupo.

Una trampa sutil: si escribieras `resultado.setdefault(linea, CONSUMO_VACIO)` con un **mismo** diccionario constante, todas las líneas compartirían el mismo objeto (la trampa de las referencias de la lección 1) y sumarían en el mismo lugar. Por eso `consumo_vacio()` es una función que crea un diccionario nuevo cada vez.

Fíjate que redondear las megas **al final** evita acumular el pequeño error de float de cada suma parcial.
