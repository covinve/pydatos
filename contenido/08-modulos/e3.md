## Enunciado

Tu equipo mantiene un paquete llamado `telco` (ya está en la carpeta de trabajo de este ejercicio) con esta estructura:

```text
telco/
├── __init__.py        ← expone formatear_pesos
├── formato.py         ← formatear_pesos(valor) -> "$48.719"
└── reglas.py          ← minutos_facturables(segundos), TARIFAS
```

Escribe `resumen_linea(linea, duraciones, destino)` que devuelva un texto así, **usando las funciones del paquete** (no las reescribas):

```python
resumen_linea("3001234567", [125, 61], "NACIONAL")
# "3001234567: 5 min · $600"
```

El valor es `minutos facturables totales × TARIFAS[destino]`. Importa `formatear_pesos` desde el paquete (`from telco import ...`) y lo de reglas desde `telco.reglas`.

## Preparación

```python
from pathlib import Path

paquete = Path("telco")
paquete.mkdir(exist_ok=True)
(paquete / "__init__.py").write_text(
    '"""Utilidades del equipo de facturación."""\nfrom telco.formato import formatear_pesos\n\n__all__ = ["formatear_pesos"]\n',
    encoding="utf-8",
)
(paquete / "formato.py").write_text(
    "def formatear_pesos(valor):\n    return '$' + f'{round(valor):,}'.replace(',', '.')\n",
    encoding="utf-8",
)
(paquete / "reglas.py").write_text(
    "TARIFAS = {'LOCAL': 100, 'NACIONAL': 120, 'INTERNACIONAL': 950}\n\n"
    "def minutos_facturables(segundos):\n    return (segundos + 59) // 60\n",
    encoding="utf-8",
)
```

## Pista 2

Suma los minutos con una comprensión y multiplica por la tarifa del destino:

```python
minutos = sum(minutos_facturables(d) for d in duraciones)
valor = minutos * TARIFAS[destino]
return f"{linea}: {minutos} min · {formatear_pesos(valor)}"
```

## Solución

```python
from telco import formatear_pesos
from telco.reglas import TARIFAS, minutos_facturables


def resumen_linea(linea, duraciones, destino):
    minutos = sum(minutos_facturables(d) for d in duraciones)
    valor = minutos * TARIFAS[destino]
    return f"{linea}: {minutos} min · {formatear_pesos(valor)}"


print(resumen_linea("3001234567", [125, 61], "NACIONAL"))
```

## Explicación

`from telco import formatear_pesos` funciona porque el `__init__.py` del paquete lo **reexporta**: quien usa el paquete no necesita saber que la función vive en `telco/formato.py`. Si mañana el equipo la mueve a otro módulo, tu código no cambia.

`minutos_facturables` y `TARIFAS` no están reexportados, así que se importan desde su módulo: `telco.reglas`.

Reutilizar en lugar de copiar significa que cuando el equipo corrija un error en `formatear_pesos`, tu reporte lo recibe automáticamente.
