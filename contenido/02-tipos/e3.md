## Enunciado

En el detalle de la factura, las llamadas se muestran como `HH:MM:SS`. Escribe dos funciones:

1. `formatear_duracion(segundos)` → texto `HH:MM:SS`, siempre con dos dígitos en cada parte. Si pasan de 99 horas, las horas pueden tener más dígitos.
2. `resumen_llamada(segundos, tarifa_minuto)` → texto con este formato exacto:

```text
00:02:05 · 3 min facturables · $360
```

Los minutos facturables se redondean hacia arriba (como en el módulo 1) y el valor es `minutos × tarifa`, con separador de miles de punto.

```python
formatear_duracion(125)      # "00:02:05"
formatear_duracion(3725)     # "01:02:05"
formatear_duracion(0)        # "00:00:00"
resumen_llamada(3725, 120)   # "01:02:05 · 63 min facturables · $7.560"
```

No uses `if`: con `//`, `%` y f-strings es suficiente.

## Código inicial

```python
def formatear_duracion(segundos):
    pass


def resumen_llamada(segundos, tarifa_minuto):
    pass


print(formatear_duracion(3725))

```

## Pista 1

Descompón los segundos con `//` y `%`:

```python
horas = segundos // 3600
minutos = segundos % 3600 // 60
resto = segundos % 60
```

Y para mostrar siempre dos dígitos usa el formato `:02d` dentro del f-string: `f"{horas:02d}"`.

## Pista 2

En `resumen_llamada` reutiliza `formatear_duracion`. Para el valor con punto de miles: `f"{valor:,}".replace(",", ".")`.

El separador es ` · ` (espacio, punto medio, espacio). Cópialo del enunciado para no equivocarte de carácter.

## Solución

```python
def formatear_duracion(segundos):
    horas = segundos // 3600
    minutos = segundos % 3600 // 60
    resto = segundos % 60
    return f"{horas:02d}:{minutos:02d}:{resto:02d}"


def resumen_llamada(segundos, tarifa_minuto):
    minutos_facturables = (segundos + 59) // 60
    valor = minutos_facturables * tarifa_minuto
    valor_texto = f"{valor:,}".replace(",", ".")
    return f"{formatear_duracion(segundos)} · {minutos_facturables} min facturables · ${valor_texto}"


print(formatear_duracion(3725))
print(resumen_llamada(3725, 120))
```

## Explicación

`segundos % 3600 // 60` se lee de izquierda a derecha: primero `% 3600` descarta las horas completas y deja los segundos sobrantes; luego `// 60` cuenta cuántos minutos completos hay en ellos.

`:02d` pone **al menos** dos dígitos: por eso 100 horas se muestran completas (`100`) en vez de cortarse. El formato nunca recorta números.

Fíjate cómo `resumen_llamada` es casi una frase: arma el texto a partir de piezas que ya existen. Cuando una función se puede leer así, es señal de que el código está bien dividido.
