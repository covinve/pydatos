Un programa automatizado no tiene a nadie mirando la pantalla. Tiene que recibir sus datos por **argumentos**, avisar si falló con un **código de salida**, escribir lo que hizo en un **registro** y poder ejecutarse dos veces sin causar daño.

## Argumentos con argparse

En lugar de cambiar rutas dentro del código, recíbelas desde la línea de comandos:

```pyrun
import argparse


def crear_parser():
    p = argparse.ArgumentParser(prog="resumen_cdr", description="Resume un archivo de CDR.")
    p.add_argument("archivo", help="Ruta del cdr.csv")
    p.add_argument("--tipo", choices=["VOZ", "SMS", "DATOS"], help="Filtra por tipo")
    p.add_argument("--top", type=int, default=5, help="Cantidad de líneas a mostrar (por defecto 5)")
    p.add_argument("-v", "--detallado", action="store_true", help="Muestra más información")
    return p


parser = crear_parser()
args = parser.parse_args(["cdr.csv", "--tipo", "VOZ", "--top", "3"])    # en un script real: parse_args()
print(args)
print(args.archivo, args.tipo, args.top, args.detallado)
parser.print_help()
```

`argparse` convierte tipos (`type=int`), valida opciones (`choices`), pone valores por defecto y genera la ayuda (`--help`) automáticamente. Si el usuario se equivoca, muestra el error y termina con código 2.

:::consejo Separa main(argv)
Escribe `def main(argv=None):` que llame `parser.parse_args(argv)`. En producción `argv=None` lee la línea de comandos; en las pruebas le pasas una lista. Así tu script es **probable** sin ejecutar procesos.
:::

:::reto Los argumentos de la conciliación
Escribe `crear_parser()` para el script `conciliar`, con:

- `--periodo`: **obligatorio** (texto, por ejemplo `202609`);
- `--region`: opcional, solo `ANDINA`, `CARIBE`, `PACÍFICO` u `ORINOQUÍA`;
- `--tolerancia`: entero, por defecto `0` (diferencia en pesos que se acepta);
- `--simular`: interruptor (`store_true`) para ejecutar sin escribir nada.

```pyreto
import argparse


def crear_parser():
    pass


args = crear_parser().parse_args(["--periodo", "202609", "--tolerancia", "50", "--simular"])
print(args)
```

:::pista
`p.add_argument("--periodo", required=True)`, `p.add_argument("--region", choices=[...])`, `p.add_argument("--tolerancia", type=int, default=0)` y `p.add_argument("--simular", action="store_true")`.
:::

```pyprueba
def prueba_valores():
    """Lee los argumentos con sus tipos y valores por defecto"""
    requiere("crear_parser")
    a = crear_parser().parse_args(["--periodo", "202609", "--tolerancia", "50", "--simular"])
    igual((a.periodo, a.region, a.tolerancia, a.simular), ("202609", None, 50, True))
    b = crear_parser().parse_args(["--periodo", "202610", "--region", "CARIBE"])
    igual((b.periodo, b.region, b.tolerancia, b.simular), ("202610", "CARIBE", 0, False))


def prueba_errores():
    """Rechaza usos inválidos con código 2"""
    import contextlib
    import io
    for argv in (["--tolerancia", "5"], ["--periodo", "202609", "--region", "LUNA"], ["--periodo", "202609", "--tolerancia", "x"]):
        with contextlib.redirect_stderr(io.StringIO()):
            error = lanza(SystemExit, crear_parser().parse_args, argv)
        igual(error.code, 2, f"código de salida con {argv}")
```


## Códigos de salida

Todo programa termina con un número: **0 es éxito**, cualquier otro es error. El Programador de tareas, los *pipelines* de GitHub Actions y otros scripts lo usan para saber si siguieron o no.

| Código | Convención habitual |
|---|---|
| 0 | Todo bien |
| 1 | Error general (excepción no controlada) |
| 2 | Uso incorrecto (argumentos inválidos) |
| 3+ | Los que tú definas: "sin archivos que procesar", "otro proceso en curso"… |

```python
import sys

def main(argv=None) -> int:
    args = crear_parser().parse_args(argv)
    if not Path(args.archivo).exists():
        print(f"No existe {args.archivo}", file=sys.stderr)    # los errores van a stderr
        return 3
    ...
    return 0

if __name__ == "__main__":
    sys.exit(main())                                           # convierte el return en código de salida
```

En PowerShell, el código del último programa queda en `$LASTEXITCODE`.

:::reto Un main que avisa cómo le fue
Escribe `main(argv=None)` para un script que cuenta los registros de un archivo:

- recibe el argumento posicional `archivo`;
- si el archivo no existe, escribe en **stderr** un mensaje que incluya la ruta y devuelve `3`;
- si existe, imprime `<nombre>: <n> registros` (sin contar el encabezado) y devuelve `0`.

```pyreto
import argparse
import sys
from pathlib import Path


def main(argv=None):
    pass


codigo_salida = main(["cdr.csv"])
print("Código:", codigo_salida)
```

:::pista
`args = argparse.ArgumentParser().parse_args(argv)` con `add_argument("archivo")`. Para el error: `print(f"No existe {ruta}", file=sys.stderr)` y `return 3`. Para contar: `len(ruta.read_text(encoding="utf-8").splitlines()) - 1`.
:::

```pyprueba
import contextlib
import io


def prueba_existe():
    """Con un archivo existente devuelve 0 e imprime el conteo"""
    requiere("main")
    salida_ = io.StringIO()
    with contextlib.redirect_stdout(salida_):
        resultado = main(["cdr.csv"])
    igual(resultado, 0, "código de salida")
    with open("cdr.csv", encoding="utf-8") as f:
        n = sum(1 for _ in f) - 1
    assert f"cdr.csv: {n} registros" in salida_.getvalue(), f"Se esperaba «cdr.csv: {n} registros». Imprimió: {salida_.getvalue()!r}"


def prueba_no_existe():
    """Sin el archivo devuelve 3 y avisa por stderr"""
    errores = io.StringIO()
    with contextlib.redirect_stderr(errores), contextlib.redirect_stdout(io.StringIO()):
        resultado = main(["no_existe.csv"])
    igual(resultado, 3, "código de salida")
    assert "no_existe.csv" in errores.getvalue(), "El mensaje de error (en stderr) debe incluir la ruta"
```

```pysolucion
import argparse
import sys
from pathlib import Path


def main(argv=None):
    parser = argparse.ArgumentParser(prog="contar")
    parser.add_argument("archivo")
    args = parser.parse_args(argv)
    ruta = Path(args.archivo)
    if not ruta.exists():
        print(f"No existe {ruta}", file=sys.stderr)
        return 3
    registros = len(ruta.read_text(encoding="utf-8").splitlines()) - 1
    print(f"{ruta.name}: {registros} registros")
    return 0


codigo_salida = main(["cdr.csv"])
print("Código:", codigo_salida)
```
:::

## Rutas que funcionan desde cualquier lugar

Un error clásico: el script funciona cuando lo ejecutas desde su carpeta, pero el Programador de tareas lo ejecuta desde `C:\Windows\System32` y no encuentra nada. Construye las rutas **relativas al script**:

```python
from pathlib import Path

CARPETA_SCRIPT = Path(__file__).resolve().parent
CONFIG = CARPETA_SCRIPT / "config.toml"
```

## El patrón bandeja de entrada

Muchísimos procesos de facturación siguen este esquema:

:::pasos Bandeja de entrada → proceso → archivados
:::paso 1. Llegan archivos
Otro sistema deja archivos en `entrada/` (por SFTP, una carpeta compartida, un correo…).
:::
:::paso 2. Se procesan
Tu programa toma cada archivo **completo** (cuidado con los que aún se están copiando: espera a que su tamaño deje de cambiar, o que el emisor use un nombre temporal y luego lo renombre).
:::
:::paso 3. Se archivan
Si salió bien, el archivo se **mueve** a `procesados/AAAA-MM-DD/`; si falló, a `errores/`, con un registro de por qué. Así `entrada/` solo contiene lo pendiente y nada se procesa dos veces.
:::
:::

```pyrun
from pathlib import Path
import shutil

entrada, procesados = Path("entrada"), Path("procesados")
for carpeta in (entrada, procesados):
    shutil.rmtree(carpeta, ignore_errors=True)
    carpeta.mkdir()
for dia in ("01", "02", "03"):
    (entrada / f"cdr_202609{dia}.csv").write_text("cdr_id|tipo\n1|VOZ\n", encoding="utf-8")
(entrada / "LEAME.txt").write_text("no es un CDR", encoding="utf-8")

for archivo in sorted(entrada.glob("cdr_*.csv")):
    filas = len(archivo.read_text(encoding="utf-8").splitlines()) - 1
    destino = procesados / archivo.name
    shutil.move(archivo, destino)                     # mover = no se procesa otra vez
    print(f"{archivo.name}: {filas} fila(s) → {destino}")

print("Quedan en entrada:", [a.name for a in entrada.iterdir()])
```

:::reto Procesados y errores
En `entrada/` hay archivos de CDR (ya creados). Escribe `procesar_bandeja(entrada, procesados, errores)`:

- recorre solo los archivos `cdr_*.csv`, en orden;
- si la primera línea es exactamente `cdr_id|tipo`, mueve el archivo a `procesados/`; si no, a `errores/`;
- devuelve un diccionario `{"procesados": [...nombres], "errores": [...nombres]}`.

Los demás archivos (como `LEAME.txt`) se quedan en `entrada/`.

```pyreto
import shutil
from pathlib import Path


def procesar_bandeja(entrada, procesados, errores):
    pass


resumen = procesar_bandeja(Path("entrada"), Path("procesados"), Path("errores"))
print(resumen)
print("Quedan:", sorted(a.name for a in Path("entrada").iterdir()))
```

:::pista
Crea las carpetas de destino con `mkdir(exist_ok=True)`. `for archivo in sorted(entrada.glob("cdr_*.csv")):`, lee la primera línea con `archivo.read_text(encoding="utf-8").splitlines()[0]` y mueve con `shutil.move(archivo, destino / archivo.name)`.
:::

```pyprueba
from pathlib import Path


def prueba_resumen():
    """Clasifica los archivos"""
    requiere("resumen")
    igual(resumen, {"procesados": ["cdr_20260901.csv", "cdr_20260903.csv"], "errores": ["cdr_20260902.csv"]})


def prueba_movidos():
    """Los archivos quedaron en su carpeta y entrada solo tiene el resto"""
    igual(sorted(a.name for a in Path("procesados").iterdir()), ["cdr_20260901.csv", "cdr_20260903.csv"], "procesados/")
    igual(sorted(a.name for a in Path("errores").iterdir()), ["cdr_20260902.csv"], "errores/")
    igual(sorted(a.name for a in Path("entrada").iterdir()), ["LEAME.txt"], "entrada/")
```

```pypreparacion
import shutil
from pathlib import Path

for carpeta in ("entrada", "procesados", "errores"):
    shutil.rmtree(carpeta, ignore_errors=True)
entrada = Path("entrada")
entrada.mkdir()
(entrada / "cdr_20260901.csv").write_text("cdr_id|tipo\n1|VOZ\n", encoding="utf-8")
(entrada / "cdr_20260902.csv").write_text("id;tipo\n1;VOZ\n", encoding="utf-8")
(entrada / "cdr_20260903.csv").write_text("cdr_id|tipo\n2|SMS\n3|DATOS\n", encoding="utf-8")
(entrada / "LEAME.txt").write_text("no es un CDR", encoding="utf-8")
```

```pysolucion
import shutil
from pathlib import Path


def procesar_bandeja(entrada, procesados, errores):
    procesados.mkdir(exist_ok=True)
    errores.mkdir(exist_ok=True)
    resumen = {"procesados": [], "errores": []}
    for archivo in sorted(entrada.glob("cdr_*.csv")):
        primera = archivo.read_text(encoding="utf-8").splitlines()[0]
        if primera == "cdr_id|tipo":
            shutil.move(archivo, procesados / archivo.name)
            resumen["procesados"].append(archivo.name)
        else:
            shutil.move(archivo, errores / archivo.name)
            resumen["errores"].append(archivo.name)
    return resumen


resumen = procesar_bandeja(Path("entrada"), Path("procesados"), Path("errores"))
print(resumen)
print("Quedan:", sorted(a.name for a in Path("entrada").iterdir()))
```

:::telco Idempotencia, otra vez
Pregúntate siempre: "¿qué pasa si este proceso se ejecuta dos veces?" o "¿qué pasa si se cae a la mitad y lo reinicio?". Mover los archivos al terminar, cargar con clave primaria (módulo 17) y escribir las salidas con un nombre temporal que se renombra al final hacen que la respuesta sea "nada malo".
:::

## Cuestionario

? ¿Qué código de salida indica que un programa terminó bien?
- [x] 0
- [ ] 1
- [ ] -1
- [ ] 200
> Por convención, 0 es éxito y cualquier otro número indica algún error.

? ¿Por qué conviene escribir `main(argv=None)` y llamar `parse_args(argv)`?
- [ ] Porque argparse lo exige
- [x] Para poder probar el programa pasándole una lista de argumentos, sin ejecutar procesos
- [ ] Para que sea más rápido
- [ ] Para no necesitar `if __name__ == "__main__"`
> Con `argv=None` lee la línea de comandos real; en las pruebas le das la lista que quieras.

? Tu script lee `config.toml` y funciona a mano, pero falla en el Programador de tareas. ¿Causa probable?
- [ ] El Programador no soporta Python
- [x] La ruta es relativa al directorio actual, que en la tarea es otro; usa `Path(__file__).resolve().parent`
- [ ] El archivo está corrupto
- [ ] Falta `argparse`
> El directorio actual depende de quién ejecuta el programa; la ubicación del script no.
