## Enunciado

El proceso que descarga los archivos del servidor de mediación falla de vez en cuando por problemas de red. Escribe una función genérica de reintentos:

```python
con_reintentos(funcion, *, intentos=3, excepciones=(ConnectionError, TimeoutError), espera=1.0, log=None)
```

- Llama a `funcion()` (sin argumentos) y devuelve su resultado si funciona.
- Si lanza una de las `excepciones` indicadas, espera y vuelve a intentar, hasta `intentos` veces en total.
- Entre intentos espera `espera × 2^(n−1)` segundos (1, 2, 4… con `espera=1`): esto se llama *backoff exponencial*. Usa `time.sleep`.
- Si el último intento también falla, **relanza la última excepción**.
- Si `funcion` lanza una excepción que **no** está en `excepciones` (por ejemplo `ValueError`), no reintenta: la deja pasar de inmediato.
- Si recibe un `log`, registra cada fallo con `log.warning("Intento %d de %d falló: %s", n, intentos, error)`.

`intentos` debe ser al menos 1; si no, lanza `ValueError`.

## Código inicial

```python
import time


def con_reintentos(funcion, *, intentos=3, excepciones=(ConnectionError, TimeoutError), espera=1.0, log=None):
    pass


llamadas = {"n": 0}


def descargar():
    llamadas["n"] += 1
    if llamadas["n"] < 3:
        raise ConnectionError("Servidor no responde")
    return "cdr_20260930.csv descargado"


print(con_reintentos(descargar, espera=0))
print("Intentos usados:", llamadas["n"])
```

## Pruebas

```python
import logging
import time as _time


def fabrica(fallos, excepcion=ConnectionError, resultado="ok"):
    estado = {"llamadas": 0}

    def funcion():
        estado["llamadas"] += 1
        if estado["llamadas"] <= fallos:
            raise excepcion(f"fallo {estado['llamadas']}")
        return resultado

    return funcion, estado


def prueba_sin_fallos():
    """Si funciona a la primera, llama una sola vez"""
    requiere("con_reintentos")
    funcion, estado = fabrica(0)
    igual(con_reintentos(funcion, espera=0), "ok")
    igual(estado["llamadas"], 1)


def prueba_reintenta_hasta_lograrlo():
    """Reintenta ante errores de conexión"""
    funcion, estado = fabrica(2)
    igual(con_reintentos(funcion, espera=0), "ok")
    igual(estado["llamadas"], 3)


def prueba_se_rinde():
    """Tras agotar los intentos, relanza la última excepción"""
    funcion, estado = fabrica(5)
    error = lanza(ConnectionError, con_reintentos, funcion, intentos=3, espera=0)
    igual(str(error), "fallo 3")
    igual(estado["llamadas"], 3)


def prueba_otras_excepciones_no_se_reintentan():
    """Un ValueError pasa de inmediato, sin reintentos"""
    funcion, estado = fabrica(5, excepcion=ValueError)
    lanza(ValueError, con_reintentos, funcion, espera=0)
    igual(estado["llamadas"], 1)


def prueba_excepciones_configurables():
    """Se puede elegir qué excepciones reintentar"""
    funcion, estado = fabrica(1, excepcion=KeyError)
    igual(con_reintentos(funcion, excepciones=(KeyError,), espera=0), "ok")


def prueba_backoff():
    """Espera 1×, 2×, 4× el tiempo base entre intentos"""
    esperas = []
    original = _time.sleep
    _time.sleep = esperas.append
    try:
        funcion, _ = fabrica(3)
        con_reintentos(funcion, intentos=4, espera=0.5)
    finally:
        _time.sleep = original
    igual(esperas, [0.5, 1.0, 2.0])


def prueba_registra_fallos():
    """Registra cada fallo en el log"""
    mensajes = []

    class Capturador(logging.Handler):
        def emit(self, record):
            mensajes.append(record.getMessage())

    log = logging.getLogger("prueba_reintentos")
    log.handlers.clear()
    log.propagate = False
    log.addHandler(Capturador())
    funcion, _ = fabrica(2)
    con_reintentos(funcion, espera=0, log=log)
    igual(mensajes, ["Intento 1 de 3 falló: fallo 1", "Intento 2 de 3 falló: fallo 2"])


def prueba_intentos_invalidos():
    """intentos debe ser al menos 1"""
    funcion, _ = fabrica(0)
    lanza(ValueError, con_reintentos, funcion, intentos=0)
```

## Pista 1

Un `for` con un `try` adentro. Si la llamada funciona, `return`. Si falla con una excepción esperada, guárdala y, si no es el último intento, espera:

```python
for n in range(1, intentos + 1):
    try:
        return funcion()
    except excepciones as error:
        ...
```

`except` acepta una **tupla** de clases de excepción: `except excepciones as error:` funciona directamente.

## Pista 2

Para relanzar la última excepción después del bucle, guárdala en una variable (`ultimo_error = error`) y al final `raise ultimo_error`. Otra opción: dentro del `except`, si `n == intentos`, usa `raise` solo para relanzar.

La espera del intento `n` es `espera * 2 ** (n - 1)`. No esperes después del último intento.

## Solución

```python
import time


def con_reintentos(funcion, *, intentos=3, excepciones=(ConnectionError, TimeoutError), espera=1.0, log=None):
    if intentos < 1:
        raise ValueError(f"intentos debe ser al menos 1, se recibió {intentos}")
    for n in range(1, intentos + 1):
        try:
            return funcion()
        except excepciones as error:
            if log is not None:
                log.warning("Intento %d de %d falló: %s", n, intentos, error)
            if n == intentos:
                raise
            time.sleep(espera * 2 ** (n - 1))


llamadas = {"n": 0}


def descargar():
    llamadas["n"] += 1
    if llamadas["n"] < 3:
        raise ConnectionError("Servidor no responde")
    return "cdr_20260930.csv descargado"


print(con_reintentos(descargar, espera=0))
print("Intentos usados:", llamadas["n"])
```

## Explicación

Cinco decisiones de diseño que hacen esta función segura para producción:

1. **Límite de intentos.** Nunca reintentar para siempre.
2. **Solo las excepciones esperadas.** Un `ValueError` es un error de datos o de programación: reintentarlo daría el mismo resultado tres veces.
3. **Backoff exponencial.** Si el servidor está saturado, bombardearlo cada segundo empeora las cosas. Esperar cada vez más le da tiempo de recuperarse.
4. **`raise` solo** relanza la excepción original con su traceback intacto: quien llama ve exactamente qué falló la última vez.
5. **La función a reintentar es un parámetro.** Sirve para descargar archivos, consultar una API o conectarse a una base de datos. Si necesitas pasarle argumentos: `con_reintentos(lambda: descargar(ruta), ...)`.

La prueba `prueba_backoff` reemplaza temporalmente `time.sleep` por una función que solo anota los tiempos. Así se verifica la espera sin esperar de verdad. En el módulo 20 verás que esta técnica se llama *mock* y que pytest trae herramientas para hacerla de forma limpia.
