## Enunciado

Antes de facturar, el equipo de mediación revisa a mano los registros con problemas evidentes. Escribe `exportar_sospechosos(ruta_entrada, ruta_salida)` que:

1. Recorra `cdr.csv` y detecte los registros con alguno de estos problemas (revisa en este orden y quédate con el **primero**):

   | Motivo | Condición |
   |---|---|
   | `linea_vacia` | `linea_origen` vacía |
   | `tipo_desconocido` | `tipo` no es `VOZ`, `SMS` ni `DATOS` |
   | `duracion_negativa` | `duracion_seg` < 0 |
   | `fecha_invalida` | `fecha_inicio` no se puede leer con `datetime.strptime(..., "%Y-%m-%d %H:%M:%S")` |

Las cantidades deben coincidir con la sección `"errores"` de `esperado.json`. Escribe también `coincide_con_esperado(conteo, ruta_json)` que devuelva `True` si los cuatro valores coinciden.

## Solución

```python
import csv
import json
from datetime import datetime

TIPOS = {"VOZ", "SMS", "DATOS"}
MOTIVOS = ["linea_vacia", "tipo_desconocido", "duracion_negativa", "fecha_invalida"]


def fecha_valida(texto):
    try:
        datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")
        return True
    except ValueError:
        return False


def motivo(fila):
    if not fila["linea_origen"]:
        return "linea_vacia"
    if fila["tipo"] not in TIPOS:
        return "tipo_desconocido"
    if int(fila["duracion_seg"]) < 0:
        return "duracion_negativa"
    if not fecha_valida(fila["fecha_inicio"]):
        return "fecha_invalida"
    return None


def exportar_sospechosos(ruta_entrada, ruta_salida):
    conteo = {m: 0 for m in MOTIVOS}
    with open(ruta_entrada, encoding="utf-8", newline="") as entrada, \
         open(ruta_salida, "w", encoding="utf-8", newline="") as salida:
        lector = csv.DictReader(entrada, delimiter="|")
        escritor = csv.DictWriter(salida, fieldnames=lector.fieldnames + ["motivo"], delimiter="|", lineterminator="\n")
        escritor.writeheader()
        for fila in lector:
            m = motivo(fila)
            if m is not None:
                conteo[m] += 1
                escritor.writerow({**fila, "motivo": m})
    return conteo


def coincide_con_esperado(conteo, ruta_json):
    with open(ruta_json, encoding="utf-8") as archivo:
        errores = json.load(archivo)["cdr"]["errores"]
    return all(conteo.get(m) == errores[m] for m in MOTIVOS)


conteo = exportar_sospechosos("cdr.csv", "sospechosos.csv")
print(conteo)
print(coincide_con_esperado(conteo, "esperado.json"))
```

## Explicación

Este es un **filtro de flujo** (*streaming*): lee un registro, decide, escribe, y sigue. Nunca hay más de un registro en memoria, así que funciona igual con la muestra que con 20 GB.

Separar `motivo(fila)` del recorrido tiene varias ventajas:

- Se prueba sola, con un diccionario inventado.
- El recorrido no cambia si agregas un motivo nuevo.
- Es exactamente la función que reutilizarás en el Proyecto 1.

`lineterminator="\n"` evita que `csv` use `\r\n` (su valor por defecto). Así el archivo de salida tiene los mismos finales de línea que el original.

Faltan dos errores de las reglas del curso: `duplicado` y `linea_desconocida`. Requieren **comparar con otros datos** (registros anteriores y el archivo de clientes): los agregarás en el Proyecto 1 con lo que aprendiste de conjuntos y diccionarios.
