## Enunciado

Los reportes de facturación muestran los valores en pesos con **punto como separador de miles** y sin decimales. Escribe la función `formatear_pesos(valor)` que recibe un número (entero o decimal, siempre positivo o cero) y devuelve el texto así:

```python
formatear_pesos(48719)        # "$48.719"
formatear_pesos(1234567)      # "$1.234.567"
formatear_pesos(950)          # "$950"
formatear_pesos(0)            # "$0"
formatear_pesos(7778.6)       # "$7.779"   ← se redondea al peso
```

Para redondear usa la regla comercial (0,5 sube): `formatear_pesos(28.5)` debe dar `"$29"`.

## Pista 1

Convierte primero el valor a `Decimal` usando `str(valor)` para no arrastrar errores del float, y redondéalo con `quantize`:

```python
pesos = Decimal(str(valor)).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
```

## Pista 2

Con el valor ya redondeado, `f"{pesos:,}"` produce `"1,234,567"`. Solo falta reemplazar las comas por puntos y agregar el `$` al inicio:

```python
texto = f"{pesos:,}".replace(",", ".")
return "$" + texto
```

## Solución

```python
from decimal import Decimal, ROUND_HALF_UP


def formatear_pesos(valor):
    pesos = Decimal(str(valor)).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
    return "$" + f"{pesos:,}".replace(",", ".")


print(formatear_pesos(48719))
print(formatear_pesos(7778.6))
```

## Explicación

La función hace tres cosas en orden:

1. **`Decimal(str(valor))`**: pasar por `str` evita que un float como `28.5` llegue con decimales escondidos. Funciona igual con `int`, `float` y `Decimal`.
2. **`quantize(Decimal("1"), rounding=ROUND_HALF_UP)`**: redondea a pesos enteros con la regla comercial. Con `round()` el caso `28.5` daría `28`.
3. **`f"{pesos:,}"`** agrega comas de miles; `.replace(",", ".")` las cambia por puntos.

¿Por qué no hizo falta el truco del comodín de la lección? Porque no hay decimales: solo hay que cambiar un símbolo. Si quisieras mostrar centavos (`1.234,56`), sí necesitarías intercambiar comas y puntos.
