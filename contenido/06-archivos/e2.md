## Enunciado

En la carpeta de trabajo están `cdr.csv` (separado por `|`, UTF-8) y `esperado.json`. Escribe:

1. `resumir_cdr(ruta)` → recorre el archivo **línea por línea** (sin cargarlo completo) y devuelve un diccionario con:
   - `"registros"`: cantidad de registros (sin contar el encabezado);
   - `"por_tipo"`: diccionario `tipo → cantidad` con los valores **tal como vienen** (incluidos los tipos erróneos), ordenado por tipo;
   - `"lineas_distintas"`: cantidad de líneas de origen distintas **no vacías**;
   - `"mb_datos"`: suma de las `mb` de los registros `DATOS`, redondeada a 3 decimales.
2. `cuadra_con_esperado(resumen, ruta_json)` → `True` si `resumen["registros"]` coincide con `registros_totales` de la sección `"cdr"` del JSON.

## Pista 2

Para el JSON: `json.load(archivo)` devuelve un diccionario; el valor está en `datos["cdr"]["registros_totales"]`.

Recuerda que `fila["mb"]` es texto: conviértelo con `float()`. Para ordenar el diccionario de tipos: `dict(sorted(por_tipo.items()))`.

## Solución

```python
import csv
import json
from collections import Counter


def resumir_cdr(ruta):
    registros = 0
    por_tipo = Counter()
    lineas = set()
    mb = 0.0
    with open(ruta, encoding="utf-8", newline="") as archivo:
        for fila in csv.DictReader(archivo, delimiter="|"):
            registros += 1
            por_tipo[fila["tipo"]] += 1
            if fila["linea_origen"]:
                lineas.add(fila["linea_origen"])
            if fila["tipo"] == "DATOS":
                mb += float(fila["mb"])
    return {
        "registros": registros,
        "por_tipo": dict(sorted(por_tipo.items())),
        "lineas_distintas": len(lineas),
        "mb_datos": round(mb, 3),
    }


def cuadra_con_esperado(resumen, ruta_json):
    with open(ruta_json, encoding="utf-8") as archivo:
        esperado = json.load(archivo)
    return resumen["registros"] == esperado["cdr"]["registros_totales"]


resumen = resumir_cdr("cdr.csv")
print(resumen)
print(cuadra_con_esperado(resumen, "esperado.json"))
```

## Explicación

**Una sola pasada, varios acumuladores.** Recorrer el archivo es lo más costoso; por eso se calculan todos los resúmenes en el mismo recorrido. Con 20 GB, hacer cuatro pasadas significaría leer 80 GB del disco.

La memoria usada depende de **lo que acumulas**, no del tamaño del archivo:

| Acumulador | Memoria |
|---|---|
| `registros`, `mb` | Un número |
| `por_tipo` | Unas pocas claves |
| `lineas` | **Una entrada por línea distinta**: con 400.000 clientes, unos 40 MB |

Esto último es importante: un conjunto de líneas es manejable; un conjunto de **cada `cdr_id`** de 280 millones de registros no lo sería.
