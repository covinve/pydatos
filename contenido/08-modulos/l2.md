Un **paquete** es una carpeta de módulos. Permite agrupar el código por tema, como las carpetas agrupan documentos.

```text
facturacion/
├── __init__.py          ← convierte la carpeta en paquete (puede estar vacío)
├── lectura.py           ← leer CDR, clientes y planes
├── reglas.py            ← validaciones y tarificación
├── reportes.py          ← resúmenes y archivos de salida
└── formatos/
    ├── __init__.py
    ├── csv_pipe.py
    └── ancho_fijo.py
```

```python
from facturacion.reglas import clasificar
from facturacion.formatos.ancho_fijo import leer_registro
import facturacion.reportes as reportes
```

Construyamos uno de verdad:

```pyrun
from pathlib import Path

paquete = Path("facturacion")
paquete.mkdir(exist_ok=True)
(paquete / "__init__.py").write_text('"""Herramientas de facturación."""\n', encoding="utf-8")
(paquete / "reglas.py").write_text(
    "TIPOS = {'VOZ', 'SMS', 'DATOS'}\n\n"
    "def minutos_facturables(segundos):\n"
    "    return (segundos + 59) // 60\n",
    encoding="utf-8",
)
(paquete / "reportes.py").write_text(
    "from facturacion.reglas import minutos_facturables\n\n"
    "def resumen(duraciones):\n"
    "    return f'{len(duraciones)} llamadas, {sum(minutos_facturables(d) for d in duraciones)} min'\n",
    encoding="utf-8",
)

from facturacion.reportes import resumen
print(resumen([125, 61, 3600]))
```

## `__init__.py`: la puerta del paquete

El `__init__.py` se ejecuta al importar el paquete. Puedes dejarlo vacío o usarlo para **exponer** lo más importante, de modo que quien lo usa no necesite conocer la estructura interna:

```python
# facturacion/__init__.py
"""Herramientas de facturación."""

from facturacion.reglas import clasificar, minutos_facturables
from facturacion.reportes import resumen

__all__ = ["clasificar", "minutos_facturables", "resumen"]
```

Ahora basta con `from facturacion import resumen`. `__all__` documenta cuál es la **interfaz pública** del paquete.

:::reto Usa el paquete del equipo
El equipo dejó listo el paquete `tarifario` (ya está creado en esta página):

```text
tarifario/
├── __init__.py      ← expone tarifa_de
├── tablas.py        ← TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
└── calculo.py       ← minutos_facturables(segundos) y valor(destino, segundos)
```

Importa lo que necesitas y calcula:

- `tarifa_int`: la tarifa internacional, usando `tarifa_de`, importada **desde el paquete** (`from tarifario import ...`);
- `valor_llamada`: el valor de una llamada nacional de 125 segundos, usando `valor` de `tarifario.calculo`;
- `destinos`: la lista de destinos de `TARIFAS`, importando el módulo `tablas` con el alias `tb`.

```pyreto
# Importa desde el paquete tarifario

print(tarifa_int, valor_llamada, destinos)
```

:::pista
Tres imports distintos: `from tarifario import tarifa_de`, `from tarifario.calculo import valor` e `import tarifario.tablas as tb`. Luego `list(tb.TARIFAS)`.
:::

```pyprueba
def prueba_valores():

```

```pypreparacion
from pathlib import Path

paquete = Path("tarifario")
paquete.mkdir(exist_ok=True)
(paquete / "tablas.py").write_text('TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}\n', encoding="utf-8")
(paquete / "calculo.py").write_text(
    "from tarifario.tablas import TARIFAS\n\n\n"
    "def minutos_facturables(segundos):\n"
    "    return (segundos + 59) // 60\n\n\n"
    "def tarifa_de(destino):\n"
    "    return TARIFAS[destino]\n\n\n"
    "def valor(destino, segundos):\n"
    "    return minutos_facturables(segundos) * tarifa_de(destino)\n",
    encoding="utf-8",
)
(paquete / "__init__.py").write_text(
    '"""Tarifas del equipo de facturación."""\n\n'
    "from tarifario.calculo import tarifa_de\n\n"
    '__all__ = ["tarifa_de"]\n',
    encoding="utf-8",
)
```

```pysolucion
import tarifario.tablas as tb
from tarifario import tarifa_de
from tarifario.calculo import valor

tarifa_int = tarifa_de("INTERNACIONAL")
valor_llamada = valor("NACIONAL", 125)
destinos = list(tb.TARIFAS)

print(tarifa_int, valor_llamada, destinos)
```

:::consejo Nombres privados
Por convención, un nombre que empieza con guion bajo (`_normalizar_linea`) es **interno**: "no lo uses desde fuera, puede cambiar sin aviso". Python no lo impide, pero ruff y los editores lo respetan, y los demás programadores también.

## Imports absolutos y relativos

Dentro de un paquete puedes importar de dos formas:

| Absoluto | Relativo |
|---|---|
| `from facturacion.reglas import clasificar` | `from .reglas import clasificar` |
| `from facturacion.formatos import ancho_fijo` | `from .formatos import ancho_fijo` |
| Funciona desde cualquier lugar | Solo dentro del paquete; `.` es "este paquete", `..` "el de arriba" |

PEP 8 recomienda los **absolutos** por ser más claros. Los relativos son útiles en paquetes grandes para no repetir el nombre largo.

:::error "attempted relative import with no known parent package"
Aparece si ejecutas directamente un archivo que usa imports relativos (`python facturacion/reportes.py`). Los módulos de un paquete se ejecutan **como parte del paquete**: `python -m facturacion.reportes`, desde la carpeta que contiene `facturacion/`.
:::

## Importaciones circulares

Si `reglas.py` importa de `reportes.py` y `reportes.py` importa de `reglas.py`, Python se enreda: al cargar uno necesita el otro, que todavía no termina de cargarse.

La función de formato pasa a un módulo propio que **no importa a nadie**. Ahora las dependencias van en una sola dirección, como un árbol.

La regla general: **las dependencias deben formar capas**. Los módulos de bajo nivel (formato, constantes, modelos) no importan a los de alto nivel (reportes, programa principal). Lo profundizarás en el módulo 19, con la arquitectura en capas.

## `python -m`: ejecutar un módulo de un paquete

```powershell
python -m facturacion.reportes      # ejecuta reportes.py como parte del paquete
python -m pytest                     # ejecuta pytest del entorno actual
python -m pip install pandas         # el pip del Python actual
```

Si un paquete tiene un archivo `__main__.py`, `python -m facturacion` ejecuta ese archivo. Es la forma estándar de darle un "punto de entrada" a un paquete.
