## Enunciado

¿Cuál herramienta usar en tu trabajo? No lo decidas por opinión: **mídelo con tus datos**.

En `ejercicios/m16-e8/comparativa.py` implementa la **misma** pregunta cuatro veces: registros válidos (las seis reglas), minutos nacionales e internacionales, MB y SMS de los CDR válidos.

| Función | Herramienta | Condición |
|---|---|---|
| `con_python(carpeta)` | `csv.reader` | Sin Pandas |
| `con_pandas(carpeta)` | `pd.read_csv` | Vectorizado |
| `con_polars(carpeta)` | `pl.scan_csv` | Perezoso |
| `con_duckdb(carpeta)` | `duckdb.sql` | Una consulta |

Las cuatro devuelven un diccionario con las claves de `CLAVES`, con valores `int`/`float` de Python (no tipos de NumPy), iguales a `esperado.json`.

Además, `medir(funcion, *argumentos)` ejecuta la función una vez y devuelve el resultado, los segundos (`time.perf_counter`) y cuánto creció la memoria del proceso (`psutil`, con un hilo que toma muestras).

Cuando pase `python comprobar.py m16-e8`, ejecútalo con 100 MB y 1 GB y anota la tabla de resultados al final del archivo:

```powershell
python herramientas/generar_datos.py --tamano 1GB
python ejercicios/m16-e8/comparativa.py datos/1GB
```

## Pista 1

Para medir la memoria mientras otra cosa se ejecuta, usa un hilo que mire la RSS cada poco tiempo hasta que le avises que pare:

```python
import threading, time, psutil

proceso = psutil.Process()
inicial = proceso.memory_info().rss
pico = inicial
parar = threading.Event()

def vigilar():
    nonlocal pico          # o una lista de un elemento
    while not parar.is_set():
        pico = max(pico, proceso.memory_info().rss)
        time.sleep(0.02)
```

Arranca el hilo, ejecuta la función, `parar.set()`, `hilo.join()` y toma una última muestra.

## Pista 2

Reutiliza lo que ya escribiste: la versión de Python puro es la del proyecto 1, la de Pandas la del módulo 13, la de Polars el ejercicio 5 y la de DuckDB el ejercicio 7. Para devolver tipos de Python: `int(x)`, `float(x)`, y `round(mb, 3)`.

En Python puro, el duplicado se detecta con un conjunto de `cdr_id` ya vistos, y los minutos se suman llamada por llamada con `(duracion + 59) // 60`.

## Solución

```python comparativa.py
"""Ejercicio m16-e8: la misma pregunta con cuatro herramientas, y quién gana.

Uso:
    python ejercicios/m16-e8/comparativa.py datos/1GB
"""

from __future__ import annotations

import csv
import sys
import threading
import time
from datetime import datetime
from pathlib import Path

import duckdb
import numpy as np
import pandas as pd
import polars as pl
import psutil

CLAVES = ["registros_validos", "minutos_nacionales", "minutos_internacionales", "mb_totales", "sms_totales"]
FORMATO = "%Y-%m-%d %H:%M:%S"


def _resultado(validos, nac, inter, mb, sms) -> dict:
    return {"registros_validos": int(validos), "minutos_nacionales": int(nac or 0),
            "minutos_internacionales": int(inter or 0), "mb_totales": round(float(mb or 0), 3),
            "sms_totales": int(sms or 0)}


def con_python(carpeta: Path) -> dict:
    with open(carpeta / "clientes.csv", encoding="latin-1", newline="") as f:
        clientes = {fila["linea"] for fila in csv.DictReader(f)}
    vistos = set()
    validos = nac = inter = sms = 0
    mb = 0.0
    with open(carpeta / "cdr.csv", encoding="utf-8", newline="") as f:
        lector = csv.reader(f, delimiter="|")
        next(lector)
        for cdr_id, origen, _, tipo, destino, fecha, duracion, megas, _ in lector:
            if cdr_id in vistos:
                continue
            vistos.add(cdr_id)
            if not origen or origen not in clientes or tipo not in ("VOZ", "SMS", "DATOS"):
                continue
            segundos = int(duracion)
            if segundos < 0:
                continue
            try:
                datetime.strptime(fecha, FORMATO)
            except ValueError:
                continue
            validos += 1
            if tipo == "VOZ":
                if destino == "INTERNACIONAL":
                    inter += (segundos + 59) // 60
                else:
                    nac += (segundos + 59) // 60
            elif tipo == "DATOS":
                mb += float(megas)
            else:
                sms += 1
    return _resultado(validos, nac, inter, mb, sms)


def con_pandas(carpeta: Path) -> dict:
    cdr = pd.read_csv(carpeta / "cdr.csv", sep="|", dtype=str, keep_default_na=False)
    clientes = pd.read_csv(carpeta / "clientes.csv", encoding="latin-1", dtype=str)
    duracion = pd.to_numeric(cdr["duracion_seg"])
    fecha = pd.to_datetime(cdr["fecha_inicio"], format=FORMATO, errors="coerce")
    ok = (~cdr["cdr_id"].duplicated() & (cdr["linea_origen"] != "") & cdr["linea_origen"].isin(clientes["linea"])
          & cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (duracion >= 0) & fecha.notna())
    v = cdr[ok]
    minutos = (duracion[ok] + 59) // 60
    voz = v["tipo"] == "VOZ"
    internacional = v["destino"] == "INTERNACIONAL"
    return _resultado(len(v), minutos[voz & ~internacional].sum(), minutos[voz & internacional].sum(),
                      pd.to_numeric(v.loc[v["tipo"] == "DATOS", "mb"]).sum(), (v["tipo"] == "SMS").sum())


def con_polars(carpeta: Path) -> dict:
    clientes = pl.scan_csv(carpeta / "clientes.csv", encoding="utf8-lossy",
                           schema_overrides={"linea": pl.String}).select("linea")
    cdr = pl.scan_csv(carpeta / "cdr.csv", separator="|",
                      schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
    fecha_ok = pl.col("fecha_inicio").str.strptime(pl.Datetime, FORMATO, strict=False).is_not_null()
    minutos = (pl.col("duracion_seg") + 59) // 60
    voz = pl.col("tipo") == "VOZ"
    internacional = pl.col("destino") == "INTERNACIONAL"
    r = (
        cdr.filter(pl.int_range(pl.len()).over("cdr_id") == 0)
        .join(clientes, left_on="linea_origen", right_on="linea", how="semi")
        .filter(pl.col("tipo").is_in(["VOZ", "SMS", "DATOS"]) & (pl.col("duracion_seg") >= 0) & fecha_ok)
        .select(
            validos=pl.len(),
            nac=minutos.filter(voz & ~internacional).sum(),
            inter=minutos.filter(voz & internacional).sum(),
            mb=pl.col("mb").filter(pl.col("tipo") == "DATOS").sum(),
            sms=(pl.col("tipo") == "SMS").sum(),
        )
        .collect()
        .row(0)
    )
    return _resultado(*r)


def con_duckdb(carpeta: Path) -> dict:
    cdr = (carpeta / "cdr.csv").as_posix()
    clientes = (carpeta / "clientes.csv").as_posix()
    r = duckdb.sql(f"""
        WITH cdr AS (
            SELECT *, ROW_NUMBER() OVER () AS rn FROM read_csv('{cdr}', delim='|', header=true, all_varchar=true)
        ),
        marcado AS (
            SELECT *, ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY rn) AS aparicion FROM cdr
        ),
        validos AS (
            SELECT tipo, destino, CAST(duracion_seg AS INTEGER) AS seg, CAST(mb AS DOUBLE) AS mb
            FROM marcado
            WHERE aparicion = 1
              AND coalesce(linea_origen, '') <> ''
              AND linea_origen IN (SELECT linea FROM read_csv('{clientes}', encoding='latin-1', header=true, all_varchar=true))
              AND tipo IN ('VOZ', 'SMS', 'DATOS')
              AND CAST(duracion_seg AS INTEGER) >= 0
              AND TRY_STRPTIME(fecha_inicio, '{FORMATO}') IS NOT NULL
        )
        SELECT COUNT(*),
               SUM((seg + 59) // 60) FILTER (WHERE tipo = 'VOZ' AND destino <> 'INTERNACIONAL'),
               SUM((seg + 59) // 60) FILTER (WHERE tipo = 'VOZ' AND destino = 'INTERNACIONAL'),
               SUM(mb) FILTER (WHERE tipo = 'DATOS'),
               COUNT(*) FILTER (WHERE tipo = 'SMS')
        FROM validos
    """).fetchone()
    return _resultado(*r)


def medir(funcion, *argumentos) -> dict:
    proceso = psutil.Process()
    inicial = proceso.memory_info().rss
    pico = [inicial]
    parar = threading.Event()

    def vigilar():
        while not parar.is_set():
            pico[0] = max(pico[0], proceso.memory_info().rss)
            time.sleep(0.02)

    hilo = threading.Thread(target=vigilar, daemon=True)
    hilo.start()
    inicio = time.perf_counter()
    try:
        resultado = funcion(*argumentos)
    finally:
        segundos = time.perf_counter() - inicio
        parar.set()
        hilo.join()
    pico[0] = max(pico[0], proceso.memory_info().rss)
    return {"resultado": resultado, "segundos": segundos, "memoria_mb": (pico[0] - inicial) / 1024**2}


if __name__ == "__main__":
    carpeta = Path(sys.argv[1])
    for funcion in (con_python, con_pandas, con_polars, con_duckdb):
        m = medir(funcion, carpeta)
        print(f"{funcion.__name__:12} {m['segundos']:8.2f} s  {m['memoria_mb']:8.0f} MB  {m['resultado']}")
```

## Explicación

Resultados típicos con 1 GB (unos 11 millones de CDR) en un portátil de oficina:

| Herramienta | Tiempo | Memoria extra | Comentario |
|---|---|---|---|
| Python puro | 60–90 s | ~1 GB (el conjunto de IDs) | Simple, sin dependencias, lento |
| Pandas | 25–40 s | 6–10 GB | Rápido de escribir; la memoria es su límite |
| Polars | 3–6 s | 1–3 GB | Usa todos los núcleos |
| DuckDB | 3–6 s | 1–2 GB | SQL, y respeta `memory_limit` |

Tus números serán distintos, y ese es el punto: **mide en tu equipo y con tus datos**. Algunas conclusiones que suelen mantenerse:

- Para archivos que caben cómodos en memoria (cientos de MB), Pandas está bien y es lo que más gente conoce.
- Para varios GB, Polars o DuckDB son 5 a 20 veces más rápidos y gastan mucha menos memoria.
- Elige entre ellos por estilo: si piensas en SQL, DuckDB; si prefieres expresiones de Python, Polars. Los dos leen y escriben Parquet, y DuckDB puede consultar DataFrames de Polars directamente.

Sobre `medir`: el hilo es necesario porque mientras la función trabaja el programa principal está ocupado. `psutil` mide la memoria **del proceso** (incluida la de DuckDB y Polars, escritas en C++ y Rust), algo que `tracemalloc` no ve porque solo sigue la memoria de objetos de Python.
