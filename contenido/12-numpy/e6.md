## Enunciado

Vas a optimizar la memoria de los arrays de un lote de CDR sin perder información.

1. `tipo_minimo(valores)` → el dtype entero **más pequeño** de esta lista que puede guardar todos los valores: `int8`, `int16`, `int32`, `int64` (usa `np.iinfo(tipo).min` y `.max`). Devuelve el **nombre** como texto (`"int16"`).
2. `optimizar(columnas)` → recibe un diccionario `nombre → array de enteros` y devuelve un diccionario nuevo con cada array convertido a su tipo mínimo.
3. `ahorro(originales, optimizados)` → porcentaje de memoria ahorrado (con `nbytes`), redondeado a 1 decimal.
4. `total_seguro(valores)` → la suma de `valores` multiplicados por 1.000 como `int` de Python, **sin desbordamiento** aunque `valores` sea `int16` (convierte antes de multiplicar).

```python
tipo_minimo(np.array([0, 23]))          # "int8"
tipo_minimo(np.array([-45, 7200]))      # "int16"
total_seguro(np.array([30000, 30000], dtype=np.int16))   # 60000000
```

## Pruebas

```python
import numpy as np


def prueba_tipo_minimo():
    """Elige el tipo más pequeño que alcanza"""
    igual(tipo_minimo(np.array([0, 23])), "int8")
    igual(tipo_minimo(np.array([-45, 7200])), "int16")
    igual(tipo_minimo(np.array([0, 3_500_000_000])), "int64")
    igual(tipo_minimo(np.array([127, -128])), "int8")
    igual(tipo_minimo(np.array([128])), "int16")


def prueba_optimizar():
    """Convierte cada columna sin cambiar los valores"""
    columnas = {"hora": np.array([0, 23, 12], dtype=np.int64), "duracion": np.array([125, -45, 7200], dtype=np.int64),
                "cdr_id": np.array([1, 2, 3_000_000_000], dtype=np.int64)}
    opt = optimizar(columnas)
    igual({k: str(v.dtype) for k, v in opt.items()}, {"hora": "int8", "duracion": "int16", "cdr_id": "int64"})
    for nombre in columnas:
        assert (opt[nombre] == columnas[nombre]).all(), f"Cambió algún valor de {nombre}"
    igual(str(columnas["hora"].dtype), "int64", "No modifiques los arrays originales")


def prueba_ahorro():
    """Porcentaje ahorrado"""
    originales = {"a": np.zeros(100, dtype=np.int64), "b": np.zeros(100, dtype=np.int64)}
    optimizados = {"a": np.zeros(100, dtype=np.int8), "b": np.zeros(100, dtype=np.int64)}
    igual(ahorro(originales, optimizados), 43.8)


def prueba_total_seguro():
    """Suma sin desbordamiento"""
    resultado = total_seguro(np.array([30000, 30000], dtype=np.int16))
    igual(resultado, 60_000_000)
    assert type(resultado) is int

        return nombre
```

## Pista 2

`array.astype("int16")` crea una copia con otro tipo (el original no cambia). Para `total_seguro`: `int((valores.astype(np.int64) * 1000).sum())`. Si multiplicas antes de convertir, `30000 * 1000` no cabe en `int16`.

## Solución

```python
import numpy as np

CANDIDATOS = ["int8", "int16", "int32", "int64"]


def tipo_minimo(valores):
    minimo, maximo = valores.min(), valores.max()
    for nombre in CANDIDATOS:
        info = np.iinfo(nombre)
        if info.min <= minimo and maximo <= info.max:
            return nombre
    raise ValueError("Los valores no caben en int64")


def optimizar(columnas):
    return {nombre: valores.astype(tipo_minimo(valores)) for nombre, valores in columnas.items()}


def ahorro(originales, optimizados):
    antes = sum(a.nbytes for a in originales.values())
    despues = sum(a.nbytes for a in optimizados.values())
    return round((1 - despues / antes) * 100, 1)


def total_seguro(valores):
    return int((valores.astype(np.int64) * 1000).sum())
```

## Explicación

Con 280 millones de CDR, cada columna en `int64` ocupa 2,2 GB. La hora en `int8` ocupa 280 MB; la duración en `int16`, 560 MB. Elegir bien los tipos puede ser la diferencia entre que los datos quepan en tus 16 GB o no.

Pero ahorrar memoria trae un riesgo: **el desbordamiento es silencioso**. La regla práctica: *guarda pequeño, calcula grande*. Antes de multiplicar o acumular, convierte a `int64` (o `float64`). Pandas ofrece lo mismo con `pd.to_numeric(..., downcast="integer")`, que verás en el módulo 13.
