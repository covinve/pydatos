## Enunciado

1. `resumen_robusto(valores)` recibe un arreglo o Serie de números y devuelve un diccionario con `n`, `media`, `mediana`, `mad` (mediana de `|x − mediana|`), `sigma_robusta` (`1.4826 × mad`), `p25`, `p75`, `iqr` y `p99`. Todos `float` (salvo `n`, `int`) y redondeados a 2 decimales.
2. `ic_bootstrap(valores, estadistico, repeticiones=2000, semilla=2026, nivel=0.95)` → tupla `(bajo, alto)` con el intervalo de confianza por bootstrap:
   - `rng = np.random.default_rng(semilla)`;
   - en cada repetición, `muestra = rng.choice(valores, size=len(valores), replace=True)` y se aplica `estadistico(muestra)`;
   - el intervalo son los percentiles `(1 − nivel)/2` y `(1 + nivel)/2` (en %) de los resultados, con `np.percentile`.

Úsalo con las duraciones de las llamadas de voz contestadas (`duracion_seg > 0`) de la muestra.

## Pruebas

```python
import numpy as np
import pandas as pd

CDR = pd.read_csv("cdr.csv", sep="|")
VOZ = CDR.loc[(CDR["tipo"] == "VOZ") & (CDR["duracion_seg"] > 0), "duracion_seg"].to_numpy()


def prueba_resumen():
    """Medidas clásicas y robustas"""
    requiere("resumen_robusto")
    r = resumen_robusto(VOZ)
    mediana = np.median(VOZ)
    mad = np.median(np.abs(VOZ - mediana))
    p25, p75, p99 = np.percentile(VOZ, [25, 75, 99])
    igual(r, {"n": len(VOZ), "media": round(float(VOZ.mean()), 2), "mediana": round(float(mediana), 2),
              "mad": round(float(mad), 2), "sigma_robusta": round(float(1.4826 * mad), 2),
              "p25": round(float(p25), 2), "p75": round(float(p75), 2), "iqr": round(float(p75 - p25), 2),
              "p99": round(float(p99), 2)})
    assert type(r["n"]) is int and type(r["media"]) is float


def prueba_robustez():
    """Un valor extremo mueve la media, no la mediana ni el MAD"""
    con_error = np.append(VOZ, 10_000_000)
    a, b = resumen_robusto(VOZ), resumen_robusto(con_error)
    assert b["media"] > a["media"] * 2
    assert abs(b["mediana"] - a["mediana"]) <= 1 and abs(b["mad"] - a["mad"]) <= 1


def prueba_acepta_series():
    """También funciona con una Serie de Pandas"""
    igual(resumen_robusto(pd.Series([1, 2, 3, 4, 100]))["mediana"], 3.0)


def prueba_bootstrap():
    """El intervalo reproduce el algoritmo indicado"""
    requiere("ic_bootstrap")
    rng = np.random.default_rng(2026)
    medianas = [np.median(rng.choice(VOZ, size=len(VOZ), replace=True)) for _ in range(2000)]
    esperado = tuple(np.percentile(medianas, [2.5, 97.5]))
    r = ic_bootstrap(VOZ, np.median)
    cerca(r[0], esperado[0], 1e-9)
    cerca(r[1], esperado[1], 1e-9)
    assert r[0] <= np.median(VOZ) <= r[1]


def prueba_bootstrap_opciones():
    """Nivel, semilla y otros estadísticos"""
    angosto = ic_bootstrap(VOZ, np.mean, repeticiones=500, nivel=0.5)
    ancho = ic_bootstrap(VOZ, np.mean, repeticiones=500, nivel=0.99)
    assert ancho[0] < angosto[0] < angosto[1] < ancho[1], "Un nivel mayor da un intervalo más ancho"
    igual(ic_bootstrap(VOZ, np.mean, repeticiones=300, semilla=5), ic_bootstrap(VOZ, np.mean, repeticiones=300, semilla=5))
```

## Pista 1

Convierte la entrada a un arreglo de NumPy al principio, así funciona igual con listas y Series: `x = np.asarray(valores, dtype=float)`. Los percentiles de una vez: `p25, p75, p99 = np.percentile(x, [25, 75, 99])`.

## Pista 2

```python

alfa = (1 - nivel) / 2 * 100

```

Devuelve `(float(bajo), float(alto))`.

## Solución

```python
import numpy as np
import pandas as pd


def resumen_robusto(valores):
    x = np.asarray(valores, dtype=float)
    mediana = np.median(x)
    mad = np.median(np.abs(x - mediana))
    p25, p75, p99 = np.percentile(x, [25, 75, 99])
    r = {"media": x.mean(), "mediana": mediana, "mad": mad, "sigma_robusta": 1.4826 * mad,
         "p25": p25, "p75": p75, "iqr": p75 - p25, "p99": p99}
    return {"n": int(len(x)), **{k: round(float(v), 2) for k, v in r.items()}}


def ic_bootstrap(valores, estadistico, repeticiones=2000, semilla=2026, nivel=0.95):
    x = np.asarray(valores)
    rng = np.random.default_rng(semilla)
    resultados = [estadistico(rng.choice(x, size=len(x), replace=True)) for _ in range(repeticiones)]
    alfa = (1 - nivel) / 2 * 100
    bajo, alto = np.percentile(resultados, [alfa, 100 - alfa])
    return float(bajo), float(alto)


cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"].to_numpy()
print(resumen_robusto(voz))
print(ic_bootstrap(voz, np.median))
```

## Explicación

La prueba de robustez lo muestra: agregar **una** llamada de 10 millones de segundos (un error típico de tasación) duplica la media y deja la mediana y el MAD prácticamente iguales. Si tu informe mensual dice "la duración promedio subió 80 %" por un solo registro corrupto, el problema no es la red: es la medida.

`ic_bootstrap` recibe el **estadístico como una función**: sirve igual para la mediana, la media, un percentil (`lambda m: np.percentile(m, 95)`) o una tasa (`lambda m: (m > 600).mean()`). Esa es la gran ventaja del bootstrap: un solo método para cualquier pregunta.

La **semilla** fija los números aleatorios: el mismo intervalo cada vez que corres el análisis. En un informe, esto es lo que permite que otra persona reproduzca exactamente tus números.
