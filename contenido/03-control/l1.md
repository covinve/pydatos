Las reglas de facturación están llenas de condiciones: *si* el plan es ilimitado no se cobra exceso; *si* la llamada es internacional usa otra tarifa; *si* es de noche hay descuento. En Python, las decisiones se escriben con `if`.

## if, elif, else

```pyrun
destino = "NACIONAL"

if destino == "LOCAL":
    tarifa = 100
elif destino == "NACIONAL":
    tarifa = 120
elif destino == "INTERNACIONAL":
    tarifa = 950
else:
    tarifa = None

print(f"Tarifa para {destino}: {tarifa}")
```

- `if` evalúa la condición; si es verdadera, ejecuta su bloque y **salta todo lo demás**.
- `elif` ("si no, si…") se revisa solo si las anteriores fueron falsas.
- `else` atrapa todo lo que no cumplió ninguna condición. Es opcional.
- El bloque se define por la **sangría de 4 espacios**: no hay llaves ni `end`.

Sigue el camino que toma el programa:

```pytrace
minutos_usados = 342
minutos_incluidos = 300
tarifa = 120

if minutos_incluidos == -1:
    valor_voz = 0
elif minutos_usados > minutos_incluidos:
    valor_voz = (minutos_usados - minutos_incluidos) * tarifa
else:
    valor_voz = 0

print(valor_voz)
```

:::error El orden de los elif importa
Python se queda con la **primera** condición verdadera. Este código nunca da descuento a los clientes de más de 10 años, porque la primera condición ya los atrapó:

```python
if antiguedad >= 3:
    descuento = 0.10
elif antiguedad >= 10:      # nunca llega aquí con antigüedad 12
    descuento = 0.20
```

Ordena las condiciones de la más específica a la más general.
:::

## Condiciones compuestas y anidadas

```pyrun
segmento = "EMPRESARIAL"
anio_alta = 2021
cargo_fijo = 79900

if segmento == "EMPRESARIAL" and anio_alta < 2023:
    descuento = round(cargo_fijo * 0.10)
else:
    descuento = 0

print(descuento)
```

Puedes anidar un `if` dentro de otro, pero con más de dos niveles el código se vuelve difícil de leer. Una técnica para aplanarlo es la **salida temprana** dentro de las funciones:

:::comparar
:::mal Anidado
```python
def valor_voz(minutos, incluidos, tarifa):
    if incluidos != -1:
        if minutos > incluidos:
            return (minutos - incluidos) * tarifa
        else:
            return 0
    else:
        return 0
```
:::
:::bien Salida temprana
```python
def valor_voz(minutos, incluidos, tarifa):
    if incluidos == -1:
        return 0                     # ilimitado
    exceso = max(0, minutos - incluidos)
    return exceso * tarifa
```
:::
:::

Primero se descartan los casos especiales con `return`, y lo que queda es el caso normal, sin sangría extra.

- si `mb_incluidas` es `-1`, el plan es ilimitado y el valor es `0`;
- si no, se cobra el exceso (nunca negativo) por la tarifa.

```pyreto
def valor_datos(mb_usadas, mb_incluidas, tarifa_mb):
    # 1. Caso especial: plan ilimitado
    # 2. Caso normal: exceso por tarifa
    pass


print(valor_datos(15500, 15360, 18))   # 2520
print(valor_datos(800, 15360, 18))     # 0

```

:::pista
Igual que el ejemplo de la voz: `if mb_incluidas == -1: return 0`, y después `exceso = max(0, mb_usadas - mb_incluidas)` y `return exceso * tarifa_mb`.
:::

```pyprueba
def prueba_con_exceso():
    """Cobra el exceso por la tarifa"""
    requiere("valor_datos")
    igual(valor_datos(15500, 15360, 18), 2520)

    """Sin exceso, el valor es 0 (no negativo)"""
    igual(valor_datos(800, 15360, 18), 0)


def prueba_ilimitado():
    """Plan ilimitado (-1) → 0"""
    igual(valor_datos(99999, -1, 18), 0)
    igual(valor_datos(0, -1, 18), 0)
```

```pysolucion
def valor_datos(mb_usadas, mb_incluidas, tarifa_mb):
    if mb_incluidas == -1:
        return 0
    exceso = max(0, mb_usadas - mb_incluidas)
    return exceso * tarifa_mb

print(valor_datos(800, 15360, 18))     # 0
print(valor_datos(99999, -1, 18))      # 0
```

## La expresión condicional

Para elegir entre dos valores en una sola línea:

```pyrun
duracion = 0
estado = "no contestada" if duracion == 0 else "contestada"
print(estado)
```

Úsala solo para decisiones cortas. Si necesitas más de dos opciones, vuelve al `if` normal.

:::reto En una sola línea
Escribe `tipo_cliente(lineas)` que devuelva `"multilínea"` si el cliente tiene más de una línea y `"individual"` si tiene una sola. El cuerpo de la función debe ser **una sola línea** con la expresión condicional.

```pyreto
def tipo_cliente(lineas):
    pass


print(tipo_cliente(3))   # multilínea
print(tipo_cliente(1))   # individual
```

:::pista
La forma es `valor_si_verdadero if condicion else valor_si_falso`: `return "multilínea" if lineas > 1 else "individual"`.
:::

```pyprueba
import ast


def prueba_resultado():
    """Clasifica según la cantidad de líneas"""
    requiere("tipo_cliente")
    igual(tipo_cliente(3), "multilínea", "3 líneas")
    igual(tipo_cliente(2), "multilínea", "2 líneas")
    igual(tipo_cliente(1), "individual", "1 línea")


def prueba_una_linea():
    """Usa la expresión condicional en una sola línea"""
    funcion = next(n for n in ast.walk(ast.parse(codigo)) if isinstance(n, ast.FunctionDef) and n.name == "tipo_cliente")
    cuerpo = funcion.body
    assert len(cuerpo) == 1 and isinstance(cuerpo[0], ast.Return) and isinstance(cuerpo[0].value, ast.IfExp), "Escribe el cuerpo como: return ... if ... else ..."
```

```pysolucion
def tipo_cliente(lineas):
    return "multilínea" if lineas > 1 else "individual"


print(tipo_cliente(3))   # multilínea
print(tipo_cliente(1))   # individual
```
:::

## match: elegir según un valor

Desde Python 3.10, `match` compara un valor contra varios **patrones**. Es ideal cuando la decisión depende de un solo valor con muchas opciones:

```pyrun
def tarifa_por_destino(destino):
    match destino:
        case "LOCAL":
            return 100
        case "NACIONAL":
            return 120
        case "INTERNACIONAL":
            return 950
        case _:
            return None    # _ atrapa cualquier otro valor


for d in ["LOCAL", "INTERNACIONAL", "SATELITAL"]:
    print(d, tarifa_por_destino(d))
```

Un `case` puede aceptar varias opciones con `|`:

```pyrun
def familia(tipo):
    match tipo:
        case "VOZ" | "SMS":
            return "comunicación"
        case "DATOS":
            return "navegación"
        case _:
            return "desconocido"


print(familia("SMS"), familia("DATOS"), familia("VOX"))
```

:::reto El segmento de cada plan
Con `match`, escribe `segmento(plan_id)`:

| Planes | Devuelve |
|---|---|
| `"BAS10"`, `"HOG30"`, `"HOG60"`, `"ILIM"` | `"RESIDENCIAL"` |
| `"EMP100"`, `"EMP300"` | `"EMPRESARIAL"` |
| cualquier otro | `"DESCONOCIDO"` |

```pyreto
def segmento(plan_id):
    # Usa match/case y agrupa los planes con |
    pass


print(segmento("HOG30"), segmento("EMP300"), segmento("XYZ"))
```

:::pista
Un solo `case` acepta varias opciones: `case "BAS10" | "HOG30" | "HOG60" | "ILIM":`. No olvides el `case _:` para los demás.
:::

```pyprueba
def prueba_residencial():
    """Los planes de hogar son RESIDENCIAL"""
    requiere("segmento")
    for plan in ("BAS10", "HOG30", "HOG60", "ILIM"):
        igual(segmento(plan), "RESIDENCIAL", plan)


def prueba_empresarial():
    """Los planes EMP son EMPRESARIAL"""
    for plan in ("EMP100", "EMP300"):
        igual(segmento(plan), "EMPRESARIAL", plan)


def prueba_desconocido():
    """Cualquier otro plan es DESCONOCIDO"""
    igual(segmento("XYZ"), "DESCONOCIDO", "XYZ")
    igual(segmento(""), "DESCONOCIDO", "texto vacío")


def prueba_usa_match():
    """Usa match/case"""
    assert "match " in codigo and "case " in codigo, "Resuélvelo con match y case"
```

```pysolucion
def segmento(plan_id):
    match plan_id:
        case "BAS10" | "HOG30" | "HOG60" | "ILIM":
            return "RESIDENCIAL"
        case "EMP100" | "EMP300":
            return "EMPRESARIAL"
        case _:
            return "DESCONOCIDO"


print(segmento("HOG30"), segmento("EMP300"), segmento("XYZ"))
```
:::

:::telco Reglas de negocio legibles
Una regla como "el exceso de voz es 0 si el plan es ilimitado" debería poder leerse en el código casi palabra por palabra. Cuando auditoría pregunte por qué se cobró un valor, quieres poder mostrarles la línea exacta que lo decide.
:::

## Cuestionario

? ¿Qué imprime este código si `minutos = 300` y `incluidos = 300`? `if minutos > incluidos: print("exceso") elif minutos == incluidos: print("justo") else: print("sobran")`
- [ ] `exceso`
- [x] `justo`
- [ ] `sobran`
- [ ] `justo` y `sobran`
> La primera condición es falsa (300 no es mayor que 300) y la segunda es verdadera. Solo se ejecuta un bloque.

? ¿Para qué sirve `case _:` en un `match`?
- [ ] Para el valor `None`
- [ ] Para el texto vacío
- [x] Para cualquier valor que no coincidió con los casos anteriores
- [ ] Para detener el programa
> `_` es el comodín: funciona como el `else` del `match`.

? ¿Qué valor queda en `x`? `x = "A" if 5 > 10 else "B"`
- [ ] `"A"`
- [x] `"B"`
- [ ] `True`
- [ ] `None`
> La condición `5 > 10` es falsa, así que se elige el valor después de `else`.
