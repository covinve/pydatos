## Enunciado

Reescribe la tarificación con NumPy, **sin `for` ni comprensiones**:

1. `minutos_facturables(duraciones)` → array con los minutos de cada llamada (redondeo hacia arriba).
2. `valores(duraciones, tarifa)` → array con el valor de cada llamada.
3. `total(duraciones, tarifa)` → el total como `int` de Python.

```python
d = np.array([125, 0, 61, 3600])
minutos_facturables(d)    # array([ 3,  0,  2, 60])
valores(d, 120)           # array([ 360,    0,  240, 7200])
total(d, 120)             # 7800
```

## Pista 1

Las operaciones aritméticas se aplican a todo el array: `(duraciones + 59) // 60` funciona igual que con un número.

## Pista 2

`array.sum()` devuelve un número de NumPy (`np.int64`). Conviértelo con `int(...)` para devolver un entero de Python.

## Solución

```python
import numpy as np


def minutos_facturables(duraciones):
    return (duraciones + 59) // 60


def valores(duraciones, tarifa):
    return minutos_facturables(duraciones) * tarifa


def total(duraciones, tarifa):
    return int(valores(duraciones, tarifa).sum())


d = np.array([125, 0, 61, 3600])
print(minutos_facturables(d), total(d, 120))
```

## Explicación

El código es casi idéntico a la versión de Python puro del módulo 1, pero ahora cada operación procesa **todas** las llamadas de una vez. Con un millón de valores, la diferencia es de cientos de milisegundos a pocos milisegundos.

Convertir el resultado final a `int` es una buena costumbre: los tipos de NumPy (`np.int64`) se comportan casi igual, pero no se pueden guardar directamente en JSON y a veces confunden a otras librerías.
