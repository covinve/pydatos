## Enunciado

Escribe `estadisticas(duraciones)` que, considerando solo las llamadas **contestadas** (duración > 0), devuelva un diccionario con estos valores en segundos, redondeados a 1 decimal y como `float` de Python:

`"cantidad"` (int), `"promedio"`, `"mediana"`, `"desviacion"`, `"p95"` (percentil 95), `"maximo"`.

Si no hay llamadas contestadas, devuelve `{"cantidad": 0}`.

```python
estadisticas(np.array([125, 0, 61, 3600, 45, 300, 15]))
# {"cantidad": 6, "promedio": 691.0, "mediana": 93.0, "desviacion": 1304.3, "p95": 2775.0, "maximo": 3600.0}
```

## Pista 1

Filtra primero: `contestadas = duraciones[duraciones > 0]`. Luego usa `.mean()`, `np.median`, `.std()`, `np.percentile(contestadas, 95)` y `.max()`.

## Pista 2

Convierte cada resultado: `round(float(valor), 1)`. Para no repetir, puedes construir el diccionario a partir de pares `(nombre, valor)`.

## Solución

```python
import numpy as np


def estadisticas(duraciones):
    contestadas = duraciones[duraciones > 0]
    if contestadas.size == 0:
        return {"cantidad": 0}
    valores = {
        "promedio": contestadas.mean(),
        "mediana": np.median(contestadas),
        "desviacion": contestadas.std(),
        "p95": np.percentile(contestadas, 95),
        "maximo": contestadas.max(),
    }
    return {"cantidad": int(contestadas.size), **{k: round(float(v), 1) for k, v in valores.items()}}


print(estadisticas(np.array([125, 0, 61, 3600, 45, 300, 15])))
```

## Explicación

El promedio (691 s) y la mediana (93 s) cuentan historias muy distintas: una sola llamada de una hora arrastra el promedio hacia arriba. En consumo telco, la mayoría de las distribuciones tienen **cola larga** (muchas llamadas cortas y pocas muy largas), por eso la mediana y los percentiles describen mejor el comportamiento típico. Lo verás a fondo en el módulo 15.

`.std()` calcula la desviación **poblacional** (divide entre `n`). Si trabajas con una muestra y quieres la desviación muestral, usa `.std(ddof=1)`.
