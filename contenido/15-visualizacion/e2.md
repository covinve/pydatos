## Solución

```python
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)


def grafico_diario(cdr):
    inicio = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    por_dia = cdr.assign(inicio=inicio).dropna(subset=["inicio"]).set_index("inicio").resample("D").size()
    fig, ax = plt.subplots(figsize=(8, 3))
    ax.plot(por_dia.index, por_dia.values, color="#16a34a", marker="o", markersize=3, label="Registros")
    ax.plot(por_dia.index, por_dia.rolling(7).mean().values, color="#334155", linestyle="--", label="Media móvil 7 días")
    ax.set_title("Registros por día")
    ax.set_ylim(bottom=0)
    ax.legend()
    ax.grid(alpha=0.3)
    fig.autofmt_xdate()
    return fig


fig = grafico_diario(cdr)
```

## Explicación

La media móvil suaviza el ruido diario y deja ver la tendencia; la línea original muestra los días puntuales que se salen de lo normal. Juntas responden dos preguntas a la vez: "¿hacia dónde va?" y "¿qué día fue raro?".

`fig.autofmt_xdate()` inclina las fechas del eje X para que no se monten unas sobre otras. Empezar el eje Y en 0 evita exagerar variaciones pequeñas, aunque en gráficos de líneas no es obligatorio: decide según lo que quieras mostrar.
