## Enunciado

Implementa el patrón bandeja de entrada. `procesar_bandeja(base)` trabaja dentro de la carpeta `base`, que tiene `entrada/`:

1. Toma, en orden alfabético, los archivos de `entrada/` cuyo nombre cumple `cdr_AAAAMMDD.csv` (otros archivos se dejan donde están).
2. Para cada uno, cuenta las filas de datos (sin la cabecera) y suma la columna `duracion_seg` (separador `|`).
3. Si se pudo leer, lo **mueve** a `procesados/` y agrega al resultado `{"archivo", "filas", "segundos"}`.
4. Si falla (por ejemplo, una duración que no es número), lo mueve a `errores/` y agrega `{"archivo", "error"}` con el mensaje de la excepción. **Un archivo malo no detiene a los demás.**
5. Crea las carpetas `procesados/` y `errores/` si no existen, y devuelve `{"procesados": [...], "errores": [...]}`.

Ejecutar dos veces seguidas no debe procesar nada la segunda vez.

## Solución

```python
import re
import shutil
from pathlib import Path

PATRON = re.compile(r"cdr_\d{8}\.csv")


def _leer(archivo):
    lineas = archivo.read_text(encoding="utf-8").splitlines()
    columnas = lineas[0].split("|")
    posicion = columnas.index("duracion_seg")
    segundos = sum(int(linea.split("|")[posicion]) for linea in lineas[1:] if linea)
    return len([l for l in lineas[1:] if l]), segundos


def procesar_bandeja(base):
    base = Path(base)
    procesados, errores = base / "procesados", base / "errores"
    procesados.mkdir(exist_ok=True)
    errores.mkdir(exist_ok=True)
    resultado = {"procesados": [], "errores": []}
    archivos = sorted(a for a in (base / "entrada").iterdir() if a.is_file() and PATRON.fullmatch(a.name))
    for archivo in archivos:
        try:
            filas, segundos = _leer(archivo)
        except Exception as e:
            shutil.move(archivo, errores / archivo.name)
            resultado["errores"].append({"archivo": archivo.name, "error": str(e)})
            continue
        shutil.move(archivo, procesados / archivo.name)
        resultado["procesados"].append({"archivo": archivo.name, "filas": filas, "segundos": segundos})
    return resultado
```

## Explicación

Tres decisiones hacen robusto este proceso:

- **Filtrar por patrón exacto**: solo se toca lo que es claramente un CDR. Un `.tmp` (un archivo que todavía se está copiando) o un `LEAME.txt` no se procesan por accidente.
- **Aislar los errores por archivo**: atrapar `Exception` es normalmente mala idea (módulo 7), pero en el ciclo principal de un proceso por lotes es justo lo correcto, siempre que **registres** el error y apartes el archivo. El resto del día se procesa igual.
- **Mover al terminar**: la carpeta `entrada/` funciona como lista de pendientes. Si el proceso se cae, lo que quedó en `entrada/` es exactamente lo que falta.

En la versión real, el `error` iría también al registro con `logging.exception`, y podrías mover a `procesados/2026-09-02/` para no tener miles de archivos en una carpeta.
