## Enunciado

En el módulo 3 encontraste, para **un** cliente, la llamada que agotó su bolsa. Ahora hazlo para **todos los clientes a la vez**, sin bucles sobre los registros.

Recibes arrays paralelos (en cualquier orden): `lineas`, `inicios` (segundo del mes en que empezó la llamada) y `duraciones` (segundos). Todos los clientes tienen la misma bolsa de `incluidos` minutos.

Escribe `analizar_bolsas(lineas, inicios, duraciones, incluidos)` que devuelva un diccionario `linea → {"agota_en": posicion, "exceso": minutos}`:

- `agota_en`: la **posición en los arrays originales** de la primera llamada (en orden cronológico de esa línea) con la que el acumulado de minutos **supera** `incluidos`; `None` si nunca lo supera.
- `exceso`: minutos usados por encima de lo incluido (`max(0, total - incluidos)`), como `int`.

Las líneas del diccionario van ordenadas.

## Código inicial

```python
import numpy as np


def analizar_bolsas(lineas, inicios, duraciones, incluidos):
    pass


lineas = np.array(["3002", "3001", "3001", "3002", "3001"])
```

## Pista 1

1. Ordena por línea y luego por inicio: `orden = np.lexsort((inicios, lineas))`.
2. Con los datos ordenados, calcula los minutos y el acumulado **por grupo**: el acumulado global menos el acumulado al inicio de cada grupo.

```python
lin = lineas[orden]
minutos = (duraciones[orden] + 59) // 60
unicas, inicio_grupo, grupo = np.unique(lin, return_index=True, return_inverse=True)
acumulado = np.cumsum(minutos)
antes_del_grupo = acumulado[inicio_grupo] - minutos[inicio_grupo]
acumulado_grupo = acumulado - antes_del_grupo[grupo]
```

## Pista 2

Las posiciones (ordenadas) donde se supera la bolsa son `supera = acumulado_grupo > incluidos`. La **primera** de cada grupo se obtiene con `np.unique(grupo[supera], return_index=True)`, que da el índice de la primera aparición de cada grupo en ese subconjunto. Traduce esa posición ordenada a la original con `orden[...]`.

El total por grupo es el acumulado en la **última** posición de cada grupo (o `np.bincount(grupo, weights=minutos)`).

## Solución

```python
import numpy as np


def analizar_bolsas(lineas, inicios, duraciones, incluidos):
    orden = np.lexsort((inicios, lineas))
    lin = lineas[orden]
    minutos = (duraciones[orden] + 59) // 60
    unicas, inicio_grupo, grupo = np.unique(lin, return_index=True, return_inverse=True)
    acumulado = np.cumsum(minutos)
    antes_del_grupo = acumulado[inicio_grupo] - minutos[inicio_grupo]
    acumulado_grupo = acumulado - antes_del_grupo[grupo]

    total = np.bincount(grupo, weights=minutos).astype(np.int64)
    exceso = np.maximum(total - incluidos, 0)

    posiciones_supera = np.where(acumulado_grupo > incluidos)[0]
    grupos_que_superan, primera = np.unique(grupo[posiciones_supera], return_index=True)
    agota = np.full(len(unicas), -1)
    agota[grupos_que_superan] = orden[posiciones_supera[primera]]

    return {
        linea: {"agota_en": None if a < 0 else int(a), "exceso": int(e)}
        for linea, a, e in zip(unicas.tolist(), agota, exceso)
    }


lineas = np.array(["3002", "3001", "3001", "3002", "3001"])
inicios = np.array([50, 10, 5, 20, 30])
duraciones = np.array([600, 3600, 125, 61, 61])
print(analizar_bolsas(lineas, inicios, duraciones, 60))
```

## Explicación

Este es el patrón más importante del cálculo vectorizado con grupos: **ordenar por grupo y después operar sobre bloques contiguos**.

1. `lexsort` deja cada línea en un bloque, en orden cronológico.
2. `cumsum` acumula todo de corrido; restando el acumulado previo a cada bloque se obtiene un acumulado que "reinicia" en cada línea.
3. `np.unique(..., return_index=True)` sobre las posiciones que superan la bolsa da la **primera** de cada grupo.
4. `orden[...]` traduce posiciones del arreglo ordenado a posiciones originales.

La prueba compara contra una versión con bucles, clara pero lenta, sobre datos aleatorios. Es una técnica muy útil: cuando escribas una versión optimizada y difícil de leer, **pruébala contra una versión simple y obviamente correcta**.

El único `for` de la solución recorre las líneas distintas para armar el diccionario de salida, no los millones de registros.
