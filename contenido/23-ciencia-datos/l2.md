Una **anomalía** es un dato que no se parece a los demás. En facturación, las anomalías importan por dos razones: pueden ser **errores** (de tasación, de carga, de facturación) o **fraude** (un SIM clonado que llama al extranjero toda la noche). En ambos casos, hay dinero en juego.

## Tres reglas sencillas

| Método | Marca como anómalo | Bueno para |
|---|---|---|
| **z-score** | `|x − media| / desviación > 3` | Datos simétricos, sin atípicos que contaminen la media |
| **z robusto** | `0.6745 · |x − mediana| / MAD > 3.5` | Datos sesgados o con atípicos (consumos) |
| **Cercas de Tukey** | `x < p25 − 1.5·IQR` o `x > p75 + 1.5·IQR` | Lo mismo que muestra un diagrama de caja |

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"})
mb = cdr[cdr["tipo"] == "DATOS"].groupby("linea_origen")["mb"].sum()

z = (mb - mb.mean()) / mb.std()
mediana = mb.median()
mad = (mb - mediana).abs().median()
z_robusto = 0.6745 * (mb - mediana) / mad
p25, p75 = mb.quantile([0.25, 0.75])
tukey = mb > p75 + 1.5 * (p75 - p25)

print(f"z > 3:          {(z.abs() > 3).sum()} líneas")
print(f"z robusto > 3.5: {(z_robusto.abs() > 3.5).sum()} líneas")
print(f"Tukey:          {tukey.sum()} líneas")
print(z_robusto.sort_values(ascending=False).head())
```

El z clásico suele marcar **menos**: los propios atípicos inflan la desviación estándar y se "esconden". Ese efecto se llama **enmascaramiento**.

## Comparar contra el propio grupo

Un cliente del plan ilimitado que consume 300 GB es normal; uno del plan básico, no. Las anomalías se buscan **dentro de grupos comparables**: por plan, por segmento, por día de la semana, por hora.

```python
def z_robusto(serie):
    mediana = serie.median()
    mad = (serie - serie.median()).abs().median()
    return 0.6745 * (serie - mediana) / mad if mad else serie * 0

consumo["z"] = consumo.groupby("plan_id")["mb"].transform(z_robusto)
```

Lo mismo en el tiempo: el tráfico de un lunes se compara con otros lunes, no con un domingo.

## Varias variables: Isolation Forest

Una línea puede ser normal en cada variable por separado y rara en la **combinación** (pocas llamadas, pero todas internacionales y de madrugada). **Isolation Forest** (de scikit-learn) busca puntos fáciles de **aislar**: corta los datos al azar una y otra vez; los puntos raros quedan solos con pocos cortes.

```python
from sklearn.ensemble import IsolationForest

X = caracteristicas[["llamadas", "minutos", "pct_internacional", "pct_nocturno", "mb"]]
modelo = IsolationForest(n_estimators=300, contamination=0.01, random_state=0).fit(X)
caracteristicas["puntaje"] = -modelo.score_samples(X)        # más alto = más anómalo
sospechosas = caracteristicas.nlargest(20, "puntaje")
```

`contamination` es la proporción esperada de anomalías: define el umbral de `predict`, pero el **puntaje** permite ordenar y revisar las más raras primero, que es lo útil en la práctica.

:::reto La SIM clonada
En `lineas` hay 300 líneas simuladas y una plantada, `SIM-CLONADA`: hace menos llamadas que el promedio, pero casi todas internacionales y de madrugada, el patrón típico de un SIM clonado. Encuéntrala con `IsolationForest` (`n_estimators=300`, `random_state=0`), mirando las tres variables a la vez:

1. Entrena con las columnas de `CARACTERISTICAS`.
2. Agrega la columna `puntaje` (más alto = más anómalo, con `-modelo.score_samples(...)`).
3. Crea `top5`: la lista de las 5 líneas con mayor puntaje.

```pyreto

lineas.loc[len(lineas)] = ["SIM-CLONADA", 45, 0.9, 0.85]
```

```pysolucion
import numpy as np
import pandas as pd
from sklearn.ensemble import IsolationForest

rng = np.random.default_rng(0)
lineas = pd.DataFrame({
    "linea": [f"L{i:03d}" for i in range(300)],
    "llamadas": rng.poisson(60, 300),
    "pct_internacional": rng.beta(1, 30, 300),
    "pct_nocturno": rng.beta(2, 12, 300),
})
lineas.loc[len(lineas)] = ["SIM-CLONADA", 45, 0.9, 0.85]
CARACTERISTICAS = ["llamadas", "pct_internacional", "pct_nocturno"]

modelo = IsolationForest(n_estimators=300, random_state=0).fit(lineas[CARACTERISTICAS])
lineas["puntaje"] = -modelo.score_samples(lineas[CARACTERISTICAS])
top5 = lineas.nlargest(5, "puntaje")["linea"].tolist()

print(top5)
```

## Aseguramiento de ingresos (*revenue assurance*)

Una **fuga de ingresos** es un servicio que se prestó y no se cobró (o se cobró de menos). Las telcos tienen áreas dedicadas a encontrarlas, porque típicamente se pierde entre el 1 % y el 3 % de los ingresos.

:::pasos Dónde se pierde el dinero
:::paso Red → mediación
CDR que la red generó pero no llegaron a la mediación (archivos perdidos, registros descartados por formato). Control: comparar conteos por conmutador y por hora entre sistemas.
:::
:::paso Mediación → tasación
CDR rechazados que nadie reprocesa, líneas desconocidas que en realidad eran clientes nuevos. Control: seguimiento de rechazos (tu validador) y su antigüedad.
:::
:::paso Tasación → facturación
Tarifas mal configuradas, planes mal asignados, descuentos aplicados de más. Control: **recalcular** independientemente y conciliar (tu proyecto 2).
:::
:::paso Facturación → cobro
Facturas emitidas que no se cobran. Control: cartera y suspensiones (módulo 19).
:::
:::

Las anomalías complementan la conciliación: la conciliación encuentra diferencias **contra una regla** conocida; las anomalías encuentran comportamientos **raros** que ninguna regla anticipó.
