## Enunciado

Resuelve cada función con la herramienta de `itertools` indicada (sin construir listas intermedias):

1. `primeras(registros, n)` → lista con los `n` primeros registros (`islice`).
2. `todos(*fuentes)` → un iterador con los registros de todas las fuentes, en orden (`chain`).
3. `contar_lotes(registros, tamano)` → cuántos lotes de `tamano` se forman (`batched`; el último puede ser incompleto).
4. `consumo_acumulado(minutos)` → lista con el consumo acumulado tras cada llamada (`accumulate`).
5. `gaps(inicios)` → lista con la diferencia entre cada inicio y el anterior (`pairwise`).

```python
primeras(range(100), 3)               # [0, 1, 2]
list(todos([1, 2], (3,), range(4, 6)))  # [1, 2, 3, 4, 5]
contar_lotes(range(10), 4)            # 3
consumo_acumulado([3, 0, 2])          # [3, 3, 5]
gaps([100, 160, 175])                 # [60, 15]
```

## Pruebas

```python
def prueba_primeras():
    """islice: los primeros n"""
    igual(primeras(range(100), 3), [0, 1, 2])
    igual(primeras(iter([5]), 3), [5])


def prueba_primeras_de_un_infinito():
    """Funciona con un generador infinito"""
    def contador():
        n = 0
        while True:
            yield n
            n += 1
    igual(primeras(contador(), 4), [0, 1, 2, 3])


def prueba_todos():
    """chain: une fuentes en orden"""
    igual(list(todos([1, 2], (3,), range(4, 6))), [1, 2, 3, 4, 5])
    igual(list(todos()), [])


def prueba_contar_lotes():
    """batched: cuenta lotes, incluido el incompleto"""
    igual(contar_lotes(range(10), 4), 3)
    igual(contar_lotes(range(8), 4), 2)
    igual(contar_lotes([], 4), 0)


def prueba_acumulado():
    """accumulate: totales acumulados"""
    igual(consumo_acumulado([3, 0, 2, 60]), [3, 3, 5, 65])


def prueba_gaps():
    """pairwise: diferencias consecutivas"""
    igual(gaps([100, 160, 175, 900]), [60, 15, 725])
    igual(gaps([5]), [])
```

## Pista 1

`islice` y `accumulate` devuelven iteradores: envuélvelos en `list(...)` cuando la función debe devolver una lista. `chain(*fuentes)` desempaqueta la tupla de fuentes.

## Pista 2

Para contar lotes sin guardarlos: `sum(1 for _ in batched(registros, tamano))`. Para los gaps: `[b - a for a, b in pairwise(inicios)]`.

## Solución

```python
from itertools import accumulate, batched, chain, islice, pairwise


def primeras(registros, n):
    return list(islice(registros, n))


def todos(*fuentes):
    return chain(*fuentes)


def contar_lotes(registros, tamano):
    return sum(1 for _ in batched(registros, tamano))


def consumo_acumulado(minutos):
    return list(accumulate(minutos))


def gaps(inicios):
    return [b - a for a, b in pairwise(inicios)]
```

## Explicación

Cada función es una línea porque `itertools` ya resuelve el patrón. Fíjate que `todos` devuelve el `chain` sin convertirlo a lista: así quien lo usa decide si lo recorre de a uno (sin memoria) o lo convierte.

`sum(1 for _ in ...)` es la forma idiomática de **contar** los elementos de un iterador sin guardarlos.
