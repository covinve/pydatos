## Enunciado

En el módulo 2 escribiste una función por campo para leer el ancho fijo. Ahora vas a guardar el **diseño del registro** en un diccionario y escribir **una sola función** que lea cualquier diseño:

```python
DISENO_CDR = {
    "cdr_id":       (1, 12, int),
    "linea_origen": (13, 22, str),
    "tipo":         (36, 40, str),
    "destino":      (41, 53, str),
    "duracion_seg": (68, 73, int),
    "mb":           (74, 83, float),
}
```

Cada campo tiene `(posición_inicial, posición_final, tipo)`, con posiciones **desde 1 e incluidas**, como en el documento del archivo. El tipo es la **función** de conversión (`int`, `str` o `float`).

Escribe `leer_registro(registro, diseno)` que devuelva un diccionario con cada campo **sin espacios sobrantes** y convertido a su tipo:

```python
leer_registro(REGISTRO, DISENO_CDR)
# {"cdr_id": 2, "linea_origen": "3302703263", "tipo": "VOZ",
#  "destino": "NACIONAL", "duracion_seg": 30, "mb": 0.0}
```

La función debe servir para **cualquier** diseño, con cualquier cantidad de campos.

## Pruebas

```python
DISENO = {
    "cdr_id": (1, 12, int),
    "linea_origen": (13, 22, str),
    "tipo": (36, 40, str),
    "destino": (41, 53, str),
    "duracion_seg": (68, 73, int),
    "mb": (74, 83, float),
}
VOZ = "00000000000233027032633040879936   VOZ  NACIONAL     20260913103128000030000000.000CEL97932"
DATOS = "0000000000023267999245             DATOS             20260914085504001856000026.274CEL59973"


def prueba_registro_voz():
    """Lee todos los campos de un registro de voz"""
    requiere("leer_registro")
    igual(leer_registro(VOZ, DISENO), {
        "cdr_id": 2, "linea_origen": "3302703263", "tipo": "VOZ",
        "destino": "NACIONAL", "duracion_seg": 30, "mb": 0.0,
    })


def prueba_registro_datos():
    """En DATOS el destino queda vacío y las megas son float"""
    r = leer_registro(DATOS, DISENO)
    igual(r["destino"], "")
    igual(r["tipo"], "DATOS")
    cerca(r["mb"], 26.274)
    igual(r["duracion_seg"], 1856)


def prueba_tipos():
    """Cada valor tiene el tipo indicado en el diseño"""
    r = leer_registro(VOZ, DISENO)
    assert isinstance(r["cdr_id"], int) and isinstance(r["mb"], float) and isinstance(r["tipo"], str)


def prueba_otro_diseno():
    """Funciona con cualquier diseño"""
    diseno = {"anio": (1, 4, int), "mes": (5, 6, int), "nombre": (7, 16, str)}
    igual(leer_registro("202609Ana       ", diseno), {"anio": 2026, "mes": 9, "nombre": "Ana"})


def prueba_conserva_orden_del_diseno():
    """Las claves aparecen en el mismo orden del diseño"""
    igual(list(leer_registro(VOZ, DISENO)), list(DISENO))
```

## Pista 1

Recorre el diseño con `.items()` y desempaqueta la tupla de cada campo:

```python
resultado = {}
for campo, (inicio, fin, tipo) in diseno.items():
    ...
return resultado
```

El slicing para posiciones del documento es `registro[inicio - 1:fin]`.

## Pista 2

`tipo` es una función: puedes llamarla como cualquier otra. `tipo("000030")` es lo mismo que `int("000030")` cuando `tipo` es `int`:

```python
texto = registro[inicio - 1:fin].strip()
resultado[campo] = tipo(texto)
```

## Solución

```python
DISENO_CDR = {
    "cdr_id": (1, 12, int),
    "linea_origen": (13, 22, str),
    "tipo": (36, 40, str),
    "destino": (41, 53, str),
    "duracion_seg": (68, 73, int),
    "mb": (74, 83, float),
}

REGISTRO = "00000000000233027032633040879936   VOZ  NACIONAL     20260913103128000030000000.000CEL97932"


def leer_registro(registro, diseno):
    return {
        campo: tipo(registro[inicio - 1:fin].strip())
        for campo, (inicio, fin, tipo) in diseno.items()
    }


print(leer_registro(REGISTRO, DISENO_CDR))
```

## Explicación

Este ejercicio muestra dos ideas muy poderosas:

1. **Las funciones son valores.** `int`, `str` y `float` se pueden guardar en un diccionario y llamar después. Por eso el diseño puede decir *cómo* convertir cada campo.
2. **Configuración como datos.** Toda la información del archivo (posiciones y tipos) vive en `DISENO_CDR`. Si el proveedor agrega un campo o mueve una posición, cambias el diccionario y el código sigue igual. Si recibes un segundo formato de archivo, solo escribes otro diseño.

La solución usa una **comprensión de diccionario** con desempaquetado anidado: `for campo, (inicio, fin, tipo) in ...`. Un bucle normal con `resultado[campo] = ...` es igual de correcto.
