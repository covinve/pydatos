## Enunciado

El CRM tiene clientes registrados dos veces con pequeñas diferencias: tildes, mayúsculas, espacios, puntos en el documento. Escribe, con métodos `.str` vectorizados:

1. `normalizar_texto(serie)` → minúsculas, sin tildes (usa `unicodedata.normalize("NFKD", ...)` y descarta los caracteres combinantes), sin signos de puntuación (`. , - &`), y con espacios simples entre palabras, sin espacios a los lados.
2. `normalizar_documento(serie)` → solo los dígitos del documento (sin puntos, guiones ni espacios).
3. `posibles_duplicados(clientes)` → DataFrame con las columnas `cliente_id`, `documento_normalizado`, `nombre_normalizado` y `grupo`, solo de los clientes cuyo **documento normalizado** aparece más de una vez. `grupo` numera cada documento repetido empezando en 1, en orden de documento. Ordena por `grupo` y luego por `cliente_id`.

## Pista 1

Quitar tildes de forma vectorizada:

```python
sin_tildes = serie.str.normalize("NFKD").str.encode("ascii", errors="ignore").str.decode("ascii")
```

`NFKD` separa `"é"` en `"e"` + el acento; al codificar a ASCII ignorando errores, el acento desaparece. Luego `.str.lower()`, `.str.replace(r"[.,&-]", "", regex=True)` y `.str.replace(r"\s+", " ", regex=True).str.strip()`.

## Pista 2

- Documento: `.str.replace(r"\D", "", regex=True)` borra todo lo que no es dígito.
- Repetidos: `doc.duplicated(keep=False)` marca **todas** las apariciones.
- Grupo: `pd.factorize(...)` sobre los documentos repetidos **ordenados** numera desde 0; suma 1.

## Solución

```python
import unicodedata

import pandas as pd

clientes = pd.read_csv("crm.csv", dtype=str)


def normalizar_texto(serie):
    return (
        serie.str.normalize("NFKD")
        .str.encode("ascii", errors="ignore")
        .str.decode("ascii")
        .str.lower()
        .str.replace(r"[.,&-]", "", regex=True)
        .str.replace(r"\s+", " ", regex=True)
        .str.strip()
    )


def normalizar_documento(serie):
    return serie.str.replace(r"\D", "", regex=True)


def posibles_duplicados(clientes):
    r = pd.DataFrame({
        "cliente_id": clientes["cliente_id"],
        "documento_normalizado": normalizar_documento(clientes["documento"]),
        "nombre_normalizado": normalizar_texto(clientes["nombre"]),
    })
    r = r[r["documento_normalizado"].duplicated(keep=False)]
    r = r.sort_values(["documento_normalizado", "cliente_id"])
    r["grupo"] = pd.factorize(r["documento_normalizado"])[0] + 1
    return r.sort_values(["grupo", "cliente_id"]).reset_index(drop=True)


print(posibles_duplicados(clientes))
```

## Explicación

Cruzar datos de distintas fuentes falla casi siempre por **formato**, no por contenido: `"52.345.678"` y `"52345678"` son el mismo documento, pero `==` dice que no. Normalizar antes de comparar es el primer paso de cualquier proceso de calidad de datos (lo hiciste en el módulo 2 con líneas, ahora a escala con Pandas).

El truco de NFKD vale para cualquier texto en español: `"Peña"` → `"pena"`, `"Óscar"` → `"oscar"`. Úsalo solo para **comparar**: para mostrar al cliente, conserva el nombre original con sus tildes.

`duplicated(keep=False)` es la clave del ejercicio: con el valor por defecto (`keep="first"`) solo verías la segunda aparición, y para revisar duplicados necesitas ver **todas**.
