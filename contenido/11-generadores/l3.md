El módulo `itertools` trae funciones para combinar iteradores sin construir listas. Todas son **perezosas**.

## islice: los primeros N (o una franja)

```pyrun
from itertools import islice

def numeros():
    n = 1
    while True:      # infinito
        yield n
        n += 1

print(list(islice(numeros(), 5)))          # los 5 primeros
print(list(islice(numeros(), 10, 15)))     # del 10 al 14
```

Muy útil para **mirar las primeras líneas** de un archivo enorme sin recorrerlo:

```python
with open("datos/20GB/cdr.csv", encoding="utf-8") as f:
    for linea in islice(f, 5):
        print(linea, end="")
```

## chain: unir varios iterables en uno

```pyrun
from itertools import chain

septiembre = ["cdr_01.csv", "cdr_02.csv"]
octubre = ["cdr_10_01.csv"]

for archivo in chain(septiembre, octubre):
    print(archivo)

listas = [[1, 2], [3], [4, 5]]
print(list(chain.from_iterable(listas)))
```

## batched: procesar por lotes

Insertar registros en una base de datos de a uno es lentísimo; de a mil es mucho más rápido. `batched` (Python 3.12+) agrupa en tuplas de tamaño fijo:

```pyrun
from itertools import batched

registros = range(1, 11)
for lote in batched(registros, 4):
    print(lote)
```

## groupby: agrupar elementos consecutivos

`groupby` agrupa elementos **consecutivos** con la misma clave. Si los datos ya vienen ordenados por esa clave, resume sin cargar nada en memoria:

```pyrun
from itertools import groupby

cdrs = [("3001", 125), ("3001", 61), ("3002", 30), ("3003", 600), ("3003", 0)]

for linea, grupo in groupby(cdrs, key=lambda c: c[0]):
    minutos = sum((segundos + 59) // 60 for _, segundos in grupo)
    print(linea, minutos)
```

:::error groupby solo junta lo que está junto
Si los datos no están ordenados por la clave, la misma línea aparecerá en varios grupos separados:

```pyrun
from itertools import groupby

desordenados = ["VOZ", "SMS", "VOZ"]
print([(clave, len(list(g))) for clave, g in groupby(desordenados)])
```

Ordena antes (si cabe en memoria) o usa un diccionario/`Counter` para agrupar.
:::

## accumulate: totales acumulados

```pyrun
from itertools import accumulate

minutos_por_llamada = [3, 0, 2, 60, 1]
print(list(accumulate(minutos_por_llamada)))   # cuánto lleva consumido después de cada llamada
```

¡Es el núcleo del ejercicio de la bolsa de minutos del módulo 3, en una línea!

## Otras útiles

| Función | Qué hace | Ejemplo |
|---|---|---|
| `count(inicio)` | Contador infinito | IDs consecutivos |
| `takewhile(cond, it)` | Entrega mientras se cumpla la condición | Leer hasta la primera línea vacía |
| `dropwhile(cond, it)` | Salta mientras se cumpla | Saltar comentarios iniciales |
| `pairwise(it)` | Pares consecutivos `(a, b), (b, c)…` | Diferencia entre llamadas seguidas |
| `zip_longest(a, b)` | Como `zip`, rellenando el más corto | Comparar dos archivos línea a línea |
| `tee(it, n)` | Duplica un iterador | Recorrer dos veces (¡usa memoria!) |

```pyrun
from itertools import pairwise

inicios = [100, 160, 175, 900]     # segundos del día en que empezó cada llamada
print([b - a for a, b in pairwise(inicios)])
```

:::telco Detectar llamadas encadenadas
`pairwise` sobre las llamadas de una línea, ordenadas por hora, permite detectar patrones sospechosos: decenas de llamadas cortas separadas por pocos segundos suelen indicar fraude o un equipo defectuoso. Lo retomarás en el módulo 23.
:::
