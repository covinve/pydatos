## Enunciado

Convierte el cálculo del ejercicio anterior en **funciones reutilizables**, que es como se escribe el código de verdad.

Escribe dos funciones:

1. `minutos_facturables(segundos)`: devuelve los minutos que se cobran, redondeando hacia arriba.
2. `valor_llamada(segundos, tarifa_minuto)`: devuelve el valor de la llamada. **Debe usar** `minutos_facturables` en lugar de repetir la fórmula.

```python
minutos_facturables(125)        # 3
valor_llamada(125, 120)         # 360
valor_llamada(0, 120)           # 0
```

Las funciones deben **devolver** el resultado con `return`, no imprimirlo.

import ast


def prueba_minutos_casos_basicos():

    igual(valor_llamada(0, 120), 0)


def prueba_reutiliza_la_funcion():
    """valor_llamada llama a minutos_facturables (sin repetir la fórmula)"""
    arbol = ast.parse(codigo)
    for nodo in ast.walk(arbol):
        if isinstance(nodo, ast.FunctionDef) and nodo.name == "valor_llamada":
            llamadas = [n.func.id for n in ast.walk(nodo) if isinstance(n, ast.Call) and isinstance(n.func, ast.Name)]

## Pista 1

Una función devuelve su resultado con `return`. Reemplaza `pass` por la fórmula:

```python
def minutos_facturables(segundos):
    return (segundos + 59) // 60
```

## Pista 2

Dentro de `valor_llamada` puedes llamar a la otra función como a cualquier función de Python:

```python
def valor_llamada(segundos, tarifa_minuto):
    minutos = minutos_facturables(segundos)
    return ...
```

## Solución

```python
def minutos_facturables(segundos):
    return (segundos + 59) // 60


def valor_llamada(segundos, tarifa_minuto):
    minutos = minutos_facturables(segundos)
    return minutos * tarifa_minuto


print(minutos_facturables(125))
print(valor_llamada(125, 120))
```

## Explicación

Dos ideas que usarás en todo el curso:

1. **Una función, una responsabilidad.** `minutos_facturables` solo sabe redondear; `valor_llamada` solo sabe multiplicar. Si mañana cambia la regla de redondeo (por ejemplo, cobro por segundos), cambias **un solo lugar**.
2. **No te repitas** (*DRY, Don't Repeat Yourself*). Si copias la fórmula en `valor_llamada`, ahora tienes dos lugares que deben cambiar al mismo tiempo, y tarde o temprano uno se queda desactualizado.

`pass` es una instrucción que no hace nada: sirve para dejar una función vacía sin error de sintaxis. Una función con solo `pass` devuelve `None`.
