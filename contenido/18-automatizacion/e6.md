## Enunciado

Los procesos de facturación dependen del **calendario hábil**. Escribe:

1. `es_habil(dia, festivos)` → `True` si `dia` (un `date`) no es sábado, domingo ni está en `festivos` (un conjunto de `date`).
2. `sumar_habiles(dia, n, festivos)` → la fecha que está `n` días hábiles **después** de `dia` (`n >= 0`; con `n = 0` devuelve `dia` si es hábil, o el siguiente hábil).
3. `proxima_ejecucion(ahora, hora, festivos)` → el `datetime` de la próxima ejecución de una tarea que corre **los días hábiles** a la hora `hora` (un `time`). Si hoy es hábil y aún no llega la hora, es hoy; si ya pasó (o es exactamente esa hora), el siguiente día hábil.
4. `fecha_emision(periodo, festivos)` → las facturas del periodo `"AAAAMM"` se emiten el **quinto día hábil** del mes siguiente.

## Pruebas

```python
from datetime import date, datetime, time

F = {date(2026, 10, 12), date(2026, 11, 2), date(2026, 11, 16), date(2026, 12, 8), date(2026, 12, 25), date(2027, 1, 1)}


def prueba_es_habil():
    """Fines de semana y festivos"""
    requiere("es_habil")
    igual(es_habil(date(2026, 10, 9), F), True)       # viernes
    igual(es_habil(date(2026, 10, 10), F), False)     # sábado
    igual(es_habil(date(2026, 10, 11), F), False)     # domingo
    igual(es_habil(date(2026, 10, 12), F), False)     # festivo lunes
    igual(es_habil(date(2026, 10, 12), set()), True)


def prueba_sumar():
    """Suma días hábiles saltando fines de semana y festivos"""
    requiere("sumar_habiles")
    igual(sumar_habiles(date(2026, 10, 9), 1, F), date(2026, 10, 13))    # viernes + 1 → martes (lunes festivo)
    igual(sumar_habiles(date(2026, 10, 9), 0, F), date(2026, 10, 9))
    igual(sumar_habiles(date(2026, 10, 10), 0, F), date(2026, 10, 13))   # sábado + 0 → siguiente hábil
    igual(sumar_habiles(date(2026, 12, 24), 1, F), date(2026, 12, 28))
    igual(sumar_habiles(date(2026, 10, 1), 20, F), date(2026, 10, 30))


def prueba_proxima():
    """Próxima ejecución de la tarea"""
    requiere("proxima_ejecucion")
    seis = time(6, 0)
    igual(proxima_ejecucion(datetime(2026, 10, 8, 5, 59), seis, F), datetime(2026, 10, 8, 6, 0))
    igual(proxima_ejecucion(datetime(2026, 10, 8, 6, 0), seis, F), datetime(2026, 10, 9, 6, 0))
    igual(proxima_ejecucion(datetime(2026, 10, 9, 7, 0), seis, F), datetime(2026, 10, 13, 6, 0))
    igual(proxima_ejecucion(datetime(2026, 10, 10, 3, 0), seis, F), datetime(2026, 10, 13, 6, 0))
    igual(proxima_ejecucion(datetime(2026, 12, 31, 23, 0), time(22, 30), F), datetime(2027, 1, 4, 22, 30))


def prueba_emision():
    """Quinto día hábil del mes siguiente"""
    requiere("fecha_emision")
    igual(fecha_emision("202609", F), date(2026, 10, 7))
    igual(fecha_emision("202610", F), date(2026, 11, 9))       # 2 nov festivo
    igual(fecha_emision("202612", F), date(2027, 1, 8))        # cambio de año, 1 ene festivo
    igual(fecha_emision("202611", set()), date(2026, 12, 7))
```

## Pista 1

`dia.weekday()` devuelve 0 para lunes y 6 para domingo: hábil es `weekday() < 5` y no festivo.

Para sumar: avanza de a un día con `timedelta(days=1)` y cuenta solo los hábiles.

## Pista 2

- `proxima_ejecucion`: candidata = `datetime.combine(ahora.date(), hora)`; si no es hábil o `candidata <= ahora`, busca el siguiente hábil a partir de mañana.
- `fecha_emision`: el primer día del mes siguiente es `date(año + mes // 12, mes % 12 + 1, 1)`. El quinto hábil es el primer hábil desde ese día, más 4 hábiles: `sumar_habiles(primero, 0, ...)` y luego `sumar_habiles(..., 4, ...)`.

## Solución

```python
from datetime import date, datetime, time, timedelta

FESTIVOS = {date(2026, 10, 12), date(2026, 11, 2), date(2026, 11, 16), date(2026, 12, 8), date(2026, 12, 25)}
UN_DIA = timedelta(days=1)


def es_habil(dia, festivos):
    return dia.weekday() < 5 and dia not in festivos


def sumar_habiles(dia, n, festivos):
    while not es_habil(dia, festivos):
        dia += UN_DIA
    while n > 0:
        dia += UN_DIA
        if es_habil(dia, festivos):
            n -= 1
    return dia


def proxima_ejecucion(ahora, hora, festivos):
    candidata = datetime.combine(ahora.date(), hora)
    if es_habil(candidata.date(), festivos) and candidata > ahora:
        return candidata
    dia = sumar_habiles(ahora.date() + UN_DIA, 0, festivos)
    return datetime.combine(dia, hora)


def fecha_emision(periodo, festivos):
    anio, mes = int(periodo[:4]), int(periodo[4:])
    primero = date(anio + mes // 12, mes % 12 + 1, 1)
    return sumar_habiles(sumar_habiles(primero, 0, festivos), 4, festivos)


print(fecha_emision("202609", FESTIVOS))
print(proxima_ejecucion(datetime(2026, 10, 9, 7, 0), time(6, 0), FESTIVOS))
```

## Explicación

El calendario hábil es una de esas lógicas que "todo el mundo cree saber" hasta que falla un 31 de diciembre, o en un puente festivo, o en enero cuando el mes siguiente cambia de año. Por eso las pruebas atacan justo los bordes: viernes antes de festivo, fin de semana, cambio de año, hora exacta.

`sumar_habiles(dia, 0, ...)` como "el siguiente hábil (o hoy)" es un pequeño truco de diseño: con una sola función resuelves dos preguntas.

En la empresa, los festivos no se escriben en el código: se leen de una tabla o archivo de configuración mantenido por alguien (en Colombia, varios festivos se trasladan al lunes y cambian cada año). Existe la librería `holidays` (`holidays.Colombia(years=2026)`), útil como punto de partida, pero conviene verificarla contra el calendario oficial de tu empresa.
