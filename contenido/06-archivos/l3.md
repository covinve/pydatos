Hacer `linea.split("|")` funciona… hasta que un campo trae el separador adentro (`"Distribuciones Andina | Sur"`) o comillas. El módulo `csv` maneja todos esos casos por ti.

## csv.reader

```pyrun
import csv
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n"
    "1|3001234567|VOZ|125\n"
    '2|3109876543|SMS|0\n'
    '3|"3157778899"|DATOS|900\n',
    encoding="utf-8",
)

with open("cdr.csv", encoding="utf-8", newline="") as archivo:
    lector = csv.reader(archivo, delimiter="|")
    encabezado = next(lector)
    for fila in lector:
        print(fila)
```

Cada fila llega como una **lista de textos**: las comillas se quitan solas. Los números siguen siendo texto: la conversión es tuya.

:::consejo newline=""
La documentación de `csv` pide abrir los archivos con `newline=""`. Así el módulo maneja bien los saltos de línea de Windows (`\r\n`) y los campos con saltos de línea adentro.
:::

## csv.DictReader: filas como diccionarios

Acceder por posición (`fila[3]`) es frágil: si el proveedor agrega una columna, todo se corre. `DictReader` usa el encabezado como claves:

```pyrun
import csv
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n1|3001234567|VOZ|125\n2|3109876543|SMS|0\n3|3157778899|VOZ|61\n",
    encoding="utf-8",
)

minutos_por_linea = {}
with open("cdr.csv", encoding="utf-8", newline="") as archivo:
    for fila in csv.DictReader(archivo, delimiter="|"):
        if fila["tipo"] == "VOZ":
            minutos = (int(fila["duracion_seg"]) + 59) // 60
            linea = fila["linea_origen"]
            minutos_por_linea[linea] = minutos_por_linea.get(linea, 0) + minutos

print(minutos_por_linea)
```

:::reto Minutos de voz de la muestra
Con `csv.DictReader`, recorre el `cdr.csv` de la muestra del curso (separado por `|`) y crea `minutos_por_linea`: los minutos facturables de **voz** de cada `linea_origen`. Ignora los registros con duración negativa.

Después, crea `top`: la línea con más minutos.

:::pista
`for fila in csv.DictReader(archivo, delimiter="|"):`. Filtra con `fila["tipo"] == "VOZ"` y `int(fila["duracion_seg"]) >= 0`. La línea top: `max(minutos_por_linea, key=minutos_por_linea.get)`.
:::

```pyprueba
import csv


def _esperado():
    totales = {}
    with open("cdr.csv", encoding="utf-8", newline="") as f:
        for fila in csv.DictReader(f, delimiter="|"):
            d = int(fila["duracion_seg"])
            if fila["tipo"] == "VOZ" and d >= 0:
                totales[fila["linea_origen"]] = totales.get(fila["linea_origen"], 0) + (d + 59) // 60
    return totales


def prueba_minutos():

    """top es la línea con más minutos"""
    requiere("top")
    esperado = _esperado()
    igual(top, max(esperado, key=esperado.get))
```

## Escribir CSV

```pyrun
import csv

facturas = [
    {"cliente_id": "CL001", "total": 48719, "estado": "EMITIDA"},
    {"cliente_id": "CL002", "total": 106981, "estado": "EMITIDA"},
]

with open("facturas.csv", "w", encoding="utf-8", newline="") as archivo:
    escritor = csv.DictWriter(archivo, fieldnames=["cliente_id", "total", "estado"], delimiter=";")
    escritor.writeheader()
    escritor.writerows(facturas)

print(open("facturas.csv", encoding="utf-8").read())
```

:::telco ¿Coma o punto y coma?
En Colombia y buena parte de Latinoamérica, Excel usa la **coma como separador decimal** y por eso espera **punto y coma** (`;`) como separador de columnas. Si generas un CSV para que alguien lo abra con doble clic en Excel, usa `delimiter=";"` y `encoding="utf-8-sig"` (el BOM le dice a Excel que es UTF-8).
:::

## JSON: datos con estructura

**JSON** es el formato estándar para configuraciones, resultados y APIs (módulo 18). Se parece mucho a los diccionarios y listas de Python:

```pyrun
import json

resultado = {
    "archivo": "cdr_20260930.csv",
    "registros": 4064,
    "errores": {"duplicado": 64, "fecha_invalida": 19},
    "ok": True,
    "observaciones": None,
}

texto = json.dumps(resultado, indent=2, ensure_ascii=False)
print(texto)

with open("resultado.json", "w", encoding="utf-8") as f:
    json.dump(resultado, f, indent=2, ensure_ascii=False)

with open("resultado.json", encoding="utf-8") as f:
    leido = json.load(f)
print(leido["errores"]["duplicado"])
```

| Python | JSON |
|---|---|
| `dict` | objeto `{}` |
| `list`, `tuple` | arreglo `[]` |
| `str` | texto `""` |
| `int`, `float` | número |
| `True` / `False` / `None` | `true` / `false` / `null` |

:::error JSON no conoce Decimal ni fechas
`json.dumps({"total": Decimal("48719")})` da `TypeError`. Convierte antes: `int(total)`, `str(total)` o `fecha.isoformat()`.
:::

Los datos del curso traen `esperado.json`: con `json.load` puedes comparar tus resultados contra él automáticamente.

:::reto Guarda el resultado del proceso
1. Guarda el diccionario `resultado` en `resultado_proceso.json`, legible (`indent=2`) y **con las tildes tal cual** (no como `ó`).
2. Vuelve a leerlo con `json.load` en la variable `leido`.

Ojo: `total_facturado` es un `Decimal`, y JSON no lo conoce. Conviértelo a `int` antes de guardar.

```pyreto
import json
from decimal import Decimal

resultado = {
    "periodo": "202609",
    "región": "ANDINA",
    "registros": 4064,
    "errores": {"duplicado": 64, "duración_negativa": 5},
    "total_facturado": Decimal("2847390"),
    "ok": True,
}

# 1. Guarda resultado_proceso.json

# 2. Léelo en leido

print(leido)
```

:::pista
Antes de guardar: `resultado["total_facturado"] = int(resultado["total_facturado"])`. Para escribir: `json.dump(resultado, f, indent=2, ensure_ascii=False)` dentro de un `with open(..., "w", encoding="utf-8")`.
:::

```pyprueba
import json
from pathlib import Path


def prueba_archivo():
    """El archivo tiene todos los datos"""
    texto = Path("resultado_proceso.json").read_text(encoding="utf-8")
    igual(json.loads(texto), {
        "periodo": "202609", "región": "ANDINA", "registros": 4064,
        "errores": {"duplicado": 64, "duración_negativa": 5},
        "total_facturado": 2847390, "ok": True,
    })


def prueba_tildes():
    """Las tildes se guardan tal cual"""
    texto = Path("resultado_proceso.json").read_text(encoding="utf-8")
    assert "región" in texto, "Las tildes quedaron escapadas: usa ensure_ascii=False"


def prueba_legible():
    """El archivo está indentado"""
    assert "\n  " in Path("resultado_proceso.json").read_text(encoding="utf-8"), "Usa indent=2 para que sea legible"


def prueba_leido():
    """leido tiene lo que se leyó del archivo"""
    requiere("leido")
    igual(leido["errores"]["duplicado"], 64)
    igual(leido["total_facturado"], 2847390)
```

## Cuestionario

? ¿Qué ventaja tiene `csv.DictReader` sobre `csv.reader`?
- [ ] Es mucho más rápido
- [x] Accede a las columnas por nombre, así que no se rompe si cambia el orden de las columnas
- [ ] Convierte los números automáticamente
- [ ] Lee archivos de cualquier encoding
> Cada fila es un diccionario con el encabezado como claves. Los valores siguen siendo texto.

? ¿Qué tipo tiene `fila["duracion_seg"]` al leer con `csv.DictReader`?
- [ ] `int`
- [x] `str`
- [ ] `float`
- [ ] Depende del valor
> El módulo `csv` no convierte tipos: todo llega como texto.

? ¿En qué se convierte `None` al guardar con `json.dump`?
- [ ] `"None"`
- [x] `null`
- [ ] `0`
- [ ] Se omite
> JSON representa la ausencia de valor con `null`, y al leer vuelve a ser `None`.
