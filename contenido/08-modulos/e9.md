## Enunciado

En `ejercicios/m08-e9/tarifario/` hay un paquete que trae su tabla de tarifas en `tarifario/datos/tarifas.json`. Complétalo para que funcione así, **desde cualquier carpeta**:

```powershell
python -m tarifario LOCAL 125
```

```text
LOCAL · 125 s · 3 min · $300
```

1. En `calculo.py`:
   - `cargar_tarifas()` lee el JSON **desde dentro del paquete** con `importlib.resources` (no con una ruta relativa a la carpeta actual) y devuelve el diccionario de `"tarifas"`.
   - `valor(destino, segundos)` → minutos facturables × tarifa.
2. Crea `tarifario/__main__.py` con el programa de terminal:
   - recibe destino y segundos (usa `argparse`); el destino se acepta en minúsculas;
   - imprime el formato de arriba (valor con punto de miles);
   - si el destino no existe, escribe un mensaje que lo mencione en **stderr** y termina con **código de salida 2** (`sys.exit(2)`), sin imprimir nada en stdout.

Comprueba con `python comprobar.py m08-e9`.

## Pista 1

`importlib.resources.files("tarifario")` devuelve un objeto parecido a un `Path` que apunta a la carpeta del paquete, esté donde esté instalado:

```python
import json
from importlib import resources


def cargar_tarifas():
    texto = resources.files("tarifario").joinpath("datos/tarifas.json").read_text(encoding="utf-8")
    return json.loads(texto)["tarifas"]
```

## Pista 2

En `__main__.py`, para escribir en stderr: `print("mensaje", file=sys.stderr)`. El código de salida 2 es la convención para "uso incorrecto" (argparse usa ese mismo código cuando faltan argumentos):

```python
try:
    total = valor(destino, args.segundos)
except KeyError:
    print(f"Destino desconocido: {destino}", file=sys.stderr)
    sys.exit(2)
```

## Solución

```python tarifario/calculo.py
"""Cálculo de valores con el tarifario incluido en el paquete."""

import json
from functools import cache
from importlib import resources


@cache
def cargar_tarifas() -> dict[str, int]:
    """Lee tarifario/datos/tarifas.json desde dentro del paquete y devuelve las tarifas."""
    texto = resources.files("tarifario").joinpath("datos/tarifas.json").read_text(encoding="utf-8")
    return json.loads(texto)["tarifas"]


def valor(destino: str, segundos: int) -> int:
    """Minutos facturables × tarifa del destino. Lanza KeyError si el destino no existe."""
    return (segundos + 59) // 60 * cargar_tarifas()[destino]
```

```python tarifario/__main__.py
"""python -m tarifario DESTINO SEGUNDOS"""

import argparse
import sys

from tarifario.calculo import valor


def main() -> None:
    parser = argparse.ArgumentParser(prog="python -m tarifario", description="Valor de una llamada")
    parser.add_argument("destino", help="LOCAL, NACIONAL o INTERNACIONAL")
    parser.add_argument("segundos", type=int, help="duración de la llamada")
    args = parser.parse_args()
    destino = args.destino.upper()
    try:
        total = valor(destino, args.segundos)
    except KeyError:
        print(f"Destino desconocido: {destino}", file=sys.stderr)
        sys.exit(2)
    minutos = (args.segundos + 59) // 60
    print(f"{destino} · {args.segundos} s · {minutos} min · ${total:,}".replace(",", "."))


main()
```

## Explicación

Tres ideas de este ejercicio que usarás en proyectos reales:

1. **`__main__.py`** convierte un paquete en programa: `python -m tarifario`. Como el archivo solo se ejecuta así, no hace falta el guardián `if __name__ == "__main__"`.
2. **`importlib.resources`** encuentra los archivos de datos del paquete aunque el programa se ejecute desde otra carpeta, o aunque el paquete esté instalado dentro de `site-packages`. `open("datos/tarifas.json")` solo funcionaría si estás parado justo en la carpeta correcta.
3. **stdout para datos, stderr para errores, y códigos de salida.** Un proceso programado (o un script que llama a otro) sabe si algo falló mirando el código de salida: 0 es éxito, cualquier otro valor es error.

`@cache` (de `functools`) recuerda el resultado de `cargar_tarifas()`: el JSON se lee una sola vez aunque calcules un millón de llamadas.
