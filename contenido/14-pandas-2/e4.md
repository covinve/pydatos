1. `consumo_por_linea(validos)` → DataFrame indexado por línea con `minutos_nacionales`, `minutos_internacionales`, `mb` (suma sin redondear) y `sms`.
2. `facturas_correctas(clientes, planes, consumo)` → una fila por **cliente** (también los que no tuvieron consumo) con `cliente_id` y `total` correcto, aplicando **todas** las reglas de facturación del curso de forma vectorizada (excesos con ilimitado = −1, megas redondeadas hacia arriba, descuento empresarial, IVA con redondeo comercial: `np.floor(subtotal * 0.19 + 0.5)`).

Los resultados deben coincidir con la sección `"facturacion"` de `esperado.json`.

Facturas: parte de `clientes.merge(planes.drop(columns="segmento"), on="plan_id")`, cruza con el consumo (`left`, por línea) y rellena los faltantes con 0. Luego calcula cada concepto con `np.where`:

## Pista 2

- Megas: `np.ceil(np.round(df["mb"], 3))` antes de restar lo incluido (redondear a 3 decimales evita que un `15360.000000001` de float se vuelva 15361).
- Descuento: `np.where((df["segmento"] == "EMPRESARIAL") & (df["fecha_alta"] < "2023-09-01"), np.floor(df["cargo_fijo"] * 0.10 + 0.5), 0)`.
- Conciliación: `merge` de correctas con `facturas[["cliente_id", "total"]]`, renombrando columnas, y filtra `diferencia != 0`.

## Solución

```python
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
planes = pd.read_csv("planes.csv")
facturas = pd.read_csv("facturas.csv", dtype={"linea": "string"})


def cdr_validos(cdr, clientes):
    fecha = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    validos = (
        ~cdr.duplicated("cdr_id")
        & (cdr["linea_origen"] != "")
        & cdr["linea_origen"].isin(clientes["linea"])
        & cdr["tipo"].isin(["VOZ", "SMS", "DATOS"])
        & (cdr["duracion_seg"] >= 0)
        & fecha.notna()
    )
    return cdr[validos]


def consumo_por_linea(validos):
    v = validos.copy()
    minutos = (v["duracion_seg"] + 59) // 60
    es_voz = v["tipo"] == "VOZ"
    internacional = v["destino"] == "INTERNACIONAL"
    v["min_nac"] = np.where(es_voz & ~internacional, minutos, 0)
    v["min_int"] = np.where(es_voz & internacional, minutos, 0)
    v["mb_datos"] = np.where(v["tipo"] == "DATOS", v["mb"], 0.0)
    v["es_sms"] = (v["tipo"] == "SMS").astype(int)
    return v.groupby("linea_origen").agg(
        minutos_nacionales=("min_nac", "sum"),
        minutos_internacionales=("min_int", "sum"),
        mb=("mb_datos", "sum"),
        sms=("es_sms", "sum"),
    )


def exceso(consumido, incluido, tarifa):
    return np.where(incluido == -1, 0, np.maximum(consumido - incluido, 0) * tarifa)


def facturas_correctas(clientes, planes, consumo):
    df = clientes.merge(planes.drop(columns="segmento"), on="plan_id", validate="many_to_one")
    df = df.merge(consumo, left_on="linea", right_index=True, how="left")
    df[["minutos_nacionales", "minutos_internacionales", "mb", "sms"]] = (
        df[["minutos_nacionales", "minutos_internacionales", "mb", "sms"]].fillna(0)
    )
    voz = exceso(df["minutos_nacionales"], df["minutos_incluidos"], df["tarifa_minuto"])
    internacional = df["minutos_internacionales"] * df["tarifa_minuto_internacional"]
    datos = exceso(np.ceil(np.round(df["mb"], 3)), df["mb_incluidos"], df["tarifa_mb"])
    sms = exceso(df["sms"], df["sms_incluidos"], df["tarifa_sms"])
    descuento = np.where(
        (df["segmento"] == "EMPRESARIAL") & (df["fecha_alta"] < "2023-09-01"),
        np.floor(df["cargo_fijo"] * 0.10 + 0.5), 0,
    )
    subtotal = df["cargo_fijo"] + voz + internacional + datos + sms - descuento
    iva = np.floor(subtotal * 0.19 + 0.5)
    return pd.DataFrame({"cliente_id": df["cliente_id"], "total": (subtotal + iva).astype("int64")})


def conciliar(correctas, facturas):
    cruce = correctas.rename(columns={"total": "total_correcto"}).merge(
        facturas[["cliente_id", "total"]].rename(columns={"total": "total_facturado"}),
        on="cliente_id", how="outer", validate="one_to_one",
    )
    cruce["diferencia"] = cruce["total_facturado"] - cruce["total_correcto"]
    return cruce[cruce["diferencia"] != 0].sort_values("cliente_id").reset_index(drop=True)


consumo = consumo_por_linea(cdr_validos(cdr, clientes))
correctas = facturas_correctas(clientes, planes, consumo)
print(conciliar(correctas, facturas))
```

## Explicación

En unas 50 líneas tienes una **conciliación completa**: millones de CDR → consumo por línea → factura que debió emitirse → comparación con lo emitido → lista de diferencias. Es el corazón del Proyecto 2.

Detalles que hacen la diferencia:

- **El cruce de clientes con consumo es `left`**: los clientes sin consumo también reciben factura (cargo fijo). Con `inner`, desaparecerían.
- **`validate="one_to_one"` en la conciliación**: si una factura estuviera repetida, el proceso fallaría en lugar de reportar diferencias falsas.
- **`np.round(..., 3)` antes del `ceil`**: la suma de megas en float puede dar `15360.000000000002`, y el `ceil` cobraría una mega de más. Redondear primero a la precisión del dato (milésimas) evita cobrar errores de float.
- **IVA con `floor(x + 0.5)`**: la regla comercial, vectorizada.

Estas diferencias son las que sembró el generador de datos: tarificación de datos inflada, minutos de voz mal calculados, consumo internacional sin cobrar e inconsistencias internas. En el ejercicio 9 las clasificarás por concepto.
