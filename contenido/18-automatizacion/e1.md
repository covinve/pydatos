## Enunciado

Convierte un resumen de CDR en un script de verdad, con argumentos y códigos de salida.

1. `crear_parser()` → un `ArgumentParser` con `prog="resumen_cdr"`:
   - `archivo`: argumento posicional (la ruta del CSV);
   - `--tipo`: opcional, solo `VOZ`, `SMS` o `DATOS`;
   - `--top`: entero, por defecto 5;
   - `--minimo`: entero, por defecto 0 (CDR con `duracion_seg` menor se ignoran).
2. `main(argv=None)` → lee los argumentos y devuelve un **código de salida**:
   - `3` si el archivo no existe (con un mensaje en `sys.stderr` que incluya la ruta);
   - `0` si todo sale bien, después de imprimir una línea por cada una de las `top` líneas de origen con más registros (filtrando por `--tipo` si se indicó y por `--minimo`), con el formato `3001112233: 12`, de mayor a menor (empates por línea);
   - los errores de uso los maneja argparse (código 2).

Usa `csv.DictReader` (sin Pandas).

with open("cdr.csv", encoding="utf-8", newline="") as f:
    FILAS = list(csv.DictReader(f, delimiter="|"))


def esperado(tipo=None, top=5, minimo=0):
    c = Counter(r["linea_origen"] for r in FILAS

    return "".join(f"{linea}: {n}\n" for linea, n in orden)

## Solución

```python
import argparse
import csv
import sys
from collections import Counter
from pathlib import Path


def crear_parser():
    p = argparse.ArgumentParser(prog="resumen_cdr", description="Líneas con más registros en un CDR.")
    p.add_argument("archivo", help="Ruta del cdr.csv")
    p.add_argument("--tipo", choices=["VOZ", "SMS", "DATOS"], help="Solo este tipo")
    p.add_argument("--top", type=int, default=5, help="Cuántas líneas mostrar")
    p.add_argument("--minimo", type=int, default=0, help="Duración mínima en segundos")
    return p


def main(argv=None):
    args = crear_parser().parse_args(argv)
    ruta = Path(args.archivo)
    if not ruta.exists():
        print(f"No existe el archivo {ruta}", file=sys.stderr)
        return 3
    conteo = Counter()
    with open(ruta, encoding="utf-8", newline="") as f:
        for r in csv.DictReader(f, delimiter="|"):
            if (args.tipo is None or r["tipo"] == args.tipo) and int(r["duracion_seg"]) >= args.minimo:
                conteo[r["linea_origen"]] += 1
    for linea, n in sorted(conteo.items(), key=lambda par: (-par[1], par[0]))[: args.top]:
        print(f"{linea}: {n}")
    return 0


codigo_salida = main(["cdr.csv", "--tipo", "VOZ", "--top", "3"])
print("Código de salida:", codigo_salida)
```

## Explicación

En un archivo `.py` real, la última línea sería:

```python
if __name__ == "__main__":
    sys.exit(main())
```

`main()` sin argumentos hace que argparse lea `sys.argv` (la línea de comandos), y `sys.exit` convierte el número devuelto en el código de salida del proceso. En las pruebas, en cambio, llamas `main([...])` con una lista: el mismo código, probado sin abrir una terminal.

Cuando el usuario se equivoca (`--tipo FAX`), argparse imprime un mensaje claro con las opciones válidas y termina con `SystemExit(2)`: no tienes que programar esas validaciones.
