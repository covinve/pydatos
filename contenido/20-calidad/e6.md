## Enunciado

`numeracion.py` (ya está en tu carpeta) clasifica números marcados:

| Número (después de quitar espacios, guiones y paréntesis) | Resultado |
|---|---|
| Empieza por `00` y tiene al menos 10 dígitos | `"INTERNACIONAL"` |
| 10 dígitos que empiezan por `3` | `"MOVIL"` |
| 10 dígitos que empiezan por `60` | `"FIJO"` |
| 3 dígitos que empiezan por `1` (`123`, `112`…) | `"ESPECIAL"` |
| Cualquier otra cosa (incluido un texto vacío o con letras) | `"INVALIDO"` |

**Escribe sus pruebas** con **una sola** función de prueba parametrizada (`@pytest.mark.parametrize`) que tenga al menos **12** casos y **`ids`** descriptivos. Piensa en los bordes: 9 y 11 dígitos, separadores, el `00` sin suficientes dígitos, letras.

## Preparación

```python
from pathlib import Path

Path("numeracion.py").write_text('''import re


def clasificar(numero):
    limpio = re.sub(r"[\\s()-]", "", numero)
    if not limpio.isdigit():
        return "INVALIDO"
    if limpio.startswith("00") and len(limpio) >= 10:
        return "INTERNACIONAL"
    if len(limpio) == 10 and limpio.startswith("3"):
        return "MOVIL"
    if len(limpio) == 10 and limpio.startswith("60"):
        return "FIJO"
    if len(limpio) == 3 and limpio.startswith("1"):
        return "ESPECIAL"
    return "INVALIDO"
''', encoding="utf-8")
```

## Código inicial

```python
import pytest

from numeracion import clasificar


@pytest.mark.parametrize(
    ("numero", "esperado"),
    [
        ("3001112233", "MOVIL"),
    ],
    ids=["movil"],
)
def test_clasificar(numero, esperado):
    assert clasificar(numero) == esperado
```

## Pista 1

Organiza la tabla por regla y por borde: para cada regla, un caso que **sí** cumple y uno que **casi** cumple.

```python
("3001112233", "MOVIL"),
("30011122334", "INVALIDO"),     # 11 dígitos
("300111223", "INVALIDO"),       # 9 dígitos
("300-111-2233", "MOVIL"),       # con guiones
```

## Pista 2

Casos que se suelen olvidar: `""` (vacío), `"00123"` (internacional demasiado corto), `"6512345678"` (empieza por 6 pero no por 60), `"1234"` (especial de 4 dígitos), `"30O1112233"` (con la letra O en lugar del cero).

## Solución

```python
import pytest

from numeracion import clasificar


@pytest.mark.parametrize(
    ("numero", "esperado"),
    [
        ("3001112233", "MOVIL"),
        ("300 111 2233", "MOVIL"),
        ("(300) 111-2233", "MOVIL"),
        ("30011122334", "INVALIDO"),
        ("300111223", "INVALIDO"),
        ("6012345678", "FIJO"),
        ("601234567", "INVALIDO"),
        ("6512345678", "INVALIDO"),
        ("0014155552671", "INTERNACIONAL"),
        ("00123", "INVALIDO"),
        ("123", "ESPECIAL"),
        ("1234", "INVALIDO"),
        ("", "INVALIDO"),
        ("30O1112233", "INVALIDO"),
    ],
    ids=["movil", "movil-espacios", "movil-parentesis", "movil-11-digitos", "movil-9-digitos", "fijo",
         "fijo-9-digitos", "fijo-sin-60", "internacional", "internacional-corto", "especial", "especial-4-digitos",
         "vacio", "letra-o"],
)
def test_clasificar(numero, esperado):
    assert clasificar(numero) == esperado
```

## Explicación

Una tabla de casos es la forma más legible de probar una función de clasificación: cada fila es un ejemplo del reglamento, y agregar un caso nuevo (cuando aparece un error en producción) es agregar una línea.

Los `ids` hacen que un fallo se explique solo:

```text
FAILED test_alumno.py::test_clasificar[movil-11-digitos] - AssertionError: assert 'MOVIL' == 'INVALIDO'
```

en lugar de `test_clasificar[30011122334-INVALIDO]`.

La estrategia de "un caso que cumple y uno que casi cumple" por regla es el **análisis de valores límite**: los errores se esconden en los bordes (`>=` en lugar de `==`, `"6"` en lugar de `"60"`). Los siete mutantes son exactamente esos errores de borde, y tu tabla los atrapó todos.
