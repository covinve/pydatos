## Enunciado

Llegó el momento de juntar todo lo aprendido en el nivel básico hasta ahora. Escribe `calcular_factura(cliente, plan, consumo)` que aplique **todas** las reglas de facturación del curso (Referencia → Datos del curso) y devuelva un diccionario con la factura.

Entradas (diccionarios):

```python
cliente = {"cliente_id": "CL0000123", "segmento": "EMPRESARIAL", "fecha_alta": "2020-05-10"}
plan = {"plan_id": "EMP100", "cargo_fijo": 79900, "minutos_incluidos": 1000, "mb_incluidos": 51200,
        "sms_incluidos": 500, "tarifa_minuto": 100, "tarifa_minuto_internacional": 800,
        "tarifa_mb": 12, "tarifa_sms": 50}
consumo = {"minutos_nacionales": 1000, "minutos_internacionales": 0, "mb": 51200.0, "sms": 0}
```

Salida: un diccionario con **estas claves, en este orden**, todos los valores `int`:

```python
{"cliente_id": "CL0000123", "plan_id": "EMP100", "cargo_fijo": 79900,
 "valor_voz": 0, "valor_internacional": 0, "valor_datos": 0, "valor_sms": 0,
 "consumo_adicional": 0, "descuento": 7990, "subtotal": 71910, "iva": 13663, "total": 85573}
```

Recuerda:

- `-1` en los incluidos significa ilimitado.
- Las megas se redondean hacia arriba antes de comparar con las incluidas.
- Descuento: 10 % del cargo fijo (redondeado al peso, 0,5 sube) para clientes `EMPRESARIAL` con `fecha_alta` **anterior** al `2023-09-01`.
- IVA: 19 % del subtotal, redondeado al peso con la regla comercial.

## Pista 1

Divide el problema en funciones pequeñas, como en los módulos anteriores: una para el exceso (con el caso ilimitado), una para el descuento y una para el IVA. `calcular_factura` solo las combina y arma el diccionario.

```python
def valor_exceso(consumido, incluido, tarifa):
    if incluido == ILIMITADO:
        return 0
    return max(0, consumido - incluido) * tarifa
```

## Pista 2

Para redondear con la regla comercial y obtener un `int`:

```python
def redondear_peso(valor):
    return int((Decimal(str(valor))).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```

Las fechas en formato `AAAA-MM-DD` se pueden comparar como texto: `"2020-05-10" < "2023-09-01"` es `True`, porque el orden alfabético coincide con el cronológico.

## Solución

```python
import math
from decimal import Decimal, ROUND_HALF_UP

ILIMITADO = -1
IVA = Decimal("0.19")
FECHA_CORTE_DESCUENTO = "2023-09-01"


def redondear_peso(valor):
    return int(Decimal(str(valor)).quantize(Decimal("1"), rounding=ROUND_HALF_UP))


def valor_exceso(consumido, incluido, tarifa):
    if incluido == ILIMITADO:
        return 0
    return max(0, consumido - incluido) * tarifa


def calcular_descuento(cliente, cargo_fijo):
    if cliente["segmento"] == "EMPRESARIAL" and cliente["fecha_alta"] < FECHA_CORTE_DESCUENTO:
        return redondear_peso(Decimal(cargo_fijo) * Decimal("0.10"))
    return 0


def calcular_factura(cliente, plan, consumo):
    valor_voz = valor_exceso(consumo["minutos_nacionales"], plan["minutos_incluidos"], plan["tarifa_minuto"])
    valor_internacional = consumo["minutos_internacionales"] * plan["tarifa_minuto_internacional"]
    valor_datos = valor_exceso(math.ceil(consumo["mb"]), plan["mb_incluidos"], plan["tarifa_mb"])
    valor_sms = valor_exceso(consumo["sms"], plan["sms_incluidos"], plan["tarifa_sms"])
    consumo_adicional = valor_voz + valor_internacional + valor_datos + valor_sms
    descuento = calcular_descuento(cliente, plan["cargo_fijo"])
    subtotal = plan["cargo_fijo"] + consumo_adicional - descuento
    iva = redondear_peso(Decimal(subtotal) * IVA)
    return {
        "cliente_id": cliente["cliente_id"],
        "plan_id": plan["plan_id"],
        "cargo_fijo": plan["cargo_fijo"],
        "valor_voz": valor_voz,
        "valor_internacional": valor_internacional,
        "valor_datos": valor_datos,
        "valor_sms": valor_sms,
        "consumo_adicional": consumo_adicional,
        "descuento": descuento,
        "subtotal": subtotal,
        "iva": iva,
        "total": subtotal + iva,
    }


cliente = {"cliente_id": "CL0000123", "segmento": "EMPRESARIAL", "fecha_alta": "2020-05-10"}
plan = {"plan_id": "EMP100", "cargo_fijo": 79900, "minutos_incluidos": 1000, "mb_incluidos": 51200,
        "sms_incluidos": 500, "tarifa_minuto": 100, "tarifa_minuto_internacional": 800,
        "tarifa_mb": 12, "tarifa_sms": 50}
consumo = {"minutos_nacionales": 1000, "minutos_internacionales": 0, "mb": 51200.0, "sms": 0}
print(calcular_factura(cliente, plan, consumo))
```

## Explicación

Compara esta función con el `consumo_adicional` de once parámetros del módulo 3: ahora recibe **tres diccionarios** con nombres claros, y cada regla vive en su propia función pequeña.

Detalles que importan:

- **`math.ceil(consumo["mb"])`** se aplica al total de megas, no a cada sesión: así lo dice la regla.
- **Las fechas ISO (`AAAA-MM-DD`) se comparan como texto** correctamente. Con otros formatos (`10/05/2020`) esto fallaría; en el módulo 6 usarás `datetime` para comparar fechas de forma robusta.
- **`Decimal(subtotal) * IVA`** parte de un entero, así que no hay errores de representación.

Con esta función, el ejemplo de la página de referencia, los datos sintéticos y tus pruebas producen exactamente los mismos números. En el **Proyecto 2** la aplicarás a todos los clientes y la compararás con las facturas emitidas para encontrar los errores del sistema de facturación.
