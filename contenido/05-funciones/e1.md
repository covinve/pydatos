## Enunciado

Varios reportes necesitan mostrar valores con formatos distintos. En vez de copiar código, escribe **una** función flexible:

```python
formatear_valor(valor, *, moneda="$", decimales=0, sep_miles=".", sep_decimal=",", sufijo="")
```

- `valor` es obligatorio y posicional.
- Todas las opciones son **de solo-nombre** (van después de `*`).
- Redondea con la regla comercial (0,5 sube) a la cantidad de `decimales`.
- Los valores negativos llevan el signo **antes** de la moneda: `-$5.000`.
- Agrega las **anotaciones de tipo** a todos los parámetros y al retorno.

```python
formatear_valor(48719)                                   # "$48.719"
formatear_valor(1234.567, decimales=2)                   # "$1.234,57"
formatear_valor(-5000)                                   # "-$5.000"
formatear_valor(15.36, moneda="", decimales=2, sufijo=" GB")   # "15,36 GB"
formatear_valor(1234.5, moneda="USD ", sep_miles=",", sep_decimal=".", decimales=2)  # "USD 1,234.50"
```

## Pista 1

Redondea primero con `Decimal` y `quantize`. Para `decimales=2` el patrón es `Decimal("0.01")`; para cualquier cantidad puedes construirlo así: `Decimal(1).scaleb(-decimales)` (que da `1`, `0.1`, `0.01`…).

Trabaja con el valor absoluto (`abs`) y agrega el signo al final.

## Pista 2

Con el valor redondeado y positivo, `f"{redondeado:,.{decimales}f}"` produce el formato inglés (`1,234.57`). Cambia los separadores con un comodín:

```python
texto = f"{redondeado:,.{decimales}f}"
texto = texto.replace(",", "\0").replace(".", sep_decimal).replace("\0", sep_miles)
signo = "-" if valor < 0 else ""
return f"{signo}{moneda}{texto}{sufijo}"
```

## Solución

```python
from decimal import Decimal, ROUND_HALF_UP


def formatear_valor(
    valor: int | float | Decimal,
    *,
    moneda: str = "$",
    decimales: int = 0,
    sep_miles: str = ".",
    sep_decimal: str = ",",
    sufijo: str = "",
) -> str:
    """Da formato a un número con separadores y moneda configurables."""
    cuantos = Decimal(1).scaleb(-decimales)
    redondeado = abs(Decimal(str(valor))).quantize(cuantos, rounding=ROUND_HALF_UP)
    texto = f"{redondeado:,.{decimales}f}"
    texto = texto.replace(",", "\0").replace(".", sep_decimal).replace("\0", sep_miles)
    signo = "-" if valor < 0 else ""
    return f"{signo}{moneda}{texto}{sufijo}"


print(formatear_valor(48719))
```

## Explicación

- **El `*` protege a quien usa la función.** `formatear_valor(1234.5, "$", 2)` no dice nada; `formatear_valor(1234.5, decimales=2)` se explica solo. La prueba `prueba_opciones_solo_por_nombre` verifica que nadie pueda llamarla de la forma ambigua.
- **`Decimal(1).scaleb(-decimales)`** construye `1`, `0.1`, `0.01`… según los decimales pedidos, para usarlo en `quantize`.
- **`"\0"` como comodín**: es un carácter que nunca aparece en un número, así que no hay riesgo de confundirlo.
- **Formato anidado** `{redondeado:,.{decimales}f}`: dentro del formato de un f-string se pueden usar otras variables.

Esta función reemplaza a `formatear_pesos` (módulo 2) y `describir_consumo` (módulo 2): una sola función bien diseñada en lugar de varias parecidas.
