## parametrize: muchos casos, una prueba

Cuando quieres probar la misma regla con muchos datos, no copies la prueba: **parametrízala**.

```python
import pytest

from tarifas import minutos_facturables


@pytest.mark.parametrize(
    ("segundos", "esperado"),
    [
        (0, 0),
        (1, 1),
        (59, 1),
        (60, 1),
        (61, 2),
        (3600, 60),
    ],
)
def test_minutos_facturables(segundos, esperado):
    assert minutos_facturables(segundos) == esperado
```

pytest ejecuta la función **una vez por cada tupla**, y si una falla te dice cuál:

```text
FAILED test_tarifas.py::test_minutos_facturables[60-1] - assert 2 == 1
```

Puedes darle nombres legibles a los casos con `pytest.param(..., id="un minuto exacto")`.

:::reto Una prueba, muchos casos
El módulo `datos.py` (ya está en tu carpeta) tiene `megas_facturables(mb)`, que redondea las megas **hacia arriba** a un entero (`15.131` → `16`, `16.0` → `16`, `0` → `0`).

Escribe **una** prueba parametrizada con al menos 4 casos. El curso la ejecuta contra la versión correcta y contra tres con errores: `int(mb)`, `round(mb)` e `int(mb) + 1`.

```pyreto
import pytest

from datos import megas_facturables


# Escribe la prueba con @pytest.mark.parametrize

```

:::pista
`@pytest.mark.parametrize(("mb", "esperado"), [(15.131, 16), (16.0, 16), (0, 0), (0.2, 1)])` sobre `def test_megas_facturables(mb, esperado):`. Un número exacto (16.0) atrapa a `int(mb) + 1`, y 15.131 atrapa a los que no redondean hacia arriba.
:::

```pyprueba
import ast

CORRECTA = "import math\n\ndef megas_facturables(mb):\n    return math.ceil(mb)\n"


def correr(implementacion):
    return correr_pytest(codigo, {"datos": implementacion})


def prueba_parametrizada():
    """Usa @pytest.mark.parametrize"""
    assert "parametrize" in codigo, "Decora la prueba con @pytest.mark.parametrize"


def prueba_pasan():
    """Tus casos pasan con el código correcto"""
    resultado, texto = correr(CORRECTA)
    assert resultado != 5, "pytest no encontró pruebas: el nombre debe empezar con test_"
    assert resultado == 0, "Algún caso falla con el código CORRECTO:\n" + texto[-900:]
    casos = int(texto.split(" passed")[0].split()[-1]) if " passed" in texto else 0
    assert casos >= 4, f"Agrega al menos 4 casos; pytest ejecutó {casos}"


def prueba_atrapa_int():
    """Atrapan int(mb) (no redondea hacia arriba)"""
    resultado, _ = correr("def megas_facturables(mb):\n    return int(mb)\n")
    assert resultado == 1, "Ningún caso falló con int(mb). Pista: megas con decimales"


def prueba_atrapa_round():
    """Atrapan round(mb)"""
    resultado, _ = correr("def megas_facturables(mb):\n    return round(mb)\n")
    assert resultado == 1, "Ningún caso falló con round(mb). Pista: un decimal menor que .5, como 0.2"


def prueba_atrapa_mas_uno():
    """Atrapan int(mb) + 1"""
    resultado, _ = correr("def megas_facturables(mb):\n    return int(mb) + 1\n")
    assert resultado == 1, "Ningún caso falló con int(mb) + 1. Pista: un valor exacto, como 16.0 o 0"
```

## Verificar excepciones: pytest.raises

```python
import pytest

from conversion import a_pesos


def test_texto_invalido_lanza_valueerror():
    with pytest.raises(ValueError):
        a_pesos("abc")


def test_el_mensaje_incluye_el_valor():
    with pytest.raises(ValueError, match="'abc'"):
        a_pesos("abc")
```

La prueba **falla** si el bloque `with` no lanza la excepción. `match` verifica (con una expresión regular) que el mensaje contenga el texto indicado.

:::reto Prueba que el error es el correcto
El módulo `conversion.py` tiene `a_pesos(texto)`: convierte `"48719"` en `48719` y, si el texto no es un entero, lanza `ValueError` con un mensaje que **incluye el texto recibido**, por ejemplo `Monto inválido: '48.719'`.

Escribe pruebas que verifiquen las dos cosas: que se lanza `ValueError` y que el mensaje menciona el valor. El curso las corre contra dos versiones con errores: una que devuelve `0` en vez de lanzar el error y otra que lanza `ValueError("Error")`, sin el valor.

```pyreto
import pytest

from conversion import a_pesos


def test_convierte_un_monto_valido():
    assert a_pesos("48719") == 48719


# Escribe las pruebas del error
```

:::pista
`with pytest.raises(ValueError, match="48.719"):` y dentro `a_pesos("48.719")`. Con `match` atrapas también la versión que lanza un mensaje sin el valor.
:::

```pyprueba
CORRECTA = (
    "def a_pesos(texto):\n"
    "    try:\n"
    "        return int(texto)\n"
    "    except ValueError:\n"
    "        raise ValueError(f'Monto inválido: {texto!r}') from None\n"
)


def correr(implementacion):
    return correr_pytest(codigo, {"conversion": implementacion})


def prueba_usa_raises():
    """Usa pytest.raises"""
    assert "pytest.raises" in codigo, "Verifica el error con with pytest.raises(...)"


def prueba_pasan():
    """Tus pruebas pasan con el código correcto"""
    resultado, texto = correr(CORRECTA)
    assert resultado != 5, "pytest no encontró pruebas"
    assert resultado == 0, "Alguna prueba falla con el código CORRECTO:\n" + texto[-900:]


def prueba_atrapa_sin_error():
    """Atrapan la versión que devuelve 0 en vez de lanzar el error"""
    mutante = "def a_pesos(texto):\n    try:\n        return int(texto)\n    except ValueError:\n        return 0\n"
    resultado, _ = correr(mutante)
    assert resultado == 1, "Ninguna prueba falló con la versión que no lanza el error"


def prueba_atrapa_mensaje_pobre():
    """Atrapan la versión cuyo mensaje no dice el valor"""
    mutante = "def a_pesos(texto):\n    try:\n        return int(texto)\n    except ValueError:\n        raise ValueError('Error') from None\n"
    resultado, _ = correr(mutante)
    assert resultado == 1, "Ninguna prueba falló con el mensaje «Error». Pista: usa match= en pytest.raises"
```

## Comparar decimales: pytest.approx

```python
import pytest


def test_promedio():
    assert promedio([0.1, 0.2]) == pytest.approx(0.15)
```

`0.1 + 0.2 == 0.3` es falso por el error de float. `pytest.approx` compara con una tolerancia razonable.

## Fixtures: preparación reutilizable

Una **fixture** es una función que prepara algo para las pruebas. Las pruebas la piden **por nombre**, como parámetro:

```python
import pytest

from facturacion import Plan


@pytest.fixture
def plan_hogar():
    return Plan("HOG30", cargo_fijo=35900, minutos_incluidos=300, tarifa_minuto=120)


def test_sin_exceso(plan_hogar):
    assert plan_hogar.valor_voz(100) == 0


def test_con_exceso(plan_hogar):
    assert plan_hogar.valor_voz(342) == 5040
```

Cada prueba recibe un objeto **nuevo**: lo que una prueba modifique no afecta a las demás.

:::reto Tu primera fixture
El módulo `bolsas.py` tiene la clase `BolsaDeMinutos(incluidos)`, con los métodos `consumir(segundos)`, `disponibles()` y `exceso()`.

1. Escribe la fixture `bolsa_300`, que devuelve `BolsaDeMinutos(300)`.
2. Escribe al menos 2 pruebas que la **pidan como parámetro**: una para la bolsa sin consumo y otra que consuma una llamada y revise los minutos.

El curso corre tus pruebas contra una versión con error: `exceso()` devuelve números negativos cuando sobran minutos.

```pyreto
import pytest

from bolsas import BolsaDeMinutos


# La fixture bolsa_300 y tus pruebas

```

:::pista
`@pytest.fixture` encima de `def bolsa_300(): return BolsaDeMinutos(300)`. Luego `def test_bolsa_nueva_no_tiene_exceso(bolsa_300): assert bolsa_300.exceso() == 0`.
:::

```pyprueba
import ast

CORRECTA = (
    "class BolsaDeMinutos:\n"
    "    def __init__(self, incluidos):\n"
    "        self.incluidos = incluidos\n"
    "        self.usados = 0\n"
    "    def consumir(self, segundos):\n"
    "        self.usados += (segundos + 59) // 60\n"
    "    def disponibles(self):\n"
    "        return max(0, self.incluidos - self.usados)\n"
    "    def exceso(self):\n"
    "        return max(0, self.usados - self.incluidos)\n"
)


def correr(implementacion):
    return correr_pytest(codigo, {"bolsas": implementacion})


def prueba_fixture():
    """Definiste la fixture bolsa_300 y al menos 2 pruebas la usan"""
    arbol = ast.parse(codigo)
    funciones = [n for n in ast.walk(arbol) if isinstance(n, ast.FunctionDef)]
    assert any(f.name == "bolsa_300" and f.decorator_list for f in funciones), "Define la fixture bolsa_300 con @pytest.fixture"
    usan = [f for f in funciones if f.name.startswith("test_") and any(a.arg == "bolsa_300" for a in f.args.args)]
    assert len(usan) >= 2, f"Al menos 2 pruebas deben recibir bolsa_300 como parámetro; hay {len(usan)}"


def prueba_pasan():
    """Tus pruebas pasan con el código correcto"""
    resultado, texto = correr(CORRECTA)
    assert resultado != 5, "pytest no encontró pruebas"
    assert resultado == 0, "Alguna prueba falla con el código CORRECTO:\n" + texto[-900:]


def prueba_atrapa_exceso_negativo():
    """Atrapan el exceso negativo"""
    resultado, _ = correr(CORRECTA.replace("return max(0, self.usados - self.incluidos)", "return self.usados - self.incluidos"))
    assert resultado == 1, "Ninguna prueba falló con el exceso negativo. Pista: revisa exceso() en una bolsa con minutos de sobra"
```

### Fixtures que incluye pytest

| Fixture | Para qué |
|---|---|
| `tmp_path` | Una carpeta temporal nueva (un `Path`) para crear archivos de prueba |
| `monkeypatch` | Cambiar temporalmente atributos, variables de entorno o `sys.argv` |
| `capsys` | Capturar lo que se imprime con `print` |
| `caplog` | Capturar los mensajes de `logging` |

```python
def test_resumen_de_archivo(tmp_path):
    archivo = tmp_path / "cdr.csv"
    archivo.write_text("cdr_id|tipo|duracion_seg\n1|VOZ|125\n2|SMS|0\n", encoding="utf-8")

    resumen = resumir(archivo)

    assert resumen["registros"] == 2
```

### conftest.py: fixtures compartidas

Las fixtures que usan varios archivos de pruebas van en `conftest.py`, en la carpeta `tests/`. pytest lo carga solo: no hace falta importarlo.

```python
# tests/conftest.py
import pytest


@pytest.fixture
def archivo_cdr(tmp_path):
    ruta = tmp_path / "cdr.csv"
    ruta.write_text("cdr_id|linea_origen|tipo|duracion_seg\n1|3001|VOZ|125\n", encoding="utf-8")
    return ruta
```

:::capo Alcance de una fixture
`@pytest.fixture(scope="module")` crea el objeto una sola vez para todas las pruebas del archivo. Útil para cosas costosas (leer un archivo grande, abrir una base de datos), pero cuidado: si una prueba lo modifica, afecta a las siguientes.
:::

## Cuestionario

? ¿Qué hace `@pytest.mark.parametrize("segundos,esperado", [(0, 0), (61, 2)])`?
- [ ] Ejecuta la prueba una vez con todos los valores
- [x] Ejecuta la prueba una vez por cada tupla, pasando sus valores como argumentos
- [ ] Genera valores aleatorios
- [ ] Ejecuta la prueba en paralelo
> Cada tupla es un caso independiente que aparece por separado en el reporte.

? ¿Cuándo falla `with pytest.raises(ValueError): a_pesos("abc")`?
- [ ] Cuando `a_pesos` lanza `ValueError`
- [x] Cuando `a_pesos` NO lanza `ValueError`
- [ ] Nunca
- [ ] Siempre
> La prueba verifica que se lance la excepción; si no se lanza, la prueba falla.

? ¿Cómo recibe una prueba la fixture `tmp_path`?
- [ ] Importándola de pytest
- [x] Declarando un parámetro llamado `tmp_path`
- [ ] Llamando a `tmp_path()` dentro de la prueba
- [ ] Con un decorador `@tmp_path`
> pytest ve el nombre del parámetro y le inyecta la fixture correspondiente.
