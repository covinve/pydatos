## Enunciado

Tienes un `requirements.lock` en Git. ¿El entorno de la oficina coincide con él? ¿Y el de casa? Escribe la herramienta que lo verifica, para correrla antes de un proceso importante (o como primer paso de GitHub Actions).

En `ejercicios/m21-e8/verificar_entorno.py` implementa `normalizar`, `leer_bloqueo`, `instaladas`, `comparar` y `main`. El docstring del archivo describe cada una, el formato del bloqueo (tal como lo genera `pip-compile`, con *hashes*, marcadores y comentarios) y el informe que imprime `main`.

Cuando pase `python comprobar.py m21-e8`, pruébala con tu entorno real:

```powershell
pip install pip-tools
pip-compile requirements.txt -o requirements.lock
python ejercicios/m21-e8/verificar_entorno.py requirements.lock
```

Ojo: `--hash=sha256:...` empieza por `-`, así que la misma regla la descarta.

## Pista 2

`importlib.metadata.distributions()` recorre lo instalado; cada distribución tiene `.metadata["Name"]` y `.version`:


En `main`, usa `argparse` con un argumento posicional y `--estricto` (`action="store_true"`).

## Solución

```python verificar_entorno.py
"""Ejercicio m21-e8: ¿mi entorno es exactamente el del archivo de bloqueo?

Uso:
    python ejercicios/m21-e8/verificar_entorno.py requirements.lock
    python ejercicios/m21-e8/verificar_entorno.py requirements.lock --estricto
"""

from __future__ import annotations

import argparse
import re
import sys
from importlib import metadata
from pathlib import Path

IGNORAR = {"pip", "setuptools", "wheel"}


def normalizar(nombre: str) -> str:
    return re.sub(r"[-_.]+", "-", nombre).lower()


def leer_bloqueo(texto: str) -> dict[str, str]:
    bloqueo = {}
    for original in texto.splitlines():
        linea = original.split("#", 1)[0].split(";", 1)[0].rstrip(" \\").strip()
        if not linea or linea.startswith("-"):
            continue
        if "==" not in linea or any(op in linea for op in (">", "<", "~", "!")):
            raise ValueError(f"Requisito sin versión exacta en el bloqueo: {linea}")
        nombre, version = linea.split("==", 1)
        bloqueo[normalizar(nombre.split("[", 1)[0].strip())] = version.strip()
    return bloqueo


def instaladas() -> dict[str, str]:
    return {normalizar(d.metadata["Name"]): d.version for d in metadata.distributions() if d.metadata["Name"]}


def comparar(bloqueo: dict[str, str], instaladas: dict[str, str]) -> dict[str, list]:
    return {
        "faltan": sorted(n for n in bloqueo if n not in instaladas),
        "distintas": sorted((n, v, instaladas[n]) for n, v in bloqueo.items() if n in instaladas and instaladas[n] != v),
        "sobran": sorted(n for n in instaladas if n not in bloqueo and n not in IGNORAR),
    }


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Compara el entorno con un archivo de bloqueo.")
    parser.add_argument("bloqueo", type=Path)
    parser.add_argument("--estricto", action="store_true", help="Los paquetes sobrantes también son error")
    args = parser.parse_args(argv)
    if not args.bloqueo.exists():
        print(f"No existe el archivo de bloqueo {args.bloqueo}", file=sys.stderr)
        return 2

    bloqueo = leer_bloqueo(args.bloqueo.read_text(encoding="utf-8"))
    actuales = instaladas()
    r = comparar(bloqueo, actuales)
    for nombre in r["faltan"]:
        print(f"❌ Falta: {nombre}=={bloqueo[nombre]}")
    for nombre, esperada, instalada in r["distintas"]:
        print(f"❌ Distinta: {nombre} (bloqueo {esperada}, instalada {instalada})")
    if not r["faltan"] and not r["distintas"]:
        print(f"✅ Entorno igual al bloqueo ({len(bloqueo)} paquetes)")
    for nombre in r["sobran"]:
        print(f"⚠️  Sobra: {nombre}=={actuales[nombre]}")
    falla = r["faltan"] or r["distintas"] or (args.estricto and r["sobran"])
    return 1 if falla else 0


if __name__ == "__main__":
    if hasattr(sys.stdout, "reconfigure"):
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
    sys.exit(main())
```

## Explicación

Esta herramienta responde la pregunta que precede a "¿por qué en tu computador da distinto?". Un `❌ Distinta: pandas (bloqueo 2.2.3, instalada 3.0.1)` explica en un segundo una diferencia de redondeo que podría tomar una tarde encontrar.

Algunos detalles del formato de bloqueo que manejaste:

- Los **marcadores** (`; sys_platform == 'win32'`) indican paquetes que solo se instalan en algunos sistemas. Esta versión los trata como siempre requeridos; una versión completa los evaluaría con `packaging.markers`.
- Los **hashes** (`--hash=sha256:...`) garantizan que el archivo descargado es exactamente el esperado (protección contra paquetes alterados). `pip install --require-hashes -r requirements.lock` los verifica.
- `sobran` como advertencia y no como error es una decisión práctica: tener `ipykernel` instalado para trabajar en notebooks no cambia los resultados. `--estricto` existe para Docker o CI, donde el entorno debería ser exacto.

`importlib.metadata` es la forma estándar (biblioteca estándar, sin instalar nada) de consultar qué hay instalado: la misma información que muestra `pip list`.
