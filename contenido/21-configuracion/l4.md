El peor momento para descubrir que `TELCO_UMBRAL=dos` no es un número es a las 6:47, después de procesar 15 GB. **pydantic-settings** lee la configuración de todas las fuentes, la **convierte** a los tipos correctos y la **valida** al arrancar: si algo está mal, el programa no empieza y te dice exactamente qué.

## Una clase de configuración

```python
from pathlib import Path

from pydantic import Field, SecretStr
from pydantic_settings import BaseSettings, SettingsConfigDict


class Config(BaseSettings):
    model_config = SettingsConfigDict(env_prefix="TELCO_", env_file=".env", env_file_encoding="utf-8")

    datos: Path = Path("datos")
    umbral_rechazo: float = Field(5.0, ge=0, le=100)
    tamano_lote: int = Field(100_000, gt=0)
    enviar_alertas: bool = False
    correos_alerta: list[str] = []
    db_url: SecretStr | None = None


config = Config()                          # lee entorno + .env, convierte y valida
print(config.umbral_rechazo, config.datos)
print(config.db_url)                       # SecretStr('**********')
url = config.db_url.get_secret_value()     # el valor real, solo donde se necesita
```

| Variable de entorno | Campo | Conversión |
|---|---|---|
| `TELCO_DATOS=D:/cdr` | `datos` | `Path("D:/cdr")` |
| `TELCO_UMBRAL_RECHAZO=2.5` | `umbral_rechazo` | `2.5` (y verifica 0–100) |
| `TELCO_ENVIAR_ALERTAS=true` | `enviar_alertas` | `True` (acepta `true`, `1`, `yes`, `on`…) |
| `TELCO_CORREOS_ALERTA=["a@x.co","b@x.co"]` | `correos_alerta` | Lista (en formato JSON) |
| `TELCO_DB_URL=postgresql://...` | `db_url` | `SecretStr`: no se imprime |

## Errores claros al arrancar

```text
$ set TELCO_UMBRAL_RECHAZO=dos
$ python -m conciliacion
pydantic_core._pydantic_core.ValidationError: 1 validation error for Config
umbral_rechazo
  Input should be a valid number, unable to parse string as a number [type=float_parsing, input_value='dos', input_type=str]
```

Compáralo con un `float(os.environ["TELCO_UMBRAL"])` perdido en la línea 340: aquí el error dice **qué** campo, **qué** valor llegó y **qué** se esperaba, antes de tocar un solo archivo.

:::reto Una configuración que falla temprano
En esta página no está `pydantic-settings`, pero sí `pydantic`, que hace exactamente la misma conversión y validación. Escribe:

1. El modelo `Config` (hereda de `BaseModel`) con: `umbral_rechazo: float` (0 a 100, por defecto 5.0), `tamano_lote: int` (mayor que 0, por defecto 100000), `enviar_alertas: bool` (por defecto `False`) y `db_url: SecretStr | None` (por defecto `None`).
2. `desde_entorno(entorno)`: recibe un diccionario como `os.environ`, toma solo las variables que empiezan con `TELCO_`, les quita el prefijo, las pasa a minúsculas y crea el `Config` con ellas.

```pyreto
from pydantic import BaseModel, Field, SecretStr, ValidationError

# Config y desde_entorno


config = desde_entorno({"TELCO_UMBRAL_RECHAZO": "2.5", "TELCO_ENVIAR_ALERTAS": "true",
                        "TELCO_DB_URL": "postgresql://carlos:clave@localhost/fact", "PATH": "C:/Windows"})
print(config)
```

:::pista
Los límites van en `Field`: `umbral_rechazo: float = Field(5.0, ge=0, le=100)`. Para el entorno: `{clave.removeprefix("TELCO_").lower(): valor for clave, valor in entorno.items() if clave.startswith("TELCO_")}` y luego `Config(**valores)`.
:::

```pyprueba
from pydantic import SecretStr, ValidationError


def prueba_convierte():
    """Convierte los textos a sus tipos"""
    requiere("desde_entorno")
    c = desde_entorno({"TELCO_UMBRAL_RECHAZO": "2.5", "TELCO_ENVIAR_ALERTAS": "true", "TELCO_TAMANO_LOTE": "500", "OTRA": "x"})
    igual((c.umbral_rechazo, c.enviar_alertas, c.tamano_lote, c.db_url), (2.5, True, 500, None))


def prueba_defectos():
    """Sin variables usa los valores por defecto"""
    c = desde_entorno({})
    igual((c.umbral_rechazo, c.tamano_lote, c.enviar_alertas), (5.0, 100000, False))


def prueba_valida():
    """Rechaza valores inválidos al crearla"""
    for malas in ({"TELCO_UMBRAL_RECHAZO": "dos"}, {"TELCO_UMBRAL_RECHAZO": "150"}, {"TELCO_TAMANO_LOTE": "0"}):
        lanza(ValidationError, desde_entorno, malas)


def prueba_secreto():
    """La URL es secreta"""
    c = desde_entorno({"TELCO_DB_URL": "postgresql://u:clave@h/db"})
    assert isinstance(c.db_url, SecretStr), "db_url debe ser SecretStr"
    assert "clave" not in str(c), "La contraseña no debe aparecer al imprimir la configuración"
    igual(c.db_url.get_secret_value(), "postgresql://u:clave@h/db")
```

```pysolucion
from pydantic import BaseModel, Field, SecretStr, ValidationError


class Config(BaseModel):
    umbral_rechazo: float = Field(5.0, ge=0, le=100)
    tamano_lote: int = Field(100_000, gt=0)
    enviar_alertas: bool = False
    db_url: SecretStr | None = None


def desde_entorno(entorno):
    valores = {clave.removeprefix("TELCO_").lower(): valor for clave, valor in entorno.items() if clave.startswith("TELCO_")}
    return Config(**valores)


config = desde_entorno({"TELCO_UMBRAL_RECHAZO": "2.5", "TELCO_ENVIAR_ALERTAS": "true",
                        "TELCO_DB_URL": "postgresql://carlos:clave@localhost/fact", "PATH": "C:/Windows"})
print(config)
```
:::

## Validaciones propias

```python
from pydantic import field_validator


class Config(BaseSettings):
    ...
    periodo: str = "202609"
    memoria_duckdb: str = "4GB"

    @field_validator("periodo")
    @classmethod
    def periodo_valido(cls, valor: str) -> str:
        if len(valor) != 6 or not valor.isdigit() or not 1 <= int(valor[4:]) <= 12:
            raise ValueError("el periodo debe tener formato AAAAMM")
        return valor

    @field_validator("memoria_duckdb")
    @classmethod
    def memoria_valida(cls, valor: str) -> str:
        if not valor.upper().endswith(("MB", "GB")) or not valor[:-2].isdigit():
            raise ValueError("usa un formato como 512MB u 8GB")
        return valor.upper()
```

:::reto Tus propias validaciones
Escribe el modelo `ConfigPeriodo` (de `BaseModel`) con dos campos y sus validadores:

- `periodo: str` en formato `AAAAMM` con mes de 01 a 12; si no, `ValueError("el periodo debe tener formato AAAAMM")`;
- `memoria_duckdb: str`, por defecto `"4GB"`, con formato como `512MB` u `8GB` (se acepta en minúsculas, pero se guarda en **mayúsculas**).

```pyreto
from pydantic import BaseModel, ValidationError, field_validator

# class ConfigPeriodo(BaseModel): ...


print(ConfigPeriodo(periodo="202609", memoria_duckdb="8gb"))
```

:::pista
Copia la forma de los validadores de la lección: `@field_validator("periodo")` sobre `@classmethod` y `def periodo_valido(cls, valor): ...` que lanza `ValueError` o devuelve el valor (en el de la memoria, `valor.upper()`).
:::

```pyprueba
from pydantic import ValidationError


def prueba_validos():
    """Acepta y normaliza valores válidos"""
    requiere("ConfigPeriodo")
    c = ConfigPeriodo(periodo="202609", memoria_duckdb="8gb")
    igual((c.periodo, c.memoria_duckdb), ("202609", "8GB"))
    igual(ConfigPeriodo(periodo="202612").memoria_duckdb, "4GB", "por defecto")


def prueba_periodos_malos():
    """Rechaza periodos inválidos"""
    for malo in ("202613", "2026-09", "26", "abcdef"):
        error = lanza(ValidationError, ConfigPeriodo, periodo=malo)
        assert "AAAAMM" in str(error), f"El mensaje debe explicar el formato: {error}"


def prueba_memoria_mala():
    """Rechaza memorias sin unidad válida"""
    for mala in ("8", "8TB", "GB", "ocho GB"):
        lanza(ValidationError, ConfigPeriodo, periodo="202609", memoria_duckdb=mala)
```

## Precedencia y argumentos

Por defecto, pydantic-settings aplica: **argumentos al crear** `Config(umbral_rechazo=1.5)` > variables de entorno > `.env` > valores por defecto. Así, en la CLI basta con pasar lo que el usuario escribió:

```python
@app.command()
def conciliar(umbral: float | None = None):
    sobrescritos = {"umbral_rechazo": umbral} if umbral is not None else {}
    config = Config(**sobrescritos)
    ...
```

Para agregar un archivo TOML como fuente intermedia, `SettingsConfigDict(toml_file="config.toml")` y sobrescribir `settings_customise_sources` (lo harás en el ejercicio 9), o leerlo tú con `tomllib` y pasarlo como base.

:::capo Configuración inmutable y en un solo lugar
Crea la configuración **una vez**, al arrancar (en la raíz de composición del módulo 19), y pásala a quien la necesite. Si cada función llama `Config()` por su cuenta, el `.env` se lee mil veces y las pruebas tienen que parchear en mil lugares. Con `model_config = SettingsConfigDict(frozen=True, ...)` nadie puede cambiarla a mitad del proceso.
:::
