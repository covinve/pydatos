## Enunciado

Completa la clase `Factura` con dos métodos especiales:

- `__repr__` → `Factura('F2026090000001', 'CL0000001', 48719)` (los textos con comillas, como los muestra `repr`).
- `__str__` → `Factura F2026090000001 · cliente CL0000001 · total $48.719` (con punto de miles).

```python
f = Factura("F2026090000001", "CL0000001", 48719)
print(f)        # Factura F2026090000001 · cliente CL0000001 · total $48.719
print([f])      # [Factura('F2026090000001', 'CL0000001', 48719)]
```

## Código inicial

```python
class Factura:
    def __init__(self, factura_id, cliente_id, total):
        self.factura_id = factura_id
        self.cliente_id = cliente_id
        self.total = total


f = Factura("F2026090000001", "CL0000001", 48719)
print(f)
print([f])
```

## Pruebas

```python
def prueba_repr():
    """__repr__ es inequívoco"""
    f = Factura("F2026090000001", "CL0000001", 48719)
    igual(repr(f), "Factura('F2026090000001', 'CL0000001', 48719)")


def prueba_str():
    """__str__ es legible y con punto de miles"""
    igual(str(Factura("F1", "CL1", 1234567)), "Factura F1 · cliente CL1 · total $1.234.567")


def prueba_en_listas():
    """Dentro de una lista se usa __repr__"""
    igual(str([Factura("F1", "CL1", 5)]), "[Factura('F1', 'CL1', 5)]")


def prueba_en_fstring():
    """Un f-string usa __str__"""
    igual(f"{Factura('F9', 'CL9', 950)}", "Factura F9 · cliente CL9 · total $950")
```

## Pista 1

`__repr__` y `__str__` son métodos que devuelven un texto. Dentro de un f-string, `{self.factura_id!r}` aplica `repr()` y agrega las comillas.

## Pista 2

```python
def __repr__(self):
    return f"Factura({self.factura_id!r}, {self.cliente_id!r}, {self.total!r})"

def __str__(self):
    total = f"{self.total:,}".replace(",", ".")
    return f"Factura {self.factura_id} · cliente {self.cliente_id} · total ${total}"
```

## Solución

```python
class Factura:
    def __init__(self, factura_id, cliente_id, total):
        self.factura_id = factura_id
        self.cliente_id = cliente_id
        self.total = total

    def __repr__(self):
        return f"Factura({self.factura_id!r}, {self.cliente_id!r}, {self.total!r})"

    def __str__(self):
        total = f"{self.total:,}".replace(",", ".")
        return f"Factura {self.factura_id} · cliente {self.cliente_id} · total ${total}"


f = Factura("F2026090000001", "CL0000001", 48719)
print(f)
print([f])
```

## Explicación

Un buen `__repr__` parece el código que crea el objeto: si lo copias en la consola, obtienes un objeto igual. Es lo que verás en el depurador, en los logs con `%r` y en los mensajes de error, así que vale la pena escribirlo siempre.

`__str__` es para las personas: aquí, el formato que iría en un reporte.
