## Enunciado

1. `minutos_por_cliente(cdr, clientes)` → DataFrame con `linea`, `plan_id` y `minutos` (facturables de VOZ con duración ≥ 0) de **todos** los clientes (los que no hablaron, con 0).

Título `Minutos al mes por cliente, según el plan`.

    t = minutos_por_cliente(CDR, CLI)
    ax = cajas_por_plan(t, INC).axes[0]
    valores = set()
    for coleccion in ax.collections:
        for segmento in coleccion.get_segments():

    for linea in ax.lines:

            valores.add(round(float(linea.get_ydata()[0])))
    esperados = {INC[p] for p in t["plan_id"].unique() if INC[p] != -1}
    assert esperados <= valores, f"Faltan líneas de referencia: {esperados - valores}"

## Solución

```python
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
INCLUIDOS = {"BAS10": 100, "HOG30": 300, "HOG60": 600, "ILIM": -1, "EMP100": 1000, "EMP300": 3000}


def minutos_por_cliente(cdr, clientes):
    voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)]
    minutos = ((voz["duracion_seg"] + 59) // 60).groupby(voz["linea_origen"]).sum().rename("minutos")
    tabla = clientes[["linea", "plan_id"]].merge(minutos, left_on="linea", right_index=True, how="left")
    tabla["minutos"] = tabla["minutos"].fillna(0).astype(int)
    return tabla


def cajas_por_plan(tabla, incluidos):
    planes = sorted(tabla["plan_id"].unique())
    fig, ax = plt.subplots(figsize=(8, 4))
    ax.boxplot([tabla.loc[tabla["plan_id"] == p, "minutos"] for p in planes], tick_labels=planes)
    for posicion, plan in enumerate(planes, start=1):
        if incluidos[plan] != -1:
            ax.hlines(incluidos[plan], posicion - 0.4, posicion + 0.4, colors="#dc2626", linestyles=":")
    ax.set_title("Minutos al mes por cliente, según el plan")
    ax.set_ylabel("Minutos")
    return fig


fig = cajas_por_plan(minutos_por_cliente(cdr, clientes), INCLUIDOS)
```

## Explicación

Las cajas muestran la distribución completa del consumo de cada plan, y la línea punteada marca la bolsa incluida. De un vistazo se ve si la mayoría de los clientes queda por debajo (el plan les sobra), por encima (pagan excesos y quizá les convendría otro plan) o alrededor.

Incluir a los clientes **sin** consumo es importante: si los quitas, el plan parece más usado de lo que es. Es el mismo cuidado con el `merge` que viste en el módulo 14.
