**Configuración** es todo lo que cambia entre ambientes sin cambiar el código: rutas de datos, umbrales, la URL de la base de datos, el tamaño de los lotes, la contraseña. Si para correr en casa tienes que editar el `.py`, eso era configuración escondida en el código.

## Las fuentes y su precedencia

:::pasos De la más general a la más específica
:::paso 1. Valores por defecto (en el código)
`umbral = 5.0`, `tamano_lote = 100_000`. Sensatos para la mayoría de los casos.
:::
:::paso 2. Archivo de configuración (TOML, en Git)
`config.toml` con lo propio del proyecto o del ambiente: carpetas, periodos, umbrales de negocio. **Sin secretos.**
:::
:::paso 3. Archivo `.env` (local, fuera de Git)
Lo propio de **tu** máquina: tu ruta `D:\datos`, tu token. Cada persona tiene el suyo.
:::
:::paso 4. Variables de entorno
Lo que define quien ejecuta: el Programador de tareas, GitHub Actions, Docker (`-e TELCO_UMBRAL=2`).
:::
:::paso 5. Argumentos de la línea de comandos
`--umbral 1.5`: la decisión de este momento. **Gana sobre todo lo anterior.**
:::
:::

Cada capa **sobrescribe** a la anterior solo en lo que define. Así un valor por defecto sirve hasta que alguien, en algún nivel, decida otra cosa.

:::reto ¿Quién gana?
Escribe `resolver(*capas)`: recibe diccionarios ordenados de la capa **más general** a la **más específica** y devuelve la configuración final, donde cada capa sobrescribe a las anteriores. Un valor `None` en una capa significa "esta capa no lo define" y **no** sobrescribe.

```pyreto
def resolver(*capas):
    pass


defectos = {"umbral": 5.0, "lote": 100_000, "alertas": False}
archivo = {"umbral": 3.0, "alertas": True}
entorno = {"umbral": 2.5}
argumentos = {"umbral": None, "lote": 50_000}      # el usuario no pasó --umbral

print(resolver(defectos, archivo, entorno, argumentos))
# {'umbral': 2.5, 'lote': 50000, 'alertas': True}
```

:::pista
Empieza con un diccionario vacío y recorre las capas en orden; dentro, recorre `capa.items()` y asigna solo si el valor no es `None`.
:::

```pyprueba
def prueba_precedencia():
    """La capa más específica gana"""
    requiere("resolver")
    r = resolver({"umbral": 5.0, "lote": 100000, "alertas": False}, {"umbral": 3.0, "alertas": True}, {"umbral": 2.5}, {"umbral": None, "lote": 50000})
    igual(r, {"umbral": 2.5, "lote": 50000, "alertas": True})


def prueba_none_no_pisa():
    """None no sobrescribe"""
    igual(resolver({"a": 1}, {"a": None}), {"a": 1})
    igual(resolver({"a": 1}, {"b": 2}, {"a": 3}), {"a": 3, "b": 2})
    igual(resolver(), {}, "sin capas")


def prueba_no_modifica():
    """No modifica las capas"""
    base = {"a": 1}
    resolver(base, {"a": 2})
    igual(base, {"a": 1}, "la primera capa fue modificada")
```

```pysolucion
def resolver(*capas):
    final = {}
    for capa in capas:
        for clave, valor in capa.items():
            if valor is not None:
                final[clave] = valor
    return final


defectos = {"umbral": 5.0, "lote": 100_000, "alertas": False}
archivo = {"umbral": 3.0, "alertas": True}
entorno = {"umbral": 2.5}
argumentos = {"umbral": None, "lote": 50_000}      # el usuario no pasó --umbral

print(resolver(defectos, archivo, entorno, argumentos))
# {'umbral': 2.5, 'lote': 50000, 'alertas': True}
```

## TOML con tomllib

TOML es el formato de `pyproject.toml`: legible, con tipos (números, booleanos, fechas, listas) y comentarios. Python lo lee sin instalar nada:

```pyrun
import tomllib

texto = """
# config.toml — configuración del proceso de conciliación
periodo = "202609"
umbral_rechazo = 2.5
enviar_alertas = true

[rutas]
datos = "D:/datos/cdr"
salidas = "salidas"

[duckdb]
memoria = "8GB"
hilos = 6
"""
config = tomllib.loads(texto)            # con un archivo: tomllib.load(open("config.toml", "rb"))
print(config["umbral_rechazo"], type(config["umbral_rechazo"]))
print(config["rutas"]["datos"], config["duckdb"])
```

:::consejo Barras en rutas de Windows
En TOML, `"D:\datos"` es un error (`\d` es una secuencia de escape). Usa `"D:/datos"` (Python acepta `/` en Windows) o comillas simples, que no interpretan escapes: `'D:\datos'`.
:::

:::reto Valores por defecto más archivo
Escribe `cargar_config(texto_toml)`: lee el TOML con `tomllib` y devuelve un diccionario que parte de `POR_DEFECTO` y **sobrescribe** solo lo que el archivo define. Las secciones (como `[rutas]`) se combinan clave por clave: si el archivo solo define `rutas.datos`, `rutas.salidas` conserva su valor por defecto.

El TOML de ejemplo tiene una ruta de Windows mal escrita: corrígela para que se pueda leer.

```pyreto
import tomllib

POR_DEFECTO = {
    "umbral_rechazo": 5.0,
    "enviar_alertas": False,
    "rutas": {"datos": "datos", "salidas": "salidas"},
}

TEXTO = """
umbral_rechazo = 2.5

[rutas]
datos = "D:\\datos\\cdr"
"""


def cargar_config(texto_toml):
    pass


print(cargar_config(TEXTO))
```

:::pista
La ruta se arregla con comillas simples (`'D:\datos\cdr'`) o con barras normales (`"D:/datos/cdr"`). Para combinar: copia `POR_DEFECTO`, y para cada clave del TOML, si ambos valores son diccionarios, combínalos con `{**defecto, **nuevo}`; si no, reemplaza.
:::

```pyprueba
def prueba_combina():
    """Sobrescribe solo lo definido"""
    requiere("cargar_config")
    r = cargar_config("umbral_rechazo = 2.5\n[rutas]\ndatos = 'D:\\datos\\cdr'\n")
    igual(r["umbral_rechazo"], 2.5, "umbral_rechazo")
    igual(r["enviar_alertas"], False, "enviar_alertas (por defecto)")
    igual(r["rutas"], {"datos": "D:\\datos\\cdr", "salidas": "salidas"}, "rutas")


def prueba_no_modifica_defectos():
    """POR_DEFECTO no cambia"""
    cargar_config("enviar_alertas = true\n[rutas]\nsalidas = 'otra'\n")
    igual(POR_DEFECTO["rutas"], {"datos": "datos", "salidas": "salidas"}, "POR_DEFECTO fue modificado")


def prueba_texto_ejemplo():
    """El TOML de ejemplo ya se puede leer"""
    requiere("TEXTO")
    r = cargar_config(TEXTO)
    assert r["rutas"]["datos"] in ("D:\\datos\\cdr", "D:/datos/cdr"), f"Ruta leída: {r['rutas']['datos']!r}"
```

```pysolucion
import tomllib

POR_DEFECTO = {
    "umbral_rechazo": 5.0,
    "enviar_alertas": False,
    "rutas": {"datos": "datos", "salidas": "salidas"},
}

TEXTO = """
umbral_rechazo = 2.5

[rutas]
datos = 'D:\\datos\\cdr'
"""


def cargar_config(texto_toml):
    leido = tomllib.loads(texto_toml)
    config = {clave: (dict(valor) if isinstance(valor, dict) else valor) for clave, valor in POR_DEFECTO.items()}
    for clave, valor in leido.items():
        if isinstance(valor, dict) and isinstance(config.get(clave), dict):
            config[clave] = {**config[clave], **valor}
        else:
            config[clave] = valor
    return config


print(cargar_config(TEXTO))
```

## Variables de entorno y .env

Las variables de entorno siempre son **texto**: `os.environ["TELCO_UMBRAL"]` es `"2.5"`, no `2.5`. Hay que convertirlas, y decidir qué significa `"true"`, `"1"` o `"si"`.

Un archivo `.env` es una lista de variables que tu programa carga al arrancar (con `python-dotenv`), para no tener que definirlas a mano en cada terminal:

```bash
# .env — NO va a Git
TELCO_DATOS=D:/datos/cdr
TELCO_UMBRAL=2.5
TELCO_DB_URL=postgresql+psycopg://carlos:clave-secreta@localhost:5432/facturacion
```

```python
from dotenv import load_dotenv

load_dotenv()                     # lee .env y define las variables que AÚN no existan
umbral = float(os.environ.get("TELCO_UMBRAL", "5.0"))
```

`load_dotenv()` no pisa variables que ya existen: si el Programador de tareas define `TELCO_UMBRAL`, gana sobre el `.env`. Respeta la precedencia.

:::reto Las variables de entorno son texto
Escribe dos funciones:

1. `a_booleano(texto)`: `True` para `"true"`, `"1"`, `"si"`, `"sí"`, `"yes"` y `"on"`; `False` para `"false"`, `"0"`, `"no"` y `"off"` (sin distinguir mayúsculas ni espacios). Cualquier otro valor lanza `ValueError` con el texto recibido.
2. `leer_entorno()`: devuelve `(umbral, alertas)` a partir de `TELCO_UMBRAL` (un `float`, por defecto `5.0`) y `TELCO_ALERTAS` (un booleano, por defecto `False`).

```pyreto
import os


def a_booleano(texto):
    pass


def leer_entorno():
    pass


os.environ["TELCO_UMBRAL"] = "2.5"
os.environ["TELCO_ALERTAS"] = " Sí "
print(leer_entorno())   # (2.5, True)
```

:::pista
Normaliza con `texto.strip().lower()` y compara con dos conjuntos de valores. En `leer_entorno`, `os.environ.get("TELCO_UMBRAL", "5.0")` y conviértelo con `float`; para las alertas usa `a_booleano(os.environ.get("TELCO_ALERTAS", "false"))`.
:::

```pyprueba
import os


def prueba_booleanos():
    """a_booleano entiende las formas comunes"""
    requiere("a_booleano")
    for texto in ("true", "1", "si", "sí", "YES", " On "):
        igual(a_booleano(texto), True, repr(texto))
    for texto in ("false", "0", "no", "OFF"):
        igual(a_booleano(texto), False, repr(texto))
    error = lanza(ValueError, a_booleano, "talvez")
    assert "talvez" in str(error), f"El mensaje debe incluir el valor recibido: {error}"


def prueba_entorno():
    """leer_entorno convierte y usa valores por defecto"""
    requiere("leer_entorno")
    os.environ["TELCO_UMBRAL"] = "1.75"
    os.environ["TELCO_ALERTAS"] = "0"
    igual(leer_entorno(), (1.75, False))
    os.environ.pop("TELCO_UMBRAL")
    os.environ.pop("TELCO_ALERTAS")
    igual(leer_entorno(), (5.0, False), "sin variables")
```

```pysolucion
import os

VERDADEROS = {"true", "1", "si", "sí", "yes", "on"}
FALSOS = {"false", "0", "no", "off"}


def a_booleano(texto):
    limpio = texto.strip().lower()
    if limpio in VERDADEROS:
        return True
    if limpio in FALSOS:
        return False
    raise ValueError(f"No es un booleano: {texto!r}")


def leer_entorno():
    umbral = float(os.environ.get("TELCO_UMBRAL", "5.0"))
    alertas = a_booleano(os.environ.get("TELCO_ALERTAS", "false"))
    return umbral, alertas


os.environ["TELCO_UMBRAL"] = "2.5"
os.environ["TELCO_ALERTAS"] = " Sí "
print(leer_entorno())   # (2.5, True)
```

## Secretos

Un **secreto** es cualquier valor que da acceso: contraseñas, tokens, llaves de API, cadenas de conexión con contraseña.

:::error Las reglas de los secretos
1. **Nunca** en el código ni en `config.toml`. Solo en variables de entorno, `.env` (fuera de Git) o un gestor de secretos.
2. `.env` en `.gitignore` **desde el primer commit**. Sube un `.env.example` con los nombres y valores de mentira, para que otros sepan qué definir.
3. **Nunca** en los registros: un `logger.info(f"Conectando a {url}")` con la contraseña dentro la deja en un archivo que lee medio mundo.
4. Si un secreto llegó a Git (aunque sea un minuto, aunque lo borres después): considéralo **comprometido** y **cámbialo**. El historial de Git lo guarda para siempre, y los repositorios públicos son escaneados por robots en minutos.
:::

```text
# .gitignore
.env
.venv/
datos/
salidas/
```

:::reto La contraseña no va al registro
Escribe `ocultar(url)`: recibe una cadena de conexión como `postgresql+psycopg://carlos:clave-secreta@localhost:5432/facturacion` y devuelve la misma URL con la contraseña reemplazada por `****`. Si la URL no tiene contraseña, la devuelve igual. Así puedes registrar `log.info("Conectando a %s", ocultar(url))` sin filtrar el secreto.

```pyreto
from urllib.parse import urlsplit, urlunsplit


def ocultar(url):
    pass


print(ocultar("postgresql+psycopg://carlos:clave-secreta@localhost:5432/facturacion"))
# postgresql+psycopg://carlos:****@localhost:5432/facturacion
```

:::pista
`partes = urlsplit(url)` te da `partes.password`, `partes.username`, `partes.hostname` y `partes.port`. Si hay contraseña, arma el nuevo `netloc` (`f"{usuario}:****@{host}"`, con `:{puerto}` si hay) y reconstruye con `urlunsplit(partes._replace(netloc=nuevo))`.
:::

```pyprueba
def prueba_oculta():
    """Reemplaza la contraseña"""
    requiere("ocultar")
    igual(ocultar("postgresql+psycopg://carlos:clave-secreta@localhost:5432/facturacion"),
          "postgresql+psycopg://carlos:****@localhost:5432/facturacion")
    igual(ocultar("mssql+pyodbc://ana:x9!@servidor/fact"), "mssql+pyodbc://ana:****@servidor/fact", "sin puerto")


def prueba_sin_clave():
    """Sin contraseña, queda igual"""
    igual(ocultar("sqlite:///telco.db"), "sqlite:///telco.db")
    igual(ocultar("postgresql://localhost:5432/fact"), "postgresql://localhost:5432/fact")


def prueba_no_filtra():
    """El secreto no aparece en el resultado"""
    assert "clave-secreta" not in ocultar("postgresql://u:clave-secreta@h/db"), "La contraseña sigue visible"
```

```pysolucion
from urllib.parse import urlsplit, urlunsplit


def ocultar(url):
    partes = urlsplit(url)
    if not partes.password:
        return url
    netloc = f"{partes.username}:****@{partes.hostname}"
    if partes.port:
        netloc += f":{partes.port}"
    return urlunsplit(partes._replace(netloc=netloc))


print(ocultar("postgresql+psycopg://carlos:clave-secreta@localhost:5432/facturacion"))
# postgresql+psycopg://carlos:****@localhost:5432/facturacion
```

## Cuestionario

? El valor de `--umbral` en la línea de comandos y el de `TELCO_UMBRAL` son distintos. ¿Cuál gana?
- [x] El de la línea de comandos
- [ ] La variable de entorno
- [ ] El del archivo TOML
- [ ] El valor por defecto
> La fuente más específica (la decisión de quien ejecuta, en este momento) gana sobre las más generales.

? Subiste por error un `.env` con un token a GitHub y lo borraste a los 2 minutos. ¿Qué haces?
- [ ] Nada, ya lo borré
- [ ] Hacer otro commit encima
- [x] Revocar ese token y generar uno nuevo: quedó en el historial y pudo ser copiado
- [ ] Hacer el repositorio privado y listo
> El historial de Git conserva el archivo, y los robots escanean repositorios públicos en minutos.

- [ ] Depende del sistema operativo
