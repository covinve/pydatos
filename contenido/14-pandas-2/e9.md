## Enunciado

Saber **cuánto** no cuadra no basta: el equipo de facturación necesita saber **por qué**, para corregir la causa. El código inicial ya trae `detalle_correcto(...)`, que calcula la factura correcta **por concepto** para cada cliente (con las mismas columnas que `facturas.csv`).

Escribe `diagnosticar(correctas, emitidas)` que compare concepto por concepto y devuelva un DataFrame con las columnas `cliente_id`, `motivo` y `diferencia` (total emitido − total correcto), **solo** de las facturas con problemas, ordenado por `cliente_id`. El `motivo` es:

1. `"inconsistencia_interna"` si en la factura emitida `total != subtotal + iva` (la factura no cuadra ni consigo misma);
2. si no, el **primer** concepto distinto entre emitida y correcta, en este orden: `valor_voz`, `valor_internacional`, `valor_datos`, `valor_sms`, `descuento`;
3. si ningún concepto difiere pero el total sí, `"otro"`.

Y `resumen(diagnostico)` → diccionario `{motivo: {"facturas": n, "diferencia": suma}}`, ordenado por motivo.

## Pista 1

Une correctas y emitidas por `cliente_id` con sufijos (`suffixes=("_ok", "_emi")`). Luego arma una máscara por concepto: `cruce[f"{c}_emi"] != cruce[f"{c}_ok"]`.

La inconsistencia interna: `cruce["total_emi"] != cruce["subtotal_emi"] + cruce["iva_emi"]`.

## Pista 2

`np.select` elige la primera condición verdadera, justo lo que pide la prioridad:

```python
condiciones = [inconsistente] + [cruce[f"{c}_emi"] != cruce[f"{c}_ok"] for c in CONCEPTOS]
motivo = np.select(condiciones, ["inconsistencia_interna"] + CONCEPTOS, default="otro")
```

Filtra solo las filas donde el total difiere **o** hay inconsistencia.

## Solución

```python
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
planes = pd.read_csv("planes.csv")
emitidas = pd.read_csv("facturas.csv", dtype={"linea": "string"})
CONCEPTOS = ["valor_voz", "valor_internacional", "valor_datos", "valor_sms", "descuento"]


def detalle_correcto(cdr, clientes, planes):
    fecha = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    v = cdr[~cdr.duplicated("cdr_id") & cdr["linea_origen"].isin(clientes["linea"])
            & cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (cdr["duracion_seg"] >= 0) & fecha.notna()].copy()
    minutos = (v["duracion_seg"] + 59) // 60
    voz, inter = v["tipo"] == "VOZ", v["destino"] == "INTERNACIONAL"
    v["mn"], v["mi"] = np.where(voz & ~inter, minutos, 0), np.where(voz & inter, minutos, 0)
    v["mb2"], v["s"] = np.where(v["tipo"] == "DATOS", v["mb"], 0.0), (v["tipo"] == "SMS").astype(int)
    consumo = v.groupby("linea_origen").agg(mn=("mn", "sum"), mi=("mi", "sum"), mb=("mb2", "sum"), s=("s", "sum"))
    df = clientes.merge(planes.drop(columns="segmento"), on="plan_id").merge(consumo, left_on="linea", right_index=True, how="left")
    df[["mn", "mi", "mb", "s"]] = df[["mn", "mi", "mb", "s"]].fillna(0)

    def exceso(c, i, t):
        return np.where(i == -1, 0, np.maximum(c - i, 0) * t)

    r = pd.DataFrame({"cliente_id": df["cliente_id"]})
    r["valor_voz"] = exceso(df["mn"], df["minutos_incluidos"], df["tarifa_minuto"]).astype(int)
    r["valor_internacional"] = (df["mi"] * df["tarifa_minuto_internacional"]).astype(int)
    r["valor_datos"] = exceso(np.ceil(np.round(df["mb"], 3)), df["mb_incluidos"], df["tarifa_mb"]).astype(int)
    r["valor_sms"] = exceso(df["s"], df["sms_incluidos"], df["tarifa_sms"]).astype(int)
    r["descuento"] = np.where((df["segmento"] == "EMPRESARIAL") & (df["fecha_alta"] < "2023-09-01"),
                              np.floor(df["cargo_fijo"] * 0.10 + 0.5), 0).astype(int)
    r["subtotal"] = df["cargo_fijo"] + r[CONCEPTOS[:4]].sum(axis=1) - r["descuento"]
    r["iva"] = np.floor(r["subtotal"] * 0.19 + 0.5).astype(int)
    r["total"] = r["subtotal"] + r["iva"]
    return r


def diagnosticar(correctas, emitidas):
    columnas = ["cliente_id", *CONCEPTOS, "subtotal", "iva", "total"]
    cruce = correctas[columnas].merge(emitidas[columnas], on="cliente_id", suffixes=("_ok", "_emi"), validate="one_to_one")
    inconsistente = cruce["total_emi"] != cruce["subtotal_emi"] + cruce["iva_emi"]
    condiciones = [inconsistente] + [cruce[f"{c}_emi"] != cruce[f"{c}_ok"] for c in CONCEPTOS]
    cruce["motivo"] = np.select(condiciones, ["inconsistencia_interna", *CONCEPTOS], default="otro")
    cruce["diferencia"] = cruce["total_emi"] - cruce["total_ok"]
    con_problema = (cruce["diferencia"] != 0) | inconsistente
    return cruce.loc[con_problema, ["cliente_id", "motivo", "diferencia"]].sort_values("cliente_id").reset_index(drop=True)


def resumen(diagnostico):
    agrupado = diagnostico.groupby("motivo")["diferencia"].agg(["size", "sum"]).sort_index()
    return {motivo: {"facturas": int(fila["size"]), "diferencia": int(fila["sum"])} for motivo, fila in agrupado.iterrows()}


d = diagnosticar(detalle_correcto(cdr, clientes, planes), emitidas)
print(d)
print(resumen(d))
```

## Explicación

Este diagnóstico convierte una lista de "facturas que no cuadran" en **acciones**: si la mayoría de las diferencias están en `valor_datos`, hay que revisar la tarificación de datos; si son inconsistencias internas, el problema está en el proceso que arma la factura, no en el consumo.

`np.select` vuelve a ser la herramienta para "el primer motivo que aplique". El orden de las condiciones es una decisión de negocio: primero se descarta que la factura esté mal construida, y solo después se compara contra el consumo.

`iterrows` en `resumen` está bien aquí: recorre los **motivos** (cinco o seis filas), no los millones de registros. La regla no es "nunca uses bucles", sino "no recorras fila por fila los datos grandes".
