## Enunciado

Para revisar posibles anomalías, compara cada llamada con el comportamiento de **su propia línea**. Con las llamadas `VOZ` contestadas (duración > 0), escribe `perfilar(cdr)` que devuelva un DataFrame con las columnas originales más:

| Columna | Cálculo (usa `transform`) |
|---|---|
| `llamadas_linea` | Cantidad de llamadas de esa línea |
| `mediana_linea` | Mediana de duración de esa línea |
| `veces_mediana` | Duración / mediana de su línea, redondeado a 2 decimales |
| `rango_en_linea` | Posición de la llamada en su línea, de la más larga (1) a la más corta; empates con el mismo rango menor (`method="min"`) |

Y `atipicas(perfil, minimo_llamadas=5, factor=10)` → DataFrame con `linea_origen`, `cdr_id`, `duracion_seg` y `veces_mediana` de las llamadas cuya duración supera `factor` veces la mediana de su línea, **solo** en líneas con al menos `minimo_llamadas` llamadas. Ordenado por `veces_mediana` descendente.

CDR = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
VOZ = CDR[(CDR["tipo"] == "VOZ") & (CDR["duracion_seg"] > 0)]

    """Una fila por llamada de voz contestada"""

    igual(len(p), len(VOZ))


def prueba_transform():
    """Columnas calculadas por línea"""
    p = perfilar(CDR)
    fila = p.iloc[0]
    duraciones = POR_LINEA[fila["linea_origen"]]
    igual(int(fila["llamadas_linea"]), len(duraciones))
    cerca(float(fila["mediana_linea"]), statistics.median(duraciones))
    cerca(float(fila["veces_mediana"]), round(fila["duracion_seg"] / statistics.median(duraciones), 2), 0.001)
    mayores = sum(1 for d in duraciones if d > fila["duracion_seg"])
    igual(int(fila["rango_en_linea"]), mayores + 1)


def prueba_atipicas():
    """Llamadas que superan factor × mediana en líneas con suficientes llamadas"""
    a = atipicas(perfilar(CDR), minimo_llamadas=5, factor=5)
    igual(list(a.columns), ["linea_origen", "cdr_id", "duracion_seg", "veces_mediana"])
    esperadas = 0
    for linea, ds in POR_LINEA.items():
        if len(ds) >= 5:
            m = statistics.median(ds)
            esperadas += sum(1 for d in ds if d > 5 * m)
    igual(len(a), esperadas)
    assert a["veces_mediana"].is_monotonic_decreasing, "Ordena de mayor a menor"

## Pista 2

`grupos.rank(method="min", ascending=False)` da la posición dentro de cada grupo. Para las atípicas, el filtro es `(p["llamadas_linea"] >= minimo_llamadas) & (p["duracion_seg"] > factor * p["mediana_linea"])`.

## Solución

```python
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)


def perfilar(cdr):
    voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0)].copy()
    grupos = voz.groupby("linea_origen")["duracion_seg"]
    voz["llamadas_linea"] = grupos.transform("size")
    voz["mediana_linea"] = grupos.transform("median")
    voz["veces_mediana"] = (voz["duracion_seg"] / voz["mediana_linea"]).round(2)
    voz["rango_en_linea"] = grupos.rank(method="min", ascending=False).astype(int)
    return voz


def atipicas(perfil, minimo_llamadas=5, factor=10):
    filtro = (perfil["llamadas_linea"] >= minimo_llamadas) & (perfil["duracion_seg"] > factor * perfil["mediana_linea"])
    columnas = ["linea_origen", "cdr_id", "duracion_seg", "veces_mediana"]
    return perfil.loc[filtro, columnas].sort_values("veces_mediana", ascending=False)


p = perfilar(cdr)
print(p[["linea_origen", "duracion_seg", "mediana_linea", "veces_mediana", "rango_en_linea"]].head())
print(atipicas(p).head())
```

## Explicación

Una llamada de una hora no es rara para un cliente que habla horas al día, pero sí lo es para uno que suele hablar dos minutos. Comparar cada registro con **su propio grupo** (con `transform`) da detecciones mucho más útiles que un umbral global.

Usar la **mediana** y no el promedio es deliberado: una sola llamada larguísima infla el promedio de su línea y "se esconde" a sí misma. La mediana es robusta a esos valores extremos. Lo profundizarás en el módulo 23, con detección de anomalías.

El mínimo de llamadas evita falsos positivos: con dos llamadas por línea, cualquier cosa parece atípica.
