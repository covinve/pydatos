Un **conjunto** (`set`) es una colección **sin orden y sin repetidos**. Igual que las claves de un diccionario, sabe al instante si un elemento está o no.

```pyrun
tipos = {"VOZ", "SMS", "DATOS", "VOZ"}
print(tipos)                 # el duplicado desaparece; el orden no está garantizado
print("VOX" in tipos)

lineas = ["3001", "3002", "3001", "3003", "3002"]
unicas = set(lineas)
print(len(lineas), "registros,", len(unicas), "líneas distintas")
```

:::error {} crea un diccionario vacío
Para un conjunto vacío escribe `set()`. `{}` es un diccionario.
:::

## Operaciones de conjuntos

Comparar fuentes de datos es una de las tareas más comunes en facturación: ¿qué líneas tienen consumo pero no son clientes?, ¿qué clientes no tuvieron consumo?

```pyrun
lineas_clientes = {"3001", "3002", "3003", "3004"}
lineas_con_cdr = {"3002", "3003", "3999", "3998"}

print("Con consumo y clientes:", lineas_clientes & lineas_con_cdr)   # intersección
print("Con consumo, sin cliente:", lineas_con_cdr - lineas_clientes)  # diferencia
print("Clientes sin consumo:", lineas_clientes - lineas_con_cdr)
print("Todas:", lineas_clientes | lineas_con_cdr)                     # unión
print("En una sola fuente:", lineas_clientes ^ lineas_con_cdr)        # diferencia simétrica
```

| Operación | Símbolo | Método | Significado |
|---|---|---|---|
| Unión | `a \| b` | `a.union(b)` | En a o en b |
| Intersección | `a & b` | `a.intersection(b)` | En a y en b |
| Diferencia | `a - b` | `a.difference(b)` | En a pero no en b |
| Diferencia simétrica | `a ^ b` | `a.symmetric_difference(b)` | En una sola de las dos |
| Subconjunto | `a <= b` | `a.issubset(b)` | Todo a está en b |

:::reto Concilia activas contra facturadas
Comparas las líneas **activas** del sistema comercial con las líneas que **se facturaron** este mes. Con operaciones de conjuntos, crea:

- `sin_factura`: activas que no se facturaron (dinero que se deja de cobrar);
- `facturadas_inactivas`: facturadas que no están activas (posibles reclamos);
- `cuadran`: cuántas líneas están en las dos fuentes.

```pyreto
activas = {"3001", "3002", "3003", "3004", "3005"}
facturadas = {"3002", "3003", "3005", "3990", "3991"}

# sin_factura, facturadas_inactivas y cuadran

print(sin_factura, facturadas_inactivas, cuadran)
```

:::pista
La diferencia `a - b` deja lo que está en `a` pero no en `b`. Para `cuadran`, cuenta la intersección: `len(activas & facturadas)`.
:::

```pyprueba
def prueba_sin_factura():
    """sin_factura = {"3001", "3004"}"""
    requiere("sin_factura")
    igual(sin_factura, {"3001", "3004"})


def prueba_inactivas():
    """facturadas_inactivas = {"3990", "3991"}"""
    requiere("facturadas_inactivas")
    igual(facturadas_inactivas, {"3990", "3991"})


def prueba_cuadran():
    """cuadran = 3"""
    requiere("cuadran")
    igual(cuadran, 3)
```

```pysolucion
activas = {"3001", "3002", "3003", "3004", "3005"}
facturadas = {"3002", "3003", "3005", "3990", "3991"}

sin_factura = activas - facturadas
facturadas_inactivas = facturadas - activas
cuadran = len(activas & facturadas)

print(sin_factura, facturadas_inactivas, cuadran)
```
:::

## Detectar duplicados

El patrón "¿ya lo vi antes?" es ideal para conjuntos:

```pytrace
ids = [101, 102, 103, 102, 104, 101]
vistos = set()
duplicados = []
for cdr_id in ids:
    if cdr_id in vistos:
        duplicados.append(cdr_id)
    else:
        vistos.add(cdr_id)
print(duplicados)
```

:::capo ¿Cabe todo en memoria?
Un conjunto con 10 millones de números ocupa unos 500 MB. Con los 280 millones de CDR del archivo de 20 GB necesitarías unos 15 GB: no cabe en tu computador de 16 GB. En el módulo 16 resolverás este problema con DuckDB, que usa el disco cuando la memoria no alcanza.
:::

```pyreto

    pass


print(repetidos([101, 102, 103, 102, 104, 101, 101]))   # {101, 102}
```

:::pista
Usa dos conjuntos: `vistos` y `dobles`. Para cada id: si ya está en `vistos`, agrégalo a `dobles` con `.add()`; si no, agrégalo a `vistos`.
:::

```pyprueba
def prueba_repetidos():
    """Devuelve los identificadores repetidos"""
    requiere("repetidos")
    igual(repetidos([101, 102, 103, 102, 104, 101, 101]), {101, 102})


def prueba_sin_repetidos():
    """Sin repetidos, devuelve un conjunto vacío"""
    igual(repetidos([1, 2, 3]), set())
    igual(repetidos([]), set())


def prueba_devuelve_conjunto():
    """Devuelve un set"""
    assert isinstance(repetidos([1, 1]), set), "Devuelve un conjunto (set)"
```

```pysolucion
def repetidos(ids):
    vistos = set()
    dobles = set()
    for cdr_id in ids:
        if cdr_id in vistos:
            dobles.add(cdr_id)
        else:
            vistos.add(cdr_id)
    return dobles


print(repetidos([101, 102, 103, 102, 104, 101, 101]))   # {101, 102}
```
:::

## ¿Qué estructura uso?

| Necesito… | Estructura | Ejemplo |
|---|---|---|
| Una secuencia ordenada que puede crecer | `list` | Las duraciones de las llamadas de un cliente |
| Un registro fijo de campos | `tuple` / `namedtuple` | `("VOZ", 36, 40)` |
| Buscar un valor por una clave | `dict` | Plan de cada línea |
| Contar o agrupar | `dict`, `Counter`, `defaultdict` | Errores por tipo |
| Saber si algo existe / quitar duplicados | `set` | IDs ya vistos |
| Comparar dos fuentes | `set` | Líneas sin cliente |

Y su costo aproximado:

| Operación | `list` | `dict` / `set` |
|---|---|---|
| `x in coleccion` | Lento: revisa uno por uno | Instantáneo |
| Acceder por posición `[i]` | Instantáneo | No aplica |
| Agregar al final | Instantáneo | Instantáneo |
| Mantiene el orden | Sí | `dict` sí (de inserción), `set` no |
| Permite repetidos | Sí | No |

:::reto Elige la estructura
Guarda cada dato en la estructura que le corresponde según la tabla de arriba:

| Variable | Qué guarda | Datos |
|---|---|---|
| `duraciones` | Las duraciones de las llamadas de un cliente, en orden (pueden repetirse) | 125, 0, 61, 125 |
| `campo_tipo` | Un registro fijo: nombre del campo, posición inicial y final | `"tipo"`, 36, 40 |
| `tarifas` | La tarifa de cada destino, para buscarla por destino | LOCAL → 100, NACIONAL → 120 |
| `tipos_validos` | Los tipos permitidos, para preguntar si uno existe | VOZ, SMS, DATOS |

:::pista
Lista con `[...]`, tupla con `(...)`, diccionario con `{clave: valor}` y conjunto con `{...}` sin dos puntos.
:::

```pyprueba
def prueba_lista():
    """duraciones es una lista con las cuatro duraciones"""
    requiere("duraciones")
    assert isinstance(duraciones, list), f"duraciones debería ser una lista, es {type(duraciones).__name__}"
    igual(duraciones, [125, 0, 61, 125])


def prueba_tupla():
    """campo_tipo es una tupla"""
    requiere("campo_tipo")
    assert isinstance(campo_tipo, tuple), f"campo_tipo debería ser una tupla, es {type(campo_tipo).__name__}"
    igual(campo_tipo, ("tipo", 36, 40))


def prueba_diccionario():
    """tarifas es un diccionario destino → tarifa"""
    requiere("tarifas")
    assert isinstance(tarifas, dict), f"tarifas debería ser un diccionario, es {type(tarifas).__name__}"
    igual(tarifas, {"LOCAL": 100, "NACIONAL": 120})


def prueba_conjunto():
    """tipos_validos es un conjunto"""
    requiere("tipos_validos")
    assert isinstance(tipos_validos, set), f"tipos_validos debería ser un conjunto, es {type(tipos_validos).__name__}"
    igual(tipos_validos, {"VOZ", "SMS", "DATOS"})
```

```pysolucion
duraciones = [125, 0, 61, 125]
campo_tipo = ("tipo", 36, 40)
tarifas = {"LOCAL": 100, "NACIONAL": 120}
tipos_validos = {"VOZ", "SMS", "DATOS"}
```
:::

:::telco Una pregunta para cada problema
Antes de escribir un bucle, pregúntate: **¿qué operación voy a repetir millones de veces?** Si es buscar, comprobar existencia o agrupar, la respuesta casi siempre es un diccionario o un conjunto.

## Cuestionario

? Tienes las líneas de los clientes y las líneas que aparecen en los CDR, ambas como conjuntos. ¿Cómo obtienes las líneas de CDR que no son clientes?

- [x] `cdr - clientes`
- [ ] `clientes & cdr`
- [ ] `clientes | cdr`
> La diferencia `a - b` deja lo que está en `a` pero no en `b`. Aquí `a` son las líneas de los CDR.

- [ ] 6

- [ ] 1
- [ ] Un error
