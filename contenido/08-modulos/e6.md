## Enunciado

Cada año comercial publica un tarifario nuevo como un módulo dentro del paquete `tarifarios` (ya está en tu carpeta de trabajo):

```text
tarifarios/
├── __init__.py
├── plan_2024.py      ← TARIFAS = {...}, VIGENTE_DESDE = "2024-01-01"
├── plan_2025.py
└── plan_2026.py
```

Para recalcular facturas de cualquier año sin escribir un `if` por año, escribe:

1. `cargar_tarifario(anio)` → importa **dinámicamente** el módulo `tarifarios.plan_<anio>` con `importlib.import_module` y devuelve su diccionario `TARIFAS`. Si no existe, lanza `ValueError("No hay tarifario para el año 2019")`, encadenado a la excepción original.
2. `valor_llamada(anio, destino, segundos)` → minutos facturables × tarifa del destino en ese año.

```python
cargar_tarifario(2026)["LOCAL"]           # 100
valor_llamada(2024, "NACIONAL", 125)      # 3 × 105 = 315
cargar_tarifario(2019)                    # ValueError
```

## Preparación

```python
from pathlib import Path

paquete = Path("tarifarios")
paquete.mkdir(exist_ok=True)
(paquete / "__init__.py").write_text('"""Tarifarios por año."""\n', encoding="utf-8")
tarifas = {
    2024: {"LOCAL": 90, "NACIONAL": 105, "INTERNACIONAL": 900},
    2025: {"LOCAL": 95, "NACIONAL": 115, "INTERNACIONAL": 920},
    2026: {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950},
}
for anio, tabla in tarifas.items():
    (paquete / f"plan_{anio}.py").write_text(f"TARIFAS = {tabla!r}\nVIGENTE_DESDE = '{anio}-01-01'\n", encoding="utf-8")
```

## Pista 1

`importlib.import_module("tarifarios.plan_2026")` hace lo mismo que `import tarifarios.plan_2026`, pero el nombre puede ser un texto construido en el momento:

```python
modulo = importlib.import_module(f"tarifarios.plan_{anio}")
return modulo.TARIFAS
```

## Pista 2

Si el módulo no existe, `import_module` lanza `ModuleNotFoundError` (una subclase de `ImportError`):

```python
try:
    modulo = importlib.import_module(f"tarifarios.plan_{anio}")
except ModuleNotFoundError as error:
    raise ValueError(f"No hay tarifario para el año {anio}") from error
```

## Solución

```python
import importlib


def cargar_tarifario(anio):
    try:
        modulo = importlib.import_module(f"tarifarios.plan_{anio}")
    except ModuleNotFoundError as error:
        raise ValueError(f"No hay tarifario para el año {anio}") from error
    return modulo.TARIFAS


def valor_llamada(anio, destino, segundos):
    tarifas = cargar_tarifario(anio)
    return (segundos + 59) // 60 * tarifas[destino]


print(cargar_tarifario(2026))
print(valor_llamada(2024, "NACIONAL", 125))
```

## Explicación

La carga dinámica convierte "un módulo nuevo" en "un dato nuevo": cuando comercial publique `plan_2027.py`, el código que calcula facturas no cambia.

Como Python guarda los módulos importados en `sys.modules`, llamar `cargar_tarifario(2026)` mil veces solo carga el archivo la primera vez: las siguientes son instantáneas.

:::error Nunca construyas el nombre con datos de un usuario externo
Si el año viniera de un formulario web, alguien podría pedir `tarifarios.plan_../../algo`. Aquí el año es un `int` de tu propio proceso, pero cuando el nombre del módulo depende de datos externos, valídalo contra una lista permitida.
:::
