El tipo de gráfico no se elige por gusto: se elige por la **pregunta** que quieres responder.

| Pregunta | Gráfico | Ejemplo telco |
|---|---|---|
| ¿Cuál es más grande? (comparar categorías) | Barras | Minutos por destino, clientes por plan |
| ¿Cómo cambia en el tiempo? | Líneas | Registros por día, ingresos por mes |
| ¿Cómo se distribuye? | Histograma | Duración de las llamadas |
| ¿Cómo se distribuye en cada grupo? | Caja (*boxplot*) | Minutos por línea según el plan |
| ¿Se relacionan dos variables? | Dispersión (*scatter*) | Minutos vs. megas por cliente |
| ¿Dónde se concentra? (dos categorías) | Mapa de calor | Llamadas por día de la semana y hora |
| ¿Qué parte del total es? | Barras apiladas (mejor que torta) | Composición del consumo adicional |

## Caja: comparar distribuciones

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].assign(minutos=lambda d: (d["duracion_seg"] + 59) // 60)
por_linea = voz.groupby("linea_origen")["minutos"].sum().rename("minutos").reset_index()
por_linea = por_linea.merge(clientes[["linea", "plan_id"]], left_on="linea_origen", right_on="linea")

planes = sorted(por_linea["plan_id"].unique())
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.boxplot([por_linea.loc[por_linea["plan_id"] == p, "minutos"] for p in planes], tick_labels=planes)
ax.set_title("Minutos al mes por línea, según el plan")
ax.set_ylabel("Minutos")
```

La caja va del percentil 25 al 75, la línea del medio es la mediana y los puntos aislados son valores atípicos.

## Dispersión: relaciones

```pyrun
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
v = cdr[cdr["tipo"].isin(["VOZ", "DATOS"]) & (cdr["duracion_seg"] >= 0)]
minutos = ((v["duracion_seg"] + 59) // 60).where(v["tipo"] == "VOZ", 0).groupby(v["linea_origen"]).sum()
mb = v["mb"].where(v["tipo"] == "DATOS", 0).groupby(v["linea_origen"]).sum()

fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(minutos, mb / 1024, alpha=0.7)
pendiente, intercepto = np.polyfit(minutos, mb / 1024, 1)
x = np.linspace(minutos.min(), minutos.max(), 50)
ax.plot(x, pendiente * x + intercepto, color="#dc2626", label="Tendencia lineal")
ax.set_xlabel("Minutos de voz en el mes")
ax.set_ylabel("GB de datos en el mes")
ax.legend()
```

## Mapa de calor

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
inicio = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
voz = inicio[(cdr["tipo"] == "VOZ") & inicio.notna()]
matriz = pd.crosstab(voz.dt.dayofweek, voz.dt.hour).reindex(index=range(7), columns=range(24), fill_value=0)

fig, ax = plt.subplots(figsize=(9, 3))
imagen = ax.imshow(matriz, aspect="auto", cmap="viridis")
ax.set_yticks(range(7), ["Lun", "Mar", "Mié", "Jue", "Vie", "Sáb", "Dom"])
ax.set_xticks(range(0, 24, 2))
ax.set_xlabel("Hora del día")
ax.set_title("Llamadas por día de la semana y hora")
fig.colorbar(imagen, ax=ax, label="Llamadas")
```

## Buenas prácticas

:::comparar
:::mal Gráficos que confunden
- Barras cuyo eje Y no empieza en 0 (exageran diferencias)
- Gráficos de torta con 8 porciones
- Sin título ni unidades
- 3D, sombras y efectos decorativos
- Colores distintos para cada barra sin motivo
:::
:::bien Gráficos que comunican
- Barras desde 0; líneas pueden no empezar en 0
- Barras ordenadas por valor
- Título que dice la conclusión: "El 64 % del tráfico es datos"
- Unidades en los ejes (minutos, GB, $)
- Un color, y otro solo para destacar lo importante
:::
:::

:::consejo El título es la conclusión
"Minutos por destino" describe el gráfico; "El internacional es solo el 3 % de los minutos" dice qué ver. Para reportes de negocio, el título que comunica la conclusión ahorra la explicación.
:::

- [x] La mediana
- [ ] El máximo
- [ ] La moda
> La caja va del percentil 25 al 75 y la línea interior es la mediana (percentil 50).

? ¿Por qué un gráfico de barras debe empezar en 0?
- [ ] Por estética
- [x] Porque la altura de la barra representa el valor; cortar el eje exagera las diferencias
- [ ] Porque matplotlib lo exige
- [ ] No es necesario
> Si el eje empieza en 900, una barra de 950 parece el doble de una de 925.
