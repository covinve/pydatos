## Enunciado

Escribe `leer_env(texto)` → diccionario con las variables de un archivo `.env`, con estas reglas:

| Línea | Resultado |
|---|---|
| `TELCO_UMBRAL=2.5` | `"TELCO_UMBRAL": "2.5"` |
| `  TELCO_DATOS = D:/cdr  ` | Espacios alrededor de nombre y valor se quitan: `"D:/cdr"` |
| `export TELCO_HILOS=6` | El prefijo `export ` se ignora |
| `TELCO_NOMBRE="Facturación Telco"` | Comillas dobles o simples se quitan |
| `TELCO_URL=postgresql://u:p@h/db?x=1` | Solo el **primer** `=` separa: el valor puede tener `=` |
| `TELCO_VACIA=` | Valor vacío `""` |
| `TELCO_PUERTO=5432  # puerto` | Un ` #` (espacio y numeral) **fuera de comillas** inicia un comentario |
| `TELCO_CLAVE="abc#123"` | Dentro de comillas, `#` es parte del valor |
| `# comentario` o línea vacía | Se ignora |
| `LINEA SIN IGUAL` | `ValueError` con el número de línea |

Y `aplicar_env(variables, entorno)`: copia en `entorno` (un diccionario como `os.environ`) las variables que **no existan** ya allí, y devuelve la lista de nombres que aplicó.

## Pruebas

```python
EJEMPLO = """
# Configuración local
TELCO_UMBRAL=2.5
  TELCO_DATOS = D:/cdr
export TELCO_HILOS=6
TELCO_NOMBRE="Facturación Telco"

TELCO_VACIA=
TELCO_PUERTO=5432  # puerto de PostgreSQL

def prueba_valores():
    """Lee todas las variables"""
    requiere("leer_env")
    igual(leer_env(EJEMPLO), {
        "TELCO_UMBRAL": "2.5", "TELCO_DATOS": "D:/cdr", "TELCO_HILOS": "6", "TELCO_NOMBRE": "Facturación Telco",
        "TELCO_SIMPLE": "hola mundo", "TELCO_URL": "postgresql://u:p@h/db?x=1&y=2", "TELCO_VACIA": "",
        "TELCO_PUERTO": "5432", "TELCO_CLAVE": "abc #123",
    })


def prueba_error_con_linea():
    """Una línea inválida dice su número"""
    e = lanza(ValueError, leer_env, "A=1\n\nESTO NO VALE\n")
    assert "3" in str(e), f"El mensaje debe incluir el número de línea (3): {e}"


def prueba_aplicar():
    """No pisa lo que ya existe"""
    requiere("aplicar_env")
    entorno = {"TELCO_UMBRAL": "9", "PATH": "x"}
    aplicadas = aplicar_env({"TELCO_UMBRAL": "2.5", "TELCO_DATOS": "D:/cdr"}, entorno)
    igual(aplicadas, ["TELCO_DATOS"])
    igual(entorno, {"TELCO_UMBRAL": "9", "PATH": "x", "TELCO_DATOS": "D:/cdr"})
```

## Pista 1

Recorre con `enumerate(texto.splitlines(), start=1)` para tener el número de línea. Quita el `export `:

```python
linea = linea.strip()
if linea.startswith("export "):
    linea = linea[len("export "):]
nombre, separador, valor = linea.partition("=")
if not separador:
    raise ValueError(f"Línea {numero}: falta '=' en {linea!r}")
```

`partition` separa en el **primer** `=`.

## Pista 2

Para el valor: si empieza con comilla, búscala de cierre y toma lo de adentro; si no, corta en el primer `" #"` y quita espacios.

```python
valor = valor.strip()
if valor[:1] in ("'", '"'):
    cierre = valor.find(valor[0], 1)
    valor = valor[1:cierre]
else:
    valor = valor.split(" #", 1)[0].strip()
```

## Solución

```python
def _valor(crudo):
    crudo = crudo.strip()
    if crudo[:1] in ("'", '"'):
        cierre = crudo.find(crudo[0], 1)
        return crudo[1:cierre] if cierre != -1 else crudo[1:]
    return crudo.split(" #", 1)[0].strip()


def leer_env(texto):
    variables = {}
    for numero, linea in enumerate(texto.splitlines(), start=1):
        linea = linea.strip()
        if not linea or linea.startswith("#"):
            continue
        if linea.startswith("export "):
            linea = linea[len("export "):]
        nombre, separador, valor = linea.partition("=")
        if not separador or not nombre.strip():
            raise ValueError(f"Línea {numero}: se esperaba NOMBRE=valor y llegó {linea!r}")
        variables[nombre.strip()] = _valor(valor)
    return variables


def aplicar_env(variables, entorno):
    aplicadas = []
    for nombre, valor in variables.items():
        if nombre not in entorno:
            entorno[nombre] = valor
            aplicadas.append(nombre)
    return aplicadas


EJEMPLO = """
# Configuración local
TELCO_DATOS = D:/cdr
export TELCO_HILOS=6
TELCO_NOMBRE="Facturación Telco"
TELCO_PUERTO=5432  # puerto
"""
print(leer_env(EJEMPLO))
```

## Explicación

Esto es, en pequeño, lo que hace `python-dotenv`. Los casos de la tabla no son inventados: la URL con `=` en los parámetros, la contraseña con `#`, el comentario al final de la línea y el `export` (para que el mismo archivo sirva con `source .env` en Linux) aparecen en archivos `.env` reales.

`aplicar_env` implementa la regla de precedencia de la lección 3: el `.env` **no pisa** lo que ya está definido en el entorno. Así, el Programador de tareas o Docker pueden sobrescribir cualquier valor sin tocar el archivo.

En tu proyecto, usa `python-dotenv` (`load_dotenv()`): está probado contra muchos más casos raros. Pero ahora sabes exactamente qué espera, y por qué `CLAVE=abc #123` sin comillas te dejaría la contraseña cortada en `abc`.
