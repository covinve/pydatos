## Enunciado

El área de red quiere saber a qué horas hay más llamadas para planear el mantenimiento. Con `cdr.csv`:

1. `llamadas_por_hora(ruta)` → lista de **24 enteros**: la posición `h` tiene la cantidad de registros `VOZ` que empezaron a la hora `h`. Ignora los registros cuya `fecha_inicio` no sea una fecha válida (usa `datetime.strptime`).
2. `hora_pico(conteo)` → la hora (0–23) con más llamadas. En empate, la más temprana.
3. `llamadas_por_dia_semana(ruta)` → diccionario con los nombres de los días en español (`"lunes"` … `"domingo"`, en ese orden) y la cantidad de registros `VOZ` válidos de cada uno.

```python
conteo = llamadas_por_hora("cdr.csv")
len(conteo)                      # 24
hora_pico(conteo)                # por ejemplo 15
llamadas_por_dia_semana("cdr.csv")   # {"lunes": ..., "martes": ..., ..., "domingo": ...}
```

## Pista 1

## Pista 2

Para la hora pico, `max(range(24), key=lambda h: conteo[h])` devuelve la primera hora con el valor máximo.

Para los días, crea el diccionario con todas las claves en cero y en orden: `{dia: 0 for dia in DIAS}`, y suma usando `DIAS[momento.weekday()]`.

Ambas funciones de conteo recorren el archivo igual: puedes escribir una función auxiliar que devuelva (con `yield`, o como lista) los momentos válidos de las llamadas.

## Solución

```python
import csv
from datetime import datetime

FORMATO = "%Y-%m-%d %H:%M:%S"
DIAS = ["lunes", "martes", "miércoles", "jueves", "viernes", "sábado", "domingo"]


def momentos_de_voz(ruta):
    """Devuelve uno a uno los inicios válidos de las llamadas de voz."""
    with open(ruta, encoding="utf-8", newline="") as archivo:
        for fila in csv.DictReader(archivo, delimiter="|"):
            if fila["tipo"] != "VOZ":
                continue
            try:
                yield datetime.strptime(fila["fecha_inicio"], FORMATO)
            except ValueError:
                continue


def llamadas_por_hora(ruta):
    conteo = [0] * 24
    for momento in momentos_de_voz(ruta):
        conteo[momento.hour] += 1
    return conteo


def hora_pico(conteo):
    return max(range(24), key=lambda hora: conteo[hora])


def llamadas_por_dia_semana(ruta):
    conteo = {dia: 0 for dia in DIAS}
    for momento in momentos_de_voz(ruta):
        conteo[DIAS[momento.weekday()]] += 1
    return conteo


conteo = llamadas_por_hora("cdr.csv")
print(conteo)
print("Hora pico:", hora_pico(conteo))
print(llamadas_por_dia_semana("cdr.csv"))
```

## Explicación

La solución introduce algo nuevo: **`yield`**. `momentos_de_voz` no devuelve una lista; es un **generador** que entrega los momentos de a uno, a medida que el `for` los pide. Así:

- Las dos funciones de conteo reutilizan la misma lógica de lectura y validación.
- No se guarda ninguna lista en memoria: funciona igual con 4.000 o con 280 millones de registros.

Verás los generadores a fondo en el módulo 11. Por ahora quédate con la idea: **`yield` convierte una función en una "fuente" de valores que se consume con `for`**.

`max(range(24), key=...)` es un truco elegante: recorre las horas y elige la que tiene el conteo más alto. `max` se queda con el primer máximo que encuentra, que es la hora más temprana.
