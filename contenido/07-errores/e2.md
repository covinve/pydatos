## Enunciado

Cuando un registro está dañado, el mensaje debe decir **línea, campo y valor**. Crea:

1. La excepción `ErrorDeRegistro(Exception)` con los atributos `numero_linea`, `campo` y `valor`, y este mensaje:

   ```text
   Línea 7, campo duracion_seg: valor inválido 'abc'
   ```

2. La función `parsear_cdr(numero_linea, linea)` que recibe una línea de `cdr.csv` (separada por `|`, sin salto de línea) y devuelve un diccionario con:
   - `cdr_id` → `int`
   - `linea_origen` → `str`
   - `tipo` → `str`
   - `fecha_inicio` → `datetime` (formato `%Y-%m-%d %H:%M:%S`)
   - `duracion_seg` → `int`
   - `mb` → `float`

   Si la línea no tiene exactamente 9 campos, lanza `ErrorDeRegistro(numero_linea, "linea", <la línea completa>)`. Si un campo no se puede convertir, lanza `ErrorDeRegistro` con ese campo y su valor, **encadenado** con `from` a la excepción original.

```python
parsear_cdr(2, "1|3001234567||DATOS||2026-09-24 09:21:27|2335|6.411|CEL63681")
# {"cdr_id": 1, "linea_origen": "3001234567", "tipo": "DATOS",
#  "fecha_inicio": datetime(2026, 9, 24, 9, 21, 27), "duracion_seg": 2335, "mb": 6.411}
```

## Pruebas

```python
from datetime import datetime

BUENA = "1|3001234567||DATOS||2026-09-24 09:21:27|2335|6.411|CEL63681"


def prueba_linea_valida():
    """Convierte cada campo a su tipo"""
    requiere("parsear_cdr", "ErrorDeRegistro")
    igual(parsear_cdr(2, BUENA), {
        "cdr_id": 1, "linea_origen": "3001234567", "tipo": "DATOS",
        "fecha_inicio": datetime(2026, 9, 24, 9, 21, 27), "duracion_seg": 2335, "mb": 6.411,
    })


def prueba_mensaje_de_la_excepcion():
    """La excepción tiene el mensaje y los atributos pedidos"""
    error = ErrorDeRegistro(7, "duracion_seg", "abc")
    igual(str(error), "Línea 7, campo duracion_seg: valor inválido 'abc'")
    igual((error.numero_linea, error.campo, error.valor), (7, "duracion_seg", "abc"))
    assert isinstance(error, Exception)


def prueba_campo_invalido():
    """Un campo que no se puede convertir lanza ErrorDeRegistro con contexto"""
    error = lanza(ErrorDeRegistro, parsear_cdr, 15, BUENA.replace("|2335|", "|abc|"))
    igual((error.numero_linea, error.campo, error.valor), (15, "duracion_seg", "abc"))


def prueba_fecha_invalida():
    """Una fecha imposible también es un error de registro"""
    error = lanza(ErrorDeRegistro, parsear_cdr, 3, BUENA.replace("2026-09-24", "2026-09-31"))
    igual(error.campo, "fecha_inicio")
    igual(error.valor, "2026-09-31 09:21:27")


def prueba_encadenada():
    """La excepción conserva la causa original (raise ... from)"""
    error = lanza(ErrorDeRegistro, parsear_cdr, 4, BUENA.replace("|6.411|", "|6,411|"))
    assert isinstance(error.__cause__, ValueError), "Usa `raise ErrorDeRegistro(...) from error`"


def prueba_cantidad_de_campos():
    """Una línea con campos de más o de menos es un error del campo 'linea'"""
    error = lanza(ErrorDeRegistro, parsear_cdr, 9, "1|3001|VOZ")
    igual((error.campo, error.valor), ("linea", "1|3001|VOZ"))
```

## Pista 1

La excepción necesita un `__init__` que guarde los datos y arme el mensaje:

class ErrorDeRegistro(Exception):

## Pista 2

Para no repetir un `try` por cada campo, describe las conversiones en una lista y recórrela:

```python
CONVERSIONES = [
    ("cdr_id", 0, int),
    ("linea_origen", 1, str),
    ("tipo", 3, str),
    ("fecha_inicio", 5, lambda t: datetime.strptime(t, "%Y-%m-%d %H:%M:%S")),
    ("duracion_seg", 6, int),
    ("mb", 7, float),
]
```

`datetime.strptime` lanza `ValueError` con una fecha imposible, igual que `int` y `float`.

## Solución

```python
from datetime import datetime


class ErrorDeRegistro(Exception):
    def __init__(self, numero_linea, campo, valor):
        self.numero_linea = numero_linea
        self.campo = campo
        self.valor = valor
        super().__init__(f"Línea {numero_linea}, campo {campo}: valor inválido {valor!r}")


def leer_fecha(texto):
    return datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")


CONVERSIONES = [
    ("cdr_id", 0, int),
    ("linea_origen", 1, str),
    ("tipo", 3, str),
    ("fecha_inicio", 5, leer_fecha),
    ("duracion_seg", 6, int),
    ("mb", 7, float),
]


def parsear_cdr(numero_linea, linea):
    campos = linea.split("|")
    if len(campos) != 9:
        raise ErrorDeRegistro(numero_linea, "linea", linea)
    registro = {}
    for nombre, posicion, convertir in CONVERSIONES:
        valor = campos[posicion]
        try:
            registro[nombre] = convertir(valor)
        except ValueError as error:
            raise ErrorDeRegistro(numero_linea, nombre, valor) from error
    return registro


print(parsear_cdr(2, "1|3001234567||DATOS||2026-09-24 09:21:27|2335|6.411|CEL63681"))
```

## Explicación

`ErrorDeRegistro` es una excepción **con datos**. Quien la atrape no solo puede mostrar el mensaje: puede usar `error.campo` para contar errores por campo, o `error.numero_linea` para escribir un archivo de rechazos. Es mucho más útil que un `ValueError` genérico.

La tabla `CONVERSIONES` es la misma idea del diseño de registro del módulo 4: la **configuración** (qué campo, qué posición, qué conversión) separada del **algoritmo** (recorrer, convertir, reportar). Un solo `try` sirve para todos los campos y el mensaje siempre sabe qué campo falló.

`super().__init__(mensaje)` llama al constructor de `Exception` para que `str(error)` devuelva el mensaje. Lo entenderás del todo en el módulo 9, cuando veas clases y herencia.
