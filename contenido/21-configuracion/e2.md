## Enunciado

Escribe `cargar_config(ruta)` que lea un archivo TOML con `tomllib` y lo **combine** con `POR_DEFECTO`:

- Las claves del archivo **reemplazan** a las por defecto; las que no están en el archivo conservan su valor por defecto.
- La combinación es **profunda**: si el archivo trae `[duckdb]` con solo `memoria`, `duckdb.hilos` sigue con su valor por defecto.
- Una clave que **no existe** en `POR_DEFECTO` es un error de tipeo: lanza `KeyError` con un mensaje que incluya la ruta completa de la clave (`"duckdb.memorya"`).
- `POR_DEFECTO` **no debe modificarse** (cada llamada parte de los valores originales).
- Si el archivo no existe, devuelve una copia de los valores por defecto.

## Pruebas

```python
import copy
from pathlib import Path

ORIGINAL = copy.deepcopy(POR_DEFECTO)


def escribir(texto, nombre="prueba.toml"):
    Path(nombre).write_text(texto, encoding="utf-8")
    return nombre


def prueba_combina():
    """Combina en profundidad"""
    requiere("cargar_config")
    c = cargar_config(escribir('umbral_rechazo = 2.5\n[duckdb]\nmemoria = "8GB"\n'))
    igual(c, {"periodo": "202609", "umbral_rechazo": 2.5,
              "rutas": {"datos": "datos", "salidas": "salidas"},
              "duckdb": {"memoria": "8GB", "hilos": 4}})


def prueba_no_modifica_por_defecto():
    """POR_DEFECTO queda igual"""
    cargar_config(escribir('[rutas]\ndatos = "D:/cdr"\n'))
    igual(POR_DEFECTO, ORIGINAL)
    c = cargar_config("no_existe.toml")
    igual(c, ORIGINAL)
    c["duckdb"]["hilos"] = 99
    igual(POR_DEFECTO["duckdb"]["hilos"], 4, "Devuelve una copia, no POR_DEFECTO mismo")


def prueba_clave_desconocida():
    """Una clave de más es un error con su ruta"""
    e = lanza(KeyError, cargar_config, escribir('[duckdb]\nmemorya = "8GB"\n'))
    assert "duckdb.memorya" in str(e), f"El mensaje debe decir qué clave: {e}"
    lanza(KeyError, cargar_config, escribir('umbral = 3\n'))


def prueba_tipos_toml():
    """Los tipos vienen de TOML"""
    c = cargar_config(escribir("[duckdb]\nhilos = 8\n"))
    igual(type(c["duckdb"]["hilos"]), int)
```

## Pista 1

`tomllib.load` necesita el archivo abierto en modo **binario**:

```python
with open(ruta, "rb") as f:
    datos = tomllib.load(f)
```

## Pista 2

Una función recursiva que combina dos diccionarios, llevando la "ruta" para el mensaje de error:

```python
def _combinar(base, nuevo, ruta=""):
    for clave, valor in nuevo.items():
        completa = f"{ruta}{clave}"
        if clave not in base:
            raise KeyError(f"Clave de configuración desconocida: {completa}")
        if isinstance(base[clave], dict) and isinstance(valor, dict):
            _combinar(base[clave], valor, completa + ".")
        else:
            base[clave] = valor
```

Llámala sobre `copy.deepcopy(POR_DEFECTO)`.

## Solución

```python
import copy
import tomllib
from pathlib import Path

POR_DEFECTO = {
    "periodo": "202609",
    "umbral_rechazo": 5.0,
    "rutas": {"datos": "datos", "salidas": "salidas"},
    "duckdb": {"memoria": "4GB", "hilos": 4},
}


def _combinar(base, nuevo, ruta=""):
    for clave, valor in nuevo.items():
        completa = f"{ruta}{clave}"
        if clave not in base:
            raise KeyError(f"Clave de configuración desconocida: {completa}")
        if isinstance(base[clave], dict) and isinstance(valor, dict):
            _combinar(base[clave], valor, completa + ".")
        else:
            base[clave] = valor


def cargar_config(ruta):
    config = copy.deepcopy(POR_DEFECTO)
    ruta = Path(ruta)
    if ruta.exists():
        with open(ruta, "rb") as f:
            _combinar(config, tomllib.load(f))
    return config


Path("config.toml").write_text('umbral_rechazo = 2.5\n[duckdb]\nmemoria = "8GB"\n', encoding="utf-8")
print(cargar_config("config.toml"))
```

## Explicación

Tres decisiones de diseño hacen robusta esta función:

- **`copy.deepcopy`**: con `dict(POR_DEFECTO)` o `.copy()` (copia superficial), los diccionarios internos (`rutas`, `duckdb`) serían **los mismos** objetos, y modificar la configuración cargada cambiaría los valores por defecto para la siguiente llamada. Es el aliasing del módulo 4, a dos niveles.
- **Rechazar claves desconocidas**: un `memorya = "8GB"` ignorado en silencio haría que DuckDB siguiera usando 4 GB, y nadie entendería por qué el proceso se cae por memoria. Fallar al arrancar con "clave desconocida: duckdb.memorya" ahorra horas.
- **Archivo opcional**: sin `config.toml`, el programa funciona con valores sensatos. Es lo que permite que alguien lo pruebe sin preparar nada.

La combinación profunda es justo lo que hace pydantic-settings con modelos anidados, y lo que hacen Docker Compose o GitHub Actions al combinar configuraciones.
