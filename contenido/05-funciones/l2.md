## Alcance: dónde vive cada variable

Las variables creadas **dentro** de una función son **locales**: nacen cuando la función empieza y desaparecen cuando termina. Las de afuera son **globales**.

```pytrace
IVA = 0.19

def calcular_iva(subtotal):
    iva = subtotal * IVA
    return round(iva)

resultado = calcular_iva(40940)
print(resultado)
```

Observa en el visualizador: `subtotal` e `iva` solo existen mientras corre `calcular_iva`. Al volver, desaparecen y solo queda `resultado`.

Una función **puede leer** las variables globales (como `IVA`), pero si intenta asignarles un valor, Python crea una variable local nueva con el mismo nombre:

```pyrun
contador = 0

def procesar():
    contador = contador + 1   # error esperado

procesar()
```

Existe la palabra `global` para modificarlas desde adentro, pero **casi nunca es buena idea**.

## Efectos secundarios

Una función tiene **efectos secundarios** cuando hace algo más que devolver un valor: modifica una variable global, cambia un argumento mutable, escribe un archivo, imprime en pantalla.

:::comparar
:::mal Con efectos secundarios
```python
total_facturado = 0

def facturar(factura):
    global total_facturado
    factura["estado"] = "EMITIDA"     # modifica el argumento
    total_facturado += factura["total"]  # modifica una global
```
:::
:::bien Pura
```python
def emitir(factura):
    return {**factura, "estado": "EMITIDA"}

def sumar_totales(facturas):
    return sum(f["total"] for f in facturas)
```
:::
:::

## Funciones puras

Una función **pura**:

1. Devuelve siempre el mismo resultado para los mismos argumentos.
2. No tiene efectos secundarios.

| | Pura | Impura |
|---|---|---|
| Probarla | Fácil: llamas y comparas | Hay que preparar y revisar el estado externo |
| Entenderla | Basta leer la función | Hay que saber qué pasó antes en el programa |
| Reutilizarla | En cualquier lugar | Depende del contexto |
| Ejecutarla en paralelo (módulo 16) | Seguro | Peligroso |

```pyrun
def tarifa(destino, tarifas):
    """Pura: todo lo que necesita llega por parámetro."""
    return tarifas.get(destino)


tarifas_2026 = {"LOCAL": 100, "NACIONAL": 120}
tarifas_promo = {"LOCAL": 50, "NACIONAL": 60}

print(tarifa("LOCAL", tarifas_2026))
print(tarifa("LOCAL", tarifas_promo))
```

Como `tarifa` recibe las tarifas por parámetro en vez de leer una global, sirve para cualquier tabla de tarifas (la vigente, la promocional, la del año pasado para recalcular).

:::reto Hazla pura
Este código calcula el valor de las llamadas leyendo la tabla global `TARIFAS` y sumando en la global `total`. Reescríbelo con una función **pura**:

`valor_llamadas(llamadas, tarifas)` recibe una lista de pares `(destino, minutos)` y la tabla de tarifas, y **devuelve** el total. Sin `global`.

```pyreto
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
total = 0


def sumar_llamada(destino, minutos):
    global total
    total += TARIFAS[destino] * minutos


sumar_llamada("LOCAL", 3)
sumar_llamada("INTERNACIONAL", 2)
print(total)
```

:::pista
Todo lo que la función necesita llega por parámetro: `def valor_llamadas(llamadas, tarifas):`. Usa un acumulador **local** y recorre `for destino, minutos in llamadas:`.
:::

```pyprueba
def prueba_resultado():
    """Calcula el total con la tabla que recibe"""
    requiere("valor_llamadas")
    llamadas = [("LOCAL", 3), ("INTERNACIONAL", 2)]
    igual(valor_llamadas(llamadas, {"LOCAL": 100, "INTERNACIONAL": 950}), 2200)
    igual(valor_llamadas(llamadas, {"LOCAL": 50, "INTERNACIONAL": 500}), 1150, "con otra tabla de tarifas")
    igual(valor_llamadas([], {"LOCAL": 100}), 0, "sin llamadas")


def prueba_pura():
    """Es pura: mismo resultado en cada llamada y sin global"""
    llamadas = [("LOCAL", 1)]
    igual(valor_llamadas(llamadas, {"LOCAL": 100}), valor_llamadas(llamadas, {"LOCAL": 100}))
    assert "global" not in codigo, "Una función pura no usa global"
```

```pysolucion
def valor_llamadas(llamadas, tarifas):
    total = 0
    for destino, minutos in llamadas:
        total += tarifas[destino] * minutos
    return total


TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
print(valor_llamadas([("LOCAL", 3), ("INTERNACIONAL", 2)], TARIFAS))
```
:::

:::consejo Núcleo puro, borde impuro
Ningún programa útil es 100 % puro: en algún momento hay que leer archivos e imprimir resultados. La estrategia profesional es mantener **la lógica de negocio pura** (calcular, validar, transformar) y concentrar los efectos (leer, escribir, imprimir) en pocas funciones del "borde". Es la base de la arquitectura en capas del módulo 19.
:::

## return temprano y una sola responsabilidad

Una buena función hace **una cosa**. Si su nombre necesita "y" (`leer_y_validar_y_guardar`), probablemente son tres funciones.

```pyrun
def leer_campos(linea):
    return linea.strip().split("|")


def es_valido(campos):
    return len(campos) == 3 and campos[1] in ("VOZ", "SMS", "DATOS")


def procesar(lineas):
    validos = 0
    for linea in lineas:
        if es_valido(leer_campos(linea)):
            validos += 1
    return validos


print(procesar(["1|VOZ|125\n", "2|VOX|10\n", "3|SMS|0\n"]))
```

:::reto Una función, una tarea
Divide el trabajo en tres funciones pequeñas:

1. `normalizar(linea)`: quita espacios y guiones → `" 300-123-4567 "` da `"3001234567"`.
2. `es_movil(linea)`: `True` si tiene 10 dígitos y empieza por `"3"`.
3. `contar_moviles(lineas)`: cuántas líneas de la lista son móviles **después de normalizarlas**, usando las dos funciones anteriores.

```pyreto
def normalizar(linea):
    pass


def es_movil(linea):
    pass


def contar_moviles(lineas):
    pass


print(contar_moviles([" 300-123-4567 ", "6014445566", "310 987 6543", "31"]))   # 2
```

:::pista
`normalizar` encadena `strip()` y dos `replace` (guiones y espacios). `es_movil` es una condición con `and`. `contar_moviles` recorre la lista y suma 1 cuando `es_movil(normalizar(linea))`.
:::

```pyprueba
import ast


def prueba_normalizar():
    """normalizar quita espacios y guiones"""
    requiere("normalizar")
    igual(normalizar(" 300-123-4567 "), "3001234567")
    igual(normalizar("310 987 6543"), "3109876543")


def prueba_es_movil():
    """es_movil revisa 10 dígitos que empiezan por 3"""
    requiere("es_movil")
    igual(es_movil("3001234567"), True, "3001234567")
    igual(es_movil("6014445566"), False, "6014445566")
    igual(es_movil("31"), False, "31")
    igual(es_movil("300123456X"), False, "300123456X")


def prueba_contar():
    """contar_moviles usa las otras dos funciones"""
    requiere("contar_moviles")
    igual(contar_moviles([" 300-123-4567 ", "6014445566", "310 987 6543", "31"]), 2)
    funcion = next(n for n in ast.walk(ast.parse(codigo)) if isinstance(n, ast.FunctionDef) and n.name == "contar_moviles")
    llamadas = {n.func.id for n in ast.walk(funcion) if isinstance(n, ast.Call) and isinstance(n.func, ast.Name)}
    assert {"normalizar", "es_movil"} <= llamadas, "contar_moviles debe llamar a normalizar y a es_movil"
```

```pysolucion
def normalizar(linea):
    return linea.strip().replace("-", "").replace(" ", "")


def es_movil(linea):
    return len(linea) == 10 and linea.isdigit() and linea.startswith("3")


def contar_moviles(lineas):
    cantidad = 0
    for linea in lineas:
        if es_movil(normalizar(linea)):
            cantidad += 1
    return cantidad


print(contar_moviles([" 300-123-4567 ", "6014445566", "310 987 6543", "31"]))   # 2
```

:::telco Recalcular el pasado
En facturación siempre aparece la pregunta: "¿cuánto se habría facturado con las tarifas anteriores?". Si tus funciones son puras y reciben las tarifas por parámetro, responderla es llamar a la misma función con otra tabla. Si leen variables globales, hay que reescribir el proceso.

## Cuestionario

? ¿Qué es una función pura?
- [ ] Una función sin parámetros
- [ ] Una función de una sola línea
- [x] Una que siempre devuelve lo mismo para los mismos argumentos y no tiene efectos secundarios
- [ ] Una que no usa `return`
> Al no depender ni modificar nada externo, es predecible y fácil de probar.

? ¿Qué pasa con la variable local `iva` cuando la función termina?
- [x] Desaparece
- [ ] Se convierte en global
- [ ] Conserva su valor para la próxima llamada
- [ ] Se guarda en el `return`
> Las variables locales solo existen mientras la función se ejecuta. Lo que quieras conservar, devuélvelo.

? ¿Cuál de estas funciones tiene un efecto secundario?
- [ ] `def doble(x): return x * 2`
- [x] `def agregar(lista, x): lista.append(x)`
- [ ] `def mayor(a, b): return max(a, b)`
- [ ] `def vacia(texto): return texto == ""`
> `agregar` modifica la lista que recibe: quien la llamó verá su lista cambiada.
