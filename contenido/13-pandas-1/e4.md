## Solución

```python
import json

import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})

PRIORIDAD = ["duplicado", "linea_vacia", "linea_desconocida", "tipo_desconocido", "duracion_negativa", "fecha_invalida"]
ORDEN_REPORTE = ["duplicado", "duracion_negativa", "fecha_invalida", "linea_vacia", "linea_desconocida", "tipo_desconocido"]


def clasificar(cdr, clientes):
    fecha = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    condiciones = [
        cdr.duplicated("cdr_id"),
        cdr["linea_origen"] == "",
        ~cdr["linea_origen"].isin(clientes["linea"]),
        ~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]),
        cdr["duracion_seg"] < 0,
        fecha.isna(),
    ]
    return pd.Series(np.select(condiciones, PRIORIDAD, default="valido"), index=cdr.index)


def reporte(cdr, clientes):
    clasif = clasificar(cdr, clientes)
    conteo = clasif.value_counts()
    por_tipo = cdr.loc[clasif == "valido", "tipo"].value_counts()
    return {
        "registros_totales": int(len(cdr)),
        "registros_validos": int(conteo.get("valido", 0)),
        "errores": {error: int(conteo.get(error, 0)) for error in ORDEN_REPORTE},
        "validos_por_tipo": {tipo: int(por_tipo.get(tipo, 0)) for tipo in ["VOZ", "SMS", "DATOS"]},
    }


print(reporte(cdr, clientes))
```

## Explicación

Compara con el Proyecto 1: allí cada registro pasaba por una cascada de `if`; aquí cada regla es **una columna booleana completa** y `np.select` las combina respetando la prioridad. El resultado es idéntico, el código es más corto y, sobre archivos de varios millones de filas, mucho más rápido.

La prueba `prueba_orden_de_prioridad` verifica algo sutil: `np.select` evalúa todas las condiciones, pero elige **la primera verdadera de la lista**. Por eso el orden de `condiciones` es la regla de negocio.

¿El límite? Este validador necesita el archivo completo en memoria: con 1 GB funciona en tu computador; con 20 GB, no. En el módulo 14 leerás por bloques, y en el 16 usarás DuckDB.
