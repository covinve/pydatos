En el módulo 15 viste que los consumos de una telco tienen **cola larga**: la mayoría de las llamadas duran poco y unas pocas duran horas; la mayoría de las líneas consume pocos MB y unas pocas, cientos de GB. Con datos así, muchas herramientas estadísticas "de libro" (que suponen una campana de Gauss) dan respuestas engañosas.

## Media frente a mediana

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

print(f"Media:    {voz.mean():8.1f} s")
print(f"Mediana:  {voz.median():8.1f} s")
print(f"p90/p99:  {voz.quantile(0.9):8.1f} / {voz.quantile(0.99):.1f} s")
print(f"Asimetría: {voz.skew():.2f}  (0 = simétrica; > 1 = cola larga a la derecha)")

con_atipico = pd.concat([voz, pd.Series([86_400])])     # una sola llamada de 24 horas (un error de tasación)
print(f"Con una llamada de 24 h → media {con_atipico.mean():.1f}, mediana {con_atipico.median():.1f}")
```

Una sola llamada mal registrada mueve la media; la mediana ni se entera. Por eso se dice que la mediana es **robusta**.

| Medida "clásica" | Medida robusta | Robusta frente a |
|---|---|---|
| Media | Mediana | Valores extremos |
| Desviación estándar | **MAD**: mediana de las distancias absolutas a la mediana | Valores extremos |
| Mínimo / máximo | Percentiles 1 y 99 | Errores puntuales |
| Rango | Rango intercuartílico (IQR = p75 − p25) | Colas |

:::consejo MAD en la escala de la desviación estándar
Para datos normales, `1.4826 × MAD` ≈ desviación estándar. Ese factor permite usar MAD en fórmulas como el z-score (lección 2) con los mismos umbrales que ya conoces.
:::

:::reto Clásicas contra robustas
Con las duraciones de voz `voz` de la muestra, calcula:

- `mad`: la mediana de las distancias absolutas a la mediana;
- `mad_escalado`: `1.4826 × mad`, para compararlo con `voz.std()`;
- `salto_media` y `salto_mediana`: cuánto **cambian** la media y la mediana si agregas una sola llamada errónea de 86.400 segundos (24 horas).

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

# mad, mad_escalado, salto_media y salto_mediana

print(f"std {voz.std():.1f} vs MAD escalado {mad_escalado:.1f}")
print(f"La llamada de 24 h mueve la media {salto_media:.1f} s y la mediana {salto_mediana:.1f} s")
```

:::pista
`mad = (voz - voz.median()).abs().median()`. Para los saltos: `con_error = pd.concat([voz, pd.Series([86_400])])` y resta, por ejemplo, `con_error.mean() - voz.mean()`.
:::

```pyprueba
import pandas as pd


def _voz():
    c = pd.read_csv("cdr.csv", sep="|")
    return c.loc[(c["tipo"] == "VOZ") & (c["duracion_seg"] > 0), "duracion_seg"]


def prueba_mad():
    """mad y mad_escalado"""
    requiere("mad", "mad_escalado")
    v = _voz()
    esperado = (v - v.median()).abs().median()
    cerca(float(mad), float(esperado), 1e-9, "mad")
    cerca(float(mad_escalado), 1.4826 * float(esperado), 1e-6, "mad_escalado")


def prueba_saltos():
    """La media salta y la mediana casi no"""
    requiere("salto_media", "salto_mediana")
    v = _voz()
    x = pd.concat([v, pd.Series([86_400])])
    cerca(float(salto_media), float(x.mean() - v.mean()), 1e-6, "salto_media")
    cerca(float(salto_mediana), float(x.median() - v.median()), 1e-6, "salto_mediana")
    assert abs(salto_media) > 10 * abs(salto_mediana) + 1, "La media debería moverse mucho más que la mediana"
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

con_error = pd.concat([voz, pd.Series([86_400])])
salto_media = con_error.mean() - voz.mean()
salto_mediana = con_error.median() - voz.median()

print(f"std {voz.std():.1f} vs MAD escalado {mad_escalado:.1f}")
print(f"La llamada de 24 h mueve la media {salto_media:.1f} s y la mediana {salto_mediana:.1f} s")
```

## ¿Cuánto podría variar? Bootstrap

La mediana de la duración de tu muestra es, digamos, 118 segundos. Si hubieras tomado otro mes, ¿sería 118? ¿110? ¿130? El **bootstrap** responde sin fórmulas: simula "otros meses" remuestreando tus propios datos **con reemplazo**, y mira cuánto varía el estadístico.

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|")
voz = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"].to_numpy()

rng = np.random.default_rng(2026)
medianas = np.array([np.median(rng.choice(voz, size=len(voz), replace=True)) for _ in range(2000)])
bajo, alto = np.percentile(medianas, [2.5, 97.5])
print(f"Mediana {np.median(voz):.0f} s; intervalo de confianza del 95 %: [{bajo:.0f}, {alto:.0f}] s")
```

:::pasos Cómo funciona el bootstrap
:::paso 1. Remuestrear
De tus N valores, toma N al azar **con reemplazo** (algunos se repiten, otros no salen). Es "un mes alternativo" plausible.
:::
:::paso 2. Calcular
Calcula el estadístico (mediana, media, percentil 95, tasa de rechazo…) en esa muestra.
:::
:::paso 3. Repetir
Miles de veces. Obtienes la distribución del estadístico.
:::
:::paso 4. Leer el intervalo
Los percentiles 2.5 y 97.5 de esa distribución forman un intervalo de confianza del 95 %. Funciona para casi cualquier estadístico, sin suponer normalidad.
:::
:::

:::reto Tu función de bootstrap

Usa un generador con la semilla para que el resultado sea reproducible.

:::pista
`rng = np.random.default_rng(semilla)`; en una comprensión, `estadistico(rng.choice(datos, size=len(datos), replace=True))` para cada repetición. Al final, `np.percentile(valores, [2.5, 97.5])`.
:::

```pyprueba
import numpy as np


def prueba_contiene():
    """El intervalo contiene el estadístico de los datos"""
    requiere("intervalo_bootstrap")
    datos = np.random.default_rng(5).lognormal(3, 1, 500)
    bajo, alto = intervalo_bootstrap(datos, np.median, repeticiones=500, semilla=1)
    assert bajo <= np.median(datos) <= alto, f"[{bajo}, {alto}] no contiene la mediana {np.median(datos)}"
    assert bajo < alto, "El intervalo debe tener ancho"


def prueba_reproducible():
    """Con la misma semilla da lo mismo"""
    datos = np.arange(100.0)
    igual(tuple(map(float, intervalo_bootstrap(datos, np.mean, 300, 7))), tuple(map(float, intervalo_bootstrap(datos, np.mean, 300, 7))))


def prueba_constantes():
    """Con datos constantes, el intervalo es un punto"""
    bajo, alto = intervalo_bootstrap(np.full(50, 120.0), np.median, 200, 0)
    igual((float(bajo), float(alto)), (120.0, 120.0))


def prueba_mas_datos():
    """Con más datos, el intervalo es más angosto"""
    rng = np.random.default_rng(3)
    pocos = rng.normal(100, 20, 50)
    muchos = rng.normal(100, 20, 2000)
    a1, b1 = intervalo_bootstrap(pocos, np.mean, 400, 0)
    a2, b2 = intervalo_bootstrap(muchos, np.mean, 400, 0)
    assert (b2 - a2) < (b1 - a1), "Con 2000 datos el intervalo debería ser más angosto que con 50"
```

```pysolucion
import numpy as np
import pandas as pd


def intervalo_bootstrap(datos, estadistico, repeticiones=1000, semilla=0):
    rng = np.random.default_rng(semilla)
    valores = [estadistico(rng.choice(datos, size=len(datos), replace=True)) for _ in range(repeticiones)]
    bajo, alto = np.percentile(valores, [2.5, 97.5])
    return bajo, alto


cdr = pd.read_csv("cdr.csv", sep="|")
mb = cdr.loc[cdr["tipo"] == "DATOS", "mb"].to_numpy()
bajo, alto = intervalo_bootstrap(mb, np.median)
print(f"Mediana {np.median(mb):.1f} MB; IC 95 %: [{bajo:.1f}, {alto:.1f}]")
```

## ¿Es real la diferencia? Pruebas de permutación

Las llamadas de clientes empresariales duran en promedio 15 segundos más que las residenciales. ¿Es una diferencia real o puro azar? La **prueba de permutación** razona así: *si el segmento no tuviera nada que ver con la duración, mezclar las etiquetas al azar debería producir diferencias tan grandes como la observada con frecuencia*.

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"})
cli = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0)].merge(cli, left_on="linea_origen", right_on="linea")

emp = voz.loc[voz["segmento"] == "EMPRESARIAL", "duracion_seg"].to_numpy()
res = voz.loc[voz["segmento"] == "RESIDENCIAL", "duracion_seg"].to_numpy()
observada = emp.mean() - res.mean()

rng = np.random.default_rng(7)
todas = np.concatenate([emp, res])
extremas = 0
for _ in range(2000):
    mezcla = rng.permutation(todas)
    diferencia = mezcla[:len(emp)].mean() - mezcla[len(emp):].mean()
    extremas += abs(diferencia) >= abs(observada)
p = (extremas + 1) / (2000 + 1)
print(f"Diferencia observada: {observada:.1f} s   valor p ≈ {p:.3f}")
```

Un **valor p** pequeño (por convención, < 0.05) dice que una diferencia así rara vez aparece por azar. No dice que la diferencia sea **importante**: con millones de CDR, una diferencia de 0.3 segundos puede tener p = 0.0001 y no importarle a nadie. Mira siempre el **tamaño** del efecto, no solo el valor p.

:::

```pyprueba
import numpy as np


def prueba_diferentes():
    """Grupos claramente distintos dan un p pequeño"""
    requiere("valor_p")
    rng = np.random.default_rng(1)
    p = valor_p(rng.lognormal(4.0, 0.5, 300), rng.lognormal(4.6, 0.5, 300), 500, 0)
    assert p < 0.01, f"Con grupos tan distintos, p debería ser < 0.01 (dio {p})"


def prueba_iguales():
    """Grupos de la misma distribución dan un p grande"""
    rng = np.random.default_rng(2)
    p = valor_p(rng.lognormal(4.0, 0.8, 300), rng.lognormal(4.0, 0.8, 300), 500, 0)
    assert p > 0.05, f"Con grupos iguales, p debería ser > 0.05 (dio {p})"


def prueba_rango():
    """El valor p nunca es 0"""
    p = valor_p(np.arange(20.0), np.arange(1000.0, 1020.0), 200, 0)
    cerca(p, 1 / 201, 1e-12, "con diferencia máxima, p = 1/(n+1)")
```

```pysolucion
import numpy as np


def valor_p(a, b, repeticiones=2000, semilla=0):
    rng = np.random.default_rng(semilla)
    observada = np.median(a) - np.median(b)
    todas = np.concatenate([a, b])
    extremas = 0
    for _ in range(repeticiones):
        mezcla = rng.permutation(todas)
        diferencia = np.median(mezcla[: len(a)]) - np.median(mezcla[len(a):])
        extremas += abs(diferencia) >= abs(observada)
    return (extremas + 1) / (repeticiones + 1)


rng = np.random.default_rng(1)
plan_a = rng.lognormal(4.0, 0.8, 300)
plan_b = rng.lognormal(4.3, 0.8, 300)
print(f"valor p = {valor_p(plan_a, plan_b):.4f}")
```

:::capo Correlación no es causalidad
Las líneas con más llamadas internacionales tienen más reclamos. ¿Las llamadas causan reclamos? Quizás ambas cosas se deben a un tercer factor (clientes empresariales con más actividad en general). Antes de recomendar una acción ("limitar llamadas internacionales para reducir reclamos"), pregunta qué más podría explicar la relación.
