## Enunciado

Escribe dos **funciones generadoras** (con `yield`) y una función que las use:

1. `campos(lineas)` → para cada línea de texto `"cdr_id|tipo|duracion_seg"`, entrega una tupla `(cdr_id: int, tipo: str, duracion: int)`. Ignora las líneas vacías o con solo espacios.
2. `solo_voz(registros)` → entrega solo los registros cuyo tipo es `"VOZ"`.
3. `total_minutos_voz(lineas)` → la suma de minutos facturables de los registros de voz, encadenando los dos generadores y usando una **expresión generadora** dentro de `sum` (no construyas listas).

```python
lineas = ["1|VOZ|125", "2|SMS|0", "", "3|VOZ|61"]
list(campos(lineas))              # [(1, "VOZ", 125), (2, "SMS", 0), (3, "VOZ", 61)]
total_minutos_voz(lineas)         # 5
```

## Pruebas

```python
import ast
import inspect

LINEAS = ["1|VOZ|125", "2|SMS|0", "  ", "3|VOZ|61", "4|DATOS|900"]


def prueba_son_generadores():
    """campos y solo_voz son funciones generadoras"""
    requiere("campos", "solo_voz")
    assert inspect.isgeneratorfunction(campos), "campos debe usar yield"
    assert inspect.isgeneratorfunction(solo_voz), "solo_voz debe usar yield"


def prueba_campos():
    """Convierte las líneas e ignora las vacías"""
    igual(list(campos(LINEAS)), [(1, "VOZ", 125), (2, "SMS", 0), (3, "VOZ", 61), (4, "DATOS", 900)])


def prueba_solo_voz():
    """Filtra los registros de voz"""
    igual(list(solo_voz(campos(LINEAS))), [(1, "VOZ", 125), (3, "VOZ", 61)])


def prueba_total():
    """Suma los minutos de voz"""
    requiere("total_minutos_voz")
    igual(total_minutos_voz(LINEAS), 5)
    igual(total_minutos_voz([]), 0)


def prueba_perezoso():
    """Funciona con un iterable enorme sin construir listas"""
    def infinito():
        n = 0
        while True:
            n += 1
            yield f"{n}|VOZ|60"
    from itertools import islice
    igual(total_minutos_voz(islice(infinito(), 200_000)), 200_000)


def prueba_sin_listas_en_total():
    """total_minutos_voz no construye listas"""
    funcion = next(n for n in ast.walk(ast.parse(codigo)) if isinstance(n, ast.FunctionDef) and n.name == "total_minutos_voz")
    assert not any(isinstance(n, ast.ListComp) for n in ast.walk(funcion)), "Usa una expresión generadora, no [...]"
    assert "list(" not in ast.get_source_segment(codigo, funcion), "No conviertas a lista"
```

```python
def campos(lineas):
    for linea in lineas:
        if not linea.strip():
            continue
        cdr_id, tipo, duracion = linea.strip().split("|")
        yield int(cdr_id), tipo, int(duracion)
```

## Pista 2

`total_minutos_voz` encadena: `solo_voz(campos(lineas))`, y suma con una expresión generadora (paréntesis implícitos dentro de `sum`):

```python
return sum((duracion + 59) // 60 for _, _, duracion in solo_voz(campos(lineas)))
```

## Solución

```python
def campos(lineas):
    for linea in lineas:
        if not linea.strip():
            continue
        cdr_id, tipo, duracion = linea.strip().split("|")
        yield int(cdr_id), tipo, int(duracion)


def solo_voz(registros):
    for registro in registros:
        if registro[1] == "VOZ":
            yield registro


def total_minutos_voz(lineas):
    return sum((duracion + 59) // 60 for _, _, duracion in solo_voz(campos(lineas)))


lineas = ["1|VOZ|125", "2|SMS|0", "", "3|VOZ|61"]
print(total_minutos_voz(lineas))
```

## Explicación

Tres funciones pequeñas encadenadas forman un pipeline. La prueba `prueba_perezoso` le pasa un iterable de 200.000 líneas generadas al vuelo: nunca existen todas a la vez, y la suma funciona igual.

Fíjate que `campos` y `solo_voz` no saben si las líneas vienen de una lista, de un archivo o de otro generador: aceptan **cualquier iterable**. Eso las hace reutilizables y fáciles de probar con datos de juguete.
