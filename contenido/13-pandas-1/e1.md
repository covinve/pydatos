## Enunciado

Escribe:

1. `leer_clientes(ruta)` → DataFrame de `clientes.csv` (latin-1), con `linea` y `documento` como **texto** y `fecha_alta` como fecha (`datetime64`).
2. `leer_planes(ruta)` → DataFrame de `planes.csv` con `plan_id` como **índice**.
3. `resumen_cartera(clientes, planes)` → diccionario con:
   - `"clientes"`: cantidad de filas;
   - `"activos"`: cantidad con estado `ACTIVO`;
   - `"por_segmento"`: `{segmento: cantidad}` (de `value_counts`, ordenado por segmento);
   - `"cargo_fijo_total"`: suma del cargo fijo de **todos** los clientes según su plan (usa `map` sobre la columna `cargo_fijo` de los planes).

Todos los números como `int` de Python.

## Pista 2

`clientes["plan_id"].map(planes["cargo_fijo"])` busca el cargo fijo de cada cliente usando el índice de los planes. Para el diccionario de segmentos: `{k: int(v) for k, v in clientes["segmento"].value_counts().sort_index().items()}`.

## Solución

```python
import pandas as pd


def leer_clientes(ruta):
    return pd.read_csv(
        ruta,
        encoding="latin-1",
        dtype={"linea": "string", "documento": "string"},
        parse_dates=["fecha_alta"],
    )


def leer_planes(ruta):
    return pd.read_csv(ruta, index_col="plan_id")


def resumen_cartera(clientes, planes):
    por_segmento = clientes["segmento"].value_counts().sort_index()
    return {
        "clientes": int(len(clientes)),
        "activos": int((clientes["estado"] == "ACTIVO").sum()),
        "por_segmento": {segmento: int(n) for segmento, n in por_segmento.items()},
        "cargo_fijo_total": int(clientes["plan_id"].map(planes["cargo_fijo"]).sum()),
    }


clientes = leer_clientes("clientes.csv")
planes = leer_planes("planes.csv")
print(resumen_cartera(clientes, planes))
```

## Explicación

Leer bien es la mitad del trabajo: encoding, tipos de los identificadores y fechas se deciden **al leer**, en un solo lugar. Si lo dejas para después, cada análisis tiene que acordarse de corregirlo.

`map` con una Series indexada es un "buscar en tabla" vectorizado: para cada `plan_id` de los clientes busca su `cargo_fijo` en el índice de los planes. Es un cruce simple entre dos tablas; el cruce completo (`merge`) lo verás en el módulo 14.
