Una **lista** guarda varios valores en orden. Es la estructura más usada de Python.

```pyrun
duraciones = [125, 0, 61, 3600]
tipos = ["VOZ", "SMS", "DATOS"]
mezclada = [1, "VOZ", 15.5, None]   # pueden mezclar tipos (pero evítalo)
vacia = []

print(len(duraciones), duraciones[0], duraciones[-1])
print(duraciones[1:3])
print("SMS" in tipos)
```

Indexar y cortar funciona igual que con el texto (módulo 2). La gran diferencia: **las listas se pueden modificar**.

## Modificar una lista

```pyrun
cola = ["cdr_01.csv", "cdr_02.csv"]

cola.append("cdr_03.csv")            # agrega al final
cola.insert(0, "urgente.csv")        # agrega en una posición
cola.extend(["a.csv", "b.csv"])      # agrega varios
print(cola)

procesado = cola.pop(0)              # saca (y devuelve) el de la posición 0
print("Procesando:", procesado)

cola.remove("a.csv")                 # quita por valor (el primero que encuentre)
cola[0] = "CDR_01.CSV"               # reemplaza
print(cola)
```

| Método | Qué hace | Devuelve |
|---|---|---|
| `append(x)` | Agrega `x` al final | `None` |
| `extend(otra)` | Agrega todos los elementos de `otra` | `None` |
| `insert(i, x)` | Inserta `x` en la posición `i` | `None` |
| `pop()` / `pop(i)` | Quita el último / el de la posición `i` | El elemento quitado |
| `remove(x)` | Quita la primera aparición de `x` | `None` (error si no existe) |
| `index(x)` | Posición de la primera aparición | `int` |
| `count(x)` | Cuántas veces aparece | `int` |
| `sort()` | Ordena **la misma lista** | `None` |
| `reverse()` | Invierte **la misma lista** | `None` |

:::reto La cola de archivos
El proceso nocturno tiene una cola de archivos por procesar. Haz estos cambios, en orden, con métodos de lista:

1. Agrega `"cdr_04.csv"` al final.
2. Agrega `"reproceso.csv"` al **principio**: es urgente.
3. Saca el primero de la cola y guárdalo en `siguiente`.
4. Quita `"cdr_02.csv"`: ya lo procesó otro servidor.

```pyreto
cola = ["cdr_01.csv", "cdr_02.csv", "cdr_03.csv"]

# 1. al final
# 2. al principio
# 3. sacar el primero en siguiente
# 4. quitar cdr_02.csv

print(siguiente)
print(cola)
```

:::pista
Los métodos son `append`, `insert(0, ...)`, `pop(0)` y `remove(...)`. `pop` devuelve el elemento que saca: `siguiente = cola.pop(0)`.
:::

```pyprueba
def prueba_siguiente():
    """siguiente = «reproceso.csv»"""
    requiere("siguiente")
    igual(siguiente, "reproceso.csv")


def prueba_cola():
    """La cola queda con cdr_01, cdr_03 y cdr_04"""
    requiere("cola")
    igual(cola, ["cdr_01.csv", "cdr_03.csv", "cdr_04.csv"])
```

```pysolucion
cola = ["cdr_01.csv", "cdr_02.csv", "cdr_03.csv"]

cola.append("cdr_04.csv")
cola.insert(0, "reproceso.csv")
siguiente = cola.pop(0)
cola.remove("cdr_02.csv")

print(siguiente)
print(cola)
```

## Ordenar

`lista.sort()` modifica la lista; `sorted(lista)` devuelve una **nueva** lista ordenada y deja la original intacta.

```pyrun
consumos = [("3001", 342), ("3002", 15), ("3003", 1203), ("3004", 342)]

por_minutos = sorted(consumos, key=lambda c: c[1], reverse=True)
print(por_minutos)
print(consumos)          # la original no cambió
```

`key=` indica **por qué** ordenar. `lambda c: c[1]` es una función pequeña, sin nombre, que dice "usa el segundo elemento". Las verás a fondo en el módulo 5.

:::error lista.sort() devuelve None
```python
ordenada = duraciones.sort()   # ordenada vale None
```
Si quieres una lista ordenada en otra variable, usa `sorted(duraciones)`.
:::

:::reto Las tres líneas que más navegan
Crea `top3` con las tres líneas de **más megas**, de mayor a menor, sin modificar la lista original `consumos`.

```pyreto
consumos = [("3001", 1520.5), ("3002", 98.0), ("3003", 20480.2), ("3004", 5120.0), ("3005", 15360.0)]

# top3: ordena por megas, de mayor a menor, y toma las tres primeras

print(top3)
```

:::pista
`sorted(consumos, key=lambda c: c[1], reverse=True)` ordena por el segundo elemento, de mayor a menor. Luego toma las tres primeras con slicing: `[:3]`.
:::

```pyprueba
def prueba_top3():
    """top3 tiene las tres de más megas, en orden"""
    requiere("top3")
    igual(top3, [("3003", 20480.2), ("3005", 15360.0), ("3004", 5120.0)])


def prueba_original_intacta():
    """La lista consumos no cambió"""
    igual(consumos, [("3001", 1520.5), ("3002", 98.0), ("3003", 20480.2), ("3004", 5120.0), ("3005", 15360.0)])
```

```pysolucion
consumos = [("3001", 1520.5), ("3002", 98.0), ("3003", 20480.2), ("3004", 5120.0), ("3005", 15360.0)]

top3 = sorted(consumos, key=lambda c: c[1], reverse=True)[:3]

print(top3)
```

## La trampa: las listas se comparten

Recuerda que las variables son etiquetas. Si dos etiquetas apuntan **a la misma lista**, modificarla por una se ve por la otra:

```pytrace
originales = [125, 0, 61]
copia = originales
copia.append(999)
print(originales)
```

`copia = originales` **no copia** la lista: pega una segunda etiqueta a la misma. Para copiarla de verdad:

```pyrun
originales = [125, 0, 61]

copia = originales.copy()      # o list(originales) o originales[:]
copia.append(999)

print(originales)
print(copia)
```

:::capo ¿Por qué con números no pasa?
Los números y los textos son **inmutables**: `x = x + 1` crea un valor nuevo y mueve la etiqueta. Las listas son **mutables**: `append` cambia la lista existente, y todas las etiquetas que la apuntan ven el cambio. Este detalle causa errores muy difíciles de encontrar, sobre todo cuando pasas una lista a una función y la función la modifica.
:::

:::reto Una función que no toca lo ajeno
Esta función agrega un ajuste a la lista de cargos… pero también **daña la lista original** de quien la llama. Corrígela para que devuelva una lista nueva y deje la original intacta.

```pyreto
def con_ajuste(cargos, ajuste):
    nuevos = cargos
    nuevos.append(ajuste)
    return nuevos


cargos_marzo = [35900, 5040, 1200]
cargos_ajustados = con_ajuste(cargos_marzo, -2000)
print(cargos_ajustados)
print(cargos_marzo)   # debería seguir con 3 cargos
```

:::pista
`nuevos = cargos` solo pega otra etiqueta a la misma lista. Cópiala de verdad: `nuevos = cargos.copy()`.
:::

```pyprueba
def prueba_devuelve_con_ajuste():
    """Devuelve los cargos con el ajuste al final"""
    requiere("con_ajuste")
    igual(con_ajuste([100, 200], -50), [100, 200, -50])


def prueba_no_modifica():
    """La lista original no cambia"""
    originales = [35900, 5040, 1200]
    con_ajuste(originales, -2000)
    igual(originales, [35900, 5040, 1200], "La lista original fue modificada")
```

```pysolucion
def con_ajuste(cargos, ajuste):
    nuevos = cargos.copy()
    nuevos.append(ajuste)
    return nuevos


cargos_marzo = [35900, 5040, 1200]
cargos_ajustados = con_ajuste(cargos_marzo, -2000)
print(cargos_ajustados)
print(cargos_marzo)   # debería seguir con 3 cargos
```
:::

## Listas de listas

Una lista puede contener otras listas. Así se representa una tabla:

```pyrun
tabla = [
    ["linea", "minutos", "mb"],
    ["3001234567", 342, 15360.5],
    ["3109876543", 15, 512.0],
]

for fila in tabla[1:]:
    linea, minutos, mb = fila
    print(f"{linea}: {minutos} min, {mb} MB")

print(tabla[2][1])   # fila 2, columna 1
```

:::reto Totales de una tabla
Con la tabla de abajo:

- `total_minutos`: suma la columna de minutos (sin el encabezado);
- `mb_tercera`: las megas de la **tercera línea** de datos, leídas con doble índice.

```pyreto
tabla = [
    ["linea", "minutos", "mb"],
    ["3001234567", 342, 15360.5],
    ["3109876543", 15, 512.0],
    ["3157778899", 1203, 20480.0],
]

# total_minutos y mb_tercera

print(total_minutos, mb_tercera)
```

:::pista
Recorre `tabla[1:]` para saltar el encabezado y acumula `fila[1]`. La tercera línea de datos es la fila 3 de la tabla (la 0 es el encabezado): `tabla[3][2]`.
:::

```pyprueba
def prueba_total():
    """total_minutos = 1560"""
    requiere("total_minutos")
    igual(total_minutos, 1560)


def prueba_tercera():
    """mb_tercera = 20480.0"""
    requiere("mb_tercera")
    igual(mb_tercera, 20480.0)
```

```pysolucion
tabla = [
    ["linea", "minutos", "mb"],
    ["3001234567", 342, 15360.5],
    ["3109876543", 15, 512.0],
    ["3157778899", 1203, 20480.0],
]

total_minutos = 0
for fila in tabla[1:]:
    total_minutos += fila[1]

mb_tercera = tabla[3][2]

print(total_minutos, mb_tercera)
```
:::

:::telco ¿Y para millones de filas?
Una lista de listas sirve para tablas pequeñas. Para los archivos de facturación usarás **Pandas** (módulos 13 y 14), que guarda las tablas en memoria de forma mucho más compacta y rápida.
:::

## Cuestionario

? ¿Qué imprime este código? `a = [1, 2]`, `b = a`, `b.append(3)`, `print(a)`
- [ ] `[1, 2]`
- [x] `[1, 2, 3]`
- [ ] `[3]`
- [ ] Un error
> `b = a` no copia la lista: ambas variables apuntan a la misma. Al modificarla por `b`, el cambio se ve por `a`.

? ¿Qué vale `x` después de `x = [3, 1, 2].sort()`?
- [ ] `[1, 2, 3]`
- [ ] `[3, 1, 2]`
- [x] `None`
- [ ] Un error
> `sort()` ordena la lista en su lugar y devuelve `None`. Para obtener una lista ordenada usa `sorted([3, 1, 2])`.

? ¿Cuál es la forma correcta de quitar y obtener el primer archivo de la cola `cola`?
- [ ] `cola.remove(0)`
- [x] `cola.pop(0)`
- [ ] `del cola`
- [ ] `cola[0] = None`
> `pop(0)` quita el elemento de la posición 0 y lo devuelve. `remove` busca por valor, no por posición.
