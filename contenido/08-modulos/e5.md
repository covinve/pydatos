## Enunciado

En `ejercicios/m08-e5/` hay un paquete casi listo con estructura `src/`:

```text
ejercicios/m08-e5/
├── README.md
└── src/
    └── telco_formato/
        ├── __init__.py
        ├── formato.py     ← formatear_pesos ya funciona
        └── cli.py         ← main() por completar
```

1. Completa `main()` en `cli.py`: lee **uno o más** valores de la terminal (con `argparse`) e imprime cada uno con `formatear_pesos`, uno por línea.
2. Crea `ejercicios/m08-e5/pyproject.toml` con:
   - nombre del proyecto `telco-formato`, versión `0.1.0`, Python `>=3.11`;
   - un comando de terminal `telco-formato` que ejecute `telco_formato.cli:main`;
   - setuptools como sistema de construcción.
3. Instálalo en modo editable con el entorno del curso activo:

```powershell
python -m pip install -e ejercicios/m08-e5
telco-formato 48719.5 1234567
python comprobar.py m08-e5
```

:::consejo Valores negativos en argparse
`telco-formato -5000` puede confundir a argparse, que cree que `-5000` es una opción. Con `type=float` y `nargs="+"`, argparse reconoce los números negativos correctamente.
:::

## Pista 1

El `pyproject.toml` mínimo para este caso:

```toml
[project]
name = "telco-formato"
version = "0.1.0"
requires-python = ">=3.11"

[project.scripts]
telco-formato = "telco_formato.cli:main"

[build-system]
requires = ["setuptools>=69"]
build-backend = "setuptools.build_meta"
```

Con la estructura `src/`, setuptools encuentra el paquete automáticamente.

## Pista 2

En `cli.py`:

```python
import argparse

from telco_formato.formato import formatear_pesos


def main() -> None:
    parser = argparse.ArgumentParser(description="Formatea valores en pesos")
    parser.add_argument("valores", type=float, nargs="+", help="valores a formatear")
    args = parser.parse_args()
    for valor in args.valores:
        print(formatear_pesos(valor))
```

Si cambias `pyproject.toml` (por ejemplo, el nombre del comando), vuelve a ejecutar `pip install -e`. Si solo cambias código Python, no hace falta.

## Solución

`ejercicios/m08-e5/pyproject.toml`:

```toml
[project]
name = "telco-formato"
version = "0.1.0"
description = "Formato de valores para reportes de facturación"
readme = "README.md"
requires-python = ">=3.11"

[project.scripts]
telco-formato = "telco_formato.cli:main"

[build-system]
requires = ["setuptools>=69"]
build-backend = "setuptools.build_meta"
```

`ejercicios/m08-e5/src/telco_formato/cli.py`:

```python
"""Comando de terminal: telco-formato VALOR [VALOR ...]"""

import argparse

from telco_formato.formato import formatear_pesos


def main() -> None:
    """Lee uno o más valores de la terminal e imprime cada uno con formato de pesos, uno por línea."""
    parser = argparse.ArgumentParser(description="Formatea valores en pesos")
    parser.add_argument("valores", type=float, nargs="+", help="valores a formatear")
    args = parser.parse_args()
    for valor in args.valores:
        print(formatear_pesos(valor))
```

Instalación: `python -m pip install -e ejercicios/m08-e5`.

## Explicación

Al instalar, pip:

1. Lee `pyproject.toml` y construye el paquete con setuptools.
2. Registra `telco-formato 0.1.0` en tu entorno (lo ves con `pip list`).
3. Como es **editable**, en lugar de copiar el código deja un enlace a `src/`: tus cambios se ven sin reinstalar.
4. Crea `telco-formato.exe` en `.venv\Scripts\`, que llama a `telco_formato.cli:main`.

Ahora `import telco_formato` funciona desde **cualquier** carpeta, un notebook o las pruebas, siempre que uses ese entorno virtual. Así se distribuyen las herramientas internas de un equipo: cada quien hace `pip install` del repositorio y obtiene la misma versión.

Para desinstalarlo: `python -m pip uninstall telco-formato`.
