## Enunciado

1. `clientes_con_plan(clientes, planes)` → `merge` de clientes con planes (`left`, por `plan_id`), **validando** que la relación sea muchos a uno. Las columnas repetidas de los planes llevan el sufijo `_plan`. Debe tener la misma cantidad de filas que `clientes`.
2. `auditar_lineas(cdr, clientes)` → diccionario con la cantidad de **líneas distintas** según su origen, haciendo un `merge` *outer* con `indicator` entre las líneas distintas del CDR (no vacías) y las de los clientes:
   - `"en_ambos"`: líneas con CDR que son clientes;
   - `"solo_cdr"`: líneas con CDR que no son clientes;
   - `"solo_clientes"`: clientes sin ningún CDR.

## Solución

```python
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
planes = pd.read_csv("planes.csv")


def clientes_con_plan(clientes, planes):
    return clientes.merge(planes, on="plan_id", how="left", suffixes=("", "_plan"), validate="many_to_one")


def auditar_lineas(cdr, clientes):
    lineas_cdr = pd.DataFrame({"linea": cdr.loc[cdr["linea_origen"] != "", "linea_origen"].unique()})
    lineas_cli = pd.DataFrame({"linea": clientes["linea"].unique()})
    conteo = lineas_cdr.merge(lineas_cli, on="linea", how="outer", indicator=True)["_merge"].value_counts()
    return {
        "en_ambos": int(conteo.get("both", 0)),
        "solo_cdr": int(conteo.get("left_only", 0)),
        "solo_clientes": int(conteo.get("right_only", 0)),
    }


print(clientes_con_plan(clientes, planes).head())
print(auditar_lineas(cdr, clientes))
```

## Explicación

Dos hábitos que te van a ahorrar muchos problemas:

- **`validate=` en los cruces de maestros**: si alguien carga un plan dos veces en el catálogo, el proceso falla con un error claro en lugar de duplicar silenciosamente el cargo fijo de miles de clientes.
- **`indicator=True` para auditar**: antes de facturar, saber cuántas líneas tienen consumo sin ser clientes (consumo que nadie va a pagar) y cuántos clientes no tienen consumo (¿líneas inactivas? ¿falta un archivo?).

Es el mismo análisis que hiciste con conjuntos en el módulo 4, ahora con las herramientas que escalan a tablas grandes.
