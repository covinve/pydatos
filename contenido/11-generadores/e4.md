## Enunciado

Construye un pipeline de **cuatro etapas generadoras** sobre `cdr.csv`:

1. `leer(ruta)` → entrega cada línea de datos sin el salto de línea (salta el encabezado).
2. `parsear(lineas)` → entrega un diccionario por línea con `cdr_id` (int), `linea_origen`, `tipo`, `destino`, `fecha_inicio` (texto) y `duracion_seg` (int).
3. `validos(cdrs)` → entrega solo los CDR con línea no vacía, tipo `VOZ`/`SMS`/`DATOS`, duración ≥ 0 y fecha válida (`datetime.strptime` con `"%Y-%m-%d %H:%M:%S"`).
4. `por_destino(cdrs)` → **no es generador**: consume el flujo y devuelve `{destino: minutos facturables}` solo de los `VOZ`, ordenado por destino.

Y `procesar(ruta)` que las encadene.

## Pista 1

`leer` es casi idéntica a la de la lección 4. En `parsear`, divide con `split("|")` y toma las posiciones 0, 1, 3, 4, 5 y 6.

## Pista 2

`validos` puede usar una función auxiliar `fecha_ok(texto)` con `try/except ValueError`. `por_destino` es el patrón agrupar del módulo 4, y `procesar` es una sola línea: `return por_destino(validos(parsear(leer(ruta))))`.

## Solución

```python
from datetime import datetime

TIPOS = {"VOZ", "SMS", "DATOS"}


def leer(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield linea.rstrip("\n")


def parsear(lineas):
    for linea in lineas:
        c = linea.split("|")
        yield {
            "cdr_id": int(c[0]),
            "linea_origen": c[1],
            "tipo": c[3],
            "destino": c[4],
            "fecha_inicio": c[5],
            "duracion_seg": int(c[6]),
        }


def fecha_ok(texto):
    try:
        datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")
    except ValueError:
        return False
    return True


def validos(cdrs):
    for c in cdrs:
        if c["linea_origen"] and c["tipo"] in TIPOS and c["duracion_seg"] >= 0 and fecha_ok(c["fecha_inicio"]):
            yield c


def por_destino(cdrs):
    totales = {}
    for c in cdrs:
        if c["tipo"] == "VOZ":
            totales[c["destino"]] = totales.get(c["destino"], 0) + (c["duracion_seg"] + 59) // 60
    return dict(sorted(totales.items()))


def procesar(ruta):
    return por_destino(validos(parsear(leer(ruta))))


print(procesar("cdr.csv"))
```

## Explicación

La última línea, `por_destino(validos(parsear(leer(ruta))))`, se lee de adentro hacia afuera como una receta: leer, parsear, filtrar, resumir.

Fíjate en la prueba `prueba_validos`: la etapa se prueba **sola**, con una lista de diccionarios inventados, sin ningún archivo. Esa es la gran ventaja de dividir el proceso en etapas que aceptan cualquier iterable.

Las condiciones de `validos` están ordenadas de la más barata a la más cara: comparar textos es instantáneo; `strptime` es lo más lento. Gracias al cortocircuito de `and`, la fecha solo se valida si todo lo demás pasó.
