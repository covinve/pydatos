## Enunciado

Vas a construir un validador donde **cada regla es una función**. Así, agregar una regla nueva no requiere tocar el código que valida.

Escribe tres **fábricas de reglas** (cada una devuelve una función `regla(cdr) -> bool` que es `True` si el CDR **cumple** la regla):

1. `no_vacio(campo)` → el campo existe y, sin espacios, no está vacío.
2. `uno_de(campo, valores)` → el valor del campo está en `valores`.
3. `en_rango(campo, minimo=None, maximo=None)` → el valor del campo es `>= minimo` (si se dio) y `<= maximo` (si se dio).

Y la función que las aplica:

4. `validar(cdr, reglas)` → `reglas` es una lista de pares `(nombre, regla)`. Devuelve la lista de **nombres** de las reglas que el CDR **no** cumple, en el orden de la lista.

```python
REGLAS = [
    ("linea_vacia", no_vacio("linea_origen")),
    ("tipo_desconocido", uno_de("tipo", {"VOZ", "SMS", "DATOS"})),
    ("duracion_negativa", en_rango("duracion_seg", minimo=0)),
    ("duracion_excesiva", en_rango("duracion_seg", maximo=7200)),
]
validar({"linea_origen": "3001", "tipo": "VOX", "duracion_seg": -5}, REGLAS)
# ["tipo_desconocido", "duracion_negativa"]
```

## Pruebas

```python
def reglas():
    return [
        ("linea_vacia", no_vacio("linea_origen")),
        ("tipo_desconocido", uno_de("tipo", {"VOZ", "SMS", "DATOS"})),
        ("duracion_negativa", en_rango("duracion_seg", minimo=0)),
        ("duracion_excesiva", en_rango("duracion_seg", maximo=7200)),
    ]


def prueba_no_vacio():
    """no_vacio rechaza vacíos, espacios y campos ausentes"""
    requiere("no_vacio")
    regla = no_vacio("linea_origen")
    igual(regla({"linea_origen": "3001"}), True)
    igual(regla({"linea_origen": "   "}), False)
    igual(regla({"linea_origen": ""}), False)
    igual(regla({}), False)


def prueba_uno_de():
    """uno_de acepta solo los valores permitidos"""
    requiere("uno_de")
    regla = uno_de("tipo", {"VOZ", "SMS", "DATOS"})
    igual(regla({"tipo": "SMS"}), True)
    igual(regla({"tipo": "VOX"}), False)


def prueba_en_rango():
    """en_rango con mínimo, máximo o ambos"""
    requiere("en_rango")
    igual(en_rango("x", minimo=0)({"x": 0}), True)
    igual(en_rango("x", minimo=0)({"x": -1}), False)
    igual(en_rango("x", maximo=10)({"x": 11}), False)
    igual(en_rango("x", minimo=1, maximo=10)({"x": 10}), True)
    igual(en_rango("x")({"x": -999}), True)


def prueba_validar_cdr_bueno():
    """Un CDR correcto no incumple ninguna regla"""
    requiere("validar")
    igual(validar({"linea_origen": "3001", "tipo": "VOZ", "duracion_seg": 125}, reglas()), [])


def prueba_validar_varios_errores():
    """Devuelve todas las reglas incumplidas, en orden"""
    igual(validar({"linea_origen": "3001", "tipo": "VOX", "duracion_seg": -5}, reglas()),
          ["tipo_desconocido", "duracion_negativa"])
    igual(validar({"linea_origen": "", "tipo": "VOZ", "duracion_seg": 9000}, reglas()),
          ["linea_vacia", "duracion_excesiva"])


def prueba_regla_personalizada():
    """Acepta cualquier función como regla"""
    solo_moviles = ("no_movil", lambda cdr: cdr["linea_origen"].startswith("3"))
    igual(validar({"linea_origen": "6011234567", "tipo": "VOZ", "duracion_seg": 1}, reglas() + [solo_moviles]), ["no_movil"])
```

## Pista 1

Cada fábrica define una función interna que usa los parámetros de la fábrica, y la devuelve:

```python
def uno_de(campo, valores):
    def regla(cdr):
        return cdr.get(campo) in valores
    return regla
```

Las otras dos siguen el mismo esquema.

## Pista 2

En `en_rango`, pregunta por cada límite solo si se dio (`is not None`):

```python
def regla(cdr):
    valor = cdr[campo]
    if minimo is not None and valor < minimo:
        return False
    if maximo is not None and valor > maximo:
        return False
    return True
```

`validar` es una comprensión: `[nombre for nombre, regla in reglas if not regla(cdr)]`.

## Solución

```python
def no_vacio(campo):
    def regla(cdr):
        return bool(str(cdr.get(campo, "")).strip())
    return regla


def uno_de(campo, valores):
    def regla(cdr):
        return cdr.get(campo) in valores
    return regla


def en_rango(campo, minimo=None, maximo=None):
    def regla(cdr):
        valor = cdr[campo]
        if minimo is not None and valor < minimo:
            return False
        if maximo is not None and valor > maximo:
            return False
        return True
    return regla


def validar(cdr, reglas):
    return [nombre for nombre, regla in reglas if not regla(cdr)]


REGLAS = [
    ("linea_vacia", no_vacio("linea_origen")),
    ("tipo_desconocido", uno_de("tipo", {"VOZ", "SMS", "DATOS"})),
    ("duracion_negativa", en_rango("duracion_seg", minimo=0)),
    ("duracion_excesiva", en_rango("duracion_seg", maximo=7200)),
]
print(validar({"linea_origen": "3001", "tipo": "VOX", "duracion_seg": -5}, REGLAS))
```

## Explicación

Compara este validador con el `clasificar_cdr` del módulo 3:

| | Módulo 3 | Ahora |
|---|---|---|
| Agregar una regla | Editar la función y su cadena de `if` | Agregar un par a la lista |
| Ver todas las reglas | Leer todo el código | Leer la lista `REGLAS` |
| Reportar varios errores | Solo el primero | Todos |
| Reutilizar reglas en otro archivo | Copiar código | Usar las mismas fábricas |

Las fábricas (`no_vacio`, `uno_de`, `en_rango`) son **closures** que "congelan" su configuración. Con tres fábricas puedes expresar decenas de reglas. Las librerías profesionales de validación de datos (como *pandera* o *Great Expectations*) funcionan con esta misma idea.

En tu **Proyecto 1** podrás usar este diseño para el validador de archivos.
