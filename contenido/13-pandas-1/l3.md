## Columnas calculadas

Las operaciones entre columnas son vectorizadas, como en NumPy:

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

cdr["minutos"] = np.where(cdr["tipo"] == "VOZ", (cdr["duracion_seg"].clip(lower=0) + 59) // 60, 0)
cdr["tarifa"] = np.select(
    [cdr["destino"] == "LOCAL", cdr["destino"] == "NACIONAL", cdr["destino"] == "INTERNACIONAL"],
    [100, 120, 950],
    default=0,
)
cdr["valor"] = cdr["minutos"] * cdr["tarifa"]
print(cdr[["tipo", "destino", "duracion_seg", "minutos", "valor"]].head(8))
print("Total:", cdr["valor"].sum())
```

:::reto El valor de los datos
Sobre el `cdr` de la muestra, sin bucles ni `apply`:

1. Crea la columna `mb_facturables`: para los registros de `DATOS`, las megas redondeadas hacia arriba; para los demás, `0`.
2. Crea la columna `valor_datos`: `mb_facturables` por 18 pesos.
3. Crea `total_datos`: la suma de `valor_datos`.


:::pista
`np.where(cdr["tipo"] == "DATOS", np.ceil(cdr["mb"]), 0)` elige el valor fila por fila. Después, `cdr["valor_datos"] = cdr["mb_facturables"] * 18`.
:::

```pyprueba
import numpy as np
import pandas as pd


def _esperado():
    datos = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    return np.where(datos["tipo"] == "DATOS", np.ceil(datos["mb"]), 0)


def prueba_columnas():
    """mb_facturables y valor_datos son correctas"""
    requiere("cdr")
    esperado = _esperado()
    igual([float(x) for x in cdr["mb_facturables"]], [float(x) for x in esperado], "mb_facturables")
    igual([float(x) for x in cdr["valor_datos"]], [float(x) * 18 for x in esperado], "valor_datos")


def prueba_total():
    """total_datos suma valor_datos"""
    requiere("total_datos")
    cerca(float(total_datos), float(_esperado().sum() * 18), 0.01)


def prueba_vectorizado():
    """Sin bucles ni apply"""
    assert "apply(" not in codigo and "for " not in codigo, "Resuélvelo con operaciones vectorizadas"
```

## Convertir tipos

```pyrun
import pandas as pd

datos = pd.DataFrame({"duracion": ["125", "61", "abc", ""], "monto": ["48719", "1.5", "x", "100"]})

print(pd.to_numeric(datos["duracion"], errors="coerce"))     # lo inválido queda como NaN
print(datos["monto"].astype("string").str.len())
print(pd.to_numeric(datos["monto"], errors="coerce").astype("Float64"))
```

| Conversión | Uso |
|---|---|
| `astype("int64")` | Cuando estás seguro de que todo es convertible |
| `pd.to_numeric(s, errors="coerce")` | Datos sucios: lo inválido queda faltante |
| `pd.to_datetime(s, format=..., errors="coerce")` | Fechas; lo inválido queda `NaT` |
| `astype("category")` | Texto con pocos valores distintos (tipo, destino, plan) |
| `astype("string")` | Texto |

:::reto Montos con punto de miles
Los montos llegaron como texto, con **punto de miles** (`"1.200"` son mil doscientos) y algunos dañados. Cuidado: `pd.to_numeric("1.200")` daría 1,2.

1. Crea `convertidos`: quita los puntos y convierte a número; lo que no se pueda convertir debe quedar faltante.
2. Crea `danados`: cuántos quedaron faltantes.
3. Crea `total`: la suma de los válidos.

```pyreto
import pandas as pd

montos = pd.Series(["35.900", "5.040", "1.200", "", "62.900", "N/A", "-2.000"])

# convertidos, danados y total

print(convertidos.tolist(), danados, total)
```

:::pista
`montos.str.replace(".", "", regex=False)` quita los puntos. Luego `pd.to_numeric(..., errors="coerce")` deja como `NaN` lo que no es número. Cuenta con `.isna().sum()`; `.sum()` ignora los `NaN`.
:::

```pyprueba
def prueba_conversion():
    """Los montos válidos quedan como números enteros"""
    requiere("convertidos")
    validos = [float(x) for x in convertidos if x == x]
    igual(validos, [35900.0, 5040.0, 1200.0, 62900.0, -2000.0])


def prueba_danados():
    """danados = 2"""
    requiere("danados")
    igual(int(danados), 2)


def prueba_total():
    """total = 103040"""
    requiere("total")
    igual(float(total), 103040.0)
```


## Fechas: to_datetime y .dt

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
print(cdr["inicio"].isna().sum(), "fechas inválidas (NaT)")

cdr["dia"] = cdr["inicio"].dt.date
cdr["hora"] = cdr["inicio"].dt.hour
cdr["dia_semana"] = cdr["inicio"].dt.day_name()
cdr["fin"] = cdr["inicio"] + pd.to_timedelta(cdr["duracion_seg"].clip(lower=0), unit="s")
print(cdr[["fecha_inicio", "hora", "dia_semana", "fin"]].head())
print(cdr["hora"].value_counts().sort_index().head(8))
```

:::consejo Siempre format= con fechas
Con `format=` Pandas no tiene que adivinar y es mucho más rápido. Con `errors="coerce"`, las fechas imposibles (31 de septiembre, hora 25) quedan como `NaT` en lugar de detener el proceso.
:::

:::reto La hora pico de la voz
Con el `cdr` de la muestra:

1. Crea la columna `inicio` con `fecha_inicio` convertida a fecha (con `format=` y `errors="coerce"`).
2. Crea `invalidas`: cuántas fechas quedaron como `NaT`.
3. Crea `hora_pico`: la hora del día (0 a 23) con **más llamadas de VOZ**.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# inicio, invalidas y hora_pico

print(invalidas, hora_pico)
```

:::pista
`pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")`. Para la hora pico, filtra la voz, toma `.dt.hour`, cuenta con `value_counts()` y pide `.idxmax()`.
:::

```pyprueba
import pandas as pd


def _esperado():
    datos = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    inicio = pd.to_datetime(datos["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    horas = inicio[datos["tipo"] == "VOZ"].dt.hour.value_counts()
    return int(inicio.isna().sum()), int(horas.idxmax())


def prueba_inicio():
    """La columna inicio es de fechas"""
    requiere("cdr")
    assert pd.api.types.is_datetime64_any_dtype(cdr["inicio"]), "inicio debe ser una columna de fechas"


def prueba_invalidas():
    """invalidas cuenta los NaT"""
    requiere("invalidas")
    igual(int(invalidas), _esperado()[0])


def prueba_hora_pico():
    """hora_pico es la hora con más llamadas de voz"""
    requiere("hora_pico")
    igual(int(hora_pico), _esperado()[1])
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
invalidas = cdr["inicio"].isna().sum()
hora_pico = cdr.loc[cdr["tipo"] == "VOZ", "inicio"].dt.hour.value_counts().idxmax()

print(invalidas, hora_pico)
```

## Textos: .str

```pyrun
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})

print(clientes["nombre"].str.upper().head(3))
print(clientes["nombre"].str.split().str[0].head(3))          # primer nombre
print(clientes["linea"].str[:3].value_counts().head())        # prefijo de la línea
print(clientes[clientes["nombre"].str.contains("S.A.S", regex=False)][["cliente_id", "nombre"]])
```

| Método | Hace |
|---|---|
| `.str.strip()`, `.str.upper()`, `.str.lower()`, `.str.title()` | Limpieza y mayúsculas |
| `.str.contains(texto)`, `.str.startswith(...)` | Buscar |
| `.str.replace(a, b)`, `.str.slice(i, j)` / `.str[i:j]` | Transformar |
| `.str.split(sep)`, `.str.len()`, `.str.zfill(n)` | Partir, medir, rellenar |
| `.str.extract(r"regex")` | Extraer con expresiones regulares |

:::reto Textos de los clientes
Con el `clientes` de la muestra:

- crea la columna `primer_nombre`, con la primera palabra de `nombre`;
- `empresas`: cuántos clientes tienen `S.A.S` en el nombre (búscalo como texto literal, sin expresiones regulares);
- `ciudades_mayus`: la lista de ciudades distintas en **mayúsculas**, ordenada.

```pyreto
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})

# primer_nombre, empresas y ciudades_mayus

print(clientes[["nombre", "primer_nombre"]].head(3))

```

:::pista
`clientes["nombre"].str.split().str[0]`; `clientes["nombre"].str.contains("S.A.S", regex=False).sum()`; y `sorted(clientes["ciudad"].str.upper().unique())`.
:::

```pyprueba
import pandas as pd


def _clientes():
    return pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})


def prueba_primer_nombre():
    """primer_nombre es la primera palabra"""
    requiere("clientes")
    igual([str(x) for x in clientes["primer_nombre"]], [n.split()[0] for n in _clientes()["nombre"]])


def prueba_empresas():
    """empresas cuenta los S.A.S"""
    requiere("empresas")
    igual(int(empresas), int(sum("S.A.S" in n for n in _clientes()["nombre"])))


def prueba_ciudades():
    """ciudades_mayus en mayúsculas y ordenadas"""
    requiere("ciudades_mayus")
    igual([str(c) for c in ciudades_mayus], sorted({c.upper() for c in _clientes()["ciudad"]}))
```

## ¿Y apply?

`apply` ejecuta una función de Python **fila por fila**. Funciona, pero es tan lento como un bucle:

:::comparar
:::mal Lento: una llamada de Python por fila
```python
cdr["minutos"] = cdr["duracion_seg"].apply(lambda s: (s + 59) // 60)
cdr["valor"] = cdr.apply(lambda f: f["minutos"] * tarifa[f["destino"]], axis=1)
```
:::
:::bien Rápido: operaciones vectorizadas
```python
cdr["minutos"] = (cdr["duracion_seg"] + 59) // 60
cdr["valor"] = cdr["minutos"] * cdr["destino"].map(tarifa)
```
:::
:::

`Series.map(diccionario)` reemplaza cada valor por su correspondiente en el diccionario: es la forma vectorizada de "buscar en una tabla".

:::reto Reemplaza los apply
Este código funciona, pero con `apply` fila por fila. Reescribe las dos columnas de forma vectorizada (con operaciones de columna y `map`), sin ningún `apply`. El resultado debe ser el mismo.

```pyreto
import pandas as pd

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].copy()

voz["minutos"] = voz["duracion_seg"].apply(lambda s: (s + 59) // 60)
voz["valor"] = voz.apply(lambda f: f["minutos"] * TARIFAS.get(f["destino"], 0), axis=1)

print(voz["valor"].sum())
```

:::pista
`voz["minutos"] = (voz["duracion_seg"] + 59) // 60`. Para la tarifa: `voz["destino"].map(TARIFAS).fillna(0)`, y multiplícala por los minutos.
:::

```pyprueba
import pandas as pd

TARIFAS_ = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def prueba_resultado():
    """minutos y valor dan lo mismo que antes"""
    requiere("voz")
    datos = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    esperado = datos[(datos["tipo"] == "VOZ") & (datos["duracion_seg"] >= 0)]
    minutos = [(s + 59) // 60 for s in esperado["duracion_seg"]]
    valores = [m * TARIFAS_.get(d, 0) for m, d in zip(minutos, esperado["destino"])]
    igual([int(x) for x in voz["minutos"]], minutos, "minutos")
    igual([float(x) for x in voz["valor"]], [float(x) for x in valores], "valor")


def prueba_sin_apply():
    """No usa apply"""
    assert "apply(" not in codigo, "Reemplaza los apply por operaciones vectorizadas y map"
    assert ".map(" in codigo, "Busca la tarifa de cada destino con .map(TARIFAS)"
```

```pysolucion
import pandas as pd

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].copy()

voz["minutos"] = (voz["duracion_seg"] + 59) // 60
voz["valor"] = voz["minutos"] * voz["destino"].map(TARIFAS).fillna(0)

print(voz["valor"].sum())
```
:::

:::telco Millones de filas, segundos
Con 14 millones de CDR (1 GB), un `apply` por filas tarda minutos; las operaciones vectorizadas, segundos. Reserva `apply` para lógica que de verdad no se puede vectorizar.

## Cuestionario

? ¿Qué hace `pd.to_datetime(s, format="%Y-%m-%d %H:%M:%S", errors="coerce")` con "2026-09-31 10:00:00"?
- [ ] Lanza un error
- [x] Lo convierte en `NaT`
- [ ] Lo convierte al 1 de octubre
- [ ] Lo deja como texto
> `errors="coerce"` convierte lo inválido en el valor faltante de fechas, `NaT`.

? ¿Cuál es la forma vectorizada de buscar la tarifa de cada destino en un diccionario?
- [ ] `cdr["destino"].apply(lambda d: tarifas[d])`
- [x] `cdr["destino"].map(tarifas)`
- [ ] Un `for` sobre las filas
- [ ] `cdr.loc[tarifas]`
> `map` con un diccionario reemplaza cada valor sin pasar por un bucle de Python.

? ¿Qué devuelve `cdr["inicio"].dt.hour`?
- [ ] La hora actual
- [x] Una Series con la hora de cada fecha
- [ ] La cantidad de horas
- [ ] Un error si hay NaT
> El accesor `.dt` aplica operaciones de fecha a toda la columna; los `NaT` dan `NaN`.
