## Enunciado

`ejercicios/m20-e7/facturas_tipadas.py` funciona "casi siempre". Tu misión: que **`mypy --strict` pase sin errores**, sin `Any` ni `# type: ignore`.

```powershell
python -m mypy --strict ejercicios/m20-e7/facturas_tipadas.py
```

Empieza ejecutando mypy sobre el archivo tal como está: verás que se queja de las funciones sin anotar. A medida que las anotes, aparecerán **errores reales** que estaban escondidos:

- un valor de tipo equivocado guardado en `Plan`;
- un `None` que se usa como si fuera un plan;
- un promedio que puede no existir.

Corrígelos de forma que el comportamiento sea el que describe el docstring del archivo (las pruebas lo verifican).

## Pista 1

Las firmas que necesitas:

```python
def leer_planes(ruta: Path | str) -> dict[str, Plan]: ...
def buscar(planes: dict[str, Plan], plan_id: str) -> Plan | None: ...
def total_por_plan(consumos: list[tuple[str, int]]) -> dict[str, int]: ...
def promedio(valores: list[int]) -> float | None: ...
```

Dentro de `total_por_plan`, mypy necesita saber el tipo del diccionario vacío: `totales: dict[str, int] = {}`.

## Pista 2

Los dos `None`:

```python
plan = buscar(planes, plan_id)
if plan is None:
    raise PlanNoEncontrado(plan_id)
# aquí mypy ya sabe que plan es Plan

prom = promedio(...)
lineas.append("Promedio: " + ("-" if prom is None else formatear(round(prom))))
```

## Solución

```python facturas_tipadas.py
"""Ejercicio m20-e7: que `mypy --strict` pase sin errores (y que el código haga lo que dice).

    python -m mypy --strict ejercicios/m20-e7/facturas_tipadas.py

Reglas:
  - Anota TODAS las funciones (parámetros y retorno), con tipos precisos (nada de Any ni comentarios para silenciar a mypy).
  - mypy va a encontrar errores reales: corrígelos. En particular:
      * valor_voz debe lanzar PlanNoEncontrado si el plan no existe.
      * reporte con una lista de consumos vacía termina en "Promedio: -".
"""

import csv
from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True)
class Plan:
    plan_id: str
    cargo_fijo: int
    minutos_incluidos: int
    tarifa_minuto: int


class PlanNoEncontrado(LookupError):
    pass


def leer_planes(ruta: Path | str) -> dict[str, Plan]:
    with open(ruta, encoding="utf-8", newline="") as f:
        return {
            p["plan_id"]: Plan(p["plan_id"], int(p["cargo_fijo"]), int(p["minutos_incluidos"]), int(p["tarifa_minuto"]))
            for p in csv.DictReader(f)
        }


def buscar(planes: dict[str, Plan], plan_id: str) -> Plan | None:
    return planes.get(plan_id)


def valor_voz(planes: dict[str, Plan], plan_id: str, minutos: int) -> int:
    plan = buscar(planes, plan_id)
    if plan is None:
        raise PlanNoEncontrado(plan_id)
    if plan.minutos_incluidos == -1:
        return 0
    return max(0, minutos - plan.minutos_incluidos) * plan.tarifa_minuto


def total_por_plan(consumos: list[tuple[str, int]]) -> dict[str, int]:
    totales: dict[str, int] = {}
    for plan_id, valor in consumos:
        totales[plan_id] = totales.get(plan_id, 0) + valor
    return totales


def formatear(valor: int) -> str:
    return "$" + f"{valor:,}".replace(",", ".")


def promedio(valores: list[int]) -> float | None:
    if not valores:
        return None
    return sum(valores) / len(valores)


def reporte(planes: dict[str, Plan], consumos: list[tuple[str, int]]) -> str:
    lineas: list[str] = []
    for plan_id, total in sorted(total_por_plan(consumos).items()):
        lineas.append(f"{plan_id}: {formatear(total)} (cargo {formatear(planes[plan_id].cargo_fijo)})")
    prom = promedio([v for _, v in consumos])
    lineas.append("Promedio: " + ("-" if prom is None else formatear(round(prom))))
    return "\n".join(lineas)
```

## Explicación

Los tres errores que mypy destapó son de los que llegan a producción:

1. **`cargo_fijo` como texto**: `Plan(..., p["cargo_fijo"], ...)` guardaba `"35900"`. Python no se queja al crear el `dataclass` (las anotaciones no se verifican en ejecución), y el error aparece lejos: `formatear("35900")` falla con un mensaje confuso, o peor, una comparación `"9900" > "35900"` da `True` en silencio.
2. **El plan inexistente**: `buscar` devuelve `Plan | None`; usar `.minutos_incluidos` sin revisar daba `AttributeError: 'NoneType' object has no attribute...`. Ahora es un `PlanNoEncontrado` con el código del plan.
3. **El promedio de nada**: `round(None)` explotaba con la lista vacía, el caso típico de "el día que no llegaron datos".

Fíjate en que mypy **no** encontró estos errores mientras las funciones no tenían anotaciones: sin tipos, mypy asume `Any` y no revisa nada. Por eso `--strict` exige anotar todo: el valor de mypy aparece cuando la información de tipos fluye de una función a otra.
