## Enunciado

Heredaste este código de un compañero. Funciona, pero nadie lo quiere tocar porque cuesta entenderlo. Reescríbelo siguiendo **PEP 8** sin cambiar lo que calcula.

Requisitos:

- Una constante `IVA = 0.19` (en mayúsculas, al inicio).
- La función `calcular_subtotal(cargo_fijo, consumo_adicional, descuento)`.
- La función `calcular_total(cargo_fijo, consumo_adicional, descuento)`, que usa `calcular_subtotal` y la constante `IVA`.
- Nombres en *snake_case* y sin parámetros de una sola letra.
- Sangría de 4 espacios y dos líneas en blanco antes de cada función.

```python
calcular_total(35900, 5040, 0)   # 48718.6
```

## Código inicial

```python
def CalcSub(CF,c,d):
  return CF+c-d
def CalcTotal(CF,c,d):
  S=CalcSub(CF,c,d)
  return S+S*0.19
print(CalcTotal(35900,5040,0))
```

## Pruebas

```python
import ast

arbol = ast.parse(codigo)
funciones = {n.name: n for n in ast.walk(arbol) if isinstance(n, ast.FunctionDef)}


def prueba_resultado():
    """calcular_total(35900, 5040, 0) devuelve 48718.6"""
    requiere("calcular_subtotal", "calcular_total")
    cerca(calcular_total(35900, 5040, 0), 48718.6, 0.001)
    cerca(calcular_total(149900, 0, 14990), 160542.9, 0.001)


def prueba_subtotal():
    """calcular_subtotal resta el descuento"""
    igual(calcular_subtotal(149900, 2000, 14990), 136910)


def prueba_constante_iva():
    """Existe la constante IVA = 0.19 y se usa en vez de escribir 0.19"""
    requiere("IVA")
    igual(IVA, 0.19)
    numeros = [n.value for n in ast.walk(funciones.get("calcular_total", arbol)) if isinstance(n, ast.Constant)]
    assert 0.19 not in numeros, "calcular_total no debe tener 0.19 escrito: usa la constante IVA"


def prueba_nombres_snake_case():
    """Funciones y parámetros en snake_case, sin nombres de una letra"""
    for nombre, nodo in funciones.items():
        assert nombre == nombre.lower(), f"La función `{nombre}` debe ir en minúsculas (snake_case)"
        for argumento in nodo.args.args:
            assert argumento.arg == argumento.arg.lower(), f"El parámetro `{argumento.arg}` debe ir en minúsculas"
            assert len(argumento.arg) > 1, f"El parámetro `{argumento.arg}` es muy corto: usa un nombre descriptivo"
    assert "CalcSub" not in funciones and "CalcTotal" not in funciones, "Cambia los nombres CalcSub y CalcTotal"


def prueba_sangria_de_cuatro_espacios():
    """La sangría usa 4 espacios (sin tabuladores)"""
    for numero, linea in enumerate(codigo.splitlines(), 1):
        assert "\t" not in linea, f"La línea {numero} tiene un tabulador"
        espacios = len(linea) - len(linea.lstrip(" "))
        if linea.strip():
            assert espacios % 4 == 0, f"La línea {numero} tiene {espacios} espacios de sangría (debe ser múltiplo de 4)"


def prueba_dos_lineas_antes_de_funciones():
    """Hay dos líneas en blanco antes de cada función"""
    lineas = codigo.splitlines()
    for numero, linea in enumerate(lineas):
        hay_codigo_antes = any(l.strip() for l in lineas[:numero])
        if linea.startswith("def ") and hay_codigo_antes:
            anteriores = lineas[max(0, numero - 2):numero]
            assert anteriores == ["", ""], f"Antes de la función de la línea {numero + 1} deben ir dos líneas en blanco"
```

## Pista 1

Empieza por los nombres. Una forma de traducirlos:

| Antes | Después |
|---|---|
| `CalcSub` | `calcular_subtotal` |
| `CalcTotal` | `calcular_total` |
| `CF` | `cargo_fijo` |
| `c` | `consumo_adicional` |
| `d` | `descuento` |
| `S` | `subtotal` |

## Pista 2

La estructura que buscan las pruebas:

```python
IVA = 0.19


def calcular_subtotal(cargo_fijo, consumo_adicional, descuento):
    return ...


def calcular_total(cargo_fijo, consumo_adicional, descuento):
    subtotal = calcular_subtotal(...)
    return subtotal + subtotal * IVA


print(calcular_total(35900, 5040, 0))
```

## Solución

```python
IVA = 0.19


def calcular_subtotal(cargo_fijo, consumo_adicional, descuento):
    return cargo_fijo + consumo_adicional - descuento


def calcular_total(cargo_fijo, consumo_adicional, descuento):
    subtotal = calcular_subtotal(cargo_fijo, consumo_adicional, descuento)
    return subtotal + subtotal * IVA


print(calcular_total(35900, 5040, 0))
```

## Explicación

El código hace exactamente lo mismo que antes, pero ahora:

- **Los nombres explican el negocio.** `cargo_fijo + consumo_adicional - descuento` se lee como la regla de facturación; `CF+c-d` obliga a adivinar.
- **La constante `IVA` vive en un solo lugar.** Si el IVA cambia, editas una línea. Escribir `0.19` repartido por el código se llama *número mágico* y es fuente de errores.
- **El formato es el estándar.** Cualquier programador de Python lo lee sin esfuerzo.

¿Notaste que el total da `48718.6` y no un número entero? Los pesos no tienen centavos en la factura: en el módulo 2 verás cómo redondear dinero correctamente con `Decimal`.
