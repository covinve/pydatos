Un **generador** es la forma más fácil de crear un iterador: una función que, en lugar de `return`, usa **`yield`**.

```pyrun
def minutos_facturables(duraciones):
    for segundos in duraciones:
        print(f"  (calculando {segundos} s)")
        yield (segundos + 59) // 60


gen = minutos_facturables([125, 0, 61])
print(gen)            # un objeto generador: todavía no se ejecutó nada
print(next(gen))
print(next(gen))
print(list(gen))      # lo que queda
```

Cada `yield` **entrega** un valor y **pausa** la función justo ahí, con todas sus variables intactas. El siguiente `next()` la reanuda en la línea siguiente.

Escribe el generador `megas_facturables(sesiones)`: para cada sesión con megas **mayores que cero**, entrega las megas redondeadas hacia arriba. Usa `yield`, no construyas una lista.

```pyreto
import math


def megas_facturables(sesiones):
    pass


print(list(megas_facturables([15.131, 0, 230.5, 0.2])))   # [16, 231, 1]
```

:::pista
`for mb in sesiones:` y, si `mb > 0`, `yield math.ceil(mb)`.
:::

```pyprueba
import inspect


def prueba_generador():
    """Es una función generadora"""
    requiere("megas_facturables")
    assert inspect.isgeneratorfunction(megas_facturables), "Usa yield dentro de la función"


def prueba_valores():
    """Entrega las megas facturables, sin las sesiones en cero"""
    igual(list(megas_facturables([15.131, 0, 230.5, 0.2])), [16, 231, 1])
    igual(list(megas_facturables([])), [])


def prueba_perezoso():
    """Entrega de a uno"""
    gen = megas_facturables([1.5, 2.5])
    igual(next(gen), 2)
```

```pysolucion
import math


def megas_facturables(sesiones):
    for mb in sesiones:
        if mb > 0:
            yield math.ceil(mb)


print(list(megas_facturables([15.131, 0, 230.5, 0.2])))   # [16, 231, 1]
```

def contar_hasta(n):

for numero in contar_hasta(3):

## return vs yield

:::comparar
:::mal Construye toda la lista en memoria
```python
def leer_validos(ruta):
    validos = []
    with open(ruta, encoding="utf-8") as f:
        for linea in f:
            if es_valido(linea):
                validos.append(linea)
    return validos      # 20 GB en una lista
```
:::
:::bien Entrega uno a la vez
```python
def leer_validos(ruta):
    with open(ruta, encoding="utf-8") as f:
        for linea in f:
            if es_valido(linea):
                yield linea   # memoria constante
```
:::
:::

Ambas se usan igual (`for linea in leer_validos(ruta):`), pero la segunda funciona con archivos de cualquier tamaño.

## Expresiones generadoras

Como las comprensiones de lista, pero con **paréntesis**: no construyen la lista, producen un generador.

```pyrun
import sys

duraciones = range(1_000_000)

como_lista = [(d + 59) // 60 for d in duraciones]
como_generador = ((d + 59) // 60 for d in duraciones)

print(f"Lista: {sys.getsizeof(como_lista):,} bytes")
print(f"Generador: {sys.getsizeof(como_generador):,} bytes")
print(sum((d + 59) // 60 for d in duraciones))   # dentro de una función, sin paréntesis extra
```

Si solo vas a **recorrer una vez** (para sumar, contar, buscar el máximo), usa un generador. Si necesitas recorrer varias veces, indexar o saber la longitud, usa una lista.

:::reto Sumas sin listas
Con **expresiones generadoras** (sin corchetes), calcula sobre `duraciones`:

- `total_minutos`: la suma de los minutos facturables;
- `largas`: cuántas llamadas duran más de 10 minutos (600 segundos).

```pyreto
duraciones = [125, 0, 61, 3600, 45, 900, 601, 600]

# total_minutos y largas con expresiones generadoras

print(total_minutos, largas)
```

:::pista
`sum((d + 59) // 60 for d in duraciones)`. Para contar, suma un 1 por cada una que cumpla: `sum(1 for d in duraciones if d > 600)`.
:::

```pyprueba
import ast


def prueba_valores():
    """total_minutos = 102 y largas = 3"""
    requiere("total_minutos", "largas")
    igual(total_minutos, 102, "total_minutos")
    igual(largas, 3, "largas")


def prueba_generadoras():
    """Usa expresiones generadoras, no listas"""
    arbol = ast.parse(codigo)
    assert any(isinstance(n, ast.GeneratorExp) for n in ast.walk(arbol)), "Usa una expresión generadora: sum(... for ... in ...)"
    assert not any(isinstance(n, ast.ListComp) for n in ast.walk(arbol)), "No construyas listas con [...]"
```

```pysolucion
duraciones = [125, 0, 61, 3600, 45, 900, 601, 600]

total_minutos = sum((d + 59) // 60 for d in duraciones)
largas = sum(1 for d in duraciones if d > 600)

print(total_minutos, largas)
```
:::

## yield from: delegar en otro iterable

```pyrun
def todos_los_cdr(archivos):
    for registros in archivos:
        yield from registros       # entrega cada elemento de registros


archivo_1 = ["1|VOZ", "2|SMS"]
archivo_2 = ["3|DATOS"]
print(list(todos_los_cdr([archivo_1, archivo_2])))
```

:::reto Encabezado y datos de varios archivos
Escribe el generador `con_encabezado(encabezado, *bloques)`: primero entrega el `encabezado` y después, con `yield from`, todas las líneas de cada bloque, en orden.

```pyreto
def con_encabezado(encabezado, *bloques):
    pass


lunes = ["1|VOZ", "2|SMS"]
martes = ["3|DATOS"]
print(list(con_encabezado("cdr_id|tipo", lunes, martes)))
# ['cdr_id|tipo', '1|VOZ', '2|SMS', '3|DATOS']
```

:::pista
`yield encabezado` y luego `for bloque in bloques: yield from bloque`.
:::

```pyprueba
def prueba_valores():
    """Entrega el encabezado y luego cada bloque"""
    requiere("con_encabezado")
    igual(list(con_encabezado("cdr_id|tipo", ["1|VOZ", "2|SMS"], ["3|DATOS"])), ["cdr_id|tipo", "1|VOZ", "2|SMS", "3|DATOS"])
    igual(list(con_encabezado("h")), ["h"], "sin bloques")


def prueba_yield_from():
    """Usa yield from"""
    assert "yield from" in codigo, "Delega en cada bloque con yield from"
```

```pysolucion
def con_encabezado(encabezado, *bloques):
    yield encabezado
    for bloque in bloques:
        yield from bloque


lunes = ["1|VOZ", "2|SMS"]
martes = ["3|DATOS"]
print(list(con_encabezado("cdr_id|tipo", lunes, martes)))
# ['cdr_id|tipo', '1|VOZ', '2|SMS', '3|DATOS']
```

## Generadores y with

Un generador puede tener un `with` adentro: el archivo se mantiene abierto mientras el generador se recorre, y se cierra cuando termina.

```python
def lineas_de_datos(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)               # salta el encabezado
        for linea in archivo:
            yield linea.rstrip("\n")
```

:::reto Un lector perezoso del archivo
Escribe el generador `tipos_de(ruta)`, que abre el `cdr.csv` de la muestra (UTF-8, separado por `|`, con el tipo en la cuarta columna), salta el encabezado y entrega **el tipo** de cada registro.

Luego usa `Counter` sobre el generador para crear `por_tipo`.

```pyreto
from collections import Counter


def tipos_de(ruta):
    pass


por_tipo = Counter(tipos_de("cdr.csv"))
print(por_tipo.most_common(3))
```

:::pista
Como `lineas_de_datos`: `with open(ruta, encoding="utf-8") as archivo:`, `next(archivo)` y dentro del `for`, `yield linea.split("|")[3]`.
:::

```pyprueba
import inspect
from collections import Counter


def prueba_generador():
    """tipos_de es una función generadora"""
    requiere("tipos_de")
    assert inspect.isgeneratorfunction(tipos_de), "Usa yield dentro de tipos_de"


def prueba_conteo():
    """por_tipo cuenta los tipos de la muestra"""
    requiere("por_tipo")
    esperado = Counter()
    with open("cdr.csv", encoding="utf-8") as f:
        next(f)
        for linea in f:
            esperado[linea.split("|")[3]] += 1
    igual(dict(por_tipo), dict(esperado))
```

```pysolucion
from collections import Counter


def tipos_de(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield linea.split("|")[3]


por_tipo = Counter(tipos_de("cdr.csv"))
print(por_tipo.most_common(3))
```
:::

:::capo Generadores infinitos
Un generador no necesita terminar: `while True: yield ...` es válido, porque solo calcula lo que se le pide. `itertools.count()` es uno de ellos. Combínalos con algo que los corte, como `islice` (lección 3) o un `break`.
:::

## Cuestionario

? ¿Qué devuelve llamar a una función que contiene `yield`?
- [ ] El primer valor
- [ ] Una lista con todos los valores
- [x] Un objeto generador, sin ejecutar todavía el cuerpo de la función
- [ ] `None`
> El cuerpo se ejecuta poco a poco, a medida que se piden valores con `next` o un `for`.

? ¿Cuál usa menos memoria para sumar un millón de valores?
- [ ] `sum([x * 2 for x in datos])`
- [x] `sum(x * 2 for x in datos)`
- [ ] `sum(list(x * 2 for x in datos))`
- [ ] Todas usan lo mismo
> La expresión generadora entrega los valores de a uno; las otras construyen la lista completa primero.

? ¿Qué hace `yield from registros`?
- [ ] Devuelve la lista completa de una vez
- [x] Entrega uno por uno los elementos de `registros`
- [ ] Termina el generador
- [ ] Copia `registros`
> Es un atajo para `for r in registros: yield r`.
