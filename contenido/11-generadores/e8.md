## Enunciado

Cada central de conmutación envía su propio archivo de CDR **ordenado por fecha**. Necesitas un único flujo cronológico de todas las centrales, sin cargar los archivos en memoria (cada uno puede pesar varios GB).

Escribe:

1. `leer_central(ruta)` → generador de tuplas `(fecha_inicio, central, cdr_id)` donde `central` es el nombre del archivo sin extensión (`Path(ruta).stem`). Los archivos tienen formato `cdr_id|fecha_inicio` con encabezado.
2. `unir(*rutas)` → generador que entrega los registros de todas las centrales **en orden de fecha** usando `heapq.merge`. Ante la misma fecha, en orden de central.
3. `verificar_orden(registros)` → generador que deja pasar los registros tal cual, pero lanza `ValueError("Registro fuera de orden en central_b: 2026-09-01 08:00:00 después de 2026-09-01 09:00:00")` si encuentra uno con fecha anterior al anterior de **esa misma central**.

```python
for fecha, central, cdr_id in unir("central_a.csv", "central_b.csv"):
    ...
```

## Pista 1

`heapq.merge(*iterables)` une iteradores **ya ordenados** en un único iterador ordenado, leyendo de a un elemento de cada uno. Como las tuplas se comparan elemento por elemento, `(fecha, central, cdr_id)` queda ordenado por fecha y luego por central sin hacer nada más:

```python
def unir(*rutas):
    yield from heapq.merge(*(leer_central(r) for r in rutas))
```

Las fechas en formato ISO (`AAAA-MM-DD HH:MM:SS`) se ordenan bien como texto.

## Pista 2

En `verificar_orden`, guarda la última fecha vista **por central** en un diccionario (tiene tantas entradas como centrales, no como registros):

```python
ultima = {}
for registro in registros:
    fecha, central, _ = registro
    if central in ultima and fecha < ultima[central]:
        raise ValueError(...)
    ultima[central] = fecha
    yield registro
```

## Solución

```python
import heapq
from pathlib import Path


def leer_central(ruta):
    central = Path(ruta).stem
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            cdr_id, fecha = linea.rstrip("\n").split("|")
            yield fecha, central, int(cdr_id)


def unir(*rutas):
    yield from heapq.merge(*(leer_central(ruta) for ruta in rutas))


def verificar_orden(registros):
    ultima = {}
    for registro in registros:
        fecha, central, _ = registro
        if central in ultima and fecha < ultima[central]:
            raise ValueError(f"Registro fuera de orden en {central}: {fecha} después de {ultima[central]}")
        ultima[central] = fecha
        yield registro


for registro in unir("central_a.csv", "central_b.csv"):
    print(registro)
```

## Explicación

`heapq.merge` es la versión perezosa de "unir y ordenar": como cada entrada ya está ordenada, solo necesita mirar **el siguiente elemento de cada archivo** y entregar el menor. Con 10 centrales, en memoria hay 10 registros, sin importar el tamaño de los archivos. Es el mismo algoritmo que usan las bases de datos para ordenar datos que no caben en memoria (*merge sort externo*).

`verificar_orden` es otro ejemplo de **verificar supuestos**: `heapq.merge` asume entradas ordenadas y, si no lo están, produce un resultado mal ordenado **sin avisar**. Envolver el flujo con una etapa que verifica convierte un error silencioso en uno ruidoso.

Fíjate que se puede verificar cada central **antes** de unir (`verificar_orden(leer_central(...))`) o el flujo ya unido: la función sirve para ambos porque recuerda la última fecha por central.
