## Enunciado

El módulo `estadisticas.py` tiene funciones sobre una lista de consumos (diccionarios con `linea`, `minutos` y `mb`):

- `promedio_mb(consumos)` → promedio de megas (`0.0` si la lista está vacía);
- `lineas_sobre(consumos, minimo_minutos)` → lista ordenada de líneas con **más** de `minimo_minutos`;
- `participacion(consumos, linea)` → porcentaje de los minutos totales que corresponde a esa línea (`ValueError` si la línea no existe).

Escribe tus pruebas usando:

- una **fixture** `consumos` que devuelva una lista de ejemplo (y que tus pruebas reciban como parámetro);
- `pytest.approx` para comparar los resultados con decimales;
- `pytest.raises` para la línea inexistente.

Deben pasar con la versión correcta y atrapar los cuatro mutantes.

## Pruebas

```python
import ast

import pytest

CORRECTA = (
    "def promedio_mb(consumos):\n"
    "    if not consumos:\n        return 0.0\n"
    "    return sum(c['mb'] for c in consumos) / len(consumos)\n\n"
    "def lineas_sobre(consumos, minimo_minutos):\n"
    "    return sorted(c['linea'] for c in consumos if c['minutos'] > minimo_minutos)\n\n"
    "def participacion(consumos, linea):\n"
    "    total = sum(c['minutos'] for c in consumos)\n"
    "    for c in consumos:\n"
    "        if c['linea'] == linea:\n"
    "            return c['minutos'] / total * 100\n"
    "    raise ValueError(f'Línea desconocida: {linea}')\n"
)


def correr(implementacion):
    return correr_pytest(codigo, {"estadisticas": implementacion})


def prueba_usa_fixture_y_approx():
    """Usa una fixture y pytest.approx"""
    texto = codigo
    assert "@pytest.fixture" in texto, "Define la fixture con @pytest.fixture"
    assert "approx" in texto, "Compara los decimales con pytest.approx"
    pruebas = [n for n in ast.walk(ast.parse(texto)) if isinstance(n, ast.FunctionDef) and n.name.startswith("test_")]
    assert any("consumos" in [a.arg for a in p.args.args] for p in pruebas), "Tus pruebas deben recibir la fixture `consumos`"


def prueba_pasan_con_el_codigo_correcto():
    """Tus pruebas pasan con la implementación correcta"""
    salida, texto = correr(CORRECTA)
    assert salida == 0, "Alguna prueba falla con el código CORRECTO:\n" + texto[-900:]


def prueba_atrapa_lista_vacia():
    """Atrapan el mutante que falla con la lista vacía"""
    salida, _ = correr(CORRECTA.replace("    if not consumos:\n        return 0.0\n", ""))
    assert salida == 1, "Ninguna prueba usó una lista vacía"


def prueba_atrapa_mayor_o_igual():
    """Atrapan el mutante que usa >= en lugar de >"""
    salida, _ = correr(CORRECTA.replace("c['minutos'] > minimo_minutos", "c['minutos'] >= minimo_minutos"))
    assert salida == 1, "Ninguna prueba usó un consumo exactamente igual al mínimo"


def prueba_atrapa_orden():
    """Atrapan el mutante que no ordena las líneas"""
    salida, _ = correr(CORRECTA.replace("return sorted(c['linea']", "return list(c['linea']"))
    assert salida == 1, "Ninguna prueba verificó el orden (pon las líneas desordenadas en la fixture)"


def prueba_atrapa_sin_error():
    """Atrapan el mutante que devuelve 0 para una línea inexistente"""
    salida, _ = correr(CORRECTA.replace("raise ValueError(f'Línea desconocida: {linea}')", "return 0.0"))
    assert salida == 1, "Ninguna prueba verificó el ValueError de la línea inexistente"
```

## Pista 1

Diseña la fixture para que sirva a todas las pruebas: líneas **desordenadas** (para probar el orden), una línea con exactamente el mínimo que vas a usar (para probar `>` contra `>=`), y megas con decimales.

Para la lista vacía no necesitas la fixture: `assert promedio_mb([]) == 0.0`.

## Solución

```python
import pytest

from estadisticas import lineas_sobre, participacion, promedio_mb


@pytest.fixture
def consumos():
    return [
        {"linea": "3003", "minutos": 100, "mb": 512.0},
        {"linea": "3002", "minutos": 200, "mb": 256.25},
        {"linea": "3001", "minutos": 300, "mb": 1024.5},
    ]


def test_promedio(consumos):
    assert promedio_mb(consumos) == pytest.approx(597.5833, rel=1e-4)


def test_promedio_lista_vacia():
    assert promedio_mb([]) == 0.0


def test_lineas_sobre_excluye_el_limite_y_ordena(consumos):
    assert lineas_sobre(consumos, 100) == ["3001", "3002"]


def test_participacion(consumos):
    assert participacion(consumos, "3001") == pytest.approx(50.0)


def test_participacion_linea_inexistente(consumos):
    with pytest.raises(ValueError, match="3999"):
        participacion(consumos, "3999")
```

## Explicación

La fixture concentra los datos de ejemplo en un solo lugar, y cada prueba la recibe **nueva**. Lo más importante es cómo se **diseñaron** esos datos:

- Líneas en desorden → atrapa la falta de `sorted`.
- Un consumo con exactamente 100 minutos → atrapa el `>=`.
- Decimales en las megas → obliga a usar `pytest.approx`.

Unos datos de prueba bien pensados valen más que muchos datos al azar.
