## Enunciado

Cada aliado de roaming deja sus CDR en una carpeta compartida. Los archivos se llaman `cdr_*.csv`, están separados por `|` y tienen estas columnas:

```text
cdr_id|linea_origen|tipo|duracion_seg|operador
```

El problema: **cada aliado usa una codificación distinta** (UTF-8, UTF-8 con BOM o latin-1), y en la carpeta también hay otros archivos que no son CDR.

Completa `ejercicios/m06-e5/consolidar.py`:

1. `detectar_encoding(ruta)` → `"utf-8-sig"` si el archivo empieza con el BOM (`b"\xef\xbb\xbf"`), `"utf-8"` si **todo** el archivo es UTF-8 válido, y `"latin-1"` en otro caso. **Lee el archivo por bloques**: no lo cargues completo.
2. `resumir_archivo(ruta)` → diccionario con `"archivo"` (solo el nombre), `"registros"`, `"minutos_voz"` (minutos facturables de los `VOZ` con duración ≥ 0), `"encoding"` y `"operadores"` (lista ordenada de operadores distintos).
3. `consolidar(carpeta, salida)` → resume cada `cdr_*.csv` de la carpeta **en orden de nombre**, escribe un reporte CSV en `salida` y devuelve `{"archivos": [resúmenes], "total_registros": ..., "total_minutos_voz": ...}`.

El reporte es UTF-8, separado por `;`, con una fila por archivo y una fila final de totales:

```text
archivo;registros;minutos_voz;encoding
cdr_01.csv;3;5;utf-8
cdr_02.csv;2;1;latin-1
...
TOTAL;7;66;
```

Comprueba con `python comprobar.py m06-e5`.

## Pista 1

Para detectar la codificación sin cargar todo, lee bloques de bytes y decodifícalos con un **decodificador incremental**, que recuerda los caracteres que quedan partidos entre un bloque y el siguiente:

```python
import codecs

decodificador = codecs.getincrementaldecoder("utf-8")()
with open(ruta, "rb") as archivo:
    inicio = archivo.read(3)
    if inicio == codecs.BOM_UTF8:
        return "utf-8-sig"
    archivo.seek(0)
    try:
        while bloque := archivo.read(1_000_000):
            decodificador.decode(bloque)
        decodificador.decode(b"", final=True)
    except UnicodeDecodeError:
        return "latin-1"
return "utf-8"
```

`while bloque := archivo.read(...)` usa el operador "morsa" (`:=`): asigna y comprueba en la misma línea.

## Pista 2

Con el encoding detectado, `resumir_archivo` abre el archivo con `csv.DictReader(..., delimiter="|")`. Con `utf-8-sig`, el BOM desaparece solo y la primera columna se llama `cdr_id` correctamente.

Para recorrer la carpeta en orden: `sorted(carpeta.glob("cdr_*.csv"))`. Escribe el reporte con `csv.writer(archivo, delimiter=";")`.

## Solución

```python consolidar.py
"""Ejercicio m06-e5: consolidar los archivos de roaming de una carpeta.

Uso:
    python ejercicios/m06-e5/consolidar.py CARPETA_ENTRADA ARCHIVO_SALIDA
"""

import codecs
import csv
import sys
from pathlib import Path

PATRON = "cdr_*.csv"
TAMANO_BLOQUE = 1_000_000


def detectar_encoding(ruta: Path) -> str:
    with open(ruta, "rb") as archivo:
        if archivo.read(3) == codecs.BOM_UTF8:
            return "utf-8-sig"
        archivo.seek(0)
        decodificador = codecs.getincrementaldecoder("utf-8")()
        try:
            while bloque := archivo.read(TAMANO_BLOQUE):
                decodificador.decode(bloque)
            decodificador.decode(b"", final=True)
        except UnicodeDecodeError:
            return "latin-1"
    return "utf-8"


def resumir_archivo(ruta: Path) -> dict:
    encoding = detectar_encoding(ruta)
    registros = 0
    minutos_voz = 0
    operadores = set()
    with open(ruta, encoding=encoding, newline="") as archivo:
        for fila in csv.DictReader(archivo, delimiter="|"):
            registros += 1
            operadores.add(fila["operador"])
            duracion = int(fila["duracion_seg"])
            if fila["tipo"] == "VOZ" and duracion >= 0:
                minutos_voz += (duracion + 59) // 60
    return {
        "archivo": ruta.name,
        "registros": registros,
        "minutos_voz": minutos_voz,
        "encoding": encoding,
        "operadores": sorted(operadores),
    }


def consolidar(carpeta: Path, salida: Path) -> dict:
    resumenes = [resumir_archivo(ruta) for ruta in sorted(carpeta.glob(PATRON))]
    total_registros = sum(r["registros"] for r in resumenes)
    total_minutos = sum(r["minutos_voz"] for r in resumenes)
    with open(salida, "w", encoding="utf-8", newline="") as archivo:
        escritor = csv.writer(archivo, delimiter=";")
        escritor.writerow(["archivo", "registros", "minutos_voz", "encoding"])
        for r in resumenes:
            escritor.writerow([r["archivo"], r["registros"], r["minutos_voz"], r["encoding"]])
        escritor.writerow(["TOTAL", total_registros, total_minutos, ""])
    return {"archivos": resumenes, "total_registros": total_registros, "total_minutos_voz": total_minutos}


if __name__ == "__main__":
    resultado = consolidar(Path(sys.argv[1]), Path(sys.argv[2]))
    for detalle in resultado["archivos"]:
        print(detalle)
    print("Total registros:", resultado["total_registros"])
```

## Explicación

Este ejercicio junta todo el módulo: pathlib para encontrar archivos, codificaciones, CSV y escritura de reportes.

Lo más interesante es `detectar_encoding`:

- **Lee por bloques de 1 MB.** Funciona igual con un archivo de 10 KB que con uno de 10 GB.
- **El decodificador incremental** guarda los bytes "a medias": un carácter UTF-8 de dos bytes puede quedar partido entre un bloque y el siguiente, y un `bloque.decode("utf-8")` normal daría un falso error.
- **`final=True`** al terminar detecta un carácter incompleto al final del archivo (justo lo que comprueba `test_detecta_error_al_final`).

¿Por qué no basta con revisar el primer megabyte? Porque en los archivos reales el primer nombre con tilde puede aparecer en la fila un millón. Esa es la causa clásica del proceso que "funcionó todo el mes y hoy falló".

Este tipo de script es el que se programa para correr cada madrugada sobre la carpeta compartida. En el módulo 18 lo convertirás en un comando de terminal con opciones y registro de ejecución.
