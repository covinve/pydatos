Cada campo de un CDR tiene un **tipo**: el `cdr_id` es un número entero, la `linea_origen` es texto, las `mb` llevan decimales. Elegir bien el tipo evita errores que, en facturación, se convierten en dinero mal cobrado.

## Las variables son etiquetas

En Python una variable **no es una caja** que guarda un valor: es una **etiqueta** pegada a un valor. Cuando reasignas, mueves la etiqueta a otro valor.

```pytrace
minutos = 120
total = minutos
minutos = minutos + 30
print(minutos, total)
```

Fíjate en el visualizador: `total` sigue valiendo 120 aunque `minutos` cambió. `total = minutos` pegó la etiqueta `total` al valor 120, no a la variable `minutos`.

## Los cinco tipos básicos

| Tipo | Qué guarda | Ejemplo telco |
|---|---|---|
| `int` | Números enteros, sin límite de tamaño | `cdr_id = 1048576`, `duracion_seg = 125` |
| `float` | Números con decimales (aproximados) | `mb = 15.131` |
| `str` | Texto | `tipo = "VOZ"`, `linea = "3001234567"` |
| `bool` | Verdadero o falso | `es_valido = True` |
| `NoneType` | La ausencia de valor | `fecha_baja = None` |

La función `type()` te dice el tipo de cualquier valor:

```pyrun
cdr_id = 1048576
mb = 15.131
tipo = "DATOS"
es_valido = True
fecha_baja = None

print(type(cdr_id))
print(type(mb))
print(type(tipo))
print(type(es_valido))
print(type(fecha_baja))
```

:::capo Tipado dinámico
Python decide el tipo **por el valor**, no por la variable. La misma variable puede apuntar a un `int` y luego a un `str`. Es cómodo, pero también peligroso: nada te impide mezclar cosas por error. Por eso desde el módulo 5 usaremos *type hints* (`def f(x: int) -> str`), y en el módulo 20 una herramienta que los revisa.
:::

## ¿Número o texto? La pregunta más importante

Un número de línea **parece** un número, pero no lo es: nadie suma dos números de teléfono. Además, si lo guardas como `int` pierdes los ceros a la izquierda.

```pyrun
destino_internacional = "0013055551234"
como_numero = int(destino_internacional)

print(destino_internacional)
print(como_numero)          # ¡se perdieron los ceros!
```

:::consejo La regla práctica
Si vas a **hacer cuentas** con el valor, es número. Si solo lo vas a **comparar, mostrar o buscar**, es texto. Por eso `linea`, `documento`, `celda` y `cliente_id` son `str`, aunque tengan dígitos.
:::

:::reto Corrige los tipos
Alguien escribió estos datos de un cliente con los tipos equivocados. Corrígelos aplicando la regla práctica:

- `linea` y `documento` son identificadores. El documento real es `0012345678`, **con** los ceros.
- `duracion_seg` y `mb` son mediciones: van como número entero y decimal.
- Al final, `total_mb` debe valer `31.0`.

```pyreto
linea = 3001234567
documento = 12345678
duracion_seg = "125"
mb = "15.5"

total_mb = mb + mb
print(total_mb)
```

:::pista
Los identificadores van entre comillas: `documento = "0012345678"`. Las mediciones van sin comillas: `mb = 15.5`. Fíjate en lo que imprime `"15.5" + "15.5"`: une los textos en lugar de sumarlos.
:::

```pyprueba
def prueba_identificadores():
    """linea y documento son texto, con los ceros del documento"""
    requiere("linea", "documento")
    igual(linea, "3001234567", "linea")
    igual(documento, "0012345678", "documento")


def prueba_mediciones():
    """duracion_seg es int y mb es float"""
    requiere("duracion_seg", "mb")
    assert isinstance(duracion_seg, int), f"duracion_seg debe ser int, es {type(duracion_seg).__name__}"
    assert isinstance(mb, float), f"mb debe ser float, es {type(mb).__name__}"
    igual(duracion_seg, 125)
    igual(mb, 15.5)


def prueba_total():
    """total_mb suma las megas (31.0)"""
    requiere("total_mb")
    igual(total_mb, 31.0)
```

```pysolucion
linea = "3001234567"
documento = "0012345678"
duracion_seg = 125
mb = 15.5

total_mb = mb + mb
print(total_mb)
```
:::

## Convertir entre tipos

Todo lo que se lee de un archivo llega como **texto**. Antes de calcular hay que convertirlo:

```pyrun
registro = "125|15.131|VOZ"
campos = registro.split("|")
print(campos)

duracion = int(campos[0])
mb = float(campos[1])

print(duracion + 1)
print(mb * 2)
print(str(duracion) + " segundos")
```

| Función | Convierte a | Ejemplo | Resultado |
|---|---|---|---|
| `int()` | entero | `int("0045")` | `45` |
| `float()` | decimal | `float("15.131")` | `15.131` |
| `str()` | texto | `str(125)` | `"125"` |
| `bool()` | booleano | `bool(0)` | `False` |
| `int()` sobre un `float` | entero (trunca) | `int(9.99)` | `9` |

:::error Las conversiones pueden fallar
Si el texto no tiene el formato esperado, Python lanza un `ValueError`. Esto pasará muchísimo con archivos reales:

```pyrun
print(int("125"))
print(float("15,131"))   # coma decimal: ¡error!  # error esperado
```

En el módulo 7 aprenderás a capturar estos errores para que tu programa no se detenga ante un registro dañado.
:::

3. Crea `minutos` con la duración dividida entre 60.

```pyreto
registro = "3001234567|245|38.75"

# 1. Separa los campos

# 2. Crea linea, duracion y mb con el tipo correcto

# 3. Calcula minutos
```

:::pista
`campos = registro.split("|")` te da una lista de textos; `campos[0]` es el primero. Para convertir usa `int(campos[1])` y `float(campos[2])`.
:::

```pyprueba
def prueba_linea():
    """linea es el texto «3001234567»"""
    requiere("linea")
    igual(linea, "3001234567")


def prueba_numeros():
    """duracion es int y mb es float"""
    requiere("duracion", "mb")
    assert isinstance(duracion, int), f"duracion debe ser int, es {type(duracion).__name__}"
    assert isinstance(mb, float), f"mb debe ser float, es {type(mb).__name__}"
    igual(duracion, 245)
    igual(mb, 38.75)


def prueba_minutos():
    """minutos es la duración dividida entre 60"""
    requiere("minutos")
    cerca(minutos, 245 / 60)
```

```pysolucion
registro = "3001234567|245|38.75"

campos = registro.split("|")

linea = campos[0]
duracion = int(campos[1])
mb = float(campos[2])

minutos = duracion / 60
print(linea, duracion, mb, minutos)
```
:::

## Saber el tipo dentro del código

`type(x) == int` funciona, pero la forma recomendada es `isinstance()`:

```pyrun
valor = 125
print(isinstance(valor, int))
print(isinstance(valor, (int, float)))   # ¿es int O float?
print(isinstance("125", int))
```

:::telco Tipos de los campos del CDR
| Campo | Tipo correcto | Por qué |
|---|---|---|
| `cdr_id` | `int` | Se compara y ordena como número |
| `linea_origen` | `str` | Es un identificador, no se suma |
| `duracion_seg` | `int` | Se suma y se convierte a minutos |
| `mb` | `float` o `Decimal` | Tiene decimales |
| `fecha_inicio` | `str` → `datetime` (módulo 6) | Se compara y se agrupa por día |
:::
