## Enunciado

Construye con Polars **en modo perezoso** el consumo válido por línea:

1. `plan_consumo(ruta_cdr, ruta_clientes)` → un **`LazyFrame`** (sin ejecutar) que:
   - lea con `pl.read_csv(...).lazy()` (en el navegador no existe `pl.scan_csv`; en VS Code sería `pl.scan_csv(...)` con los mismos argumentos);
   - descarte duplicados (conserva la **primera** aparición de cada `cdr_id`: usa `pl.int_range(pl.len()).over("cdr_id") == 0` o `is_first_distinct()`), líneas vacías o desconocidas (`semi join` con los clientes), tipos inválidos, duraciones negativas y fechas inválidas (`str.strptime(..., strict=False)` da nulo si es inválida);
   - agrupe por `linea_origen` con `minutos_nacionales`, `minutos_internacionales`, `mb` y `sms`;
   - quede ordenado por `linea_origen`.
2. `consumo(ruta_cdr, ruta_clientes)` → ejecuta el plan (`collect()`) y lo devuelve.

Los totales deben coincidir con `esperado.json`.

## Solución

```python
import polars as pl


def plan_consumo(ruta_cdr, ruta_clientes):
    clientes = pl.read_csv(ruta_clientes, encoding="utf8-lossy", schema_overrides={"linea": pl.String}).lazy().select("linea")
    cdr = pl.read_csv(ruta_cdr, separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String}).lazy()
    fecha_ok = pl.col("fecha_inicio").str.strptime(pl.Datetime, "%Y-%m-%d %H:%M:%S", strict=False).is_not_null()
    minutos = (pl.col("duracion_seg") + 59) // 60
    voz = pl.col("tipo") == "VOZ"
    internacional = pl.col("destino") == "INTERNACIONAL"
    return (
        cdr.filter(pl.int_range(pl.len()).over("cdr_id") == 0)
        .join(clientes, left_on="linea_origen", right_on="linea", how="semi")
        .filter(pl.col("tipo").is_in(["VOZ", "SMS", "DATOS"]) & (pl.col("duracion_seg") >= 0) & fecha_ok)
        .group_by("linea_origen")
        .agg(
            minutos_nacionales=minutos.filter(voz & ~internacional).sum(),
            minutos_internacionales=minutos.filter(voz & internacional).sum(),
            mb=pl.col("mb").filter(pl.col("tipo") == "DATOS").sum(),
            sms=(pl.col("tipo") == "SMS").sum(),
        )
        .sort("linea_origen")
    )


def consumo(ruta_cdr, ruta_clientes):
    return plan_consumo(ruta_cdr, ruta_clientes).collect()


print(consumo("cdr.csv", "clientes.csv").head())
```

## Explicación

El plan completo (leer, quitar duplicados, cruzar, filtrar, agrupar) se describe antes de ejecutarse. Ejecuta `print(plan_consumo("cdr.csv", "clientes.csv").explain())` para ver cómo Polars lo reorganiza.

Detalles interesantes:

- **`pl.int_range(pl.len()).over("cdr_id") == 0`** numera las filas de cada `cdr_id` y se queda con la primera: la función de ventana de Polars para duplicados.
- **El `semi join`** filtra por pertenencia sin agregar columnas ni duplicar filas.
- **Agregaciones condicionales** (`minutos.filter(...).sum()`) calculan varias sumas distintas en un solo `group_by`, sin columnas auxiliares.

Con el archivo de 20 GB, `plan_consumo(...).collect(engine="streaming")` procesa por lotes y mantiene acotada la memoria.
