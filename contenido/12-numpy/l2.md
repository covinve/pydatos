## Máscaras booleanas

Una comparación sobre un array devuelve un array de `True`/`False`: una **máscara**. Con ella puedes filtrar, contar o modificar.

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600, 45])

contestadas = duraciones > 0
print(contestadas)
print(duraciones[contestadas])       # filtra
print(contestadas.sum())             # cuenta los True
print(contestadas.mean())            # proporción de True
```

Combina condiciones con `&` (y), `|` (o) y `~` (no), **siempre con paréntesis**:

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600, 45])
tipos = np.array(["VOZ", "SMS", "VOZ", "VOZ", "DATOS", "VOZ"])

voz_validas = (tipos == "VOZ") & (duraciones >= 0)
print(duraciones[voz_validas])
print(((duraciones + 59) // 60)[voz_validas].sum())
print(np.count_nonzero((tipos == "SMS") | (tipos == "DATOS")))
```

:::error and / or no funcionan con arrays
`(tipos == "VOZ") and (duraciones >= 0)` da `ValueError: The truth value of an array... is ambiguous`. Con arrays usa `&`, `|`, `~` y pon paréntesis a cada comparación (sin paréntesis, `&` se evalúa antes que `==`).
:::

:::reto Preguntas con máscaras
Con máscaras (sin bucles), responde:

- `voz_negativas`: cuántos registros de VOZ tienen duración negativa;
- `pct_sms`: la proporción de registros que son SMS (entre 0 y 1);
- `datos_largos`: las duraciones de los registros de DATOS de más de 1000 segundos.

```pyreto
import numpy as np

tipos = np.array(["VOZ", "SMS", "VOZ", "DATOS", "VOZ", "DATOS", "SMS", "DATOS"])
duraciones = np.array([125, 0, -30, 2400, -5, 600, 0, 1800])

# voz_negativas, pct_sms y datos_largos

print(voz_negativas, pct_sms, datos_largos)
```

:::pista
Combina con `&` y paréntesis: `((tipos == "VOZ") & (duraciones < 0)).sum()`. La proporción es el `.mean()` de la máscara. Para filtrar: `duraciones[(tipos == "DATOS") & (duraciones > 1000)]`.
:::

```pyprueba
def prueba_conteo():
    """voz_negativas = 2"""
    requiere("voz_negativas")
    igual(int(voz_negativas), 2)


def prueba_proporcion():
    """pct_sms = 0.25"""
    requiere("pct_sms")
    cerca(float(pct_sms), 0.25)


def prueba_filtro():
    """datos_largos = [2400, 1800]"""
    requiere("datos_largos")
    igual(list(datos_largos), [2400, 1800])
    assert "for " not in codigo, "Resuélvelo con máscaras, sin bucles"
```

```pysolucion
import numpy as np

tipos = np.array(["VOZ", "SMS", "VOZ", "DATOS", "VOZ", "DATOS", "SMS", "DATOS"])
duraciones = np.array([125, 0, -30, 2400, -5, 600, 0, 1800])

voz_negativas = ((tipos == "VOZ") & (duraciones < 0)).sum()
pct_sms = (tipos == "SMS").mean()
datos_largos = duraciones[(tipos == "DATOS") & (duraciones > 1000)]

print(voz_negativas, pct_sms, datos_largos)
```

## np.isin: pertenencia vectorizada

```pyrun
import numpy as np

tipos = np.array(["VOZ", "VOX", "DATOS", "MMS", "SMS"])
validos = np.isin(tipos, ["VOZ", "SMS", "DATOS"])
print(validos)
print(tipos[~validos])     # los inválidos
```

:::reto Los tipos que no existen
Con `np.isin` y `~`, crea:

- `cantidad_invalidos`: cuántos registros tienen un tipo inválido;
- `invalidos`: los tipos inválidos **distintos**, ordenados (usa `np.unique`).

```pyreto
import numpy as np

tipos = np.array(["VOZ", "VOX", "DATOS", "MMS", "SMS", "VOX", "DAT", "VOZ"])
VALIDOS = ["VOZ", "SMS", "DATOS"]

# cantidad_invalidos e invalidos

print(cantidad_invalidos, invalidos)
```

:::pista
`mascara = ~np.isin(tipos, VALIDOS)`. Cuenta con `mascara.sum()` y obtén los distintos con `np.unique(tipos[mascara])`, que ya los devuelve ordenados.
:::

```pyprueba
def prueba_invalidos():
    """4 registros inválidos con 3 tipos distintos"""
    requiere("cantidad_invalidos", "invalidos")
    igual(int(cantidad_invalidos), 4, "cantidad_invalidos")
    igual(list(invalidos), ["DAT", "MMS", "VOX"], "invalidos")
```

```pysolucion
import numpy as np

tipos = np.array(["VOZ", "VOX", "DATOS", "MMS", "SMS", "VOX", "DAT", "VOZ"])
VALIDOS = ["VOZ", "SMS", "DATOS"]

mascara = ~np.isin(tipos, VALIDOS)
cantidad_invalidos = mascara.sum()
invalidos = np.unique(tipos[mascara])

print(cantidad_invalidos, invalidos)
```

## np.where: el if vectorizado

`np.where(condicion, si_verdadero, si_falso)` elige elemento a elemento:

```pyrun
import numpy as np

minutos = np.array([342, 100, 0, 5000])
incluidos = np.array([300, 300, 300, -1])

exceso = np.where(incluidos == -1, 0, np.maximum(minutos - incluidos, 0))
print(exceso)
```

Sin argumentos de valor, `np.where(mascara)` devuelve las **posiciones** donde la máscara es verdadera:

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600])
print(np.where(duraciones < 0)[0])     # posiciones de las duraciones negativas
```

:::reto Planes ilimitados y datos sucios
Con `np.where`:

- `exceso_sms`: los SMS por encima de los incluidos de cada línea, **0** si el plan es ilimitado (`-1`);
- `posiciones`: las posiciones de las líneas que mandaron **más** de 1000 SMS.

```pyreto
import numpy as np

sms = np.array([120, 40, 2500, 0, 1300])
incluidos = np.array([100, 100, -1, 50, 1000])

# exceso_sms y posiciones

print(exceso_sms, posiciones)
```

:::pista
`np.where(incluidos == -1, 0, np.maximum(sms - incluidos, 0))`. Para las posiciones, `np.where(sms > 1000)[0]`.
:::

```pyprueba
def prueba_exceso():
    """exceso_sms respeta el ilimitado"""
    requiere("exceso_sms")
    igual(list(exceso_sms), [20, 0, 0, 0, 300])


def prueba_posiciones():
    """posiciones = [2, 4]"""
    requiere("posiciones")
    igual(list(posiciones), [2, 4])
```

```pysolucion
import numpy as np

sms = np.array([120, 40, 2500, 0, 1300])
incluidos = np.array([100, 100, -1, 50, 1000])

exceso_sms = np.where(incluidos == -1, 0, np.maximum(sms - incluidos, 0))
posiciones = np.where(sms > 1000)[0]

print(exceso_sms, posiciones)
```
:::

## np.select: varios casos (el elif vectorizado)

```pyrun
import numpy as np

destinos = np.array(["LOCAL", "NACIONAL", "INTERNACIONAL", "LOCAL", "SATELITAL"])
condiciones = [destinos == "LOCAL", destinos == "NACIONAL", destinos == "INTERNACIONAL"]
tarifas = [100, 120, 950]

print(np.select(condiciones, tarifas, default=0))
```

Se evalúan en orden: el primer caso verdadero gana, igual que en `if/elif/else`.

:::reto Tarifa por franja horaria
Con `np.select`, asigna a cada llamada la tarifa de su franja según la hora en que empezó:

| Horas | Tarifa |
|---|---|
| 6 a 17 | 120 |
| 18 a 21 | 100 |
| cualquier otra (noche) | 60 |

Crea `tarifas` y `valor_total`: la suma de `minutos × tarifa`.

```pyreto
import numpy as np

horas = np.array([3, 6, 12, 17, 18, 21, 22, 0])
minutos = np.array([5, 2, 10, 1, 3, 4, 20, 2])

# tarifas con np.select y valor_total

print(tarifas, valor_total)
```

:::pista
`condiciones = [(horas >= 6) & (horas <= 17), (horas >= 18) & (horas <= 21)]`, `valores = [120, 100]` y `np.select(condiciones, valores, default=60)`.
:::

```pyprueba

    """Cada hora tiene la tarifa de su franja"""
    requiere("tarifas")
    igual(list(tarifas), [60, 120, 120, 120, 100, 100, 60, 60])


def prueba_total():
    """valor_total = 3880"""
    requiere("valor_total")
    igual(int(valor_total), 3880)


def prueba_usa_select():
    """Usa np.select"""
    assert "select(" in codigo, "Asigna las tarifas con np.select"
```

```pysolucion
import numpy as np

horas = np.array([3, 6, 12, 17, 18, 21, 22, 0])
minutos = np.array([5, 2, 10, 1, 3, 4, 20, 2])

condiciones = [(horas >= 6) & (horas <= 17), (horas >= 18) & (horas <= 21)]
tarifas = np.select(condiciones, [120, 100], default=60)
valor_total = (minutos * tarifas).sum()

print(tarifas, valor_total)
```

## Modificar con máscaras

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600])
limpias = duraciones.copy()
limpias[limpias < 0] = 0          # reemplaza los negativos
print(limpias)
print(np.clip(duraciones, 0, 3600))   # recorta a un rango
```

:::capo Copias y vistas
Cortar un array (`a[1:3]`) devuelve una **vista**: comparte la memoria con el original, y modificarla modifica el original. Filtrar con una máscara (`a[a > 0]`) devuelve una **copia**. Ante la duda, usa `.copy()` antes de modificar.
:::

:::telco Tarificación sin bucles
Con `np.select` para la tarifa por destino, `np.where` para el plan ilimitado y una máscara para los registros válidos, la tarificación completa de millones de CDR son tres o cuatro líneas que corren en milisegundos.
:::

## Cuestionario

? ¿Qué devuelve `(np.array([5, -1, 3]) > 0).sum()`?
- [ ] `7`
- [x] `2`
- [ ] `[True, False, True]`
- [ ] Un error
> La máscara tiene dos `True`, y al sumar booleanos cada `True` vale 1.

? ¿Cómo combinas dos condiciones sobre arrays?
- [ ] `(a > 0) and (b == "VOZ")`
- [x] `(a > 0) & (b == "VOZ")`
- [ ] `a > 0 & b == "VOZ"`
- [ ] `(a > 0) + (b == "VOZ")`
> Con arrays se usa `&` y cada comparación entre paréntesis.

? ¿Qué hace `np.select(condiciones, valores, default=0)`?
- [ ] Ordena los valores
- [x] Para cada elemento, devuelve el valor de la primera condición verdadera, o el default
- [ ] Devuelve las posiciones verdaderas
- [ ] Suma los valores
> Es el equivalente vectorizado de una cadena `if/elif/else`.
