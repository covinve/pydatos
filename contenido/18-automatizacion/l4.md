El último paso de la automatización: que el programa se ejecute **solo**, todos los días a las 6:00, aunque no estés.

## El Programador de tareas de Windows

Puedes crear tareas **para tu propio usuario sin permisos de administrador**, desde la interfaz (busca "Programador de tareas" en el menú Inicio → *Crear tarea básica*) o desde PowerShell con `schtasks`:

```powershell
schtasks /Create /TN "Telco\ResumenDiario" /SC DAILY /ST 06:00 `
  /TR "\"D:\curso\.venv\Scripts\python.exe\" \"D:\curso\scripts\resumen_diario.py\""

schtasks /Query /TN "Telco\ResumenDiario" /V /FO LIST     # ver estado y último resultado
schtasks /Run /TN "Telco\ResumenDiario"                   # ejecutarla ya, para probar
schtasks /Delete /TN "Telco\ResumenDiario" /F             # eliminarla
```

| Opción | Significa |
|---|---|
| `/TN` | Nombre de la tarea (puedes usar carpetas: `Telco\...`) |
| `/SC DAILY` · `WEEKLY /D LUN,MAR` · `HOURLY` | Frecuencia |
| `/ST 06:00` | Hora de inicio |
| `/TR` | Qué ejecutar: **ruta completa** del `python.exe` del entorno virtual y del script |

:::error Las tres causas de "a mano funciona y programado no"
1. **Rutas relativas**: el directorio actual de la tarea no es el del script. Usa `Path(__file__).resolve().parent`.
2. **El Python equivocado**: `python` a secas puede ser otro intérprete sin tus librerías. Usa la ruta del `.venv\Scripts\python.exe`.
3. **Variables de entorno**: la tarea no ve las variables de tu terminal; las de `setx` sí (son de tu usuario).
:::

En Linux y macOS (o en Docker, módulo 22) el equivalente es **cron**: `0 6 * * 1-5 /ruta/.venv/bin/python /ruta/resumen_diario.py` = a las 6:00, de lunes a viernes.

## No ejecutar dos veces a la vez

Si el proceso de las 6:00 tarda más de lo normal y otro lo lanza de nuevo, dos copias procesando la misma bandeja pueden duplicar o corromper resultados. Un **archivo de bloqueo** lo evita:

```pyrun
import os
from pathlib import Path


class Bloqueo:
    """Crea el archivo en modo exclusivo: si ya existe, otro proceso está trabajando."""

    def __init__(self, ruta):
        self.ruta = Path(ruta)

    def __enter__(self):
        try:
            self.descriptor = os.open(self.ruta, os.O_CREAT | os.O_EXCL | os.O_WRONLY)
        except FileExistsError:
            raise RuntimeError(f"Ya hay un proceso en curso ({self.ruta})") from None
        os.write(self.descriptor, str(os.getpid()).encode())
        return self

    def __exit__(self, *error):
        os.close(self.descriptor)
        self.ruta.unlink()


with Bloqueo("proceso.lock"):
    print("Trabajando...")
    try:
        with Bloqueo("proceso.lock"):
            print("Esto no debería verse")
    except RuntimeError as e:
        print("Segundo intento:", e)
print("¿Quedó el archivo?", Path("proceso.lock").exists())
```

`O_EXCL` hace que crear el archivo y comprobar que no existía sea **una sola operación atómica**: no hay un instante en que dos procesos puedan pasar a la vez.

:::consejo Bloqueos huérfanos
Si el proceso muere de golpe (corte de luz), el archivo queda y bloquea las ejecuciones siguientes. Las soluciones habituales: guardar dentro el PID y la hora, y considerar vencido un bloqueo de más de N horas.
:::

:::reto Un proceso a la vez, pase lo que pase
Escribe `ejecutar_exclusivo(ruta_bloqueo, tarea)`:

- intenta crear el archivo de bloqueo de forma **atómica** (`os.O_CREAT | os.O_EXCL`); si ya existe, devuelve `"ocupado"` sin ejecutar la tarea;
- si lo consigue, ejecuta `tarea()` y devuelve su resultado;
- el archivo de bloqueo se borra **siempre** al terminar, incluso si `tarea()` lanza una excepción (que debe seguir subiendo).

```pyreto
import os
from pathlib import Path


def ejecutar_exclusivo(ruta_bloqueo, tarea):
    pass


print(ejecutar_exclusivo("resumen.lock", lambda: "resumen listo"))
print(Path("resumen.lock").exists())   # False
```

:::pista
`descriptor = os.open(ruta_bloqueo, os.O_CREAT | os.O_EXCL | os.O_WRONLY)` dentro de un `try` con `except FileExistsError: return "ocupado"`. Luego `try: return tarea()` y en el `finally:` cierra el descriptor con `os.close` y borra con `Path(ruta_bloqueo).unlink()`.
:::

```pyprueba
import os
from pathlib import Path


def prueba_normal():
    """Ejecuta la tarea y borra el bloqueo"""
    requiere("ejecutar_exclusivo")
    igual(ejecutar_exclusivo("a.lock", lambda: 42), 42)
    igual(Path("a.lock").exists(), False, "el bloqueo debe borrarse")


def prueba_ocupado():
    """Si ya hay bloqueo, no ejecuta"""
    Path("b.lock").write_text("123")
    llamadas = []
    igual(ejecutar_exclusivo("b.lock", lambda: llamadas.append(1)), "ocupado")
    igual(llamadas, [], "no debe ejecutar la tarea")
    os.remove("b.lock")


def prueba_error():
    """Si la tarea falla, el error sube y el bloqueo igual se borra"""
    def falla():
        raise ValueError("archivo dañado")

    lanza(ValueError, ejecutar_exclusivo, "c.lock", falla)
    igual(Path("c.lock").exists(), False, "el bloqueo debe borrarse aunque la tarea falle")
```

```pypreparacion
from pathlib import Path
for nombre in ("resumen.lock", "a.lock", "b.lock", "c.lock"):
    Path(nombre).unlink(missing_ok=True)
```

```pysolucion
import os
from pathlib import Path


def ejecutar_exclusivo(ruta_bloqueo, tarea):
    try:
        descriptor = os.open(ruta_bloqueo, os.O_CREAT | os.O_EXCL | os.O_WRONLY)
    except FileExistsError:
        return "ocupado"
    try:
        os.write(descriptor, str(os.getpid()).encode())
        return tarea()
    finally:
        os.close(descriptor)
        Path(ruta_bloqueo).unlink()


print(ejecutar_exclusivo("resumen.lock", lambda: "resumen listo"))
print(Path("resumen.lock").exists())   # False
```

## Registros que sirven al día siguiente

Nadie ve la pantalla de una tarea programada: el **registro** (módulo 7) es tu único testigo. Para procesos diarios:

```python
import logging
from logging.handlers import TimedRotatingFileHandler

manejador = TimedRotatingFileHandler("logs/resumen.log", when="midnight", backupCount=30, encoding="utf-8")
manejador.setFormatter(logging.Formatter("%(asctime)s %(levelname)s %(message)s"))
logging.basicConfig(level=logging.INFO, handlers=[manejador])
```

Un archivo por día, 30 días de historia. Registra el **inicio**, cada archivo procesado con sus conteos, los errores con `logging.exception` (incluye el *traceback*) y el **fin** con el tiempo total. Y termina con el código de salida correcto: el Programador de tareas lo muestra como "Resultado de la última ejecución".

:::reto La bitácora en un archivo
Escribe `crear_bitacora(ruta)`: devuelve un logger llamado `"resumen_diario"`, con nivel INFO, que escribe en el archivo `ruta` (UTF-8) con el formato `%(levelname)s %(message)s`, usando un `TimedRotatingFileHandler` que rote a medianoche y guarde 30 días.

Llamarla dos veces no debe duplicar los mensajes (quita los manejadores anteriores del logger antes de agregar el nuevo).

```pyreto
import logging
from logging.handlers import TimedRotatingFileHandler


def crear_bitacora(ruta):
    pass


log = crear_bitacora("resumen.log")
log.info("Inicio: 3 archivos en la bandeja")
log.warning("cdr_20260902.csv: encabezado inválido, se mueve a errores")
log.info("Fin: 2 procesados, 1 con error")
```

:::pista
`log = logging.getLogger("resumen_diario")`, `log.setLevel(logging.INFO)` y `log.handlers.clear()`. Crea `TimedRotatingFileHandler(ruta, when="midnight", backupCount=30, encoding="utf-8")`, ponle `setFormatter(logging.Formatter("%(levelname)s %(message)s"))` y agrégalo con `log.addHandler(...)`.
:::

```pyprueba
from logging.handlers import TimedRotatingFileHandler
from pathlib import Path


def prueba_archivo():
    """Los mensajes quedan en el archivo"""
    requiere("log")
    for h in log.handlers:
        h.flush()
    lineas = Path("resumen.log").read_text(encoding="utf-8").splitlines()
    igual(lineas, [
        "INFO Inicio: 3 archivos en la bandeja",
        "WARNING cdr_20260902.csv: encabezado inválido, se mueve a errores",
        "INFO Fin: 2 procesados, 1 con error",
    ])


def prueba_manejador():
    """Un solo TimedRotatingFileHandler, a medianoche y 30 días"""
    requiere("crear_bitacora")
    otro = crear_bitacora("otro.log")
    otro = crear_bitacora("otro.log")
    manejadores = otro.handlers
    igual(len(manejadores), 1, "manejadores (no deben duplicarse)")
    h = manejadores[0]
    assert isinstance(h, TimedRotatingFileHandler), "Usa TimedRotatingFileHandler"
    igual((h.when, h.backupCount), ("MIDNIGHT", 30), "rotación")
    h.close()
```

```pypreparacion
import logging
from pathlib import Path

for h in list(logging.getLogger("resumen_diario").handlers):
    h.close()
    logging.getLogger("resumen_diario").removeHandler(h)
for nombre in ("resumen.log", "otro.log"):
    Path(nombre).unlink(missing_ok=True)
```

```pysolucion
import logging
from logging.handlers import TimedRotatingFileHandler


def crear_bitacora(ruta):
    log = logging.getLogger("resumen_diario")
    log.setLevel(logging.INFO)
    for anterior in list(log.handlers):
        anterior.close()
        log.removeHandler(anterior)
    manejador = TimedRotatingFileHandler(ruta, when="midnight", backupCount=30, encoding="utf-8")
    manejador.setFormatter(logging.Formatter("%(levelname)s %(message)s"))
    log.addHandler(manejador)
    return log


log = crear_bitacora("resumen.log")
log.info("Inicio: 3 archivos en la bandeja")
log.warning("cdr_20260902.csv: encabezado inválido, se mueve a errores")
log.info("Fin: 2 procesados, 1 con error")
```

## Calendarios de negocio

"Todos los días hábiles a las 6:00" no es lo mismo que "todos los días": fines de semana y festivos cambian el cálculo. Las fechas de corte y de emisión de facturas suelen depender de esto, y es una lógica que conviene tener en **una función probada** (lo harás en el ejercicio 6).

:::reto ¿Hoy se corre?
La tarea está programada todos los días, pero solo debe trabajar en días **hábiles**. Escribe `debe_correr(hoy, festivos)`: `True` si `hoy` es de lunes a viernes y no está en el conjunto `festivos`.

```pyreto
from datetime import date

FESTIVOS = {date(2026, 10, 12), date(2026, 11, 2), date(2026, 11, 16)}


def debe_correr(hoy, festivos):
    pass


print(debe_correr(date(2026, 10, 9), FESTIVOS))    # viernes → True
print(debe_correr(date(2026, 10, 10), FESTIVOS))   # sábado → False
print(debe_correr(date(2026, 10, 12), FESTIVOS))   # lunes festivo → False
```

:::pista
`hoy.weekday()` da 0 para el lunes y 6 para el domingo: hábil es `< 5`. Además, `hoy not in festivos`.
:::

```pyprueba
from datetime import date

F = {date(2026, 10, 12), date(2026, 11, 2)}


def prueba_habiles():
    """De lunes a viernes, sin festivos, sí corre"""
    requiere("debe_correr")
    for dia in (5, 6, 7, 8, 9, 13):
        igual(debe_correr(date(2026, 10, dia), F), True, f"2026-10-{dia:02d}")


def prueba_no_habiles():
    """Fines de semana y festivos no"""
    for fecha in (date(2026, 10, 10), date(2026, 10, 11), date(2026, 10, 12), date(2026, 11, 2)):
        igual(debe_correr(fecha, F), False, str(fecha))
    igual(debe_correr(date(2026, 10, 12), set()), True, "sin festivos, un lunes sí corre")
```

```pysolucion
from datetime import date

FESTIVOS = {date(2026, 10, 12), date(2026, 11, 2), date(2026, 11, 16)}


def debe_correr(hoy, festivos):
    return hoy.weekday() < 5 and hoy not in festivos


print(debe_correr(date(2026, 10, 9), FESTIVOS))    # viernes → True
print(debe_correr(date(2026, 10, 10), FESTIVOS))   # sábado → False
print(debe_correr(date(2026, 10, 12), FESTIVOS))   # lunes festivo → False
```

## Cuestionario

? ¿Qué ruta de Python debe usar la tarea programada?
- [ ] `python`, el que esté en el PATH
- [x] La ruta completa del `python.exe` del entorno virtual del proyecto
- [ ] La de Python 2
- [ ] Ninguna: el Programador ejecuta `.py` directamente
> Así la tarea usa exactamente el intérprete con las librerías del proyecto.

? ¿Por qué el archivo de bloqueo se crea con `O_CREAT | O_EXCL`?
- [ ] Para que sea oculto
- [x] Para que comprobar que no existe y crearlo sea una sola operación atómica
- [ ] Para escribir más rápido
- [ ] Para que se borre solo
> Si se comprobara y luego se creara en dos pasos, dos procesos podrían pasar a la vez entre ambos.

? Un proceso programado falla de madrugada. ¿Dónde lo investigas?
- [ ] En la pantalla
- [x] En el archivo de registro y en el resultado de la última ejecución de la tarea
- [ ] En el código, adivinando
- [ ] No se puede saber
> El registro y el código de salida son los testigos de lo que pasó sin nadie mirando.
