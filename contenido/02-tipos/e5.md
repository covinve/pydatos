## Enunciado

Los números de línea llegan de muchas fuentes (formularios, archivos de aliados, el CRM) y con formatos distintos: `"300 123 4567"`, `"300-123-4567"`, `" 3001234567 "`, `"+57 3001234567"`.

Escribe dos funciones:

1. `normalizar_linea(texto)` → devuelve la línea **solo con dígitos**: quita espacios, guiones, puntos, paréntesis y el prefijo de país `+57` si viene al inicio.
2. `es_linea_movil(texto)` → `True` si, **después de normalizar**, la línea tiene exactamente 10 dígitos y empieza por `3`. Si no, `False`.

```python
normalizar_linea("+57 300-123-4567")   # "3001234567"
normalizar_linea("(300) 123.4567")     # "3001234567"
es_linea_movil(" 300 123 4567 ")       # True
es_linea_movil("6014445566")           # False (fijo, no empieza por 3)
es_linea_movil("300123456")            # False (9 dígitos)
es_linea_movil("300123456A")           # False (no son todos dígitos)
es_linea_movil("")                     # False
```

No uses `if`: combina las condiciones con `and`.

## Pista 1

Para normalizar, encadena `.replace()` para cada símbolo y `.strip()` para los espacios. Para el prefijo de país, `removeprefix("+57")` quita el texto solo si está al inicio:

```python
limpio = texto.strip().removeprefix("+57")
```

Pero ojo con el orden: en `" +57 300..."` primero hay que quitar los espacios de los lados.

## Pista 2

Para validar, guarda la línea normalizada en una variable y combina tres condiciones:

```python
linea = normalizar_linea(texto)
return len(linea) == 10 and linea.isdigit() and linea.startswith("3")
```

`"".isdigit()` es `False`, así que el texto vacío queda rechazado solo.

## Solución

```python
def normalizar_linea(texto):
    limpio = texto.strip().removeprefix("+57")
    for simbolo in [" ", "-", ".", "(", ")"]:
        limpio = limpio.replace(simbolo, "")
    return limpio


def es_linea_movil(texto):
    linea = normalizar_linea(texto)
    return len(linea) == 10 and linea.isdigit() and linea.startswith("3")


print(normalizar_linea("+57 300-123-4567"))
print(es_linea_movil("300 123 4567"))
```

## Explicación

La solución usa un pequeño bucle `for` para no escribir cinco `.replace()` seguidos; lo verás a fondo en el módulo 3. Encadenarlos también es correcto:

```python
texto.strip().removeprefix("+57").replace(" ", "").replace("-", "").replace(".", "")...
```

Dos ideas importantes:

- **Normalizar antes de validar.** Separar "limpiar" de "decidir" hace que cada función sea simple y fácil de probar.
- **`and` en cortocircuito.** Si la longitud no es 10, Python ni siquiera evalúa las otras condiciones.

En el mundo real, normalizar identificadores (líneas, documentos, NIT) antes de cruzar fuentes es lo que hace que los cruces funcionen. Un `"300 123 4567"` y un `"3001234567"` son la misma línea, pero para `==` son distintos.
