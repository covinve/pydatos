Hacer `linea.split("|")` funciona… hasta que un campo trae el separador adentro (`"Distribuciones Andina | Sur"`) o comillas. El módulo `csv` maneja todos esos casos por ti.

## csv.reader

```pyrun
import csv
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n"
    "1|3001234567|VOZ|125\n"
    '2|3109876543|SMS|0\n'
    '3|"3157778899"|DATOS|900\n',
    encoding="utf-8",
)

with open("cdr.csv", encoding="utf-8", newline="") as archivo:
    lector = csv.reader(archivo, delimiter="|")
    encabezado = next(lector)
    for fila in lector:
        print(fila)
```

Cada fila llega como una **lista de textos**: las comillas se quitan solas. Los números siguen siendo texto: la conversión es tuya.

:::consejo newline=""
La documentación de `csv` pide abrir los archivos con `newline=""`. Así el módulo maneja bien los saltos de línea de Windows (`\r\n`) y los campos con saltos de línea adentro.
:::

## csv.DictReader: filas como diccionarios

Acceder por posición (`fila[3]`) es frágil: si el proveedor agrega una columna, todo se corre. `DictReader` usa el encabezado como claves:

```pyrun
import csv
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n1|3001234567|VOZ|125\n2|3109876543|SMS|0\n3|3157778899|VOZ|61\n",
    encoding="utf-8",
)

minutos_por_linea = {}
with open("cdr.csv", encoding="utf-8", newline="") as archivo:
    for fila in csv.DictReader(archivo, delimiter="|"):
        if fila["tipo"] == "VOZ":
            minutos = (int(fila["duracion_seg"]) + 59) // 60
            linea = fila["linea_origen"]
            minutos_por_linea[linea] = minutos_por_linea.get(linea, 0) + minutos

print(minutos_por_linea)
```

## Escribir CSV

```pyrun
import csv

facturas = [
    {"cliente_id": "CL001", "total": 48719, "estado": "EMITIDA"},
    {"cliente_id": "CL002", "total": 106981, "estado": "EMITIDA"},
]

with open("facturas.csv", "w", encoding="utf-8", newline="") as archivo:
    escritor = csv.DictWriter(archivo, fieldnames=["cliente_id", "total", "estado"], delimiter=";")
    escritor.writeheader()
    escritor.writerows(facturas)

print(open("facturas.csv", encoding="utf-8").read())
```

:::telco ¿Coma o punto y coma?
En Colombia y buena parte de Latinoamérica, Excel usa la **coma como separador decimal** y por eso espera **punto y coma** (`;`) como separador de columnas. Si generas un CSV para que alguien lo abra con doble clic en Excel, usa `delimiter=";"` y `encoding="utf-8-sig"` (el BOM le dice a Excel que es UTF-8).
:::

## JSON: datos con estructura

**JSON** es el formato estándar para configuraciones, resultados y APIs (módulo 18). Se parece mucho a los diccionarios y listas de Python:

```pyrun
import json

resultado = {
    "archivo": "cdr_20260930.csv",
    "registros": 4064,
    "errores": {"duplicado": 64, "fecha_invalida": 19},
    "ok": True,
    "observaciones": None,
}

texto = json.dumps(resultado, indent=2, ensure_ascii=False)
print(texto)

with open("resultado.json", "w", encoding="utf-8") as f:
    json.dump(resultado, f, indent=2, ensure_ascii=False)

with open("resultado.json", encoding="utf-8") as f:
    leido = json.load(f)
print(leido["errores"]["duplicado"])
```

| Python | JSON |
|---|---|
| `dict` | objeto `{}` |
| `list`, `tuple` | arreglo `[]` |
| `str` | texto `""` |
| `int`, `float` | número |
| `True` / `False` / `None` | `true` / `false` / `null` |

:::error JSON no conoce Decimal ni fechas
`json.dumps({"total": Decimal("48719")})` da `TypeError`. Convierte antes: `int(total)`, `str(total)` o `fecha.isoformat()`.
:::

Los datos del curso traen `esperado.json`: con `json.load` puedes comparar tus resultados contra él automáticamente.
