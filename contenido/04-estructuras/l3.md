Si tuvieras que aprender **una sola** estructura para trabajar con datos, sería el diccionario. Guarda pares **clave → valor** y encuentra cualquier valor por su clave casi instantáneamente, sin importar cuántos haya.

```pyrun
plan = {
    "plan_id": "HOG30",
    "cargo_fijo": 35900,
    "minutos_incluidos": 300,
    "tarifa_minuto": 120,
}

print(plan["cargo_fijo"])
plan["tarifa_minuto"] = 125          # modificar
plan["segmento"] = "RESIDENCIAL"     # agregar
del plan["segmento"]                 # borrar
print(plan)
print(len(plan), "claves")
```

## Leer sin errores: get

Pedir una clave que no existe lanza `KeyError`. `get` devuelve un valor por defecto:

```pyrun
plan = {"plan_id": "HOG30", "cargo_fijo": 35900}

print(plan.get("descuento"))        # None
print(plan.get("descuento", 0))     # 0
print("descuento" in plan)          # ¿existe la clave?
print(plan["descuento"])            # error esperado
```

Escribe `valor_llamada(destino, minutos)` que busque la tarifa en el diccionario `TARIFAS` y devuelva `minutos × tarifa`. Si el destino no está en el diccionario, la tarifa es `0` (no debe lanzar error).

```pyreto
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def valor_llamada(destino, minutos):
    pass


print(valor_llamada("NACIONAL", 3))    # 360
print(valor_llamada("SATELITAL", 3))   # 0
```

:::pista
`TARIFAS.get(destino, 0)` devuelve la tarifa, o 0 si el destino no existe. Multiplícala por los minutos.
:::

## Recorrer un diccionario

```pyrun
tarifas = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}

for destino in tarifas:                 # recorre las claves
    print(destino)

for destino, tarifa in tarifas.items(): # claves y valores juntos
    print(f"{destino:<14} ${tarifa}")

print(list(tarifas.keys()))
print(list(tarifas.values()))
```

Desde Python 3.7 los diccionarios **conservan el orden** en que insertaste las claves.

## El superpoder: buscar sin recorrer

Este es el concepto más importante del módulo. Imagina que tienes 300.000 clientes y 10 millones de CDR, y para cada CDR necesitas el plan de su línea.

Compruébalo tú mismo (el número exacto depende del equipo, pero la diferencia es enorme):

```pyrun
import time

n = 200_000
lista = [f"3{i:09d}" for i in range(n)]
diccionario = {linea: i for i, linea in enumerate(lista)}
buscadas = lista[-200:]   # las 200 últimas: el peor caso para la lista

inicio = time.perf_counter()
for b in buscadas:
    b in lista
t_lista = time.perf_counter() - inicio

inicio = time.perf_counter()
for b in buscadas:
    b in diccionario
t_dict = time.perf_counter() - inicio

print(f"Lista:       {t_lista * 1000:8.1f} ms")
print(f"Diccionario: {t_dict * 1000:8.3f} ms")
print(f"El diccionario fue ~{t_lista / t_dict:,.0f} veces más rápido")
```

## Construir un índice

El patrón: recorre una vez la lista y crea un diccionario cuya clave es lo que vas a buscar.

```pyrun
clientes = [
    {"cliente_id": "CL001", "linea": "3001234567", "plan_id": "HOG30"},
    {"cliente_id": "CL002", "linea": "3109876543", "plan_id": "ILIM"},
]

por_linea = {c["linea"]: c for c in clientes}     # comprensión de diccionario

cdrs = [("3109876543", 125), ("3001234567", 61), ("3999999999", 30)]
for linea, segundos in cdrs:
    cliente = por_linea.get(linea)
    if cliente is None:
        print(f"{linea}: línea desconocida")
    else:
        print(f"{linea}: plan {cliente['plan_id']}")
```

:::reto Tu primer índice
1. Construye `por_linea`: un diccionario cuya clave es la línea y cuyo valor es el **plan** del cliente.
2. Crea `planes_cdr`: para cada CDR (en orden), el plan de su línea, o `"DESCONOCIDA"` si la línea no es de ningún cliente.

```pyreto
clientes = [
    {"cliente_id": "CL001", "linea": "3001234567", "plan_id": "HOG30"},
    {"cliente_id": "CL002", "linea": "3109876543", "plan_id": "ILIM"},
    {"cliente_id": "CL003", "linea": "3157778899", "plan_id": "EMP100"},
]
cdrs = [("3109876543", 125), ("3001234567", 61), ("3999999999", 30), ("3109876543", 5)]

# 1. por_linea

# 2. planes_cdr

print(planes_cdr)
```

:::pista
`por_linea = {c["linea"]: c["plan_id"] for c in clientes}`. Después, recorre los CDR y agrega `por_linea.get(linea, "DESCONOCIDA")` a la lista.
:::

```pyprueba
def prueba_indice():
    """por_linea va de línea a plan"""
    requiere("por_linea")
    igual(por_linea, {"3001234567": "HOG30", "3109876543": "ILIM", "3157778899": "EMP100"})


def prueba_cruce():
    """planes_cdr tiene el plan de cada CDR"""
    requiere("planes_cdr")
    igual(planes_cdr, ["ILIM", "HOG30", "DESCONOCIDA", "ILIM"])
```


## Contar con diccionarios

```pyrun
tipos = ["VOZ", "DATOS", "DATOS", "SMS", "DATOS", "VOZ", "VOX"]

conteo = {}
for t in tipos:
    conteo[t] = conteo.get(t, 0) + 1
print(conteo)

# La biblioteca estándar lo hace por ti:
from collections import Counter
c = Counter(tipos)
print(c)
print(c.most_common(2))
```

:::reto Errores por tipo
El validador dejó la lista `errores`. Crea:

- `conteo`: un diccionario con cuántas veces aparece cada error, contando **a mano** con `get`;
- `mas_comun`: el nombre del error más frecuente, usando `Counter`.

```pyreto
from collections import Counter

errores = ["duracion_negativa", "linea_vacia", "tipo_invalido", "duracion_negativa",
           "duracion_negativa", "linea_vacia", "fecha_invalida"]

# conteo con get

# mas_comun con Counter

print(conteo)
print(mas_comun)
```

:::pista
`conteo[e] = conteo.get(e, 0) + 1` dentro de un `for`. Para el más común: `Counter(errores).most_common(1)` devuelve `[("duracion_negativa", 3)]`; toma el `[0][0]`.
:::

```pyprueba
def prueba_conteo():
    """conteo tiene cuántas veces aparece cada error"""
    requiere("conteo")
    igual(conteo, {"duracion_negativa": 3, "linea_vacia": 2, "tipo_invalido": 1, "fecha_invalida": 1})
    assert ".get(" in codigo, "Cuenta a mano con conteo.get(error, 0) + 1"


def prueba_mas_comun():
    """mas_comun = «duracion_negativa»"""
    requiere("mas_comun")
    igual(mas_comun, "duracion_negativa")
```

```pysolucion
from collections import Counter

errores = ["duracion_negativa", "linea_vacia", "tipo_invalido", "duracion_negativa",
           "duracion_negativa", "linea_vacia", "fecha_invalida"]

conteo = {}
for e in errores:
    conteo[e] = conteo.get(e, 0) + 1

mas_comun = Counter(errores).most_common(1)[0][0]

print(conteo)
print(mas_comun)
```

## Agrupar con diccionarios

```pyrun
from collections import defaultdict

cdrs = [("3001", 125), ("3002", 61), ("3001", 300), ("3003", 0), ("3002", 45)]

minutos_por_linea = defaultdict(int)       # si la clave no existe, empieza en 0
for linea, segundos in cdrs:
    minutos_por_linea[linea] += (segundos + 59) // 60

print(dict(minutos_por_linea))

llamadas_por_linea = defaultdict(list)     # si no existe, empieza en []
for linea, segundos in cdrs:
    llamadas_por_linea[linea].append(segundos)

print(dict(llamadas_por_linea))
```

:::reto Megas por plan
Agrupa con `defaultdict`:

- `mb_por_plan`: el total de megas de cada plan;
- `sesiones_por_plan`: la lista de megas de cada sesión, por plan.

```pyreto
from collections import defaultdict

sesiones = [("HOG30", 120.5), ("ILIM", 2048.0), ("HOG30", 79.5), ("EMP100", 512.0), ("ILIM", 1024.0)]

# mb_por_plan y sesiones_por_plan

print(dict(mb_por_plan))
print(dict(sesiones_por_plan))
```

:::pista
`mb_por_plan = defaultdict(float)` empieza cada plan en 0.0, y `defaultdict(list)` empieza cada uno en `[]`. En el `for plan, mb in sesiones:` usa `+=` y `.append(mb)`.
:::

```pyprueba
def prueba_totales():
    """mb_por_plan suma las megas de cada plan"""
    requiere("mb_por_plan")
    igual(dict(mb_por_plan), {"HOG30": 200.0, "ILIM": 3072.0, "EMP100": 512.0})


def prueba_listas():
    """sesiones_por_plan agrupa cada sesión en su plan"""
    requiere("sesiones_por_plan")
    igual(dict(sesiones_por_plan), {"HOG30": [120.5, 79.5], "ILIM": [2048.0, 1024.0], "EMP100": [512.0]})
```

```pysolucion
from collections import defaultdict

sesiones = [("HOG30", 120.5), ("ILIM", 2048.0), ("HOG30", 79.5), ("EMP100", 512.0), ("ILIM", 1024.0)]

mb_por_plan = defaultdict(float)
sesiones_por_plan = defaultdict(list)
for plan, mb in sesiones:
    mb_por_plan[plan] += mb
    sesiones_por_plan[plan].append(mb)

print(dict(mb_por_plan))
print(dict(sesiones_por_plan))
```

## Diccionarios anidados

Los datos reales tienen estructura: un cliente tiene un plan, el plan tiene tarifas…

```pyrun
planes = {
    "HOG30": {"cargo_fijo": 35900, "incluidos": {"minutos": 300, "mb": 15360}},
    "ILIM": {"cargo_fijo": 89900, "incluidos": {"minutos": -1, "mb": -1}},
}

print(planes["HOG30"]["incluidos"]["minutos"])
for plan_id, plan in planes.items():
    print(plan_id, plan["cargo_fijo"])
```

:::telco El diccionario es un cruce (JOIN)
Cruzar los CDR con los clientes por la línea es exactamente lo que hace un `JOIN` en SQL o un `merge` en Pandas. Por dentro, ambos construyen un índice parecido a un diccionario. Entender esto te ayudará a razonar por qué algunos cruces son rápidos y otros no.
:::

## Cuestionario

? ¿Qué devuelve `{"a": 1}.get("b", 0)`?
- [ ] `None`
- [x] `0`
- [ ] `1`
- [ ] Un `KeyError`
> `get` devuelve el valor por defecto (el segundo argumento) cuando la clave no existe.

? Necesitas buscar el plan de cada uno de 10 millones de CDR entre 300.000 clientes. ¿Qué es lo correcto?
- [ ] Recorrer la lista de clientes para cada CDR
- [x] Construir una vez un diccionario línea → cliente y consultarlo para cada CDR
- [ ] Ordenar los CDR primero
- [ ] Usar una tupla de clientes
> Construir el índice cuesta un recorrido; luego cada consulta es instantánea. Con la lista serían billones de comparaciones.

? ¿Qué ventaja tiene `defaultdict(int)` al contar?
- [ ] Ordena las claves
- [x] Las claves nuevas empiezan en 0, así que no hace falta comprobar si existen
- [ ] Es más rápido que `Counter`
- [ ] Evita los duplicados
> Con un diccionario normal tendrías que usar `get(clave, 0)` o preguntar si la clave existe antes de sumar.
