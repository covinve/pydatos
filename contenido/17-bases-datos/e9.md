## Enunciado

Vas a conciliar la voz facturada contra los CDR **con una sola consulta SQL** que funcione igual en SQLite (en la oficina, hoy) y en PostgreSQL (en casa con Docker, en el módulo 22).

En `ejercicios/m17-e9/conciliacion_sql.py`, `cargar` ya crea las tablas `planes`, `facturas` y `cdr` (solo válidos). Tú escribes:

1. `SQL_DIFERENCIAS`: la consulta. El comentario sobre ella describe las columnas y los cálculos (las reglas de `valor_voz` y `valor_internacional` de la página de referencia de datos).
2. `diferencias_voz(engine, periodo)`: la ejecuta con `pd.read_sql(text(SQL_DIFERENCIAS), con, params={"periodo": periodo})`.

**Portable** significa: nada de funciones exclusivas de SQLite. En lugar de `MAX(a, b)` (que en PostgreSQL es `GREATEST`), usa `CASE WHEN`; en lugar de `IFNULL`, `COALESCE`.

Si ya tienes PostgreSQL (módulo 22), define `TELCO_DB_URL_PRUEBAS` y la última prueba correrá contra él.

## Pista 1

Organiza la consulta en CTE:

```sql
WITH consumo AS (
    SELECT linea_origen AS linea,
           SUM(CASE WHEN destino <> 'INTERNACIONAL' THEN (duracion_seg + 59) / 60 ELSE 0 END) AS min_nac,
           SUM(CASE WHEN destino = 'INTERNACIONAL' THEN (duracion_seg + 59) / 60 ELSE 0 END) AS min_int
    FROM cdr WHERE tipo = 'VOZ'
    GROUP BY linea_origen
),
calculo AS (
    SELECT f.factura_id, f.linea, f.valor_voz AS voz_facturado, ...
    FROM facturas f
    JOIN planes p ON p.plan_id = f.plan_id
    LEFT JOIN consumo c ON c.linea = f.linea
    WHERE f.periodo = :periodo
)
SELECT ... FROM calculo WHERE ... ORDER BY factura_id
```

## Pista 2

El excedente sin `MAX`:

```sql
CASE
    WHEN p.minutos_incluidos = -1 THEN 0
    WHEN COALESCE(c.min_nac, 0) > p.minutos_incluidos
        THEN (COALESCE(c.min_nac, 0) - p.minutos_incluidos) * p.tarifa_minuto
    ELSE 0
END AS voz_calculado
```

La columna `diferencia` y el filtro `diferencia <> 0` van en el `SELECT` final, sobre la CTE `calculo` (en SQL no puedes usar en el `WHERE` un alias definido en el mismo `SELECT`).

## Solución

```python conciliacion_sql.py
"""Ejercicio m17-e9: conciliar la voz facturada con SQL portable (SQLite hoy, PostgreSQL mañana).

Uso:
    python ejercicios/m17-e9/conciliacion_sql.py datos/10MB 202609
    TELCO_DB_URL=postgresql+psycopg://... python ejercicios/m17-e9/conciliacion_sql.py datos/10MB 202609
"""

from __future__ import annotations

import os
import sys
from pathlib import Path

import pandas as pd
from sqlalchemy import Engine, create_engine, text


def crear_engine(url: str | None = None) -> Engine:
    """Engine para `url`, o para la variable de entorno TELCO_DB_URL, o SQLite en memoria."""
    return create_engine(url or os.environ.get("TELCO_DB_URL", "sqlite://"))


def _cdr_validos(carpeta: Path) -> pd.DataFrame:
    """Los CDR válidos con las seis reglas del curso (ya lo sabes hacer: módulo 13)."""
    cdr = pd.read_csv(carpeta / "cdr.csv", sep="|", dtype=str, keep_default_na=False)
    lineas = pd.read_csv(carpeta / "clientes.csv", encoding="latin-1", dtype=str)["linea"]
    duracion = pd.to_numeric(cdr["duracion_seg"])
    fecha = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    ok = (~cdr["cdr_id"].duplicated() & cdr["linea_origen"].isin(lineas)
          & cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (duracion >= 0) & fecha.notna())
    validos = cdr[ok].copy()
    validos["duracion_seg"] = duracion[ok].astype("int64")
    validos["mb"] = pd.to_numeric(validos["mb"])
    return validos


def cargar(engine: Engine, carpeta: Path) -> None:
    """Crea las tablas planes, facturas y cdr (solo los válidos). Ya está hecho."""
    carpeta = Path(carpeta)
    planes = pd.read_csv(carpeta / "planes.csv")
    facturas = pd.read_csv(carpeta / "facturas.csv", dtype={"linea": str})
    with engine.begin() as con:
        planes.to_sql("planes", con, index=False, if_exists="replace")
        facturas.to_sql("facturas", con, index=False, if_exists="replace")
        _cdr_validos(carpeta).to_sql("cdr", con, index=False, if_exists="replace", chunksize=50_000)


# ---------------------------------------------------------------------------
# Tu trabajo
# ---------------------------------------------------------------------------

SQL_DIFERENCIAS = """
WITH consumo AS (
    SELECT linea_origen AS linea,
           SUM(CASE WHEN destino <> 'INTERNACIONAL' THEN (duracion_seg + 59) / 60 ELSE 0 END) AS min_nac,
           SUM(CASE WHEN destino = 'INTERNACIONAL' THEN (duracion_seg + 59) / 60 ELSE 0 END) AS min_int
    FROM cdr
    WHERE tipo = 'VOZ'
    GROUP BY linea_origen
),
calculo AS (
    SELECT f.factura_id,
           f.linea,
           f.valor_voz AS voz_facturado,
           CASE
               WHEN p.minutos_incluidos = -1 THEN 0
               WHEN COALESCE(c.min_nac, 0) > p.minutos_incluidos
                   THEN (COALESCE(c.min_nac, 0) - p.minutos_incluidos) * p.tarifa_minuto
               ELSE 0
           END AS voz_calculado,
           f.valor_internacional AS internacional_facturado,
           COALESCE(c.min_int, 0) * p.tarifa_minuto_internacional AS internacional_calculado
    FROM facturas f
    JOIN planes p ON p.plan_id = f.plan_id
    LEFT JOIN consumo c ON c.linea = f.linea
    WHERE f.periodo = :periodo
)
SELECT factura_id, linea, voz_facturado, voz_calculado, internacional_facturado, internacional_calculado,
       (voz_calculado + internacional_calculado) - (voz_facturado + internacional_facturado) AS diferencia
FROM calculo
WHERE (voz_calculado + internacional_calculado) <> (voz_facturado + internacional_facturado)
ORDER BY factura_id
"""


def diferencias_voz(engine: Engine, periodo: int) -> pd.DataFrame:
    with engine.connect() as con:
        return pd.read_sql(text(SQL_DIFERENCIAS), con, params={"periodo": periodo})


if __name__ == "__main__":
    engine = crear_engine()
    cargar(engine, Path(sys.argv[1]))
    print(diferencias_voz(engine, int(sys.argv[2])))
```

## Explicación

Has hecho en SQL la parte de voz de la conciliación del proyecto 2. ¿Cuándo conviene SQL en lugar de Pandas?

- Cuando los datos **ya están** en una base de datos: llevar 200 millones de CDR a Python solo para sumar es absurdo; la base suma donde están y te devuelve unas filas.
- Cuando la regla debe ser **auditable** por otras personas (de facturación, de control interno), que muchas veces leen SQL pero no Python.

Detalles de portabilidad que vale la pena recordar:

| Necesitas | SQLite | PostgreSQL | Portable |
|---|---|---|---|
| Mayor de dos valores | `MAX(a, b)` | `GREATEST(a, b)` | `CASE WHEN a > b THEN a ELSE b END` |
| Valor si es nulo | `IFNULL(x, 0)` | — | `COALESCE(x, 0)` |
| Parámetros | `?` | `%s` | `:nombre` con `text()` de SQLAlchemy |
| División entera | `5 / 2 = 2` | `5 / 2 = 2` | Igual, si ambos son enteros |

El `LEFT JOIN` con `COALESCE` es importante: una línea sin llamadas igual debe conciliarse (con 0 minutos). Con un `JOIN` normal, esa factura desaparecería del informe, y justo esas pueden ser las que tienen voz cobrada sin consumo.
