Una lista de Python guarda **objetos** sueltos en memoria; cada número es un objeto con su propio tipo y su propio espacio. Un **array** de NumPy guarda los números **juntos, todos del mismo tipo**, como una columna de una planilla. Eso permite que las operaciones se ejecuten en código compilado (C), sin pasar por el intérprete en cada elemento.

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45])
print(duraciones)
print(duraciones.dtype, duraciones.shape, duraciones.size)

minutos = (duraciones + 59) // 60      # se aplica a TODOS los elementos a la vez
print(minutos)
print(minutos * 120)                   # valor de cada llamada
print(minutos.sum())
```

Fíjate: no hay `for`. Escribir operaciones sobre el array completo se llama **vectorizar**.

:::reto Tarifica sin bucles
Sin usar `for`, calcula sobre el array `duraciones`:

- `minutos`: los minutos facturables de cada llamada (un array);
- `valores`: el valor de cada llamada a 120 pesos el minuto (un array);
- `total`: la suma de los valores, como `int`.

```pyreto
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45, 900])

# minutos, valores y total, sin for

print(minutos, valores, total)
```

:::pista
Las operaciones se aplican a todo el array: `minutos = (duraciones + 59) // 60` y `valores = minutos * 120`. Para el total, `int(valores.sum())`.
:::

```pyprueba
import numpy as np


def prueba_minutos():
    """minutos es un array con los minutos de cada llamada"""
    requiere("minutos")
    assert isinstance(minutos, np.ndarray), "minutos debe ser un array de NumPy"
    igual(minutos.tolist(), [3, 0, 2, 60, 1, 15])


def prueba_valores_y_total():
    """valores y total son correctos"""
    requiere("valores", "total")
    igual(valores.tolist(), [360, 0, 240, 7200, 120, 1800], "valores")
    igual(total, 9720, "total")
    assert isinstance(total, int), f"total debe ser int, es {type(total).__name__}"


def prueba_sin_for():
    """No usa for"""
    assert "for " not in codigo, "Resuélvelo sin bucles: opera sobre el array completo"
```

```pysolucion
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45, 900])

minutos = (duraciones + 59) // 60
valores = minutos * 120
total = int(valores.sum())

```

## ¿Cuánto más rápido?

```pyrun
import time

import numpy as np

n = 2_000_000
lista = list(range(n))
array = np.arange(n)

inicio = time.perf_counter()
total_lista = sum((d + 59) // 60 for d in lista)
t_lista = time.perf_counter() - inicio

inicio = time.perf_counter()
total_array = int(((array + 59) // 60).sum())
t_array = time.perf_counter() - inicio

print(total_lista == total_array)
print(f"Python puro: {t_lista * 1000:7.1f} ms")
print(f"NumPy:       {t_array * 1000:7.1f} ms   (~{t_lista / t_array:.0f} veces más rápido)")
```

## Crear arrays

| Función | Crea | Ejemplo |
|---|---|---|
| `np.array(lista)` | Desde una lista | `np.array([125, 0, 61])` |
| `np.arange(inicio, fin, paso)` | Secuencia, como `range` | `np.arange(0, 24)` (horas) |
| `np.zeros(n)` / `np.ones(n)` | Llenos de 0 o 1 | Acumuladores |
| `np.full(n, valor)` | Llenos de un valor | `np.full(5, 120)` |
| `np.linspace(a, b, n)` | `n` valores equiespaciados | Ejes de gráficos |

```pyrun
import numpy as np

horas = np.arange(24)
print(horas)
tarifas = np.full(5, 120)
print(tarifas)
tabla = np.zeros((3, 4), dtype=int)     # 2 dimensiones: 3 filas, 4 columnas
print(tabla.shape)
print(tabla)
```

:::reto Crea los arrays
Con las funciones de la tabla, crea:

- `dias`: los días del mes del 1 al 30;
- `cargos`: un array con el cargo fijo `35900` repetido para 12 meses;
- `llamadas_por_hora`: una tabla de ceros **enteros** de 7 filas (días de la semana) por 24 columnas (horas).

```pyreto
import numpy as np

# dias, cargos y llamadas_por_hora

print(dias, cargos, llamadas_por_hora.shape)
```

:::pista
`np.arange(1, 31)` (el final no se incluye), `np.full(12, 35900)` y `np.zeros((7, 24), dtype=int)`.
:::

```pyprueba
import numpy as np


def prueba_dias():
    """dias va del 1 al 30"""
    requiere("dias")
    igual(dias.tolist(), list(range(1, 31)))


def prueba_cargos():
    """cargos repite 35900 doce veces"""
    requiere("cargos")
    igual(cargos.tolist(), [35900] * 12)


def prueba_tabla():
    """llamadas_por_hora es 7 × 24 de ceros enteros"""
    requiere("llamadas_por_hora")
    igual(llamadas_por_hora.shape, (7, 24), "forma")
    assert np.issubdtype(llamadas_por_hora.dtype, np.integer), f"Debe ser de enteros, es {llamadas_por_hora.dtype}"
    igual(int(llamadas_por_hora.sum()), 0, "todo en cero")
```

```pysolucion
import numpy as np

dias = np.arange(1, 31)
cargos = np.full(12, 35900)
llamadas_por_hora = np.zeros((7, 24), dtype=int)

print(dias, cargos, llamadas_por_hora.shape)
```

## Operaciones elemento a elemento

Las operaciones entre arrays del mismo tamaño se aplican **posición por posición**:

```pyrun
import numpy as np

minutos = np.array([3, 0, 2, 60])
tarifas = np.array([120, 120, 950, 100])

print(minutos * tarifas)                 # valor de cada llamada
print(np.maximum(minutos - 1, 0))        # versión vectorizada de max(0, x)
print(np.ceil(np.array([15.131, 0.2, 7.0])))
print(np.round(np.array([1.234, 5.678]), 1))
```

| Python (un valor) | NumPy (todo el array) |
|---|---|
| `max(0, x)` | `np.maximum(x, 0)` |
| `math.ceil(x)` | `np.ceil(x)` |
| `abs(x)` | `np.abs(x)` |
| `round(x, 2)` | `np.round(x, 2)` |
| `sum(lista)` | `array.sum()` |

:::error Las funciones de math no aceptan arrays
`math.ceil(array)` da error. Usa siempre la versión de NumPy (`np.ceil`). Y `max(array)` funciona pero es lento: usa `array.max()`.
:::

:::reto El exceso de datos de todas las líneas
Cada posición corresponde a una línea. Calcula, sin bucles:

- `facturables`: las megas usadas redondeadas hacia arriba;
- `exceso`: las megas facturables por encima de las incluidas (nunca negativo);
- `cobro`: el exceso por la tarifa de 18 pesos por mega.

```pyreto
import numpy as np

mb_usadas = np.array([15500.2, 800.0, 5120.5, 20480.0])
mb_incluidas = np.array([15360, 15360, 5120, 20480])

# facturables, exceso y cobro

print(facturables, exceso, cobro)
```

:::pista
`np.ceil(mb_usadas)` redondea todo el array hacia arriba, y `np.maximum(facturables - mb_incluidas, 0)` es el `max(0, x)` vectorizado.
:::

```pyprueba
def prueba_facturables():
    """facturables redondea hacia arriba"""
    requiere("facturables")
    igual(facturables.tolist(), [15501.0, 800.0, 5121.0, 20480.0])


def prueba_exceso_y_cobro():
    """exceso nunca es negativo y cobro usa 18 por mega"""
    requiere("exceso", "cobro")
    igual(exceso.tolist(), [141.0, 0.0, 1.0, 0.0], "exceso")
    igual(cobro.tolist(), [2538.0, 0.0, 18.0, 0.0], "cobro")


def prueba_sin_math():
    """Usa funciones de NumPy, no de math"""
    assert "math." not in codigo and "for " not in codigo, "Usa np.ceil y np.maximum, sin math ni bucles"
```

```pysolucion
import numpy as np

mb_usadas = np.array([15500.2, 800.0, 5120.5, 20480.0])
mb_incluidas = np.array([15360, 15360, 5120, 20480])

facturables = np.ceil(mb_usadas)
exceso = np.maximum(facturables - mb_incluidas, 0)
cobro = exceso * 18

print(facturables, exceso, cobro)
```
:::

## Arrays de dos dimensiones

```pyrun
import numpy as np

# filas: líneas; columnas: minutos, megas, sms
consumo = np.array([
    [342, 15500.2, 120],
    [15, 80000.0, 3],
    [1203, 512.0, 40],
])
print(consumo.shape)
print(consumo[0])          # primera fila
print(consumo[:, 1])       # columna de megas
print(consumo[1, 2])       # fila 1, columna 2
```

:::reto Filas y columnas
Con la tabla `consumo` (filas: líneas; columnas: minutos, megas y SMS), calcula:

- `total_minutos`: la suma de la columna de minutos;
- `tercera`: la fila completa de la tercera línea;
- `mas_sms`: el mayor número de SMS.

```pyreto
import numpy as np

consumo = np.array([
    [342, 15500, 120],
    [15, 80000, 3],
    [1203, 512, 40],
    [98, 20480, 250],
])

# total_minutos, tercera y mas_sms

print(total_minutos, tercera, mas_sms)
```

:::pista
Una columna completa es `consumo[:, 0]`; una fila, `consumo[2]`. Suma con `.sum()` y busca el máximo con `.max()`.
:::

```pyprueba
def prueba_valores():
    """total_minutos, tercera y mas_sms son correctos"""
    requiere("total_minutos", "tercera", "mas_sms")
    igual(int(total_minutos), 1658, "total_minutos")
    igual(list(tercera), [1203, 512, 40], "tercera")
    igual(int(mas_sms), 250, "mas_sms")


def prueba_indices():
    """Usa índices de NumPy"""
    assert "[:, " in codigo or "[:," in codigo, "Toma columnas completas con consumo[:, columna]"
```

```pysolucion
import numpy as np

consumo = np.array([
    [342, 15500, 120],
    [15, 80000, 3],
    [1203, 512, 40],
    [98, 20480, 250],
])

total_minutos = consumo[:, 0].sum()
tercera = consumo[2]
mas_sms = consumo[:, 2].max()

print(total_minutos, tercera, mas_sms)
```
:::

:::telco ¿Y para tablas con columnas de distinto tipo?
Un array guarda un **solo tipo**: si mezclas números y textos, todo se vuelve texto. Para tablas como el archivo de CDR (líneas, tipos, fechas, números) usarás **Pandas** (módulos 13 y 14), que está construido sobre NumPy: cada columna de un DataFrame es un array.
