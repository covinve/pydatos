En Python las funciones son **valores**, igual que los números o las listas: se pueden guardar en variables, poner en listas y diccionarios, pasar como argumento y devolver desde otra función.

```pyrun
def tarifa_local(minutos):
    return minutos * 100


calcular = tarifa_local          # sin paréntesis: la función, no su resultado
print(calcular(3))

reglas = {"LOCAL": tarifa_local, "NACIONAL": lambda m: m * 120}
print(reglas["NACIONAL"](3))
```

## lambda: funciones de una línea

`lambda argumentos: expresión` crea una función pequeña sin nombre. Se usa sobre todo como argumento de otras funciones:

```pyrun
consumos = [
    {"linea": "3001", "minutos": 342, "mb": 15360},
    {"linea": "3002", "minutos": 15, "mb": 80000},
    {"linea": "3003", "minutos": 1203, "mb": 512},
]

por_minutos = sorted(consumos, key=lambda c: c["minutos"], reverse=True)
print([c["linea"] for c in por_minutos])

mas_datos = max(consumos, key=lambda c: c["mb"])
print(mas_datos["linea"])
```

`key=` aparece en `sorted`, `max`, `min` y muchas funciones más: "compara usando lo que devuelva esta función".

:::reto Rankings con key
Con `sorted`, `min` y `lambda`:

- `por_datos`: las líneas ordenadas de **más a menos megas** (solo los números de línea);
- `menos_habla`: la línea con menos minutos.

```pyreto
consumos = [
    {"linea": "3001", "minutos": 342, "mb": 15360},
    {"linea": "3002", "minutos": 15, "mb": 80000},
    {"linea": "3003", "minutos": 1203, "mb": 512},
    {"linea": "3004", "minutos": 98, "mb": 20480},
]

# por_datos y menos_habla

print(por_datos, menos_habla)
```

:::pista
`sorted(consumos, key=lambda c: c["mb"], reverse=True)` da los diccionarios ordenados; luego saca la línea de cada uno con una comprensión. `min(consumos, key=lambda c: c["minutos"])` da el diccionario completo: toma su `["linea"]`.
:::

```pyprueba
def prueba_por_datos():
    """por_datos = ['3002', '3004', '3001', '3003']"""
    requiere("por_datos")
    igual(por_datos, ["3002", "3004", "3001", "3003"])


def prueba_menos_habla():
    """menos_habla = '3002'"""
    requiere("menos_habla")
    igual(menos_habla, "3002")


def prueba_usa_lambda():
    """Usa lambda como key"""
    assert "lambda" in codigo and "key=" in codigo.replace(" ", ""), "Ordena con key=lambda ..."
```

```pysolucion
consumos = [
    {"linea": "3001", "minutos": 342, "mb": 15360},
    {"linea": "3002", "minutos": 15, "mb": 80000},
    {"linea": "3003", "minutos": 1203, "mb": 512},
    {"linea": "3004", "minutos": 98, "mb": 20480},
]

ordenados = sorted(consumos, key=lambda c: c["mb"], reverse=True)
por_datos = [c["linea"] for c in ordenados]
menos_habla = min(consumos, key=lambda c: c["minutos"])["linea"]

print(por_datos, menos_habla)
```
:::

:::consejo lambda solo para lo corto
Si una lambda no cabe cómoda en una línea o necesita un `if`, escribe una función normal con `def` y un buen nombre. Las lambdas no tienen docstring ni nombre en los errores.
:::

## Funciones que reciben funciones

Puedes escribir funciones genéricas que reciben **el criterio** como parámetro:

```pyrun
def filtrar(registros, condicion):
    return [r for r in registros if condicion(r)]


cdrs = [
    {"tipo": "VOZ", "duracion": 125},
    {"tipo": "SMS", "duracion": 0},
    {"tipo": "VOZ", "duracion": 0},
]

print(filtrar(cdrs, lambda r: r["tipo"] == "VOZ"))
print(filtrar(cdrs, lambda r: r["duracion"] == 0))
```

`map` y `filter` existen en Python, pero las comprensiones suelen ser más claras:

```pyrun
duraciones = [125, 0, 61]

print(list(map(lambda d: (d + 59) // 60, duraciones)))
print([(d + 59) // 60 for d in duraciones])          # equivalente, más legible
```

:::reto Contar con cualquier criterio
Escribe `contar_si(registros, condicion)` que devuelva cuántos registros cumplen `condicion` (una función que recibe un registro y devuelve `True` o `False`).

Después úsala para crear:

- `internacionales`: cuántos CDR tienen destino `"INTERNACIONAL"`;
- `largas`: cuántos duran más de 600 segundos.

```pyreto
def contar_si(registros, condicion):
    pass


cdrs = [
    {"destino": "LOCAL", "duracion": 125},
    {"destino": "INTERNACIONAL", "duracion": 900},
    {"destino": "NACIONAL", "duracion": 1800},
    {"destino": "INTERNACIONAL", "duracion": 30},
]

# internacionales y largas, usando contar_si con una lambda

print(internacionales, largas)
```

:::pista
Dentro de `contar_si`, llama a la función que recibiste: `if condicion(r):`. Para usarla: `contar_si(cdrs, lambda r: r["destino"] == "INTERNACIONAL")`.
:::

```pyprueba
def prueba_contar_si():
    """contar_si aplica la condición que recibe"""
    requiere("contar_si")
    igual(contar_si([1, 2, 3, 4], lambda x: x > 2), 2)
    igual(contar_si([], lambda x: True), 0)
    igual(contar_si(["a", "bb"], lambda x: len(x) == 2), 1)


def prueba_resultados():
    """internacionales = 2 y largas = 2"""
    requiere("internacionales", "largas")
    igual(internacionales, 2, "internacionales")
    igual(largas, 2, "largas")
```

```pysolucion
def contar_si(registros, condicion):
    cantidad = 0
    for r in registros:
        if condicion(r):
            cantidad += 1
    return cantidad


cdrs = [
    {"destino": "LOCAL", "duracion": 125},
    {"destino": "INTERNACIONAL", "duracion": 900},
    {"destino": "NACIONAL", "duracion": 1800},
    {"destino": "INTERNACIONAL", "duracion": 30},
]

internacionales = contar_si(cdrs, lambda r: r["destino"] == "INTERNACIONAL")
largas = contar_si(cdrs, lambda r: r["duracion"] > 600)

print(internacionales, largas)
```
:::

## Closures: funciones que fabrican funciones

Una función puede crear y devolver otra función que **recuerda** las variables del lugar donde nació:

```pyrun
def crear_tarificador(tarifa_minuto, descuento=0.0):
    def tarificar(segundos):
        minutos = (segundos + 59) // 60
        return round(minutos * tarifa_minuto * (1 - descuento))
    return tarificar


normal = crear_tarificador(120)
nocturno = crear_tarificador(120, descuento=0.5)

print(normal(125), nocturno(125))
```

`tarificar` recuerda `tarifa_minuto` y `descuento` aunque `crear_tarificador` ya terminó. Eso es un **closure**. Es una forma elegante de "configurar una vez, usar muchas veces".

:::reto Una fábrica de validadores
Escribe `crear_validador_rango(minimo, maximo)` que **devuelva una función**. Esa función recibe un valor y devuelve `True` si está entre `minimo` y `maximo` (ambos incluidos).

Luego crea con ella:

- `duracion_ok`: valida duraciones entre 0 y 7200 segundos;
- `mb_ok`: valida megas entre 0 y 102400.

```pyreto
def crear_validador_rango(minimo, maximo):
    pass


# duracion_ok y mb_ok

print(duracion_ok(125), duracion_ok(-5), mb_ok(500.5))   # True False True
```

:::pista
Define una función interna, por ejemplo `def validar(valor): return minimo <= valor <= maximo`, y devuélvela **sin paréntesis**: `return validar`.
:::

```pyprueba
def prueba_fabrica():
    """crear_validador_rango devuelve una función"""
    requiere("crear_validador_rango")
    v = crear_validador_rango(1, 10)
    assert callable(v), "crear_validador_rango debe devolver una función (sin paréntesis en el return)"
    igual(v(1), True, "límite inferior")
    igual(v(10), True, "límite superior")
    igual(v(11), False, "fuera del rango")


def prueba_validadores():
    """duracion_ok y mb_ok validan sus rangos"""
    requiere("duracion_ok", "mb_ok")
    igual(duracion_ok(125), True, "duracion_ok(125)")
    igual(duracion_ok(-5), False, "duracion_ok(-5)")
    igual(duracion_ok(7201), False, "duracion_ok(7201)")
    igual(mb_ok(500.5), True, "mb_ok(500.5)")
    igual(mb_ok(102401), False, "mb_ok(102401)")
```

```pysolucion
def crear_validador_rango(minimo, maximo):
    def validar(valor):
        return minimo <= valor <= maximo
    return validar


duracion_ok = crear_validador_rango(0, 7200)
mb_ok = crear_validador_rango(0, 102400)

print(duracion_ok(125), duracion_ok(-5), mb_ok(500.5))   # True False True
```

## Decoradores: una primera mirada

Un **decorador** es una función que recibe una función y devuelve una versión mejorada. Se aplica con `@`:

```pyrun
import time


def cronometrar(funcion):
    def envoltura(*args, **kwargs):
        inicio = time.perf_counter()
        resultado = funcion(*args, **kwargs)
        print(f"{funcion.__name__} tardó {(time.perf_counter() - inicio) * 1000:.1f} ms")
        return resultado
    return envoltura


@cronometrar
def tarificar_lote(duraciones):
    return sum((d + 59) // 60 * 120 for d in duraciones)


print(tarificar_lote(list(range(200_000))))
```

`@cronometrar` es exactamente lo mismo que escribir `tarificar_lote = cronometrar(tarificar_lote)`. Verás decoradores en muchas librerías: `@dataclass` (módulo 9), `@pytest.fixture` (módulo 10), `@app.command()` (módulo 18).

:::reto Tu primer decorador
Escribe el decorador `nunca_negativo`: envuelve una función y, si el resultado es negativo, devuelve `0` en su lugar. Aplícalo con `@` a `saldo_a_cobrar`.

```pyreto
def nunca_negativo(funcion):
    pass


def saldo_a_cobrar(total, pagado):
    return total - pagado


print(saldo_a_cobrar(50000, 20000))   # 30000
print(saldo_a_cobrar(50000, 60000))   # 0 (no -10000)
```

:::pista
Igual que `cronometrar`: dentro define `def envoltura(*args, **kwargs):`, llama a `funcion(*args, **kwargs)`, y devuelve `max(0, resultado)`. Al final, `return envoltura`. Luego pon `@nunca_negativo` encima de `def saldo_a_cobrar`.
:::

```pyprueba
def prueba_decorador():
    """nunca_negativo convierte los negativos en 0"""
    requiere("nunca_negativo")
    doble = nunca_negativo(lambda x: x * 2)
    igual(doble(5), 10, "valor positivo")
    igual(doble(-5), 0, "valor negativo")


def prueba_aplicado():
    """saldo_a_cobrar está decorada"""
    requiere("saldo_a_cobrar")
    igual(saldo_a_cobrar(50000, 20000), 30000)
    igual(saldo_a_cobrar(50000, 60000), 0)
    assert "@nunca_negativo" in codigo, "Aplica el decorador con @nunca_negativo"
```

```pysolucion
def nunca_negativo(funcion):
    def envoltura(*args, **kwargs):
        resultado = funcion(*args, **kwargs)
        return max(0, resultado)
    return envoltura


@nunca_negativo
def saldo_a_cobrar(total, pagado):
    return total - pagado


print(saldo_a_cobrar(50000, 20000))   # 30000
print(saldo_a_cobrar(50000, 60000))   # 0 (no -10000)
```

## Cuestionario

? ¿Qué diferencia hay entre `f` y `f()`?
- [ ] Ninguna
- [x] `f` es la función como valor; `f()` la ejecuta y da su resultado
- [ ] `f()` es la función como valor; `f` la ejecuta
- [ ] `f` da error si la función no tiene parámetros
> Sin paréntesis te refieres a la función misma (para guardarla o pasarla); con paréntesis la llamas.

? ¿Qué devuelve `max(["VOZ", "DATOS", "SMS"], key=len)`?
- [ ] `"VOZ"`
- [x] `"DATOS"`
- [ ] `5`
- [ ] `"SMS"`
> `key=len` compara por longitud y `max` devuelve el elemento (no la longitud) con el mayor valor.

? En `nocturno = crear_tarificador(120, descuento=0.5)`, ¿qué es `nocturno`?
- [ ] Un número
- [x] Una función que recuerda la tarifa y el descuento
- [ ] Un diccionario
- [ ] `None`
> `crear_tarificador` devuelve la función interna `tarificar`, que conserva acceso a sus variables: es un closure.
