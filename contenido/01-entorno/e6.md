## Enunciado

En `ejercicios/m01-e6/reporte.py` hay un script con varios problemas de estilo **y un error escondido** que `ruff` puede detectar. Tu tarea:

1. Abre la carpeta del curso en VS Code y activa el entorno.
2. Ejecuta el script para ver qué hace: `python ejercicios/m01-e6/reporte.py`.
3. Revisa los problemas: `ruff check ejercicios/m01-e6/reporte.py`.
4. Lee cada mensaje. Corrige los que `ruff check --fix` no arregla solo. **No cambies lo que calcula el script.**
5. Formatea el archivo: `ruff format ejercicios/m01-e6/reporte.py`.
6. Comprueba: `python comprobar.py m01-e6`.

Las pruebas revisan que `ruff check` no encuentre ningún problema, que el archivo esté formateado y que las funciones `resumen_consumo` y `megas_a_gigas` sigan calculando lo mismo.

:::consejo Lee los códigos de ruff
Cada problema trae un código, por ejemplo `F401` o `N802`. Si no entiendes uno, búscalo con `ruff rule F401`: te explica qué significa y cómo arreglarlo.
:::

## Pista 1

Los códigos que vas a encontrar significan:

| Código | Significado |
|---|---|
| `F401` | Importaste algo que no usas. |
| `F841` | Creaste una variable que nunca usas. |
| `E711` | Comparaste con `None` usando `==` en vez de `is`. |
| `N802` / `N803` / `N806` | Nombres que no están en *snake_case*. |

`ruff check --fix` arregla solo los imports sin usar. Los nombres los debes cambiar tú… **también donde se usan**.

## Pista 2

Si cambias el nombre de una función, cámbialo también donde se llama. En VS Code, pon el cursor sobre el nombre y pulsa **F2** (*Rename Symbol*): lo renombra en todo el archivo.

Las pruebas importan las funciones `resumen_consumo` y `megas_a_gigas`: esos deben ser los nombres finales.

## Solución

```python reporte.py
"""Reporte rápido del consumo de una línea."""

GIGA = 1024


def megas_a_gigas(megas):
    return round(megas / GIGA, 2)


def resumen_consumo(linea, minutos, megas, plan=None):
    if plan is None:
        plan = "SIN PLAN"
    gigas = megas_a_gigas(megas)
    return f"Línea {linea} ({plan}): {minutos} min de voz y {gigas} GB de datos"


if __name__ == "__main__":
    print(resumen_consumo("3001234567", 342, 20480, "HOG30"))
    print(resumen_consumo("3109876543", 15, 512))
```

## Explicación

Lo que encontró `ruff` y por qué importa:

- **Imports y variables sin usar** (`F401`, `F841`): ensucian el código y a veces delatan un error (calculaste algo y olvidaste usarlo).
- **`== None`** (`E711`): `is None` es la forma correcta. Algunos objetos (como las columnas de Pandas) redefinen `==` y la comparación puede dar resultados sorprendentes.
- **Nombres** (`N802`, `N803`, `N806`): *snake_case* para funciones, parámetros y variables.
- **`if __name__ == "__main__":`**: el código de prueba queda protegido. Si otro archivo importa `reporte.py`, no se imprimen los ejemplos. Lo verás en el módulo 8.

Desde ahora, ejecuta `ruff check` sobre tu código antes de cada commit. En el módulo 20 lo automatizarás para que se ejecute solo.
