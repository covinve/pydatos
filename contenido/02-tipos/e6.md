## Enunciado

Para la sección de datos de la factura necesitas tres funciones:

1. `megas_facturables(mb)` → las megas consumidas **redondeadas hacia arriba** a un entero (`15.131` → `16`). Devuelve `int`.
2. `valor_datos(mb_consumidas, mb_incluidas, tarifa_mb)` → el valor a cobrar por exceso: `max(0, megas_facturables - mb_incluidas) × tarifa_mb`. Devuelve `int`.
3. `describir_consumo(mb)` → texto para el cliente en **gigas** (1 GB = 1024 MB) con dos decimales, **coma decimal** y **punto de miles**:

```python
megas_facturables(15.131)              # 16
valor_datos(15500.2, 15360, 18)        # 2538   → (15501 - 15360) × 18
valor_datos(800, 15360, 18)            # 0      → no hay exceso
describir_consumo(15728.64)            # "15,36 GB"
describir_consumo(1572864)             # "1.536,00 GB"
describir_consumo(0)                   # "0,00 GB"
```

## Pruebas

```python
def prueba_megas_redondea_hacia_arriba():
    """Cualquier fracción de mega se cobra como mega completa"""
    requiere("megas_facturables")
    igual(megas_facturables(15.131), 16)
    igual(megas_facturables(15.0), 15)
    igual(megas_facturables(0.001), 1)
    igual(megas_facturables(0), 0)


def prueba_megas_devuelve_int():
    """megas_facturables devuelve un int"""
    assert isinstance(megas_facturables(15.5), int), "Debe devolver int"


def prueba_valor_con_exceso():
    """Cobra solo las megas que exceden lo incluido"""
    requiere("valor_datos")
    igual(valor_datos(15500.2, 15360, 18), 2538)
    igual(valor_datos(5121, 5120, 22), 22)


def prueba_valor_sin_exceso():
    """Si no hay exceso, el valor es 0 (nunca negativo)"""
    igual(valor_datos(800, 15360, 18), 0)
    igual(valor_datos(15360, 15360, 18), 0)


def prueba_describir_gigas():
    """Convierte a GB con coma decimal"""

    igual(describir_consumo(15728.64), "15,36 GB")
```

## Pista 1

`math.ceil()` redondea hacia arriba y devuelve un `int`. Para el exceso, recuerda el patrón `max(0, consumo - incluido)`, que nunca es negativo:

```python
exceso = max(0, megas_facturables(mb_consumidas) - mb_incluidas)
```

## Pista 2

Para `describir_consumo`, `f"{gb:,.2f}"` produce `"1,536.00"`. Hay que intercambiar comas y puntos, y para eso se necesita un comodín intermedio:

```python
texto = f"{gb:,.2f}"
texto = texto.replace(",", "X").replace(".", ",").replace("X", ".")
```

## Solución

```python
import math

MB_POR_GB = 1024


def megas_facturables(mb):
    return math.ceil(mb)


def valor_datos(mb_consumidas, mb_incluidas, tarifa_mb):
    exceso = max(0, megas_facturables(mb_consumidas) - mb_incluidas)
    return exceso * tarifa_mb


def describir_consumo(mb):
    gigas = mb / MB_POR_GB
    texto = f"{gigas:,.2f}"
    texto = texto.replace(",", "X").replace(".", ",").replace("X", ".")
    return f"{texto} GB"


print(valor_datos(15500.2, 15360, 18))
print(describir_consumo(15728.64))
```

## Explicación

- **`math.ceil`** aplica la regla "cualquier fracción se cobra completa". Es la misma idea que `(segundos + 59) // 60` para los minutos, pero para valores con decimales.
- **`max(0, …)`** expresa "no hay cobro negativo" sin necesidad de un `if`.
- **El comodín `X`** evita que los reemplazos se pisen: si cambias directamente `,` por `.` y luego `.` por `,`, ambos terminan iguales.

¿Y los planes ilimitados (`mb_incluidos = -1`)? Con esta fórmula, un cliente ilimitado pagaría todo su consumo. En el módulo 3 agregarás esa regla con un `if`, que es justamente para lo que sirve.
