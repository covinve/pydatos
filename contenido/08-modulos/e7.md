## Enunciado

El paquete `ejercicios/m08-e7/tarifacion/` no se puede importar:

```powershell
cd ejercicios/m08-e7
python -c "import tarifacion"
```

```text
ImportError: cannot import name 'valor_llamada' from partially initialized module 'tarifacion.reglas'
(most likely due to a circular import)
```

`reglas.py` importa `formatear_pesos` de `reportes.py`, y `reportes.py` importa `valor_llamada` de `reglas.py`.

Arréglalo **reorganizando los módulos**, no escondiendo el problema:

- Crea `tarifacion/formato.py` con `formatear_pesos`.
- `reglas.py` y `reportes.py` importan `formatear_pesos` desde `formato`.
- `reglas.py` no importa `reportes`; `formato.py` no importa nada del paquete.
- No vale mover los `import` dentro de las funciones (las pruebas lo revisan).

El comportamiento de `reporte_linea` y `describir_cobro` no debe cambiar. Comprueba con `python comprobar.py m08-e7`.

## Pista 1

Dibuja las dependencias en un papel: una flecha de A a B si A importa de B. Hay un ciclo `reglas ⇄ reportes`. La función que causa el ciclo es `formatear_pesos`: no es ni una regla ni un reporte, es una utilidad de **formato** que ambos necesitan.

## Pista 2

Después del cambio, las flechas quedan así, sin ciclos:

```text
__init__ → reportes → reglas → formato
              └──────────────────┘
```

Mueve la función completa (con su anotación) a `formato.py` y bórrala de `reportes.py`; luego corrige los dos imports.

## Solución

```python tarifacion/formato.py
def formatear_pesos(valor: int) -> str:
    return "$" + f"{valor:,}".replace(",", ".")
```

```python tarifacion/reglas.py
from tarifacion.formato import formatear_pesos

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def valor_llamada(destino: str, segundos: int) -> int:
    return (segundos + 59) // 60 * TARIFAS[destino]


def describir_cobro(destino: str, segundos: int) -> str:
    return f"{destino.lower()} {segundos} s → {formatear_pesos(valor_llamada(destino, segundos))}"
```

```python tarifacion/reportes.py
from tarifacion.formato import formatear_pesos
from tarifacion.reglas import valor_llamada


def reporte_linea(linea: str, llamadas: list[tuple[str, int]]) -> str:
    total = sum(valor_llamada(destino, segundos) for destino, segundos in llamadas)
    return f"{linea}: {len(llamadas)} llamadas · {formatear_pesos(total)}"
```

## Explicación

¿Por qué Python no puede resolver el ciclo solo? Al hacer `import tarifacion`:

1. `__init__.py` empieza a importar `reportes`.
2. `reportes.py` (línea 1) empieza a importar `reglas`.
3. `reglas.py` (línea 1) pide `formatear_pesos` a `reportes`… que está **a medio cargar**: todavía no llegó a la línea donde se define la función.

Mover el `import` dentro de la función "funciona" porque retrasa la importación hasta que todo terminó de cargarse, pero **esconde un problema de diseño**: dos módulos que se necesitan mutuamente en realidad comparten algo que merece su propio lugar.

Las importaciones circulares casi siempre son una señal de que una responsabilidad está en el módulo equivocado. Crear el módulo `formato` deja la estructura en capas: utilidades abajo, reglas en el medio, reportes arriba.
