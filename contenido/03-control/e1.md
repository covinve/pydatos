## Enunciado

Un plan promocional tiene estas tarifas por minuto:

| Destino | Tarifa normal | Franja nocturna (22:00 a 05:59) |
|---|---|---|
| `LOCAL` | $100 | 50 % de descuento → $50 |
| `NACIONAL` | $120 | 50 % de descuento → $60 |
| `INTERNACIONAL` | $950 | Sin descuento → $950 |

Escribe:

1. `tarifa_minuto(destino, hora)` → la tarifa que aplica. `hora` es un entero de 0 a 23. Si el destino no existe o la hora está fuera de 0–23, devuelve `None`. El destino puede venir en minúsculas o con espacios (`" local "`).
2. `valor_llamada(destino, hora, segundos)` → `minutos facturables × tarifa`. Si la tarifa es `None`, devuelve `None`.

```python
tarifa_minuto("LOCAL", 14)          # 100
tarifa_minuto("NACIONAL", 23)       # 60
tarifa_minuto("INTERNACIONAL", 2)   # 950
tarifa_minuto(" local ", 5)         # 50
tarifa_minuto("SATELITAL", 10)      # None
tarifa_minuto("LOCAL", 24)          # None
valor_llamada("NACIONAL", 22, 125)  # 180   → 3 min × $60
```

## Pista 1

Organízalo en dos pasos: primero descarta lo inválido (hora fuera de rango), luego elige la tarifa base según el destino (con `if/elif` o `match`) y al final aplica el descuento si corresponde.

La franja nocturna es `hora >= 22 or hora < 6`.

## Pista 2

Normaliza el destino al inicio: `destino = destino.strip().upper()`. Una posible estructura:

```python
if hora < 0 or hora > 23:
    return None
if destino == "LOCAL":
    base = 100
elif ...:
    ...
else:
    return None
nocturna = hora >= 22 or hora < 6
if nocturna and destino != "INTERNACIONAL":
    return base // 2
return base
```

## Solución

```python
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def tarifa_minuto(destino, hora):
    destino = destino.strip().upper()
    if not 0 <= hora <= 23:
        return None
    match destino:
        case "LOCAL":
            base = 100
        case "NACIONAL":
            base = 120
        case "INTERNACIONAL":
            return 950
        case _:
            return None
    nocturna = hora >= 22 or hora < 6
    if nocturna:
        return base // 2
    return base


def valor_llamada(destino, hora, segundos):
    tarifa = tarifa_minuto(destino, hora)
    if tarifa is None:
        return None
    return (segundos + 59) // 60 * tarifa


print(tarifa_minuto("NACIONAL", 23))
print(valor_llamada("NACIONAL", 22, 125))
```

## Explicación

La solución aplica **salida temprana**: primero se descartan los casos inválidos con `return None`, y lo que queda es la regla normal.

El `case "INTERNACIONAL": return 950` sale de inmediato porque esa tarifa nunca tiene descuento. Así la regla nocturna solo se evalúa para local y nacional, sin necesidad de preguntar `destino != "INTERNACIONAL"`.

Fíjate en `if tarifa is None:` dentro de `valor_llamada`. Si escribieras `if not tarifa:`, una tarifa de $0 (posible en una promoción) se trataría como inválida. **Pregunta exactamente lo que quieres saber.**

La constante `TARIFAS` de la primera línea no se usa todavía: en el módulo 4 verás cómo un diccionario reemplaza todo el `match` por una sola consulta.
