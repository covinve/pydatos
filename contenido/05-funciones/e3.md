## Enunciado

Este código "funciona", pero nadie se atreve a reutilizarlo: depende de variables globales, modifica los CDR que recibe y su resultado cambia según cuántas veces se haya llamado antes.

```python
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
total_facturado = 0

def tarificar(cdr):
    global total_facturado
    minutos = (cdr["duracion"] + 59) // 60
    valor = minutos * TARIFAS[cdr["destino"]]
    cdr["valor"] = valor
    total_facturado += valor
    return valor
```

Reescríbelo con **tres funciones puras**, con anotaciones de tipo:

1. `valor_cdr(cdr: dict, tarifas: dict[str, int]) -> int` → el valor de un CDR.
2. `tarificar_cdrs(cdrs: list[dict], tarifas: dict[str, int]) -> list[dict]` → una lista **nueva** de copias de los CDR, cada una con la clave `"valor"`.
3. `total_facturado(cdrs_tarificados: list[dict]) -> int` → la suma de los valores.

Reglas: no uses `global`, no modifiques los argumentos y no leas `TARIFAS` desde dentro de las funciones (llega por parámetro).

## Código inicial

```python
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
total_facturado = 0


def tarificar(cdr):
    global total_facturado
    minutos = (cdr["duracion"] + 59) // 60
    valor = minutos * TARIFAS[cdr["destino"]]
    cdr["valor"] = valor
    total_facturado += valor
    return valor


cdrs = [{"destino": "LOCAL", "duracion": 125}, {"destino": "INTERNACIONAL", "duracion": 61}]
for c in cdrs:
    tarificar(c)
print(total_facturado)
```

## Pruebas

```python
import ast
import copy
import inspect

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
PROMO = {"LOCAL": 50, "NACIONAL": 60, "INTERNACIONAL": 900}
CDRS = [{"destino": "LOCAL", "duracion": 125}, {"destino": "INTERNACIONAL", "duracion": 61}, {"destino": "NACIONAL", "duracion": 0}]


def prueba_valor_cdr():
    """valor_cdr calcula el valor con las tarifas recibidas"""
    requiere("valor_cdr")
    igual(valor_cdr({"destino": "LOCAL", "duracion": 125}, TARIFAS), 300)
    igual(valor_cdr({"destino": "LOCAL", "duracion": 125}, PROMO), 150)


def prueba_tarificar_cdrs():
    """tarificar_cdrs devuelve copias con la clave valor"""
    requiere("tarificar_cdrs")
    resultado = tarificar_cdrs(CDRS, TARIFAS)
    igual([c["valor"] for c in resultado], [300, 1900, 0])
    igual(resultado[0]["destino"], "LOCAL")


def prueba_no_modifica_entradas():
    """Los CDR y las tarifas originales no cambian"""
    cdrs = copy.deepcopy(CDRS)
    tarifas = dict(TARIFAS)
    tarificar_cdrs(cdrs, tarifas)
    igual(cdrs, CDRS, "tarificar_cdrs modificó los CDR originales")
    igual(tarifas, TARIFAS, "tarificar_cdrs modificó las tarifas")


def prueba_total():
    """total_facturado suma los valores"""
    requiere("total_facturado")
    igual(total_facturado(tarificar_cdrs(CDRS, TARIFAS)), 2200)
    igual(total_facturado([]), 0)


def prueba_resultado_repetible():
    """Llamar dos veces da el mismo resultado (sin estado oculto)"""
    igual(total_facturado(tarificar_cdrs(CDRS, PROMO)), total_facturado(tarificar_cdrs(CDRS, PROMO)))


def prueba_sin_global():
    """No se usa global ni se lee TARIFAS dentro de las funciones"""
    arbol = ast.parse(codigo)
    assert not any(isinstance(n, ast.Global) for n in ast.walk(arbol)), "No uses `global`"
    for nodo in ast.walk(arbol):
        if isinstance(nodo, ast.FunctionDef):
            nombres = {n.id for n in ast.walk(nodo) if isinstance(n, ast.Name)}
            assert "TARIFAS" not in nombres, f"`{nodo.name}` lee TARIFAS: recíbelas por parámetro"


def prueba_anotaciones():
    """Las tres funciones tienen anotaciones de tipo"""
    for funcion in (valor_cdr, tarificar_cdrs, total_facturado):
        firma = inspect.signature(funcion)
        assert firma.return_annotation is not inspect.Signature.empty, f"Falta `-> ...` en {funcion.__name__}"
        for p in firma.parameters.values():
            assert p.annotation is not inspect.Parameter.empty, f"Falta anotar `{p.name}` en {funcion.__name__}"
```

## Pista 1

`valor_cdr` es casi la función original sin las líneas de efectos secundarios: ni `global`, ni `cdr["valor"] = ...`, ni `total_facturado +=`. Y en vez de `TARIFAS[...]` usa `tarifas[...]`, el parámetro.

## Pista 2

Para no modificar el CDR original, crea una copia con la clave nueva: `{**cdr, "valor": valor_cdr(cdr, tarifas)}`. Con una comprensión, `tarificar_cdrs` cabe en una línea. `total_facturado` es una suma con `sum(...)`.

## Solución

```python
TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}


def valor_cdr(cdr: dict, tarifas: dict[str, int]) -> int:
    minutos = (cdr["duracion"] + 59) // 60
    return minutos * tarifas[cdr["destino"]]


def tarificar_cdrs(cdrs: list[dict], tarifas: dict[str, int]) -> list[dict]:
    return [{**cdr, "valor": valor_cdr(cdr, tarifas)} for cdr in cdrs]


def total_facturado(cdrs_tarificados: list[dict]) -> int:
    return sum(cdr["valor"] for cdr in cdrs_tarificados)


cdrs = [{"destino": "LOCAL", "duracion": 125}, {"destino": "INTERNACIONAL", "duracion": 61}]
print(total_facturado(tarificar_cdrs(cdrs, TARIFAS)))
```

## Explicación

Las tres funciones juntas hacen lo mismo que el código original, pero ahora:

- **Se pueden probar por separado** con datos inventados, sin preparar ningún estado global.
- **Sirven para cualquier tabla de tarifas**: la vigente, una promoción, la del año pasado.
- **Son repetibles**: llamar dos veces da lo mismo. En el original, la segunda vez el total se duplicaba.
- **No hay sorpresas**: quien llama a `tarificar_cdrs` sabe que sus CDR siguen intactos.

El total ya no es una variable que "va creciendo" en algún lugar del programa: es el resultado de una función que puedes llamar cuando lo necesites.
