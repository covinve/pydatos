## Enunciado

En el Proyecto 1 validaste el archivo completo, pero el conjunto `vistos` con **todos** los IDs crecía con el archivo. Ahora vas a reescribir la validación como un **pipeline de generadores con memoria constante**.

Completa `resumir_cdr(ruta_cdr, ruta_clientes, ventana=5000)` en `ejercicios/m11-e7/pipeline.py`:

- Divide el proceso en **al menos tres etapas generadoras** (por ejemplo: leer → clasificar → acumular).
- Detecta los duplicados con la **ventana deslizante** del ejercicio 6.
- Aplica las demás reglas del curso (línea vacía, línea desconocida, tipo, duración negativa, fecha inválida).
- Devuelve las claves `registros_totales`, `registros_validos`, `errores`, `minutos_nacionales`, `minutos_internacionales`, `mb_totales` y `sms_totales`, con los mismos valores que `esperado.json`.

Las pruebas verifican el resultado y que el **pico de memoria** no pase de 8 MB con un archivo de 200.000 registros.

Después, pruébalo en grande y anota el tiempo y la memoria máxima (Administrador de tareas):

```powershell
python ejercicios/m11-e7/pipeline.py datos/1GB
```

## Pista 1

Una estructura posible:

```python
def lineas(ruta):                     # etapa 1: texto
    ...

def clasificados(filas, clientes, ventana):   # etapa 2: (motivo o None, campos)
    ...

def acumular(clasificados):           # etapa 3: consume y suma (no es generador)
    ...
```

El conjunto de líneas de clientes sí puede estar en memoria: crece con los clientes, no con los CDR.

## Pista 2

Para `errores`, inicia `{e: 0 for e in ERRORES}` así el diccionario tiene las seis claves en el mismo orden de `esperado.json`. Los minutos nacionales incluyen `LOCAL` y `NACIONAL`; los internacionales, `INTERNACIONAL`. Las megas se suman de los `DATOS` válidos y se redondean a 3 decimales al final.

## Solución

```python pipeline.py
"""Ejercicio m11-e7: pipeline de generadores con memoria constante.

Uso:
    python ejercicios/m11-e7/pipeline.py datos/1GB
"""

from __future__ import annotations

import csv
import sys
from collections import deque
from datetime import datetime
from pathlib import Path

ERRORES = ["duplicado", "duracion_negativa", "fecha_invalida", "linea_vacia", "linea_desconocida", "tipo_desconocido"]
TIPOS = {"VOZ", "SMS", "DATOS"}


def cargar_clientes(ruta: Path) -> set[str]:
    with open(ruta, encoding="latin-1", newline="") as archivo:
        return {fila["linea"] for fila in csv.DictReader(archivo)}


def filas(ruta: Path):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield linea.rstrip("\n").split("|")


def sin_duplicados(registros, ventana: int):
    """Entrega (es_duplicado, campos) recordando los últimos `ventana` IDs distintos."""
    recientes = deque(maxlen=ventana)
    vistos = set()
    for campos in registros:
        cdr_id = campos[0]
        if cdr_id in vistos:
            yield True, campos
            continue
        if len(recientes) == ventana:
            vistos.discard(recientes[0])
        recientes.append(cdr_id)
        vistos.add(cdr_id)
        yield False, campos


def fecha_ok(texto: str) -> bool:
    try:
        datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")
    except ValueError:
        return False
    return True


def clasificados(registros, clientes: set[str]):
    """Entrega (motivo, campos); motivo es None si el CDR es válido."""
    for duplicado, c in registros:
        if duplicado:
            motivo = "duplicado"
        elif not c[1]:
            motivo = "linea_vacia"
        elif c[1] not in clientes:
            motivo = "linea_desconocida"
        elif c[3] not in TIPOS:
            motivo = "tipo_desconocido"
        elif int(c[6]) < 0:
            motivo = "duracion_negativa"
        elif not fecha_ok(c[5]):
            motivo = "fecha_invalida"
        else:
            motivo = None
        yield motivo, c


def acumular(clasificacion) -> dict:
    errores = {e: 0 for e in ERRORES}
    total = min_nac = min_int = sms = 0
    mb = 0.0
    for motivo, c in clasificacion:
        total += 1
        if motivo:
            errores[motivo] += 1
        elif c[3] == "VOZ":
            minutos = (int(c[6]) + 59) // 60
            if c[4] == "INTERNACIONAL":
                min_int += minutos
            else:
                min_nac += minutos
        elif c[3] == "DATOS":
            mb += float(c[7])
        else:
            sms += 1
    return {
        "registros_totales": total,
        "registros_validos": total - sum(errores.values()),
        "errores": errores,
        "minutos_nacionales": min_nac,
        "minutos_internacionales": min_int,
        "mb_totales": round(mb, 3),
        "sms_totales": sms,
    }


def resumir_cdr(ruta_cdr: Path, ruta_clientes: Path, ventana: int = 5000) -> dict:
    clientes = cargar_clientes(ruta_clientes)
    return acumular(clasificados(sin_duplicados(filas(ruta_cdr), ventana), clientes))


if __name__ == "__main__":
    carpeta = Path(sys.argv[1]) if len(sys.argv) > 1 else Path(__file__).parent / "datos_prueba"
    print(resumir_cdr(carpeta / "cdr.csv", carpeta / "clientes.csv"))
```

## Explicación

Compara la memoria con el Proyecto 1 sobre el archivo de 1 GB (unos 14 millones de registros):

| Versión | Lo que crece con el archivo | Memoria aproximada |
|---|---|---|
| Proyecto 1 (`set` de todos los IDs) | Un ID por registro | ~1 GB |
| Pipeline con ventana | Nada | Unos pocos MB |

Con 20 GB, la primera versión necesitaría unos 15 GB y no correría en tu computador de la casa; esta corre igual, solo que tarda más.

Las etapas tienen responsabilidades claras: `filas` sabe leer, `sin_duplicados` sabe recordar, `clasificados` sabe las reglas, `acumular` sabe resumir. Cada una se puede probar con listas pequeñas.

¿Y la velocidad? Python puro procesa del orden de 0,5 a 1 millón de registros por segundo. En el módulo 12 verás cómo NumPy acelera los cálculos, y en el 16 cómo DuckDB y Polars hacen todo esto en una fracción del tiempo.
