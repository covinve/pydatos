`merge` combina dos tablas por una o más columnas clave, como un `JOIN` de SQL. Es el diccionario-índice del módulo 4, aplicado a tablas completas.

```pyrun
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
planes = pd.read_csv("planes.csv")

con_plan = clientes.merge(planes, on="plan_id", how="left", suffixes=("", "_plan"))
print(con_plan[["cliente_id", "plan_id", "cargo_fijo", "minutos_incluidos"]].head())
print(con_plan.columns.tolist())
```

`suffixes` resuelve columnas con el mismo nombre en ambas tablas (`segmento` existe en clientes y en planes).

:::reto El cargo fijo de cada cliente
1. Cruza `clientes` con `planes` por `plan_id` (sin perder clientes) en `con_plan`.
2. Crea `cargo_activos`: la suma del `cargo_fijo` de los clientes con `estado` `ACTIVO`.
3. Crea `por_segmento`: el cargo fijo total por `segmento` del **cliente** (una Series).

```pyreto
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
planes = pd.read_csv("planes.csv")

# con_plan, cargo_activos y por_segmento

print(cargo_activos)
```

:::pista
`clientes.merge(planes, on="plan_id", how="left", suffixes=("", "_plan"))`: con esos sufijos, el `segmento` del cliente conserva su nombre y el del plan queda como `segmento_plan`. Después filtra los activos y suma, y agrupa por `segmento`.
:::

```pyprueba
import pandas as pd


def _esperado():
    c = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
    p = pd.read_csv("planes.csv")
    return c.merge(p, on="plan_id", how="left", suffixes=("", "_plan"))


def prueba_cruce():
    """con_plan conserva todos los clientes"""
    requiere("con_plan")
    igual(len(con_plan), 40, "filas")
    assert "cargo_fijo" in con_plan.columns, "con_plan debe tener el cargo_fijo del plan"


def prueba_activos():
    """cargo_activos suma los activos"""
    requiere("cargo_activos")
    e = _esperado()
    igual(int(cargo_activos), int(e.loc[e["estado"] == "ACTIVO", "cargo_fijo"].sum()))


def prueba_segmento():
    """por_segmento suma por segmento del cliente"""
    requiere("por_segmento")
    e = _esperado()
    igual({str(k): int(v) for k, v in por_segmento.items()}, {str(k): int(v) for k, v in e.groupby("segmento")["cargo_fijo"].sum().items()})
```

## Tipos de cruce

| `how=` | Conserva | Uso típico |
|---|---|---|
| `"inner"` | Solo las claves que están en **ambas** tablas | Consumo de clientes conocidos |
| `"left"` | **Todas** las filas de la izquierda | Enriquecer CDR con datos del cliente |
| `"right"` | Todas las de la derecha | (poco usado: invierte las tablas y usa `left`) |
| `"outer"` | Todas, de ambas | Conciliación: ver lo que falta en cada lado |

:::pasos Cómo cambia el resultado según how
:::paso Las dos tablas
| consumo.linea | minutos |
|---|---|
| 3001 | 342 |
| 3002 | 15 |
| 3999 | 60 |

| clientes.linea | plan |
|---|---|
| 3001 | HOG30 |
| 3002 | ILIM |
| 3003 | BAS10 |
:::
:::paso inner: solo lo que coincide
| linea | minutos | plan |
|---|---|---|
| 3001 | 342 | HOG30 |
| 3002 | 15 | ILIM |

La línea 3999 (sin cliente) y el cliente 3003 (sin consumo) desaparecen **sin aviso**.
:::
:::paso left: todo el consumo
| linea | minutos | plan |
|---|---|---|
| 3001 | 342 | HOG30 |
| 3002 | 15 | ILIM |
| 3999 | 60 | *NaN* |

El consumo de la línea desconocida se conserva, con el plan faltante.
:::
:::paso outer + indicator: la vista de auditoría
| linea | minutos | plan | _merge |
|---|---|---|---|
| 3001 | 342 | HOG30 | both |
| 3002 | 15 | ILIM | both |
| 3999 | 60 | *NaN* | left_only |
| 3003 | *NaN* | BAS10 | right_only |

`indicator=True` agrega la columna `_merge`, que dice de dónde vino cada fila. Es la base de cualquier conciliación.
:::
:::

```pyrun
import pandas as pd

consumo = pd.DataFrame({"linea": ["3001", "3002", "3999"], "minutos": [342, 15, 60]})
clientes = pd.DataFrame({"linea": ["3001", "3002", "3003"], "plan": ["HOG30", "ILIM", "BAS10"]})

auditoria = consumo.merge(clientes, on="linea", how="outer", indicator=True)
print(auditoria)
print(auditoria["_merge"].value_counts())
```

:::reto Concilia facturado contra calculado
Tienes lo que **debió** cobrarse a cada línea (`calculado`) y lo que **se cobró** (`facturado`). Con un `merge` `outer` e `indicator`:

- `sin_factura`: la lista ordenada de líneas calculadas que no se facturaron;
- `facturadas_de_mas`: la lista ordenada de líneas facturadas que no estaban en el cálculo;
- `diferencias`: la lista ordenada de líneas que están en ambas pero con **total distinto**.

```pyreto
import pandas as pd

calculado = pd.DataFrame({"linea": ["3001", "3002", "3003", "3004"], "total": [48719, 106981, 42721, 66521]})
facturado = pd.DataFrame({"linea": ["3001", "3002", "3004", "3999"], "total": [48719, 107000, 66521, 23860]})

# Cruza y crea sin_factura, facturadas_de_mas y diferencias

print(sin_factura, facturadas_de_mas, diferencias)
```

:::pista
`calculado.merge(facturado, on="linea", how="outer", suffixes=("_calc", "_fact"), indicator=True)`. Filtra por `_merge == "left_only"`, `"right_only"` y, entre las `"both"`, las que tienen `total_calc != total_fact`.
:::

```pyprueba
def prueba_lados():
    """Lo que falta en cada lado"""
    requiere("sin_factura", "facturadas_de_mas")
    igual([str(x) for x in sin_factura], ["3003"], "sin_factura")
    igual([str(x) for x in facturadas_de_mas], ["3999"], "facturadas_de_mas")


def prueba_diferencias():
    """Las que no cuadran"""
    requiere("diferencias")
    igual([str(x) for x in diferencias], ["3002"])


def prueba_indicator():
    """Usa indicator"""
    assert "indicator=True" in codigo.replace(" ", ""), "Agrega indicator=True al merge"
```

```pysolucion
import pandas as pd

calculado = pd.DataFrame({"linea": ["3001", "3002", "3003", "3004"], "total": [48719, 106981, 42721, 66521]})
facturado = pd.DataFrame({"linea": ["3001", "3002", "3004", "3999"], "total": [48719, 107000, 66521, 23860]})

cruce = calculado.merge(facturado, on="linea", how="outer", suffixes=("_calc", "_fact"), indicator=True)
sin_factura = sorted(cruce.loc[cruce["_merge"] == "left_only", "linea"].tolist())
facturadas_de_mas = sorted(cruce.loc[cruce["_merge"] == "right_only", "linea"].tolist())
ambas = cruce[cruce["_merge"] == "both"]
diferencias = sorted(ambas.loc[ambas["total_calc"] != ambas["total_fact"], "linea"].tolist())

print(sin_factura, facturadas_de_mas, diferencias)
```

## El peligro: duplicar filas sin querer

Si la clave se repite en ambas tablas, `merge` genera **todas las combinaciones**: 3 filas × 2 filas = 6 filas. Cuando esperabas una relación "muchos a uno" (muchos CDR, un cliente), un cliente duplicado en el maestro duplica su consumo y la facturación.

```pyrun
import pandas as pd

cdr = pd.DataFrame({"linea": ["3001", "3001", "3001"], "minutos": [3, 2, 1]})
clientes = pd.DataFrame({"linea": ["3001", "3001"], "plan": ["HOG30", "HOG30"]})   # cliente repetido por error

cruce = cdr.merge(clientes, on="linea")
print(len(cdr), "→", len(cruce), "filas; minutos:", cdr["minutos"].sum(), "→", cruce["minutos"].sum())

try:
    cdr.merge(clientes, on="linea", validate="many_to_one")
except Exception as error:
    print("validate lo detecta:", type(error).__name__)
```

:::error Usa validate en los cruces importantes
`validate="many_to_one"` (o `"one_to_one"`) hace que `merge` falle si la tabla de la derecha tiene claves repetidas. Es una línea que evita errores de facturación muy caros.
:::

:::reto Un cruce que se protege
El maestro de clientes llegó con una línea repetida. Escribe `cruzar(cdr, maestro)`:

1. Intenta el `merge` con `validate="many_to_one"`.
2. Si falla por claves repetidas (`pandas.errors.MergeError`), quita los duplicados del maestro por `linea` (conservando el primero) y vuelve a cruzar.

El resultado debe tener **las mismas filas que `cdr`**: ni una más.

```pyreto
import pandas as pd

cdr = pd.DataFrame({"linea": ["3001", "3001", "3002", "3001"], "minutos": [3, 2, 7, 1]})
maestro = pd.DataFrame({"linea": ["3001", "3002", "3001"], "plan": ["HOG30", "ILIM", "HOG30"]})


def cruzar(cdr, maestro):
    return cdr.merge(maestro, on="linea", how="left")


resultado = cruzar(cdr, maestro)
print(len(cdr), "→", len(resultado), "filas")
```

:::pista
`try: return cdr.merge(maestro, on="linea", how="left", validate="many_to_one")` y `except pd.errors.MergeError:` con el mismo cruce sobre `maestro.drop_duplicates("linea")`.
:::

```pyprueba
import pandas as pd


def prueba_sin_duplicar():
    """El cruce no duplica filas"""
    requiere("cruzar")
    cdr_ = pd.DataFrame({"linea": ["3001", "3001", "3002", "3001"], "minutos": [3, 2, 7, 1]})
    maestro_ = pd.DataFrame({"linea": ["3001", "3002", "3001"], "plan": ["HOG30", "ILIM", "HOG30"]})
    r = cruzar(cdr_, maestro_)
    igual(len(r), 4, "filas")
    igual(int(r["minutos"].sum()), 13, "minutos totales")
    igual(r["plan"].tolist(), ["HOG30", "HOG30", "ILIM", "HOG30"], "plan de cada CDR")


def prueba_maestro_limpio():
    """Con un maestro sin repetidos, cruza normal"""
    cdr_ = pd.DataFrame({"linea": ["3001", "3002"], "minutos": [1, 2]})
    maestro_ = pd.DataFrame({"linea": ["3001", "3002"], "plan": ["A", "B"]})
    igual(cruzar(cdr_, maestro_)["plan"].tolist(), ["A", "B"])


def prueba_usa_validate():
    """Usa validate"""
    assert "validate=" in codigo, "Protege el cruce con validate='many_to_one'"
```

```pysolucion
import pandas as pd

cdr = pd.DataFrame({"linea": ["3001", "3001", "3002", "3001"], "minutos": [3, 2, 7, 1]})
maestro = pd.DataFrame({"linea": ["3001", "3002", "3001"], "plan": ["HOG30", "ILIM", "HOG30"]})


def cruzar(cdr, maestro):
    try:
        return cdr.merge(maestro, on="linea", how="left", validate="many_to_one")
    except pd.errors.MergeError:
        return cdr.merge(maestro.drop_duplicates("linea"), on="linea", how="left")


resultado = cruzar(cdr, maestro)
print(len(cdr), "→", len(resultado), "filas")
```

## Claves de tipos distintos

Si una tabla tiene `linea` como texto y la otra como número, `merge` no encuentra coincidencias (o da error). Por eso desde el módulo 13 lees los identificadores **siempre como texto**.

## concat: apilar tablas

```pyrun
import pandas as pd

septiembre = pd.DataFrame({"linea": ["3001", "3002"], "total": [48719, 106981]})
octubre = pd.DataFrame({"linea": ["3001", "3003"], "total": [51200, 23860]})

historico = pd.concat([septiembre.assign(periodo="202609"), octubre.assign(periodo="202610")], ignore_index=True)
print(historico)
```

Úsalo para unir archivos con las mismas columnas (por ejemplo, los CDR de varios días).

:::reto El histórico de tres meses
Apila las facturas de los tres meses en `historico`, con una columna `periodo` que diga de qué mes viene cada fila y un índice continuo (0, 1, 2…). Después crea `total_por_periodo`: el total facturado de cada periodo (una Series).

```pyreto
import pandas as pd

julio = pd.DataFrame({"linea": ["3001", "3002"], "total": [48719, 106981]})
agosto = pd.DataFrame({"linea": ["3001", "3002", "3003"], "total": [50120, 98000, 23860]})
septiembre = pd.DataFrame({"linea": ["3001", "3003"], "total": [51200, 24100]})

# historico y total_por_periodo

print(historico)
print(total_por_periodo)
```

:::pista
`pd.concat([julio.assign(periodo="202607"), agosto.assign(periodo="202608"), septiembre.assign(periodo="202609")], ignore_index=True)`. Luego agrupa por `periodo` y suma `total`.
:::

```pyprueba
def prueba_historico():
    """historico apila los tres meses con su periodo"""
    requiere("historico")
    igual(len(historico), 7, "filas")
    igual(list(historico.index), list(range(7)), "índice continuo (ignore_index=True)")
    igual(historico["periodo"].tolist(), ["202607"] * 2 + ["202608"] * 3 + ["202609"] * 2, "periodo")


def prueba_totales():
    """total_por_periodo"""
    requiere("total_por_periodo")
    igual({str(k): int(v) for k, v in total_por_periodo.items()}, {"202607": 155700, "202608": 171980, "202609": 75300})
```

```pysolucion
import pandas as pd

julio = pd.DataFrame({"linea": ["3001", "3002"], "total": [48719, 106981]})
agosto = pd.DataFrame({"linea": ["3001", "3002", "3003"], "total": [50120, 98000, 23860]})
septiembre = pd.DataFrame({"linea": ["3001", "3003"], "total": [51200, 24100]})

historico = pd.concat(
    [julio.assign(periodo="202607"), agosto.assign(periodo="202608"), septiembre.assign(periodo="202609")],
    ignore_index=True,
)
total_por_periodo = historico.groupby("periodo")["total"].sum()

print(historico)
print(total_por_periodo)
```

## Cuestionario

? Cruzas CDR (izquierda) con clientes usando `how="inner"`. ¿Qué pasa con los CDR de líneas desconocidas?
- [ ] Quedan con el cliente faltante
- [x] Desaparecen del resultado sin aviso
- [ ] Se produce un error
- [ ] Se duplican
> `inner` conserva solo las claves presentes en ambas tablas. Para no perderlos, usa `left`.

? ¿Para qué sirve `indicator=True`?
- [ ] Para acelerar el cruce
- [x] Para agregar una columna que dice si cada fila vino de ambas tablas, solo de la izquierda o solo de la derecha
- [ ] Para quitar duplicados
- [ ] Para ordenar
> Es fundamental en conciliaciones: muestra lo que falta en cada lado.

? Un cliente aparece dos veces en el maestro. ¿Qué pasa al cruzar sus 100 CDR con `merge`?
- [ ] Nada
- [ ] Error automático
- [x] El resultado tiene 200 filas: su consumo queda duplicado
- [ ] Se usa el primero
> `merge` genera todas las combinaciones. `validate="many_to_one"` convierte ese error silencioso en uno visible.
