## Máscaras booleanas

Una comparación sobre un array devuelve un array de `True`/`False`: una **máscara**. Con ella puedes filtrar, contar o modificar.

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600, 45])

contestadas = duraciones > 0
print(contestadas)
print(duraciones[contestadas])       # filtra
print(contestadas.sum())             # cuenta los True
print(contestadas.mean())            # proporción de True
```

Combina condiciones con `&` (y), `|` (o) y `~` (no), **siempre con paréntesis**:

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600, 45])
tipos = np.array(["VOZ", "SMS", "VOZ", "VOZ", "DATOS", "VOZ"])

voz_validas = (tipos == "VOZ") & (duraciones >= 0)
print(duraciones[voz_validas])
print(((duraciones + 59) // 60)[voz_validas].sum())
print(np.count_nonzero((tipos == "SMS") | (tipos == "DATOS")))
```

:::error and / or no funcionan con arrays
`(tipos == "VOZ") and (duraciones >= 0)` da `ValueError: The truth value of an array... is ambiguous`. Con arrays usa `&`, `|`, `~` y pon paréntesis a cada comparación (sin paréntesis, `&` se evalúa antes que `==`).
:::

## np.isin: pertenencia vectorizada

```pyrun
import numpy as np

tipos = np.array(["VOZ", "VOX", "DATOS", "MMS", "SMS"])
validos = np.isin(tipos, ["VOZ", "SMS", "DATOS"])
print(validos)
print(tipos[~validos])     # los inválidos
```

## np.where: el if vectorizado

`np.where(condicion, si_verdadero, si_falso)` elige elemento a elemento:

```pyrun
import numpy as np

minutos = np.array([342, 100, 0, 5000])
incluidos = np.array([300, 300, 300, -1])

exceso = np.where(incluidos == -1, 0, np.maximum(minutos - incluidos, 0))
print(exceso)
```

Sin argumentos de valor, `np.where(mascara)` devuelve las **posiciones** donde la máscara es verdadera:

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600])
print(np.where(duraciones < 0)[0])     # posiciones de las duraciones negativas
```

## np.select: varios casos (el elif vectorizado)

```pyrun
import numpy as np

destinos = np.array(["LOCAL", "NACIONAL", "INTERNACIONAL", "LOCAL", "SATELITAL"])
condiciones = [destinos == "LOCAL", destinos == "NACIONAL", destinos == "INTERNACIONAL"]
tarifas = [100, 120, 950]

print(np.select(condiciones, tarifas, default=0))
```

Se evalúan en orden: el primer caso verdadero gana, igual que en `if/elif/else`.

## Modificar con máscaras

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, -30, 3600])
limpias = duraciones.copy()
limpias[limpias < 0] = 0          # reemplaza los negativos
print(limpias)
print(np.clip(duraciones, 0, 3600))   # recorta a un rango
```

:::capo Copias y vistas
Cortar un array (`a[1:3]`) devuelve una **vista**: comparte la memoria con el original, y modificarla modifica el original. Filtrar con una máscara (`a[a > 0]`) devuelve una **copia**. Ante la duda, usa `.copy()` antes de modificar.
:::

:::telco Tarificación sin bucles
Con `np.select` para la tarifa por destino, `np.where` para el plan ilimitado y una máscara para los registros válidos, la tarificación completa de millones de CDR son tres o cuatro líneas que corren en milisegundos.
:::

## Cuestionario

? ¿Qué devuelve `(np.array([5, -1, 3]) > 0).sum()`?
- [ ] `7`
- [x] `2`
- [ ] `[True, False, True]`
- [ ] Un error
> La máscara tiene dos `True`, y al sumar booleanos cada `True` vale 1.

? ¿Cómo combinas dos condiciones sobre arrays?
- [ ] `(a > 0) and (b == "VOZ")`
- [x] `(a > 0) & (b == "VOZ")`
- [ ] `a > 0 & b == "VOZ"`
- [ ] `(a > 0) + (b == "VOZ")`
> Con arrays se usa `&` y cada comparación entre paréntesis.

? ¿Qué hace `np.select(condiciones, valores, default=0)`?
- [ ] Ordena los valores
- [x] Para cada elemento, devuelve el valor de la primera condición verdadera, o el default
- [ ] Devuelve las posiciones verdaderas
- [ ] Suma los valores
> Es el equivalente vectorizado de una cadena `if/elif/else`.
