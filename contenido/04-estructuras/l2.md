Una **tupla** es como una lista que **no se puede modificar**. Se escribe con paréntesis:

```pyrun
registro = (2, "3302703263", "VOZ", 30)
print(registro[2])
print(len(registro))
```

```pyrun
registro = (2, "3302703263", "VOZ", 30)
registro[3] = 60     # error esperado
```

## ¿Para qué sirve algo que no se puede cambiar?

- **Expresa intención**: una tupla dice "esto es un registro fijo de campos", una lista dice "esto es una colección que puede crecer".
- **Seguridad**: nadie puede modificarla por accidente (adiós a la trampa de las referencias).
- **Puede ser clave de un diccionario** o elemento de un conjunto (las listas no pueden).

| Usa una lista cuando… | Usa una tupla cuando… |
|---|---|
| Los elementos son del **mismo tipo** y la cantidad varía | Cada posición tiene un **significado distinto** |
| Vas a agregar o quitar elementos | El registro no debe cambiar |
| `duraciones = [125, 0, 61]` | `posicion = ("VOZ", 36, 40)` |

## Desempaquetado

Puedes repartir los elementos de una tupla (o lista) en varias variables de una vez:

```pyrun
registro = (2, "3302703263", "VOZ", 30)

cdr_id, linea, tipo, duracion = registro
print(linea, tipo)

# _ significa "no me interesa este valor"
_, linea, _, duracion = registro
print(linea, duracion)

# * recoge "el resto"
cdr_id, *demas = registro
print(cdr_id, demas)
```

:::reto Desempaqueta el registro
Del registro de abajo, usando **desempaquetado** (sin índices como `registro[2]`):

- crea `linea`, `tipo` y `mb`, ignorando con `_` lo que no necesitas;
- crea `cdr_id` y `resto`, donde `resto` recoge todo lo demás con `*`.

```pyreto
registro = (7, "3157778899", "DATOS", 0, 230.5)

# 1. linea, tipo y mb (usa _ para lo que sobra)

# 2. cdr_id y resto

print(linea, tipo, mb)
print(cdr_id, resto)
```

:::pista
Debe haber tantas variables como elementos: `_, linea, tipo, _, mb = registro`. Para el resto: `cdr_id, *resto = registro`.
:::

```pyprueba
def prueba_campos():
    """linea, tipo y mb correctos"""
    requiere("linea", "tipo", "mb")
    igual(linea, "3157778899", "linea")
    igual(tipo, "DATOS", "tipo")
    igual(mb, 230.5, "mb")


def prueba_resto():
    """cdr_id = 7 y resto con los demás campos"""
    requiere("cdr_id", "resto")
    igual(cdr_id, 7, "cdr_id")
    igual(resto, ["3157778899", "DATOS", 0, 230.5], "resto")


def prueba_sin_indices():
    """Usa desempaquetado, no índices"""
    assert "registro[" not in codigo, "Resuélvelo con desempaquetado, sin registro[...]"
```

```pysolucion
registro = (7, "3157778899", "DATOS", 0, 230.5)

_, linea, tipo, _, mb = registro
cdr_id, *resto = registro

print(linea, tipo, mb)
print(cdr_id, resto)
```
:::

El caso más famoso: intercambiar dos variables sin auxiliar.

```pyrun
a, b = 10, 20
a, b = b, a
print(a, b)
```

## Devolver varios valores

Una función puede devolver una tupla, y quien la llama la desempaqueta:

```pyrun
def separar_duracion(segundos):
    minutos = segundos // 60
    resto = segundos % 60
    return minutos, resto        # devuelve la tupla (minutos, resto)


m, s = separar_duracion(125)
print(f"{m} min {s} s")
```

## Recorrer pares

El desempaquetado brilla dentro de un `for`:

```pyrun
consumos = [("3001234567", 342), ("3109876543", 15), ("3157778899", 1203)]

for linea, minutos in consumos:
    print(f"{linea} habló {minutos} min")
```

`for linea, minutos in consumos:` acumula el total y guarda el máximo hasta ahora (patrón del módulo 3). Al final, `return total, linea_top`.

```pyprueba
def prueba_devuelve_dos():
    """Devuelve dos valores (una tupla)"""
    requiere("resumen")
    r = resumen([("3001", 10), ("3002", 20)])
    assert isinstance(r, tuple) and len(r) == 2, f"Debe devolver dos valores separados por coma, devolvió {r!r}"


def prueba_valores():
    """Total de minutos y línea top"""
    igual(resumen([("3001234567", 342), ("3109876543", 15), ("3157778899", 1203)]), (1560, "3157778899"))
    igual(resumen([("A", 5)]), (5, "A"))
```

```pysolucion
def resumen(consumos):
    total = 0
    linea_top = None
    mas_minutos = -1
    for linea, minutos in consumos:
        total += minutos
        if minutos > mas_minutos:
            mas_minutos = minutos
            linea_top = linea
    return total, linea_top


consumos = [("3001234567", 342), ("3109876543", 15), ("3157778899", 1203)]
total, top = resumen(consumos)
print(total, top)   # 1560 3157778899
```

## namedtuple: tuplas con nombres

Acceder por posición (`registro[2]`) obliga a recordar qué hay en cada lugar. `namedtuple` le pone nombre a cada campo y sigue siendo una tupla:

```pyrun
from collections import namedtuple

CDR = namedtuple("CDR", ["cdr_id", "linea", "tipo", "duracion"])

c = CDR(2, "3302703263", "VOZ", 30)
print(c.tipo, c.duracion)
print(c)

cdr_id, linea, tipo, duracion = c   # se puede desempaquetar igual
```

:::reto El plan con nombres
1. Crea con `namedtuple` el tipo `Plan`, con los campos `plan_id`, `cargo_fijo` y `minutos_incluidos`.
2. Crea `hog30` con los valores `"HOG30"`, `52900` y `300`.
3. Escribe `exceso(plan, minutos)` que devuelva los minutos por encima de los incluidos (nunca negativo), leyendo el campo **por su nombre**.

```pyreto
from collections import namedtuple

# 1. Plan
# 2. hog30
# 3. exceso(plan, minutos)

print(hog30)
print(exceso(hog30, 342))   # 42
```

:::pista
`Plan = namedtuple("Plan", ["plan_id", "cargo_fijo", "minutos_incluidos"])`. Dentro de `exceso`, usa `plan.minutos_incluidos` en vez de `plan[2]`.
:::

```pyprueba
def prueba_plan():
    """Plan tiene los tres campos pedidos"""
    requiere("Plan")
    igual(Plan._fields, ("plan_id", "cargo_fijo", "minutos_incluidos"))


def prueba_hog30():
    """hog30 tiene los valores del plan"""
    requiere("hog30")
    igual(hog30.plan_id, "HOG30", "plan_id")
    igual(hog30.cargo_fijo, 52900, "cargo_fijo")
    igual(hog30.minutos_incluidos, 300, "minutos_incluidos")


def prueba_exceso():
    """exceso usa los minutos incluidos del plan"""
    requiere("exceso")
    igual(exceso(hog30, 342), 42)
    igual(exceso(hog30, 100), 0)
    igual(exceso(Plan("X", 0, 1000), 1500), 500)


def prueba_por_nombre():
    """Lee el campo por su nombre"""
    assert ".minutos_incluidos" in codigo, "Dentro de exceso usa plan.minutos_incluidos"
```

```pysolucion
from collections import namedtuple

Plan = namedtuple("Plan", ["plan_id", "cargo_fijo", "minutos_incluidos"])
hog30 = Plan("HOG30", 52900, 300)


def exceso(plan, minutos):
    return max(0, minutos - plan.minutos_incluidos)


print(hog30)
print(exceso(hog30, 342))   # 42
```

## Cuestionario

? ¿Cuál de estas estructuras puede usarse como clave de un diccionario?
- [ ] `[2026, 9]`
- [x] `(2026, 9)`
- [ ] `{2026, 9}`
- [ ] Ninguna
> Las claves deben ser inmutables. Las tuplas lo son; las listas y los conjuntos no.

? Después de `a, *b = (1, 2, 3, 4)`, ¿qué vale `b`?
- [ ] `2`
- [ ] `(2, 3, 4)`
- [x] `[2, 3, 4]`
- [ ] `4`
> El asterisco recoge todos los elementos restantes en una lista.

? ¿Qué devuelve `def f(): return 1, 2`?
- [ ] Solo `1`
- [ ] Un error
- [x] La tupla `(1, 2)`
- [ ] La lista `[1, 2]`
> Separar valores con comas en un `return` crea una tupla.
