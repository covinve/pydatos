Un archivo de CDR tiene millones de registros, pero la lógica para procesar uno es la misma que para procesarlos todos. Los bucles repiten un bloque de código para cada elemento.

## for: un elemento a la vez

```pyrun
duraciones = [125, 0, 61, 3600, 45]

for duracion in duraciones:
    minutos = (duracion + 59) // 60
    print(f"{duracion:>5} s → {minutos} min")

print("Listo")
```

En cada vuelta (*iteración*), la variable `duracion` toma el siguiente valor de la lista. El bloque con sangría se repite; lo que está fuera (`print("Listo")`) se ejecuta una sola vez, al final.

```pytrace
duraciones = [125, 0, 61]
total_minutos = 0
for duracion in duraciones:
    minutos = (duracion + 59) // 60
    total_minutos = total_minutos + minutos
print(total_minutos)
```

## ¿Qué se puede recorrer?

Cualquier cosa **iterable**: listas, textos, rangos, archivos (módulo 6), diccionarios (módulo 4)…

```pyrun
for caracter in "VOZ":
    print(caracter)

for numero in range(3):
    print("vuelta", numero)
```

## range: secuencias de números

| Expresión | Genera |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 24, 6)` | 0, 6, 12, 18 |
| `range(10, 0, -3)` | 10, 7, 4, 1 |

Igual que el slicing: incluye el inicio y **no** incluye el final.

```pyrun
# Las 4 franjas horarias de 6 horas
for hora_inicio in range(0, 24, 6):
    print(f"{hora_inicio:02d}:00 a {hora_inicio + 5:02d}:59")
```

## enumerate: el elemento y su posición

Cuando necesitas saber en qué posición vas, no uses `range(len(...))`. Usa `enumerate`:

:::comparar
:::mal Estilo de otros lenguajes
```python
for i in range(len(lineas)):
    print(i, lineas[i])
```
:::
:::bien Estilo Python
```python
for i, linea in enumerate(lineas):
    print(i, linea)
```
:::
:::

```pyrun
registros = ["1|VOZ|125", "2|SMS|0", "3|VOX|45"]

for numero, registro in enumerate(registros, start=1):
    tipo = registro.split("|")[1]
    if tipo not in ("VOZ", "SMS", "DATOS"):
        print(f"Línea {numero}: tipo desconocido '{tipo}'")
```

`start=1` hace que la numeración empiece en 1, como las líneas de un archivo. Así tus mensajes de error coinciden con lo que ve una persona al abrir el archivo.

## Recorrer dos listas a la vez: zip

```pyrun
lineas = ["3001234567", "3109876543", "3157778899"]
minutos = [342, 15, 1203]

for linea, mins in zip(lineas, minutos):
    print(f"{linea}: {mins} min")
```

`zip` empareja los elementos por posición y se detiene cuando se acaba la lista más corta.

## Bucles anidados

Un bucle dentro de otro recorre todas las combinaciones:

```pyrun
planes = ["HOG30", "HOG60"]
destinos = ["LOCAL", "INTERNACIONAL"]

for plan in planes:
    for destino in destinos:
        print(plan, destino)
```

:::capo Cuidado con el costo
Si cada lista tiene 1.000 elementos, el bucle interno se ejecuta 1.000 × 1.000 = **un millón** de veces. Con un archivo de 10 millones de CDR contra 400.000 clientes, un bucle anidado tardaría días. En el módulo 4 aprenderás a resolverlo con diccionarios en segundos.
:::
