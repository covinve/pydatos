`groupby` sigue tres pasos: **dividir** la tabla en grupos, **aplicar** una función a cada grupo y **combinar** los resultados. Es el `GROUP BY` de SQL y el patrón "agrupar" del módulo 4, ahora vectorizado.

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
validos = cdr[cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (cdr["duracion_seg"] >= 0)].copy()
validos["minutos"] = (validos["duracion_seg"] + 59) // 60

print(validos.groupby("tipo").size())                         # registros por tipo
print(validos.groupby("tipo")["duracion_seg"].mean().round(1))
print(validos.groupby(["linea_origen", "tipo"]).size().head(6))
```

## Agregaciones con nombre

La forma más clara de pedir varias métricas: `agg` con pares `nombre=(columna, funcion)`:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].copy()
voz["minutos"] = (voz["duracion_seg"] + 59) // 60

por_linea = voz.groupby("linea_origen").agg(
    llamadas=("cdr_id", "size"),
    minutos=("minutos", "sum"),
    promedio_seg=("duracion_seg", "mean"),
    mas_larga=("duracion_seg", "max"),
    destinos=("destino", "nunique"),
)
print(por_linea.sort_values("minutos", ascending=False).head())
```

| Función | Calcula |
|---|---|
| `"size"` | Filas del grupo (incluye faltantes) |
| `"count"` | Valores **no faltantes** de la columna |
| `"sum"`, `"mean"`, `"median"`, `"min"`, `"max"`, `"std"` | Lo de siempre |
| `"nunique"` | Valores distintos |
| `"first"`, `"last"` | Primer y último valor del grupo |

:::consejo reset_index
El resultado de un `groupby` usa las columnas de agrupación como índice. Agrega `.reset_index()` (o `as_index=False`) para tenerlas como columnas normales, por ejemplo antes de un `merge` o de guardar en CSV.
:::

:::reto El consumo de datos de cada línea

## transform: un resultado por fila

`agg` devuelve **una fila por grupo**. `transform` devuelve un valor **por cada fila original**, alineado con ella. Sirve para comparar cada registro con su grupo:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0)].copy()

voz["total_linea"] = voz.groupby("linea_origen")["duracion_seg"].transform("sum")
voz["participacion"] = (voz["duracion_seg"] / voz["total_linea"] * 100).round(1)
voz["promedio_linea"] = voz.groupby("linea_origen")["duracion_seg"].transform("mean")
voz["atipica"] = voz["duracion_seg"] > 5 * voz["promedio_linea"]
print(voz[["linea_origen", "duracion_seg", "participacion", "atipica"]].head(8))
print(voz["atipica"].sum(), "llamadas 5 veces más largas que el promedio de su línea")
```

:::reto Cada sesión frente a su línea
Con las sesiones de **DATOS** de la muestra:

1. Crea la columna `mediana_linea`: la mediana de `mb` de la línea de cada sesión (con `transform`).
2. Crea la columna `grande`: `True` si la sesión consumió **más del triple** de la mediana de su línea.
3. Crea `cantidad_grandes`: cuántas sesiones grandes hay.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
datos = cdr[cdr["tipo"] == "DATOS"].copy()

# mediana_linea, grande y cantidad_grandes

print(cantidad_grandes)
```

:::pista
`datos.groupby("linea_origen")["mb"].transform("median")` devuelve un valor por fila, alineado. Luego `datos["grande"] = datos["mb"] > 3 * datos["mediana_linea"]` y súmalo.
:::

```pyprueba
import pandas as pd


def _esperado():
    cdr_ = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    d = cdr_[cdr_["tipo"] == "DATOS"].copy()
    d["mediana_linea"] = d.groupby("linea_origen")["mb"].transform("median")
    return d, int((d["mb"] > 3 * d["mediana_linea"]).sum())


def prueba_columna():
    """mediana_linea tiene un valor por fila"""
    requiere("datos")
    esperado, _ = _esperado()
    igual(len(datos), len(esperado), "filas")
    a = [float(x) for x in datos["mediana_linea"].fillna(-1)]
    b = [float(x) for x in esperado["mediana_linea"].fillna(-1)]
    igual(a, b, "mediana_linea")


def prueba_cantidad():
    """cantidad_grandes"""
    requiere("cantidad_grandes")
    igual(int(cantidad_grandes), _esperado()[1])
    assert "transform(" in codigo, "Calcula la mediana de cada línea con transform"
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
datos = cdr[cdr["tipo"] == "DATOS"].copy()

datos["mediana_linea"] = datos.groupby("linea_origen")["mb"].transform("median")
datos["grande"] = datos["mb"] > 3 * datos["mediana_linea"]
cantidad_grandes = datos["grande"].sum()
```

## filter: quedarse con grupos completos

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
voz = cdr[cdr["tipo"] == "VOZ"]

intensas = voz.groupby("linea_origen").filter(lambda g: len(g) > 40)
print(intensas["linea_origen"].nunique(), "líneas con más de 40 llamadas")
```

:::reto Lo mayor de cada línea y las líneas intensas
Con las sesiones de **DATOS** de la muestra:

- `mayor_por_linea`: un DataFrame con **la sesión de más megas de cada línea** (una fila por línea, con todas sus columnas);
- `intensas`: la **lista ordenada** de líneas con más de 100 sesiones, usando `filter`.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
datos = cdr[cdr["tipo"] == "DATOS"]

# mayor_por_linea e intensas

print(len(mayor_por_linea), intensas)
```

:::pista
Ordena por `mb` de mayor a menor y toma `groupby("linea_origen").head(1)`. Para las intensas: `datos.groupby("linea_origen").filter(lambda g: len(g) > 100)` y luego las líneas distintas, ordenadas.
:::

```pyprueba
import pandas as pd


def _datos():
    cdr_ = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    return cdr_[cdr_["tipo"] == "DATOS"]


def prueba_mayor():
    """Una fila por línea, con su sesión más grande"""
    requiere("mayor_por_linea")
    d = _datos()
    esperado = d.groupby("linea_origen")["mb"].max()
    obtenido = mayor_por_linea.set_index("linea_origen")["mb"]
    igual(len(mayor_por_linea), len(esperado), "una fila por línea")
    igual({str(k): float(v) for k, v in obtenido.items()}, {str(k): float(v) for k, v in esperado.items()})


def prueba_intensas():
    """intensas: líneas con más de 100 sesiones"""
    requiere("intensas")
    conteo = _datos().groupby("linea_origen").size()
    igual([str(x) for x in intensas], sorted(str(k) for k, v in conteo.items() if v > 100))
    assert ".filter(" in codigo, "Quédate con los grupos usando filter"
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
datos = cdr[cdr["tipo"] == "DATOS"]

mayor_por_linea = datos.sort_values("mb", ascending=False).groupby("linea_origen").head(1)
grupos = datos.groupby("linea_origen").filter(lambda g: len(g) > 100)
intensas = sorted(grupos["linea_origen"].unique().tolist())

print(len(mayor_por_linea), intensas)
```

## Cuestionario

? ¿Qué diferencia hay entre `agg` y `transform`?
- [ ] Ninguna
- [x] `agg` devuelve una fila por grupo; `transform` devuelve un valor por cada fila original
- [ ] `transform` es más rápido
- [ ] `agg` no acepta funciones
> `transform` permite comparar cada registro con un valor de su grupo.

? ¿Qué cuenta `groupby(...)["mb"].count()`?
- [ ] Todas las filas del grupo
- [x] Los valores no faltantes de `mb` en cada grupo
- [ ] Los valores distintos
- [ ] La suma de megas
> `size` cuenta filas; `count` cuenta valores no faltantes de una columna.

? Quieres las 3 llamadas más largas de cada línea. ¿Qué haces?
- [ ] `groupby("linea").max()`
- [x] Ordenar por duración descendente y luego `groupby("linea").head(3)`
- [ ] `nlargest(3, "duracion")`
- [ ] `groupby("linea").filter(...)`
> Ordenar primero hace que `head(3)` de cada grupo sean sus mayores.
