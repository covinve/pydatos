## Enunciado

Este script funciona, pero mezcla lectura, cálculo e impresión:

```python
import csv

def reporte(ruta_planes, consumos):
    with open(ruta_planes, encoding="utf-8") as f:
        planes = {p["plan_id"]: p for p in csv.DictReader(f)}
    for linea, plan_id, minutos in consumos:
        p = planes[plan_id]
        incluidos = int(p["minutos_incluidos"])
        extra = 0 if incluidos == -1 else max(0, minutos - incluidos)
        valor = extra * int(p["tarifa_minuto"])
        print(f"{linea}: {extra} min adicionales = ${valor:,}".replace(",", "."))
```

Sepáralo en tres piezas:

1. `minutos_adicionales(minutos, incluidos)` y `valor_adicional(minutos, incluidos, tarifa)`: **dominio**, funciones puras con números (sin archivos, sin `print`).
2. `leer_planes(ruta)` → diccionario `{plan_id: (minutos_incluidos, tarifa_minuto)}` con enteros: **infraestructura**.
3. `lineas_reporte(planes, consumos)` → **lista de textos** con el formato de arriba (no imprime): **aplicación**.

Y un `reporte(ruta_planes, consumos)` de una línea que junte todo e imprima.

import builtins


def sin_archivos(funcion, *args):
    """Ejecuta funcion prohibiendo abrir archivos e imprimir."""
    abrir, imprimir = builtins.open, builtins.print

    def prohibido(*a, **k):
        raise AssertionError(f"{funcion.__name__} no debe abrir archivos ni imprimir")

    builtins.open = builtins.print = prohibido
    try:
        return funcion(*args)
    finally:
        builtins.open, builtins.print = abrir, imprimir


def prueba_dominio():
    """Reglas puras"""
    requiere("minutos_adicionales", "valor_adicional")
    igual(sin_archivos(minutos_adicionales, 342, 300), 42)
    igual(sin_archivos(minutos_adicionales, 120, 300), 0)
    igual(sin_archivos(minutos_adicionales, 9999, -1), 0)
    igual(sin_archivos(valor_adicional, 342, 300, 120), 5040)
    igual(sin_archivos(valor_adicional, 9999, -1, 0), 0)


def prueba_infraestructura():

## Pista 2

`reporte` es la "raíz de composición": lee, calcula, muestra.

```python
def reporte(ruta_planes, consumos):
    print("\n".join(lineas_reporte(leer_planes(ruta_planes), consumos)))
```

Cuidado: si la lista está vacía, `print("")` imprimiría una línea en blanco. Un `for texto in ...: print(texto)` evita ese caso.

## Solución

```python
import csv


def minutos_adicionales(minutos, incluidos):
    return 0 if incluidos == -1 else max(0, minutos - incluidos)


def valor_adicional(minutos, incluidos, tarifa):
    return minutos_adicionales(minutos, incluidos) * tarifa


def leer_planes(ruta):
    with open(ruta, encoding="utf-8", newline="") as f:
        return {p["plan_id"]: (int(p["minutos_incluidos"]), int(p["tarifa_minuto"])) for p in csv.DictReader(f)}


def lineas_reporte(planes, consumos):
    lineas = []
    for linea, plan_id, minutos in consumos:
        incluidos, tarifa = planes[plan_id]
        extra = minutos_adicionales(minutos, incluidos)
        valor = valor_adicional(minutos, incluidos, tarifa)
        lineas.append(f"{linea}: {extra} min adicionales = ${valor:,}".replace(",", "."))
    return lineas


def reporte(ruta_planes, consumos):
    for texto in lineas_reporte(leer_planes(ruta_planes), consumos):
        print(texto)


reporte("planes.csv", [("3001112233", "HOG30", 342), ("3104445566", "ILIM", 5000), ("3205556677", "BAS10", 99)])
```

## Explicación

Las pruebas usan un truco para **demostrar** la separación: reemplazan `open` y `print` por funciones que fallan. Si el dominio o la aplicación intentaran leer un archivo o imprimir, la prueba lo detectaría.

El resultado vale más de lo que parece:

- La regla (`minutos_adicionales`) se prueba con números, en microsegundos, y cubre los casos raros (ilimitado, consumo menor que lo incluido) sin preparar un CSV para cada uno.
- `lineas_reporte` devuelve textos en lugar de imprimirlos: mañana pueden ir a un correo, a un Excel o a un log, sin tocarla.
- Si los planes pasan a una base de datos, solo cambia `leer_planes`.

Todo esto sin clases, `Protocol` ni patrones: separar responsabilidades empieza con funciones.
