## Enunciado

Combina lo mejor de los módulos 11 y 13: **Pandas por bloques**, con memoria acotada. Completa `resumir_por_bloques(carpeta, tamano_bloque, ventana)` en `ejercicios/m14-e7/por_bloques.py`:

- Lee `cdr.csv` con `pd.read_csv(..., chunksize=tamano_bloque)`.
- Valida cada bloque de forma vectorizada (las seis reglas del curso) y **acumula** los conteos y sumas.
- Los duplicados pueden tener su original **en el bloque anterior**: guarda los últimos `ventana` `cdr_id` vistos y úsalos al validar el bloque siguiente.

El resultado debe ser **idéntico** con cualquier tamaño de bloque: las pruebas lo ejecutan con bloques de 100.000, 700 y 250 filas.

Luego mide con 1 GB, y prueba bloques de 500.000 y 2.000.000 filas mirando la memoria en el Administrador de tareas:

```powershell

```

## Pista 1

Dentro de un bloque, un registro es duplicado si su ID ya apareció **antes en el mismo bloque** o **en los recientes del bloque anterior**:

```python
ids = bloque["cdr_id"]
duplicado = ids.duplicated() | ids.isin(recientes)
```

Al terminar el bloque, actualiza `recientes` con los últimos `ventana` IDs distintos vistos: `recientes = set(pd.concat([pd.Series(list(recientes)), ids]).drop_duplicates().tail(ventana))`. (Hay formas más eficientes, como un `deque`; esta es la más corta.)

## Pista 2

Acumula en variables (o en un `Counter`) a lo largo de los bloques:

```python
errores = Counter()
...
errores.update(clasificacion[clasificacion != "valido"].value_counts().to_dict())
```

Las megas suman en `float`; redondea a 3 decimales solo al final.

## Solución

```python por_bloques.py
"""Ejercicio m14-e7: validar un CDR de cualquier tamaño con Pandas, por bloques.

Uso:
    python ejercicios/m14-e7/por_bloques.py datos/1GB 1000000
"""

from __future__ import annotations

import sys
from collections import Counter, deque
from pathlib import Path

import numpy as np
import pandas as pd

ERRORES = ["duplicado", "duracion_negativa", "fecha_invalida", "linea_vacia", "linea_desconocida", "tipo_desconocido"]
PRIORIDAD = ["duplicado", "linea_vacia", "linea_desconocida", "tipo_desconocido", "duracion_negativa", "fecha_invalida"]
TIPOS_LECTURA = {"linea_origen": "string", "linea_destino": "string", "tipo": "string", "destino": "string"}


def clasificar(bloque: pd.DataFrame, recientes: set, clientes: set) -> pd.Series:
    fecha = pd.to_datetime(bloque["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    condiciones = [
        bloque["cdr_id"].duplicated() | bloque["cdr_id"].isin(recientes),
        bloque["linea_origen"] == "",
        ~bloque["linea_origen"].isin(clientes),
        ~bloque["tipo"].isin(["VOZ", "SMS", "DATOS"]),
        bloque["duracion_seg"] < 0,
        fecha.isna(),
    ]
    return pd.Series(np.select(condiciones, PRIORIDAD, default="valido"), index=bloque.index)


def resumir_por_bloques(carpeta: Path, tamano_bloque: int = 1_000_000, ventana: int = 5000) -> dict:
    clientes = set(pd.read_csv(carpeta / "clientes.csv", encoding="latin-1", dtype={"linea": "string"})["linea"])
    errores = Counter()
    total = min_nac = min_int = sms = 0
    mb = 0.0
    recientes: deque = deque(maxlen=ventana)
    lector = pd.read_csv(carpeta / "cdr.csv", sep="|", keep_default_na=False, dtype=TIPOS_LECTURA, chunksize=tamano_bloque)
    for bloque in lector:
        clasificacion = clasificar(bloque, set(recientes), clientes)
        total += len(bloque)
        errores.update(clasificacion[clasificacion != "valido"].value_counts().to_dict())
        validos = bloque[clasificacion == "valido"]
        voz = validos[validos["tipo"] == "VOZ"]
        minutos = (voz["duracion_seg"] + 59) // 60
        internacional = voz["destino"] == "INTERNACIONAL"
        min_nac += int(minutos[~internacional].sum())
        min_int += int(minutos[internacional].sum())
        mb += float(validos.loc[validos["tipo"] == "DATOS", "mb"].sum())
        sms += int((validos["tipo"] == "SMS").sum())
        recientes.extend(bloque["cdr_id"].drop_duplicates().tail(ventana).tolist())
    return {
        "registros_totales": total,
        "registros_validos": total - sum(errores.values()),
        "errores": {e: int(errores.get(e, 0)) for e in ERRORES},
        "minutos_nacionales": min_nac,
        "minutos_internacionales": min_int,
        "mb_totales": round(mb, 3),
        "sms_totales": sms,
    }


if __name__ == "__main__":
    print(resumir_por_bloques(Path(sys.argv[1]), int(sys.argv[2]) if len(sys.argv) > 2 else 1_000_000))
```

## Explicación

Este es el patrón profesional para datos que no caben en memoria con Pandas: **cada bloque se procesa vectorizado** (rápido) y **solo se acumulan resultados pequeños** (memoria constante). El tamaño del bloque es la perilla entre velocidad y memoria: bloques más grandes aprovechan mejor la vectorización, pero ocupan más RAM.

La parte delicada es lo que **cruza los límites** entre bloques. Un duplicado cuyo original quedó en el bloque anterior pasaría como válido si cada bloque se validara por separado. Las pruebas con bloques de 250 filas existen justamente para forzar ese caso. El `deque(maxlen=ventana)` recuerda los últimos IDs y se descarta solo lo más viejo.

¿Y la mediana, o los percentiles? No se pueden combinar entre bloques sumando. Para ese tipo de cálculo sobre 20 GB, la herramienta adecuada es DuckDB (módulo 16).
