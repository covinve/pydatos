Antes de analizar o facturar, hay que saber **qué tan sucios están los datos**. Esta lección convierte las reglas de validación del curso en código Pandas vectorizado.

## Valores faltantes

| Tipo de columna | Valor faltante |
|---|---|
| Números (`float`) | `NaN` |
| Enteros con faltantes (`Int64`) | `<NA>` |
| Fechas | `NaT` |
| Texto (`string`) | `<NA>` |

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                  keep_default_na=False, na_values=[""])

print(cdr.isna().sum())                     # faltantes por columna
sin_linea = cdr[cdr["linea_origen"].isna()]
print(len(sin_linea), "registros sin línea de origen")
print(cdr["linea_destino"].fillna("(sin destino)").head())
```

| Método | Hace |
|---|---|
| `isna()` / `notna()` | Máscara de faltantes |
| `fillna(valor)` | Rellena |
| `dropna(subset=[...])` | Elimina filas con faltantes en esas columnas |

:::error No rellenes a ciegas
`fillna(0)` en una duración faltante convierte "no sé cuánto duró" en "duró 0 segundos": un dato inventado. Antes de rellenar, decide qué significa el faltante para el negocio. A veces lo correcto es rechazar el registro.
:::

:::reto ¿Dónde faltan datos?
Lee el `cdr` de la muestra tratando el texto vacío como faltante y responde:

- `faltantes`: una Series con cuántos faltantes tiene cada columna;
- `sin_origen`: cuántos registros no tienen `linea_origen`;
- `con_origen`: el DataFrame **sin** esos registros.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                  keep_default_na=False, na_values=[""])

# faltantes, sin_origen y con_origen

print(faltantes)
print(sin_origen, len(con_origen))
```

:::pista
`cdr.isna().sum()` cuenta por columna. `cdr["linea_origen"].isna().sum()` cuenta una sola. Para quitar las filas: `cdr.dropna(subset=["linea_origen"])`.
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                       keep_default_na=False, na_values=[""])


def prueba_faltantes():
    """faltantes por columna"""
    requiere("faltantes")
    igual({k: int(v) for k, v in faltantes.items()}, {k: int(v) for k, v in _cdr().isna().sum().items()})


def prueba_origen():
    """sin_origen y con_origen"""
    requiere("sin_origen", "con_origen")
    datos = _cdr()
    igual(int(sin_origen), int(datos["linea_origen"].isna().sum()), "sin_origen")
    igual(len(con_origen), len(datos) - int(datos["linea_origen"].isna().sum()), "filas de con_origen")
    igual(int(con_origen["linea_origen"].isna().sum()), 0, "con_origen no debe tener faltantes en linea_origen")
```


## Duplicados

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

repetidos = cdr.duplicated("cdr_id")                 # True desde la SEGUNDA aparición
print(repetidos.sum(), "registros duplicados")
print(cdr[cdr["cdr_id"].isin(cdr.loc[repetidos, "cdr_id"])].sort_values("cdr_id").head(4)[["cdr_id", "tipo", "fecha_inicio"]])
sin_duplicados = cdr.drop_duplicates("cdr_id", keep="first")
print(len(cdr), "→", len(sin_duplicados))
```

:::reto Los CDR que llegaron dos veces
Con el `cdr` de la muestra:

- `ids_repetidos`: la lista **ordenada** de los `cdr_id` que aparecen más de una vez (cada uno una sola vez en la lista);
- `veces_max`: la mayor cantidad de veces que se repite un mismo `cdr_id`;
- `unicos`: el DataFrame sin duplicados, conservando la **primera** aparición.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# ids_repetidos, veces_max y unicos

print(len(ids_repetidos), veces_max, len(unicos))
```

:::pista
`cdr.loc[cdr.duplicated("cdr_id"), "cdr_id"]` da los repetidos (desde la segunda aparición): quita los duplicados con `.unique()` y ordénalos. `cdr["cdr_id"].value_counts().max()` da las veces máximas.
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def prueba_repetidos():
    """ids_repetidos, sin repetir y ordenados"""
    requiere("ids_repetidos")
    conteo = _cdr()["cdr_id"].value_counts()
    igual([int(x) for x in ids_repetidos], sorted(int(i) for i in conteo[conteo > 1].index))


def prueba_veces_y_unicos():
    """veces_max y unicos"""
    requiere("veces_max", "unicos")
    datos = _cdr()
    igual(int(veces_max), int(datos["cdr_id"].value_counts().max()), "veces_max")
    igual_df(unicos, datos.drop_duplicates("cdr_id", keep="first"))
```

## Validar con reglas vectorizadas

Las reglas del curso, todas a la vez sobre el DataFrame, con `np.select` para asignar el **primer** error de cada registro:

```pyrun
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                  keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})

fecha = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
condiciones = [
    cdr.duplicated("cdr_id"),
    cdr["linea_origen"] == "",
    ~cdr["linea_origen"].isin(clientes["linea"]),
    ~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]),
    cdr["duracion_seg"] < 0,
    fecha.isna(),
]
nombres = ["duplicado", "linea_vacia", "linea_desconocida", "tipo_desconocido", "duracion_negativa", "fecha_invalida"]
cdr["error"] = np.select(condiciones, nombres, default="")
print(cdr["error"].value_counts())
```

Compara los conteos con `esperado.json` de la muestra: deberían coincidir exactamente.

:::reto Tu propio validador de tres reglas
Crea en el `cdr` de la muestra la columna `motivo`, con el **primer** problema de cada registro según estas reglas, en este orden:

1. `"tipo_desconocido"`: el tipo no es VOZ, SMS ni DATOS;
2. `"duracion_negativa"`: la duración es menor que 0;
3. `"sin_origen"`: la línea de origen está vacía.

Los registros sin problemas quedan con `"ok"`. Después crea `resumen`: cuántos registros hay de cada motivo (`value_counts`).

```pyreto
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                  keep_default_na=False)

# motivo con np.select y resumen

print(resumen)
```

:::pista
Una lista de condiciones en el orden pedido: `~cdr["tipo"].isin([...])`, `cdr["duracion_seg"] < 0` y `cdr["linea_origen"] == ""`. Luego `np.select(condiciones, nombres, default="ok")`.
:::

```pyprueba
import pandas as pd


def _esperado():
    datos = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"}, keep_default_na=False)
    motivos = []
    for tipo, duracion, origen in zip(datos["tipo"], datos["duracion_seg"], datos["linea_origen"]):
        if tipo not in ("VOZ", "SMS", "DATOS"):
            motivos.append("tipo_desconocido")
        elif duracion < 0:
            motivos.append("duracion_negativa")
        elif origen == "":
            motivos.append("sin_origen")
        else:
            motivos.append("ok")
    return motivos


def prueba_motivo():
    """Cada registro tiene su primer motivo"""
    requiere("cdr")
    igual([str(m) for m in cdr["motivo"]], _esperado())


def prueba_resumen():
    """resumen cuenta cada motivo"""
    requiere("resumen")
    esperado = {}
    for m in _esperado():
        esperado[m] = esperado.get(m, 0) + 1
    igual({str(k): int(v) for k, v in resumen.items()}, esperado)
```

```pysolucion
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"},
                  keep_default_na=False)

condiciones = [
    ~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]),
    cdr["duracion_seg"] < 0,
    cdr["linea_origen"] == "",
]

cdr["motivo"] = np.select(condiciones, nombres, default="ok")
resumen = cdr["motivo"].value_counts()

print(resumen)
```

## Optimizar la memoria

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
antes = cdr.memory_usage(deep=True).sum()

optimizado = cdr.astype({"tipo": "category", "destino": "category", "celda": "category"})
optimizado["duracion_seg"] = pd.to_numeric(optimizado["duracion_seg"], downcast="integer")
optimizado["cdr_id"] = pd.to_numeric(optimizado["cdr_id"], downcast="integer")
despues = optimizado.memory_usage(deep=True).sum()

print(f"{antes / 1024:.0f} KB → {despues / 1024:.0f} KB ({1 - despues / antes:.0%} menos)")
print(optimizado.dtypes)
```

El tipo `category` guarda cada valor distinto una sola vez y usa números pequeños para cada fila: ideal para columnas como `tipo` (3 valores) o `plan_id` (6 valores) en tablas de millones de filas.

:::reto Clientes más livianos
Optimiza la memoria del `clientes` de la muestra:

- convierte a `category` las columnas `segmento`, `region`, `plan_id` y `estado`;
- crea `ahorro`: la proporción de memoria ahorrada (entre 0 y 1), midiendo con `memory_usage(deep=True)` antes y después.

```pyreto
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})
antes = clientes.memory_usage(deep=True).sum()

# Convierte las columnas y calcula ahorro

print(f"Ahorro: {ahorro:.0%}")
```

:::pista
`clientes = clientes.astype({"segmento": "category", "region": "category", "plan_id": "category", "estado": "category"})`. Luego `despues = clientes.memory_usage(deep=True).sum()` y `ahorro = 1 - despues / antes`.
:::

```pyprueba
import pandas as pd


def prueba_categorias():
    """Las cuatro columnas son category"""
    requiere("clientes")
    for columna in ("segmento", "region", "plan_id", "estado"):
        assert isinstance(clientes[columna].dtype, pd.CategoricalDtype), f"{columna} debe ser category, es {clientes[columna].dtype}"


def prueba_ahorro():
    """ahorro es la proporción ahorrada"""
    requiere("ahorro", "antes")
    despues = clientes.memory_usage(deep=True).sum()
    cerca(float(ahorro), 1 - despues / antes, 1e-9)
    assert 0 < ahorro < 1, f"ahorro debe estar entre 0 y 1: {ahorro}"
```

```pysolucion
import pandas as pd

clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})
antes = clientes.memory_usage(deep=True).sum()

clientes = clientes.astype({"segmento": "category", "region": "category", "plan_id": "category", "estado": "category"})
despues = clientes.memory_usage(deep=True).sum()
ahorro = 1 - despues / antes

print(f"Ahorro: {ahorro:.0%}")
```

## Cuestionario

? ¿Qué marca `cdr.duplicated("cdr_id")` como `True`?
- [ ] Todas las apariciones de un ID repetido
- [x] Las apariciones de un ID a partir de la segunda
- [ ] Solo la primera aparición
- [ ] Los IDs nulos
> Con el valor por defecto `keep="first"`, la primera aparición se considera original.

? ¿Por qué `fillna(0)` en duraciones faltantes puede ser un error?
- [ ] Porque es lento
- [x] Porque inventa un dato: "no sabemos la duración" pasa a ser "duró 0 segundos"
- [ ] Porque 0 no es un número válido
- [ ] Porque borra la columna
> Rellenar es una decisión de negocio; a veces lo correcto es rechazar o marcar el registro.

? ¿Cuándo conviene el tipo `category`?
- [ ] Para montos en pesos
- [ ] Para identificadores únicos como `cdr_id`
- [x] Para columnas de texto con pocos valores distintos repetidos muchas veces
- [ ] Para fechas
> Guarda cada valor distinto una vez y un código pequeño por fila.
