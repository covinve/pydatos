Escribir `sqlite3` directo está bien para SQLite. Pero en el trabajo te encontrarás con PostgreSQL, Oracle o SQL Server, cada uno con su propia librería. **SQLAlchemy** es la capa común: el mismo código Python funciona con todos, cambiando solo la **dirección de conexión**.

## Pandas ↔ base de datos

```pyrun
import sqlite3
import pandas as pd

con = sqlite3.connect(":memory:")
cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr.to_sql("cdr", con, index=False, if_exists="replace", chunksize=10_000)

resumen = pd.read_sql("""
    SELECT tipo, COUNT(*) AS registros, SUM(duracion_seg) AS segundos
    FROM cdr WHERE duracion_seg >= 0
    GROUP BY tipo ORDER BY registros DESC
""", con)
print(resumen)

linea = cdr["linea_origen"].iloc[0]
print(pd.read_sql("SELECT cdr_id, tipo, duracion_seg FROM cdr WHERE linea_origen = ? LIMIT 3", con, params=(linea,)))
```

| Parámetro de `to_sql` | Para qué |
|---|---|
| `if_exists="fail"` / `"replace"` / `"append"` | Qué hacer si la tabla ya existe |
| `index=False` | No guardar el índice de Pandas como columna |
| `chunksize=10_000` | Insertar por lotes |
| `dtype={...}` | Forzar tipos de columna en la base |

:::consejo to_sql crea tablas sin restricciones
`to_sql` con `replace` crea la tabla adivinando los tipos y **sin** claves ni restricciones. Para tablas de verdad, créalas tú con `CREATE TABLE` y usa `if_exists="append"`.
:::

```pyprueba
import pandas as pd


def _clientes():
    return pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})


def prueba_tabla():
    """La tabla clientes está en la base"""
    requiere("con")
    igual(con.execute("SELECT COUNT(*) FROM clientes").fetchone()[0], 40)


def prueba_por_region():
    """por_region cuenta por región, de mayor a menor"""
    requiere("por_region")
    esperado = _clientes()["region"].value_counts()
    igual(dict(zip(por_region["region"], [int(x) for x in por_region["clientes"]])), {str(k): int(v) for k, v in esperado.items()})
    igual([int(x) for x in por_region["clientes"]], sorted([int(x) for x in esperado], reverse=True), "orden")


def prueba_de_plan():
    """de_plan usa un parámetro"""
    requiere("de_plan")
    c = _clientes()
    igual(sorted(str(x) for x in de_plan["cliente_id"]), sorted(c.loc[c["plan_id"] == "HOG30", "cliente_id"]))
    assert "params=" in codigo, "Pasa el plan con params=..."
```

```pysolucion
import sqlite3

import pandas as pd
```

## SQLAlchemy: el motor

Todo empieza con un **engine** creado a partir de una URL:

| Base de datos | URL |
|---|---|
| SQLite (archivo) | `sqlite:///telco.db` |
| SQLite (memoria) | `sqlite://` |
| PostgreSQL | `postgresql+psycopg://usuario:clave@servidor:5432/facturacion` |
| SQL Server | `mssql+pyodbc://usuario:clave@dsn` |
| Oracle | `oracle+oracledb://usuario:clave@servidor:1521/?service_name=FACT` |

```pyrun
from sqlalchemy import create_engine, text

engine = create_engine("sqlite://")

with engine.begin() as con:                      # transacción: commit al salir, rollback si falla
    con.execute(text("CREATE TABLE planes (plan_id TEXT PRIMARY KEY, cargo_fijo INTEGER)"))
    con.execute(text("INSERT INTO planes VALUES (:p, :c)"),
                [{"p": "BAS10", "c": 25900}, {"p": "ILIM", "c": 89900}])

with engine.connect() as con:                    # solo lectura
    for fila in con.execute(text("SELECT * FROM planes WHERE cargo_fijo > :minimo"), {"minimo": 30000}):
        print(fila.plan_id, fila.cargo_fijo)
```

`text()` con parámetros `:nombre` funciona igual en todas las bases. Pandas también acepta el engine: `pd.read_sql(text("..."), engine)` y `df.to_sql("tabla", engine)`.

:::reto El mismo código para cualquier base
Con SQLAlchemy y un engine en memoria (`sqlite://`):

1. Dentro de **una transacción** (`engine.begin()`), crea la tabla `tarifas` (`destino` texto clave primaria, `valor` entero) e inserta LOCAL 100, NACIONAL 120 e INTERNACIONAL 950 con parámetros `:nombre`.
2. Con `engine.connect()`, crea `caras`: la **lista** de destinos con tarifa mayor que el valor de la variable `umbral`, usando un parámetro.

```pyreto
from sqlalchemy import create_engine, text

engine = create_engine("sqlite://")
umbral = 110

# 1 y 2

print(caras)
```

:::pista
`con.execute(text("INSERT INTO tarifas VALUES (:d, :v)"), [{"d": "LOCAL", "v": 100}, ...])`. Para leer: `[fila.destino for fila in con.execute(text("SELECT destino FROM tarifas WHERE valor > :u ORDER BY destino"), {"u": umbral})]`.
:::

```pyprueba
from sqlalchemy import text


def prueba_tabla():
    """La tabla tarifas tiene los tres destinos"""
    requiere("engine")
    with engine.connect() as c:
        filas = c.execute(text("SELECT destino, valor FROM tarifas ORDER BY destino")).fetchall()
    igual([tuple(f) for f in filas], [("INTERNACIONAL", 950), ("LOCAL", 100), ("NACIONAL", 120)])


def prueba_caras():
    """caras usa el parámetro"""
    requiere("caras")
    igual(sorted(caras), ["INTERNACIONAL", "NACIONAL"])
    assert ":" in codigo and "text(" in codigo, "Usa text() con parámetros :nombre"
```

```pysolucion
from sqlalchemy import create_engine, text

engine = create_engine("sqlite://")
umbral = 110

with engine.begin() as con:
    con.execute(text("CREATE TABLE tarifas (destino TEXT PRIMARY KEY, valor INTEGER)"))
    con.execute(text("INSERT INTO tarifas VALUES (:d, :v)"),
                [{"d": "LOCAL", "v": 100}, {"d": "NACIONAL", "v": 120}, {"d": "INTERNACIONAL", "v": 950}])

with engine.connect() as con:
    caras = [fila.destino for fila in con.execute(text("SELECT destino FROM tarifas WHERE valor > :u ORDER BY destino"), {"u": umbral})]

print(caras)
```

## SQLAlchemy ORM: tablas como clases

El **ORM** (*Object Relational Mapper*) representa cada tabla como una clase y cada fila como un objeto, como en el módulo 9:

```pyrun
from sqlalchemy import ForeignKey, String, create_engine, func, select
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column, relationship


class Base(DeclarativeBase):
    pass


class Plan(Base):
    __tablename__ = "planes"
    plan_id: Mapped[str] = mapped_column(String(10), primary_key=True)
    cargo_fijo: Mapped[int]
    clientes: Mapped[list["Cliente"]] = relationship(back_populates="plan")


class Cliente(Base):
    __tablename__ = "clientes"
    linea: Mapped[str] = mapped_column(String(10), primary_key=True)
    segmento: Mapped[str]
    plan_id: Mapped[str] = mapped_column(ForeignKey("planes.plan_id"))
    plan: Mapped[Plan] = relationship(back_populates="clientes")


engine = create_engine("sqlite://")
Base.metadata.create_all(engine)                 # crea las tablas

with Session(engine) as sesion:
    basico = Plan(plan_id="BAS10", cargo_fijo=25900)
    sesion.add_all([basico, Cliente(linea="3001112233", segmento="RESIDENCIAL", plan=basico),
                    Cliente(linea="3104445566", segmento="RESIDENCIAL", plan=basico)])
    sesion.commit()

    cliente = sesion.get(Cliente, "3001112233")
    print(cliente.linea, "→", cliente.plan.plan_id, cliente.plan.cargo_fijo)

    consulta = select(Plan.plan_id, func.count(Cliente.linea)).join(Cliente).group_by(Plan.plan_id)
    print(sesion.execute(consulta).all())
```

| | `sqlite3` / `text()` | Core (`select`) | ORM (clases) |
|---|---|---|---|
| Escribes | SQL en texto | SQL con funciones de Python | Clases y objetos |
| Ideal para | Consultas analíticas, scripts | Consultas dinámicas | Aplicaciones con lógica de negocio |
| Portabilidad | Depende del SQL que escribas | Alta | Alta |

:::pista
`minutos: Mapped[int] = mapped_column(default=0)`. Después `Base.metadata.create_all(engine)`, `sesion.add_all([...])`, `sesion.commit()` y `sesion.execute(select(func.sum(Linea.minutos)).where(Linea.plan_id == "HOG30")).scalar()`.

```pyprueba
from sqlalchemy import text


def prueba_modelo():
    """Linea está mapeada a la tabla lineas"""
    requiere("Linea")
    igual(Linea.__tablename__, "lineas")


def prueba_datos():
    """Las tres líneas, con el valor por defecto"""
    requiere("engine")
    with engine.connect() as c:
        filas = c.execute(text("SELECT linea, plan_id, minutos FROM lineas ORDER BY linea")).fetchall()
    igual([tuple(f) for f in filas], [("3001", "HOG30", 342), ("3002", "HOG30", 15), ("3003", "ILIM", 0)])


def prueba_suma():
    """minutos_hog30 = 357"""
    requiere("minutos_hog30")
    igual(minutos_hog30, 357)
```

```pysolucion
from sqlalchemy import String, create_engine, func, select
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column


class Base(DeclarativeBase):
    pass


class Linea(Base):
    __tablename__ = "lineas"
    linea: Mapped[str] = mapped_column(String(10), primary_key=True)
    plan_id: Mapped[str]
    minutos: Mapped[int] = mapped_column(default=0)


engine = create_engine("sqlite://")
Base.metadata.create_all(engine)

with Session(engine) as sesion:
    sesion.add_all([
        Linea(linea="3001", plan_id="HOG30", minutos=342),
        Linea(linea="3002", plan_id="HOG30", minutos=15),
        Linea(linea="3003", plan_id="ILIM"),
    ])
    sesion.commit()
    minutos_hog30 = sesion.execute(select(func.sum(Linea.minutos)).where(Linea.plan_id == "HOG30")).scalar()

print(minutos_hog30)
```
:::

:::capo No todo debe ser ORM
Para análisis de millones de filas, una consulta SQL bien escrita (con `text()` o en DuckDB) es más clara y mucho más rápida que cargar millones de objetos. El ORM brilla cuando manejas **entidades** (un cliente, una factura) con reglas; la arquitectura en capas del módulo 19 lo usa así.
:::

## PostgreSQL

**PostgreSQL** es la base de datos libre más usada en empresas. Para conectarte desde Python: `pip install "psycopg[binary]"` (no necesita permisos de administrador) y una URL como las de arriba. En casa la levantarás con Docker en el módulo 22; en la oficina, si tienes acceso a una base de datos, pide al administrador un usuario **de solo lectura** para tus análisis.

Diferencias que vas a notar respecto a SQLite:

- Tipos estrictos: no puedes guardar texto en una columna `INTEGER`.
- Las claves foráneas siempre están activas.
- Muchos usuarios a la vez, permisos por tabla, esquemas (`facturacion.cdr`).
- Carga masiva con `COPY` (próxima lección), mucho más rápida que `INSERT`.
