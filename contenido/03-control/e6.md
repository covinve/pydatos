## Enunciado

Un cliente reclama: "me cobraron minutos adicionales y yo no hablé tanto". Para responderle, necesitas saber **en qué llamada se agotó su bolsa de minutos**.

Recibes las duraciones de sus llamadas **en orden cronológico** (en segundos) y los minutos incluidos en su plan. Cada llamada consume sus minutos facturables (redondeados hacia arriba).

1. `llamada_que_agota_bolsa(duraciones, minutos_incluidos)` → la posición (desde 1) de la **primera** llamada con la que el acumulado de minutos **supera** los incluidos. Si nunca los supera, `None`. Si el plan es ilimitado (`-1`), `None`.
2. `resumen_bolsa(duraciones, minutos_incluidos)` → un texto:
   - Ilimitado: `"Plan ilimitado: 71 min usados"`
   - Si la bolsa se agotó: `"Bolsa agotada en la llamada 4: 71 min usados de 60 (exceso: 11 min)"`
   - Si no: `"Quedan 229 min de 300 (71 min usados)"`

```python
d = [125, 0, 61, 3600, 45, 0, 300]       # minutos: 3, 0, 2, 60, 1, 0, 5
llamada_que_agota_bolsa(d, 60)           # 4   → tras la 4.ª llamada van 65 min
llamada_que_agota_bolsa(d, 300)          # None
llamada_que_agota_bolsa(d, 65)           # 5   → tras la 4.ª van 65 (no los supera); tras la 5.ª, 66
```

Ojo: **superar** no es **alcanzar**. Usar exactamente los minutos incluidos no agota la bolsa.

## Pruebas

```python
D = [125, 0, 61, 3600, 45, 0, 300]


def prueba_agota_en_la_cuarta():
```

## Pista 1

Es el patrón **acumular + buscar**: acumula los minutos llamada por llamada y, en cuanto el acumulado sea **mayor** que lo incluido, devuelve la posición actual.

```python
usados = 0
for posicion, d in enumerate(duraciones, start=1):
    usados += (d + 59) // 60
    if usados > minutos_incluidos:
        return posicion
return None
```

No olvides la salida temprana del ilimitado.

## Pista 2

En `resumen_bolsa` necesitas el total de minutos usados (todas las llamadas) y la llamada en que se agotó. Reutiliza `llamada_que_agota_bolsa` y calcula el total con una comprensión:

```python
usados = sum((d + 59) // 60 for d in duraciones)
agotada_en = llamada_que_agota_bolsa(duraciones, minutos_incluidos)
```

Luego decide qué texto devolver con `if` / `elif` / `else`.

## Solución

```python
ILIMITADO = -1


def minutos_facturables(segundos):
    return (segundos + 59) // 60


def llamada_que_agota_bolsa(duraciones, minutos_incluidos):
    if minutos_incluidos == ILIMITADO:
        return None
    usados = 0
    for posicion, segundos in enumerate(duraciones, start=1):
        usados += minutos_facturables(segundos)
        if usados > minutos_incluidos:
            return posicion
    return None


def resumen_bolsa(duraciones, minutos_incluidos):
    usados = sum(minutos_facturables(d) for d in duraciones)
    if minutos_incluidos == ILIMITADO:
        return f"Plan ilimitado: {usados} min usados"
    agotada_en = llamada_que_agota_bolsa(duraciones, minutos_incluidos)
    if agotada_en is not None:
        exceso = usados - minutos_incluidos
        return (
            f"Bolsa agotada en la llamada {agotada_en}: "
            f"{usados} min usados de {minutos_incluidos} (exceso: {exceso} min)"
        )
    return f"Quedan {minutos_incluidos - usados} min de {minutos_incluidos} ({usados} min usados)"


d = [125, 0, 61, 3600, 45, 0, 300]
print(llamada_que_agota_bolsa(d, 60))
print(resumen_bolsa(d, 60))
print(resumen_bolsa(d, 300))
```

## Explicación

Detalles que hacen la diferencia:

- **`return` dentro del `for`** termina la función en cuanto encuentra la respuesta: es el patrón *buscar* sin necesidad de `break` ni de variables extra.
- **`>` y no `>=`**: "superar" no es "alcanzar". Con 65 minutos incluidos, usar exactamente 65 no genera cobro. Las reglas de negocio se juegan en estos detalles, y las pruebas `prueba_igualar_no_es_superar` existen justamente para atraparlos.
- **`if agotada_en is not None`** y no `if agotada_en`: la posición nunca es 0 aquí, pero acostumbrarte a preguntar por `None` explícitamente evita errores cuando el 0 sí es un valor válido.

Con esta función puedes responder el reclamo con datos: "su bolsa se agotó en la llamada del día X a las Y horas".
