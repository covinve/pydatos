## Enunciado

Con el `parsear_cdr` del ejercicio anterior (ya está en el código inicial), escribe `procesar_archivo(ruta, max_porcentaje_errores=5.0)`:

1. Recorre `cdr.csv` línea por línea (saltando el encabezado). Numera las líneas **como en el archivo** (el encabezado es la línea 1).
2. Cada línea que se pueda parsear se agrega a una lista de registros. Las que lanzan `ErrorDeRegistro` **no detienen el proceso**: se guardan en una lista de errores como tuplas `(numero_linea, campo, valor)`.
3. Al terminar, si el porcentaje de líneas con error supera `max_porcentaje_errores`, lanza `ArchivoCorrupto` (una excepción que debes crear) con el mensaje:

   ```text
   cdr.csv: 12.50 % de líneas con error (máximo 5.0 %)
   ```

4. Si no, devuelve `(registros, errores)`.

```python
registros, errores = procesar_archivo("cdr.csv")
len(registros) + len(errores)    # total de líneas de datos
errores[0]                       # (numero_linea, "fecha_inicio", "2026-09-31 10:15:00") por ejemplo
```

from datetime import datetime
from pathlib import Path


class ErrorDeRegistro(Exception):
    def __init__(self, numero_linea, campo, valor):
        self.numero_linea = numero_linea
        self.campo = campo
        self.valor = valor
        super().__init__(f"Línea {numero_linea}, campo {campo}: valor inválido {valor!r}")


def parsear_cdr(numero_linea, linea):
    campos = linea.split("|")
    if len(campos) != 9:
        raise ErrorDeRegistro(numero_linea, "linea", linea)
    conversiones = [
        ("cdr_id", 0, int), ("linea_origen", 1, str), ("tipo", 3, str),
        ("fecha_inicio", 5, lambda t: datetime.strptime(t, "%Y-%m-%d %H:%M:%S")),
        ("duracion_seg", 6, int), ("mb", 7, float),
    ]
    registro = {}
    for nombre, posicion, convertir in conversiones:
        try:
            registro[nombre] = convertir(campos[posicion])
        except ValueError as error:
            raise ErrorDeRegistro(numero_linea, nombre, campos[posicion]) from error
    return registro

## Pista 2

Al final calcula el porcentaje sobre el total de líneas de datos (registros + errores) y compáralo con el máximo. La excepción se crea con una línea: `class ArchivoCorrupto(Exception): pass`. Para el nombre del archivo en el mensaje usa `Path(ruta).name`.

Formato del porcentaje: `f"{porcentaje:.2f} %"`.

## Solución

```python
from datetime import datetime
from pathlib import Path


class ErrorDeRegistro(Exception):
    def __init__(self, numero_linea, campo, valor):
        self.numero_linea = numero_linea
        self.campo = campo
        self.valor = valor
        super().__init__(f"Línea {numero_linea}, campo {campo}: valor inválido {valor!r}")


def parsear_cdr(numero_linea, linea):
    campos = linea.split("|")
    if len(campos) != 9:
        raise ErrorDeRegistro(numero_linea, "linea", linea)
    conversiones = [
        ("cdr_id", 0, int), ("linea_origen", 1, str), ("tipo", 3, str),
        ("fecha_inicio", 5, lambda t: datetime.strptime(t, "%Y-%m-%d %H:%M:%S")),
        ("duracion_seg", 6, int), ("mb", 7, float),
    ]
    registro = {}
    for nombre, posicion, convertir in conversiones:
        try:
            registro[nombre] = convertir(campos[posicion])
        except ValueError as error:
            raise ErrorDeRegistro(numero_linea, nombre, campos[posicion]) from error
    return registro


class ArchivoCorrupto(Exception):
    """El archivo tiene más errores de los tolerables."""


def procesar_archivo(ruta, max_porcentaje_errores=5.0):
    registros = []
    errores = []
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for numero, linea in enumerate(archivo, start=2):
            try:
                registros.append(parsear_cdr(numero, linea.rstrip("\n")))
            except ErrorDeRegistro as error:
                errores.append((error.numero_linea, error.campo, error.valor))
    total = len(registros) + len(errores)
    porcentaje = len(errores) / total * 100 if total else 0.0
    if porcentaje > max_porcentaje_errores:
        raise ArchivoCorrupto(
            f"{Path(ruta).name}: {porcentaje:.2f} % de líneas con error (máximo {max_porcentaje_errores} %)"
        )
    return registros, errores


registros, errores = procesar_archivo("cdr.csv")
print(len(registros), "registros,", len(errores), "errores")
print(errores[:3])
```

## Explicación

Este es el patrón más importante del módulo para tu trabajo diario: **el error de un registro se maneja en el nivel del registro; el error del archivo, en el nivel del archivo**.

- Un registro dañado es normal: se anota y se sigue.
- Un archivo con 12 % de registros dañados **no es normal**: probablemente cambió el formato o el archivo llegó truncado. Seguir procesando produciría una facturación basura, así que el proceso se detiene con un error claro.

El umbral (`max_porcentaje_errores`) es una decisión de negocio, por eso es un parámetro y no un número fijo dentro del código.

Fíjate en el detalle de numeración: `enumerate(archivo, start=2)` después de consumir el encabezado. Así el número de línea del error coincide con lo que ve una persona al abrir el archivo en un editor.
