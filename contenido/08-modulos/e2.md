## Enunciado

Este archivo funciona como script, pero cuando otro módulo lo **importa** para usar `minutos_facturables`, se ejecuta todo el reporte. Reorganízalo:

- Deja `minutos_facturables` y `resumen` como funciones reutilizables.
- Mueve el código que imprime el reporte a una función `main()`.
- Llama a `main()` solo cuando el archivo se ejecuta directamente, con el guardián `if __name__ == "__main__":`.

Al ejecutarlo como script debe imprimir lo mismo que antes. Al importarlo, no debe imprimir nada.

## Código inicial

```python
def minutos_facturables(segundos):
    return (segundos + 59) // 60


def resumen(duraciones):
    total = sum(minutos_facturables(d) for d in duraciones)
    return f"{len(duraciones)} llamadas · {total} min facturables"


llamadas = [125, 0, 61, 3600]
print("Reporte de llamadas")
print(resumen(llamadas))
```

## Pista 1

Todo lo que está al final del archivo (la lista y los dos `print`) va dentro de una función:

```python
def main():

```

## Pista 2

Al final del archivo:

```python
if __name__ == "__main__":
    main()
```

## Solución

```python
def minutos_facturables(segundos):
    return (segundos + 59) // 60


def resumen(duraciones):
    total = sum(minutos_facturables(d) for d in duraciones)
    return f"{len(duraciones)} llamadas · {total} min facturables"


def main():
    llamadas = [125, 0, 61, 3600]
    print("Reporte de llamadas")
    print(resumen(llamadas))


if __name__ == "__main__":
    main()
```

## Explicación

Las pruebas ejecutan tu código dos veces, simulando los dos usos: con `__name__ == "__main__"` (como `python tarificador.py`) y con `__name__ == "tarificador"` (como `import tarificador`).

Este patrón, **funciones arriba, `main()` y guardián al final**, es la plantilla de todo script profesional en Python. Tiene un beneficio extra: las variables de `main` (como `llamadas`) son locales y no contaminan el módulo.
