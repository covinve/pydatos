## Enunciado

Reescribe el validador de CDR de forma **abierta a extensión**: cada regla es un objeto y el validador solo las recorre.

1. `Regla` (`Protocol`): atributo `nombre: str` y método `falla(cdr: dict) -> bool`.
2. Seis clases, una por regla del curso, con su `nombre` igual a la clave de `esperado.json`: `Duplicado`, `LineaVacia`, `LineaDesconocida(lineas)`, `TipoDesconocido`, `DuracionNegativa`, `FechaInvalida`. `Duplicado` recuerda los `cdr_id` que ya vio; `LineaDesconocida` recibe el conjunto de líneas de clientes.
3. `Validador(reglas)`:
   - `motivo(cdr)` → el `nombre` de la **primera** regla que falla, o `"valido"`. **Las reglas siguientes no se evalúan** (algunas reglas tienen memoria, como `Duplicado`, y evaluarlas de más cambiaría su estado; además, es más rápido).
   - `resumen(filas)` → `{"registros_totales", "registros_validos", "errores": {nombre: n}}`, con los errores en el **orden de las reglas** (incluidos los que tienen 0).
4. `reglas_estandar(lineas)` → la lista de las seis, en el orden de prioridad del curso.

## Pista 1

Cada regla es una clase pequeña:


## Pista 2

`next()` con un generador se detiene en el primer valor y no evalúa el resto:

```python
def motivo(self, cdr):
    return next((r.nombre for r in self.reglas if r.falla(cdr)), "valido")
```

Para el resumen, inicializa `errores = {r.nombre: 0 for r in self.reglas}` y suma.

## Solución

```python
import csv
from datetime import datetime
from typing import Protocol


class Regla(Protocol):
    nombre: str

    def falla(self, cdr: dict) -> bool: ...


class Duplicado:
    nombre = "duplicado"

    def __init__(self):
        self.vistos = set()

    def falla(self, cdr):
        if cdr["cdr_id"] in self.vistos:
            return True
        self.vistos.add(cdr["cdr_id"])
        return False


class LineaVacia:
    nombre = "linea_vacia"

    def falla(self, cdr):
        return not cdr["linea_origen"]


class LineaDesconocida:
    nombre = "linea_desconocida"

    def __init__(self, lineas):
        self.lineas = set(lineas)

    def falla(self, cdr):
        return cdr["linea_origen"] not in self.lineas


class TipoDesconocido:
    nombre = "tipo_desconocido"

    def falla(self, cdr):
        return cdr["tipo"] not in ("VOZ", "SMS", "DATOS")


class DuracionNegativa:
    nombre = "duracion_negativa"

    def falla(self, cdr):
        return int(cdr["duracion_seg"]) < 0


class FechaInvalida:
    nombre = "fecha_invalida"

    def falla(self, cdr):
        try:
            datetime.strptime(cdr["fecha_inicio"], "%Y-%m-%d %H:%M:%S")
        except ValueError:
            return True
        return False


class Validador:
    def __init__(self, reglas):
        self.reglas = list(reglas)

    def motivo(self, cdr):
        return next((r.nombre for r in self.reglas if r.falla(cdr)), "valido")

    def resumen(self, filas):
        errores = {r.nombre: 0 for r in self.reglas}
        total = validos = 0
        for cdr in filas:
            total += 1
            m = self.motivo(cdr)
            if m == "valido":
                validos += 1
            else:
                errores[m] += 1
        return {"registros_totales": total, "registros_validos": validos, "errores": errores}


def reglas_estandar(lineas):
    return [Duplicado(), LineaVacia(), LineaDesconocida(lineas), TipoDesconocido(), DuracionNegativa(), FechaInvalida()]
```

## Explicación

Compara con tu validador del proyecto 1: allí, agregar una regla significaba editar la función principal (otro `if`, otro contador, otra clave en el resumen). Aquí, la prueba `LlamadaLarga` agregó una regla **sin tocar una línea** del `Validador`: principio abierto/cerrado. El orden de prioridad es simplemente el orden de la lista.

Este diseño se llama patrón **Strategy** (estrategia): cada regla es una estrategia intercambiable con la misma interfaz. Tiene otra ventaja: cada regla se prueba por separado, con un diccionario de una fila.

Un detalle de diseño: `Duplicado` tiene **estado** (los IDs vistos). Por eso `reglas_estandar` crea instancias nuevas cada vez: si dos validadores compartieran el mismo `Duplicado`, el segundo vería todo como repetido. La última prueba verifica justo eso.
