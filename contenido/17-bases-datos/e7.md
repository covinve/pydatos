## Enunciado

Construye la carga de CDR tal como se hace en producción (lección 4): **tabla de paso → validación en SQL → tabla definitiva + rechazos**, rápida, con memoria constante y **repetible** sin duplicar.

Completa `cargar_cdr(carpeta, ruta_bd, lote)` en `ejercicios/m17-e7/carga_masiva.py`. El docstring describe las tablas y los cuatro pasos. Las reglas de validación son las de siempre, en el mismo orden de prioridad; en SQLite:

| Regla | Condición en SQL |
|---|---|
| `duplicado` | `ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY fila) > 1` |
| `linea_vacia` | `coalesce(linea_origen, '') = ''` |
| `linea_desconocida` | `linea_origen NOT IN (SELECT linea FROM clientes)` |
| `tipo_desconocido` | `tipo NOT IN ('VOZ', 'SMS', 'DATOS')` |
| `duracion_negativa` | `CAST(duracion_seg AS INTEGER) < 0` |
| `fecha_invalida` | `fecha_inicio IS NOT strftime('%Y-%m-%d %H:%M:%S', julianday(fecha_inicio))` |

Cuando pase `python comprobar.py m17-e7`, carga el archivo de 100 MB y luego el de 1 GB, mide el tiempo y el tamaño del `.db`, y prueba una consulta por línea antes y después del índice.

## Pista 1

La lectura por lotes con `itertools.batched` (Python 3.12+), agregando el número de fila:

```python
with open(carpeta / "cdr.csv", encoding="utf-8", newline="") as f:
    lector = csv.reader(f, delimiter="|")
    next(lector)
    filas = ((n, *fila) for n, fila in enumerate(lector, start=1))
    for grupo in batched(filas, lote):
        with con:
            con.executemany("INSERT INTO paso_cdr VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)", grupo)
```

## Pista 2

Clasifica una sola vez en una tabla temporal y de ahí sale todo:

```sql
CREATE TEMP TABLE clasificados AS
WITH marcado AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY fila) AS aparicion FROM paso_cdr
)
SELECT *, CASE WHEN aparicion > 1 THEN 'duplicado' WHEN ... ELSE 'valido' END AS motivo
FROM marcado;
```

Luego `INSERT OR IGNORE INTO cdr SELECT ... FROM clasificados WHERE motivo = 'valido'`, lo mismo para `rechazos`, y un `GROUP BY motivo` para el resumen. Al final, `DROP TABLE clasificados`.

## Solución

```python carga_masiva.py
"""Ejercicio m17-e7: carga masiva de CDR a SQLite, con validación en SQL, rechazos e idempotencia.

Uso:
    python ejercicios/m17-e7/carga_masiva.py datos/100MB salidas/telco.db
"""

from __future__ import annotations

import csv
import sqlite3
import sys
from itertools import batched
from pathlib import Path

ERRORES = ["duplicado", "duracion_negativa", "fecha_invalida", "linea_vacia", "linea_desconocida", "tipo_desconocido"]
COLUMNAS = ["cdr_id", "linea_origen", "linea_destino", "tipo", "destino", "fecha_inicio", "duracion_seg", "mb", "celda"]

ESQUEMA = """
    CREATE TABLE IF NOT EXISTS clientes (linea TEXT PRIMARY KEY, plan_id TEXT);
    CREATE TABLE IF NOT EXISTS paso_cdr (
        fila INTEGER, cdr_id TEXT, linea_origen TEXT, linea_destino TEXT, tipo TEXT, destino TEXT,
        fecha_inicio TEXT, duracion_seg TEXT, mb TEXT, celda TEXT
    );
    CREATE TABLE IF NOT EXISTS cdr (
        cdr_id INTEGER PRIMARY KEY, linea_origen TEXT, linea_destino TEXT, tipo TEXT, destino TEXT,
        fecha_inicio TEXT, duracion_seg INTEGER, mb REAL, celda TEXT, archivo TEXT
    );
    CREATE TABLE IF NOT EXISTS rechazos (
        archivo TEXT, fila INTEGER, cdr_id TEXT, motivo TEXT, PRIMARY KEY (archivo, fila)
    );
"""

CLASIFICAR = """
    CREATE TEMP TABLE clasificados AS
    WITH marcado AS (
        SELECT *, ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY fila) AS aparicion FROM paso_cdr
    )
    SELECT *,
           CASE
               WHEN aparicion > 1 THEN 'duplicado'
               WHEN coalesce(linea_origen, '') = '' THEN 'linea_vacia'
               WHEN linea_origen NOT IN (SELECT linea FROM clientes) THEN 'linea_desconocida'
               WHEN tipo NOT IN ('VOZ', 'SMS', 'DATOS') THEN 'tipo_desconocido'
               WHEN CAST(duracion_seg AS INTEGER) < 0 THEN 'duracion_negativa'
               WHEN fecha_inicio IS NOT strftime('%Y-%m-%d %H:%M:%S', julianday(fecha_inicio)) THEN 'fecha_invalida'
               ELSE 'valido'
           END AS motivo
    FROM marcado
"""


def cargar_cdr(carpeta: Path, ruta_bd: Path, lote: int = 100_000) -> dict:
    carpeta = Path(carpeta)
    archivo = (carpeta / "cdr.csv").resolve().as_posix()
    Path(ruta_bd).parent.mkdir(parents=True, exist_ok=True)
    con = sqlite3.connect(ruta_bd)
    try:
        con.executescript(ESQUEMA)
        with open(carpeta / "clientes.csv", encoding="latin-1", newline="") as f, con:
            con.executemany(
                "INSERT INTO clientes VALUES (?, ?) ON CONFLICT (linea) DO UPDATE SET plan_id = excluded.plan_id",
                ((c["linea"], c["plan_id"]) for c in csv.DictReader(f)),
            )
        with con:
            con.execute("DELETE FROM paso_cdr")
        with open(carpeta / "cdr.csv", encoding="utf-8", newline="") as f:
            lector = csv.reader(f, delimiter="|")
            next(lector)
            filas = ((n, *fila) for n, fila in enumerate(lector, start=1))
            for grupo in batched(filas, lote):
                with con:
                    con.executemany("INSERT INTO paso_cdr VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)", grupo)

        with con:
            con.execute(CLASIFICAR)
            con.execute("""
                INSERT OR IGNORE INTO cdr
                SELECT CAST(cdr_id AS INTEGER), linea_origen, linea_destino, tipo, destino, fecha_inicio,
                       CAST(duracion_seg AS INTEGER), CAST(mb AS REAL), celda, ?
                FROM clasificados WHERE motivo = 'valido'
            """, (archivo,))
            con.execute("""
                INSERT OR IGNORE INTO rechazos
                SELECT ?, fila, cdr_id, motivo FROM clasificados WHERE motivo <> 'valido'
            """, (archivo,))
            conteo = dict(con.execute("SELECT motivo, COUNT(*) FROM clasificados GROUP BY motivo").fetchall())
            con.execute("DROP TABLE clasificados")
            con.execute("DELETE FROM paso_cdr")
            con.execute("CREATE INDEX IF NOT EXISTS ix_cdr_linea ON cdr (linea_origen)")
            con.execute("CREATE INDEX IF NOT EXISTS ix_cdr_fecha ON cdr (fecha_inicio)")
    finally:
        con.close()

    errores = {e: conteo.get(e, 0) for e in ERRORES}
    validos = conteo.get("valido", 0)
    return {"leidos": validos + sum(errores.values()), "validos": validos,
            "rechazados": sum(errores.values()), "errores": errores}


if __name__ == "__main__":
    import time

    inicio = time.perf_counter()
    print(cargar_cdr(Path(sys.argv[1]), Path(sys.argv[2])))
    print(f"{time.perf_counter() - inicio:.1f} s")
```

## Explicación

Este diseño separa tres responsabilidades:

1. **Mover bytes** (CSV → `paso_cdr`): rápido y tonto, todo como texto, nada puede fallar por un dato malo.
2. **Decidir** (SQL): las reglas de negocio en un solo lugar, legibles y fáciles de auditar.
3. **Publicar** (`cdr` y `rechazos`): solo datos limpios y tipados en la tabla que usan los demás.

Es **repetible** por dos razones: la tabla de paso se vacía al empezar, e `INSERT OR IGNORE` con clave primaria descarta lo que ya estaba. Si la carga se cae a la mitad, la vuelves a ejecutar y listo.

Los índices se crean **al final**: con la tabla ya llena, SQLite ordena una sola vez, mucho más rápido que actualizar el índice fila por fila durante la carga.

En PostgreSQL el diseño es idéntico, pero el paso 1 sería un `COPY` y los `INSERT OR IGNORE` serían `INSERT ... ON CONFLICT DO NOTHING`.
