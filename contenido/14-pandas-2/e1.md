## Solución

```python
import numpy as np
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"}, keep_default_na=False)


def consumo_mensual(cdr):
    v = cdr[cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]) & (cdr["duracion_seg"] >= 0)].copy()
    v["es_voz"] = v["tipo"] == "VOZ"
    v["minutos"] = np.where(v["es_voz"], (v["duracion_seg"] + 59) // 60, 0)
    v["mb_datos"] = np.where(v["tipo"] == "DATOS", v["mb"], 0.0)
    v["es_sms"] = v["tipo"] == "SMS"
    resultado = v.groupby("linea_origen").agg(
        registros=("cdr_id", "size"),
        llamadas=("es_voz", "sum"),
        minutos=("minutos", "sum"),
        mb=("mb_datos", "sum"),
        sms=("es_sms", "sum"),
    )
    resultado["mb"] = resultado["mb"].round(3)
    return resultado


print(consumo_mensual(cdr).head())
```

## Explicación

El truco de **columnas auxiliares** (`es_voz`, `minutos`, `mb_datos`, `es_sms`) convierte un cálculo condicional en sumas simples: sumar un booleano cuenta los `True`, y sumar una columna con ceros donde no corresponde suma solo lo que importa. Así un solo `groupby` calcula todo en una pasada.

Esta tabla de consumo es el insumo de la factura: tiene exactamente lo que necesitan las reglas de facturación (minutos, megas y SMS por línea).
