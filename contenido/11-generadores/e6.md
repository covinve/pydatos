## Enunciado

Vas a comparar los dos métodos de detección de duplicados de la lección 4 sobre `cdr.csv`:

1. `ids(ruta)` → generador con el `cdr_id` (int) de cada registro, en orden.
2. `duplicados_exacto(ids)` → cantidad de registros duplicados usando un `set` con todos los IDs vistos.
3. `duplicados_en_ventana(ids, ventana)` → **generador** que entrega `(posicion, cdr_id)` de cada duplicado detectado recordando solo los últimos `ventana` IDs **distintos** (posición desde 1). Usa `collections.deque(maxlen=...)` y un `set` sincronizados.
4. `ventana_suficiente(ruta, ventana)` → `True` si con esa ventana se detectan **exactamente** los mismos duplicados que con el método exacto.

El generador del curso siembra los duplicados a menos de 5.000 registros del original, así que con `ventana=5000` debe coincidir con `esperado.json`.

import json

ESPERADO = json.loads(Path("esperado.json").read_text(encoding="utf-8"))["cdr"]["errores"]["duplicado"]

## Pista 2

Para la ventana, sigue la función de la lección 4 pero entrega la posición: recorre con `enumerate(ids, start=1)`. Cuando la ventana está llena, antes de agregar un ID nuevo, quita del `set` el más viejo (`recientes[0]`); el `deque` con `maxlen` lo descarta solo al hacer `append`.

## Solución

```python
from collections import deque


def ids(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield int(linea.split("|", 1)[0])


def duplicados_exacto(ids):
    vistos = set()
    duplicados = 0
    for cdr_id in ids:
        if cdr_id in vistos:
            duplicados += 1
        else:
            vistos.add(cdr_id)
    return duplicados


def duplicados_en_ventana(ids, ventana):
    recientes = deque(maxlen=ventana)
    vistos = set()
    for posicion, cdr_id in enumerate(ids, start=1):
        if cdr_id in vistos:
            yield posicion, cdr_id
            continue
        if len(recientes) == ventana:
            vistos.discard(recientes[0])
        recientes.append(cdr_id)
        vistos.add(cdr_id)


def ventana_suficiente(ruta, ventana):
    con_ventana = sum(1 for _ in duplicados_en_ventana(ids(ruta), ventana))
    return con_ventana == duplicados_exacto(ids(ruta))


print(duplicados_exacto(ids("cdr.csv")))
print(sum(1 for _ in duplicados_en_ventana(ids("cdr.csv"), 5000)))
```

## Explicación

Los dos métodos tienen costos muy distintos con el archivo de 20 GB (unos 280 millones de registros):

| Método | Memoria | Exactitud |
|---|---|---|
| `set` con todos los IDs | ~15 GB: no cabe en 16 GB de RAM | Exacto |
| Ventana de 5.000 | Unos KB | Exacto **si** los duplicados llegan cerca |

`ventana_suficiente` es la **verificación del supuesto**: con un archivo mediano (donde el método exacto sí cabe), compruebas que la ventana no pierde duplicados. Si coinciden, tienes evidencia para usar la ventana con el archivo completo, y conviene repetir la verificación de vez en cuando.

Recorrer el archivo dos veces (una por método) es aceptable aquí porque es una verificación. En producción usarías solo la ventana, en una sola pasada.
