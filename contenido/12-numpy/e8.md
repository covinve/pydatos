## Enunciado

Comercial quiere recomendar planes según el consumo de cada cliente. Como el consumo varía mes a mes, vas a **simularlo**: un cliente cuyo promedio es `lam` minutos al mes consume, cada mes, una cantidad con distribución de **Poisson** de media `lam`.

1. `simular_minutos(lam, meses, semilla)` → array con los minutos simulados de `meses` meses (`np.random.default_rng(semilla).poisson(lam, meses)`).
2. `costo_esperado(minutos, plan)` → costo promedio mensual del plan con esos minutos: `cargo_fijo + max(0, minutos - incluidos) × tarifa_minuto`, promediado sobre los meses (float, 1 decimal). Sin bucles.
3. `prob_exceder(minutos, incluidos)` → proporción de meses en que se supera la bolsa (float, 3 decimales).
4. `plan_recomendado(lam, planes, meses=20_000, semilla=2026)` → el `plan_id` con menor costo esperado (usa la **misma** simulación para todos los planes, para compararlos con justicia).

```python
PLANES = [
    {"plan_id": "BAS10", "cargo_fijo": 19900, "incluidos": 100, "tarifa_minuto": 150},
    {"plan_id": "HOG30", "cargo_fijo": 35900, "incluidos": 300, "tarifa_minuto": 120},
    {"plan_id": "HOG60", "cargo_fijo": 55900, "incluidos": 600, "tarifa_minuto": 110},
]
plan_recomendado(80, PLANES)    # "BAS10"
```

## Solución

```python
import numpy as np

PLANES = [
    {"plan_id": "BAS10", "cargo_fijo": 19900, "incluidos": 100, "tarifa_minuto": 150},
    {"plan_id": "HOG30", "cargo_fijo": 35900, "incluidos": 300, "tarifa_minuto": 120},
    {"plan_id": "HOG60", "cargo_fijo": 55900, "incluidos": 600, "tarifa_minuto": 110},
]


def simular_minutos(lam, meses, semilla):
    return np.random.default_rng(semilla).poisson(lam, meses)


def costo_esperado(minutos, plan):
    exceso = np.maximum(minutos - plan["incluidos"], 0)
    return round(float((plan["cargo_fijo"] + exceso * plan["tarifa_minuto"]).mean()), 1)


def prob_exceder(minutos, incluidos):
    return round(float((minutos > incluidos).mean()), 3)


def plan_recomendado(lam, planes, meses=20_000, semilla=2026):
    minutos = simular_minutos(lam, meses, semilla)
    return min(planes, key=lambda plan: costo_esperado(minutos, plan))["plan_id"]


for lam in [80, 250, 450]:
    print(lam, plan_recomendado(lam, PLANES))
```

## Explicación

Esto es una **simulación de Monte Carlo**: en lugar de resolver una fórmula, generas miles de escenarios posibles y promedias. Con NumPy, simular 20.000 meses y evaluar tres planes toma milisegundos.

Dos ideas importantes:

- **Semilla fija = resultados reproducibles.** Sin semilla, cada ejecución daría una recomendación ligeramente distinta y las pruebas serían inestables.
- **Números aleatorios comunes.** Comparar los planes con **la misma** simulación elimina el ruido: las diferencias de costo se deben a los planes, no a que a uno "le tocaron" meses más caros.

Fíjate en el caso de 250 minutos: aunque el promedio cabe en el plan de 100 minutos más un exceso, el exceso le cuesta más al cliente que el cargo fijo del plan de 300. Así se diseñan las recomendaciones de "cambio de plan".
