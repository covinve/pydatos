Antes de cualquier modelo o reporte, hay que **describir** los datos: dónde se concentran, cuánto varían, qué tan extremos son sus valores raros.

## Medidas de centro

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

print(f"Promedio: {d.mean():.1f} s")
print(f"Mediana:  {d.median():.1f} s")
print(f"Moda:     {d.mode().iloc[0]} s")
```

| Medida | Qué es | Cuidado |
|---|---|---|
| Promedio (media) | Suma / cantidad | Muy sensible a valores extremos |
| Mediana | El valor del medio al ordenar | Robusta: no le afectan los extremos |
| Moda | El valor más frecuente | Útil en categorías |

Cuando el promedio es mucho mayor que la mediana, la distribución tiene **cola a la derecha**: unos pocos valores muy grandes tiran el promedio hacia arriba. Es lo normal en duraciones, consumo de datos y facturas.

## Dispersión y percentiles

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

print(f"Desviación estándar: {d.std():.1f}")
print(d.quantile([0.10, 0.25, 0.50, 0.75, 0.90, 0.99]))
print(f"Asimetría: {d.skew():.2f}  (positiva = cola a la derecha)")
```

Los percentiles responden preguntas concretas: "el 90 % de las llamadas dura menos de X segundos". Son la base de los acuerdos de servicio y de los umbrales de alerta.

:::reto Describe las sesiones de datos
Con las megas de las sesiones de **DATOS** de la muestra (`mb`) y las duraciones de voz (`d`), calcula:

- `promedio` y `mediana` de `mb`;
- `cola_derecha`: `True` si el promedio de `mb` es mayor que su mediana;
- `p90`: el percentil 90 de `d`;
- `pct_cortas`: la proporción de llamadas de `d` que duran **menos de 5 minutos** (300 segundos).

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
mb = cdr.loc[cdr["tipo"] == "DATOS", "mb"]
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

# promedio, mediana, cola_derecha, p90 y pct_cortas

print(promedio, mediana, cola_derecha, p90, pct_cortas)
```

:::pista
`mb.mean()`, `mb.median()`, `d.quantile(0.90)`. Para la proporción, el promedio de una máscara: `(d < 300).mean()`.
:::

```pyprueba
import pandas as pd


def _datos():
    c = pd.read_csv("cdr.csv", sep="|", keep_default_na=False)
    return c.loc[c["tipo"] == "DATOS", "mb"], c.loc[(c["tipo"] == "VOZ") & (c["duracion_seg"] > 0), "duracion_seg"]


def prueba_centro():
    """promedio, mediana y cola_derecha"""
    requiere("promedio", "mediana", "cola_derecha")
    mb_, _ = _datos()
    cerca(float(promedio), float(mb_.mean()), 1e-6, "promedio")
    cerca(float(mediana), float(mb_.median()), 1e-6, "mediana")
    igual(bool(cola_derecha), True, "cola_derecha")


def prueba_percentiles():
    """p90 y pct_cortas"""
    requiere("p90", "pct_cortas")
    _, d_ = _datos()
    cerca(float(p90), float(d_.quantile(0.90)), 1e-6, "p90")
    cerca(float(pct_cortas), float((d_ < 300).mean()), 1e-9, "pct_cortas")
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
mb = cdr.loc[cdr["tipo"] == "DATOS", "mb"]
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

promedio = mb.mean()
mediana = mb.median()
cola_derecha = promedio > mediana
p90 = d.quantile(0.90)
pct_cortas = (d < 300).mean()

print(promedio, mediana, cola_derecha, p90, pct_cortas)
```

## Valores atípicos con el rango intercuartílico

Una regla clásica y robusta: un valor es atípico si está más de **1,5 × IQR** por fuera de la caja.

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
mb = cdr.loc[cdr["tipo"] == "DATOS", "mb"]

q1, q3 = mb.quantile([0.25, 0.75])
iqr = q3 - q1
limite_superior = q3 + 1.5 * iqr
atipicos = mb[mb > limite_superior]
print(f"Q1={q1:.1f}  Q3={q3:.1f}  IQR={iqr:.1f}  límite={limite_superior:.1f} MB")
print(f"{len(atipicos)} sesiones atípicas de {len(mb)} ({len(atipicos) / len(mb):.1%})")
```

:::error Atípico no significa error
Una sesión de 3 GB puede ser una descarga legítima. "Atípico" significa "merece revisión", no "hay que borrarlo". Borrar atípicos sin entenderlos puede esconder justamente lo que importa: fraude, errores de tarificación o clientes valiosos.
:::

Con distribuciones muy asimétricas, a veces conviene aplicar la regla sobre el **logaritmo** de los valores (`np.log1p(mb)`), que acerca la forma a una campana.

:::reto Llamadas atípicas
Aplica la regla del IQR a las duraciones de las llamadas de voz (`d`):

- `q1`, `q3` e `iqr`;
- `limite`: el límite superior (Q3 + 1,5 × IQR);
- `atipicas`: las duraciones que superan el límite (una Series);
- `pct_atipicas`: qué proporción del total son atípicas.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

# q1, q3, iqr, limite, atipicas y pct_atipicas

print(q1, q3, iqr, limite, len(atipicas), f"{pct_atipicas:.1%}")
```

:::pista
`q1, q3 = d.quantile([0.25, 0.75])`, `iqr = q3 - q1`, `limite = q3 + 1.5 * iqr`, `atipicas = d[d > limite]` y `pct_atipicas = len(atipicas) / len(d)`.
:::

```pyprueba
import pandas as pd


def prueba_cuartiles():
    """q1, q3, iqr y limite"""
    requiere("q1", "q3", "iqr", "limite")
    c = pd.read_csv("cdr.csv", sep="|", keep_default_na=False)
    d_ = c.loc[(c["tipo"] == "VOZ") & (c["duracion_seg"] > 0), "duracion_seg"]
    e1, e3 = d_.quantile([0.25, 0.75])
    cerca(float(q1), float(e1), 1e-9, "q1")
    cerca(float(q3), float(e3), 1e-9, "q3")
    cerca(float(iqr), float(e3 - e1), 1e-9, "iqr")
    cerca(float(limite), float(e3 + 1.5 * (e3 - e1)), 1e-9, "limite")


def prueba_atipicas():
    """atipicas y pct_atipicas"""
    requiere("atipicas", "pct_atipicas", "d")
    igual(len(atipicas), int((d > limite).sum()), "cantidad de atípicas")
    cerca(float(pct_atipicas), len(atipicas) / len(d), 1e-9, "pct_atipicas")
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
d = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

q1, q3 = d.quantile([0.25, 0.75])
iqr = q3 - q1
limite = q3 + 1.5 * iqr
atipicas = d[d > limite]
pct_atipicas = len(atipicas) / len(d)

print(q1, q3, iqr, limite, len(atipicas), f"{pct_atipicas:.1%}")
```

## Correlación

La correlación mide si dos variables se mueven juntas, entre −1 y 1:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
v = cdr[cdr["tipo"].isin(["VOZ", "DATOS", "SMS"]) & (cdr["duracion_seg"] >= 0)]
por_linea = pd.DataFrame({
    "minutos": ((v["duracion_seg"] + 59) // 60).where(v["tipo"] == "VOZ", 0).groupby(v["linea_origen"]).sum(),
    "mb": v["mb"].where(v["tipo"] == "DATOS", 0).groupby(v["linea_origen"]).sum(),
    "sms": (v["tipo"] == "SMS").groupby(v["linea_origen"]).sum(),
})
print(por_linea.corr().round(2))                    # Pearson: relación lineal
print(por_linea.corr(method="spearman").round(2))   # Spearman: relación de orden, robusta a extremos
```

| Valor | Interpretación |
|---|---|
| Cerca de 1 | Cuando una sube, la otra también |
| Cerca de 0 | Sin relación (lineal o de orden) |
| Cerca de −1 | Cuando una sube, la otra baja |

:::reto Pearson contra Spearman
Con la tabla `por_linea` (minutos, megas y SMS de cada línea), calcula la correlación entre **minutos** y **megas** de dos formas:

- `pearson`: la correlación de Pearson;
- `spearman`: la de Spearman;
- `mas_robusta`: el nombre (`"pearson"` o `"spearman"`) de la que da el valor **más alto**.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
v = cdr[cdr["tipo"].isin(["VOZ", "DATOS", "SMS"]) & (cdr["duracion_seg"] >= 0)]
por_linea = pd.DataFrame({
    "minutos": ((v["duracion_seg"] + 59) // 60).where(v["tipo"] == "VOZ", 0).groupby(v["linea_origen"]).sum(),
    "mb": v["mb"].where(v["tipo"] == "DATOS", 0).groupby(v["linea_origen"]).sum(),
    "sms": (v["tipo"] == "SMS").groupby(v["linea_origen"]).sum(),
})

# pearson, spearman y mas_robusta

print(round(pearson, 3), round(spearman, 3), mas_robusta)
```

:::pista
`por_linea["minutos"].corr(por_linea["mb"])` es Pearson; agrega `method="spearman"` para la otra.
:::

```pyprueba
def prueba_correlaciones():
    """pearson, spearman y la mayor"""
    requiere("pearson", "spearman", "mas_robusta", "por_linea")
    p = por_linea["minutos"].corr(por_linea["mb"])
    s = por_linea["minutos"].corr(por_linea["mb"], method="spearman")
    cerca(float(pearson), float(p), 1e-9, "pearson")
    cerca(float(spearman), float(s), 1e-9, "spearman")
    igual(mas_robusta, "pearson" if p > s else "spearman", "mas_robusta")
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
v = cdr[cdr["tipo"].isin(["VOZ", "DATOS", "SMS"]) & (cdr["duracion_seg"] >= 0)]
por_linea = pd.DataFrame({
    "minutos": ((v["duracion_seg"] + 59) // 60).where(v["tipo"] == "VOZ", 0).groupby(v["linea_origen"]).sum(),
    "mb": v["mb"].where(v["tipo"] == "DATOS", 0).groupby(v["linea_origen"]).sum(),
    "sms": (v["tipo"] == "SMS").groupby(v["linea_origen"]).sum(),
})

pearson = por_linea["minutos"].corr(por_linea["mb"])
spearman = por_linea["minutos"].corr(por_linea["mb"], method="spearman")
mas_robusta = "pearson" if pearson > spearman else "spearman"

print(round(pearson, 3), round(spearman, 3), mas_robusta)
```
:::

:::capo Correlación no es causalidad
Que los clientes que más hablan también usen más datos no significa que hablar cause usar datos: ambos pueden depender de una tercera variable (por ejemplo, ser cliente empresarial). En los datos del curso, el generador asigna a cada cliente una "intensidad" que aumenta todo su consumo a la vez: por eso verás correlaciones positivas.
:::

## Cuestionario

? Las facturas tienen promedio de $95.000 y mediana de $62.000. ¿Qué indica?
- [ ] Que hay un error
- [x] Que hay facturas muy altas que tiran el promedio hacia arriba (cola a la derecha)
- [ ] Que la mayoría de las facturas son de $95.000
- [ ] Que la distribución es simétrica
> En distribuciones asimétricas a la derecha, el promedio queda por encima de la mediana.

? ¿Cómo se calcula el límite superior de atípicos con la regla del IQR?
- [ ] Promedio + 2 × desviación
- [x] Q3 + 1,5 × (Q3 − Q1)
- [ ] El percentil 99
- [ ] El máximo menos el mínimo
> Es una regla robusta porque usa percentiles, que no dependen de los valores extremos.

? Una correlación de Spearman de 0,85 entre minutos y megas indica…
- [ ] Que los minutos causan el consumo de datos
- [x] Que los clientes con más minutos tienden a estar también entre los que más datos usan
- [ ] Que no hay relación
- [ ] Que el 85 % de los minutos son datos
> Spearman mide si el orden de los clientes es parecido en ambas variables, sin implicar causalidad.
