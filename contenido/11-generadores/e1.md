## Enunciado

Crea la clase `Periodo(inicio, fin)` (ambas fechas `date`, incluidas) que sea **iterable** y **reutilizable**: cada `for` sobre el mismo objeto debe empezar de nuevo. Además:

- `len(periodo)` → cantidad de días;
- `fecha in periodo` → `True` si la fecha está en el rango (sin recorrerlo).

```python
septiembre = Periodo(date(2026, 9, 1), date(2026, 9, 30))
len(septiembre)                      # 30
date(2026, 9, 15) in septiembre      # True
list(septiembre)[:2]                 # [date(2026, 9, 1), date(2026, 9, 2)]
list(septiembre)[:2]                 # igual: se puede recorrer otra vez
```

## Código inicial

```python
from datetime import date, timedelta


class Periodo:
    def __init__(self, inicio, fin):
        self.inicio = inicio
        self.fin = fin


septiembre = Periodo(date(2026, 9, 1), date(2026, 9, 30))
print(len(septiembre))
```

## Pista 1

Para que sea **reutilizable**, `__iter__` no debe devolver `self`: debe crear un iterador nuevo cada vez. La forma más simple es que `__iter__` sea un generador:

```python
def __iter__(self):
    dia = self.inicio
    while dia <= self.fin:
        yield dia
        dia += timedelta(days=1)
```

## Pista 2

`len` se calcula sin recorrer: `(self.fin - self.inicio).days + 1`, con `max(0, ...)` para el periodo vacío. `__contains__` compara: `self.inicio <= fecha <= self.fin`.

## Solución

```python
from datetime import date, timedelta


class Periodo:
    def __init__(self, inicio, fin):
        self.inicio = inicio
        self.fin = fin

    def __iter__(self):
        dia = self.inicio
        while dia <= self.fin:
            yield dia
            dia += timedelta(days=1)

    def __len__(self):
        return max(0, (self.fin - self.inicio).days + 1)

    def __contains__(self, fecha):
        return self.inicio <= fecha <= self.fin


septiembre = Periodo(date(2026, 9, 1), date(2026, 9, 30))
print(len(septiembre))
```

## Explicación

Hay una diferencia importante con la clase `DiasDelPeriodo` de la lección 1:

- Allí `__iter__` devolvía `self`: el objeto **era** su propio iterador y se gastaba al recorrerlo.
- Aquí `__iter__` es un generador: **cada `for` recibe un iterador nuevo**. El objeto es un iterable reutilizable, como una lista o un `range`.

`__len__` y `__contains__` se calculan con aritmética de fechas, sin recorrer los días: igual que `range`, que sabe si un número está dentro sin generar todos sus valores.
