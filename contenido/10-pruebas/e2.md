## Enunciado

El módulo `conversion.py` (en tu carpeta de trabajo) tiene `a_pesos(texto)`, la función del módulo 7: convierte textos como `"$ 1.234.567,50"` a `Decimal` y lanza `ValueError` con un mensaje que incluye el texto original entre comillas cuando el valor no es válido.

Escribe pruebas que verifiquen:

- al menos un caso válido con decimales y uno con símbolo `$`;
- que un texto inválido lanza `ValueError` (usa `pytest.raises`);
- que el mensaje del error **incluye el texto original** (usa `match=`).

Tus pruebas deben pasar con la versión correcta y atrapar tres mutantes.

## Preparación

from pathlib import Path

## Pista 1

```python
def test_texto_invalido_lanza_valueerror():
    with pytest.raises(ValueError):
        a_pesos("abc")
```

El bloque `with` falla la prueba si **no** se lanza la excepción.

## Pista 2

`match` recibe una expresión regular que se busca en el mensaje. Para buscar el texto `'abc'` (con comillas) sirve directamente `match="'abc'"`. Si el texto tuviera símbolos especiales como `$` o `.`, usa `re.escape(...)`.

## Solución

```python
from decimal import Decimal

import pytest

from conversion import a_pesos


def test_valor_simple():
    assert a_pesos("48719") == Decimal("48719")


def test_formato_colombiano_con_decimales():
    assert a_pesos("1.234.567,50") == Decimal("1234567.50")


def test_con_simbolo_de_pesos():
    assert a_pesos("$ 48.719") == Decimal("48719")


def test_texto_invalido_lanza_valueerror():
    with pytest.raises(ValueError):
        a_pesos("abc")


def test_el_mensaje_incluye_el_texto():
    with pytest.raises(ValueError, match="'abc'"):
        a_pesos("abc")
```

## Explicación

Probar el **camino feliz** no basta: la mitad de los errores de un proceso de facturación están en cómo maneja los datos malos. El mutante "devuelve 0 en vez de error" es especialmente peligroso: el proceso sigue como si nada y factura en cero. Solo una prueba con `pytest.raises` lo detecta.

Probar el mensaje (`match`) parece un detalle, pero ese mensaje es lo que lee quien investiga un archivo rechazado a las 3 de la mañana.
