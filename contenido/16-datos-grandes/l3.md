**Polars** es un motor de DataFrames escrito en Rust. Se parece a Pandas, pero su forma de pensar es distinta: en lugar de modificar columnas paso a paso, describes **expresiones** que el motor optimiza y ejecuta en paralelo.

```pyrun
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
print(cdr.shape)
print(cdr.head(3))
```

## Expresiones

Una expresión (`pl.col(...)`) describe un cálculo sobre columnas. Se usa dentro de **contextos**: `select`, `with_columns`, `filter` y `group_by().agg()`.

```pyrun
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})

resultado = (
    cdr.filter((pl.col("tipo") == "VOZ") & (pl.col("duracion_seg") >= 0))
       .with_columns(minutos=(pl.col("duracion_seg") + 59) // 60)
       .group_by("destino")
       .agg(
           llamadas=pl.len(),
           minutos=pl.col("minutos").sum(),
           mas_larga=pl.col("duracion_seg").max(),
       )
       .sort("minutos", descending=True)
)
print(resultado)
```

| Pandas | Polars |
|---|---|
| `df[df["tipo"] == "VOZ"]` | `df.filter(pl.col("tipo") == "VOZ")` |
| `df["minutos"] = ...` | `df.with_columns(minutos=...)` |
| `df[["a", "b"]]` | `df.select("a", "b")` |
| `np.where(c, a, b)` | `pl.when(c).then(a).otherwise(b)` |
| `df.groupby("g").agg(...)` | `df.group_by("g").agg(...)` |
| `df.merge(otro, on="k")` | `df.join(otro, on="k")` |

:::capo Sin índice
Polars no tiene índice como Pandas: las filas no tienen etiquetas. Todo se hace con columnas, lo que elimina muchas confusiones (`reset_index`, alineación inesperada).
:::

:::reto Tu primera cadena de Polars
Con una sola cadena de Polars sobre el `cdr` de la muestra, crea `por_linea`: las sesiones de **DATOS** de líneas **no vacías**, agrupadas por `linea_origen`, con las columnas `sesiones` (cantidad) y `mb_total` (suma de `mb`), ordenadas de más a menos megas.

Después crea `top3`: la **lista** de las tres líneas con más megas.

```pyreto
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})

# por_linea y top3

print(por_linea.head())
print(top3)
```

:::pista
`cdr.filter((pl.col("tipo") == "DATOS") & pl.col("linea_origen").is_not_null()).group_by("linea_origen").agg(sesiones=pl.len(), mb_total=pl.col("mb").sum()).sort("mb_total", descending=True)`. Para la lista: `por_linea["linea_origen"].head(3).to_list()`.
:::

```pyprueba
import pandas as pd


def _esperado():
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
    g = d[(d["tipo"] == "DATOS") & (d["linea_origen"] != "")].groupby("linea_origen").agg(sesiones=("cdr_id", "size"), mb_total=("mb", "sum"))
    return g.sort_values("mb_total", ascending=False)


def prueba_por_linea():
    """por_linea tiene las sesiones y megas de cada línea"""
    requiere("por_linea")
    esperado = _esperado()
    igual(por_linea.height, len(esperado), "cantidad de líneas")
    obtenido = dict(zip(por_linea["linea_origen"].to_list(), por_linea["sesiones"].to_list()))
    igual(obtenido, {str(k): int(v) for k, v in esperado["sesiones"].items()}, "sesiones por línea")


def prueba_top3():
    """top3 son las tres líneas con más megas"""
    requiere("top3")
    igual([str(x) for x in top3], [str(x) for x in _esperado().index[:3]])
```

```pysolucion
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
```

## when/then/otherwise

```pyrun
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})

tarifado = cdr.with_columns(
    tarifa=pl.when(pl.col("destino") == "LOCAL").then(100)
             .when(pl.col("destino") == "NACIONAL").then(120)
             .when(pl.col("destino") == "INTERNACIONAL").then(950)
             .otherwise(0),
).with_columns(valor=((pl.col("duracion_seg").clip(lower_bound=0) + 59) // 60) * pl.col("tarifa"))
print(tarifado.filter(pl.col("tipo") == "VOZ").select("destino", "duracion_seg", "valor").head())
```

:::reto Clasifica las sesiones
Agrega a las sesiones de **DATOS** la columna `tamano` con `when/then/otherwise`:

| Megas | tamano |
|---|---|
| menos de 10 | `"pequeña"` |
| de 10 a menos de 100 | `"media"` |
| 100 o más | `"grande"` |

Después crea `conteo`: un diccionario `{tamano: cantidad}`.

```pyprueba
    igual({str(k): int(v) for k, v in dict(conteo).items()}, esperado)
```

## Modo perezoso: scan_csv y collect

Con archivos grandes, usa `scan_csv` (o `scan_parquet`) en lugar de `read_csv`. Todo lo que encadenes es un **plan**; nada se ejecuta hasta `collect()`:

```pyrun
import polars as pl

# En tu computador: pl.scan_csv("cdr.csv", ...). En el navegador: pl.read_csv(...).lazy() (ver la nota abajo)
fuente = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String}).lazy()
plan = (
    fuente
      .filter(pl.col("tipo") == "DATOS")
      .group_by("linea_origen")
      .agg(mb=pl.col("mb").sum())
      .sort("mb", descending=True)
      .head(5)
)
print(plan.explain())     # el plan optimizado: fíjate qué columnas lee
print(plan.collect())
```

En `explain()` verás el plan optimizado. Con `scan_csv`, además, Polars solo lee del archivo las columnas `tipo`, `linea_origen` y `mb` (*projection pushdown*) y aplica el filtro mientras lee (*predicate pushdown*).

:::nota Polars en el navegador
La versión de Polars que corre en esta página (Pyodide) no incluye `scan_csv` ni el motor *streaming*. Aquí usamos `pl.read_csv(...).lazy()`, que crea el mismo tipo de plan perezoso a partir de un archivo ya leído. En VS Code, con archivos grandes, usa siempre `pl.scan_csv(...)`: el resto del código es idéntico.
:::

Con archivos más grandes que la memoria, `collect(engine="streaming")` procesa por lotes.

:::reto Un plan antes de ejecutar
1. Arma `plan`: un plan **perezoso** que, a partir de `fuente`, filtre la VOZ con duración ≥ 0, calcule los minutos facturables, agrupe por `destino` sumando los minutos y ordene de más a menos.
2. Ejecútalo en `resultado`.

`plan` debe ser un `LazyFrame` (todavía sin ejecutar).

```pyreto
import polars as pl

fuente = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String}).lazy()

# plan y resultado

print(type(plan).__name__)
print(resultado)
```

:::pista
Encadena sobre `fuente`: `.filter(...)`, `.with_columns(minutos=(pl.col("duracion_seg") + 59) // 60)`, `.group_by("destino").agg(minutos=pl.col("minutos").sum())` y `.sort("minutos", descending=True)`. Al final, `resultado = plan.collect()`.
:::

```pyprueba
import pandas as pd
import polars as pl


def prueba_perezoso():
    """plan es un LazyFrame"""
    requiere("plan")
    assert isinstance(plan, pl.LazyFrame), f"plan debe ser un LazyFrame (sin collect), es {type(plan).__name__}"


def prueba_resultado():
    """resultado tiene los minutos por destino, de mayor a menor"""
    requiere("resultado")
    d = pd.read_csv("cdr.csv", sep="|", keep_default_na=False)
    v = d[(d["tipo"] == "VOZ") & (d["duracion_seg"] >= 0)]
    esperado = ((v["duracion_seg"] + 59) // 60).groupby(v["destino"]).sum().sort_values(ascending=False)
    igual(resultado["destino"].to_list(), [str(x) for x in esperado.index], "destinos en orden")
    igual(resultado["minutos"].to_list(), [int(x) for x in esperado], "minutos")
```

```pysolucion
import polars as pl

fuente = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String}).lazy()

plan = (
    fuente
    .filter((pl.col("tipo") == "VOZ") & (pl.col("duracion_seg") >= 0))
    .with_columns(minutos=(pl.col("duracion_seg") + 59) // 60)
    .group_by("destino")
    .agg(minutos=pl.col("minutos").sum())
    .sort("minutos", descending=True)
)
resultado = plan.collect()

print(type(plan).__name__)
print(resultado)
```

## Joins y ventanas

```pyrun
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
clientes = pl.read_csv("clientes.csv", encoding="latin1", schema_overrides={"linea": pl.String, "documento": pl.String})

con_cliente = cdr.join(clientes.select("linea", "plan_id", "region"), left_on="linea_origen", right_on="linea", how="left")
print(con_cliente.select("cdr_id", "linea_origen", "plan_id", "region").head(3))

# ventana: total de la línea en cada fila (como transform de Pandas)
print(cdr.filter(pl.col("tipo") == "VOZ")
         .with_columns(total_linea=pl.col("duracion_seg").sum().over("linea_origen"))
         .select("linea_origen", "duracion_seg", "total_linea").head(3))
```

`.over("columna")` es la función de ventana de Polars: calcula por grupo y devuelve un valor por fila.

:::reto Cruce y ventana en Polars
1. Crea `por_region`: los minutos de VOZ válidos por `region`, cruzando los CDR con `clientes` (`join` interno por línea), ordenados de más a menos.
2. Crea `voz` con una columna `pct_linea`: qué porcentaje del total de segundos **de su línea** representa cada llamada (con `.over`), redondeado a 1 decimal.

```pyreto
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
clientes = pl.read_csv("clientes.csv", encoding="latin1", schema_overrides={"linea": pl.String, "documento": pl.String})
voz = cdr.filter((pl.col("tipo") == "VOZ") & (pl.col("duracion_seg") >= 0)).with_columns(minutos=(pl.col("duracion_seg") + 59) // 60)

# por_region y la columna pct_linea en voz

print(por_region)
print(voz.select("linea_origen", "duracion_seg", "pct_linea").head())
```

:::pista
`voz.join(clientes.select("linea", "region"), left_on="linea_origen", right_on="linea", how="inner").group_by("region").agg(minutos=pl.col("minutos").sum()).sort("minutos", descending=True)`. Para el porcentaje: `(pl.col("duracion_seg") / pl.col("duracion_seg").sum().over("linea_origen") * 100).round(1)`.
:::

```pyprueba
import pandas as pd


def prueba_por_region():
    """Minutos por región, de mayor a menor"""
    requiere("por_region")
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
    c = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
    v = d[(d["tipo"] == "VOZ") & (d["duracion_seg"] >= 0) & (d["linea_origen"] != "")].copy()
    v["minutos"] = (v["duracion_seg"] + 59) // 60
    esperado = v.merge(c[["linea", "region"]], left_on="linea_origen", right_on="linea").groupby("region")["minutos"].sum().sort_values(ascending=False)
    igual(por_region["region"].to_list(), [str(x) for x in esperado.index], "regiones")
    igual(por_region["minutos"].to_list(), [int(x) for x in esperado], "minutos")


def prueba_pct_linea():
    """pct_linea suma 100 en cada línea"""
    requiere("voz")
    assert "pct_linea" in voz.columns, "Agrega la columna pct_linea a voz"
    import polars as pl
    sumas = voz.filter(pl.col("linea_origen").is_not_null() & (pl.col("duracion_seg").sum().over("linea_origen") > 0)).group_by("linea_origen").agg(pl.col("pct_linea").sum())
    assert all(abs(s - 100) < 1 for s in sumas["pct_linea"].to_list()), "En cada línea los porcentajes deben sumar ~100"
    assert ".over(" in codigo, "Calcula el total de la línea con .over"
```

```pysolucion
import polars as pl

cdr = pl.read_csv("cdr.csv", separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
clientes = pl.read_csv("clientes.csv", encoding="latin1", schema_overrides={"linea": pl.String, "documento": pl.String})
voz = cdr.filter((pl.col("tipo") == "VOZ") & (pl.col("duracion_seg") >= 0)).with_columns(minutos=(pl.col("duracion_seg") + 59) // 60)

por_region = (
    voz.join(clientes.select("linea", "region"), left_on="linea_origen", right_on="linea", how="inner")
       .group_by("region")
       .agg(minutos=pl.col("minutos").sum())
       .sort("minutos", descending=True)
)
voz = voz.with_columns(pct_linea=(pl.col("duracion_seg") / pl.col("duracion_seg").sum().over("linea_origen") * 100).round(1))

print(por_region)
print(voz.select("linea_origen", "duracion_seg", "pct_linea").head())
```

:::telco Pipelines legibles
Una cadena de Polars se lee de arriba abajo como la descripción del proceso: filtrar válidos, calcular minutos, cruzar con clientes, agrupar por línea. Y, por ser perezosa, el motor decide el orden más eficiente para ejecutarla.
:::

## Cuestionario

? ¿Qué hace `.with_columns(minutos=...)` en Polars?
- [ ] Modifica el DataFrame original
- [x] Devuelve un DataFrame nuevo con la columna agregada o reemplazada
- [ ] Filtra filas
- [ ] Agrupa
> En Polars los DataFrames son inmutables: cada operación devuelve uno nuevo.

? ¿Cuándo lee el archivo `pl.scan_csv(...).filter(...).group_by(...).agg(...)`?
- [ ] Al llamar `scan_csv`
- [ ] Al llamar `filter`
- [x] Al llamar `collect()`
- [ ] Nunca
> Antes de `collect()` solo existe un plan.

? ¿Cuál es el equivalente de `transform("sum")` de Pandas en Polars?
- [ ] `.agg(pl.col("x").sum())`
- [x] `pl.col("x").sum().over("grupo")`
- [ ] `.group_by("grupo").sum()`
- [ ] `.window("grupo")`
> `.over()` calcula por grupo pero conserva una fila por registro.
