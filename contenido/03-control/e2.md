## Enunciado

Implementa las reglas de **consumo adicional** del curso (Referencia → Datos del curso). En los planes, `-1` significa **ilimitado**.

1. `valor_voz(minutos, minutos_incluidos, tarifa_minuto)` → `max(0, minutos − incluidos) × tarifa`. Ilimitado → 0.
2. `valor_datos(mb, mb_incluidos, tarifa_mb)` → las megas se redondean **hacia arriba**; luego `max(0, megas − incluidas) × tarifa`. Ilimitado → 0.
3. `valor_sms(sms, sms_incluidos, tarifa_sms)` → igual que voz. Ilimitado → 0.
4. `consumo_adicional(...)` → la suma de los tres anteriores más `minutos_internacionales × tarifa_internacional` (lo internacional **nunca** está incluido). Recibe, en este orden:

```python
consumo_adicional(minutos, minutos_incluidos, tarifa_minuto,
                  minutos_internacionales, tarifa_internacional,
                  mb, mb_incluidos, tarifa_mb,
                  sms, sms_incluidos, tarifa_sms)
```

```python
valor_voz(342, 300, 120)                 # 5040
valor_voz(5000, -1, 0)                   # 0   ← ilimitado
valor_datos(15500.2, 15360, 18)          # 2538
valor_sms(120, 100, 60)                  # 1200
consumo_adicional(342, 300, 120, 3, 950, 15500.2, 15360, 18, 120, 100, 60)   # 11628
```

## Pista 1

Las tres funciones de voz, datos y SMS tienen la misma forma. Empieza con la salida temprana para el ilimitado:

```python
def valor_voz(minutos, minutos_incluidos, tarifa_minuto):
    if minutos_incluidos == ILIMITADO:
        return 0
    return max(0, minutos - minutos_incluidos) * tarifa_minuto
```

## Pista 2

`valor_sms` es idéntica a `valor_voz`: puede simplemente llamarla. En `valor_datos` redondea primero con `math.ceil(mb)` y después aplica la misma lógica.

`consumo_adicional` solo suma: `valor_voz(...) + minutos_internacionales * tarifa_internacional + valor_datos(...) + valor_sms(...)`.

## Solución

```python
import math

ILIMITADO = -1


def valor_exceso(consumo, incluido, tarifa):
    if incluido == ILIMITADO:
        return 0
    return max(0, consumo - incluido) * tarifa


def valor_voz(minutos, minutos_incluidos, tarifa_minuto):
    return valor_exceso(minutos, minutos_incluidos, tarifa_minuto)


def valor_datos(mb, mb_incluidos, tarifa_mb):
    return valor_exceso(math.ceil(mb), mb_incluidos, tarifa_mb)


def valor_sms(sms, sms_incluidos, tarifa_sms):
    return valor_exceso(sms, sms_incluidos, tarifa_sms)


def consumo_adicional(minutos, minutos_incluidos, tarifa_minuto,
                      minutos_internacionales, tarifa_internacional,
                      mb, mb_incluidos, tarifa_mb,
                      sms, sms_incluidos, tarifa_sms):
    return (
        valor_voz(minutos, minutos_incluidos, tarifa_minuto)
        + minutos_internacionales * tarifa_internacional
        + valor_datos(mb, mb_incluidos, tarifa_mb)
        + valor_sms(sms, sms_incluidos, tarifa_sms)
    )


print(consumo_adicional(342, 300, 120, 3, 950, 15500.2, 15360, 18, 120, 100, 60))
```

## Explicación

Las tres reglas de exceso son **la misma regla** con distintos datos. La solución la escribe una vez en `valor_exceso` y las otras funciones solo la llaman, con un ajuste en datos (`math.ceil`). Si mañana el negocio decide que el ilimitado tiene un tope, se cambia en un solo lugar.

La constante `ILIMITADO = -1` evita el número mágico: `incluido == ILIMITADO` se entiende; `incluido == -1` obliga a recordar qué significaba.

Fíjate en `consumo_adicional`: once parámetros es demasiado, y es fácil pasarlos en desorden. En el módulo 4 pasarás un **diccionario con el plan** y otro con el consumo, y la función quedará con dos parámetros.
