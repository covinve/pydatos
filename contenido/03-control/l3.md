`for` es para "haz esto con cada elemento". `while` es para "haz esto **mientras** se cumpla algo", cuando no sabes de antemano cuántas vueltas darás.

## while

```pyrun
saldo_minutos = 300
llamada = 0

while saldo_minutos > 0:
    llamada = llamada + 1
    saldo_minutos = saldo_minutos - 45
    print(f"Llamada {llamada}: quedan {saldo_minutos} min")

print(f"La bolsa se agotó en la llamada {llamada}")
```

```pytrace
saldo = 100
llamadas = 0
while saldo > 0:
    saldo = saldo - 45
    llamadas = llamadas + 1
print(llamadas, saldo)
```

:::error El bucle infinito
Si la condición nunca se vuelve falsa, el bucle no termina:

```python
intentos = 0
while intentos < 3:
    print("Reintentando…")
    # olvidaste: intentos = intentos + 1
```

En VS Code lo detienes con `Ctrl + C` en la terminal. En esta página, el código se corta solo tras unos segundos. Regla de oro: **dentro de un `while` algo debe acercar la condición a ser falsa**.
:::

## break: salir del bucle

`break` termina el bucle inmediatamente, aunque queden elementos o la condición siga siendo verdadera. Es perfecto para **buscar**:

```pyrun
lineas = ["3001234567", "6014445566", "3109876543", "3157778899"]
buscada = "3109876543"

for posicion, linea in enumerate(lineas):
    if linea == buscada:
        print(f"Encontrada en la posición {posicion}")
        break
    print(f"Revisando {linea}…")
```

Fíjate que, una vez encontrada, no se revisa `3157778899`: con millones de registros, salir temprano ahorra mucho tiempo.

## continue: saltar al siguiente

`continue` abandona la vuelta actual y pasa a la siguiente. Sirve para **descartar** elementos sin anidar más código:

```pyrun
duraciones = [125, -30, 0, 61, -5, 3600]
total = 0

for duracion in duraciones:
    if duracion < 0:
        print(f"Descartada: {duracion}")
        continue
    total = total + (duracion + 59) // 60

print(f"Minutos facturables: {total}")
```

## while True con break

Un patrón muy común: repetir "para siempre" y salir cuando se cumpla la condición. Se usa cuando la condición de salida se conoce **en medio** de la vuelta:

```pyrun
intentos = 0
exito_en = 3   # simulamos que la conexión funciona en el tercer intento

while True:
    intentos = intentos + 1
    print(f"Intento {intentos}: conectando al servidor de mediación…")
    if intentos == exito_en:
        print("¡Conectado!")
        break
    if intentos >= 5:
        print("Demasiados intentos, abortando")
        break
```

:::telco Reintentos en procesos reales
Los procesos que descargan archivos de un servidor o consultan una API (módulo 18) fallan de vez en cuando. El patrón "reintentar hasta 3 veces y luego rendirse" es estándar, y siempre necesita un **límite**: un proceso que reintenta para siempre puede quedarse colgado toda la noche.
:::

## Cuestionario

? ¿Qué hace `continue` dentro de un `for`?
- [ ] Termina el bucle
- [x] Salta el resto de la vuelta actual y pasa al siguiente elemento

- [ ] Detiene el programa
> `continue` solo abandona la iteración actual; el bucle sigue con el siguiente elemento.

? ¿Cuándo es preferible `while` en lugar de `for`?
- [ ] Siempre, porque es más rápido
- [ ] Para recorrer una lista
- [x] Cuando no sabes de antemano cuántas vueltas habrá y depende de una condición
- [ ] Nunca, `while` es obsoleto
> `for` recorre colecciones conocidas; `while` repite hasta que una condición cambie.
