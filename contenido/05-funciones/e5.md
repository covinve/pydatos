## Enunciado

El área comercial pide rankings de clientes con criterios que cambian cada semana: "los 10 que más hablan", "los 5 con más datos", "los que más gastan en internacional". En lugar de escribir una función por pedido, escribe dos funciones **genéricas** que reciban el criterio como función:

1. `top_lineas(consumos, n, criterio)` → lista con las **líneas** de los `n` consumos con mayor valor según `criterio` (una función que recibe un consumo y devuelve un número). Ante un empate, la línea menor va primero.
2. `filtrar(consumos, *condiciones)` → lista de los consumos que cumplen **todas** las condiciones (cada una es una función que recibe un consumo y devuelve `bool`). Sin condiciones, devuelve todos.

```python
consumos = [
    {"linea": "3001", "minutos": 342, "mb": 15360.0, "internacional": 3},
    {"linea": "3002", "minutos": 15, "mb": 80000.0, "internacional": 0},
    {"linea": "3003", "minutos": 1203, "mb": 512.0, "internacional": 12},
]
top_lineas(consumos, 2, lambda c: c["minutos"])        # ["3003", "3001"]
top_lineas(consumos, 1, lambda c: c["mb"])             # ["3002"]
filtrar(consumos, lambda c: c["minutos"] > 100, lambda c: c["internacional"] > 5)   # [consumo de 3003]
```

## Pruebas

```python
CONSUMOS = [
    {"linea": "3001", "minutos": 342, "mb": 15360.0, "internacional": 3},
    {"linea": "3002", "minutos": 15, "mb": 80000.0, "internacional": 0},
    {"linea": "3003", "minutos": 1203, "mb": 512.0, "internacional": 12},
    {"linea": "3000", "minutos": 342, "mb": 100.0, "internacional": 0},
]


def prueba_top_por_minutos():
    """Ranking por minutos"""
    requiere("top_lineas")
    igual(top_lineas(CONSUMOS, 2, lambda c: c["minutos"]), ["3003", "3000"])


def prueba_top_empates():
    """En empate gana la línea menor"""
    igual(top_lineas(CONSUMOS, 3, lambda c: c["minutos"]), ["3003", "3000", "3001"])


def prueba_top_otro_criterio():
    """Funciona con cualquier criterio"""
    igual(top_lineas(CONSUMOS, 1, lambda c: c["mb"]), ["3002"])
    igual(top_lineas(CONSUMOS, 2, lambda c: c["internacional"] * 950 + c["minutos"]), ["3003", "3001"])


def prueba_top_n_mayor_que_la_lista():
    """Si n es mayor que la cantidad de consumos, devuelve todos"""
    igual(len(top_lineas(CONSUMOS, 10, lambda c: c["mb"])), 4)


def prueba_filtrar_varias_condiciones():
    """Cumple todas las condiciones"""
    requiere("filtrar")
    r = filtrar(CONSUMOS, lambda c: c["minutos"] > 100, lambda c: c["internacional"] > 0)
    igual([c["linea"] for c in r], ["3001", "3003"])


def prueba_filtrar_sin_condiciones():
    """Sin condiciones devuelve todos"""
    igual(len(filtrar(CONSUMOS)), 4)


def prueba_filtrar_no_modifica():
    """Devuelve una lista nueva"""
    r = filtrar(CONSUMOS, lambda c: True)
    assert r is not CONSUMOS, "Devuelve una lista nueva, no la misma"
```

## Pista 1

`sorted` acepta una `key` que puede devolver una **tupla**. Para ordenar por el criterio de mayor a menor y, en empate, por línea ascendente:

```python
ordenados = sorted(consumos, key=lambda c: (-criterio(c), c["linea"]))
```

Luego toma los primeros `n` con slicing.

## Pista 2

`all()` es perfecto para "cumple todas": `all(condicion(c) for condicion in condiciones)`. Con una tupla de condiciones vacía, `all` devuelve `True`, así que el caso "sin condiciones" funciona solo.

## Solución

```python
def top_lineas(consumos, n, criterio):
    ordenados = sorted(consumos, key=lambda c: (-criterio(c), c["linea"]))
    return [c["linea"] for c in ordenados[:n]]


def filtrar(consumos, *condiciones):
    return [c for c in consumos if all(condicion(c) for condicion in condiciones)]


consumos = [
    {"linea": "3001", "minutos": 342, "mb": 15360.0, "internacional": 3},
    {"linea": "3002", "minutos": 15, "mb": 80000.0, "internacional": 0},
    {"linea": "3003", "minutos": 1203, "mb": 512.0, "internacional": 12},
]
print(top_lineas(consumos, 2, lambda c: c["minutos"]))
```

## Explicación

Dos funciones de una línea resuelven **infinitos** pedidos: cada pedido nuevo de comercial es una lambda distinta, no una función nueva.

- **`-criterio(c)`** invierte el orden solo del primer criterio. Funciona porque el criterio devuelve números.
- **`*condiciones`** recibe cuantas funciones quieras. Dentro de la función es una tupla.
- **`all()` con una tupla vacía es `True`**: "todas las condiciones de una lista vacía se cumplen". Es una propiedad matemática que aquí simplifica el código.

Esta idea, separar **qué** se calcula (la lambda) de **cómo** se recorre (la función genérica), es la que usan Pandas y SQL por dentro.
