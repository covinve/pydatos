## Enunciado

Implementa las reglas de `.dockerignore` para saber qué archivos se envían al construir la imagen.

1. `excluido(ruta, patrones)` → `True` si la ruta (relativa, con `/`) queda **fuera** del contexto:
   - Se aplican **todos** los patrones en orden; el **último** que coincide decide.
   - Un patrón que empieza por `!` **vuelve a incluir** lo que coincide (`!datos/LEAME.md`).
   - `*` coincide con cualquier texto **dentro** de un nombre (sin `/`); `**` coincide con cualquier cantidad de carpetas (incluso ninguna).
   - Un patrón que coincide con una **carpeta** excluye todo lo que hay dentro (`datos` excluye `datos/20GB/cdr.csv`).
   - Se ignoran las líneas vacías, los comentarios (`#`) y una `/` al principio o al final del patrón.
2. `contexto(archivos, texto_dockerignore)` → `(incluidos, bytes)`: la lista ordenada de rutas incluidas y la suma de sus tamaños, a partir de un diccionario `{ruta: tamaño}`.

Puedes usar `fnmatch` o expresiones regulares.

## Solución

```python
import re


def _regex(patron):
    partes = patron.split("**/")
    convertidas = []
    for parte in partes:
        trozos = parte.split("**")
        convertidas.append(".*".join(re.escape(t).replace(r"\*", "[^/]*").replace(r"\?", "[^/]") for t in trozos))
    return re.compile("(.*/)?".join(convertidas) + "(/.*)?")


def excluido(ruta, patrones):
    resultado = False
    for patron in patrones:
        patron = patron.strip()
        if not patron or patron.startswith("#"):
            continue
        negado = patron.startswith("!")
        patron = patron.lstrip("!").strip().strip("/")
        if _regex(patron).fullmatch(ruta):
            resultado = not negado
    return resultado


def contexto(archivos, texto_dockerignore):
    patrones = texto_dockerignore.splitlines()
    incluidos = sorted(r for r in archivos if not excluido(r, patrones))
    return incluidos, sum(archivos[r] for r in incluidos)


ARCHIVOS = {"Dockerfile": 400, "src/app/cli.py": 2_000, "datos/20GB/cdr.csv": 21_000_000_000, ".env": 120}
print(contexto(ARCHIVOS, "datos/\n.env\n"))
```

## Explicación

La prueba de `contexto` lo dice todo: sin `.dockerignore`, construir la imagen enviaría **21 GB** al motor de Docker antes de empezar (minutos de espera, y una imagen gigante con datos de clientes adentro). Con las reglas correctas, 3,6 KB.

Las reglas de `.dockerignore` tienen sutilezas que las pruebas atacan a propósito:

- `*.pyc` sin `**/` solo aplica en la **raíz** del contexto (a diferencia de `.gitignore`, que aplica en cualquier carpeta). Por eso el patrón habitual es `**/*.pyc` o `**/__pycache__`.
- `*` no cruza carpetas: `salidas/*.csv` no excluye `salidas/2026/rechazos.csv`.
- La negación `!` solo funciona si viene **después** del patrón que excluía: el último que coincide gana.

Para ver qué entra de verdad en tu contexto, puedes construir con `docker build --progress=plain .` y mirar el tamaño de "transferring context".
