En el módulo 3 validaste fechas a mano. El módulo `datetime` lo hace por ti, conoce los años bisiestos y además permite **calcular** con fechas: ¿cuántos días lleva el cliente?, ¿cuándo vence la factura?, ¿cuántas llamadas hubo por hora?

## De texto a fecha: strptime

```pyrun
from datetime import datetime

texto = "2026-09-13 10:31:28"
inicio = datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")

print(inicio)
print(type(inicio))
print(inicio.year, inicio.month, inicio.day, inicio.hour)
print(inicio.weekday())        # 0 = lunes … 6 = domingo
print(inicio.date())           # solo la fecha
```

`strptime` = *string parse time*: "lee este texto con este formato".

| Código | Significa | Ejemplo |
|---|---|---|
| `%Y` | Año (4 dígitos) | `2026` |
| `%m` | Mes (2 dígitos) | `09` |
| `%d` | Día | `13` |
| `%H` | Hora (00–23) | `10` |
| `%M` | Minuto | `31` |
| `%S` | Segundo | `28` |
| `%y` | Año (2 dígitos) | `26` |
| `%b` / `%B` | Mes abreviado / completo (en inglés) | `Sep` / `September` |

```pyrun
from datetime import datetime

# El archivo de ancho fijo trae la fecha pegada: AAAAMMDDHHMMSS
print(datetime.strptime("20260913103128", "%Y%m%d%H%M%S"))

# Otros sistemas usan día/mes/año
print(datetime.strptime("13/09/2026", "%d/%m/%Y").date())
```

## Validar con strptime

Si el texto no es una fecha real, `strptime` lanza `ValueError`. Con `try/except` (módulo 7) se convierte en una validación de una línea:

```pyrun
from datetime import datetime


def fecha_valida(texto):
    try:
        datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")
        return True
    except ValueError:
        return False


for t in ["2026-09-13 10:31:28", "2026-09-31 10:15:00", "2026-09-15 25:10:00", "2028-02-29 08:00:00"]:
    print(t, fecha_valida(t))
```

Fíjate en el último: 2028 **es** bisiesto, así que el 29 de febrero es válido. Tu versión del módulo 3 lo habría rechazado.

## De fecha a texto: strftime

```pyrun
from datetime import datetime

momento = datetime(2026, 9, 13, 10, 31, 28)
print(momento.strftime("%d/%m/%Y %H:%M"))
print(momento.strftime("%Y%m%d"))         # para nombres de archivo: cdr_20260913.csv
print(momento.isoformat())                 # formato estándar ISO 8601
print(f"{momento:%Y-%m}")                  # también funciona dentro de f-strings
```

## Calcular con fechas: timedelta

```pyrun
from datetime import datetime, date, timedelta

inicio = datetime(2026, 9, 13, 23, 58, 0)
fin = inicio + timedelta(seconds=185)
print(fin)                                  # cruza la medianoche correctamente

emision = date(2026, 10, 5)
vencimiento = emision + timedelta(days=15)
print("Vence:", vencimiento)

alta = date(2020, 5, 10)
corte = date(2026, 9, 30)
antiguedad = corte - alta                   # restar fechas da un timedelta
print(antiguedad.days, "días ≈", antiguedad.days // 365, "años")
```

## Agrupar por día, hora o día de la semana

```pyrun
from collections import Counter
from datetime import datetime

fechas = ["2026-09-13 10:31:28", "2026-09-13 22:05:10", "2026-09-14 10:59:59", "2026-09-14 23:30:00", "2026-09-20 10:15:00"]
momentos = [datetime.strptime(f, "%Y-%m-%d %H:%M:%S") for f in fechas]

por_dia = Counter(m.date().isoformat() for m in momentos)
por_hora = Counter(m.hour for m in momentos)
DIAS = ["lunes", "martes", "miércoles", "jueves", "viernes", "sábado", "domingo"]
por_dia_semana = Counter(DIAS[m.weekday()] for m in momentos)

print(por_dia)
print(por_hora)
print(por_dia_semana)
```

## Comparar fechas

Los objetos `datetime` y `date` se comparan con `<`, `>`, `==` correctamente:

```pyrun
from datetime import date

alta = date.fromisoformat("2020-05-10")
corte = date.fromisoformat("2023-09-01")
print(alta < corte)
```

:::error No compares fechas como texto (salvo en formato ISO)
`"2020-05-10" < "2023-09-01"` funciona porque el formato ISO (`AAAA-MM-DD`) ordena igual alfabética y cronológicamente. Pero `"10/05/2020" < "01/09/2023"` da `False` (compara el "1" con el "0"). Ante la duda, convierte a `date` o `datetime`.
:::

:::capo ¿Y las zonas horarias?
Los `datetime` de esta lección son "ingenuos": no saben en qué zona horaria están. Para datos de un solo país suele bastar. Si integras sistemas en distintas zonas (o con horario de verano), usa `zoneinfo.ZoneInfo("America/Bogota")` y guarda las fechas en UTC.
:::
