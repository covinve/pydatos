Un **pipeline** es una cadena de etapas en la que cada una recibe los registros de la anterior, los transforma y los pasa a la siguiente. Con generadores, **cada registro recorre todo el pipeline antes de que se lea el siguiente**.

## Un pipeline completo

```pyrun
from pathlib import Path

Path("cdr.csv").write_text(
    "cdr_id|linea_origen|tipo|duracion_seg\n1|3001|VOZ|125\n2|3001|SMS|0\n3||VOZ|60\n4|3002|VOZ|-5\n5|3002|VOZ|61\n",
    encoding="utf-8",
)


def leer(ruta):
    with open(ruta, encoding="utf-8") as archivo:
        next(archivo)
        for linea in archivo:
            yield linea.rstrip("\n")


def parsear(lineas):
    for linea in lineas:
        cdr_id, linea_origen, tipo, duracion = linea.split("|")
        yield {"cdr_id": int(cdr_id), "linea": linea_origen, "tipo": tipo, "duracion": int(duracion)}


def validos(cdrs):
    for c in cdrs:
        if c["linea"] and c["duracion"] >= 0:
            yield c


def minutos_por_linea(cdrs):
    totales = {}
    for c in cdrs:
        if c["tipo"] == "VOZ":
            totales[c["linea"]] = totales.get(c["linea"], 0) + (c["duracion"] + 59) // 60
    return totales


print(minutos_por_linea(validos(parsear(leer("cdr.csv")))))
```

Cada etapa es una función pequeña, fácil de probar por separado (con una lista en lugar de un archivo) y fácil de reordenar o reemplazar.

:::reto Dos etapas más
Al pipeline le faltan dos etapas, escritas como **generadores**:

- `solo_tipo(cdrs, tipo)`: deja pasar solo los CDR del tipo indicado;
- `con_minutos(cdrs)`: entrega cada CDR con una clave nueva, `"minutos"`, con sus minutos facturables (sin modificar el diccionario original).

Encadénalas para calcular `total_voz`: los minutos de voz válidos.

```pyreto
cdrs = [
    {"linea": "3001", "tipo": "VOZ", "duracion": 125},
    {"linea": "3001", "tipo": "SMS", "duracion": 0},
    {"linea": "3002", "tipo": "VOZ", "duracion": 61},
    {"linea": "3002", "tipo": "DATOS", "duracion": 900},
]


def solo_tipo(cdrs, tipo):
    pass


def con_minutos(cdrs):
    pass


total_voz = sum(c["minutos"] for c in con_minutos(solo_tipo(cdrs, "VOZ")))
print(total_voz)   # 5
```

:::pista
`solo_tipo` es un `for` con un `if` y un `yield c`. `con_minutos` entrega `{**c, "minutos": (c["duracion"] + 59) // 60}`: un diccionario nuevo con todo lo de `c` más la clave nueva.
:::

```pyprueba
import inspect

CDRS = [
    {"linea": "3001", "tipo": "VOZ", "duracion": 125},
    {"linea": "3001", "tipo": "SMS", "duracion": 0},
    {"linea": "3002", "tipo": "VOZ", "duracion": 61},
]


def prueba_son_generadores():
    """Las dos etapas son generadores"""
    requiere("solo_tipo", "con_minutos")
    assert inspect.isgeneratorfunction(solo_tipo), "solo_tipo debe usar yield"
    assert inspect.isgeneratorfunction(con_minutos), "con_minutos debe usar yield"


def prueba_etapas():
    """Cada etapa hace su parte"""
    igual([c["linea"] for c in solo_tipo(CDRS, "SMS")], ["3001"], "solo_tipo SMS")
    igual([c["minutos"] for c in con_minutos(CDRS)], [3, 0, 2], "con_minutos")


def prueba_no_modifica():
    """con_minutos no modifica los diccionarios originales"""
    originales = [{"tipo": "VOZ", "duracion": 60}]
    list(con_minutos(originales))
    assert "minutos" not in originales[0], "Crea un diccionario nuevo en lugar de modificar el original"


def prueba_total():
    """total_voz = 5"""
    requiere("total_voz")
    igual(total_voz, 5)
```

```pysolucion
cdrs = [
    {"linea": "3001", "tipo": "VOZ", "duracion": 125},
    {"linea": "3001", "tipo": "SMS", "duracion": 0},
    {"linea": "3002", "tipo": "VOZ", "duracion": 61},
    {"linea": "3002", "tipo": "DATOS", "duracion": 900},
]


def solo_tipo(cdrs, tipo):
    for c in cdrs:
        if c["tipo"] == tipo:
            yield c


def con_minutos(cdrs):
    for c in cdrs:
        yield {**c, "minutos": (c["duracion"] + 59) // 60}


total_voz = sum(c["minutos"] for c in con_minutos(solo_tipo(cdrs, "VOZ")))
print(total_voz)   # 5
```

## Medir la memoria: tracemalloc

`tracemalloc` (biblioteca estándar) mide cuánta memoria reservó Python:

```pyrun
import tracemalloc

tracemalloc.start()
total = sum((d + 59) // 60 for d in range(2_000_000))       # generador
_, pico_generador = tracemalloc.get_traced_memory()
tracemalloc.reset_peak()

total = sum([(d + 59) // 60 for d in range(2_000_000)])     # lista
_, pico_lista = tracemalloc.get_traced_memory()
tracemalloc.stop()

print(f"Pico con generador: {pico_generador / 1e6:6.2f} MB")
print(f"Pico con lista:     {pico_lista / 1e6:6.2f} MB")
```

:::reto Mide antes de creer
Con `tracemalloc`, mide el pico de memoria de dos formas de calcular la suma de los megas de un millón de sesiones (`mb = i % 1000 / 10` para `i` de 0 a 999.999):

- `pico_lista`: construyendo primero una lista con todos los megas;
- `pico_generador`: con una expresión generadora.

Guarda los picos en bytes y compáralos.

```pyreto
import tracemalloc

N = 1_000_000

# Mide pico_lista y pico_generador

print(f"Lista: {pico_lista / 1e6:.1f} MB, generador: {pico_generador / 1e6:.3f} MB")
```

:::pista
`tracemalloc.start()`, calcula con lista, `_, pico_lista = tracemalloc.get_traced_memory()`, luego `tracemalloc.reset_peak()`, calcula con el generador y vuelve a leer el pico. Al final, `tracemalloc.stop()`.
:::

```pyprueba
def prueba_medidas():
    """Midió los dos picos"""
    requiere("pico_lista", "pico_generador")
    assert pico_lista > 1_000_000, f"El pico con lista debería pasar de 1 MB: {pico_lista}"


def prueba_generador_ahorra():
    """El generador usa mucho menos memoria"""
    assert pico_generador * 10 < pico_lista, f"Con generador {pico_generador} bytes no es mucho menor que con lista {pico_lista}: ¿mediste cada uno por separado con reset_peak()?"
```

```pysolucion
import tracemalloc

N = 1_000_000

tracemalloc.start()
total = sum([i % 1000 / 10 for i in range(N)])
_, pico_lista = tracemalloc.get_traced_memory()
tracemalloc.reset_peak()

total = sum(i % 1000 / 10 for i in range(N))
_, pico_generador = tracemalloc.get_traced_memory()
tracemalloc.stop()

print(f"Lista: {pico_lista / 1e6:.1f} MB, generador: {pico_generador / 1e6:.3f} MB")
```

## Duplicados con memoria acotada

Detectar duplicados con un `set` de todos los IDs necesita memoria proporcional al archivo: con 280 millones de CDR no cabe. Pero si sabes que los duplicados aparecen **cerca** del original (como en los datos del curso, donde el duplicado llega a menos de 5.000 registros de distancia), basta recordar los **últimos N** IDs:

```pyrun
from collections import deque


def duplicados_cercanos(ids, ventana):
    recientes = deque(maxlen=ventana)   # al llenarse, descarta el más viejo solo
    vistos = set()
    for cdr_id in ids:
        if cdr_id in vistos:
            yield cdr_id
            continue
        if len(recientes) == ventana:
            vistos.discard(recientes[0])
        recientes.append(cdr_id)
        vistos.add(cdr_id)


print(list(duplicados_cercanos([1, 2, 3, 2, 4, 5, 1, 6], ventana=3)))
```

El `1` del final no se detecta porque ya salió de la ventana de 3. Es un **compromiso consciente**: memoria constante a cambio de detectar solo duplicados cercanos. Documenta siempre ese supuesto.

:::reto Promedio de las últimas llamadas
Escribe el generador `promedio_movil(duraciones, n)`: después de cada llamada, entrega el promedio de duración de las **últimas `n`** llamadas (o de las que haya, si todavía son menos de `n`), redondeado a 1 decimal. Usa un `deque(maxlen=n)` para recordar solo lo necesario.

```pyreto
from collections import deque


def promedio_movil(duraciones, n):
    pass


print(list(promedio_movil([120, 60, 30, 300, 0], 3)))   # [120.0, 90.0, 70.0, 130.0, 110.0]
```

:::pista
Crea `ultimas = deque(maxlen=n)`. En cada vuelta, `ultimas.append(d)` y `yield round(sum(ultimas) / len(ultimas), 1)`. El `deque` descarta solo la más vieja.
:::

```pyprueba
import inspect


def prueba_generador():
    """Es un generador"""
    requiere("promedio_movil")
    assert inspect.isgeneratorfunction(promedio_movil), "Usa yield"


def prueba_valores():
    """Promedia las últimas n llamadas"""
    igual(list(promedio_movil([120, 60, 30, 300, 0], 3)), [120.0, 90.0, 70.0, 130.0, 110.0])
    igual(list(promedio_movil([10, 20], 5)), [10.0, 15.0], "menos llamadas que n")
    igual(list(promedio_movil([], 3)), [], "sin llamadas")


def prueba_usa_deque():
    """Usa deque con maxlen"""
    assert "maxlen" in codigo, "Recuerda solo las últimas n con deque(maxlen=n)"
```

```pysolucion
from collections import deque


def promedio_movil(duraciones, n):
    ultimas = deque(maxlen=n)
    for d in duraciones:
        ultimas.append(d)
        yield round(sum(ultimas) / len(ultimas), 1)


print(list(promedio_movil([120, 60, 30, 300, 0], 3)))   # [120.0, 90.0, 70.0, 130.0, 110.0]
```
:::

:::telco El supuesto debe verificarse
"Los duplicados llegan cerca" es una hipótesis sobre el sistema de mediación. Antes de confiar en ella, verifícala con un archivo mediano usando el método exacto (`set`) y el aproximado (ventana): si dan lo mismo, puedes usar la ventana con el archivo grande. Lo harás en el ejercicio 7.

## Cuestionario

> Cada etapa pide un registro a la anterior solo cuando lo necesita.

? ¿Qué hace `deque(maxlen=5000)` al agregar el elemento 5001?

- [ ] Crece a 5001
- [x] Descarta automáticamente el elemento más antiguo

> Con `maxlen`, el `deque` mantiene solo los últimos N elementos.

? ¿Qué mide `tracemalloc.get_traced_memory()`?
