## Enunciado

Docker Compose reemplaza variables en `compose.yaml` con los valores de tu entorno o del `.env`. Escribe `interpolar(texto, variables)` con sus reglas:

| Sintaxis | Resultado |
|---|---|
| `$VAR` o `${VAR}` | El valor de `VAR`; si no existe, texto vacío |
| `${VAR:-defecto}` | El valor, o `defecto` si no existe **o está vacía** |
| `${VAR-defecto}` | El valor, o `defecto` solo si **no existe** (vacía se respeta) |
| `${VAR:?mensaje}` | El valor; si no existe o está vacía, `ValueError` con `VAR` y el `mensaje` |
| `$$` | Un `$` literal (para pasar `$` a un comando) |

Los nombres de variable son letras, dígitos y `_`, sin empezar por dígito. Un `${` sin cierre `}` es un `ValueError`.

Y `faltantes(texto, variables)` → lista ordenada de variables usadas en el texto que **no** están definidas y **no** tienen valor por defecto (ni `:-` ni `-`).

## Pista 1

Una sola expresión regular con alternativas reconoce los cuatro casos:

```python
PATRON = re.compile(r"\$(?:(\$)|([A-Za-z_]\w*)|\{([A-Za-z_]\w*)(?:(:?[-?])([^}]*))?\}|(\{))")
```

Grupos: 1 = `$$`, 2 = `$VAR`, 3 + 4 + 5 = `${VAR}` con operador y argumento, 6 = un `{` que no cerró (error).

## Pista 2

`re.sub` acepta una **función** en lugar del texto de reemplazo: recibe cada coincidencia y devuelve lo que va en su lugar.

```python
def reemplazar(m):
    if m.group(1):
        return "$"
    if m.group(6):
        raise ValueError("llave sin cerrar")
    nombre = m.group(2) or m.group(3)
    operador, argumento = m.group(4), m.group(5)
    ...
return PATRON.sub(reemplazar, texto)
```

## Solución

```python
import re

PATRON = re.compile(r"\$(?:(\$)|([A-Za-z_]\w*)|\{([A-Za-z_]\w*)(?:(:?[-?])([^}]*))?\}|(\{))")


def _partes(m):
    return m.group(2) or m.group(3), m.group(4), m.group(5)


def interpolar(texto, variables):
    def reemplazar(m):
        if m.group(1):
            return "$"
        if m.group(6):
            raise ValueError(f"Llave sin cerrar en la posición {m.start()}")
        nombre, operador, argumento = _partes(m)
        existe = nombre in variables
        valor = variables.get(nombre, "")
        if operador == ":-":
            return valor if valor else argumento
        if operador == "-":
            return valor if existe else argumento
        if operador in (":?", "?") and (not existe or (operador == ":?" and not valor)):
            raise ValueError(f"Variable obligatoria {nombre}: {argumento}")
        return valor

    return PATRON.sub(reemplazar, texto)


def faltantes(texto, variables):
    nombres = set()
    for m in PATRON.finditer(texto):
        if m.group(1) or m.group(6):
            continue
        nombre, operador, _ = _partes(m)
        if nombre not in variables and operador not in (":-", "-"):
            nombres.add(nombre)
    return sorted(nombres)


COMPOSE = """
    environment:
      TELCO_DB_URL: postgresql+psycopg://telco:${PG_PASSWORD:?Define PG_PASSWORD}@bd:5432/facturacion
      TELCO_PERIODO: ${TELCO_PERIODO:-202609}
"""
print(interpolar(COMPOSE, {"PG_PASSWORD": "secreta"}))
```

## Explicación

`${VAR:?mensaje}` es la herramienta más valiosa de las cinco: convierte "olvidé definir la contraseña" en un error **inmediato y claro** al ejecutar `docker compose up`, en lugar de un PostgreSQL que arranca con contraseña vacía o una aplicación que falla con un error de autenticación incomprensible. Es la misma filosofía de validar al arrancar del módulo 21.

La diferencia entre `:-` y `-` parece mínima, pero importa: con `TELCO_FILTRO=` (definida a propósito como vacía, "sin filtro"), `${TELCO_FILTRO:-VOZ}` la ignoraría y filtraría por voz; `${TELCO_FILTRO-VOZ}` la respeta.

Pasar una **función** a `re.sub` es una técnica que vale la pena recordar: permite reemplazos con lógica (buscar en un diccionario, validar, lanzar errores) en una sola pasada sobre el texto, sin problemas de reemplazos que se pisan entre sí.

`faltantes` es lo que harías en un `validar` (como el del módulo 21) antes de lanzar `docker compose up` en un servidor: listar de una vez **todas** las variables que faltan, en lugar de descubrirlas de a una.
