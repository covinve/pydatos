## Enunciado

El código ya funciona; tu trabajo es **anotarlo** para que mypy pueda verificarlo. Agrega las anotaciones exactas:

| Elemento | Tipo |
|---|---|
| `Tipo` | Un alias `Literal["VOZ", "SMS", "DATOS"]` |
| `ResumenLinea` | `TypedDict` con `linea: str`, `llamadas: int`, `minutos: int`, `mb: float` |
| `minutos_facturables` | recibe `segundos: int`, devuelve `int` |
| `buscar_plan` | recibe `planes: dict[str, int]` y `plan_id: str`; devuelve `int \| None` |
| `resumir` | recibe `linea: str` y `cdrs: Iterable[tuple[Tipo, int, float]]`; devuelve `ResumenLinea` |
| `aplicar` | recibe `funcion: Callable[[int], int]` y `valores: list[int]`; devuelve `list[int]` |

`Iterable` y `Callable` se importan de `collections.abc`; `Literal` y `TypedDict` de `typing`.

## Código inicial

```python
from collections.abc import Callable, Iterable
from typing import Literal, TypedDict

Tipo = None            # reemplaza por el alias


class ResumenLinea:    # conviértela en TypedDict
    pass


def minutos_facturables(segundos):
    return (segundos + 59) // 60


def buscar_plan(planes, plan_id):
    return planes.get(plan_id)


def resumir(linea, cdrs):
    r = {"linea": linea, "llamadas": 0, "minutos": 0, "mb": 0.0}
    for tipo, segundos, mb in cdrs:
        if tipo == "VOZ":
            r["llamadas"] += 1
            r["minutos"] += minutos_facturables(segundos)
        elif tipo == "DATOS":
            r["mb"] += mb
    return r


def aplicar(funcion, valores):
    return [funcion(v) for v in valores]


print(resumir("3001", [("VOZ", 61, 0.0), ("DATOS", 0, 12.5), ("VOZ", 30, 0.0)]))
```

## Pruebas

```python
from collections.abc import Callable, Iterable
from typing import Literal, get_args, get_origin, get_type_hints


def prueba_literal():
    """Tipo es un Literal con los tres valores"""
    igual(get_origin(Tipo), Literal, "Tipo = Literal[...]")
    igual(set(get_args(Tipo)), {"VOZ", "SMS", "DATOS"})


def prueba_typeddict():
    """ResumenLinea es un TypedDict con cuatro claves"""
    igual(get_type_hints(ResumenLinea), {"linea": str, "llamadas": int, "minutos": int, "mb": float})
    assert hasattr(ResumenLinea, "__required_keys__"), "Hereda de TypedDict"


def prueba_funciones_simples():
    """minutos_facturables y buscar_plan"""
    igual(get_type_hints(minutos_facturables), {"segundos": int, "return": int})
    igual(get_type_hints(buscar_plan), {"planes": dict[str, int], "plan_id": str, "return": int | None})


def prueba_resumir():
    """resumir usa Iterable, Tipo y ResumenLinea"""
    h = get_type_hints(resumir)
    igual(h["linea"], str)
    igual(h["cdrs"], Iterable[tuple[Tipo, int, float]])
    igual(h["return"], ResumenLinea)


def prueba_aplicar():
    """aplicar usa Callable"""
    igual(get_type_hints(aplicar), {"funcion": Callable[[int], int], "valores": list[int], "return": list[int]})


def prueba_sigue_funcionando():
    """Las anotaciones no cambian el comportamiento"""
    igual(resumir("3001", [("VOZ", 61, 0.0), ("DATOS", 0, 12.5), ("VOZ", 30, 0.0)]),
          {"linea": "3001", "llamadas": 2, "minutos": 3, "mb": 12.5})
    igual(aplicar(minutos_facturables, [0, 60, 61]), [0, 1, 2])
```

## Pista 2

Dentro de `resumir`, para que mypy acepte el diccionario como `ResumenLinea`, anota la variable: `r: ResumenLinea = {...}`. Y `int | None` se escribe así, con la barra (Python 3.10+).

## Solución

```python
from collections.abc import Callable, Iterable
from typing import Literal, TypedDict

Tipo = Literal["VOZ", "SMS", "DATOS"]


class ResumenLinea(TypedDict):
    linea: str
    llamadas: int
    minutos: int
    mb: float


def minutos_facturables(segundos: int) -> int:
    return (segundos + 59) // 60


def buscar_plan(planes: dict[str, int], plan_id: str) -> int | None:
    return planes.get(plan_id)


def resumir(linea: str, cdrs: Iterable[tuple[Tipo, int, float]]) -> ResumenLinea:
    r: ResumenLinea = {"linea": linea, "llamadas": 0, "minutos": 0, "mb": 0.0}
    for tipo, segundos, mb in cdrs:
        if tipo == "VOZ":
            r["llamadas"] += 1
            r["minutos"] += minutos_facturables(segundos)
        elif tipo == "DATOS":
            r["mb"] += mb
    return r


def aplicar(funcion: Callable[[int], int], valores: list[int]) -> list[int]:
    return [funcion(v) for v in valores]


print(resumir("3001", [("VOZ", 61, 0.0), ("DATOS", 0, 12.5), ("VOZ", 30, 0.0)]))
```

## Explicación

Las pruebas leen las anotaciones con `typing.get_type_hints`: las anotaciones son datos que Python guarda (en `__annotations__`), aunque no los use al ejecutar. mypy, los editores y librerías como Typer o pydantic los leen.

Con estas anotaciones, mypy detectaría, sin ejecutar nada:

```python
resumir("3001", [("FAX", 10, 0.0)])          # "FAX" no es un Tipo válido
resumen = resumir(...); resumen["minuto"]    # clave inexistente en ResumenLinea
plan = buscar_plan(p, "X"); plan + 1         # plan puede ser None
aplicar(str.upper, [1, 2])                   # str.upper no es Callable[[int], int]
```

Y VS Code (con la extensión de Python) usa los mismos tipos para autocompletar `resumen["...` con las cuatro claves válidas.
