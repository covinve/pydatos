En el módulo 3 validaste fechas a mano. El módulo `datetime` lo hace por ti, conoce los años bisiestos y además permite **calcular** con fechas: ¿cuántos días lleva el cliente?, ¿cuándo vence la factura?, ¿cuántas llamadas hubo por hora?

## De texto a fecha: strptime

```pyrun
from datetime import datetime

texto = "2026-09-13 10:31:28"
inicio = datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")

print(inicio)
print(type(inicio))
print(inicio.year, inicio.month, inicio.day, inicio.hour)
print(inicio.weekday())        # 0 = lunes … 6 = domingo
print(inicio.date())           # solo la fecha
```

`strptime` = *string parse time*: "lee este texto con este formato".

| Código | Significa | Ejemplo |
|---|---|---|
| `%Y` | Año (4 dígitos) | `2026` |
| `%m` | Mes (2 dígitos) | `09` |
| `%d` | Día | `13` |
| `%H` | Hora (00–23) | `10` |
| `%M` | Minuto | `31` |
| `%S` | Segundo | `28` |
| `%y` | Año (2 dígitos) | `26` |
| `%b` / `%B` | Mes abreviado / completo (en inglés) | `Sep` / `September` |

```pyrun
from datetime import datetime

# El archivo de ancho fijo trae la fecha pegada: AAAAMMDDHHMMSS
print(datetime.strptime("20260913103128", "%Y%m%d%H%M%S"))

# Otros sistemas usan día/mes/año
print(datetime.strptime("13/09/2026", "%d/%m/%Y").date())
```

:::reto Lee la fecha de un CDR
El archivo de ancho fijo trae la fecha pegada. Con `strptime`, convierte `texto` en el `datetime` `momento` y saca de él:

- `hora`: la hora del día (un entero);
- `fin_de_semana`: `True` si fue sábado o domingo.

```pyreto
from datetime import datetime

texto = "20260913103128"

# momento, hora y fin_de_semana

print(momento, hora, fin_de_semana)
```

:::pista
El formato es `"%Y%m%d%H%M%S"`. `momento.weekday()` da 0 para el lunes y 6 para el domingo, así que el fin de semana es `>= 5`.
:::

```pyprueba
from datetime import datetime


def prueba_momento():
    """momento es el datetime correcto"""
    requiere("momento")
    igual(momento, datetime(2026, 9, 13, 10, 31, 28))


def prueba_hora_y_dia():
    """hora = 10 y fin_de_semana = True (13 de septiembre de 2026 es domingo)"""
    requiere("hora", "fin_de_semana")
    igual(hora, 10, "hora")
    igual(fin_de_semana, True, "fin_de_semana")
```

```pysolucion
from datetime import datetime

texto = "20260913103128"

momento = datetime.strptime(texto, "%Y%m%d%H%M%S")
hora = momento.hour
fin_de_semana = momento.weekday() >= 5

print(momento, hora, fin_de_semana)
```
:::

## Validar con strptime

Si el texto no es una fecha real, `strptime` lanza `ValueError`. Con `try/except` (módulo 7) se convierte en una validación de una línea:

```pyrun
from datetime import datetime


def fecha_valida(texto):
    try:
        datetime.strptime(texto, "%Y-%m-%d %H:%M:%S")
        return True
    except ValueError:
        return False


for t in ["2026-09-13 10:31:28", "2026-09-31 10:15:00", "2026-09-15 25:10:00", "2028-02-29 08:00:00"]:
    print(t, fecha_valida(t))
```

Fíjate en el último: 2028 **es** bisiesto, así que el 29 de febrero es válido. Tu versión del módulo 3 lo habría rechazado.

## De fecha a texto: strftime

```pyrun
from datetime import datetime

momento = datetime(2026, 9, 13, 10, 31, 28)
print(momento.strftime("%d/%m/%Y %H:%M"))
print(momento.strftime("%Y%m%d"))         # para nombres de archivo: cdr_20260913.csv
print(momento.isoformat())                 # formato estándar ISO 8601
print(f"{momento:%Y-%m}")                  # también funciona dentro de f-strings
```

:::reto Nombres de archivo y fechas para el cliente
Escribe dos funciones que reciban un `datetime`:

- `nombre_archivo(momento)` → `"cdr_20260913.csv"`;
- `para_cliente(momento)` → `"13/09/2026 10:31"`.

```pyreto
from datetime import datetime


def nombre_archivo(momento):
    pass


def para_cliente(momento):
    pass


m = datetime(2026, 9, 13, 10, 31, 28)
print(nombre_archivo(m), para_cliente(m))
```

:::pista
Con f-strings: `f"cdr_{momento:%Y%m%d}.csv"`. Para el cliente, el formato es `"%d/%m/%Y %H:%M"`.
:::

```pyprueba
from datetime import datetime


def prueba_nombre_archivo():
    """nombre_archivo usa AAAAMMDD"""
    requiere("nombre_archivo")
    igual(nombre_archivo(datetime(2026, 9, 13, 10, 31, 28)), "cdr_20260913.csv")
    igual(nombre_archivo(datetime(2027, 1, 5)), "cdr_20270105.csv")


def prueba_para_cliente():
    """para_cliente usa DD/MM/AAAA HH:MM"""
    requiere("para_cliente")
    igual(para_cliente(datetime(2026, 9, 13, 10, 31, 28)), "13/09/2026 10:31")
    igual(para_cliente(datetime(2027, 1, 5, 7, 5)), "05/01/2027 07:05")
```

```pysolucion
from datetime import datetime


def nombre_archivo(momento):
    return f"cdr_{momento:%Y%m%d}.csv"


def para_cliente(momento):
    return momento.strftime("%d/%m/%Y %H:%M")


m = datetime(2026, 9, 13, 10, 31, 28)
print(nombre_archivo(m), para_cliente(m))
```

## Calcular con fechas: timedelta

```pyrun
from datetime import datetime, date, timedelta

inicio = datetime(2026, 9, 13, 23, 58, 0)
fin = inicio + timedelta(seconds=185)
print(fin)                                  # cruza la medianoche correctamente

emision = date(2026, 10, 5)
vencimiento = emision + timedelta(days=15)
print("Vence:", vencimiento)

alta = date(2020, 5, 10)
corte = date(2026, 9, 30)
antiguedad = corte - alta                   # restar fechas da un timedelta
print(antiguedad.days, "días ≈", antiguedad.days // 365, "años")
```

:::reto Vencimientos y fin de llamada
Con `timedelta`, escribe:

- `vencimiento(emision)`: la fecha de emisión más 15 días;
- `fin_llamada(inicio, segundos)`: el momento en que terminó una llamada;
- `dias_mora(vence, pago)`: los días de retraso de un pago (0 si pagó a tiempo).

```pyreto
from datetime import date, datetime, timedelta


def vencimiento(emision):
    pass


def fin_llamada(inicio, segundos):
    pass


def dias_mora(vence, pago):
    pass


print(vencimiento(date(2026, 10, 5)))                      # 2026-10-20
print(fin_llamada(datetime(2026, 9, 30, 23, 59, 0), 185))  # 2026-10-01 00:02:05
print(dias_mora(date(2026, 10, 20), date(2026, 11, 2)))     # 13
```

:::pista
Suma con `timedelta(days=15)` o `timedelta(seconds=segundos)`. Restar dos fechas da un `timedelta`: usa su `.days` y protégelo con `max(0, ...)`.
:::

```pyprueba
from datetime import date, datetime


def prueba_vencimiento():
    """vencimiento suma 15 días (también entre meses)"""
    requiere("vencimiento")
    igual(vencimiento(date(2026, 10, 5)), date(2026, 10, 20))
    igual(vencimiento(date(2026, 12, 20)), date(2027, 1, 4))


def prueba_fin_llamada():
    """fin_llamada cruza la medianoche y el cambio de mes"""
    requiere("fin_llamada")
    igual(fin_llamada(datetime(2026, 9, 30, 23, 59, 0), 185), datetime(2026, 10, 1, 0, 2, 5))


def prueba_dias_mora():
    """dias_mora cuenta los días de retraso, nunca negativos"""
    requiere("dias_mora")
    igual(dias_mora(date(2026, 10, 20), date(2026, 11, 2)), 13)
    igual(dias_mora(date(2026, 10, 20), date(2026, 10, 1)), 0)
```

```pysolucion
from datetime import date, datetime, timedelta


def vencimiento(emision):
    return emision + timedelta(days=15)


def fin_llamada(inicio, segundos):
    return inicio + timedelta(seconds=segundos)


def dias_mora(vence, pago):
    return max(0, (pago - vence).days)


print(vencimiento(date(2026, 10, 5)))                      # 2026-10-20
print(fin_llamada(datetime(2026, 9, 30, 23, 59, 0), 185))  # 2026-10-01 00:02:05
print(dias_mora(date(2026, 10, 20), date(2026, 11, 2)))     # 13
```
:::

## Agrupar por día, hora o día de la semana

```pyrun
from collections import Counter
from datetime import datetime

fechas = ["2026-09-13 10:31:28", "2026-09-13 22:05:10", "2026-09-14 10:59:59", "2026-09-14 23:30:00", "2026-09-20 10:15:00"]
momentos = [datetime.strptime(f, "%Y-%m-%d %H:%M:%S") for f in fechas]

por_dia = Counter(m.date().isoformat() for m in momentos)
por_hora = Counter(m.hour for m in momentos)
DIAS = ["lunes", "martes", "miércoles", "jueves", "viernes", "sábado", "domingo"]
por_dia_semana = Counter(DIAS[m.weekday()] for m in momentos)

print(por_dia)
print(por_hora)
print(por_dia_semana)
```

## Comparar fechas

Los objetos `datetime` y `date` se comparan con `<`, `>`, `==` correctamente:

```pyrun
from datetime import date

alta = date.fromisoformat("2020-05-10")
corte = date.fromisoformat("2023-09-01")
print(alta < corte)
```

:::error No compares fechas como texto (salvo en formato ISO)
`"2020-05-10" < "2023-09-01"` funciona porque el formato ISO (`AAAA-MM-DD`) ordena igual alfabética y cronológicamente. Pero `"10/05/2020" < "01/09/2023"` da `False` (compara el "1" con el "0"). Ante la duda, convierte a `date` o `datetime`.
:::

:::reto Clientes con más de diez años
Recorre `clientes.csv` (separado por comas, en **latin-1**) con `csv.DictReader` y crea `veteranos`: la lista de `cliente_id` de los clientes cuya `fecha_alta` es **anterior** al 1 de octubre de 2016, en el orden del archivo. Compara fechas como `date`, no como texto.

```pyreto
import csv
from datetime import date

CORTE = date(2016, 10, 1)
veteranos = []

# Recorre clientes.csv y compara fecha_alta con CORTE

print(veteranos)
```

:::pista
Convierte con `date.fromisoformat(fila["fecha_alta"])` y compara con `< CORTE`. Abre el archivo con `encoding="latin-1"` y `newline=""`.
:::

```pyprueba
import csv
from datetime import date


def prueba_veteranos():
    """veteranos tiene los clientes de alta antes del corte"""
    requiere("veteranos")
    esperado = []
    with open("clientes.csv", encoding="latin-1", newline="") as f:
        for fila in csv.DictReader(f):
            if date.fromisoformat(fila["fecha_alta"]) < date(2016, 10, 1):
                esperado.append(fila["cliente_id"])
    igual(veteranos, esperado)


def prueba_usa_date():
    """Compara como fecha"""
    assert "fromisoformat" in codigo or "strptime" in codigo, "Convierte fecha_alta a date antes de comparar"
```

```pysolucion

CORTE = date(2016, 10, 1)
veteranos = []
```

:::capo ¿Y las zonas horarias?
Los `datetime` de esta lección son "ingenuos": no saben en qué zona horaria están. Para datos de un solo país suele bastar. Si integras sistemas en distintas zonas (o con horario de verano), usa `zoneinfo.ZoneInfo("America/Bogota")` y guarda las fechas en UTC.
:::
