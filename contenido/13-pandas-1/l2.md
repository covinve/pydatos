## Filas: loc e iloc

| | Selecciona por | Ejemplo |
|---|---|---|
| `loc` | **etiquetas** del índice y nombres de columna | `cdr.loc[10, "tipo"]` |
| `iloc` | **posiciones** (como una lista) | `cdr.iloc[0:5, 2]` |

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

print(cdr.iloc[0])                                  # primera fila
print(cdr.iloc[:3, :4])                             # 3 filas, 4 columnas
print(cdr.loc[cdr.index[:3], ["tipo", "mb"]])
indexado = cdr.set_index("cdr_id")                  # usar cdr_id como índice
print(indexado.loc[5, ["tipo", "duracion_seg"]])
```

:::reto Por etiqueta y por posición
Con el `cdr` de la muestra:

- `vistazo`: las **3 primeras filas** y solo las columnas `cdr_id`, `tipo` y `duracion_seg`, usando `iloc` para las filas;
- `tipo_100`: el `tipo` del registro cuyo **`cdr_id` es 100**, usando `cdr_id` como índice y `loc`.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# vistazo y tipo_100

print(vistazo)
print(tipo_100)
```

:::pista
`cdr.iloc[:3][["cdr_id", "tipo", "duracion_seg"]]` toma las tres primeras filas y luego las columnas. Para el otro: `cdr.set_index("cdr_id").loc[100, "tipo"]`.
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def prueba_vistazo():
    """vistazo tiene 3 filas y 3 columnas"""
    requiere("vistazo")
    igual_df(vistazo, _cdr().iloc[:3][["cdr_id", "tipo", "duracion_seg"]])


def prueba_tipo_100():
    """tipo_100 es el tipo del cdr_id 100"""
    requiere("tipo_100")
    datos = _cdr()
    igual(str(tipo_100), str(datos.loc[datos["cdr_id"] == 100, "tipo"].iloc[0]))
    assert ".loc[" in codigo and "set_index" in codigo, "Usa set_index('cdr_id') y .loc[...]"
```

```pysolucion

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

vistazo = cdr.iloc[:3][["cdr_id", "tipo", "duracion_seg"]]
```

## Filtrar con máscaras

Igual que en NumPy: una condición produce una Series de `True`/`False` y se usa dentro de los corchetes.

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

voz = cdr[cdr["tipo"] == "VOZ"]
print(len(voz), "llamadas de voz")

internacionales_largas = cdr[(cdr["destino"] == "INTERNACIONAL") & (cdr["duracion_seg"] > 300)]
print(internacionales_largas[["cdr_id", "linea_origen", "duracion_seg"]].head())

raros = cdr[~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"])]
print(raros["tipo"].value_counts())

franja = cdr[cdr["duracion_seg"].between(60, 120)]     # incluye ambos extremos
print(len(franja))
```

:::error Paréntesis y &, |, ~
Igual que en NumPy: `(cdr["tipo"] == "VOZ") & (cdr["mb"] > 0)`. Sin paréntesis o con `and`, da error.
:::

## query: filtros que se leen como texto

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

minimo = 600
print(cdr.query("tipo == 'VOZ' and duracion_seg > @minimo")[["cdr_id", "duracion_seg"]].head())
```

`@variable` usa una variable de Python dentro de la consulta.

:::reto Preguntas de negocio con filtros
Con el `cdr` de la muestra, responde con filtros:

- `invalidos`: cuántos registros tienen un tipo que **no** es VOZ, SMS ni DATOS;
- `datos_pesados`: cuántos registros de DATOS consumieron más de 50 MB;
- `voz_largas`: el DataFrame de llamadas de VOZ de **30 minutos o más**, usando `query` con la variable `umbral`.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
umbral = 1800

# invalidos, datos_pesados y voz_largas

print(invalidos, datos_pesados, len(voz_largas))
```

:::pista
`(~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"])).sum()`; `((cdr["tipo"] == "DATOS") & (cdr["mb"] > 50)).sum()`; y `cdr.query("tipo == 'VOZ' and duracion_seg >= @umbral")`.
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def prueba_conteos():
    """invalidos y datos_pesados"""
    requiere("invalidos", "datos_pesados")
    datos = _cdr()
    igual(int(invalidos), int((~datos["tipo"].isin(["VOZ", "SMS", "DATOS"])).sum()), "invalidos")
    igual(int(datos_pesados), int(((datos["tipo"] == "DATOS") & (datos["mb"] > 50)).sum()), "datos_pesados")


def prueba_query():
    """voz_largas con query y @umbral"""
    requiere("voz_largas")
    datos = _cdr()
    esperado = datos[(datos["tipo"] == "VOZ") & (datos["duracion_seg"] >= 1800)]
    igual(sorted(voz_largas["cdr_id"].tolist()), sorted(esperado["cdr_id"].tolist()))
    assert ".query(" in codigo and "@umbral" in codigo, "Filtra con cdr.query(...) usando @umbral"
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
umbral = 1800

invalidos = (~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"])).sum()
datos_pesados = ((cdr["tipo"] == "DATOS") & (cdr["mb"] > 50)).sum()
voz_largas = cdr.query("tipo == 'VOZ' and duracion_seg >= @umbral")

print(invalidos, datos_pesados, len(voz_largas))
```

## Ordenar y tomar los mayores

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

print(cdr.sort_values("duracion_seg", ascending=False).head(3)[["cdr_id", "tipo", "duracion_seg"]])
print(cdr.sort_values(["linea_origen", "fecha_inicio"]).head(3)[["linea_origen", "fecha_inicio"]])
print(cdr.nlargest(3, "mb")[["cdr_id", "mb"]])
```

:::reto Los mayores consumos
Con el `cdr` de la muestra:

- `top5_mb`: la **lista** de los `cdr_id` de los 5 registros con más megas, de mayor a menor;
- `mas_larga`: la `linea_origen` de la llamada de **VOZ** más larga.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# top5_mb y mas_larga

print(top5_mb, mas_larga)
```

:::pista
`cdr.nlargest(5, "mb")["cdr_id"].tolist()`. Para la otra, filtra la voz y ordena: `voz.sort_values("duracion_seg", ascending=False)["linea_origen"].iloc[0]` (o usa `nlargest(1, ...)`).
:::

```pyprueba
import pandas as pd


def _cdr():
    return pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def prueba_top5():
    """top5_mb son los 5 cdr_id con más megas"""
    requiere("top5_mb")
    igual([int(x) for x in top5_mb], _cdr().nlargest(5, "mb")["cdr_id"].tolist())


def prueba_mas_larga():
    """mas_larga es la línea de la llamada de voz más larga"""
    requiere("mas_larga")
    datos = _cdr()
    voz = datos[datos["tipo"] == "VOZ"]
    igual(str(mas_larga), str(voz.loc[voz["duracion_seg"].idxmax(), "linea_origen"]))
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

top5_mb = cdr.nlargest(5, "mb")["cdr_id"].tolist()
voz = cdr[cdr["tipo"] == "VOZ"]
mas_larga = voz.sort_values("duracion_seg", ascending=False)["linea_origen"].iloc[0]

print(top5_mb, mas_larga)
```

## Modificar de forma segura

Para modificar filas que cumplen una condición, usa `loc` con la máscara y la columna:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

limpio = cdr.copy()
limpio.loc[limpio["duracion_seg"] < 0, "duracion_seg"] = 0
print((cdr["duracion_seg"] < 0).sum(), "negativas en el original;", (limpio["duracion_seg"] < 0).sum(), "en la copia")
```

:::capo Copy-on-Write
En Pandas 3, un filtro como `voz = cdr[cdr["tipo"] == "VOZ"]` se comporta siempre como una **copia**: modificar `voz` nunca altera `cdr`. Era una fuente clásica de confusión (el famoso `SettingWithCopyWarning`) en versiones anteriores. Para modificar el original, usa `cdr.loc[mascara, columna] = valor`.
:::

:::reto Corrige sin dañar el original
Crea `limpio`, una copia del `cdr` de la muestra con dos correcciones hechas con `loc`:

- las duraciones negativas pasan a `0`;
- el tipo `"VOX"` (un error de digitación conocido) pasa a `"VOZ"`.

El `cdr` original no debe cambiar.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

# limpio, con las dos correcciones

print((limpio["duracion_seg"] < 0).sum(), (limpio["tipo"] == "VOX").sum())
```

:::pista
`limpio = cdr.copy()`, luego `limpio.loc[limpio["duracion_seg"] < 0, "duracion_seg"] = 0` y lo mismo para el tipo: `limpio.loc[limpio["tipo"] == "VOX", "tipo"] = "VOZ"`.
:::

```pyprueba
import pandas as pd


def prueba_correcciones():
    """limpio no tiene negativas ni VOX"""
    requiere("limpio")
    igual(int((limpio["duracion_seg"] < 0).sum()), 0, "duraciones negativas")
    igual(int((limpio["tipo"] == "VOX").sum()), 0, "tipos VOX")


def prueba_resto_igual():
    """Lo demás no cambia"""
    original = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    igual(len(limpio), len(original), "cantidad de filas")
    voz_esperada = int(((original["tipo"] == "VOZ") | (original["tipo"] == "VOX")).sum())
    igual(int((limpio["tipo"] == "VOZ").sum()), voz_esperada, "registros de VOZ")


def prueba_original_intacto():
    """El cdr original no cambió"""
    requiere("cdr")
    assert (cdr["duracion_seg"] < 0).any(), "El cdr original fue modificado: trabaja sobre limpio = cdr.copy()"
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})

limpio = cdr.copy()
limpio.loc[limpio["duracion_seg"] < 0, "duracion_seg"] = 0
limpio.loc[limpio["tipo"] == "VOX", "tipo"] = "VOZ"

print((limpio["duracion_seg"] < 0).sum(), (limpio["tipo"] == "VOX").sum())
```
:::

## Cuestionario

? ¿Qué diferencia hay entre `loc` e `iloc`?
- [ ] Ninguna
- [x] `loc` usa etiquetas (índice y nombres de columna); `iloc` usa posiciones
- [ ] `iloc` es más moderno
- [ ] `loc` solo sirve para columnas
> `cdr.iloc[0]` es la primera fila sin importar su etiqueta; `cdr.loc[0]` es la fila cuya etiqueta es 0.

? ¿Qué devuelve `cdr[["tipo", "mb"]]`?
- [ ] Una Series
- [x] Un DataFrame con esas dos columnas
- [ ] Un error
- [ ] Una lista
> Con doble corchete pasas una lista de columnas y obtienes un DataFrame.

? ¿Cómo pones en 0 las duraciones negativas del DataFrame `cdr`?
- [ ] `cdr[cdr["duracion_seg"] < 0]["duracion_seg"] = 0`
- [x] `cdr.loc[cdr["duracion_seg"] < 0, "duracion_seg"] = 0`
- [ ] `cdr.duracion_seg < 0 = 0`
- [ ] `cdr.replace(-1, 0)`
> El primer intento modifica una copia temporal y no tiene efecto. `loc[mascara, columna]` modifica el original.
