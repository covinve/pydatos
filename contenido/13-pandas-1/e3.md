## Solución

```python
import numpy as np
import pandas as pd

TARIFAS = {"LOCAL": 100, "NACIONAL": 120, "INTERNACIONAL": 950}
cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def enriquecer(cdr):
    r = cdr.copy()
    r["inicio"] = pd.to_datetime(r["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    r["hora"] = r["inicio"].dt.hour
    r["nocturna"] = ((r["hora"] >= 22) | (r["hora"] <= 5)).fillna(False).astype(bool)
    es_voz = (r["tipo"] == "VOZ") & (r["duracion_seg"] >= 0)
    r["minutos"] = np.where(es_voz, (r["duracion_seg"] + 59) // 60, 0)
    r["tarifa"] = r["destino"].map(TARIFAS).fillna(0).astype(int)
    bruto = r["minutos"] * r["tarifa"]
    con_descuento = r["nocturna"] & (r["destino"] != "INTERNACIONAL")
    r["valor"] = np.where(con_descuento, bruto // 2, bruto)
    return r


def total_por_destino(enriquecido):
    return {d: int(enriquecido.loc[enriquecido["destino"] == d, "valor"].sum()) for d in TARIFAS}


print(enriquecer(cdr)[["fecha_inicio", "hora", "minutos", "tarifa", "valor"]].head())
```

## Explicación

Las reglas de tarificación que en el módulo 3 eran una cadena de `if`, aquí son columnas: cada paso del cálculo queda **visible** en el DataFrame (`hora`, `nocturna`, `minutos`, `tarifa`), lo que hace muy fácil auditar un valor: basta mirar su fila.

Trabajar sobre `cdr.copy()` hace que la función no tenga efectos secundarios, como las funciones puras del módulo 5.
