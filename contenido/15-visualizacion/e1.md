## Pista 1

Calcula los minutos por destino con `groupby` y ordénalos con `reindex(DESTINOS, fill_value=0)`. Luego:

```python
fig, ax = plt.subplots(figsize=(6, 3.5))
barras = ax.bar(minutos.index, minutos.values)
```

## Pista 2

`ax.bar_label(barras)` escribe los valores. `ax.set_title(...)` y `ax.set_ylabel(...)` ponen los textos. No olvides `return fig`.

## Solución

```python
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
DESTINOS = ["LOCAL", "NACIONAL", "INTERNACIONAL"]


def grafico_destinos(cdr):
    voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)]
    minutos = ((voz["duracion_seg"] + 59) // 60).groupby(voz["destino"]).sum().reindex(DESTINOS, fill_value=0)
    fig, ax = plt.subplots(figsize=(6, 3.5))
    barras = ax.bar(minutos.index, minutos.values, color="#4f46e5")
    ax.bar_label(barras, padding=3)
    ax.set_title("Minutos de voz por destino")
    ax.set_ylabel("Minutos")
    ax.spines[["top", "right"]].set_visible(False)
    return fig


fig = grafico_destinos(cdr)
```

## Explicación

Una función que **devuelve la figura** es más útil que una que solo dibuja: quien la llama puede mostrarla, guardarla (`fig.savefig`) o insertarla en un reporte. También permite probarla: las pruebas inspeccionan `fig.axes[0].patches` (las barras) y sus alturas, exactamente como harías para verificar que un gráfico de un reporte muestra los números correctos.

Quitar los bordes de arriba y la derecha (`spines`) es un detalle de estilo que hace el gráfico más limpio.
