## Enunciado

El módulo `tarifas.py` (ya está en tu carpeta de trabajo) tiene la función `minutos_facturables(segundos)`, que redondea hacia arriba al minuto.

Esta vez **no escribes la función: escribes sus pruebas**. Escribe al menos **3** funciones de prueba de pytest (`def test_...():` con `assert`) que verifiquen la regla.

Para comprobar tus pruebas, el curso las ejecuta con pytest contra:

- la implementación **correcta**: todas tus pruebas deben **pasar**;
- tres versiones con **errores sembrados** (mutantes): para cada una, al menos una de tus pruebas debe **fallar**.

Piensa en los casos borde: ¿qué pasa con 0 segundos?, ¿con 60?, ¿con 61?

```python
import ast

import pytest

CORRECTA = "def minutos_facturables(segundos):\n    return (segundos + 59) // 60\n"

    return correr_pytest(codigo, {"tarifas": implementacion})


def prueba_al_menos_tres_pruebas():
    """Escribiste al menos 3 funciones test_"""

    assert len(pruebas) >= 3, f"Escribe al menos 3 pruebas; hay {len(pruebas)}"


def prueba_pasan_con_el_codigo_correcto():
    """Tus pruebas pasan con la implementación correcta"""
    salida, texto = correr(CORRECTA)
    assert salida != 5, "pytest no encontró pruebas: los nombres deben empezar con test_"
    assert salida == 0, "Alguna de tus pruebas falla con el código CORRECTO:\n" + texto[-900:]


def prueba_atrapa_mas_uno():
    """Atrapan el mutante `segundos // 60 + 1` (cobra 60 s como 2 minutos)"""

    assert salida == 1, "Ninguna prueba falló con este error. Pista: ¿qué pasa con 0 o 60 segundos?"


def prueba_atrapa_sin_redondeo():
    """Atrapan el mutante `segundos // 60` (no redondea hacia arriba)"""
```

## Pista 1

Cada prueba es una función que empieza con `test_` y contiene un `assert`. Prueba estos casos: 0 segundos (0 minutos), 60 segundos (1 minuto) y 61 segundos (2 minutos).

## Solución

```python
from tarifas import minutos_facturables


def test_un_segundo_se_cobra_como_un_minuto():
    assert minutos_facturables(1) == 1


def test_llamada_no_contestada_no_se_cobra():
    assert minutos_facturables(0) == 0


def test_minuto_exacto():
    assert minutos_facturables(60) == 1


def test_un_segundo_de_mas_cobra_otro_minuto():
    assert minutos_facturables(61) == 2


def test_una_hora():
    assert minutos_facturables(3600) == 60
```

## Explicación

Fíjate en qué caso atrapa cada mutante:

| Mutante | 0 s | 1 s | 60 s | 61 s |
|---|---|---|---|---|
| Correcto `(s + 59) // 60` | 0 | 1 | 1 | 2 |
| `s // 60 + 1` | **1** | 1 | **2** | 2 |
| `s // 60` | 0 | **0** | 1 | **1** |
| `(s + 60) // 60` | **1** | 1 | **2** | 2 |

La prueba con 1 segundo, sola, solo atrapa uno de los tres mutantes. Las pruebas en los **límites** (0 y 60) son las que más errores detectan. Ese es el criterio para elegir casos: no "muchos", sino los que separan el código correcto de los errores posibles.
