## Enunciado

Servicio al cliente quiere ver estadísticas rápidas de las llamadas de una línea. Recibes una lista con las duraciones en segundos (puede estar **vacía**). Escribe:

1. `total_minutos(duraciones)` → suma de los minutos facturables de cada llamada (cada una redondeada hacia arriba por separado).
2. `porcentaje_contestadas(duraciones)` → porcentaje de llamadas con duración mayor que 0, redondeado a 1 decimal. Si no hay llamadas, `0.0`.
3. `promedio_contestadas(duraciones)` → duración promedio en segundos de las llamadas **contestadas**, redondeada a 1 decimal. Si no hay contestadas, `0.0`.
4. `llamada_mas_larga(duraciones)` → la posición (empezando en 1) de la llamada más larga. Si hay empate, la primera. Si la lista está vacía, `None`.

```python
d = [125, 0, 61, 3600, 45, 0, 300]
total_minutos(d)            # 71
porcentaje_contestadas(d)   # 71.4
promedio_contestadas(d)     # 826.2
llamada_mas_larga(d)        # 4
```

## Pruebas

```python
D = [125, 0, 61, 3600, 45, 0, 300]


def prueba_total_minutos():
    """Suma los minutos facturables de cada llamada"""
    requiere("total_minutos")
    igual(total_minutos(D), 71)
    igual(total_minutos([1, 1, 1]), 3, "Cada llamada se redondea por separado")


def prueba_porcentaje():
    """Porcentaje de llamadas contestadas con 1 decimal"""
    requiere("porcentaje_contestadas")
    igual(porcentaje_contestadas(D), 71.4)
    igual(porcentaje_contestadas([0, 0]), 0.0)
    igual(porcentaje_contestadas([10, 20]), 100.0)


def prueba_promedio():
    """Promedio de las llamadas contestadas con 1 decimal"""
    requiere("promedio_contestadas")
    igual(promedio_contestadas(D), 826.2)
    igual(promedio_contestadas([0, 10, 0, 20]), 15.0)


def prueba_mas_larga():
    """Posición (desde 1) de la llamada más larga"""
    requiere("llamada_mas_larga")
    igual(llamada_mas_larga(D), 4)
    igual(llamada_mas_larga([50, 90, 90, 10]), 2, "Con empate, la primera")
    igual(llamada_mas_larga([7]), 1)


def prueba_listas_vacias():
    """Con la lista vacía no hay errores"""
    igual(total_minutos([]), 0)
    igual(porcentaje_contestadas([]), 0.0)
    igual(promedio_contestadas([]), 0.0)
    igual(llamada_mas_larga([]), None)


def prueba_sin_contestadas():
    """Si ninguna llamada fue contestada, el promedio es 0.0"""
    igual(promedio_contestadas([0, 0, 0]), 0.0)
```

## Pista 1

Cada función es un patrón de la lección 4:

- `total_minutos` → **acumular**.
- `porcentaje_contestadas` → **contar** y dividir entre `len(duraciones)`.
- `promedio_contestadas` → **filtrar** las contestadas y luego dividir la suma entre la cantidad.
- `llamada_mas_larga` → **máximo**, guardando también la posición.

Antes de dividir, protege la división entre cero con una salida temprana.

## Pista 2

Para la más larga, recorre con `enumerate(duraciones, start=1)` y reemplaza solo si es **estrictamente** mayor (así, en un empate, se queda la primera):

```python
mejor_posicion = None
mejor_duracion = -1
for posicion, d in enumerate(duraciones, start=1):
    if d > mejor_duracion:
        ...
```

`round(valor, 1)` redondea a un decimal.

## Solución

```python
def total_minutos(duraciones):
    total = 0
    for d in duraciones:
        total += (d + 59) // 60
    return total


def porcentaje_contestadas(duraciones):
    if not duraciones:
        return 0.0
    contestadas = 0
    for d in duraciones:
        if d > 0:
            contestadas += 1
    return round(contestadas / len(duraciones) * 100, 1)


def promedio_contestadas(duraciones):
    contestadas = [d for d in duraciones if d > 0]
    if not contestadas:
        return 0.0
    return round(sum(contestadas) / len(contestadas), 1)


def llamada_mas_larga(duraciones):
    mejor_posicion = None
    mejor_duracion = -1
    for posicion, d in enumerate(duraciones, start=1):
        if d > mejor_duracion:
            mejor_posicion = posicion
            mejor_duracion = d
    return mejor_posicion


d = [125, 0, 61, 3600, 45, 0, 300]
print(total_minutos(d), porcentaje_contestadas(d), promedio_contestadas(d), llamada_mas_larga(d))
```

## Explicación

Las listas vacías son el **caso borde** que más programas rompe. `sum([]) / len([])` lanza `ZeroDivisionError`. Por eso cada función que divide empieza con `if not ...: return 0.0`: una lista vacía es "falsa".

En `llamada_mas_larga`, el valor inicial `-1` garantiza que la primera llamada (aunque dure 0 segundos) siempre reemplace al "mejor hasta ahora". Y el `>` estricto hace que, ante un empate, se quede la primera.

`promedio_contestadas` usa una comprensión para filtrar y luego `sum` y `len`. Ambas versiones (bucle o comprensión) son correctas: elige la que leas más fácil.
