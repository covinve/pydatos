## pivot_table: la tabla dinámica de Excel, en código

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})

voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].dropna(subset=["linea_origen"]).copy()
voz["minutos"] = (voz["duracion_seg"] + 59) // 60
voz = voz.merge(clientes[["linea", "region"]], left_on="linea_origen", right_on="linea", how="inner")

tabla = voz.pivot_table(index="region", columns="destino", values="minutos", aggfunc="sum", fill_value=0, margins=True, margins_name="TOTAL")
print(tabla)
```

| Parámetro | Equivale en Excel a |
|---|---|
| `index` | Filas |
| `columns` | Columnas |
| `values` | Valores |
| `aggfunc` | Resumir valores por (suma, promedio, cuenta…) |
| `margins=True` | Totales generales |

:::reto Registros por región y tipo
Con los CDR de la muestra cruzados con la región de cada cliente (ya preparado en `cruce`), crea `tabla`: una tabla dinámica con las **regiones** en las filas, los **tipos** en las columnas y la **cantidad de registros** en cada celda (0 donde no hay).

## melt: de ancho a largo

`melt` hace lo contrario: convierte columnas en filas. Muchos gráficos y herramientas prefieren el formato "largo":

```pyrun
import pandas as pd

ancho = pd.DataFrame({"linea": ["3001", "3002"], "voz": [5040, 0], "datos": [2538, 0], "sms": [1200, 60]})
largo = ancho.melt(id_vars="linea", var_name="concepto", value_name="valor")
print(largo)
print(largo.pivot(index="linea", columns="concepto", values="valor"))   # y de vuelta
```

:::reto De ancho a largo
La factura llegó en formato ancho (una columna por concepto). Con `melt`:

1. Crea `largo`, con las columnas `linea`, `concepto` y `valor`.
2. Crea `cobrados`: solo las filas con valor mayor que 0.
3. Crea `por_concepto`: el total de cada concepto (una Series).

```pyreto
import pandas as pd

ancho = pd.DataFrame({
    "linea": ["3001", "3002", "3003"],
    "voz": [5040, 0, 1200],
    "datos": [2538, 0, 0],
    "sms": [1200, 60, 0],
})

# largo, cobrados y por_concepto

print(cobrados)
print(por_concepto)
```

:::pista
`ancho.melt(id_vars="linea", var_name="concepto", value_name="valor")`. Filtra con `largo[largo["valor"] > 0]` y agrupa por `concepto`.
:::

```pyprueba
def prueba_largo():
```

## Series de tiempo: resample

Con una columna de fechas como índice, `resample` agrupa por periodos de tiempo:

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
serie = cdr.dropna(subset=["inicio"]).set_index("inicio").sort_index()

por_dia = serie.resample("D").size()
print(por_dia.head())
print("Día con más tráfico:", por_dia.idxmax().date(), por_dia.max())

datos_por_dia = serie[serie["tipo"] == "DATOS"].resample("D")["mb"].sum().round(1)
print(datos_por_dia.head())

por_semana = serie.resample("W-MON").size()      # semanas que empiezan el lunes
print(por_semana)
```

| Código | Periodo |
|---|---|
| `"h"` | Hora |
| `"D"` | Día |
| `"W-MON"` | Semana (que empieza el lunes) |
| `"MS"` / `"ME"` | Mes (inicio / fin) |

:::reto Megas por día
Con la serie de tiempo de la muestra (ya preparada en `serie`, con las fechas como índice):

- `mb_por_dia`: el total de megas de las sesiones de **DATOS** de cada día;
- `dia_pico`: la fecha (como `date`) del día con más megas;
- `por_hora`: la cantidad de registros por **hora**, solo del 15 de septiembre de 2026.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
serie = cdr.dropna(subset=["inicio"]).set_index("inicio").sort_index()

# mb_por_dia, dia_pico y por_hora

print(mb_por_dia.head(), dia_pico, por_hora.max())
```

:::pista
`serie[serie["tipo"] == "DATOS"].resample("D")["mb"].sum()`. `mb_por_dia.idxmax().date()` da la fecha. Para un solo día, corta el índice por texto: `serie.loc["2026-09-15"].resample("h").size()`.
:::

```pyprueba
import pandas as pd


def _serie():
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    d["inicio"] = pd.to_datetime(d["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    return d.dropna(subset=["inicio"]).set_index("inicio").sort_index()


def prueba_mb_por_dia():
    """mb_por_dia suma las megas de cada día"""
    requiere("mb_por_dia")
    s = _serie()
    esperado = s[s["tipo"] == "DATOS"].resample("D")["mb"].sum()
    igual(len(mb_por_dia), len(esperado), "cantidad de días")
    cerca(float(mb_por_dia.sum()), float(esperado.sum()), 0.01, "total de megas")


def prueba_dia_pico():
    """dia_pico es el día con más megas"""
    requiere("dia_pico")
    s = _serie()
    igual(str(dia_pico), str(s[s["tipo"] == "DATOS"].resample("D")["mb"].sum().idxmax().date()))


def prueba_por_hora():
    """por_hora cuenta los registros del 15 de septiembre"""
    requiere("por_hora")
    esperado = _serie().loc["2026-09-15"].resample("h").size()
    igual(int(por_hora.sum()), int(esperado.sum()), "registros del día")
    igual(int(por_hora.max()), int(esperado.max()), "hora con más registros")
```

## Tendencias: rolling

`rolling` calcula sobre una **ventana móvil**: el promedio de los últimos 7 días suaviza las variaciones diarias y deja ver la tendencia.

```pyrun
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
por_dia = cdr.dropna(subset=["inicio"]).set_index("inicio").resample("D").size()

tendencia = por_dia.rolling(7).mean().round(1)
cambio = por_dia.pct_change().mul(100).round(1)
print(pd.DataFrame({"registros": por_dia, "media_7_dias": tendencia, "cambio_%": cambio}).tail(8))
```

:::telco Detectar caídas de carga
Si un día llegan muchos menos CDR que el promedio de la semana, probablemente faltó un archivo de alguna central. Una regla simple como "alertar si el volumen del día está 30 % por debajo de la media móvil de 7 días" detecta cargas incompletas antes de facturar.
:::

:::reto La alerta de carga incompleta
Con la cantidad de registros por día (`por_dia`), implementa la alerta:

1. `referencia`: la media de los **7 días anteriores** a cada día (la media móvil de 7, corrida un día con `shift(1)` para no incluir el día que se evalúa).
2. `alertas`: la lista de fechas (como texto `AAAA-MM-DD`) en que el volumen estuvo **12 % o más por debajo** de su referencia.

```pyreto
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
por_dia = cdr.dropna(subset=["inicio"]).set_index("inicio").resample("D").size()

# referencia y alertas

print(alertas)
```

:::pista
`referencia = por_dia.rolling(7).mean().shift(1)`. El día alerta si `por_dia <= 0.88 * referencia`. Para el texto: `[f.strftime("%Y-%m-%d") for f in por_dia[mascara].index]`.
:::

```pyprueba
import pandas as pd


def _esperado():
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    d["inicio"] = pd.to_datetime(d["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    serie = d.dropna(subset=["inicio"]).set_index("inicio").resample("D").size()
    ref = serie.rolling(7).mean().shift(1)
    return ref, [f.strftime("%Y-%m-%d") for f in serie[serie <= 0.88 * ref].index]


def prueba_referencia():
    """referencia es la media de los 7 días anteriores"""
    requiere("referencia")
    esperado, _ = _esperado()
    a = [round(float(x), 6) for x in referencia.fillna(-1)]
    b = [round(float(x), 6) for x in esperado.fillna(-1)]
    igual(a, b)


def prueba_alertas():
    """alertas son los días con caída de 12 % o más"""
    requiere("alertas")
    igual([str(x) for x in alertas], _esperado()[1])
```

```pysolucion
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")

print(alertas)
```
