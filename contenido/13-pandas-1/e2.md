## Enunciado

Con `cdr.csv` cargado en un DataFrame (`linea_origen` y `linea_destino` como texto), responde con filtros:

1. `llamadas_internacionales_largas(cdr, minimo_seg)` → DataFrame con las llamadas `VOZ` a `INTERNACIONAL` de **más** de `minimo_seg` segundos, solo con las columnas `cdr_id`, `linea_origen` y `duracion_seg`, ordenado de mayor a menor duración.
2. `top_sesiones_datos(cdr, n)` → lista de los `cdr_id` de las `n` sesiones de `DATOS` con más megas.
3. `tipos_raros(cdr)` → diccionario `{tipo: cantidad}` de los tipos que no son `VOZ`, `SMS` ni `DATOS`, ordenado por tipo.
4. `proporcion_sin_contestar(cdr)` → proporción de llamadas `VOZ` con duración 0, redondeada a 4 decimales (float).

## Pista 2

- `cdr[cdr["tipo"] == "DATOS"].nlargest(n, "mb")["cdr_id"].tolist()`
- La proporción de una máscara es su media: `(voz["duracion_seg"] == 0).mean()`.

## Solución

```python
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})


def llamadas_internacionales_largas(cdr, minimo_seg):
    filtro = (cdr["tipo"] == "VOZ") & (cdr["destino"] == "INTERNACIONAL") & (cdr["duracion_seg"] > minimo_seg)
    return cdr.loc[filtro, ["cdr_id", "linea_origen", "duracion_seg"]].sort_values("duracion_seg", ascending=False)


def top_sesiones_datos(cdr, n):
    return cdr[cdr["tipo"] == "DATOS"].nlargest(n, "mb")["cdr_id"].tolist()


def tipos_raros(cdr):
    raros = cdr.loc[~cdr["tipo"].isin(["VOZ", "SMS", "DATOS"]), "tipo"].value_counts().sort_index()
    return {tipo: int(n) for tipo, n in raros.items()}


def proporcion_sin_contestar(cdr):
    voz = cdr[cdr["tipo"] == "VOZ"]
    return round(float((voz["duracion_seg"] == 0).mean()), 4)


print(llamadas_internacionales_largas(cdr, 600).head())
```

## Explicación

Cada pregunta de negocio es un **filtro** (qué filas), una **selección** (qué columnas) y a veces un **orden** o una **agregación**. Con esa receta respondes la mayoría de las preguntas que llegan por correo: "¿cuáles fueron las llamadas internacionales más largas?", "¿cuántos registros traen tipos inválidos?".

`loc[filtro, columnas]` hace las dos cosas a la vez y deja claro qué filas y qué columnas te interesan.
