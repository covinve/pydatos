## dtype: el tipo de cada elemento

| dtype | Rango | Bytes | Ejemplo telco |
|---|---|---|---|
| `int8` | −128 a 127 | 1 | Hora del día (0–23) |
| `int16` | −32.768 a 32.767 | 2 | Día del año |
| `int32` | ±2.100 millones | 4 | Duración en segundos |
| `int64` | ±9,2 × 10¹⁸ | 8 | Totales en pesos, `cdr_id` |
| `float32` | ~7 dígitos de precisión | 4 | Megas de una sesión |
| `float64` | ~15 dígitos | 8 | Sumas de megas, estadísticas |
| `bool` | Verdadero/falso | 1 | Máscaras |

```pyrun
import numpy as np

n = 10_000_000
horas_64 = np.zeros(n, dtype=np.int64)
horas_8 = np.zeros(n, dtype=np.int8)
print(f"int64: {horas_64.nbytes / 1e6:.0f} MB")
print(f"int8:  {horas_8.nbytes / 1e6:.0f} MB")
```

Con 280 millones de registros, elegir `int8` para la hora en lugar de `int64` ahorra casi 2 GB.

## El peligro: desbordamiento

Los enteros de NumPy tienen **tamaño fijo**. Si un resultado no cabe, **da la vuelta en silencio**:

```pyrun
import numpy as np

duraciones = np.array([30_000, 10_000], dtype=np.int16)
print(duraciones.sum())                 # NumPy agranda el tipo al sumar: correcto
print(duraciones + duraciones)          # aquí no: 60.000 no cabe en int16 → número negativo
print((duraciones.astype(np.int64) + duraciones).dtype)
```

:::error Guardar pequeño, calcular grande
Guarda con el tipo más pequeño que alcance, pero **convierte a `int64` o `float64` antes de multiplicar o sumar** valores que pueden crecer (pesos, totales). Un desbordamiento no da error: da un número equivocado.
:::

## float y dinero

Igual que en Python, los `float` de NumPy tienen errores de representación. Para dinero, la estrategia con arrays es **trabajar en pesos enteros (`int64`)** y redondear explícitamente donde la regla lo diga:

```pyrun
import numpy as np

subtotales = np.array([150, 40940, 20150], dtype=np.int64)
iva_banquero = np.round(subtotales * 0.19)              # redondeo del banquero
iva_comercial = np.floor(subtotales * 0.19 + 0.5)       # 0,5 sube
print(iva_banquero)
print(iva_comercial.astype(np.int64))
```

`np.floor(x + 0.5)` implementa "0,5 sube" para valores positivos (es lo que usa el generador de datos del curso).

## NaN: el dato faltante

`np.nan` representa un valor faltante en arrays de `float`. Contagia todo lo que toca:

```pyrun
import numpy as np

mb = np.array([15.1, np.nan, 7.2])
print(mb.sum())                 # nan
print(np.nansum(mb))            # ignora los nan
print(np.isnan(mb))
print(np.nan == np.nan)         # ¡False! usa np.isnan
```

## Archivos más grandes que la memoria: memmap

`np.memmap` mapea un archivo binario a un array **sin cargarlo**: el sistema operativo lee del disco solo las partes que usas. Funciona muy bien con archivos de **ancho fijo**, donde cada registro mide lo mismo:

```python
import numpy as np

bytes_ = np.memmap("datos/1GB/cdr_ancho_fijo.txt", dtype=np.uint8, mode="r")
registros = bytes_.reshape(-1, 92)          # 91 caracteres + salto de línea
tipos = registros[:, 35:40]                  # columna de tipo, sin leer el resto
```

Lo usarás en el ejercicio 9 para leer 1 GB a velocidad de NumPy.

## Números aleatorios reproducibles

Para simulaciones (¿qué pasaría si cambiamos el plan?) usa un **generador con semilla**: así los resultados se pueden repetir.

```pyrun
import numpy as np

rng = np.random.default_rng(2026)
minutos = rng.poisson(lam=320, size=10)          # minutos de 10 clientes simulados
print(minutos)
print((minutos > 300).mean())                    # proporción que excedería un plan de 300

rng = np.random.default_rng(2026)
print(rng.poisson(lam=320, size=10))             # misma semilla → mismos números
```

| Función | Distribución | Uso típico |
|---|---|---|
| `rng.integers(a, b, n)` | Enteros uniformes | Horas, celdas |
| `rng.poisson(lam, n)` | Conteos | Llamadas o SMS por mes |
| `rng.lognormal(mu, sigma, n)` | Asimétrica, de cola larga | Duraciones, megas |
| `rng.normal(media, desv, n)` | Normal | Errores de medición |
| `rng.choice(opciones, n, p=...)` | Categórica | Tipo de CDR, destino |

:::telco Así se generaron tus datos
`herramientas/generar_datos.py` usa exactamente estas funciones: `lognormal` para duraciones y megas, `choice` para tipos y destinos, `bincount` para acumular el consumo por cliente. Ahora puedes leerlo y entenderlo.
:::
