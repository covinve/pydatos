**matplotlib** es la librería base de gráficos en Python: Pandas y seaborn la usan por dentro. Su modelo tiene dos piezas:

- **Figure**: el lienzo completo (la imagen).
- **Axes**: un gráfico dentro del lienzo, con sus ejes, título y etiquetas. Una figura puede tener varios.

```pyrun
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 3.5))
dias = [1, 2, 3, 4, 5, 6, 7]
llamadas = [120, 135, 128, 150, 162, 90, 75]

ax.plot(dias, llamadas, marker="o")
ax.set_title("Llamadas por día (primera semana)")
ax.set_xlabel("Día de septiembre")
ax.set_ylabel("Llamadas")
ax.grid(alpha=0.3)
```

:::consejo Usa siempre fig, ax = plt.subplots()
Hay dos estilos: llamar a `plt.plot(...)` directamente, o crear `fig, ax` y usar `ax.plot(...)`. El segundo es explícito, funciona igual con uno o con veinte gráficos, y es el que usan los profesionales. Es el que usaremos.
:::

## Barras

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)]
minutos = ((voz["duracion_seg"] + 59) // 60).groupby(voz["destino"]).sum().sort_values()

fig, ax = plt.subplots(figsize=(7, 3))
barras = ax.barh(minutos.index, minutos.values, color="#4f46e5")
ax.bar_label(barras, labels=[f"{v:,}".replace(",", ".") for v in minutos.values], padding=3)
ax.set_title("Minutos de voz por destino")
ax.set_xlabel("Minutos")
ax.spines[["top", "right"]].set_visible(False)
```

`barh` (barras horizontales) es ideal cuando las categorías tienen nombres largos. `bar_label` escribe el valor al final de cada barra.

## Histograma: la forma de los datos

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
duraciones = cdr.loc[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] > 0), "duracion_seg"]

fig, ax = plt.subplots(figsize=(7, 3))
ax.hist(duraciones, bins=40, color="#0891b2", edgecolor="white")
ax.set_title("Distribución de la duración de las llamadas")
ax.set_xlabel("Segundos")
ax.set_ylabel("Llamadas")
```

La mayoría de las llamadas son cortas y unas pocas muy largas: una distribución con **cola larga a la derecha**, muy común en consumo telco.

## Desde Pandas

Los objetos de Pandas tienen `.plot()`, que crea el gráfico en un `ax` (puedes pasarle el tuyo):

```pyrun
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
cdr["inicio"] = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
por_dia = cdr.dropna(subset=["inicio"]).set_index("inicio").resample("D").size()

fig, ax = plt.subplots(figsize=(8, 3))
por_dia.plot(ax=ax, color="#16a34a")
por_dia.rolling(7).mean().plot(ax=ax, color="#334155", linestyle="--", label="Media móvil 7 días")
ax.set_title("Registros por día")
ax.set_xlabel("")
ax.legend(["Registros", "Media móvil 7 días"])
```

## Guardar el gráfico

```python
fig.savefig("reportes/minutos_por_destino.png", dpi=150, bbox_inches="tight")
```

`bbox_inches="tight"` recorta los márgenes sobrantes; `dpi=150` da buena calidad para informes y presentaciones.

:::telco Un gráfico vale más que una tabla de 30 filas
"El consumo de datos creció 18 % en la última semana" se entiende en un segundo con una línea; en una tabla de 30 días, nadie lo ve. Los gráficos no son decoración: son la forma más rápida de que una persona de negocio entienda lo que dicen los datos.
:::
