## Enunciado

El proceso nocturno de validación reporta errores **que no son del archivo que se está procesando**: a veces aparecen errores de archivos anteriores. Este es el código:

```python
def validar_archivo(registros, errores=[], resumen={}):
    for numero, registro in enumerate(registros, start=1):
        if registro["duracion"] < 0:
            errores.append((numero, "duracion_negativa"))
            resumen["duracion_negativa"] = resumen.get("duracion_negativa", 0) + 1
    return errores, resumen
```

Encuentra el problema y corrígelo **sin cambiar la forma de usar la función**:

- `validar_archivo(registros)` devuelve los errores y el resumen **solo de esos registros**.
- Si se pasan `errores` y `resumen` existentes, la función agrega a ellos (para acumular varios archivos a propósito).
- Además, agrega las anotaciones de tipo: los parámetros opcionales son `list[tuple[int, str]] | None` y `dict[str, int] | None`.

## Código inicial

```python
def validar_archivo(registros, errores=[], resumen={}):
    for numero, registro in enumerate(registros, start=1):
        if registro["duracion"] < 0:
            errores.append((numero, "duracion_negativa"))
            resumen["duracion_negativa"] = resumen.get("duracion_negativa", 0) + 1
    return errores, resumen


archivo_1 = [{"duracion": 10}, {"duracion": -5}]
archivo_2 = [{"duracion": 30}]
print(validar_archivo(archivo_1))
print(validar_archivo(archivo_2))   # debería no tener errores
```

## Pruebas

```python
import inspect

A1 = [{"duracion": 10}, {"duracion": -5}, {"duracion": -1}]
A2 = [{"duracion": 30}]


def prueba_archivo_con_errores():
    """Reporta los errores de un archivo"""
    requiere("validar_archivo")
    igual(validar_archivo(A1), ([(2, "duracion_negativa"), (3, "duracion_negativa")], {"duracion_negativa": 2}))


def prueba_llamadas_independientes():
    """Cada llamada sin acumuladores empieza de cero"""
    validar_archivo(A1)
    validar_archivo(A1)
    igual(validar_archivo(A2), ([], {}), "El segundo archivo no debe arrastrar errores del primero")


def prueba_acumular_a_proposito():
    """Si se pasan acumuladores, agrega a ellos"""
    errores, resumen = [], {}
    validar_archivo(A1, errores, resumen)
    validar_archivo([{"duracion": -9}], errores, resumen)
    igual(len(errores), 3)
    igual(resumen, {"duracion_negativa": 3})


def prueba_sin_valores_mutables_por_defecto():
    """Ningún parámetro tiene una lista o diccionario como valor por defecto"""
    for nombre, parametro in inspect.signature(validar_archivo).parameters.items():
        assert not isinstance(parametro.default, (list, dict, set)), (
            f"El parámetro `{nombre}` tiene un valor por defecto mutable"
        )


def prueba_anotaciones():
    """Los parámetros opcionales están anotados como ... | None"""
    firma = inspect.signature(validar_archivo)
    for nombre in ("errores", "resumen"):
        anotacion = str(firma.parameters[nombre].annotation)
        assert "None" in anotacion, f"Anota `{nombre}` con `| None`; tiene: {anotacion}"
```

## Pista 1

El problema es la **trampa del valor por defecto mutable** de la lección 1: `errores=[]` y `resumen={}` se crean una sola vez, cuando Python lee el `def`. Todas las llamadas que no pasan esos argumentos comparten la misma lista y el mismo diccionario.

## Pista 2

Cambia los valores por defecto a `None` y crea los objetos dentro de la función:

```python
def validar_archivo(registros, errores=None, resumen=None):
    if errores is None:
        errores = []
    if resumen is None:
        resumen = {}
    ...
```

Para las anotaciones: `errores: list[tuple[int, str]] | None = None`.

## Solución

```python
def validar_archivo(
    registros: list[dict],
    errores: list[tuple[int, str]] | None = None,
    resumen: dict[str, int] | None = None,
) -> tuple[list[tuple[int, str]], dict[str, int]]:
    if errores is None:
        errores = []
    if resumen is None:
        resumen = {}
    for numero, registro in enumerate(registros, start=1):
        if registro["duracion"] < 0:
            errores.append((numero, "duracion_negativa"))
            resumen["duracion_negativa"] = resumen.get("duracion_negativa", 0) + 1
    return errores, resumen


archivo_1 = [{"duracion": 10}, {"duracion": -5}]
archivo_2 = [{"duracion": 30}]
print(validar_archivo(archivo_1))
print(validar_archivo(archivo_2))
```

## Explicación

Este es uno de los errores más famosos de Python, y es especialmente traicionero porque:

- **Las pruebas con un solo archivo pasan.** El problema solo aparece en la segunda llamada.
- **En producción se ve como datos corruptos**, no como un error de programación: "el archivo de hoy tiene errores que no están en el archivo".

El patrón `=None` + `if x is None: x = []` es la solución estándar, y `ruff` (regla `B006`) lo detecta automáticamente si activas las reglas de *bugbear*. Desde ahora, cuando veas `=[]` o `={}` en la definición de una función, enciende la alarma.
