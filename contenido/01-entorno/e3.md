## Enunciado

El área de servicio al cliente necesita un resumen de cada llamada. Las primeras líneas del código traen los datos de **una** llamada. Escribe debajo el código que imprima **exactamente** este formato:

```text
Llamada de 3001234567 a 3109876543
Duración: 125 segundos
Minutos facturables: 3
Valor: $360
```

Reglas:

- Los minutos se cobran **redondeando hacia arriba**: 125 segundos son 3 minutos. En Python se calcula así: `(duracion_seg + 59) // 60` (el operador `//` divide y descarta los decimales; lo verás en el módulo 2).
- El valor es `minutos facturables × tarifa_minuto`.

:::error No escribas los números a mano
Las pruebas cambian los datos de las primeras líneas y vuelven a ejecutar tu código. Si escribes `print("Valor: $360")`, fallará con otra llamada. Usa las variables.
:::

## Código inicial

```python
linea_origen = "3001234567"
linea_destino = "3109876543"
duracion_seg = 125
tarifa_minuto = 120

# Escribe tu código debajo de esta línea
```

```python
def correr_con(**valores):
```

## Pista 1

Primero calcula los valores en variables nuevas y después imprímelos:

```python
minutos = (duracion_seg + 59) // 60
valor = ...
```

Luego usa un f-string por cada línea: `print(f"Llamada de {linea_origen} a ...")`.

## Pista 2

Fíjate en los detalles del formato: hay un espacio después de cada `:`, la palabra `segundos` va al final de la línea de duración y el valor lleva `$` pegado al número:

```python
print(f"Valor: ${valor}")
```

## Solución

```python
linea_origen = "3001234567"
linea_destino = "3109876543"
duracion_seg = 125
tarifa_minuto = 120

minutos_facturables = (duracion_seg + 59) // 60
valor = minutos_facturables * tarifa_minuto

print(f"Llamada de {linea_origen} a {linea_destino}")
print(f"Duración: {duracion_seg} segundos")
print(f"Minutos facturables: {minutos_facturables}")
print(f"Valor: ${valor}")
```

## Explicación

Separar **cálculo** e **impresión** hace el código más claro: primero se calculan `minutos_facturables` y `valor`, y después se muestran.

El truco `(duracion_seg + 59) // 60` redondea hacia arriba sin usar decimales:

| Segundos | + 59 | // 60 |
|---|---|---|
| 0 | 59 | 0 |
| 1 | 60 | 1 |
| 60 | 119 | 1 |
| 61 | 120 | 2 |
| 125 | 184 | 3 |

Las pruebas que cambian los datos de entrada son una idea que verás en todo el curso: un programa correcto debe funcionar con **cualquier** dato válido, no solo con el del ejemplo.
