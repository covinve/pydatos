## Enunciado

Agrupa con NumPy, sin diccionarios ni bucles sobre los registros. Recibes arrays paralelos `lineas`, `tipos`, `duraciones` y `mb`. Escribe `consumo_por_linea(lineas, tipos, duraciones, mb)` que devuelva un diccionario:

```python
{"lineas": [...], "minutos": [...], "mb": [...], "registros": [...]}
```

- `lineas`: líneas distintas, ordenadas;
- `minutos`: minutos facturables de `VOZ` de cada línea (int);
- `mb`: megas de `DATOS` de cada línea, redondeadas a 3 decimales (float);
- `registros`: cantidad total de registros de cada línea (int).

Todas las listas en el mismo orden de `lineas`, con tipos de Python.

Y `top_consumidores(resultado, n)` → las `n` líneas con más minutos (de mayor a menor; en empate, la línea menor primero), usando `np.lexsort` o `np.argsort`.

## Pista 2

`bincount` con `weights` devuelve `float`: convierte los minutos con `.astype(int)`. Para el top: `np.lexsort((lineas, -minutos))` ordena por el **último** criterio primero (minutos descendentes) y desempata con el anterior (línea).

## Solución

```python
import numpy as np


def consumo_por_linea(lineas, tipos, duraciones, mb):
    unicas, indice = np.unique(lineas, return_inverse=True)
    k = len(unicas)
    minutos = np.bincount(indice, weights=np.where(tipos == "VOZ", (duraciones + 59) // 60, 0), minlength=k)
    megas = np.bincount(indice, weights=np.where(tipos == "DATOS", mb, 0.0), minlength=k)
    registros = np.bincount(indice, minlength=k)
    return {
        "lineas": unicas.tolist(),
        "minutos": minutos.astype(np.int64).tolist(),
        "mb": np.round(megas, 3).tolist(),
        "registros": registros.tolist(),
    }


def top_consumidores(resultado, n):
    lineas = np.array(resultado["lineas"])
    minutos = np.array(resultado["minutos"])
    orden = np.lexsort((lineas, -minutos))
    return lineas[orden][:n].tolist()
```

## Explicación

`np.unique(..., return_inverse=True)` convierte cada línea en un **número de grupo** (0, 1, 2…). Con eso, `np.bincount` suma por grupo en una sola pasada en C. Es la misma técnica que usa el generador de datos del curso para acumular el consumo de cientos de miles de clientes.

Comparado con el diccionario del módulo 4:

| | Diccionario | unique + bincount |
|---|---|---|
| 1 millón de registros | ~1 s | ~0,1 s |
| Código | Bucle con `if` por tipo | Tres llamadas vectorizadas |
| Memoria | Objetos de Python | Arrays compactos |

`np.lexsort` recibe las claves **al revés** (la última es la principal). Es poco intuitivo, pero es la forma de ordenar por varios criterios sin bucles.
