## Agregaciones

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45, 300, 15])

print("Total:", duraciones.sum())
print("Promedio:", duraciones.mean().round(1))
print("Mediana:", np.median(duraciones))
print("Desviación:", duraciones.std().round(1))
print("Mín / máx:", duraciones.min(), duraciones.max())
print("Percentil 95:", np.percentile(duraciones, 95))
print("Posición del máximo:", duraciones.argmax())
```

### El parámetro axis

En arrays de 2 dimensiones, `axis` dice en qué dirección agregar: `axis=0` recorre **filas** (resultado por columna) y `axis=1` recorre **columnas** (resultado por fila).

```pyrun
import numpy as np

# filas: 3 líneas; columnas: minutos de 4 semanas
semanas = np.array([
    [80, 95, 70, 97],
    [5, 0, 10, 0],
    [300, 280, 310, 313],
])
print(semanas.sum(axis=1))    # total de cada línea
print(semanas.sum(axis=0))    # total de cada semana
print(semanas.mean(axis=0))
```

:::reto Totales por fila y por columna
Con la tabla `semanas` (filas: 4 líneas; columnas: minutos de 4 semanas), calcula:

- `por_linea`: el total de minutos de cada línea;
- `promedio_semana`: el promedio de cada semana entre las 4 líneas;
- `linea_top`: la **posición** de la línea con más minutos en el mes.

```pyreto
import numpy as np

semanas = np.array([
    [80, 95, 70, 97],
    [5, 0, 10, 0],
    [300, 280, 310, 313],
    [120, 150, 90, 110],
])

# por_linea, promedio_semana y linea_top

print(por_linea, promedio_semana, linea_top)
```

:::pista
`axis=1` da un resultado por fila (por línea) y `axis=0` uno por columna (por semana). La posición del mayor la da `.argmax()`.
:::



## Agrupar: np.unique y np.bincount

Para sumar por grupo (minutos por línea), NumPy no tiene `groupby`, pero tiene piezas muy rápidas:

```pyrun
import numpy as np

lineas = np.array(["3002", "3001", "3002", "3003", "3001", "3002"])
minutos = np.array([3, 2, 1, 60, 5, 2])

unicas, indice = np.unique(lineas, return_inverse=True)
print(unicas)          # las líneas distintas, ordenadas
print(indice)          # para cada registro, la posición de su línea en `unicas`

totales = np.bincount(indice, weights=minutos)
print(dict(zip(unicas.tolist(), totales.astype(int).tolist())))

conteos = np.bincount(indice)            # sin weights: cuenta registros por grupo
print(conteos)
```

`np.bincount(indice, weights=valores)` suma `valores` en la posición `indice` de cada uno. Es exactamente lo que hace el generador de datos del curso para acumular el consumo de cientos de miles de líneas.

:::reto Megas por plan, sin diccionarios
Con `np.unique` y `np.bincount`, crea:

- `planes_unicos`: los planes distintos (ordenados);
- `mb_por_plan`: el total de megas de cada plan, en el mismo orden;
- `sesiones_por_plan`: cuántas sesiones tuvo cada plan.

```pyreto
import numpy as np

planes = np.array(["HOG30", "ILIM", "HOG30", "EMP100", "ILIM", "HOG30"])
mb = np.array([120.5, 2048.0, 79.5, 512.0, 1024.0, 300.0])

# planes_unicos, mb_por_plan y sesiones_por_plan

print(planes_unicos, mb_por_plan, sesiones_por_plan)
```

:::pista
`planes_unicos, indice = np.unique(planes, return_inverse=True)`. Luego `np.bincount(indice, weights=mb)` suma por grupo, y `np.bincount(indice)` cuenta.
:::

## Ordenar

```pyrun
import numpy as np

minutos = np.array([342, 15, 1203, 342, 60])
print(np.sort(minutos))                  # copia ordenada
orden = np.argsort(minutos)[::-1]        # posiciones de mayor a menor
print(orden)
lineas = np.array(["3001", "3002", "3003", "3004", "3005"])
print(lineas[orden][:3])                 # top 3
```

`argsort` devuelve **posiciones**: sirve para ordenar varios arrays "en paralelo" según uno de ellos.

## Acumulados

```pyrun
import numpy as np

minutos_por_llamada = np.array([3, 0, 2, 60, 1, 5])
acumulado = np.cumsum(minutos_por_llamada)
print(acumulado)
print(np.argmax(acumulado > 60))   # primera llamada en que se superan 60 minutos
```

:::reto Top y acumulado
1. Con `argsort`, crea `top2`: las dos líneas con más minutos, de mayor a menor.
2. Con `cumsum`, crea `acumulado` (los minutos consumidos después de cada llamada) y `agota`: la **posición** de la primera llamada en que el acumulado supera 60.

```pyreto
import numpy as np

lineas = np.array(["3001", "3002", "3003", "3004", "3005"])
minutos_linea = np.array([342, 15, 1203, 980, 60])

minutos_llamada = np.array([3, 0, 2, 60, 1, 5, 40])

# top2, acumulado y agota

print(top2, acumulado, agota)
```

:::pista
`orden = np.argsort(minutos_linea)[::-1]` da las posiciones de mayor a menor; `lineas[orden][:2]` toma las dos primeras. Para la primera posición donde se cumple una condición: `np.argmax(acumulado > 60)`.
:::

```pyprueba
def prueba_top2():
    """top2 = ['3003', '3004']"""
    requiere("top2")
    igual(list(top2), ["3003", "3004"])


def prueba_acumulado():
    """acumulado y agota"""
    requiere("acumulado", "agota")
    igual(list(acumulado), [3, 3, 5, 65, 66, 71, 111], "acumulado")
    igual(int(agota), 3, "agota")
```

```pysolucion
import numpy as np

lineas = np.array(["3001", "3002", "3003", "3004", "3005"])
minutos_linea = np.array([342, 15, 1203, 980, 60])

minutos_llamada = np.array([3, 0, 2, 60, 1, 5, 40])

orden = np.argsort(minutos_linea)[::-1]
top2 = lineas[orden][:2]

acumulado = np.cumsum(minutos_llamada)
agota = np.argmax(acumulado > 60)

print(top2, acumulado, agota)
```
:::

## Broadcasting

NumPy puede operar arrays de **formas distintas** "estirando" el más pequeño. El caso más común es un array con un escalar (`array * 120`), pero también funciona con filas y columnas:

```pyrun
import numpy as np

# 3 líneas × 3 conceptos (minutos, megas, sms) de exceso
excesos = np.array([
    [42, 141, 20],
    [0, 0, 0],
    [203, 0, 5],
])
tarifas = np.array([120, 18, 60])      # una tarifa por columna

print(excesos * tarifas)               # la fila de tarifas se aplica a cada fila
print((excesos * tarifas).sum(axis=1))
```

:::capo La regla del broadcasting
Se comparan las formas desde la última dimensión: son compatibles si son iguales o si una de ellas es 1. `(3, 3)` con `(3,)` funciona (la fila se repite); `(3, 3)` con `(4,)` da error.
:::

:::reto Una factura por línea con broadcasting
Cada fila de `excesos` es una línea, y las columnas son minutos, megas y SMS de exceso. Con **broadcasting** (sin bucles ni repetir las tarifas a mano):

- `valores`: la tabla con el valor de cada exceso (exceso × tarifa de su columna);
- `por_linea`: el total a cobrar de cada línea;
- `con_iva`: `por_linea` más el 19 % de IVA, redondeado al peso con la regla comercial (`np.floor(x + 0.5)`), como enteros.

```pyreto
import numpy as np

excesos = np.array([
    [42, 141, 20],
    [0, 0, 0],
    [203, 0, 5],
])
tarifas = np.array([120, 18, 60])

# valores, por_linea y con_iva

print(valores, por_linea, con_iva)
```

:::pista
`excesos * tarifas` aplica la fila de tarifas a cada fila. Suma por fila con `.sum(axis=1)`. El IVA: `np.floor(por_linea * 1.19 + 0.5).astype(np.int64)`.
:::

```pyprueba
def prueba_valores():
    """valores multiplica cada columna por su tarifa"""
    requiere("valores")
    igual(valores.tolist(), [[5040, 2538, 1200], [0, 0, 0], [24360, 0, 300]])


def prueba_totales():
    """por_linea y con_iva"""
    requiere("por_linea", "con_iva")
    igual(list(por_linea), [8778, 0, 24660], "por_linea")
    igual([int(x) for x in con_iva], [10446, 0, 29345], "con_iva")
```

```pysolucion
import numpy as np

excesos = np.array([
    [42, 141, 20],
    [0, 0, 0],
    [203, 0, 5],
])
tarifas = np.array([120, 18, 60])

valores = excesos * tarifas
por_linea = valores.sum(axis=1)
con_iva = np.floor(por_linea * 1.19 + 0.5).astype(np.int64)

print(valores, por_linea, con_iva)
```
:::

:::telco De diccionarios a arrays
En el módulo 4 agrupaste con diccionarios: correcto y claro, pero con 280 millones de registros es lento. Con `np.unique` + `np.bincount`, el mismo agrupamiento sobre millones de valores toma milisegundos. Pandas (`groupby`) usa estas mismas ideas por dentro.
:::
