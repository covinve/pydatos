La mayor parte de los datos de facturación llega como **texto**: líneas de archivos planos que hay que cortar, limpiar y convertir. Dominar el texto en Python es la mitad del trabajo.

## Índices y slicing

Cada carácter de un texto tiene una posición, **empezando en 0**. Con números negativos cuentas desde el final.

```pyrun
tipo = "DATOS"
print(tipo[0])     # D
print(tipo[1])     # A
print(tipo[-1])    # S (el último)
print(len(tipo))   # 5 caracteres
```

El **slicing** `texto[inicio:fin]` toma desde `inicio` **hasta antes de** `fin`:

```pyrun
fecha = "2026-09-13 10:31:28"
print(fecha[0:4])    # año
print(fecha[5:7])    # mes
print(fecha[8:10])   # día
print(fecha[11:])    # desde la posición 11 hasta el final
print(fecha[:10])    # desde el inicio hasta antes de la 10
```

## Registros de ancho fijo

En un archivo de ancho fijo cada campo ocupa siempre las mismas posiciones. El slicing es la herramienta perfecta. Según el diseño del archivo del curso (**Referencia → Datos del curso**), el `cdr_id` ocupa las posiciones 1 a 12 y la línea de origen, de la 13 a la 22:

```pyrun
registro = "00000000000233027032633040879936   VOZ  NACIONAL     20260913103128000030000000.000CEL97932"

cdr_id = registro[0:12]
linea_origen = registro[12:22]
tipo = registro[35:40]

print(repr(cdr_id), "→", int(cdr_id))
print(repr(linea_origen))
print(repr(tipo), "→", repr(tipo.strip()))
```

:::consejo De posiciones del documento a índices de Python
Los diseños de archivo cuentan desde 1. Para el campo que va de la posición **a** a la **b** (incluidas), usa `registro[a - 1:b]`. Por ejemplo, posiciones 13 a 22 → `registro[12:22]`.
:::

`repr()` muestra el texto con comillas, lo que deja ver los espacios sobrantes. Úsalo siempre que depures texto.

## Métodos de texto

Un método es una función que pertenece a un valor y se llama con un punto: `texto.upper()`. Los textos **no cambian**: cada método devuelve un texto nuevo.

```pyrun
crudo = "  voz  "
print(repr(crudo.strip()))          # quita espacios a los lados
print(crudo.strip().upper())         # VOZ

linea = "300-123-4567"
print(linea.replace("-", ""))        # 3001234567
print(linea.replace("-", "").isdigit())

print("3001234567".startswith("3"))
print("45".zfill(6))                 # rellena con ceros: 000045
print("CEL97932".removeprefix("CEL"))
```

| Método | Qué hace | Ejemplo → resultado |
|---|---|---|
| `strip()` | Quita espacios (y saltos de línea) a los lados | `" VOZ \n".strip()` → `"VOZ"` |
| `upper()` / `lower()` | Mayúsculas / minúsculas | `"voz".upper()` → `"VOZ"` |
| `replace(a, b)` | Reemplaza `a` por `b` | `"1,5".replace(",", ".")` → `"1.5"` |
| `split(sep)` | Corta en una lista | `"a|b|c".split("|")` → `["a", "b", "c"]` |
| `startswith(x)` | ¿Empieza con x? | `"3001".startswith("3")` → `True` |
| `isdigit()` | ¿Son todos dígitos? | `"300a".isdigit()` → `False` |
| `zfill(n)` | Rellena con ceros a la izquierda | `"45".zfill(6)` → `"000045"` |
| `count(x)` | Cuántas veces aparece | `"a|b|c".count("|")` → `2` |

## f-strings con formato

Dentro de las llaves, después de `:`, va el **formato**:

```pyrun
total = 1234567.891
minutos = 7
codigo = 45

print(f"{total:,.2f}")       # separador de miles y 2 decimales
print(f"{total:.0f}")        # sin decimales
print(f"{minutos:02d}")      # 2 dígitos con cero: 07
print(f"{codigo:06d}")       # 6 dígitos: 000045
print(f"{0.1532:.1%}")       # porcentaje: 15.3%
print(f"[{'VOZ':<8}]")      # alineado a la izquierda en 8 espacios
print(f"[{'VOZ':>8}]")      # a la derecha
print(f"[{'VOZ':^8}]")      # centrado
```

### Formato colombiano: punto de miles y coma decimal

Python usa la convención inglesa (`1,234.56`). Para mostrar `1.234,56` intercambia los símbolos con un comodín:

```pyrun
total = 1234567.891
texto = f"{total:,.2f}"
print(texto)
print(texto.replace(",", "X").replace(".", ",").replace("X", "."))
```

:::telco Reportes legibles
Los reportes de facturación los leen personas de negocio. `$48.719` se entiende al instante; `48719.0` genera preguntas. Darle formato a los números es parte del trabajo, no un detalle.
:::

## Cuestionario

? Si `registro = "0000000000123001234567"`, ¿qué devuelve `registro[12:22]`?
- [x] `"3001234567"`
- [ ] `"0000000000123"`
- [ ] `"001234567"`
- [ ] `"30012345678"`
> Las posiciones 12 a 21 (el 22 no se incluye) son los 10 caracteres de la línea.

? ¿Qué imprime `print(f"{7:03d}")`?
- [ ] `7.00`
- [x] `007`
- [ ] `700`
- [ ] `  7`
> `03d` significa: entero (`d`) de 3 dígitos rellenado con ceros.

? Tienes `tipo = " voz "`. ¿Qué expresión produce exactamente `"VOZ"`?
- [ ] `tipo.upper()`
- [ ] `tipo.strip`
- [x] `tipo.strip().upper()`
- [ ] `upper(strip(tipo))`
> Hay que quitar los espacios y luego pasar a mayúsculas. Los métodos se encadenan con puntos y llevan paréntesis.
