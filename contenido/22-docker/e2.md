## Enunciado

Escribe `revisar(texto)` que devuelva la lista de **advertencias** de un Dockerfile, cada una como tupla `(codigo, linea)`, ordenadas por línea y luego por código:

| Código | Regla | Línea que se informa |
|---|---|---|
| `D001` | Un `FROM` sin etiqueta o con `:latest` | La del `FROM` |
| `D002` | Un `RUN` con `pip install` sin `--no-cache-dir` | La del `RUN` |
| `D003` | Un `COPY . ` (copiar todo el proyecto) **antes** de un `RUN` con `pip install` | La del `COPY` |
| `D004` | Un `ENV` o `ARG` cuyo nombre contiene `PASSWORD`, `TOKEN`, `SECRET` o `KEY` (sin distinguir mayúsculas) | La del `ENV`/`ARG` |
| `D005` | No hay ninguna instrucción `USER` (o la última es `USER root`) | `0` |
| `D006` | `ENTRYPOINT` o `CMD` que no está en forma de lista (no empieza por `[`) | La de esa instrucción |

La función `instrucciones(texto)` del ejercicio anterior ya está disponible (viene en la preparación).

## Preparación

```python
from pathlib import Path

Path("dockerfile_lector.py").write_text('''
def instrucciones(texto):
    resultado, actual, inicio = [], [], None
    for numero, linea in enumerate(texto.splitlines(), start=1):
        limpia = linea.strip()
        if not limpia or limpia.startswith("#"):
            continue
        if inicio is None:
            inicio = numero
        continua = limpia.endswith("\\\\")
        actual.append(limpia[:-1].strip() if continua else limpia)
        if not continua:
            completa = " ".join(p for p in actual if p)
            nombre, _, argumentos = completa.partition(" ")
            resultado.append((nombre.upper(), argumentos.strip(), inicio))
            actual, inicio = [], None
    return resultado
''', encoding="utf-8")
```

def prueba_casos():
    """Casos sueltos"""
    base = "USER app\n"

## Pista 1

Recorre `instrucciones(texto)` una vez y ve anotando. Para `D002`, separa el `RUN` en comandos por `&&` y revisa cada `pip install`. Para `D003`, recuerda si ya viste un `COPY . ...` (el primer argumento es `.`) sin un `pip install` previo.

## Pista 2

Para el nombre de la variable en `ENV NOMBRE=valor` o `ARG NOMBRE`: `argumentos.split("=")[0].split()[0]`. Para la etiqueta del `FROM`: la imagen es `argumentos.split()[0]`; no tiene etiqueta si no hay `:` después de la última `/`.

## Solución

```python
from dockerfile_lector import instrucciones

SECRETOS = ("PASSWORD", "TOKEN", "SECRET", "KEY")


def revisar(texto):
    avisos = []
    copia_total = None
    instalo = False
    usuario = None
    for nombre, argumentos, linea in instrucciones(texto):
        if nombre == "FROM":
            imagen = argumentos.split()[0]
            etiqueta = imagen.rsplit("/", 1)[-1].partition(":")[2]
            if not etiqueta or etiqueta == "latest":
                avisos.append(("D001", linea))
        elif nombre == "RUN":
            for comando in argumentos.split("&&"):
                if "pip install" in comando and "--no-cache-dir" not in comando:
                    avisos.append(("D002", linea))
                    break
            if "pip install" in argumentos:
                if copia_total is not None:
                    avisos.append(("D003", copia_total))
                    copia_total = None
                instalo = True
        elif nombre == "COPY":
            if argumentos.split()[0] == "." and not instalo:
                copia_total = linea
        elif nombre in ("ENV", "ARG"):
            variable = argumentos.split("=")[0].split()[0].upper()
            if any(s in variable for s in SECRETOS):
                avisos.append(("D004", linea))
        elif nombre == "USER":
            usuario = argumentos.strip()
        elif nombre in ("ENTRYPOINT", "CMD") and not argumentos.startswith("["):
            avisos.append(("D006", linea))
    if usuario is None or usuario == "root":
        avisos.append(("D005", 0))
    return sorted(avisos, key=lambda a: (a[1], a[0]))


MALO = """FROM python
ENV API_TOKEN=abc123
COPY . /app
RUN pip install -r /app/requirements.txt
CMD python /app/main.py
"""
print(revisar(MALO))
```

## Explicación

Cada regla corresponde a una lección:

- **D001** (etiqueta concreta): reproducibilidad. `python` sin etiqueta es `python:latest`, que cambia sin aviso.
- **D002** (`--no-cache-dir`): pip guarda una copia de cada paquete descargado; dentro de una imagen, eso son cientos de MB que nunca se usarán.
- **D003** (orden de los `COPY`): la caché de capas. Copiar todo antes de instalar obliga a reinstalar las librerías con cada cambio de código.
- **D004** (secretos en `ENV`/`ARG`): quedan grabados en la imagen y se ven con `docker history`. Los secretos llegan al **ejecutar**, con `-e` o `--env-file`.
- **D005** (usuario sin privilegios) y **D006** (forma de lista): seguridad y señales.

Herramientas como `hadolint` revisan decenas de reglas así, y se pueden agregar a `pre-commit` o a GitHub Actions como hiciste en el módulo 20. Escribir tu propio revisor te da otra ventaja: puedes agregar reglas **de tu equipo** ("nunca copiar la carpeta `datos/`").
