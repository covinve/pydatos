## Enunciado

Implementa la precedencia completa de la lección 3. `configuracion(por_defecto, archivo, entorno, argumentos)` recibe:

- `por_defecto`: diccionario plano con **todos** los campos y su valor (su **tipo** define cómo convertir);
- `archivo`: diccionario (lo que vino del TOML), con un subconjunto de campos ya tipados;
- `entorno`: diccionario de variables de entorno (todo texto); solo cuentan las que empiezan por `TELCO_` (`TELCO_UMBRAL` → campo `umbral`, sin distinguir mayúsculas);
- `argumentos`: diccionario de la CLI; los valores `None` significan "no lo indicó" y se ignoran.

Devuelve un diccionario con el valor final de cada campo **y** de dónde salió: `{"umbral": (2.5, "entorno"), ...}`, con origen `"defecto"`, `"archivo"`, `"entorno"` o `"argumentos"`.

Conversión de texto según el tipo del valor por defecto:

| Tipo | Acepta | Error |
|---|---|---|
| `bool` | `true/false`, `1/0`, `si/no`, `yes/no` (sin distinguir mayúsculas) | Otro texto |
| `int` | `"6"` | `"seis"`, `"6.5"` |
| `float` | `"2.5"` | `"dos"` |
| `Path` | Cualquier texto | — |
| `list` | Elementos separados por comas, sin espacios alrededor (`"a@x.co, b@x.co"`) | — |
| `str` | Tal cual | — |

Un error de conversión lanza `ValueError` que menciona la **variable** y el **valor** recibido. Una variable `TELCO_` que no corresponde a ningún campo lanza `KeyError`. Las claves de `archivo` y `argumentos` también deben existir en `por_defecto`.

## Código inicial

```python
from pathlib import Path

POR_DEFECTO = {"datos": Path("datos"), "umbral": 5.0, "hilos": 4, "alertas": False, "correos": [], "periodo": "202609"}


def configuracion(por_defecto, archivo, entorno, argumentos):
    pass


r = configuracion(POR_DEFECTO, {"umbral": 3.0, "hilos": 8},
                  {"TELCO_UMBRAL": "2.5", "TELCO_ALERTAS": "si", "PATH": "C:/Windows"},
                  {"umbral": None, "periodo": "202610"})
for campo, (valor, origen) in r.items():
    print(f"{campo:8} = {valor!r:20} ← {origen}")
```

## Pista 2

Ojo con el orden de las comprobaciones de tipo: `isinstance(True, int)` es `True` en Python (bool es subclase de int), así que pregunta **primero** por `bool`.

```python
def _convertir(variable, texto, tipo_de):
    if isinstance(tipo_de, bool):
        ...
    if isinstance(tipo_de, int):
        try:
            return int(texto)
        except ValueError:

```

## Solución

```python
from pathlib import Path

POR_DEFECTO = {"datos": Path("datos"), "umbral": 5.0, "hilos": 4, "alertas": False, "correos": [], "periodo": "202609"}
VERDADEROS = {"true", "1", "si", "yes"}
FALSOS = {"false", "0", "no"}


def _exigir(campo, por_defecto):
    if campo not in por_defecto:
        raise KeyError(f"Campo de configuración desconocido: {campo}")


def _convertir(variable, texto, ejemplo):
    if isinstance(ejemplo, bool):
        if texto.lower() in VERDADEROS:
            return True
        if texto.lower() in FALSOS:
            return False
        raise ValueError(f"{variable}={texto!r} no es un booleano (usa true/false)")
    try:
        if isinstance(ejemplo, int):
            return int(texto)
        if isinstance(ejemplo, float):
            return float(texto)
    except ValueError:
        raise ValueError(f"{variable}={texto!r} no es un {type(ejemplo).__name__} válido") from None
    if isinstance(ejemplo, Path):
        return Path(texto)
    if isinstance(ejemplo, list):
        return [parte.strip() for parte in texto.split(",") if parte.strip()]
    return texto


def configuracion(por_defecto, archivo, entorno, argumentos):
    final = {campo: (valor, "defecto") for campo, valor in por_defecto.items()}
    for campo, valor in archivo.items():
        _exigir(campo, por_defecto)
        final[campo] = (valor, "archivo")
    for variable, texto in entorno.items():
        if not variable.upper().startswith("TELCO_"):
            continue
        campo = variable[len("TELCO_"):].lower()
        _exigir(campo, por_defecto)
        final[campo] = (_convertir(variable, texto, por_defecto[campo]), "entorno")
    for campo, valor in argumentos.items():
        _exigir(campo, por_defecto)
        if valor is not None:
            final[campo] = (valor, "argumentos")
    return final


r = configuracion(POR_DEFECTO, {"umbral": 3.0, "hilos": 8},
                  {"TELCO_UMBRAL": "2.5", "TELCO_ALERTAS": "si", "PATH": "C:/Windows"},
                  {"umbral": None, "periodo": "202610"})
for campo, (valor, origen) in r.items():
    print(f"{campo:8} = {valor!r:20} ← {origen}")
```

## Explicación

Guardar el **origen** de cada valor parece un lujo, pero es la herramienta de diagnóstico más útil de la configuración. La pregunta "¿por qué está usando umbral 2.5 si en el TOML puse 3?" se responde de inmediato: "porque `TELCO_UMBRAL` está definida en el entorno". Un comando `config mostrar` que imprima esta tabla (con los secretos ocultos) te ahorrará muchas horas; lo harás en el ejercicio 9.

La trampa de `bool` es clásica: `isinstance(True, int)` es verdadero, así que si preguntas primero por `int`, `"true"` intentaría convertirse con `int("true")` y fallaría. Y si alguien usara `bool(texto)`, `bool("false")` daría `True` (cualquier texto no vacío es verdadero). Por eso los booleanos desde texto necesitan una lista explícita de valores aceptados.

Los argumentos con `None` se ignoran porque así es como llegan de Typer o argparse las opciones que el usuario **no** escribió: no deben borrar lo que dijeron las otras capas.
