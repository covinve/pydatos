## Enunciado

Escribe el caso de uso **"suspender líneas morosas"**. Las reglas del negocio:

- Una factura está **vencida** si su estado es `PENDIENTE` y su `vencimiento` es **anterior** a hoy.
- Una línea se suspende si tiene **2 o más** facturas vencidas, **o** una sola vencida hace **más de 60 días**.
- Las líneas que ya están `SUSPENDIDA` no se vuelven a procesar.
- Cada suspensión se guarda en el repositorio y se notifica.

Lo que recibe el caso de uso (todo inyectado):

| Dependencia | Qué ofrece |
|---|---|
| `facturas` | `pendientes() -> list[Factura]` |
| `lineas` | `estado(linea) -> str` y `suspender(linea, motivo) -> None` |
| `notificador` | `enviar(asunto, mensaje) -> None` |
| `hoy` | una función sin argumentos que devuelve un `date` |

Implementa `Factura` (`dataclass(frozen=True)`: `factura_id`, `linea`, `vencimiento: date`, `total: int`, `estado: str`) y la clase `SuspenderMorosos(facturas, lineas, notificador, hoy)` con `ejecutar() -> list[str]`, que devuelve las líneas suspendidas **ordenadas**. El motivo es `"2 facturas vencidas"` (con la cantidad) o `"vencida hace 75 días"`. Envía **un solo** aviso al final con asunto `"Suspensiones"` si hubo alguna.

Las pruebas usan dobles en memoria que tú no tienes que escribir.

## Pruebas

```python
from datetime import date


class FacturasFalsas:
    def __init__(self, facturas):
        self.facturas = facturas

    def pendientes(self):
        return [f for f in self.facturas if f.estado == "PENDIENTE"]


class LineasFalsas:
    def __init__(self, suspendidas=()):
        self.estados = {l: "SUSPENDIDA" for l in suspendidas}
        self.suspensiones = []

    def estado(self, linea):
        return self.estados.get(linea, "ACTIVA")

    def suspender(self, linea, motivo):
        self.estados[linea] = "SUSPENDIDA"
        self.suspensiones.append((linea, motivo))


class Notificaciones:
    def __init__(self):
        self.enviados = []

    def enviar(self, asunto, mensaje):
        self.enviados.append((asunto, mensaje))


HOY = date(2026, 10, 17)
F = lambda i, linea, venc, estado="PENDIENTE": Factura(f"F{i}", linea, venc, 50000, estado)
FACTURAS = [
    F(1, "3001", date(2026, 9, 5)), F(2, "3001", date(2026, 10, 5)),            # 2 vencidas → suspender
    F(3, "3002", date(2026, 8, 3)),                                              # 1 vencida hace 75 días → suspender
    F(4, "3003", date(2026, 9, 20)),                                             # 1 vencida hace 27 días → no
    F(5, "3004", date(2026, 10, 17)), F(6, "3004", date(2026, 10, 30)),          # vence hoy / después → no
    F(7, "3005", date(2026, 7, 1)), F(8, "3005", date(2026, 8, 1)),              # ya suspendida → no
    F(9, "3006", date(2026, 5, 1), "PAGADA"), F(10, "3006", date(2026, 6, 1), "PAGADA"),   # pagadas → no
    F(11, "3007", date(2026, 8, 18)),                                            # hace 60 días exactos → no
]


def correr(facturas=FACTURAS, suspendidas=("3005",)):
    lineas, avisos = LineasFalsas(suspendidas), Notificaciones()
    r = SuspenderMorosos(FacturasFalsas(facturas), lineas, avisos, lambda: HOY).ejecutar()
    return r, lineas, avisos


def prueba_factura():
    """Factura es un objeto de valor"""
    requiere("Factura", "SuspenderMorosos")
    f = Factura("F1", "3001", date(2026, 9, 5), 50000, "PENDIENTE")
    lanza(Exception, setattr, f, "total", 1)


def prueba_suspende():
    """Suspende exactamente las líneas que cumplen la regla"""
    r, lineas, _ = correr()
    igual(r, ["3001", "3002"])
    igual(sorted(lineas.suspensiones), [("3001", "2 facturas vencidas"), ("3002", "vencida hace 75 días")])


def prueba_notifica_una_vez():
    """Un solo aviso con todas las líneas"""
    _, _, avisos = correr()
    igual(len(avisos.enviados), 1)
    asunto, mensaje = avisos.enviados[0]
    igual(asunto, "Suspensiones")
    assert "3001" in mensaje and "3002" in mensaje


def prueba_nada_que_hacer():
    """Sin morosos: nada se suspende ni se notifica"""
    r, lineas, avisos = correr(FACTURAS[3:6])
    igual((r, lineas.suspensiones, avisos.enviados), ([], [], []))


def prueba_usa_el_reloj():
    """La fecha viene de la dependencia hoy, no de date.today()"""
    lineas, avisos = LineasFalsas(), Notificaciones()
    r = SuspenderMorosos(FacturasFalsas(FACTURAS[3:4]), lineas, avisos, lambda: date(2026, 12, 1)).ejecutar()
    igual(r, ["3003"], "El 1 de diciembre la factura F4 lleva 72 días vencida")
    assert "today()" not in codigo, "No uses date.today(): usa la dependencia hoy"
```

## Pista 2

Para cada línea (en orden), si ya está suspendida, `continue`. Si tiene 2 o más, el motivo es `f"{len(lista)} facturas vencidas"`; si tiene una y `(hoy - factura.vencimiento).days > 60`, el motivo es `f"vencida hace {dias} días"`. Junta las líneas suspendidas y notifica al final, una vez.

## Solución

```python
from dataclasses import dataclass
from datetime import date


@dataclass(frozen=True)
class Factura:
    factura_id: str
    linea: str
    vencimiento: date
    total: int
    estado: str


class SuspenderMorosos:
    DIAS_MAXIMOS = 60

    def __init__(self, facturas, lineas, notificador, hoy):
        self.facturas = facturas
        self.lineas = lineas
        self.notificador = notificador
        self.hoy = hoy

    def _motivo(self, vencidas, hoy):
        if len(vencidas) >= 2:
            return f"{len(vencidas)} facturas vencidas"
        dias = (hoy - vencidas[0].vencimiento).days
        if dias > self.DIAS_MAXIMOS:
            return f"vencida hace {dias} días"
        return None

    def ejecutar(self):
        hoy = self.hoy()
        vencidas = {}
        for f in self.facturas.pendientes():
            if f.vencimiento < hoy:
                vencidas.setdefault(f.linea, []).append(f)
        suspendidas = []
        for linea in sorted(vencidas):
            if self.lineas.estado(linea) == "SUSPENDIDA":
                continue
            motivo = self._motivo(vencidas[linea], hoy)
            if motivo:
                self.lineas.suspender(linea, motivo)
                suspendidas.append(linea)
        if suspendidas:
            self.notificador.enviar("Suspensiones", f"{len(suspendidas)} líneas suspendidas: {', '.join(suspendidas)}")
        return suspendidas
```

## Explicación

Este caso de uso toca **cuatro** sistemas (facturas, líneas, notificaciones y el reloj) y se probó sin ninguno: ni base de datos, ni correo, ni esperar a que pasen 60 días. Por eso la inyección de dependencias se nota tanto en las pruebas: los dobles permiten construir el escenario exacto (la factura vencida hace exactamente 60 días, la línea ya suspendida) en tres líneas.

El **reloj inyectado** (`hoy`) merece atención. `date.today()` dentro del caso de uso haría que la prueba pase hoy y falle la semana que viene. Cualquier lógica que dependa de "ahora" debería recibir el tiempo de afuera.

La regla de negocio quedó en dos lugares claros: `DIAS_MAXIMOS` y `_motivo`. Si la política cambia a 45 días, o a "3 facturas", sabes qué tocar y qué prueba actualizar.
