## Enunciado

Tu validador del módulo 3 clasificó cada CDR de un archivo. Ahora recibes la lista de clasificaciones (por ejemplo `["valido", "duplicado", "valido", "fecha_invalida", ...]`) y debes preparar el reporte:

1. `contar_clasificaciones(clasificaciones)` → diccionario `{clasificación: cantidad}` con **todas** las clasificaciones que aparecen.
2. `resumen_errores(clasificaciones)` → **lista de tuplas** `(error, cantidad)` **sin** `"valido"`, ordenada de mayor a menor cantidad; ante un empate, por nombre alfabético.
3. `porcentaje_validos(clasificaciones)` → porcentaje de `"valido"` redondeado a 2 decimales (`0.0` si la lista está vacía).
4. `reporte(clasificaciones)` → texto con este formato (una línea por error, cantidades con punto de miles):

```text
Registros: 10.000 · Válidos: 99.17 %
  duplicado               45
  fecha_invalida          20
  linea_desconocida       18
```

El nombre del error ocupa 20 caracteres alineado a la izquierda, y la cantidad 6 alineada a la derecha.

## Pruebas

EJ = ["valido"] * 9917 + ["duplicado"] * 45 + ["fecha_invalida"] * 20 + ["linea_desconocida"] * 18


def prueba_contar():
    """Cuenta todas las clasificaciones"""

    igual(contar_clasificaciones(["valido", "duplicado", "valido"]), {"valido": 2, "duplicado": 1})

## Pista 1

Para contar, `collections.Counter` hace todo el trabajo, pero devuelve un `Counter`; conviértelo con `dict(...)`. Para el resumen, crea la lista de tuplas sin `"valido"` y ordénala con `sorted` y una `key`.

## Pista 2

Para ordenar de mayor a menor cantidad y, en empate, por nombre ascendente, usa una clave que devuelva una tupla con la cantidad **negativa**:

```python
sorted(pares, key=lambda par: (-par[1], par[0]))
```

En el reporte, el formato de cada línea es `f"  {error:<20}{cantidad:>6}"`. Une las líneas con `"\n".join(lineas)`.

## Solución

```python
from collections import Counter


def contar_clasificaciones(clasificaciones):
    return dict(Counter(clasificaciones))


def resumen_errores(clasificaciones):
    conteo = contar_clasificaciones(clasificaciones)
    errores = [(nombre, cantidad) for nombre, cantidad in conteo.items() if nombre != "valido"]
    return sorted(errores, key=lambda par: (-par[1], par[0]))


def porcentaje_validos(clasificaciones):
    if not clasificaciones:
        return 0.0
    validos = clasificaciones.count("valido")
    return round(validos / len(clasificaciones) * 100, 2)


def con_miles(numero):
    return f"{numero:,}".replace(",", ".")


def reporte(clasificaciones):
    lineas = [f"Registros: {con_miles(len(clasificaciones))} · Válidos: {porcentaje_validos(clasificaciones)} %"]
    for error, cantidad in resumen_errores(clasificaciones):
        lineas.append(f"  {error:<20}{con_miles(cantidad):>6}")
    return "\n".join(lineas)


ejemplo = ["valido"] * 9917 + ["duplicado"] * 45 + ["fecha_invalida"] * 20 + ["linea_desconocida"] * 18
print(reporte(ejemplo))
```

## Explicación

- **`Counter`** es el atajo para el patrón contar. Sigue siendo un diccionario, con extras como `most_common()`.
- **Ordenar por varios criterios** con una tupla en `key`: Python compara tuplas elemento por elemento. Negar la cantidad (`-par[1]`) invierte ese criterio sin afectar el segundo (`par[0]`, ascendente).
- **`"\n".join(lineas)`** es la forma eficiente de unir muchas líneas: construir el texto con `+=` dentro de un bucle es más lento y menos claro.

Este reporte es exactamente lo que imprimirá tu **Proyecto 1** al terminar de validar un archivo.
