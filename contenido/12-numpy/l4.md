## dtype: el tipo de cada elemento

| dtype | Rango | Bytes | Ejemplo telco |
|---|---|---|---|
| `int8` | −128 a 127 | 1 | Hora del día (0–23) |
| `int16` | −32.768 a 32.767 | 2 | Día del año |
| `int32` | ±2.100 millones | 4 | Duración en segundos |
| `int64` | ±9,2 × 10¹⁸ | 8 | Totales en pesos, `cdr_id` |
| `float32` | ~7 dígitos de precisión | 4 | Megas de una sesión |
| `float64` | ~15 dígitos | 8 | Sumas de megas, estadísticas |
| `bool` | Verdadero/falso | 1 | Máscaras |

```pyrun
import numpy as np

n = 10_000_000
horas_64 = np.zeros(n, dtype=np.int64)
horas_8 = np.zeros(n, dtype=np.int8)
print(f"int64: {horas_64.nbytes / 1e6:.0f} MB")
print(f"int8:  {horas_8.nbytes / 1e6:.0f} MB")
```

Con 280 millones de registros, elegir `int8` para la hora en lugar de `int64` ahorra casi 2 GB.

## El peligro: desbordamiento

Los enteros de NumPy tienen **tamaño fijo**. Si un resultado no cabe, **da la vuelta en silencio**:

```pyrun
import numpy as np

duraciones = np.array([30_000, 10_000], dtype=np.int16)
print(duraciones.sum())                 # NumPy agranda el tipo al sumar: correcto
print(duraciones + duraciones)          # aquí no: 60.000 no cabe en int16 → número negativo
print((duraciones.astype(np.int64) + duraciones).dtype)
```

:::error Guardar pequeño, calcular grande
Guarda con el tipo más pequeño que alcance, pero **convierte a `int64` o `float64` antes de multiplicar o sumar** valores que pueden crecer (pesos, totales). Un desbordamiento no da error: da un número equivocado.
:::

:::reto Guardar pequeño, calcular grande
Los minutos y las tarifas se guardaron en `int16` para ahorrar memoria, pero al multiplicarlos el resultado se desborda: fíjate en los valores negativos que imprime. Corrige el cálculo de `valores` para que sea exacto, sin cambiar cómo están guardados `minutos` y `tarifas`.

```pyreto
import numpy as np

minutos = np.array([300, 250, 400], dtype=np.int16)
tarifas = np.array([120, 120, 950], dtype=np.int16)

valores = minutos * tarifas
print(valores, valores.dtype)
```

:::pista
Convierte uno de los dos a `int64` antes de multiplicar: `minutos.astype(np.int64) * tarifas`. NumPy usará el tipo más grande para el resultado.
:::

```pyprueba
import numpy as np


def prueba_valores():
    """valores = [36000, 30000, 380000]"""
    requiere("valores")
    igual([int(v) for v in valores], [36000, 30000, 380000])


def prueba_guardados_igual():
    """minutos y tarifas siguen en int16"""
    igual(str(minutos.dtype), "int16", "minutos.dtype")
    igual(str(tarifas.dtype), "int16", "tarifas.dtype")
```

```pysolucion
import numpy as np

minutos = np.array([300, 250, 400], dtype=np.int16)
tarifas = np.array([120, 120, 950], dtype=np.int16)

valores = minutos.astype(np.int64) * tarifas
print(valores, valores.dtype)
```
:::

## float y dinero

Igual que en Python, los `float` de NumPy tienen errores de representación. Para dinero, la estrategia con arrays es **trabajar en pesos enteros (`int64`)** y redondear explícitamente donde la regla lo diga:

```pyrun
import numpy as np

subtotales = np.array([150, 40940, 20150], dtype=np.int64)
iva_banquero = np.round(subtotales * 0.19)              # redondeo del banquero
iva_comercial = np.floor(subtotales * 0.19 + 0.5)       # 0,5 sube
print(iva_banquero)
print(iva_comercial.astype(np.int64))
```

`np.floor(x + 0.5)` implementa "0,5 sube" para valores positivos (es lo que usa el generador de datos del curso).

:::reto El IVA de todas las facturas
Para el array de subtotales (en pesos enteros):

- `iva`: el 19 % redondeado con la regla comercial, como `int64`;
- `total`: subtotal más IVA, también `int64`;
- `diferencia`: cuántos pesos más se cobran en total con la regla comercial que con `np.round` (el redondeo del banquero).

```pyreto
import numpy as np

subtotales = np.array([150, 40940, 20150, 5, 2850], dtype=np.int64)

# iva, total y diferencia

print(iva, total, diferencia)
```

:::pista
`iva = np.floor(subtotales * 0.19 + 0.5).astype(np.int64)`. Para la diferencia, compara contra `np.round(subtotales * 0.19)` y suma: `int((iva - banquero).sum())`.
:::

```pyprueba
import numpy as np


def prueba_iva():
    """iva con la regla comercial, en int64"""
    requiere("iva")
    igual([int(x) for x in iva], [29, 7779, 3829, 1, 542])
    assert np.issubdtype(iva.dtype, np.integer), f"iva debe ser entero, es {iva.dtype}"


def prueba_total():
    """total = subtotal + iva"""
    requiere("total")
    igual([int(x) for x in total], [179, 48719, 23979, 6, 3392])


def prueba_diferencia():
    """diferencia = 2"""
    requiere("diferencia")
    igual(int(diferencia), 2)
```

```pysolucion
import numpy as np

subtotales = np.array([150, 40940, 20150, 5, 2850], dtype=np.int64)

iva = np.floor(subtotales * 0.19 + 0.5).astype(np.int64)
total = subtotales + iva
banquero = np.round(subtotales * 0.19)
diferencia = int((iva - banquero).sum())

print(iva, total, diferencia)
```
:::

## NaN: el dato faltante

`np.nan` representa un valor faltante en arrays de `float`. Contagia todo lo que toca:

```pyrun
import numpy as np

mb = np.array([15.1, np.nan, 7.2])
print(mb.sum())                 # nan
print(np.nansum(mb))            # ignora los nan
print(np.isnan(mb))
print(np.nan == np.nan)         # ¡False! usa np.isnan
```

:::reto Megas con huecos
Algunas sesiones llegaron sin el dato de megas (`np.nan`). Calcula:

- `total_mb`: el total de megas, ignorando los faltantes;
- `faltantes`: cuántas sesiones no tienen dato;
- `completas`: el array de megas solo con las sesiones que sí tienen dato.

```pyreto
import numpy as np

mb = np.array([15.1, np.nan, 7.2, np.nan, 230.5])

# total_mb, faltantes y completas

print(total_mb, faltantes, completas)
```

:::pista
`np.nansum(mb)` ignora los `nan`. `np.isnan(mb)` es una máscara: súmala para contar, y usa `~` para quedarte con los que sí tienen dato.
:::

```pyprueba
def prueba_total():
    """total_mb = 252.8"""
    requiere("total_mb")
    cerca(float(total_mb), 252.8)


def prueba_faltantes():
    """faltantes = 2 y completas sin nan"""
    requiere("faltantes", "completas")
    igual(int(faltantes), 2, "faltantes")
    igual([float(x) for x in completas], [15.1, 7.2, 230.5], "completas")


def prueba_isnan():
    """Usa np.isnan (nan == nan es falso)"""
    assert "isnan(" in codigo, "Detecta los faltantes con np.isnan"
```

```pysolucion
import numpy as np

mb = np.array([15.1, np.nan, 7.2, np.nan, 230.5])

total_mb = np.nansum(mb)
faltantes = np.isnan(mb).sum()
completas = mb[~np.isnan(mb)]

print(total_mb, faltantes, completas)
```
:::

## Archivos más grandes que la memoria: memmap

`np.memmap` mapea un archivo binario a un array **sin cargarlo**: el sistema operativo lee del disco solo las partes que usas. Funciona muy bien con archivos de **ancho fijo**, donde cada registro mide lo mismo:

```python
import numpy as np

bytes_ = np.memmap("datos/1GB/cdr_ancho_fijo.txt", dtype=np.uint8, mode="r")
registros = bytes_.reshape(-1, 92)          # 91 caracteres + salto de línea
tipos = registros[:, 35:40]                  # columna de tipo, sin leer el resto
```

Lo usarás en el ejercicio 9 para leer 1 GB a velocidad de NumPy.

## Números aleatorios reproducibles

Para simulaciones (¿qué pasaría si cambiamos el plan?) usa un **generador con semilla**: así los resultados se pueden repetir.

```pyrun
import numpy as np

rng = np.random.default_rng(2026)
minutos = rng.poisson(lam=320, size=10)          # minutos de 10 clientes simulados
print(minutos)
print((minutos > 300).mean())                    # proporción que excedería un plan de 300

rng = np.random.default_rng(2026)
print(rng.poisson(lam=320, size=10))             # misma semilla → mismos números
```

| Función | Distribución | Uso típico |
|---|---|---|
| `rng.integers(a, b, n)` | Enteros uniformes | Horas, celdas |
| `rng.poisson(lam, n)` | Conteos | Llamadas o SMS por mes |
| `rng.lognormal(mu, sigma, n)` | Asimétrica, de cola larga | Duraciones, megas |
| `rng.normal(media, desv, n)` | Normal | Errores de medición |
| `rng.choice(opciones, n, p=...)` | Categórica | Tipo de CDR, destino |

:::reto ¿A cuántos clientes les queda corto el plan?
Simula el consumo de 1.000 clientes con un generador de semilla `7`: sus minutos del mes siguen una distribución de Poisson con promedio 320.

- `minutos`: el array simulado;
- `pct_exceden`: la proporción de clientes que pasaría de los 300 minutos del plan;
- `exceso_promedio`: el exceso promedio en minutos **solo entre los que exceden**, redondeado a 1 decimal.

```pyreto
import numpy as np

# Crea el generador con semilla 7 y simula

print(pct_exceden, exceso_promedio)
```

:::pista
`rng = np.random.default_rng(7)` y `minutos = rng.poisson(lam=320, size=1000)`. La proporción es el `.mean()` de la máscara `minutos > 300`; el exceso promedio, `(minutos[minutos > 300] - 300).mean()`.
:::

```pyprueba
import numpy as np


def _esperado():
    m = np.random.default_rng(7).poisson(lam=320, size=1000)
    return m, (m > 300).mean(), round(float((m[m > 300] - 300).mean()), 1)


def prueba_simulacion():
    """minutos usa la semilla 7 (es reproducible)"""
    requiere("minutos")
    igual([int(x) for x in minutos], [int(x) for x in _esperado()[0]])


def prueba_resultados():
    """pct_exceden y exceso_promedio"""
    requiere("pct_exceden", "exceso_promedio")
    _, pct, exceso = _esperado()
    cerca(float(pct_exceden), float(pct), 1e-9, "pct_exceden")
    cerca(float(exceso_promedio), exceso, 0.05, "exceso_promedio")
```

```pysolucion
import numpy as np

rng = np.random.default_rng(7)
minutos = rng.poisson(lam=320, size=1000)

pct_exceden = (minutos > 300).mean()
exceso_promedio = round(float((minutos[minutos > 300] - 300).mean()), 1)

print(pct_exceden, exceso_promedio)
```
