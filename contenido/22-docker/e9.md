
```python esperar_servicio.py
"""Ejercicio m22-e9: esperar a que un servicio acepte conexiones y luego ejecutar un comando.

Uso:
    python esperar_servicio.py bd:5432 --timeout 60 -- python -m app.cargar
"""

from __future__ import annotations

import argparse
import socket
import subprocess
import sys
import time
from collections.abc import Callable


def destino(texto: str) -> tuple[str, int]:
    host, separador, puerto = texto.rpartition(":")
    if not separador or not host or not puerto.isdigit() or not 1 <= int(puerto) <= 65535:
        raise ValueError(f"Destino inválido {texto!r}: usa servidor:puerto, como bd:5432")
    return host, int(puerto)


def esperar(host: str, puerto: int, timeout: float = 30.0, intervalo: float = 0.5,
            reloj: Callable[[], float] = time.monotonic, dormir: Callable[[float], None] = time.sleep) -> float:
    inicio = reloj()
    while True:
        try:
            with socket.create_connection((host, puerto), timeout=intervalo):
                return reloj() - inicio
        except OSError:
            if reloj() - inicio >= timeout:
                raise TimeoutError(f"{host}:{puerto} no respondió en {timeout} s") from None
            dormir(intervalo)


def main(argv: list[str] | None = None) -> int:
    argv = sys.argv[1:] if argv is None else list(argv)
    comando = argv[argv.index("--") + 1:] if "--" in argv else []
    propios = argv[:argv.index("--")] if "--" in argv else argv
    parser = argparse.ArgumentParser(description="Espera un servicio y ejecuta un comando.")
    parser.add_argument("destino", type=destino, help="servidor:puerto")
    parser.add_argument("--timeout", type=float, default=30.0)
    args = parser.parse_args(propios)
    host, puerto = args.destino
    try:
        segundos = esperar(host, puerto, timeout=args.timeout)
    except TimeoutError as error:
        print(error, file=sys.stderr)
        return 1
    print(f"{host}:{puerto} disponible en {segundos:.1f} s", flush=True)
    if not comando:
        return 0
    return subprocess.run(comando).returncode


if __name__ == "__main__":
    sys.exit(main())
```

## Explicación

**El devcontainer** convierte la configuración de tu entorno en un archivo del repositorio. En Codespaces, cualquier persona (o tú mismo desde la oficina, en el navegador) obtiene en un minuto: Python 3.12, todas las librerías del curso, las extensiones de VS Code y Docker funcionando, sin instalar nada en el computador. Recuerda la regla: en un servicio externo, solo los **datos generados** del curso, nunca datos reales de la empresa.

**`esperar_servicio.py`** resuelve el problema de "arrancado no es listo" de forma general: funciona para PostgreSQL, una API o cualquier cosa que escuche en un puerto, y su código de salida es el del comando que lanza, así que el contenedor termina con el resultado real del proceso. Tres decisiones lo hacen confiable:

- `rpartition(":")` separa en el **último** `:`, el correcto para `host:puerto`.
- El *timeout* cuenta tiempo **total**, no intentos: con una red lenta, cada intento tarda distinto.
- `reloj` y `dormir` inyectados (como en los módulos 18 y 19) permiten probar el caso del *timeout* en milisegundos, en lugar de esperar 30 segundos de verdad.

Una conexión TCP exitosa significa que el proceso escucha, no necesariamente que esté listo para trabajar (PostgreSQL acepta conexiones un instante antes de aceptar consultas). Por eso, en Compose, `pg_isready` en el `healthcheck` sigue siendo la mejor señal, y esta utilidad es el complemento para servicios que no tienen *healthcheck*.
