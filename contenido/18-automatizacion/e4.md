## Enunciado

En el navegador no hay acceso a una API real, así que la preparación crea `api_falsa.py` con `ClienteFalso`, que se comporta como una `requests.Session`: `cliente.get(url, params=..., timeout=...)` devuelve una respuesta con `.status_code`, `.json()` y `.raise_for_status()`.

La API de facturas pagina **por cursor**: la respuesta tiene `{"datos": [...], "siguiente": "cursor" o None}` y la siguiente página se pide con `params={"cursor": ..., "limite": ...}`.

Escribe el generador `facturas(cliente, periodo, limite=100)`:

1. Pide `URL` con `params` `{"periodo": periodo, "limite": limite}` (y `"cursor"` desde la segunda página), siempre con `timeout=10`.
2. Llama `raise_for_status()` en cada respuesta.
3. Entrega (`yield`) las facturas **una a una**, sin juntar todas en una lista.
4. Termina cuando `siguiente` sea `None`.

Y `total_por_estado(cliente, periodo)` → `{estado_pago: suma_de_total}` ordenado por estado, usando el generador.

## Preparación

```python
from pathlib import Path

Path("api_falsa.py").write_text('''
import math


class ErrorHTTP(Exception):
    pass


class Respuesta:
    def __init__(self, estado, cuerpo):
        self.status_code = estado
        self._cuerpo = cuerpo

    def json(self):
        return self._cuerpo

    def raise_for_status(self):
        if self.status_code >= 400:
            raise ErrorHTTP(f"{self.status_code}: {self._cuerpo}")


class ClienteFalso:
    """Simula la API: 237 facturas por periodo, paginadas por cursor."""

    def __init__(self, total=237, fallar_en=None):
        self.total = total
        self.fallar_en = fallar_en
        self.peticiones = []

    def get(self, url, params=None, timeout=None):
        params = params if params is not None else {}
        self.peticiones.append((url, params, timeout))
        if timeout is None:
            raise RuntimeError("Sin timeout tu programa podría quedar colgado")
        if len(self.peticiones) > 100:
            raise RuntimeError("Demasiadas peticiones: ¿un ciclo infinito?")
        if self.fallar_en == len(self.peticiones):
            return Respuesta(503, {"error": "servicio no disponible"})
        if url != "https://api.telco.example/v1/facturas" or "periodo" not in params:
            return Respuesta(400, {"error": "petición inválida"})
        limite = int(params.get("limite", 50))
        inicio = int(params.get("cursor", "c0")[1:])
        total = self.total if params["periodo"] == "202609" else 0
        datos = [
            {"factura_id": f"F{params['periodo']}{i:05d}", "total": 50_000 + (i * 7919) % 100_000,
             "estado_pago": ["PAGADA", "PENDIENTE", "VENCIDA"][i % 3]}
            for i in range(inicio, min(inicio + limite, total))
        ]
        siguiente = f"c{inicio + limite}" if inicio + limite < total else None
        return Respuesta(200, {"datos": datos, "siguiente": siguiente})
''', encoding="utf-8")
```

## Pista 2

Después de entregar los datos de una página, mira `cuerpo["siguiente"]`: si es `None`, `return` (o `break`); si no, agrégalo a `params["cursor"]`. Ojo: crea un diccionario nuevo de parámetros en cada vuelta (`{**params, "cursor": siguiente}`), así no modificas uno que el cliente pudo haber guardado.

## Solución

```python
from api_falsa import ClienteFalso

URL = "https://api.telco.example/v1/facturas"


def facturas(cliente, periodo, limite=100):
    params = {"periodo": periodo, "limite": limite}
    while True:
        respuesta = cliente.get(URL, params=params, timeout=10)
        respuesta.raise_for_status()
        cuerpo = respuesta.json()
        yield from cuerpo["datos"]
        siguiente = cuerpo.get("siguiente")
        if siguiente is None:
            return
        params = {**params, "cursor": siguiente}


def total_por_estado(cliente, periodo):
    totales = {}
    for f in facturas(cliente, periodo):
        totales[f["estado_pago"]] = totales.get(f["estado_pago"], 0) + f["total"]
    return dict(sorted(totales.items()))


cliente = ClienteFalso()
print(sum(1 for _ in facturas(cliente, "202609")), "facturas en", len(cliente.peticiones), "peticiones")
print(total_por_estado(ClienteFalso(), "202609"))
```

## Explicación

El generador **esconde la paginación**: quien lo usa recorre facturas como si fueran una lista, y las páginas se piden solo a medida que se necesitan. Si el análisis se detiene en la factura 15, nunca se piden las demás páginas. Y la memoria es constante: con un millón de facturas, en memoria solo hay una página.

La prueba de parámetros revela un error sutil: si modificas `params["cursor"] = ...` sobre el **mismo** diccionario, cualquier objeto que lo haya guardado (como el `ClienteFalso`, o la caché de una librería) verá el cambio "en el pasado". Crear un diccionario nuevo en cada vuelta evita esa sorpresa (es el aliasing del módulo 4).

Con `requests` de verdad, el código es idéntico: `cliente = requests.Session()`. Así se prueba código de APIs en el mundo real: con un **doble** que simula el servidor (lo verás a fondo con `unittest.mock` en el módulo 20).
