## Enunciado

Vas a escribir las consultas de una pequeña herramienta de atención al cliente, donde el asesor **escribe** la línea o el nombre que busca. Las pruebas crean una base de datos con las tablas `cdr` y `clientes` (columnas iguales a los CSV) y le pasan la conexión a tus funciones.

1. `consumo_linea(con, linea)` → diccionario con `llamadas` (CDR de `VOZ` con duración ≥ 0), `minutos` (minutos facturables de esas llamadas: `(duracion_seg + 59) / 60` en SQL hace división entera) y `sms` (CDR de `SMS`) de esa línea. Si la línea no existe, todo en 0.
2. `buscar_clientes(con, texto)` → lista de tuplas `(linea, nombre)` de los clientes cuyo nombre **contiene** `texto` (sin distinguir mayúsculas), ordenada por nombre.

Las dos con **parámetros**: las pruebas intentarán atacarlas con inyección SQL.

## Pruebas

```python
import ast
import sqlite3

import pandas as pd

CDR = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
CLI = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})


def base():
    con = sqlite3.connect(":memory:")
    CDR.to_sql("cdr", con, index=False)
    CLI.to_sql("clientes", con, index=False)
    return con


def prueba_consumo():
    """Calcula el consumo de una línea"""
    requiere("consumo_linea")
    con = base()
    linea = CLI["linea"].iloc[3]
    d = CDR[CDR["linea_origen"] == linea]
    voz = d[(d["tipo"] == "VOZ") & (d["duracion_seg"] >= 0)]
    r = consumo_linea(con, linea)
    igual(r, {"llamadas": len(voz), "minutos": int(((voz["duracion_seg"] + 59) // 60).sum()),
              "sms": int((d["tipo"] == "SMS").sum())})
    igual(consumo_linea(con, "3000000000"), {"llamadas": 0, "minutos": 0, "sms": 0})


def prueba_inyeccion_consumo():
    """No se deja engañar por una línea maliciosa"""
    con = base()
    igual(consumo_linea(con, "x' OR '1'='1"), {"llamadas": 0, "minutos": 0, "sms": 0})


def prueba_buscar():
    """Busca por nombre sin distinguir mayúsculas"""
    requiere("buscar_clientes")
    con = base()
    esperado = CLI[CLI["nombre"].str.lower().str.contains("ez")].sort_values("nombre")
    igual(buscar_clientes(con, "EZ"), list(zip(esperado["linea"], esperado["nombre"])))


def prueba_inyeccion_busqueda():
    """Resiste la inyección en la búsqueda"""
    con = base()
    igual(buscar_clientes(con, "zzz' OR 1=1 --"), [])
    igual(buscar_clientes(con, "zzz') UNION SELECT name, sql FROM sqlite_master --"), [])
    con.execute("SELECT COUNT(*) FROM cdr")      # la tabla sigue viva


def prueba_sin_fstrings():
    """No arma SQL pegando texto"""
    for nodo in ast.walk(ast.parse(codigo)):
        if isinstance(nodo, ast.Call) and getattr(nodo.func, "attr", "") == "execute":
            primero = nodo.args[0] if nodo.args else None
            assert not isinstance(primero, (ast.JoinedStr, ast.BinOp)), "El SQL no debe armarse con f-strings ni +"
```

## Pista 1

Una sola consulta puede contar varias cosas a la vez con `SUM(CASE ...)`:

```sql
SELECT SUM(CASE WHEN tipo = 'VOZ' AND duracion_seg >= 0 THEN 1 ELSE 0 END),
       ...
FROM cdr WHERE linea_origen = ?
```

Si la línea no tiene CDR, `SUM` devuelve `NULL` (`None` en Python): usa `COALESCE(SUM(...), 0)` o `or 0`.

## Pista 2

En `LIKE`, el patrón `%texto%` significa "contiene". El `%` también va en el **parámetro**, no en el SQL:

```python
con.execute("SELECT linea, nombre FROM clientes WHERE lower(nombre) LIKE lower(?) ORDER BY nombre", (f"%{texto}%",))
```

Usar f-string para armar el **valor** del parámetro está bien; lo peligroso es pegarlo en el texto del SQL.

## Solución

```python
import sqlite3


def consumo_linea(con, linea):
    llamadas, minutos, sms = con.execute("""
        SELECT COALESCE(SUM(CASE WHEN tipo = 'VOZ' AND duracion_seg >= 0 THEN 1 ELSE 0 END), 0),
               COALESCE(SUM(CASE WHEN tipo = 'VOZ' AND duracion_seg >= 0 THEN (duracion_seg + 59) / 60 ELSE 0 END), 0),
               COALESCE(SUM(CASE WHEN tipo = 'SMS' THEN 1 ELSE 0 END), 0)
        FROM cdr
        WHERE linea_origen = ?
    """, (linea,)).fetchone()
    return {"llamadas": llamadas, "minutos": minutos, "sms": sms}


def buscar_clientes(con, texto):
    return con.execute(
        "SELECT linea, nombre FROM clientes WHERE lower(nombre) LIKE lower(?) ORDER BY nombre",
        (f"%{texto}%",),
    ).fetchall()
```

## Explicación

Las pruebas intentaron dos ataques clásicos: `' OR 1=1 --` (convertir el filtro en "siempre verdadero" y comentar el resto) y `UNION SELECT ... FROM sqlite_master` (pegar al resultado la lista de tablas de la base, el primer paso para robar datos). Con parámetros, el texto completo se busca **literalmente** como nombre, así que no encuentra nada.

Un detalle: `lower()` de SQLite solo convierte letras sin tilde (A–Z). Para buscar "ÁLVAREZ" con "álvarez" tendrías que normalizar el texto antes de guardarlo (por ejemplo, sin tildes, como en el módulo 6) o registrar una función de Python con `con.create_function`.
