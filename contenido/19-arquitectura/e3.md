## Enunciado

Cuando la validación diaria tiene muchos rechazos hay que avisar. Hoy por archivo, mañana por correo o por Teams. El caso de uso **no debe saber** cómo se envía.

1. Define el protocolo `Notificador` con un método `enviar(asunto: str, mensaje: str) -> None`.
2. Implementa dos adaptadores:
   - `NotificadorMemoria`: guarda cada envío como tupla `(asunto, mensaje)` en su lista `enviados`.
   - `NotificadorArchivo(ruta)`: **agrega** al archivo (utf-8) una línea `"[asunto] mensaje"` por envío.
3. Escribe el caso de uso `revisar_validacion(resumen, notificador, umbral=5.0)`:
   - `resumen` tiene `registros_totales`, `registros_validos` y `errores` (diccionario).
   - Si el porcentaje de rechazos **supera** `umbral`, envía **una** alerta con asunto `"ALERTA validación"` y un mensaje que incluya el porcentaje con 2 decimales y el error más frecuente (`"... 7.43 % rechazados ... principal: duplicado (64)"`), y devuelve `True`.
   - Si no, no envía nada y devuelve `False`. Con 0 registros, tampoco envía (y devuelve `False`).

## Pruebas

```python
from pathlib import Path

R = {"registros_totales": 4064, "registros_validos": 3933,
     "errores": {"duplicado": 64, "duracion_negativa": 5, "fecha_invalida": 19,
                 "linea_vacia": 15, "linea_desconocida": 17, "tipo_desconocido": 11}}


def prueba_memoria():
    """Guarda los envíos"""
    requiere("NotificadorMemoria")
    n = NotificadorMemoria()
    n.enviar("a", "b")
    n.enviar("c", "d")
    igual(n.enviados, [("a", "b"), ("c", "d")])
    igual(NotificadorMemoria().enviados, [], "Cada instancia tiene su propia lista")


def prueba_archivo():
    """Agrega líneas al archivo"""
    requiere("NotificadorArchivo")
    ruta = Path("alertas_prueba.log")
    ruta.unlink(missing_ok=True)
    NotificadorArchivo(ruta).enviar("Uno", "primero")
    NotificadorArchivo(ruta).enviar("Dos", "segundo con tildes: línea")
    igual(ruta.read_text(encoding="utf-8").splitlines(), ["[Uno] primero", "[Dos] segundo con tildes: línea"])


def prueba_alerta():
    """Alerta cuando supera el umbral"""
    requiere("revisar_validacion")
    n = NotificadorMemoria()
    igual(revisar_validacion(R, n, umbral=2), True)
    igual(len(n.enviados), 1)
    asunto, mensaje = n.enviados[0]
    igual(asunto, "ALERTA validación")
    assert "3.22 %" in mensaje, f"El porcentaje con 2 decimales (3.22 %): {mensaje}"
    assert "duplicado (64)" in mensaje, "Incluye el error principal y su cantidad"


def prueba_sin_alerta():
    """No alerta bajo el umbral ni sin registros"""
    n = NotificadorMemoria()
    igual(revisar_validacion(R, n), False)
    igual(revisar_validacion(R, n, umbral=3.23), False)
    igual(revisar_validacion({"registros_totales": 100, "registros_validos": 95, "errores": {"duplicado": 5}}, n, umbral=5), False, "Igual al umbral no lo supera")

    igual(n.enviados, [])


def prueba_cualquier_notificador():
    """Funciona con cualquier objeto que tenga enviar()"""
    class Contador:
        veces = 0

        def enviar(self, asunto, mensaje):
            self.veces += 1

    c = Contador()
    revisar_validacion(R, c, umbral=1)
    igual(c.veces, 1)
```

## Pista 1

Un `Protocol` solo declara la firma:

```python
class Notificador(Protocol):
    def enviar(self, asunto: str, mensaje: str) -> None: ...
```

Los adaptadores **no** heredan de él; basta con que tengan el método.

## Pista 2

El porcentaje y el error principal:

```python
rechazos = total - validos
porcentaje = rechazos / total * 100
error, cantidad = max(resumen["errores"].items(), key=lambda par: par[1])
```

Para agregar al archivo: `open(ruta, "a", encoding="utf-8")`.

## Solución

```python
from pathlib import Path
from typing import Protocol


class Notificador(Protocol):
    def enviar(self, asunto: str, mensaje: str) -> None: ...


class NotificadorMemoria:
    def __init__(self):
        self.enviados = []

    def enviar(self, asunto, mensaje):
        self.enviados.append((asunto, mensaje))


class NotificadorArchivo:
    def __init__(self, ruta):
        self.ruta = Path(ruta)

    def enviar(self, asunto, mensaje):
        with open(self.ruta, "a", encoding="utf-8") as f:
            f.write(f"[{asunto}] {mensaje}\n")


def revisar_validacion(resumen, notificador: Notificador, umbral=5.0):
    total = resumen["registros_totales"]
    if total == 0:
        return False
    porcentaje = (total - resumen["registros_validos"]) / total * 100
    if porcentaje <= umbral:
        return False
    error, cantidad = max(resumen["errores"].items(), key=lambda par: par[1])
    notificador.enviar(
        "ALERTA validación",
        f"{porcentaje:.2f} % rechazados (umbral {umbral} %); principal: {error} ({cantidad})",
    )
    return True


resumen = {"registros_totales": 4064, "registros_validos": 3933,
           "errores": {"duplicado": 64, "duracion_negativa": 5, "fecha_invalida": 19,
                       "linea_vacia": 15, "linea_desconocida": 17, "tipo_desconocido": 11}}
n = NotificadorMemoria()
print(revisar_validacion(resumen, n, umbral=2))
print(n.enviados)
```

## Explicación

La última prueba lo demuestra: `revisar_validacion` funcionó con una clase `Contador` que se escribió **en la prueba** y que no sabe nada de `Notificador`. Eso es el *duck typing* con contrato: el `Protocol` documenta (y mypy verifica) qué se necesita, sin obligar a heredar.

Agregar un `NotificadorTeams` mañana es escribir una clase nueva con `enviar` (que haga un POST al *webhook* de Teams con `requests`), y crearla en la raíz de composición. `revisar_validacion` y sus pruebas no cambian: principio abierto/cerrado.

Y fíjate en qué se prueba con `NotificadorMemoria`: la **decisión** (¿se alerta o no?, ¿con qué mensaje?), que es lo importante, sin enviar correos reales cada vez que corres las pruebas.
