## Enunciado

Reescribe la factura del módulo 4 con objetos. Ya tienes las dataclasses `Cliente`, `Plan` y `Consumo` en el código inicial. Crea:

1. `Concepto` (dataclass inmutable): `descripcion: str`, `valor: int`.
2. `Factura` (dataclass) **compuesta** por: `cliente: Cliente`, `plan: Plan`, `conceptos: list[Concepto]` (lista nueva por defecto). Con:
   - propiedades `subtotal` (suma de los conceptos), `iva` (19 % redondeado al peso, 0,5 sube) y `total`;
   - el constructor alternativo `Factura.calcular(cliente, plan, consumo)` que arma los conceptos **en este orden**, incluyendo **solo los distintos de cero** (excepto el cargo fijo, que siempre va):

| Concepto | Descripción exacta |
|---|---|
| Cargo fijo | `"Cargo fijo HOG30"` (con el `plan_id`) |
| Voz | `"Minutos adicionales (42)"` (con la cantidad) |
| Internacional | `"Minutos internacionales (3)"` |
| Datos | `"Megas adicionales (141)"` |
| SMS | `"SMS adicionales (20)"` |
| Descuento | `"Descuento cliente empresarial"`, con valor **negativo** |

   - `__str__` que imprima la factura así (columnas: descripción a la izquierda en 32 caracteres, valor a la derecha en 10, con punto de miles):

```text
Factura de CL0000001 · plan HOG30
Cargo fijo HOG30                    35.900
Minutos adicionales (42)             5.040
--------------------------------------------
Subtotal                            40.940
IVA 19 %                             7.779
TOTAL                               48.719
```

Las reglas de facturación son las del curso (Referencia → Datos del curso).

## Pista 1

Piensa `calcular` como una lista de candidatos `(descripción, valor)`; luego filtras los ceros. El cargo fijo va siempre:

```python
@classmethod
def calcular(cls, cliente, plan, consumo):
    conceptos = [Concepto(f"Cargo fijo {plan.plan_id}", plan.cargo_fijo)]
    candidatos = [
        (f"Minutos adicionales ({exceso_min})", exceso_min * plan.tarifa_minuto),
        ...
    ]
    conceptos += [Concepto(d, v) for d, v in candidatos if v != 0]
    return cls(cliente, plan, conceptos)
```

Calcula cada exceso con una función auxiliar que respete el `-1` de ilimitado.

## Pista 2

La línea de separación tiene 42 guiones (32 + 10). Para el formato de cada fila:

```python
def fila(texto, valor):
    return f"{texto:<32}{f'{valor:,}'.replace(',', '.'):>10}"
```

El IVA: `int((Decimal(self.subtotal) * Decimal("0.19")).quantize(Decimal("1"), rounding=ROUND_HALF_UP))`.

## Solución

```python
import math
from dataclasses import dataclass, field
from decimal import ROUND_HALF_UP, Decimal

ILIMITADO = -1


@dataclass(frozen=True)
class Cliente:
    cliente_id: str
    segmento: str
    fecha_alta: str


@dataclass(frozen=True)
class Plan:
    plan_id: str
    cargo_fijo: int
    minutos_incluidos: int
    mb_incluidos: int
    sms_incluidos: int
    tarifa_minuto: int
    tarifa_minuto_internacional: int
    tarifa_mb: int
    tarifa_sms: int


@dataclass(frozen=True)
class Consumo:
    minutos_nacionales: int = 0
    minutos_internacionales: int = 0
    mb: float = 0.0
    sms: int = 0


def exceso(consumido, incluido):
    return 0 if incluido == ILIMITADO else max(0, consumido - incluido)


def pesos(valor):
    return f"{valor:,}".replace(",", ".")


@dataclass(frozen=True)
class Concepto:
    descripcion: str
    valor: int


@dataclass
class Factura:
    cliente: Cliente
    plan: Plan
    conceptos: list[Concepto] = field(default_factory=list)

    @classmethod
    def calcular(cls, cliente, plan, consumo):
        minutos = exceso(consumo.minutos_nacionales, plan.minutos_incluidos)
        megas = exceso(math.ceil(consumo.mb), plan.mb_incluidos)
        sms = exceso(consumo.sms, plan.sms_incluidos)
        internacional = consumo.minutos_internacionales
        descuento = 0
        if cliente.segmento == "EMPRESARIAL" and cliente.fecha_alta < "2023-09-01":
            descuento = int((Decimal(plan.cargo_fijo) * Decimal("0.10")).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
        candidatos = [
            (f"Minutos adicionales ({minutos})", minutos * plan.tarifa_minuto),
            (f"Minutos internacionales ({internacional})", internacional * plan.tarifa_minuto_internacional),
            (f"Megas adicionales ({megas})", megas * plan.tarifa_mb),
            (f"SMS adicionales ({sms})", sms * plan.tarifa_sms),
            ("Descuento cliente empresarial", -descuento),
        ]
        conceptos = [Concepto(f"Cargo fijo {plan.plan_id}", plan.cargo_fijo)]
        conceptos += [Concepto(descripcion, valor) for descripcion, valor in candidatos if valor != 0]
        return cls(cliente, plan, conceptos)

    @property
    def subtotal(self):
        return sum(c.valor for c in self.conceptos)

    @property
    def iva(self):
        return int((Decimal(self.subtotal) * Decimal("0.19")).quantize(Decimal("1"), rounding=ROUND_HALF_UP))

    @property
    def total(self):
        return self.subtotal + self.iva

    def __str__(self):
        def fila(texto, valor):
            return f"{texto:<32}{pesos(valor):>10}"

        lineas = [f"Factura de {self.cliente.cliente_id} · plan {self.plan.plan_id}"]
        lineas += [fila(c.descripcion, c.valor) for c in self.conceptos]
        lineas += ["-" * 42, fila("Subtotal", self.subtotal), fila("IVA 19 %", self.iva), fila("TOTAL", self.total)]
        return "\n".join(lineas)


HOG30 = Plan("HOG30", 35900, 300, 15360, 100, 120, 950, 18, 60)
f = Factura.calcular(Cliente("CL0000001", "RESIDENCIAL", "2015-01-01"), HOG30, Consumo(minutos_nacionales=342))
print(f)
```

## Explicación

Compara con la función del módulo 4 que devolvía un diccionario con 12 claves:

- **Los conceptos son datos**, no columnas fijas. Agregar un cargo nuevo (por ejemplo, "Reposición de SIM") es agregar un `Concepto`; no hay que cambiar la estructura de la factura.
- **`subtotal`, `iva` y `total` son propiedades**: se calculan siempre a partir de los conceptos, así que nunca pueden quedar desincronizados (justamente el error de las facturas "inconsistentes" de los datos del curso).
- **La factura *tiene* un cliente y *tiene* un plan** (composición): puedes llegar a `f.plan.tarifa_minuto` cuando lo necesites, sin copiar datos.

El descuento como concepto negativo hace que el subtotal se calcule con una simple suma, y además queda visible en el detalle para el cliente.
