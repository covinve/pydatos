## Enunciado

Deja listo tu entorno profesional **en el computador donde estés** (y luego repítelo en el otro). Al final, las pruebas de este ejercicio verifican todo por ti.

1. Abre la carpeta del curso en VS Code (**Archivo → Abrir carpeta**).
2. Crea el entorno virtual: `python -m venv .venv`.
3. Actívalo: `.venv\Scripts\Activate.ps1` (debe aparecer `(.venv)` en la terminal).
4. Instala las librerías del curso: `python -m pip install -r requirements.txt`.
5. En VS Code selecciona el intérprete del entorno: `Ctrl + Shift + P` → **Python: Select Interpreter** → `.venv`.
6. Genera los datos de 10 MB: `python herramientas/generar_datos.py --tamano 10MB`.
7. Comprueba: `python comprobar.py m01-e1`.

Las pruebas revisan que:

- uses Python 3.11 o superior;
- estés **dentro de un entorno virtual**;
- estén instaladas las librerías principales del curso;
- existan los datos de 10 MB en `datos/10MB/`.

## Pista 1

Si la prueba del entorno virtual falla, casi siempre es porque ejecutaste `comprobar.py` con el Python global. Mira si la terminal muestra `(.venv)` al inicio. Si no, actívalo, o ejecuta con la ruta completa:

```powershell
.venv\Scripts\python comprobar.py m01-e1
```

## Pista 2

Si falta una librería, revisa que el `pip install` haya terminado sin errores rojos. En la oficina, si falla por conexión, puede que necesites el proxy de la empresa:

```powershell
python -m pip install --proxy http://usuario:clave@proxy:puerto -r requirements.txt
```

Si falta `datos/10MB`, ejecuta el generador desde la carpeta raíz del curso, no desde `ejercicios/`.

## Solución

La secuencia completa, desde la carpeta del curso:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python herramientas/generar_datos.py --tamano 10MB
python comprobar.py m01-e1
```

## Explicación

Cada pieza tiene un propósito:

- `venv` aísla las librerías de este proyecto.
- `requirements.txt` hace que el entorno sea **reproducible**: en la casa y en la oficina instalas exactamente lo mismo.
- El generador crea datos con una semilla fija: los dos computadores tendrán **los mismos datos** y el mismo `esperado.json`.

Este ejercicio lo repetirás en cada computador donde trabajes. Cuando lo hayas hecho una vez, la segunda te tomará cinco minutos.
