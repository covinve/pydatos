## Enunciado

Construye el puerto, dos adaptadores y un servicio que solo depende del puerto.

1. `Plan`: `dataclass(frozen=True)` con `plan_id`, `nombre`, `segmento`, `cargo_fijo`, `minutos_incluidos`, `tarifa_minuto`, `tarifa_minuto_internacional` (los números como `int`).
2. `PlanNoEncontrado`: excepción, subclase de `LookupError`.
3. `RepositorioPlanes` (`Protocol`): `obtener(plan_id) -> Plan` y `del_segmento(segmento) -> list[Plan]` (ordenados por `cargo_fijo`).
4. `PlanesEnMemoria(planes)` y `PlanesCSV(ruta)`: los dos adaptadores. `obtener` lanza `PlanNoEncontrado` si no existe.
5. `CotizadorVoz(repositorio)` con:
   - `cotizar(plan_id, min_nacionales, min_internacionales)` → valor del consumo adicional de voz (las reglas de siempre: excedente nacional, ilimitado con `-1`, todo lo internacional se cobra);
   - `mejor_plan(segmento, min_nacionales, min_internacionales)` → el `plan_id` con el menor **cargo fijo + consumo adicional** para ese consumo (empate: el de menor cargo fijo).

## Solución

```python
import csv
from dataclasses import dataclass
from typing import Protocol


@dataclass(frozen=True)
class Plan:
    plan_id: str
    nombre: str
    segmento: str
    cargo_fijo: int
    minutos_incluidos: int
    tarifa_minuto: int
    tarifa_minuto_internacional: int


class PlanNoEncontrado(LookupError):
    pass


class RepositorioPlanes(Protocol):
    def obtener(self, plan_id: str) -> Plan: ...
    def del_segmento(self, segmento: str) -> list[Plan]: ...


class PlanesEnMemoria:
    def __init__(self, planes):
        self._planes = {p.plan_id: p for p in planes}

    def obtener(self, plan_id):
        try:
            return self._planes[plan_id]
        except KeyError:
            raise PlanNoEncontrado(f"No existe el plan {plan_id}") from None

    def del_segmento(self, segmento):
        return sorted((p for p in self._planes.values() if p.segmento == segmento), key=lambda p: p.cargo_fijo)


class PlanesCSV(PlanesEnMemoria):
    def __init__(self, ruta):
        with open(ruta, encoding="utf-8", newline="") as f:
            super().__init__([
                Plan(p["plan_id"], p["nombre"], p["segmento"], int(p["cargo_fijo"]), int(p["minutos_incluidos"]),
                     int(p["tarifa_minuto"]), int(p["tarifa_minuto_internacional"]))
                for p in csv.DictReader(f)
            ])


class CotizadorVoz:
    def __init__(self, repo: RepositorioPlanes):
        self.repo = repo

    @staticmethod
    def _valor(plan, nacionales, internacionales):
        voz = 0 if plan.minutos_incluidos == -1 else max(0, nacionales - plan.minutos_incluidos) * plan.tarifa_minuto
        return voz + internacionales * plan.tarifa_minuto_internacional

    def cotizar(self, plan_id, min_nacionales, min_internacionales):
        return self._valor(self.repo.obtener(plan_id), min_nacionales, min_internacionales)

    def mejor_plan(self, segmento, min_nacionales, min_internacionales):
        candidatos = self.repo.del_segmento(segmento)
        mejor = min(candidatos, key=lambda p: (p.cargo_fijo + self._valor(p, min_nacionales, min_internacionales),
                                               p.cargo_fijo))
        return mejor.plan_id


cotizador = CotizadorVoz(PlanesCSV("planes.csv"))
print(cotizador.cotizar("HOG30", 342, 5))
print(cotizador.mejor_plan("RESIDENCIAL", 342, 5))
```

## Explicación

`CotizadorVoz` es lógica de negocio valiosa ("¿qué plan le conviene a este cliente?", la base de una campaña de retención) y se probó con **cuatro planes inventados** en memoria, diseñados para cubrir cada caso: el plan barato, el intermedio, el ilimitado, el empate. Con el CSV real sería difícil encontrar consumos que ejerciten cada rama.

`PlanesCSV` hereda de `PlanesEnMemoria`: leer el archivo es lo único distinto, y la búsqueda y el filtro se reutilizan. Mañana, `PlanesSQLite` implementaría los mismos dos métodos con consultas, y el cotizador no se enteraría.

Fíjate en que `obtener` convierte el `KeyError` del diccionario en `PlanNoEncontrado` (`from None` oculta el error interno). Quien usa el repositorio no tiene por qué saber que por dentro hay un diccionario: el error habla el idioma del dominio.
