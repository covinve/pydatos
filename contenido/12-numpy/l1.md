Una lista de Python guarda **objetos** sueltos en memoria; cada número es un objeto con su propio tipo y su propio espacio. Un **array** de NumPy guarda los números **juntos, todos del mismo tipo**, como una columna de una planilla. Eso permite que las operaciones se ejecuten en código compilado (C), sin pasar por el intérprete en cada elemento.

```pyrun
import numpy as np

duraciones = np.array([125, 0, 61, 3600, 45])
print(duraciones)
print(duraciones.dtype, duraciones.shape, duraciones.size)

minutos = (duraciones + 59) // 60      # se aplica a TODOS los elementos a la vez
print(minutos)
print(minutos * 120)                   # valor de cada llamada
print(minutos.sum())
```

Fíjate: no hay `for`. Escribir operaciones sobre el array completo se llama **vectorizar**.

## ¿Cuánto más rápido?

```pyrun
import time

import numpy as np

n = 2_000_000
lista = list(range(n))
array = np.arange(n)

inicio = time.perf_counter()
total_lista = sum((d + 59) // 60 for d in lista)
t_lista = time.perf_counter() - inicio

inicio = time.perf_counter()
total_array = int(((array + 59) // 60).sum())
t_array = time.perf_counter() - inicio

print(total_lista == total_array)
print(f"Python puro: {t_lista * 1000:7.1f} ms")
print(f"NumPy:       {t_array * 1000:7.1f} ms   (~{t_lista / t_array:.0f} veces más rápido)")
```

## Crear arrays

| Función | Crea | Ejemplo |
|---|---|---|
| `np.array(lista)` | Desde una lista | `np.array([125, 0, 61])` |
| `np.arange(inicio, fin, paso)` | Secuencia, como `range` | `np.arange(0, 24)` (horas) |
| `np.zeros(n)` / `np.ones(n)` | Llenos de 0 o 1 | Acumuladores |
| `np.full(n, valor)` | Llenos de un valor | `np.full(5, 120)` |
| `np.linspace(a, b, n)` | `n` valores equiespaciados | Ejes de gráficos |

```pyrun
import numpy as np

horas = np.arange(24)
print(horas)
tarifas = np.full(5, 120)
print(tarifas)
tabla = np.zeros((3, 4), dtype=int)     # 2 dimensiones: 3 filas, 4 columnas
print(tabla.shape)
print(tabla)
```

## Operaciones elemento a elemento

Las operaciones entre arrays del mismo tamaño se aplican **posición por posición**:

```pyrun
import numpy as np

minutos = np.array([3, 0, 2, 60])
tarifas = np.array([120, 120, 950, 100])

print(minutos * tarifas)                 # valor de cada llamada
print(np.maximum(minutos - 1, 0))        # versión vectorizada de max(0, x)
print(np.ceil(np.array([15.131, 0.2, 7.0])))
print(np.round(np.array([1.234, 5.678]), 1))
```

| Python (un valor) | NumPy (todo el array) |
|---|---|
| `max(0, x)` | `np.maximum(x, 0)` |
| `math.ceil(x)` | `np.ceil(x)` |
| `abs(x)` | `np.abs(x)` |
| `round(x, 2)` | `np.round(x, 2)` |
| `sum(lista)` | `array.sum()` |

:::error Las funciones de math no aceptan arrays
`math.ceil(array)` da error. Usa siempre la versión de NumPy (`np.ceil`). Y `max(array)` funciona pero es lento: usa `array.max()`.
:::

## Arrays de dos dimensiones

```pyrun
import numpy as np

# filas: líneas; columnas: minutos, megas, sms
consumo = np.array([
    [342, 15500.2, 120],
    [15, 80000.0, 3],
    [1203, 512.0, 40],
])
print(consumo.shape)
print(consumo[0])          # primera fila
print(consumo[:, 1])       # columna de megas
print(consumo[1, 2])       # fila 1, columna 2
```

:::telco ¿Y para tablas con columnas de distinto tipo?
Un array guarda un **solo tipo**: si mezclas números y textos, todo se vuelve texto. Para tablas como el archivo de CDR (líneas, tipos, fechas, números) usarás **Pandas** (módulos 13 y 14), que está construido sobre NumPy: cada columna de un DataFrame es un array.
:::
