## Enunciado

Para facturar, cada CDR necesita saber **a qué cliente y plan pertenece**. Recibes dos listas de diccionarios:

```python
clientes = [
    {"cliente_id": "CL001", "linea": "3001234567", "plan_id": "HOG30"},
    {"cliente_id": "CL002", "linea": "3109876543", "plan_id": "ILIM"},
]
cdrs = [
    {"cdr_id": 1, "linea_origen": "3109876543", "tipo": "VOZ", "duracion_seg": 125},
    {"cdr_id": 2, "linea_origen": "3999999999", "tipo": "SMS", "duracion_seg": 0},
]
```

Escribe:

1. `indice_por_linea(clientes)` → diccionario `linea → cliente`.
2. `enriquecer_cdrs(cdrs, clientes)` → una **lista nueva** de diccionarios **nuevos**: cada CDR con dos claves más, `cliente_id` y `plan_id`. Si la línea no pertenece a ningún cliente, ambas valen `None`.
3. `lineas_desconocidas(cdrs, clientes)` → lista **ordenada y sin repetidos** de las líneas de los CDR que no son de ningún cliente.

:::error No modifiques los datos originales
`enriquecer_cdrs` no debe cambiar los diccionarios de `cdrs`. Otras partes del programa los usan, y modificarlos "por debajo" causa errores muy difíciles de rastrear. Las pruebas lo verifican.
:::

## Pruebas

```python
import copy

CLIENTES = [
    {"cliente_id": "CL001", "linea": "3001234567", "plan_id": "HOG30"},
    {"cliente_id": "CL002", "linea": "3109876543", "plan_id": "ILIM"},
    {"cliente_id": "CL003", "linea": "3157778899", "plan_id": "EMP100"},
]
CDRS = [
    {"cdr_id": 1, "linea_origen": "3109876543", "tipo": "VOZ", "duracion_seg": 125},
    {"cdr_id": 2, "linea_origen": "3999999999", "tipo": "SMS", "duracion_seg": 0},
    {"cdr_id": 3, "linea_origen": "3001234567", "tipo": "DATOS", "duracion_seg": 600},
    {"cdr_id": 4, "linea_origen": "3888888888", "tipo": "VOZ", "duracion_seg": 30},
    {"cdr_id": 5, "linea_origen": "3999999999", "tipo": "VOZ", "duracion_seg": 61},
]


def prueba_indice():
    """El índice encuentra cada cliente por su línea"""
    requiere("indice_por_linea")
    indice = indice_por_linea(CLIENTES)
    igual(indice["3157778899"]["cliente_id"], "CL003")
    igual(len(indice), 3)


def prueba_enriquecer():
    """Agrega cliente_id y plan_id a cada CDR"""
    requiere("enriquecer_cdrs")
    resultado = enriquecer_cdrs(CDRS, CLIENTES)
    igual(len(resultado), 5)
    igual(resultado[0], {"cdr_id": 1, "linea_origen": "3109876543", "tipo": "VOZ", "duracion_seg": 125,
                         "cliente_id": "CL002", "plan_id": "ILIM"})
    igual(resultado[2]["plan_id"], "HOG30")


def prueba_lineas_sin_cliente():
    """Las líneas desconocidas quedan con None"""
    resultado = enriquecer_cdrs(CDRS, CLIENTES)
    igual(resultado[1]["cliente_id"], None)
    igual(resultado[1]["plan_id"], None)


def prueba_no_modifica_originales():
    """Los CDR originales no cambian"""
    originales = copy.deepcopy(CDRS)
    enriquecer_cdrs(CDRS, CLIENTES)
    igual(CDRS, originales, "enriquecer_cdrs modificó la lista o los diccionarios originales")


def prueba_lineas_desconocidas():
    """Lista ordenada y sin repetidos de las líneas sin cliente"""
    requiere("lineas_desconocidas")
    igual(lineas_desconocidas(CDRS, CLIENTES), ["3888888888", "3999999999"])
    igual(lineas_desconocidas(CDRS[:1], CLIENTES), [])
```

## Pista 1

Construye el índice con una comprensión de diccionario: `{c["linea"]: c for c in clientes}`.

Para no modificar el CDR original, crea una copia antes de agregarle claves: `nuevo = dict(cdr)` o `nuevo = cdr.copy()`.

## Pista 2

Con `get` obtienes el cliente o `None` en una línea:

```python
cliente = indice.get(cdr["linea_origen"])
nuevo["cliente_id"] = cliente["cliente_id"] if cliente else None
```

Para las desconocidas, un conjunto elimina los repetidos y `sorted()` lo devuelve como lista ordenada.

## Solución

```python
clientes = [
    {"cliente_id": "CL001", "linea": "3001234567", "plan_id": "HOG30"},
    {"cliente_id": "CL002", "linea": "3109876543", "plan_id": "ILIM"},
]
cdrs = [
    {"cdr_id": 1, "linea_origen": "3109876543", "tipo": "VOZ", "duracion_seg": 125},
    {"cdr_id": 2, "linea_origen": "3999999999", "tipo": "SMS", "duracion_seg": 0},
]


def indice_por_linea(clientes):
    return {c["linea"]: c for c in clientes}


def enriquecer_cdrs(cdrs, clientes):
    indice = indice_por_linea(clientes)
    resultado = []
    for cdr in cdrs:
        cliente = indice.get(cdr["linea_origen"])
        nuevo = {
            **cdr,
            "cliente_id": cliente["cliente_id"] if cliente else None,
            "plan_id": cliente["plan_id"] if cliente else None,
        }
        resultado.append(nuevo)
    return resultado


def lineas_desconocidas(cdrs, clientes):
    conocidas = set(indice_por_linea(clientes))
    return sorted({cdr["linea_origen"] for cdr in cdrs} - conocidas)


for cdr in enriquecer_cdrs(cdrs, clientes):
    print(cdr)
```

## Explicación

- **`{**cdr, "cliente_id": ...}`** crea un diccionario nuevo con todas las claves de `cdr` más las nuevas. Es la forma idiomática de "copiar y agregar". Equivale a `nuevo = dict(cdr)` seguido de asignaciones.
- **El índice se construye una sola vez**, fuera del bucle. Construirlo dentro del `for` lo recrearía para cada CDR: el programa funcionaría, pero miles de veces más lento.
- **`lineas_desconocidas`** combina una comprensión de **conjunto** (`{... for ...}`) con la diferencia de conjuntos. `set(indice)` toma las claves del diccionario.

Lo que hiciste se llama **enriquecer** datos y es un paso de casi todos los procesos de facturación: los CDR llegan "pelados" desde la red y se completan con la información comercial.
