## Pista 2

`COUNT(DISTINCT c.linea)` cuenta clientes distintos. Divide con `ROUND(SUM(v.minutos) / COUNT(DISTINCT c.linea), 1)`. Agrupa también por `p.minutos_incluidos` (o usa `ANY_VALUE`).

## Solución

```python
import duckdb


def minutos_por_plan():
    return duckdb.sql("""
        WITH voz AS (
            SELECT linea_origen, (duracion_seg + 59) // 60 AS minutos
            FROM read_csv('cdr.csv', delim='|', header=true, types={'linea_origen': 'VARCHAR'})
            WHERE tipo = 'VOZ' AND duracion_seg >= 0
        ),
        clientes AS (
            SELECT * FROM read_csv('clientes.csv', encoding='latin-1', header=true, types={'linea': 'VARCHAR'})
        ),
        planes AS (
            SELECT * FROM read_csv('planes.csv', header=true)
        )
        SELECT c.plan_id,
               COUNT(DISTINCT c.linea) AS clientes,
               SUM(v.minutos) AS minutos,
               ROUND(SUM(v.minutos) / COUNT(DISTINCT c.linea), 1) AS minutos_por_cliente,
               p.minutos_incluidos
        FROM voz v
        JOIN clientes c ON c.linea = v.linea_origen
        JOIN planes p ON p.plan_id = c.plan_id
        GROUP BY c.plan_id, p.minutos_incluidos
        ORDER BY c.plan_id
    """).df()


print(minutos_por_plan())
```

## Explicación

Tres CTE dejan la consulta en pasos claros: qué es una llamada válida, de dónde salen los clientes y los planes, y cómo se combinan. Los `JOIN` de SQL funcionan como los `merge` de Pandas con `how="inner"`: solo quedan los CDR de líneas que son clientes.

Comparar `minutos_por_cliente` con `minutos_incluidos` es la base de un análisis de "dimensionamiento de planes": si los clientes de un plan usan en promedio mucho menos de lo incluido, quizá ese plan esté sobredimensionado.
