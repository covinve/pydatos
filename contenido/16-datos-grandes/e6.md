## Enunciado

Las medianas y percentiles no se pueden combinar entre bloques (módulo 14), pero DuckDB los calcula sobre el archivo completo. Escribe `distribucion_por_plan()` que devuelva un DataFrame de Pandas con, para cada `plan_id` (ordenado), sobre las llamadas `VOZ` contestadas (duración > 0) de clientes conocidos:

| Columna | Cálculo |
|---|---|
| `llamadas` | Cantidad |
| `p50` | Mediana de la duración (segundos), con `quantile_cont(duracion_seg, 0.5)` |
| `p90` | Percentil 90 |
| `p99` | Percentil 99 |
| `promedio` | Promedio, redondeado a 1 decimal |

Los percentiles redondeados a 1 decimal.

## Pruebas

```python
import numpy as np
import pandas as pd

CDR = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
CLI = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})


def prueba_distribucion():
    """Coincide con los percentiles calculados con NumPy"""
    v = CDR[(CDR["tipo"] == "VOZ") & (CDR["duracion_seg"] > 0)].merge(CLI, left_on="linea_origen", right_on="linea")
    r = distribucion_por_plan()
    igual(list(r.columns), ["plan_id", "llamadas", "p50", "p90", "p99", "promedio"])
    igual(r["plan_id"].tolist(), sorted(v["plan_id"].unique()))
    for _, fila in r.iterrows():
        d = v.loc[v["plan_id"] == fila["plan_id"], "duracion_seg"].to_numpy()
        igual(int(fila["llamadas"]), len(d))
        for col, q in [("p50", 50), ("p90", 90), ("p99", 99)]:
            cerca(float(fila[col]), round(float(np.percentile(d, q)), 1), 0.051)
        cerca(float(fila["promedio"]), round(float(d.mean()), 1), 0.051)
```

## Pista 2

`quantile_cont` interpola entre valores, igual que `np.percentile` por defecto. (`quantile_disc` devuelve siempre un valor existente.) Recuerda leer las líneas como texto en ambos archivos.

## Solución

```python
import duckdb


def distribucion_por_plan():
    return duckdb.sql("""
        SELECT c.plan_id,
               COUNT(*) AS llamadas,
               ROUND(quantile_cont(v.duracion_seg, 0.5), 1) AS p50,
               ROUND(quantile_cont(v.duracion_seg, 0.9), 1) AS p90,
               ROUND(quantile_cont(v.duracion_seg, 0.99), 1) AS p99,
               ROUND(AVG(v.duracion_seg), 1) AS promedio
        FROM read_csv('cdr.csv', delim='|', header=true, types={'linea_origen': 'VARCHAR'}) v
        JOIN read_csv('clientes.csv', encoding='latin-1', header=true, types={'linea': 'VARCHAR'}) c
          ON c.linea = v.linea_origen
        WHERE v.tipo = 'VOZ' AND v.duracion_seg > 0
        GROUP BY c.plan_id
        ORDER BY c.plan_id
    """).df()


print(distribucion_por_plan())
```

## Explicación

Los percentiles altos (p90, p99) describen la "cola" de la distribución: qué tan largas son las llamadas más largas. En la muestra, el promedio está muy por encima de la mediana en todos los planes: la cola larga que viste en el módulo 15.

¿Por qué este cálculo es difícil por bloques y fácil en DuckDB? Para la mediana exacta hay que ver todos los valores juntos (ordenados). DuckDB lo resuelve internamente ordenando con ayuda del disco si es necesario. Para datos enormes también existe `approx_quantile`, mucho más rápido y con un error pequeño y controlado.
