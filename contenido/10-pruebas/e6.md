## Enunciado

Llegó este reporte de auditoría:

> **Ticket FAC-412.** El cliente CL0004410 (empresarial, alta el **2023-09-01**) recibió el descuento del 10 %. Según la regla, el descuento aplica solo a clientes empresariales con alta **anterior** al 2023-09-01. Además, revisando el código vimos que nadie probó qué pasa con los clientes residenciales antiguos.

El módulo `descuentos.py` (en tu carpeta de trabajo) tiene **la versión con el error**. Antes de que alguien lo arregle, escribe las pruebas:

1. Una prueba de regresión que **falle** con la versión actual por el error del ticket (y pase cuando se corrija).
2. Pruebas que fijen el resto de la regla: un empresarial antiguo sí tiene descuento; un residencial antiguo no.

El curso comprueba que tus pruebas **fallan** con la versión con error, **pasan** con la versión corregida y atrapan otros dos mutantes.

## Pruebas

```python
import pytest

BASE = "FECHA_CORTE = '2023-09-01'\n\ndef tiene_descuento(segmento, fecha_alta):\n"
CON_ERROR = BASE + "    return segmento == 'EMPRESARIAL' and fecha_alta <= FECHA_CORTE\n"
CORREGIDA = BASE + "    return segmento == 'EMPRESARIAL' and fecha_alta < FECHA_CORTE\n"


def correr(implementacion):
    return correr_pytest(codigo, {"descuentos": implementacion})


def prueba_reproduce_el_ticket():
    """Tus pruebas FALLAN con la versión que tiene el error del ticket"""
    salida, _ = correr(CON_ERROR)
    assert salida == 1, "Tus pruebas pasan con la versión con error: no reproducen el ticket FAC-412"


def prueba_pasan_con_la_correccion():
    """Tus pruebas pasan con la versión corregida"""
    salida, texto = correr(CORREGIDA)
    assert salida == 0, "Tus pruebas fallan con la versión CORREGIDA:\n" + texto[-900:]


def prueba_atrapa_sin_segmento():
    """Atrapan el mutante que da descuento sin mirar el segmento"""
    salida, _ = correr(BASE + "    return fecha_alta < FECHA_CORTE\n")
    assert salida == 1, "Ninguna prueba usa un cliente residencial antiguo"


def prueba_atrapa_sin_descuento():
    """Atrapan el mutante que nunca da descuento"""
    salida, _ = correr(BASE + "    return False\n")
    assert salida == 1, "Ninguna prueba verifica que un empresarial antiguo SÍ tiene descuento"
```

## Pista 1

La prueba del ticket usa los datos exactos del reporte:

```python
def test_regresion_fac_412():
    """Alta exactamente el 2023-09-01: no tiene descuento."""
    assert tiene_descuento("EMPRESARIAL", "2023-09-01") is False
```

Con la versión actual (`<=`) devuelve `True`, así que esta prueba falla. ¡Eso es lo que buscamos!

## Pista 2

Faltan dos pruebas: `tiene_descuento("EMPRESARIAL", "2020-05-10")` debe ser `True` y `tiene_descuento("RESIDENCIAL", "2010-01-01")` debe ser `False`. Agrega también el día anterior al corte (`"2023-08-31"`) para fijar el límite desde los dos lados.

## Solución

```python
from descuentos import tiene_descuento


def test_regresion_fac_412():
    """Alta exactamente el 2023-09-01: no tiene descuento."""
    assert tiene_descuento("EMPRESARIAL", "2023-09-01") is False


def test_un_dia_antes_del_corte_si_tiene_descuento():
    assert tiene_descuento("EMPRESARIAL", "2023-08-31") is True


def test_empresarial_antiguo_tiene_descuento():
    assert tiene_descuento("EMPRESARIAL", "2020-05-10") is True


def test_residencial_nunca_tiene_descuento():
    assert tiene_descuento("RESIDENCIAL", "2010-01-01") is False
```

## Explicación

Este es el flujo profesional para corregir un error:

1. **Reproducirlo con una prueba** que falle (rojo). Demuestra que entendiste el error.
2. **Corregir el código** hasta que pase (verde). Demuestra que lo arreglaste.
3. **Dejar la prueba para siempre.** Si alguien vuelve a escribir `<=`, la prueba lo atrapa.

Poner el número del ticket en el nombre o el docstring de la prueba deja trazabilidad: dentro de un año, quien vea `test_regresion_fac_412` sabrá exactamente por qué existe.

Fíjate que el error era de **un carácter** (`<=` en vez de `<`) y solo se manifestaba **un día de todo el calendario**. Ningún análisis de datos "normal" lo habría encontrado; una prueba en el límite sí.
