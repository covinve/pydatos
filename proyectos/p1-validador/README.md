# Proyecto 1 · Validador de archivos de facturación

La guía completa está en la página del curso: **Nivel básico → Proyecto 1**.

Ejecutar las pruebas:

```powershell
python -m pytest proyectos/p1-validador -v
```

Ejecutar el validador:

```powershell
python proyectos/p1-validador/validador.py --cdr datos/10MB/cdr.csv --clientes datos/10MB/clientes.csv --salida reportes/10MB
```

> Al terminar el proyecto, reemplaza este archivo con tu propio README: qué hace, cómo se usa, un ejemplo de salida y los tiempos que mediste con 10 MB y 1 GB.
