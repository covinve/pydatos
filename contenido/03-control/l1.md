Las reglas de facturación están llenas de condiciones: *si* el plan es ilimitado no se cobra exceso; *si* la llamada es internacional usa otra tarifa; *si* es de noche hay descuento. En Python, las decisiones se escriben con `if`.

## if, elif, else

```pyrun
destino = "NACIONAL"

if destino == "LOCAL":
    tarifa = 100
elif destino == "NACIONAL":
    tarifa = 120
elif destino == "INTERNACIONAL":
    tarifa = 950
else:
    tarifa = None

print(f"Tarifa para {destino}: {tarifa}")
```

- `if` evalúa la condición; si es verdadera, ejecuta su bloque y **salta todo lo demás**.
- `elif` ("si no, si…") se revisa solo si las anteriores fueron falsas.
- `else` atrapa todo lo que no cumplió ninguna condición. Es opcional.
- El bloque se define por la **sangría de 4 espacios**: no hay llaves ni `end`.

Sigue el camino que toma el programa:

```pytrace
minutos_usados = 342
minutos_incluidos = 300
tarifa = 120

if minutos_incluidos == -1:
    valor_voz = 0
elif minutos_usados > minutos_incluidos:
    valor_voz = (minutos_usados - minutos_incluidos) * tarifa
else:
    valor_voz = 0

print(valor_voz)
```

:::error El orden de los elif importa
Python se queda con la **primera** condición verdadera. Este código nunca da descuento a los clientes de más de 10 años, porque la primera condición ya los atrapó:

```python
if antiguedad >= 3:
    descuento = 0.10
elif antiguedad >= 10:      # nunca llega aquí con antigüedad 12
    descuento = 0.20
```

Ordena las condiciones de la más específica a la más general.
:::

## Condiciones compuestas y anidadas

```pyrun
segmento = "EMPRESARIAL"
anio_alta = 2021
cargo_fijo = 79900

if segmento == "EMPRESARIAL" and anio_alta < 2023:
    descuento = round(cargo_fijo * 0.10)
else:
    descuento = 0

print(descuento)
```

Puedes anidar un `if` dentro de otro, pero con más de dos niveles el código se vuelve difícil de leer. Una técnica para aplanarlo es la **salida temprana** dentro de las funciones:

:::comparar
:::mal Anidado
```python
def valor_voz(minutos, incluidos, tarifa):
    if incluidos != -1:
        if minutos > incluidos:
            return (minutos - incluidos) * tarifa
        else:
            return 0
    else:
        return 0
```
:::
:::bien Salida temprana
```python
def valor_voz(minutos, incluidos, tarifa):
    if incluidos == -1:
        return 0                     # ilimitado
    exceso = max(0, minutos - incluidos)
    return exceso * tarifa
```
:::
:::

Primero se descartan los casos especiales con `return`, y lo que queda es el caso normal, sin sangría extra.

## La expresión condicional

Para elegir entre dos valores en una sola línea:

```pyrun
duracion = 0
estado = "no contestada" if duracion == 0 else "contestada"
print(estado)
```

Úsala solo para decisiones cortas. Si necesitas más de dos opciones, vuelve al `if` normal.

## match: elegir según un valor

Desde Python 3.10, `match` compara un valor contra varios **patrones**. Es ideal cuando la decisión depende de un solo valor con muchas opciones:

```pyrun
def tarifa_por_destino(destino):
    match destino:
        case "LOCAL":
            return 100
        case "NACIONAL":
            return 120
        case "INTERNACIONAL":
            return 950
        case _:
            return None    # _ atrapa cualquier otro valor


for d in ["LOCAL", "INTERNACIONAL", "SATELITAL"]:
    print(d, tarifa_por_destino(d))
```

Un `case` puede aceptar varias opciones con `|`:

```pyrun
def familia(tipo):
    match tipo:
        case "VOZ" | "SMS":
            return "comunicación"
        case "DATOS":
            return "navegación"
        case _:
            return "desconocido"


print(familia("SMS"), familia("DATOS"), familia("VOX"))
```

:::telco Reglas de negocio legibles
Una regla como "el exceso de voz es 0 si el plan es ilimitado" debería poder leerse en el código casi palabra por palabra. Cuando auditoría pregunte por qué se cobró un valor, quieres poder mostrarles la línea exacta que lo decide.
:::

## Cuestionario

? ¿Qué imprime este código si `minutos = 300` y `incluidos = 300`? `if minutos > incluidos: print("exceso") elif minutos == incluidos: print("justo") else: print("sobran")`
- [ ] `exceso`
- [x] `justo`
- [ ] `sobran`
- [ ] `justo` y `sobran`
> La primera condición es falsa (300 no es mayor que 300) y la segunda es verdadera. Solo se ejecuta un bloque.

? ¿Para qué sirve `case _:` en un `match`?
- [ ] Para el valor `None`
- [ ] Para el texto vacío
- [x] Para cualquier valor que no coincidió con los casos anteriores
- [ ] Para detener el programa
> `_` es el comodín: funciona como el `else` del `match`.

? ¿Qué valor queda en `x`? `x = "A" if 5 > 10 else "B"`
- [ ] `"A"`
- [x] `"B"`
- [ ] `True`
- [ ] `None`
> La condición `5 > 10` es falsa, así que se elige el valor después de `else`.
