## Operadores aritméticos

| Operador | Operación | Ejemplo | Resultado |
|---|---|---|---|
| `+` `-` `*` | Suma, resta, multiplicación | `35900 + 5040` | `40940` |
| `/` | División (siempre da `float`) | `125 / 60` | `2.0833…` |
| `//` | División entera (descarta decimales) | `125 // 60` | `2` |
| `%` | Módulo: el residuo de la división | `125 % 60` | `5` |
| `**` | Potencia | `1024 ** 2` | `1048576` |

`//` y `%` son la pareja perfecta para convertir unidades:

```pyrun
segundos = 3725
horas = segundos // 3600
minutos = segundos % 3600 // 60
resto = segundos % 60
print(horas, "h", minutos, "min", resto, "s")
```

:::capo Precedencia
Python sigue el orden matemático: primero `**`, luego `*` `/` `//` `%`, y al final `+` `-`. Ante la duda, usa paréntesis: `(segundos + 59) // 60` no es lo mismo que `segundos + 59 // 60`.
:::

:::reto Minutos y segundos de una llamada
Una llamada duró `duracion = 754` segundos. Con `//` y `%` calcula:

- `minutos`: los minutos completos (12);
- `segundos`: los segundos que sobran (34);
- `minutos_facturables`: los minutos que se cobran, sabiendo que **todo minuto iniciado se cobra completo** (13).

Imprime `12 min 34 s`.

```pyreto
duracion = 754

# Calcula minutos, segundos y minutos_facturables

```

:::pista
`754 // 60` da los minutos completos y `754 % 60` lo que sobra. Para redondear hacia arriba sin `if`, suma 59 antes de dividir: `(duracion + 59) // 60`.
:::

```pyprueba
def prueba_minutos_y_segundos():
    """minutos = 12 y segundos = 34"""
    requiere("minutos", "segundos")
    igual(minutos, 12, "minutos")
    igual(segundos, 34, "segundos")


def prueba_facturables():
    """minutos_facturables = 13 (el minuto iniciado se cobra)"""
    requiere("minutos_facturables")
    igual(minutos_facturables, 13)


def prueba_imprime():
    """Imprime «12 min 34 s»"""
    assert "12 min 34 s" in salida, f"Se esperaba ver «12 min 34 s» y se imprimió: {salida!r}"
```

```pysolucion
duracion = 754

minutos = duracion // 60
segundos = duracion % 60
minutos_facturables = (duracion + 59) // 60

print(minutos, "min", segundos, "s")
```
:::

## Funciones numéricas útiles

```pyrun
import math

print(abs(-450))          # valor absoluto
print(max(0, 342 - 300))  # el mayor: nunca cobra exceso negativo
print(min(15.5, 10))      # el menor
print(math.ceil(15.131))  # redondea hacia ARRIBA (megas facturables)
print(math.floor(15.9))   # redondea hacia ABAJO
print(sum([120, 45, 300]))
```

`max(0, consumo - incluido)` es un patrón que verás en todo el curso: calcula el exceso sin que nunca sea negativo.

## El problema de float

Los `float` se guardan en binario y **la mayoría de los decimales no se pueden representar exactamente**. El error es diminuto, pero existe:

```pyrun
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(1.1 * 3)
```

En un cálculo aislado no importa. Pero en facturación sumas millones de valores, comparas totales y redondeas, y ahí esos errores aparecen.

## La trampa de round()

`round()` usa el **redondeo del banquero**: cuando el número termina exactamente en `.5`, redondea al **par** más cercano. En una factura, la regla habitual es que `.5` siempre sube.

```pyrun
print(round(2.5))     # 2   ← ¡no 3!
print(round(3.5))     # 4
print(round(28.5))    # 28  ← el IVA de una factura de 150
```

:::error Un error real de facturación
El IVA de un subtotal de $150 es exactamente $28,5. Con `round()` se cobran $28; con la regla comercial, $29. Un peso parece poco… hasta que lo multiplicas por un millón de facturas, y los totales no cuadran con la contabilidad.
:::

## Decimal: números para dinero

El módulo `decimal` de la biblioteca estándar representa los decimales **exactamente**, como en papel:

```pyrun
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))
print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))
```

:::error Crea los Decimal desde texto, no desde float
`Decimal(0.1)` copia el error del float. Usa siempre `Decimal("0.1")` o un entero, `Decimal(150)`:

```pyrun
from decimal import Decimal

print(Decimal(0.1))      # el float ya venía con error
print(Decimal("0.1"))    # exacto
```
:::

### Redondear con la regla comercial

`quantize()` redondea a la cantidad de decimales que indiques, con la regla que elijas. `ROUND_HALF_UP` es "0,5 sube":

```pyrun
from decimal import Decimal, ROUND_HALF_UP

IVA = Decimal("0.19")
subtotal = Decimal(150)

iva = subtotal * IVA
print(iva)
print(iva.quantize(Decimal("1"), rounding=ROUND_HALF_UP))      # a pesos enteros
print(iva.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))   # a centavos
```

`Decimal("1")` significa "sin decimales"; `Decimal("0.01")`, "con dos decimales".

### Una factura completa con Decimal

```pyrun
from decimal import Decimal, ROUND_HALF_UP

IVA = Decimal("0.19")
PESO = Decimal("1")

cargo_fijo = Decimal(35900)
valor_voz = Decimal(42 * 120)
descuento = Decimal(0)

subtotal = cargo_fijo + valor_voz - descuento
iva = (subtotal * IVA).quantize(PESO, rounding=ROUND_HALF_UP)
total = subtotal + iva

print(f"Subtotal: {subtotal}")
print(f"IVA:      {iva}")
print(f"Total:    {total}")
```

:::reto El IVA que sí cuadra
Una factura tiene `subtotal = Decimal(40940)`. Calcula con `Decimal`:

- `iva`: el 19 % del subtotal **redondeado al peso con la regla comercial** (debe dar `7779`, porque el valor exacto es 7778,6);
- `total`: subtotal más IVA.

Ojo: el 19 % debe ser exacto, así que créalo desde texto.

```pyreto
from decimal import Decimal, ROUND_HALF_UP

subtotal = Decimal(40940)

# Calcula iva y total

```

:::pista
`(subtotal * Decimal("0.19")).quantize(Decimal("1"), rounding=ROUND_HALF_UP)` redondea a pesos enteros con 0,5 hacia arriba.
:::

```pyprueba
from decimal import Decimal


def prueba_iva():
    """iva = Decimal('7779')"""
    requiere("iva")
    assert isinstance(iva, Decimal), f"iva debe ser Decimal, es {type(iva).__name__}"
    igual(iva, Decimal("7779"))
    igual(str(iva), "7779", "iva debe quedar sin decimales")


def prueba_total():
    """total = Decimal('48719')"""
    requiere("total")
    assert isinstance(total, Decimal), f"total debe ser Decimal, es {type(total).__name__}"
    igual(total, Decimal("48719"))


def prueba_iva_exacto():
    """Crea el 19 % desde texto, no desde float"""
    assert "Decimal(0.19)" not in codigo.replace(" ", ""), "Decimal(0.19) copia el error del float: usa Decimal(\"0.19\")"
```

```pysolucion
from decimal import Decimal, ROUND_HALF_UP

subtotal = Decimal(40940)

iva = (subtotal * Decimal("0.19")).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
total = subtotal + iva
print(iva, total)
```
:::

:::telco Las reglas del curso
En **Referencia → Datos del curso** está la regla de facturación: el IVA es el 19 % del subtotal **redondeado al peso más cercano (0,5 sube)**. Es exactamente `quantize(Decimal("1"), rounding=ROUND_HALF_UP)`.
:::

:::consejo ¿Siempre Decimal?
Para **dinero**, sí. Para **mediciones** (megas, segundos, promedios, estadísticas) `float` es perfecto y mucho más rápido. Pandas y NumPy trabajan con `float`; en esos módulos verás cómo mantener la precisión trabajando en pesos enteros.
:::
