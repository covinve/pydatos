## Pista 2

```sql
SELECT c.ciudad, COUNT(DISTINCT c.linea) AS lineas, SUM((v.duracion_seg + 59) / 60) AS minutos
FROM cdr v JOIN clientes c ON c.linea = v.linea_origen
WHERE v.tipo = 'VOZ' AND v.duracion_seg >= 0
GROUP BY c.ciudad
ORDER BY minutos DESC, c.ciudad
```

Para el top: `... WHERE c.ciudad = ? ... LIMIT ?` y `pd.read_sql(sql, con, params=(ciudad, n))`.

## Solución

```python
import sqlite3

import pandas as pd


def cargar(con):
    cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string", "linea_destino": "string"})
    clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string", "documento": "string"})
    cdr.to_sql("cdr", con, index=False, if_exists="replace")
    clientes.to_sql("clientes", con, index=False, if_exists="replace")
    return (con.execute("SELECT COUNT(*) FROM cdr").fetchone()[0],
            con.execute("SELECT COUNT(*) FROM clientes").fetchone()[0])


def minutos_por_ciudad(con):
    return pd.read_sql("""
        SELECT c.ciudad, COUNT(DISTINCT c.linea) AS lineas, SUM((v.duracion_seg + 59) / 60) AS minutos
        FROM cdr v
        JOIN clientes c ON c.linea = v.linea_origen
        WHERE v.tipo = 'VOZ' AND v.duracion_seg >= 0
        GROUP BY c.ciudad
        ORDER BY minutos DESC, c.ciudad
    """, con)


def top_lineas(con, ciudad, n):
    return pd.read_sql("""
        SELECT c.linea, c.nombre, SUM((v.duracion_seg + 59) / 60) AS minutos
        FROM cdr v
        JOIN clientes c ON c.linea = v.linea_origen
        WHERE v.tipo = 'VOZ' AND v.duracion_seg >= 0 AND c.ciudad = ?
        GROUP BY c.linea, c.nombre
        ORDER BY minutos DESC, c.linea
        LIMIT ?
    """, con, params=(ciudad, n))


con = sqlite3.connect(":memory:")
print(cargar(con))
print(minutos_por_ciudad(con).head())
```

## Explicación

Pandas y SQL se complementan: Pandas lee y limpia archivos con comodidad; la base de datos guarda, cruza y filtra. `read_sql` devuelve directamente un DataFrame listo para graficar o exportar.

Fíjate en que la división `(duracion_seg + 59) / 60` en SQLite es **entera** porque los dos operandos son enteros, igual que `//` en Python. En PostgreSQL también; pero si una columna fuera decimal, el resultado tendría decimales. Cuando quieras ser explícito y portable, usa `CAST(... AS INTEGER)`.

`LIMIT ?` también acepta parámetros: así `n` nunca se pega en el texto.
