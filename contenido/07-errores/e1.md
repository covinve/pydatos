## Enunciado

Los valores en pesos llegan de fuentes distintas con formatos distintos. Escribe:

1. `a_entero(texto, defecto=None)` → convierte el texto a `int` (quitando espacios). Si no se puede, devuelve `defecto`. Acepta signo negativo (`"-45"`).
2. `a_pesos(texto)` → convierte a `Decimal` valores escritos en formato colombiano o con símbolo de moneda:

```python
a_pesos("48719")          # Decimal("48719")
a_pesos("$ 48.719")       # Decimal("48719")
a_pesos("1.234.567,50")   # Decimal("1234567.50")
a_pesos("-5.000")         # Decimal("-5000")
a_pesos("  $1.234,5 ")    # Decimal("1234.5")
```

   Si el texto no es un valor válido (vacío, letras, varias comas), lanza `ValueError` con un mensaje que **incluya el texto original entre comillas**, por ejemplo: `Valor en pesos inválido: 'abc'`.

Usa `try/except` (estilo "pedir perdón") en lugar de revisar cada carácter.

## Código inicial

```python
from decimal import Decimal, InvalidOperation


def a_entero(texto, defecto=None):
    pass


def a_pesos(texto):
    pass


print(a_entero("125"), a_entero("abc", 0))
print(a_pesos("$ 1.234.567,50"))
```

## Pista 1

`a_entero` es el patrón EAFP de la lección 2:

```python
try:
    return int(texto.strip())
except ValueError:
    return defecto
```

Para `a_pesos`, limpia primero: quita espacios y `$`, borra los puntos de miles y cambia la coma decimal por punto. Luego intenta `Decimal(limpio)`.

## Pista 2

`Decimal("abc")` no lanza `ValueError` sino `decimal.InvalidOperation`. Atrápala y lanza tu propio `ValueError`, encadenado con `from`:

```python
try:
    return Decimal(limpio)
except InvalidOperation as error:
    raise ValueError(f"Valor en pesos inválido: {texto!r}") from error
```

`"1,2,3"` tiene dos comas: después de reemplazarlas quedaría `"1.2.3"`, que `Decimal` también rechaza. ¡Deja que `Decimal` decida!

## Solución

```python
from decimal import Decimal, InvalidOperation


def a_entero(texto, defecto=None):
    try:
        return int(texto.strip())
    except ValueError:
        return defecto


def a_pesos(texto):
    limpio = texto.strip().replace("$", "").replace(" ", "").replace(".", "").replace(",", ".")
    try:
        return Decimal(limpio)
    except InvalidOperation as error:
        raise ValueError(f"Valor en pesos inválido: {texto!r}") from error


print(a_entero("125"), a_entero("abc", 0))
print(a_pesos("$ 1.234.567,50"))
```

## Explicación

Las dos funciones delegan la validación a quien mejor la sabe hacer: `int()` y `Decimal()`. Revisar a mano cada carácter sería más largo y casi seguro olvidaría algún caso (¿y el signo?, ¿y los espacios internos?).

Fíjate en las dos estrategias distintas ante un dato malo:

- **`a_entero` devuelve un valor por defecto.** Útil cuando el dato malo es esperable y tienes un buen reemplazo.
- **`a_pesos` lanza un error.** Un valor monetario ilegible no debe convertirse silenciosamente en cero: quien llama decide qué hacer.

`raise ... from error` transforma una excepción técnica (`InvalidOperation`) en una que el resto del programa espera (`ValueError`) sin perder el detalle.
