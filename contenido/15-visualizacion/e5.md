## Solución

```python
import matplotlib.pyplot as plt
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
DIAS = ["Lun", "Mar", "Mié", "Jue", "Vie", "Sáb", "Dom"]


def mapa_de_calor(cdr):
    inicio = pd.to_datetime(cdr["fecha_inicio"], format="%Y-%m-%d %H:%M:%S", errors="coerce")
    voz = inicio[(cdr["tipo"] == "VOZ") & inicio.notna()]
    matriz = pd.crosstab(voz.dt.dayofweek, voz.dt.hour).reindex(index=range(7), columns=range(24), fill_value=0)
    fig, ax = plt.subplots(figsize=(10, 3.2))
    imagen = ax.imshow(matriz.to_numpy(), aspect="auto", cmap="viridis")
    ax.set_yticks(range(7), DIAS)
    ax.set_xticks(range(0, 24, 2))
    ax.set_xlabel("Hora del día")
    ax.set_title("Llamadas de voz por día y hora")
    fig.colorbar(imagen, ax=ax, label="Llamadas")
    return fig


fig = mapa_de_calor(cdr)
```

## Explicación

Un mapa de calor muestra 168 números (7 × 24) en una imagen que se entiende de un vistazo: las horas pico, la caída de la madrugada y si el fin de semana se comporta distinto.

`aspect="auto"` deja que las celdas sean rectangulares para llenar el ancho; sin él, `imshow` las haría cuadradas y el gráfico quedaría diminuto. Las paletas como `viridis` están diseñadas para que la intensidad se perciba bien, incluso por personas con daltonismo o impresas en blanco y negro.
