## Solución

```python
import polars as pl


def minutos_por_destino(ruta):
    tarifa = (
        pl.when(pl.col("destino") == "LOCAL").then(100)
        .when(pl.col("destino") == "NACIONAL").then(120)
        .otherwise(950)
    )
    return (
        pl.read_csv(ruta, separator="|", schema_overrides={"linea_origen": pl.String, "linea_destino": pl.String})
        .filter((pl.col("tipo") == "VOZ") & (pl.col("duracion_seg") >= 0))
        .with_columns(minutos=(pl.col("duracion_seg") + 59) // 60, tarifa=tarifa)
        .group_by("destino")
        .agg(
            llamadas=pl.len(),
            minutos=pl.col("minutos").sum(),
            valor=(pl.col("minutos") * pl.col("tarifa")).sum(),
        )
        .sort("destino")
    )


print(minutos_por_destino("cdr.csv"))
```

## Explicación

En Polars todo es una **expresión** que el motor ejecuta en paralelo. `tarifa` se define una vez como expresión (sin calcular nada) y se usa dentro de `with_columns`. Dentro de `agg`, `(pl.col("minutos") * pl.col("tarifa")).sum()` multiplica y suma por grupo en una sola expresión.

Comparado con Pandas, Polars obliga a ser explícito: no hay índice, no hay modificación en el lugar, y cada paso devuelve un DataFrame nuevo. Al principio cuesta un poco; después, el código se vuelve muy predecible.
