## Enunciado

Un registro con una contraseña adentro es una filtración. Construye la protección en dos niveles:

1. `enmascarar(texto, secretos=())` devuelve el texto con:
   - cada valor de `secretos` (no vacío) reemplazado por `"***"`;
   - la contraseña de cualquier **URL de conexión** (`esquema://usuario:CLAVE@servidor...`) reemplazada: `postgresql://carlos:***@localhost:5432/fact`;
   - el valor después de `Bearer ` reemplazado: `Authorization: Bearer ***`;
   - los valores de `password=`, `clave=`, `token=` o `api_key=` (sin distinguir mayúsculas, hasta el siguiente espacio, `&` o `;`) reemplazados: `token=***`.
2. `FiltroSecretos(secretos)`: un `logging.Filter` que aplica `enmascarar` al mensaje **ya formateado** de cada registro (incluidos sus argumentos `%s`) y deja pasar el registro (devuelve `True`).

## Código inicial

```python
import logging
import re


def enmascarar(texto, secretos=()):
    pass


class FiltroSecretos(logging.Filter):
    pass

```

## Pruebas

```python
import io
import logging


def prueba_secretos_explicitos():
    """Valores conocidos"""
    requiere("enmascarar")
    igual(enmascarar("el token es k9z-11 y otra vez k9z-11", ["k9z-11"]), "el token es *** y otra vez ***")
    igual(enmascarar("nada que ocultar", ["", "xyz"]), "nada que ocultar", "Un secreto vacío no debe reemplazar nada")


def prueba_urls():
    """Contraseñas en URL de conexión"""
    igual(enmascarar("Conectando a postgresql+psycopg://carlos:Sup3r#Clave@db.local:5432/fact ..."),
          "Conectando a postgresql+psycopg://carlos:***@db.local:5432/fact ...")
    igual(enmascarar("sqlite:///telco.db"), "sqlite:///telco.db", "Sin contraseña no hay nada que ocultar")
    igual(enmascarar("https://api.telco.example/v1"), "https://api.telco.example/v1")


def prueba_bearer_y_parametros():
    """Tokens en cabeceras y parámetros"""
    igual(enmascarar("Authorization: Bearer eyJhbGciOi.abc.def"), "Authorization: Bearer ***")
    igual(enmascarar("GET /x?periodo=202609&token=abc123&y=2"), "GET /x?periodo=202609&token=***&y=2")
    igual(enmascarar("PASSWORD=hola; Clave=chao api_key=k1"), "PASSWORD=***; Clave=*** api_key=***")


def prueba_filtro_en_logging():
    """El filtro protege el registro completo"""
    requiere("FiltroSecretos")
    salida = io.StringIO()
    logger = logging.getLogger("prueba_secretos")
    logger.handlers.clear()
    manejador = logging.StreamHandler(salida)
    manejador.addFilter(FiltroSecretos(["k9z-11"]))
    logger.addHandler(manejador)
    logger.setLevel(logging.INFO)
    logger.propagate = False
    logger.info("Usando %s con token %s", "postgresql://u:pw@h/db", "k9z-11")
    logger.warning("Bearer xyz falló")
    texto = salida.getvalue()
    igual(texto, "Usando postgresql://u:***@h/db con token ***\nBearer *** falló\n")
```

## Pista 1

Cada patrón es una expresión regular con grupos para lo que **se conserva**:

```python
URL = re.compile(r"(\w[\w+.-]*://[^:/\s@]+:)[^@\s]+(@)")
texto = URL.sub(r"\1***\2", texto)
```

`[^@\s]+` es "todo hasta la arroba": la contraseña puede tener `#`, `:` o `!`.

## Pista 2

En el filtro, `record.getMessage()` arma el mensaje con sus argumentos. Reemplaza el mensaje y borra los argumentos para que el manejador no vuelva a formatear:

```python
def filter(self, record):
    record.msg = enmascarar(record.getMessage(), self.secretos)
    record.args = ()
    return True
```

## Solución

```python
import logging
import re

URL = re.compile(r"(\w[\w+.-]*://[^:/\s@]+:)[^@\s]+(@)")
BEARER = re.compile(r"(Bearer\s+)\S+")
PARAMETRO = re.compile(r"((?:password|clave|token|api_key)=)[^\s&;]+", re.IGNORECASE)


def enmascarar(texto, secretos=()):
    for secreto in secretos:
        if secreto:
            texto = texto.replace(secreto, "***")
    texto = URL.sub(r"\1***\2", texto)
    texto = BEARER.sub(r"\1***", texto)
    return PARAMETRO.sub(r"\1***", texto)


class FiltroSecretos(logging.Filter):
    def __init__(self, secretos=()):
        super().__init__()
        self.secretos = list(secretos)

    def filter(self, record):
        record.msg = enmascarar(record.getMessage(), self.secretos)
        record.args = ()
        return True


print(enmascarar("Conectando a postgresql://carlos:Sup3r#Clave@db.local:5432/fact"))
print(enmascarar("GET /tarifas?periodo=202609&token=abc123&x=1"))
```

## Explicación

Un filtro en el **manejador** protege todo lo que pasa por él, venga de tu código o de una librería que registra la URL de conexión por su cuenta (SQLAlchemy, con `echo=True`, imprime cada consulta; requests registra las URL con sus parámetros en nivel DEBUG).

Los secretos explícitos (los valores reales de tu configuración, como `config.api_token.get_secret_value()`) son la defensa más fuerte: los patrones genéricos atrapan los formatos comunes, pero un token que aparece "suelto" en un mensaje solo se reconoce si sabes cuál es.

Aplicar el filtro sobre `record.getMessage()` (el mensaje con los `%s` ya reemplazados) es clave: con `logger.info("token %s", token)`, el secreto no está en `record.msg` sino en `record.args`. Filtrar solo `msg` dejaría pasar justo el caso más común.

Esto **complementa**, no reemplaza, la regla principal: no registres secretos. Es el cinturón de seguridad para cuando, un viernes con prisa, alguien escriba `logger.debug(f"config: {config}")`.
