Todo lo que hiciste hasta ahora trabajaba con datos escritos en el código. En la vida real los datos están en **archivos**. Esta lección te enseña a leerlos de la forma correcta, que es la única que funciona con archivos de 20 GB.

## Abrir un archivo con `with`

```pyrun
# Primero creamos un archivo de ejemplo
with open("cdr_ejemplo.csv", "w", encoding="utf-8") as archivo:
    archivo.write("cdr_id|tipo|duracion_seg\n")
    archivo.write("1|VOZ|125\n")
    archivo.write("2|SMS|0\n")
    archivo.write("3|DATOS|900\n")

# Y lo leemos
with open("cdr_ejemplo.csv", encoding="utf-8") as archivo:
    contenido = archivo.read()

print(contenido)
```

`with` abre el archivo y **lo cierra automáticamente** al salir del bloque, incluso si ocurre un error. Siempre usa `with`.

| Modo | Significado |
|---|---|
| `"r"` | Leer (por defecto). Error si no existe. |
| `"w"` | Escribir. **Borra** el contenido anterior si existe. |
| `"a"` | Agregar al final (*append*). |
| `"x"` | Crear. Error si ya existe (protege contra sobrescribir). |
| `"rb"`, `"wb"` | Leer o escribir **bytes** (sin decodificar). |

:::error Indica siempre el encoding
Si no escribes `encoding=`, Python usa el de tu sistema operativo: en Windows suele ser `cp1252`, en Linux `utf-8`. El mismo script daría resultados distintos en tu PC y en un servidor. Escribe siempre `encoding="utf-8"` (o el que corresponda).
:::

## Leer línea por línea: la regla de oro

`archivo.read()` carga **todo el archivo** en memoria. Con un archivo de 20 GB y 16 GB de RAM, eso termina mal. La forma correcta es **recorrer el archivo** con `for`: Python lee una línea, la procesas, la suelta y lee la siguiente.

```pyrun
with open("cdr_ejemplo.csv", "w", encoding="utf-8") as f:
    f.write("cdr_id|tipo|duracion_seg\n1|VOZ|125\n2|SMS|0\n3|DATOS|900\n4|VOZ|61\n")

total_minutos = 0
with open("cdr_ejemplo.csv", encoding="utf-8") as archivo:
    encabezado = next(archivo)               # consume la primera línea
    for numero, linea in enumerate(archivo, start=2):
        cdr_id, tipo, duracion = linea.rstrip("\n").split("|")
        if tipo == "VOZ":
            total_minutos += (int(duracion) + 59) // 60

print("Encabezado:", encabezado.strip())
print("Minutos de voz:", total_minutos)
```

:::reto Recorre el archivo de verdad
En esta página tienes a mano `cdr.csv`, una muestra de 4.064 CDR separados por `|`, con el encabezado:

`cdr_id|linea_origen|linea_destino|tipo|destino|fecha_inicio|duracion_seg|mb|celda`

Recórrelo **línea por línea** (sin `read()` ni `readlines()`) y calcula:

- `registros`: cuántos registros tiene, **sin** contar el encabezado;
- `mb_datos`: el total de megas (`mb`, la columna 8) de los registros de tipo `DATOS`, redondeado a 2 decimales.

```pyreto
registros = 0
mb_datos = 0.0

# Abre cdr.csv con with y encoding, salta el encabezado y recorre

print(registros, mb_datos)
```

:::pista
`with open("cdr.csv", encoding="utf-8") as archivo:` y `next(archivo)` para saltar el encabezado. Dentro del `for`, `campos = linea.rstrip("\n").split("|")`: el tipo es `campos[3]` y las megas `float(campos[7])`. Redondea al final con `round(mb_datos, 2)`.
:::

```pyprueba
def _esperado():
    total = 0
    mb = 0.0
    with open("cdr.csv", encoding="utf-8") as f:
        next(f)
        for linea in f:
            c = linea.rstrip("\n").split("|")
            total += 1
            if c[3] == "DATOS":
                mb += float(c[7])
    return total, round(mb, 2)


def prueba_registros():
    """registros cuenta las filas sin el encabezado"""
    requiere("registros")
    igual(registros, _esperado()[0])


def prueba_mb():
    """mb_datos suma las megas de DATOS"""
    requiere("mb_datos")
    cerca(mb_datos, _esperado()[1], 0.01)


def prueba_linea_por_linea():
    """Recorre el archivo sin cargarlo entero"""
    assert ".read()" not in codigo and "readlines" not in codigo, "No uses read() ni readlines(): recorre con for linea in archivo"
    assert "with open" in codigo, "Abre el archivo con with open(...)"
```

```pysolucion
registros = 0
mb_datos = 0.0

with open("cdr.csv", encoding="utf-8") as archivo:
    next(archivo)
    for linea in archivo:
        campos = linea.rstrip("\n").split("|")
        registros += 1
        if campos[3] == "DATOS":
            mb_datos += float(campos[7])

mb_datos = round(mb_datos, 2)
print(registros, mb_datos)
```
:::

:::telco 20 GB con 16 GB de RAM
Este es exactamente el problema de tus archivos de facturación. Con `for linea in archivo` puedes procesar 20 GB en un computador de 16 GB, siempre que lo que acumules (contadores, sumas por línea) sea pequeño. En el ejercicio 4 procesarás 1 GB así.
:::

## Escribir archivos

```pyrun
errores = [(2, "duracion_negativa"), (7, "tipo_desconocido")]

with open("errores.txt", "w", encoding="utf-8") as salida:
    salida.write("linea|motivo\n")
    for numero, motivo in errores:
        salida.write(f"{numero}|{motivo}\n")
    print("También puedo usar print", file=salida)

with open("errores.txt", encoding="utf-8") as f:
    print(f.read())
```

`write` no agrega el salto de línea: escribe `\n` tú mismo. `print(..., file=salida)` sí lo agrega.

```pyprueba
from pathlib import Path


def prueba_archivo():
    """El archivo tiene el encabezado y las tres filas"""
    ruta = Path("resumen_tipos.txt")
    assert ruta.exists(), "No se encontró resumen_tipos.txt"
    igual(ruta.read_text(encoding="utf-8").splitlines(), ["tipo|registros", "VOZ|1217", "DATOS|2647", "SMS|189"])


def prueba_fin_de_linea():
    """Cada línea termina con salto de línea"""
    assert Path("resumen_tipos.txt").read_text(encoding="utf-8").endswith("\n"), "La última fila también debe terminar en \\n"
```

## pathlib: rutas modernas

En vez de pegar textos (`"datos" + "\\" + "cdr.csv"`), usa `Path`: funciona igual en Windows, Linux y Mac.

```pyrun
from pathlib import Path

carpeta = Path("datos") / "10MB"
archivo = carpeta / "cdr.csv"

print(archivo)
print(archivo.name, archivo.stem, archivo.suffix)
print(archivo.parent)

Path("salidas").mkdir(exist_ok=True)
ruta = Path("salidas") / "resumen.txt"
ruta.write_text("Total: 48.719\n", encoding="utf-8")   # atajo para archivos pequeños
print(ruta.exists(), ruta.read_text(encoding="utf-8"))

for p in Path(".").glob("*.txt"):
    print("Encontrado:", p, p.stat().st_size, "bytes")
```

| Operación | pathlib |
|---|---|
| Unir rutas | `Path("datos") / "10MB" / "cdr.csv"` |
| ¿Existe? | `ruta.exists()`, `ruta.is_file()`, `ruta.is_dir()` |
| Crear carpeta | `ruta.mkdir(parents=True, exist_ok=True)` |
| Listar archivos | `carpeta.iterdir()`, `carpeta.glob("*.csv")`, `carpeta.rglob("*.csv")` (recursivo) |
| Tamaño | `ruta.stat().st_size` |
| Leer/escribir pequeño | `ruta.read_text(encoding=...)`, `ruta.write_text(...)` |
| Abrir para recorrer | `with ruta.open(encoding=...) as f:` |

:::reto Rutas con pathlib

```pyprueba
from pathlib import Path


def prueba_ruta():
    """ruta apunta a reportes/2026-09/consumo.txt"""
    requiere("ruta")
    assert isinstance(ruta, Path), f"ruta debe ser un Path, es {type(ruta).__name__}"
    igual(ruta, Path("reportes") / "2026-09" / "consumo.txt")


def prueba_contenido():
    """El archivo existe y tiene el texto pedido"""
    archivo = Path("reportes") / "2026-09" / "consumo.txt"
    assert archivo.exists(), "No existe reportes/2026-09/consumo.txt"
    igual(archivo.read_text(encoding="utf-8").strip(), "Minutos: 1560")


def prueba_nombre_base():
    """nombre_base = «consumo»"""
    requiere("nombre_base")
    igual(nombre_base, "consumo")


def prueba_sin_sumar_textos():
    """Une las rutas con /"""
    assert '"/' not in codigo and "+" not in codigo, "Une las partes de la ruta con el operador / de Path, no con +"
```

:::consejo Rutas relativas a tu script
`Path("datos")` es relativa a la carpeta **desde donde ejecutas** el script, no a donde está el archivo `.py`. Para rutas relativas al script usa `Path(__file__).parent / "datos"`.
:::

## Cuestionario

? Tienes un archivo de 20 GB y 16 GB de RAM. ¿Cuál es la forma correcta de procesarlo?
- [ ] `datos = archivo.read()`
- [ ] `lineas = archivo.readlines()`
- [x] `for linea in archivo:`
- [ ] Comprar más RAM
> Recorrer el archivo con `for` lee una línea a la vez, así la memoria usada no depende del tamaño del archivo.

? ¿Qué pasa si abres con modo `"w"` un archivo que ya existe?
- [ ] Se agrega el texto al final
- [x] Se borra su contenido y se escribe desde cero
- [ ] Python da un error
- [ ] Se crea una copia
> `"w"` trunca el archivo. Para agregar al final usa `"a"`; para evitar sobrescribir por error, `"x"`.

? ¿Por qué conviene escribir siempre `encoding="utf-8"`?
- [ ] Porque es más rápido
- [x] Porque sin indicarlo, Python usa el encoding del sistema y el mismo script puede comportarse distinto en otro computador
- [ ] Porque UTF-8 ocupa menos espacio
- [ ] No hace falta nunca
> El encoding por defecto depende del sistema operativo. Ser explícito hace tu programa reproducible.
