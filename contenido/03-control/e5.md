## Enunciado

El plan empresarial cobra los minutos adicionales con una **tarifa escalonada**: entre más minutos, más barato cada minuto, pero **cada tramo se cobra a su propia tarifa** (como los impuestos por tramos):

| Tramo | Minutos adicionales | Tarifa por minuto |
|---|---|---|
| 1 | Los primeros 100 | $120 |
| 2 | Del 101 al 300 (200 minutos) | $100 |
| 3 | Del 301 en adelante | $80 |

Ejemplo con 400 minutos adicionales: 100 × 120 + 200 × 100 + 100 × 80 = **$40.000**.

Escribe `valor_escalonado(minutos, tramos)` donde `tramos` es una lista de pares `(tamaño_del_tramo, tarifa)`. El último tramo tiene tamaño `None`, que significa "sin límite":

```python
TRAMOS = [(100, 120), (200, 100), (None, 80)]

valor_escalonado(50, TRAMOS)     # 6000
valor_escalonado(150, TRAMOS)    # 17000   → 100×120 + 50×100
valor_escalonado(400, TRAMOS)    # 40000
valor_escalonado(0, TRAMOS)      # 0
```

La función debe funcionar con **cualquier** lista de tramos, no solo con esta.

## Código inicial

TRAMOS = [(100, 120), (200, 100), (None, 80)]


def valor_escalonado(minutos, tramos):
    pass


print(valor_escalonado(400, TRAMOS))

## Pista 1

Lleva una variable con los **minutos que faltan por cobrar** y recorre los tramos. En cada tramo, cobra lo que quepa en él y descuéntalo de lo que falta:

```python
restantes = minutos
total = 0
for tamano, tarifa in tramos:
    ...
```

## Pista 2

En cada tramo, los minutos que se cobran son `min(restantes, tamano)`, salvo que el tamaño sea `None`: entonces se cobran todos los restantes. Cuando `restantes` llegue a 0, puedes salir con `break`.

```python
en_este_tramo = restantes if tamano is None else min(restantes, tamano)
total += en_este_tramo * tarifa
restantes -= en_este_tramo
```

## Solución

```python
TRAMOS = [(100, 120), (200, 100), (None, 80)]


def valor_escalonado(minutos, tramos):
    restantes = minutos
    total = 0
    for tamano, tarifa in tramos:
        if restantes <= 0:
            break
        en_este_tramo = restantes if tamano is None else min(restantes, tamano)
        total += en_este_tramo * tarifa
        restantes -= en_este_tramo
    return total


print(valor_escalonado(400, TRAMOS))
```

## Explicación

Este es el patrón **acumular** con un giro: además del total, se acumula lo que *falta*. Cada vuelta "consume" una parte de los minutos.

Sigue el caso de 400 minutos:

| Tramo | Restantes antes | Se cobran | Valor | Restantes después |
|---|---|---|---|---|
| (100, 120) | 400 | 100 | 12.000 | 300 |
| (200, 100) | 300 | 200 | 20.000 | 100 |
| (None, 80) | 100 | 100 | 8.000 | 0 |

Lo más importante del ejercicio: **la tabla de tramos es un dato, no código**. Si comercial cambia las tarifas o agrega un cuarto tramo, solo cambia la lista `TRAMOS`; la función sigue igual. Separar las reglas (datos) de la lógica (código) es una de las ideas más valiosas del curso.
