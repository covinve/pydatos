## Enunciado

Construye un detector de líneas sospechosas en `ejercicios/m23-e7/anomalias.py`:

1. `caracteristicas(carpeta)`: el **perfil** de cada línea (llamadas, minutos, porcentaje internacional, porcentaje nocturno, MB y SMS), calculado sobre los CDR válidos.
2. `puntuar(df)`: un puntaje de anomalía con **Isolation Forest** sobre las características en escala logarítmica.
3. `sospechosas(carpeta, n)`: el top *n* para revisar.

El docstring define cada columna con precisión.

¿Cómo se prueba un detector si no sabemos cuáles son las anomalías reales? **Plantándolas**: la prueba copia los datos y le agrega a tres clientes residenciales comportamientos típicos de problemas reales (80 llamadas internacionales de media hora a las 2 de la madrugada, 1,8 TB de datos, 600 SMS nocturnos). Las tres deben aparecer en tu top 6 entre 64 líneas.

## Pista 1

Con DuckDB, el perfil sale en una consulta (o hazlo con Pandas, como prefieras):

```sql
WITH cdr AS (SELECT *, ROW_NUMBER() OVER () AS rn FROM read_csv('...', delim='|', header=true, all_varchar=true)),
marcado AS (SELECT *, ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY rn) AS aparicion FROM cdr),
validos AS (
    SELECT linea_origen AS linea, tipo, destino, CAST(duracion_seg AS INTEGER) AS seg, CAST(mb AS DOUBLE) AS mb,
           HOUR(TRY_STRPTIME(fecha_inicio, '%Y-%m-%d %H:%M:%S')) AS hora
    FROM marcado
    WHERE aparicion = 1 AND linea_origen IN (SELECT linea FROM clientes) AND tipo IN ('VOZ', 'SMS', 'DATOS')
      AND CAST(duracion_seg AS INTEGER) >= 0 AND TRY_STRPTIME(fecha_inicio, '%Y-%m-%d %H:%M:%S') IS NOT NULL
)
SELECT linea, COUNT(*) FILTER (WHERE tipo = 'VOZ') AS llamadas, ...
FROM validos GROUP BY linea
```

Después, `reindex` con todas las líneas de clientes y `fillna(0)` para los que no tienen consumo.

## Solución

```python anomalias.py
"""Ejercicio m23-e7: líneas sospechosas con Isolation Forest.

Uso:
    python ejercicios/m23-e7/anomalias.py datos/100MB
"""

from __future__ import annotations

import sys
from pathlib import Path

import duckdb
import numpy as np
import pandas as pd
from sklearn.ensemble import IsolationForest

COLUMNAS = ["llamadas", "minutos", "pct_internacional", "pct_nocturno", "mb", "sms"]
FORMATO = "%Y-%m-%d %H:%M:%S"


def caracteristicas(carpeta: Path) -> pd.DataFrame:
    carpeta = Path(carpeta)
    cdr = (carpeta / "cdr.csv").as_posix()
    clientes = pd.read_csv(carpeta / "clientes.csv", encoding="latin-1", dtype={"linea": str})
    con = duckdb.connect()
    con.register("clientes", clientes[["linea"]])
    perfil = con.sql(f"""
        WITH cdr AS (
            SELECT *, ROW_NUMBER() OVER () AS rn FROM read_csv('{cdr}', delim='|', header=true, all_varchar=true)
        ),
        marcado AS (
            SELECT *, ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY rn) AS aparicion FROM cdr
        ),
        validos AS (
            SELECT linea_origen AS linea, tipo, destino,
                   CAST(duracion_seg AS INTEGER) AS seg, CAST(mb AS DOUBLE) AS mb,
                   HOUR(TRY_STRPTIME(fecha_inicio, '{FORMATO}')) AS hora
            FROM marcado
            WHERE aparicion = 1
              AND linea_origen IN (SELECT linea FROM clientes)
              AND tipo IN ('VOZ', 'SMS', 'DATOS')
              AND CAST(duracion_seg AS INTEGER) >= 0
              AND TRY_STRPTIME(fecha_inicio, '{FORMATO}') IS NOT NULL
        )
        SELECT linea,
               COUNT(*) FILTER (WHERE tipo = 'VOZ') AS llamadas,
               COALESCE(SUM((seg + 59) // 60) FILTER (WHERE tipo = 'VOZ'), 0) AS minutos,
               COALESCE(SUM((seg + 59) // 60) FILTER (WHERE tipo = 'VOZ' AND destino = 'INTERNACIONAL'), 0) AS min_int,
               COUNT(*) FILTER (WHERE tipo = 'VOZ' AND hora < 6) AS nocturnas,
               COALESCE(SUM(mb) FILTER (WHERE tipo = 'DATOS'), 0) AS mb,
               COUNT(*) FILTER (WHERE tipo = 'SMS') AS sms
        FROM validos
        GROUP BY linea
    """).df().set_index("linea")
    perfil = perfil.reindex(sorted(clientes["linea"])).fillna(0)
    perfil.index.name = "linea"
    minutos = perfil["minutos"].replace(0, np.nan)
    llamadas = perfil["llamadas"].replace(0, np.nan)
    perfil["pct_internacional"] = (perfil["min_int"] / minutos).fillna(0).round(4)
    perfil["pct_nocturno"] = (perfil["nocturnas"] / llamadas).fillna(0).round(4)
    perfil["mb"] = perfil["mb"].round(3)
    for columna in ("llamadas", "minutos", "sms"):
        perfil[columna] = perfil[columna].astype(int)
    return perfil[COLUMNAS]


def puntuar(df: pd.DataFrame, semilla: int = 0) -> pd.Series:
    X = np.log1p(df[COLUMNAS])
    modelo = IsolationForest(n_estimators=300, random_state=semilla).fit(X)
    return pd.Series(-modelo.score_samples(X), index=df.index, name="puntaje")


def sospechosas(carpeta: Path, n: int = 10, semilla: int = 0) -> pd.DataFrame:
    df = caracteristicas(carpeta)
    return df.assign(puntaje=puntuar(df, semilla)).nlargest(n, "puntaje")


if __name__ == "__main__":
    print(sospechosas(Path(sys.argv[1])))
```

## Explicación

Isolation Forest no necesita ejemplos de fraude para aprender (es **no supervisado**): solo busca lo que se aparta del resto. Por eso es útil al empezar, cuando nadie ha etiquetado casos. Cada anomalía plantada era rara por una combinación distinta: la SIM clonada no tenía un volumen extraño de llamadas, sino un porcentaje internacional y nocturno altísimo; la de SMS, un conteo extremo; la de datos, un consumo enorme. Un solo modelo las encontró a las tres.

Las decisiones de diseño que más pesan en el resultado:

- **El perfil** (qué características calculas) importa más que el algoritmo. Porcentajes (internacional, nocturno) capturan comportamientos que los totales esconden.
- **La escala**: `log1p` comprime los totales enormes y deja todas las variables comparables.
- **Una fila por cliente, incluidos los inactivos**: una línea sin ningún consumo también puede ser interesante (servicio caído, CDR que no llegan).

En la operación real, el top se revisa cada día y el resultado de la revisión ("era fraude", "era un cliente que viajó") se guarda. Con el tiempo, esas etiquetas permiten pasar a un modelo **supervisado** como el del ejercicio 6, que aprende qué tipo de rareza importa.
