**DuckDB** es una base de datos analítica que vive dentro de tu programa: no hay servidor que instalar. Su superpoder: hacer **SQL directamente sobre archivos**.

```pyrun
import duckdb

print(duckdb.sql("""
    SELECT tipo, COUNT(*) AS registros, ROUND(AVG(duracion_seg), 1) AS duracion_promedio
    FROM read_csv('cdr.csv', delim='|', header=true)
    GROUP BY tipo
    ORDER BY registros DESC
"""))
```

## SQL en cinco minutos

Si nunca escribiste SQL, esta es la estructura de una consulta (el orden de las cláusulas es fijo):

```sql
SELECT   columnas o cálculos          -- qué devolver
FROM     tabla o archivo               -- de dónde
WHERE    condición sobre las filas     -- filtrar antes de agrupar
GROUP BY columnas                      -- agrupar
HAVING   condición sobre los grupos    -- filtrar después de agrupar
ORDER BY columnas                      -- ordenar
LIMIT    n                             -- cuántas filas
```

| Pandas | SQL |
|---|---|
| `df[df["tipo"] == "VOZ"]` | `WHERE tipo = 'VOZ'` |
| `df.groupby("linea")["dur"].sum()` | `SELECT linea, SUM(dur) ... GROUP BY linea` |
| `df.merge(clientes, on="linea")` | `JOIN clientes USING (linea)` |
| `df.sort_values("dur", ascending=False).head(5)` | `ORDER BY dur DESC LIMIT 5` |
| `np.where(cond, a, b)` | `CASE WHEN cond THEN a ELSE b END` |
| `df["x"].isin([...])` | `x IN (...)` |

```pyprueba
import pandas as pd


def prueba_resumen():
    """Una fila por tipo, de más a menos registros"""
    requiere("resumen")
    datos = pd.read_csv("cdr.csv", sep="|", keep_default_na=False)
    esperado = datos.groupby("tipo").agg(registros=("cdr_id", "size"), mb_total=("mb", "sum"))
    igual(sorted(str(t) for t in resumen["tipo"]), sorted(esperado.index), "tipos")
    igual([int(x) for x in resumen["registros"]], sorted(esperado["registros"].tolist(), reverse=True), "registros en orden")
    for tipo, mb in zip(resumen["tipo"], resumen["mb_total"]):
        cerca(float(mb), round(float(esperado.loc[tipo, "mb_total"]), 2), 0.011, f"mb_total de {tipo}")
```

## Leer archivos

```pyrun
import duckdb

con = duckdb.connect()   # base de datos en memoria
con.sql("""
    CREATE VIEW cdr AS
    SELECT * FROM read_csv('cdr.csv', delim='|', header=true,
                           types={'linea_origen': 'VARCHAR', 'linea_destino': 'VARCHAR'})
""")
con.sql("""
    CREATE VIEW clientes AS
    SELECT * FROM read_csv('clientes.csv', encoding='latin-1', header=true, types={'linea': 'VARCHAR'})
""")
print(con.sql("SELECT COUNT(*) AS registros FROM cdr").fetchone())
print(con.sql("DESCRIBE cdr").df()[["column_name", "column_type"]])
```

Una **vista** (`VIEW`) es una consulta con nombre: no copia datos, solo los describe. Cada vez que la usas, DuckDB lee el archivo de nuevo (solo las columnas necesarias).

```pyprueba
import pandas as pd


def prueba_intensas():
```

## Cruces

```pyrun
import duckdb

print(duckdb.sql("""
    WITH voz AS (
        SELECT linea_origen, (duracion_seg + 59) // 60 AS minutos
        FROM read_csv('cdr.csv', delim='|', header=true, types={'linea_origen': 'VARCHAR'})
        WHERE tipo = 'VOZ' AND duracion_seg >= 0
    ),
    clientes AS (
        SELECT * FROM read_csv('clientes.csv', encoding='latin-1', header=true, types={'linea': 'VARCHAR'})
    )
    SELECT c.region, COUNT(*) AS llamadas, SUM(v.minutos) AS minutos
    FROM voz v
    JOIN clientes c ON c.linea = v.linea_origen
    GROUP BY c.region
    ORDER BY minutos DESC
"""))
```

`WITH nombre AS (...)` (una *CTE*) le pone nombre a una subconsulta: es la forma de escribir SQL largo en pasos legibles.

:::reto Minutos por plan con un JOIN
Con una sola consulta (usa `WITH` para separar los pasos), crea `por_plan`: los **minutos de voz** válidos por `plan_id` del cliente, cruzando los CDR con `clientes.csv`, ordenados de más a menos minutos. Columnas: `plan_id` y `minutos`.


:::pista
Una CTE `voz` con `linea_origen` y `(duracion_seg + 59) // 60 AS minutos` (solo VOZ y duración ≥ 0), otra `clientes` con el archivo de clientes, y al final `JOIN clientes c ON c.linea = v.linea_origen` con `GROUP BY c.plan_id`.

```pyprueba
import pandas as pd


def prueba_por_plan():
    """Minutos por plan, de mayor a menor"""
    requiere("por_plan")
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
    c = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})
    v = d[(d["tipo"] == "VOZ") & (d["duracion_seg"] >= 0) & (d["linea_origen"] != "")].copy()
    v["minutos"] = (v["duracion_seg"] + 59) // 60
    esperado = v.merge(c[["linea", "plan_id"]], left_on="linea_origen", right_on="linea").groupby("plan_id")["minutos"].sum().sort_values(ascending=False)
    igual([str(x) for x in por_plan["plan_id"]], [str(x) for x in esperado.index], "planes en orden")
    igual([int(x) for x in por_plan["minutos"]], [int(x) for x in esperado], "minutos")


def prueba_join():
    """Usa JOIN y WITH"""
    texto = codigo.upper()
    assert "JOIN" in texto and "WITH" in texto, "Cruza con JOIN y organiza la consulta con WITH"
```

```pysolucion
""").df()
```

## Funciones de ventana

Las **funciones de ventana** calculan sobre un grupo de filas **sin colapsarlas**: el `transform` de Pandas, en SQL. Con ellas, los duplicados exactos son una línea:

```pyrun
import duckdb

print(duckdb.sql("""
    SELECT cdr_id, tipo, fecha_inicio,
           ROW_NUMBER() OVER (PARTITION BY cdr_id ORDER BY rn) AS aparicion
    FROM (SELECT *, ROW_NUMBER() OVER () AS rn FROM read_csv('cdr.csv', delim='|', header=true))
    QUALIFY COUNT(*) OVER (PARTITION BY cdr_id) > 1
    ORDER BY cdr_id, aparicion
    LIMIT 6
"""))
```

- `PARTITION BY cdr_id` agrupa las filas del mismo ID.
- `ROW_NUMBER()` las numera (1 es la primera aparición; 2 o más, duplicados).
- `QUALIFY` filtra por el resultado de una función de ventana.

| Función de ventana | Para qué |
|---|---|
| `ROW_NUMBER()` | Numerar dentro del grupo (duplicados, "el primero de cada…") |
| `RANK()` | Ranking con empates |
| `SUM(x) OVER (PARTITION BY g ORDER BY t)` | Acumulado dentro del grupo (bolsa de minutos) |
| `LAG(x)` / `LEAD(x)` | Valor de la fila anterior / siguiente (tiempo entre llamadas) |
| `AVG(x) OVER (PARTITION BY g)` | Promedio del grupo en cada fila |

:::reto La llamada más larga de cada línea
Con una función de ventana, crea `mas_larga`: **una fila por línea** con su llamada de VOZ más larga (columnas `linea_origen`, `cdr_id` y `duracion_seg`), ordenada por `linea_origen`.

```pyprueba
import pandas as pd


def prueba_mas_larga():
    """Una fila por línea con su llamada más larga"""
    requiere("mas_larga")
    d = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
    v = d[(d["tipo"] == "VOZ") & (d["linea_origen"] != "")]
    esperado = v.groupby("linea_origen")["duracion_seg"].max().sort_index()
    igual([str(x) for x in mas_larga["linea_origen"]], [str(x) for x in esperado.index], "líneas")
    igual([int(x) for x in mas_larga["duracion_seg"]], [int(x) for x in esperado], "duraciones")


def prueba_ventana():
    """Usa una función de ventana"""
    texto = codigo.upper()
    assert "OVER" in texto and "PARTITION BY" in texto, "Usa ROW_NUMBER() OVER (PARTITION BY ...)"
```

- [ ] `WHERE` solo funciona con números
