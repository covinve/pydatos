## Enunciado

En el módulo 6 resumiste el archivo de ancho fijo con Python puro, línea por línea. Ahora vas a obtener **el mismo resultado** tratando el archivo como una **matriz de bytes**: cada registro mide 92 bytes (91 caracteres más el salto de línea), así que el archivo completo es una matriz de `(registros, 92)`.

Completa `ejercicios/m12-e9/ancho_fijo_numpy.py`:

1. `leer_matriz(ruta)` → `np.memmap(ruta, dtype=np.uint8, mode="r")` con la forma `(-1, 92)`. No carga el archivo: el sistema operativo lee del disco lo que vayas usando.
2. `columna_entera(matriz, inicio, fin)` → convierte una columna de dígitos ASCII a enteros **sin bucles por registro**. Ten en cuenta el signo `-` que puede aparecer en la primera posición (duraciones negativas).
3. `resumir(ruta)` → `{"registros", "por_tipo", "minutos_voz", "mb_datos"}` igual que en el módulo 6.

Prueba con la muestra (`python comprobar.py m12-e9`) y luego compara tiempos con tu versión del módulo 6 sobre 1 GB:

```powershell
python ejercicios/m06-e4/ancho_fijo.py datos/1GB/cdr_ancho_fijo.txt
python ejercicios/m12-e9/ancho_fijo_numpy.py datos/1GB/cdr_ancho_fijo.txt
```

## Pista 1

Un dígito ASCII menos `48` (el código de `"0"`) es su valor. Para un número de varias cifras, multiplica cada columna por su potencia de 10 y suma por fila:

```python
digitos = matriz[:, inicio:fin].astype(np.int64) - 48          # '-' daría -3: hay que tratarlo
pesos = 10 ** np.arange(fin - inicio - 1, -1, -1)
valores = (digitos * pesos).sum(axis=1)
```

Para el signo: detecta las filas cuyo primer byte es `ord("-")` (45), pon ese dígito en 0 antes de sumar y luego multiplica esas filas por −1.

## Pista 2

- Tipos: `matriz[:, 35:40]` son 5 bytes. Conviértelos a texto en bloque con `.copy().view("S5")`, quita espacios y cuéntalos con `np.unique(..., return_counts=True)`.
- Megas: el campo es `000026.274` (posiciones 74–83): la parte entera son las columnas 73–79 y los milésimos 80–83. Súmalos como enteros en milésimas para no acumular error de float: `mb_milesimas = entera * 1000 + milesimas`.
- Minutos: máscara `tipo == b"VOZ"` y duración ≥ 0.

## Solución

```python ancho_fijo_numpy.py
"""Ejercicio m12-e9: resumir un archivo de ancho fijo con np.memmap, sin bucles por registro.

Uso:
    python ejercicios/m12-e9/ancho_fijo_numpy.py datos/1GB/cdr_ancho_fijo.txt
"""

from __future__ import annotations

import sys
import time
from pathlib import Path

import numpy as np

ANCHO = 92  # 91 caracteres + salto de línea
CERO, MENOS = ord("0"), ord("-")


def leer_matriz(ruta: Path) -> np.ndarray:
    return np.memmap(ruta, dtype=np.uint8, mode="r").reshape(-1, ANCHO)


def columna_entera(matriz: np.ndarray, inicio: int, fin: int) -> np.ndarray:
    bloque = matriz[:, inicio:fin].astype(np.int64)
    negativo = bloque[:, 0] == MENOS
    bloque[negativo, 0] = CERO
    pesos = 10 ** np.arange(fin - inicio - 1, -1, -1, dtype=np.int64)
    valores = ((bloque - CERO) * pesos).sum(axis=1)
    return np.where(negativo, -valores, valores)


def resumir(ruta: Path) -> dict:
    matriz = leer_matriz(ruta)
    tipos = np.char.strip(np.ascontiguousarray(matriz[:, 35:40]).view("S5").ravel())
    nombres, cantidades = np.unique(tipos, return_counts=True)
    duracion = columna_entera(matriz, 67, 73)
    voz = (tipos == b"VOZ") & (duracion >= 0)
    datos = tipos == b"DATOS"
    milesimas = columna_entera(matriz, 73, 79) * 1000 + columna_entera(matriz, 80, 83)
    return {
        "registros": int(matriz.shape[0]),
        "por_tipo": {n.decode(): int(c) for n, c in zip(nombres, cantidades)},
        "minutos_voz": int(((duracion[voz] + 59) // 60).sum()),
        "mb_datos": round(int(milesimas[datos].sum()) / 1000, 3),
    }


if __name__ == "__main__":
    ruta = Path(sys.argv[1]) if len(sys.argv) > 1 else Path(__file__).parent / "muestra_ancho_fijo.txt"
    inicio = time.perf_counter()
    resultado = resumir(ruta)
    print(resultado)
    print(f"{ruta.stat().st_size / 1e6:,.0f} MB en {time.perf_counter() - inicio:.2f} s")
```

## Explicación

En un archivo de ancho fijo, la posición de cada campo es aritmética: el campo `tipo` del registro `i` está en el byte `i * 92 + 35`. Por eso se puede ver el archivo como una **matriz** y extraer columnas enteras de una vez, sin "partir" líneas.

`np.memmap` no lee el archivo al abrirlo: el sistema operativo trae del disco las páginas a medida que se usan. Así puedes trabajar con un archivo más grande que tu memoria, aunque las columnas que conviertes (duración, megas) sí ocupan RAM. Con 14 millones de registros, cada columna `int64` son unos 110 MB: perfectamente manejable. Para 20 GB lo procesarías por bloques de filas (`matriz[inicio:fin]`).

Sumar las megas como **enteros en milésimas** evita el error acumulado de float: el resultado coincide al milésimo con `esperado.json`.

¿Cuánto más rápido? Con Python puro, 1 GB toma del orden de un minuto; con esta versión, unos pocos segundos. Esta es la idea que llevan al extremo DuckDB y Polars (módulo 16).
