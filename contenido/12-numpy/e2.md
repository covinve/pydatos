## Enunciado

Recibes tres arrays paralelos (la posición `i` de cada uno es el mismo CDR): `tipos`, `duraciones` y `lineas`. Usa **máscaras** (sin bucles) para escribir:

1. `contar_invalidos(tipos, duraciones)` → cuántos registros tienen tipo fuera de `VOZ`/`SMS`/`DATOS` **o** duración negativa.
2. `minutos_voz_validos(tipos, duraciones)` → minutos facturables totales de los `VOZ` con duración ≥ 0 (`int`).
3. `lineas_con_llamadas_largas(tipos, duraciones, lineas, minimo)` → lista ordenada y sin repetidos de las líneas con al menos una llamada `VOZ` de **más** de `minimo` segundos.
4. `posiciones_negativas(duraciones)` → lista con las posiciones de las duraciones negativas.

## Pista 1

`np.isin(tipos, TIPOS_VALIDOS)` dice cuáles son válidos. Combina con `|` y niega con `~`:

```python
invalidos = ~np.isin(tipos, TIPOS_VALIDOS) | (duraciones < 0)
```

## Pista 2

- Para las líneas: filtra `lineas[mascara]` y aplica `np.unique` (que ya ordena y quita repetidos); `.tolist()` convierte a lista.
- Para las posiciones: `np.where(duraciones < 0)[0].tolist()`.

## Solución

```python
import numpy as np

TIPOS_VALIDOS = ["VOZ", "SMS", "DATOS"]


def contar_invalidos(tipos, duraciones):
    return int((~np.isin(tipos, TIPOS_VALIDOS) | (duraciones < 0)).sum())


def minutos_voz_validos(tipos, duraciones):
    voz = (tipos == "VOZ") & (duraciones >= 0)
    return int(((duraciones[voz] + 59) // 60).sum())


def lineas_con_llamadas_largas(tipos, duraciones, lineas, minimo):
    largas = (tipos == "VOZ") & (duraciones > minimo)
    return np.unique(lineas[largas]).tolist()


def posiciones_negativas(duraciones):
    return np.where(duraciones < 0)[0].tolist()
```

## Explicación

Las máscaras son la herramienta central de NumPy (y de Pandas): una condición produce un array de `True`/`False` del mismo largo, que sirve para **contar** (`.sum()`), **filtrar** (`a[mascara]`) o **encontrar posiciones** (`np.where`).

Como los tres arrays son paralelos, la misma máscara calculada con `tipos` y `duraciones` filtra correctamente `lineas`. Esa idea, columnas alineadas por posición, es exactamente un DataFrame de Pandas.
