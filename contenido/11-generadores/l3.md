El módulo `itertools` trae funciones para combinar iteradores sin construir listas. Todas son **perezosas**.

## islice: los primeros N (o una franja)

```pyrun
from itertools import islice

def numeros():
    n = 1
    while True:      # infinito
        yield n
        n += 1

print(list(islice(numeros(), 5)))          # los 5 primeros
print(list(islice(numeros(), 10, 15)))     # del 10 al 14
```

Muy útil para **mirar las primeras líneas** de un archivo enorme sin recorrerlo:

```python
with open("datos/20GB/cdr.csv", encoding="utf-8") as f:
    for linea in islice(f, 5):
        print(linea, end="")
```

:::reto Un vistazo al archivo
Con `islice`, y **sin recorrer todo el archivo**, guarda en `primeras` las tres primeras líneas de **datos** del `cdr.csv` de la muestra (es decir, sin el encabezado), sin el salto de línea final.

```pyreto
from itertools import islice

# Abre cdr.csv y toma las líneas 2, 3 y 4 con islice

print(primeras)
```

:::pista
`islice(archivo, 1, 4)` salta la línea 0 (el encabezado) y entrega las líneas 1, 2 y 3. Quita el salto de línea con `rstrip("\n")`.
:::

```pyprueba
def prueba_primeras():
    """primeras tiene las tres primeras líneas de datos"""
    requiere("primeras")
    with open("cdr.csv", encoding="utf-8") as f:
        lineas = f.read().splitlines()
    igual(list(primeras), lineas[1:4])


def prueba_usa_islice():
    """Usa islice"""
    assert "islice(" in codigo, "Toma las líneas con islice"
    assert ".read()" not in codigo and "readlines" not in codigo, "No cargues el archivo entero"
```

```pysolucion
from itertools import islice

with open("cdr.csv", encoding="utf-8") as archivo:
    primeras = [linea.rstrip("\n") for linea in islice(archivo, 1, 4)]

print(primeras)
```
:::

## chain: unir varios iterables en uno

```pyrun
from itertools import chain

septiembre = ["cdr_01.csv", "cdr_02.csv"]
octubre = ["cdr_10_01.csv"]

for archivo in chain(septiembre, octubre):
    print(archivo)

listas = [[1, 2], [3], [4, 5]]
print(list(chain.from_iterable(listas)))
```

## batched: procesar por lotes

Insertar registros en una base de datos de a uno es lentísimo; de a mil es mucho más rápido. `batched` (Python 3.12+) agrupa en tuplas de tamaño fijo:

```pyrun
from itertools import batched

registros = range(1, 11)
for lote in batched(registros, 4):
    print(lote)
```

:::reto Une y reparte en lotes
Los IDs pendientes llegaron en dos listas. Con `chain` y `batched`:

- `lotes`: la lista de lotes de **3** IDs, recorriendo primero `manana` y luego `tarde`;
- `ultimo`: el último lote (que puede ser más corto).

```pyreto
from itertools import batched, chain

manana = [101, 102, 103, 104]
tarde = [201, 202, 203]

# lotes y ultimo

print(lotes, ultimo)
```

:::pista
`chain(manana, tarde)` une las dos listas sin copiarlas; `batched(..., 3)` las agrupa. Convierte el resultado a lista para poder tomar `lotes[-1]`.
:::

```pyprueba
def prueba_lotes():
    """lotes agrupa de a 3, en orden"""
    requiere("lotes", "ultimo")
    igual([tuple(l) for l in lotes], [(101, 102, 103), (104, 201, 202), (203,)])
    igual(tuple(ultimo), (203,), "ultimo")


def prueba_herramientas():
    """Usa chain y batched"""
    assert "chain(" in codigo and "batched(" in codigo, "Usa chain y batched de itertools"
```

```pysolucion
from itertools import batched, chain

manana = [101, 102, 103, 104]
tarde = [201, 202, 203]

lotes = list(batched(chain(manana, tarde), 3))
ultimo = lotes[-1]

print(lotes, ultimo)
```
:::

## groupby: agrupar elementos consecutivos

`groupby` agrupa elementos **consecutivos** con la misma clave. Si los datos ya vienen ordenados por esa clave, resume sin cargar nada en memoria:

```pyrun
from itertools import groupby

cdrs = [("3001", 125), ("3001", 61), ("3002", 30), ("3003", 600), ("3003", 0)]

for linea, grupo in groupby(cdrs, key=lambda c: c[0]):
    minutos = sum((segundos + 59) // 60 for _, segundos in grupo)
    print(linea, minutos)
```

:::error groupby solo junta lo que está junto
Si los datos no están ordenados por la clave, la misma línea aparecerá en varios grupos separados:

```pyrun
from itertools import groupby

desordenados = ["VOZ", "SMS", "VOZ"]
print([(clave, len(list(g))) for clave, g in groupby(desordenados)])
```

Ordena antes (si cabe en memoria) o usa un diccionario/`Counter` para agrupar.
:::

:::reto Agrupa lo que llegó desordenado
Los CDR de abajo **no** vienen ordenados por línea. Con `groupby`, crea `minutos_por_linea`: un diccionario con los minutos facturables de cada línea. Ordena primero, o la misma línea aparecerá en varios grupos.

```pyreto
from itertools import groupby

cdrs = [("3002", 30), ("3001", 125), ("3003", 600), ("3001", 61), ("3002", 90), ("3003", 0)]

# Ordena por línea y agrupa con groupby

print(minutos_por_linea)
```

:::pista
`ordenados = sorted(cdrs, key=lambda c: c[0])` y luego `for linea, grupo in groupby(ordenados, key=lambda c: c[0]):`, sumando `(segundos + 59) // 60` de cada elemento del grupo.
:::

```pyprueba
def prueba_resultado():
    """Cada línea aparece una vez con todos sus minutos"""
    requiere("minutos_por_linea")
    igual(dict(minutos_por_linea), {"3001": 5, "3002": 3, "3003": 10})


def prueba_usa_groupby():
    """Usa groupby después de ordenar"""
    assert "groupby(" in codigo and "sorted(" in codigo, "Ordena con sorted y agrupa con groupby"
```

```pysolucion
from itertools import groupby

cdrs = [("3002", 30), ("3001", 125), ("3003", 600), ("3001", 61), ("3002", 90), ("3003", 0)]

ordenados = sorted(cdrs, key=lambda c: c[0])
minutos_por_linea = {}
for linea, grupo in groupby(ordenados, key=lambda c: c[0]):
    minutos_por_linea[linea] = sum((segundos + 59) // 60 for _, segundos in grupo)

print(minutos_por_linea)
```
:::

## accumulate: totales acumulados

```pyrun
from itertools import accumulate

minutos_por_llamada = [3, 0, 2, 60, 1]
print(list(accumulate(minutos_por_llamada)))   # cuánto lleva consumido después de cada llamada
```

¡Es el núcleo del ejercicio de la bolsa de minutos del módulo 3, en una línea!

## Otras útiles

| Función | Qué hace | Ejemplo |
|---|---|---|
| `count(inicio)` | Contador infinito | IDs consecutivos |
| `takewhile(cond, it)` | Entrega mientras se cumpla la condición | Leer hasta la primera línea vacía |
| `dropwhile(cond, it)` | Salta mientras se cumpla | Saltar comentarios iniciales |
| `pairwise(it)` | Pares consecutivos `(a, b), (b, c)…` | Diferencia entre llamadas seguidas |
| `zip_longest(a, b)` | Como `zip`, rellenando el más corto | Comparar dos archivos línea a línea |
| `tee(it, n)` | Duplica un iterador | Recorrer dos veces (¡usa memoria!) |

```pyrun
from itertools import pairwise

inicios = [100, 160, 175, 900]     # segundos del día en que empezó cada llamada
print([b - a for a, b in pairwise(inicios)])
```

:::reto Acumulados y llamadas en ráfaga
Con las llamadas de una línea (minutos facturables y segundo del día en que empezó cada una):

- `consumido`: la lista de minutos acumulados después de cada llamada, con `accumulate`;
- `agotada_en`: el número de llamada (contando desde 1) en que el acumulado **supera** los 100 minutos incluidos, o `None`;
- `rafagas`: cuántas llamadas empezaron **menos de 10 segundos** después de la anterior, con `pairwise`.

```pyreto
from itertools import accumulate, pairwise

minutos = [12, 40, 3, 30, 20, 7]
inicios = [3600, 3605, 3612, 4000, 4004, 9000]

# consumido, agotada_en y rafagas

print(consumido, agotada_en, rafagas)
```

:::pista
`consumido = list(accumulate(minutos))`. Para `agotada_en`, recorre `enumerate(consumido, start=1)` y quédate con el primero que pase de 100. Para las ráfagas: `sum(1 for a, b in pairwise(inicios) if b - a < 10)`.
:::

```pyprueba
def prueba_consumido():
    """consumido = [12, 52, 55, 85, 105, 112]"""
    requiere("consumido")
    igual(list(consumido), [12, 52, 55, 85, 105, 112])


def prueba_agotada():
    """agotada_en = 5"""
    requiere("agotada_en")
    igual(agotada_en, 5)


def prueba_rafagas():
    """rafagas = 3"""
    requiere("rafagas")
    igual(rafagas, 3)
```

```pysolucion
from itertools import accumulate, pairwise

minutos = [12, 40, 3, 30, 20, 7]
inicios = [3600, 3605, 3612, 4000, 4004, 9000]

consumido = list(accumulate(minutos))

agotada_en = None
for numero, total in enumerate(consumido, start=1):
    if total > 100:
        agotada_en = numero
        break

rafagas = sum(1 for a, b in pairwise(inicios) if b - a < 10)

print(consumido, agotada_en, rafagas)
```
:::

:::telco Detectar llamadas encadenadas
`pairwise` sobre las llamadas de una línea, ordenadas por hora, permite detectar patrones sospechosos: decenas de llamadas cortas separadas por pocos segundos suelen indicar fraude o un equipo defectuoso. Lo retomarás en el módulo 23.
:::
