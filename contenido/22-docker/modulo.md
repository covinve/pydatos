titulo: Docker
icono: 🐳
resumen: Empaquetar tu pipeline con todo lo que necesita para que corra igual en cualquier máquina. Imágenes y contenedores, Dockerfile para proyectos Python, volúmenes para los 20 GB, Docker Compose con PostgreSQL y entornos de desarrollo en GitHub Codespaces (útil para la oficina, sin instalar nada).
objetivos:
  - Entender la diferencia entre **imagen** y **contenedor**, y usar los comandos básicos de Docker.
  - Escribir un **Dockerfile** eficiente para un proyecto Python (capas, caché, usuario sin privilegios).
  - Controlar qué entra a la imagen con **.dockerignore** (¡nunca los 20 GB de datos!).
  - Montar datos con **volúmenes** y configurar con variables de entorno.
  - Levantar la aplicación con **PostgreSQL** usando **Docker Compose**, con *healthchecks*.
  - Trabajar en un **devcontainer** / GitHub Codespaces cuando no puedes instalar Docker.
