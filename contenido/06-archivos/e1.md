## Enunciado

El archivo `clientes.csv` (en la carpeta de trabajo de este ejercicio) viene del sistema legado: separado por comas y codificado en **latin-1**. Escribe:

1. `leer_clientes(ruta)` → lista de diccionarios (una por cliente) con los nombres y ciudades **con sus tildes correctas**. Todos los valores pueden quedar como texto.
2. `activos_por_ciudad(clientes)` → diccionario `ciudad → cantidad de clientes ACTIVO`, ordenado de mayor a menor cantidad (en empate, por nombre de ciudad).
3. `guardar_utf8(clientes, ruta_salida)` → escribe los clientes en un nuevo CSV **UTF-8 con BOM** (`utf-8-sig`) y separado por **punto y coma**, con el mismo encabezado. Devuelve cuántos clientes escribió.

```python
clientes = leer_clientes("clientes.csv")
clientes[0]["nombre"]          # "Servicios Cóndor S.A.S."
activos_por_ciudad(clientes)   # {"Bogotá": ..., ...}
guardar_utf8(clientes, "clientes_utf8.csv")   # 40
```

## Pista 2

Para escribir, `csv.DictWriter` necesita la lista de columnas (`fieldnames`). Tómala de las claves del primer cliente:

```python
with open(ruta_salida, "w", encoding="utf-8-sig", newline="") as archivo:
    escritor = csv.DictWriter(archivo, fieldnames=list(clientes[0]), delimiter=";")
    escritor.writeheader()
    escritor.writerows(clientes)
```

Un diccionario ordenado se construye con `dict(sorted(conteo.items(), key=...))`.

## Solución

```python
import csv
from collections import Counter


def leer_clientes(ruta):
    with open(ruta, encoding="latin-1", newline="") as archivo:
        return list(csv.DictReader(archivo))


def activos_por_ciudad(clientes):
    conteo = Counter(c["ciudad"] for c in clientes if c["estado"] == "ACTIVO")
    return dict(sorted(conteo.items(), key=lambda par: (-par[1], par[0])))


def guardar_utf8(clientes, ruta_salida):
    with open(ruta_salida, "w", encoding="utf-8-sig", newline="") as archivo:
        escritor = csv.DictWriter(archivo, fieldnames=list(clientes[0]), delimiter=";")
        escritor.writeheader()
        escritor.writerows(clientes)
    return len(clientes)


clientes = leer_clientes("clientes.csv")
print(len(clientes), clientes[0])
print(activos_por_ciudad(clientes))
```

## Explicación

Leer con `encoding="latin-1"` es todo lo que hace falta para que `Cóndor`, `Ibáñez` y `Núñez` se vean bien. El error típico es omitir el encoding: en tu PC con Windows quizá funcione (cp1252 es casi igual a latin-1), y en el servidor Linux falla con `UnicodeDecodeError`.

`list(csv.DictReader(...))` carga todo en memoria: está bien para 40 o 400.000 clientes (unos pocos MB). Para los CDR de 20 GB recorrerás el archivo sin convertirlo en lista.

El archivo de salida queda listo para abrir con doble clic en Excel con configuración regional colombiana: punto y coma como separador y BOM para que reconozca UTF-8.
