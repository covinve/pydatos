## Enunciado

El proceso nocturno debe dejar un registro claro de lo que hizo. Escribe `procesar(lineas, log)` que reciba una lista de líneas con el formato `cdr_id|tipo|duracion_seg` (sin encabezado) y un `logging.Logger`, y que:

1. Registre en **INFO** al empezar: `Inicio: 5 líneas por procesar`.
2. Para cada línea inválida registre un **WARNING**: `Línea 3: tipo desconocido 'VOX'` o `Línea 4: duración inválida '-5'`. Una línea es inválida si el tipo no es `VOZ`, `SMS` o `DATOS`, o si la duración no es un entero mayor o igual a 0 (revisa el tipo primero). La numeración empieza en 1.
3. Registre en **INFO** al terminar: `Fin: 3 válidas, 2 inválidas`.
4. Si **ninguna** línea es válida (y había líneas), registre además un **ERROR**: `Ninguna línea válida: revisar el archivo de origen`.
5. Devuelva la cantidad de líneas válidas.

La función **no debe usar `print`**: todo va por el logger que recibe.

```python
import logging

log = logging.getLogger("bitacora")
```

## Pruebas

```python
import ast
import logging


class Capturador(logging.Handler):
    def __init__(self):
        super().__init__()
        self.registros = []

    def emit(self, record):
        self.registros.append((record.levelname, record.getMessage()))


def correr(lineas):
    log = logging.getLogger("prueba_bitacora")
    log.handlers.clear()
    log.propagate = False
    log.setLevel(logging.DEBUG)
    capturador = Capturador()
    log.addHandler(capturador)
    resultado = procesar(lineas, log)
    return resultado, capturador.registros


def prueba_flujo_completo():
    """Registra inicio, advertencias y fin"""
    requiere("procesar")
    resultado, registros = correr(["1|VOZ|125", "2|SMS|0", "3|VOX|10", "4|VOZ|-5", "5|DATOS|900"])
    igual(resultado, 3)
    igual(registros, [
        ("INFO", "Inicio: 5 líneas por procesar"),
        ("WARNING", "Línea 3: tipo desconocido 'VOX'"),
        ("WARNING", "Línea 4: duración inválida '-5'"),
        ("INFO", "Fin: 3 válidas, 2 inválidas"),
    ])


def prueba_duracion_no_numerica():
    """Una duración que no es número también es inválida"""
    _, registros = correr(["1|VOZ|abc"])
    assert ("WARNING", "Línea 1: duración inválida 'abc'") in registros


def prueba_ninguna_valida():
    """Si ninguna línea es válida, registra un ERROR al final"""
    resultado, registros = correr(["1|VOX|1", "2|MMS|2"])
    igual(resultado, 0)
    igual(registros[-1], ("ERROR", "Ninguna línea válida: revisar el archivo de origen"))


def prueba_lista_vacia():
    """Sin líneas no hay error"""
    resultado, registros = correr([])
    igual(resultado, 0)
    igual(registros, [("INFO", "Inicio: 0 líneas por procesar"), ("INFO", "Fin: 0 válidas, 0 inválidas")])
```

## Pista 1

Recorre con `enumerate(lineas, start=1)` y separa con `split("|")`. Para la duración usa el patrón EAFP:

```python
try:
    duracion = int(texto_duracion)
except ValueError:
    duracion = -1
```

así un texto como `"abc"` cae en el mismo caso que una duración negativa.

## Pista 2

Los mensajes con datos variables se pasan como argumentos del logger:

```python
log.info("Inicio: %d líneas por procesar", len(lineas))
log.warning("Línea %d: tipo desconocido %r", numero, tipo)
```

`%r` muestra el valor con comillas, como `repr()`. Al final, compara las válidas con cero **y** que la lista no esté vacía antes de registrar el ERROR.

## Solución

```python
import logging
import sys

TIPOS = {"VOZ", "SMS", "DATOS"}


def procesar(lineas, log):
    log.info("Inicio: %d líneas por procesar", len(lineas))
    validas = 0
    for numero, linea in enumerate(lineas, start=1):
        _, tipo, texto_duracion = linea.split("|")
        if tipo not in TIPOS:
            log.warning("Línea %d: tipo desconocido %r", numero, tipo)
            continue
        try:
            duracion = int(texto_duracion)
        except ValueError:
            duracion = -1
        if duracion < 0:
            log.warning("Línea %d: duración inválida %r", numero, texto_duracion)
            continue
        validas += 1
    invalidas = len(lineas) - validas
    log.info("Fin: %d válidas, %d inválidas", validas, invalidas)
    if lineas and validas == 0:
        log.error("Ninguna línea válida: revisar el archivo de origen")
    return validas


logging.basicConfig(level=logging.INFO, format="%(levelname)-8s %(message)s", stream=sys.stdout, force=True)
log = logging.getLogger("bitacora")
procesar(["1|VOZ|125", "2|SMS|0", "3|VOX|10", "4|VOZ|-5", "5|DATOS|900"], log)
```

## Explicación

Fíjate en el diseño: `procesar` **recibe** el logger en lugar de crearlo o configurarlo. Eso permite que:

- El programa principal decida si los mensajes van a la pantalla, a un archivo o a ambos.
- Las pruebas conecten un `Capturador` y verifiquen **exactamente** qué se registró, con qué nivel y en qué orden.

Una bitácora bien hecha cuenta la historia del proceso: cuándo empezó, qué encontró y cómo terminó. Si una mañana falta la línea "Fin", sabes que el proceso se interrumpió a mitad de camino.

En los proyectos usarás `logging.getLogger(__name__)` en cada módulo y configurarás el destino una sola vez en el punto de entrada.
