## Enunciado

Escribe `tabla_regional(cdr, clientes)` que devuelva una tabla dinámica con:

- **filas**: `region` del cliente (solo CDR de líneas que son clientes);
- **columnas**: `LOCAL`, `NACIONAL`, `INTERNACIONAL` (en ese orden);
- **valores**: suma de minutos facturables de las llamadas `VOZ` con duración ≥ 0;
- celdas sin datos en 0, valores enteros;

Y `region_mas_internacional(tabla)` → la región (sin contar `TOTAL`) con mayor **porcentaje** de minutos internacionales sobre su total.

## Pista 2

Para el orden de las columnas usa `reindex(columns=["LOCAL", "NACIONAL", "INTERNACIONAL", "TOTAL"], fill_value=0)` y `.astype(int)`. Para la región: `(sin_total["INTERNACIONAL"] / sin_total["TOTAL"]).idxmax()`, donde `sin_total = tabla.drop(index="TOTAL")`.

## Solución

```python
import pandas as pd

cdr = pd.read_csv("cdr.csv", sep="|", dtype={"linea_origen": "string"}, keep_default_na=False)
clientes = pd.read_csv("clientes.csv", encoding="latin-1", dtype={"linea": "string"})

DESTINOS = ["LOCAL", "NACIONAL", "INTERNACIONAL"]


def tabla_regional(cdr, clientes):
    voz = cdr[(cdr["tipo"] == "VOZ") & (cdr["duracion_seg"] >= 0)].copy()
    voz["minutos"] = (voz["duracion_seg"] + 59) // 60
    voz = voz.merge(clientes[["linea", "region"]], left_on="linea_origen", right_on="linea", how="inner")
    tabla = voz.pivot_table(index="region", columns="destino", values="minutos", aggfunc="sum",
                            fill_value=0, margins=True, margins_name="TOTAL")
    return tabla.reindex(columns=DESTINOS + ["TOTAL"], fill_value=0).astype(int)


def region_mas_internacional(tabla):
    sin_total = tabla.drop(index="TOTAL")
    return (sin_total["INTERNACIONAL"] / sin_total["TOTAL"]).idxmax()


t = tabla_regional(cdr, clientes)
print(t)
print(region_mas_internacional(t))
```

## Explicación

`pivot_table` reemplaza la tabla dinámica que tantas veces se arma a mano en Excel, con una ventaja: el código se vuelve a ejecutar cada mes con un clic, siempre igual. 

Comparar **porcentajes** y no valores absolutos es importante: la región más grande casi siempre tiene más minutos internacionales en total, pero no necesariamente la mayor proporción. La pregunta de negocio ("¿dónde se llama más al exterior?") define cuál de los dos usar.
